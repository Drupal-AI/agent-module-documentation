A library of ready-to-use Paragraph types for page building.

---

Web Initial Paragraphs is a collection of ready-to-use Paragraphs for Drupal projects, providing flexible and reusable structures — so a site starts with a set of pre-built Paragraph types (hero, cards, media, CTA, etc.) for building landing pages without creating each from scratch. Depends on core paragraphs + media/field stack and `field_group`; supports Drupal 10.1+ and 11. Project `wip`.

Google Analytics Light Report shows Google Analytics reports inside Drupal via the Google API client.

---

Google Analytics Light Report fetches Google Analytics data using the google-api-php-client library and displays the report inside Drupal — a lightweight way to surface site analytics in the admin without an external dashboard.

Google API credentials should be stored securely (env-backed). Permissions cover viewing (`google analytics report light`) and administration (`administer google analytics light report`). Depends on the `libraries` module; supports Drupal 8 through 11.

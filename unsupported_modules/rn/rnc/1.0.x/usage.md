A Secret-Santa-style random name matcher with spouse constraints.

---

Random Name Chooser (rnc) is a per-user random name chooser with spouse constraints and per-user settings — participants add names to a list and each draws a random match, with the matcher avoiding pairing someone with their spouse (a `spouse_letter` grouping), for gift-exchange / Secret-Santa style draws. Supports Drupal 10 and 11.

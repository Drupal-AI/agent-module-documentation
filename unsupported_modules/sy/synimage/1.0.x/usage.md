Synimage provides a WYSIWYG Colorbox image.

---

Synimage provides a **WYSIWYG plugin for inserting images that open in a Colorbox lightbox** — so editors
can add an image in the rich-text editor that pops up a larger version in a Colorbox overlay. It is in the
Synapse package.

Use it to add lightbox images from the editor. It is a content-editing/display feature; it inserts image
markup (ensure the text format allows it) and images follow core file access, and it has no access-control
role. Enable it in the editor.

Override field values on referenced entities per-reference instance.

---

Entity Reference Field Override lets you override specific field values on referenced entities per-instance without modifying the original entity — so the same referenced entity (e.g. a shared block/media/node) can display different field values in different places that reference it, storing the overrides on the reference rather than the source. It's shipped by the `erfo` project. Depends on core `field`; supports Drupal 10.3+ and 11.

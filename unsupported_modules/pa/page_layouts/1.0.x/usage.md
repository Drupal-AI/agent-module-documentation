Define page sections for use in tutorials or documentation.

---

Page Layouts defines sections of a page to use in things like tutorials or documentation — so a site can mark up structured page sections (steps, blocks) that guided content (tutorials, docs) references and renders consistently. Depends on core `views`; supports Drupal 8 through 11.

Relocate resource-intensive scripts into a web worker via Partytown.

---

Partytown Drupal integrates the Partytown lazy-loaded library to help relocate resource-intensive scripts (analytics, tag managers, third-party JS) into a web worker, off the main thread — so heavy third-party scripts don't block page interactivity, improving performance/Core Web Vitals. Supports Drupal 10 and 11.

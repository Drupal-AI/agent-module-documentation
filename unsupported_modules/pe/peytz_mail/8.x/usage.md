Communicate with Peytz Mail newsletter services.

---

Peytz Mail is a basic module for communicating to Peytz Mail services — connecting Drupal to the Peytz Mail email/newsletter platform so subscribers and mailings can be managed/synced via its API.

The Peytz Mail API credentials are admin-configured and should be stored securely (env-backed), never committed. Supports Drupal 8.8 through 11.

Phone Link provides a field formatter that renders text and/or telephone fields as clickable tel: links.

---

A phone number should be tappable on mobile. Phone Link formats text/telephone fields as clickable `tel:` links. It is a display formatter with no security surface — it wraps the field value in a tel: link. Confirm the phone numbers are formatted for tel: (the formatter typically handles this).

Create a new node preloaded with another node's values.

---

Node Add Copy creates a form of the same node type with info preloaded from another node's values — so an editor can start a new node pre-filled from an existing one (a 'duplicate to a new node' flow), speeding up creating similar content. Supports Drupal 9, 10, and 11.

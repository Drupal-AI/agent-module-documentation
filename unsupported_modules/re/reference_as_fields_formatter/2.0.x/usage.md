Render a referenced entity's fields merged into the host render array.

---

Entity Reference as fields formatter is an entity reference formatter that merges the referenced entity's fields into the content render array — so instead of rendering the referenced entity as a nested block, its individual fields appear inline among the host entity's own fields, useful for flattening referenced content into a single display. Supports Drupal 10 and 11.

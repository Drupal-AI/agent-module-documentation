Cache-safe reverse entity-reference lookup with computed-field plugins.

---

Reverse Reference provides reverse entity reference lookup with cache-safe correctness, optional async indexing, and computed field plugins — so an entity can expose the entities that reference it (the inverse of a normal reference field) as a computed field, with cache metadata handled correctly and optional background indexing for performance. Depends on core `system` and `field`; supports Drupal 10 and 11.

# Entity Meta Force (entity_meta_force) — agent index

Nested submodule of **entity_meta_example**, itself under **emr**. One of **four** demonstration
meta types. Version **8.x-1.9**. Core `^10 || ^11`.

**It exists to be one of several** — EMR allows a host to carry multiple meta types, configured and
revised independently, which one example cannot show.

The `force` subject is a deliberate placeholder. The useful content is the **shape**: how a meta
type declares itself, defines fields, relates to a host and joins the host's revisions.

**Not for production.** Best used as a **diff target** — build your own, compare, and the
differences are either deliberate or a mistake you just found.

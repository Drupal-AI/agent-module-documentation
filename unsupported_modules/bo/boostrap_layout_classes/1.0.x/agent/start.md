# Boostrap Layout Classes (`boostrap_layout_classes`) — agent index
**Field widget + formatter for attaching Bootstrap layout CSS classes to fields.**

- **Version:** 1.0.x  | **Core:** ^8 || ^9 (composer allows ^10)
- **Depends on:** core `field`
- **No routes, no permissions, no admin form.**
- **Plugins:** `BoostrapLayoutClassesWidget` (Form Display) + `BoostrapLayoutClassesFormatter` (Manage Display).
- Note the misspelled machine name `boostrap_layout_classes`.

**Security:** presentational only; no routes, no user input beyond a class selection stored on a field. No findings.

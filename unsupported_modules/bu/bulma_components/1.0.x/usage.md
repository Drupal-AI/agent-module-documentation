Bulma Components offers ready-made Bulma-based SDC components for themes.

---

Bulma Components provides a set of components to use when theming with the Bulma CSS framework — ready-made Single Directory Components (SDC) built with Bulma markup/classes, so theme developers can compose UIs from Bulma components with schema-validated props.

It's a theming/component library with no content or access role of its own. Depends on the `components` and `component_schema` modules; supports Drupal 10.2+, 11, and 12.

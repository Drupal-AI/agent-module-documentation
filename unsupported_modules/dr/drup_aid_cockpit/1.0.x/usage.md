An admin cockpit to watch and steer the Drup-AID master agent and its sub-agents.

---

Drup-AID Cockpit is the agent cockpit — watch the Drup-AID master agent and its sub-agents work, and steer them, in one branded admin screen — providing an admin UI (gated by the `access drup-aid cockpit` permission) to observe and direct the Drup-AID AI agents built on the AI and AI Agents modules.

AI provider keys are handled by the `ai` module (env-backed via a Key entity); the cockpit is permission-gated. Depends on `ai` and `ai_agents`; supports Drupal 10.3+ and 11. Part of the Drup-AID project.

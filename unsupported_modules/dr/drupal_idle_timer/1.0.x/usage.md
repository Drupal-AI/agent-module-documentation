An idle timer that manages user sessions on inactivity.

---

Drupal Idle Timer provides a Drupal idle timer with multiple configuration options — a flexible way to manage user sessions and inactivity, so after a configurable idle period the user is warned and/or logged out, improving security on shared/kiosk machines. It's shipped by the `dit` project. Supports Drupal 10 and 11.

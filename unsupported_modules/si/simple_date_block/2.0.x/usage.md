A block showing a configurable date/time with formats and timezones.

---

Simple Date Block displays a configurable date and time in a block, with support for custom formats and timezones — so a site can show the current date/time (or a fixed date) in a block, formatted as configured and in a chosen timezone, e.g. a header clock or event date. Depends on core `block` and `system`; supports Drupal 9.5+, 10, and 11. Project `sdb`.

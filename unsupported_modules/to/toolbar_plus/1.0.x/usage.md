A standardized admin-toolbar UI for a suite of tool-based modules.

---

Toolbar + provides a standardized UI for a suite of tool-based modules — extending the admin navigation toolbar with a consistent interface for the related 'tool' modules, so their controls appear together in a unified toolbar. Depends on core `navigation` and `twig_events`; supports Drupal 10 and 11.

Tool Workspace adds Workspaces helper tools via the Tool module.

---

Tool - Workspace provides Workspaces-related tools — helpers/actions for working with core Workspaces (content staging), built on the Tool framework, so developers/site builders can extend or automate workspace operations as part of Tool-based workflows.

It's a developer/site-building tool with no content or access role of its own (workspace access follows core Workspaces). Depends on `tool` and core `workspaces`; supports Drupal 10 and 11.

Filter which content types a Link field can link to, site-wide.

---

Link Field Entity Filter provides the ability to filter content types for a Link field across the site — so a link field configured to link to internal content can be restricted to specific content types, guiding editors to valid targets. It's shipped by the `link_field_filter` project. Depends on core `link`; supports Drupal 9, 10, and 11.

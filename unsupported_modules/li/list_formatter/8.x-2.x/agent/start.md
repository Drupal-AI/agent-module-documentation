# List Formatter — agent index

A **field formatter that renders multi-value fields as HTML lists** (ul/ol/comma-separated). Depends on core
`field`. Version **8.x-2.0-alpha1**. Core `^8.8||^9||^10||^11`.

Content-display — values follow normal field sanitization; no content/access role.

List Formatter renders fields as lists.

---

List Formatter provides a **field formatter that renders multi-value fields as HTML lists** — outputting a
field's values as an unordered/ordered list or comma-separated inline list, instead of the default per-item
markup. It depends on core Field, in the Fields package.

Use it to render multi-value fields as lists. It is a content-display feature affecting field rendering; values
follow normal field sanitization and it has no content or access role. Apply the list formatter to a field.

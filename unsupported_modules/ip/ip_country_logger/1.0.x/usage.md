Logs the country associated with the current user's IP address.

---

IP Country Logger logs the country associated with the IP address of the current user — resolving each request's IP to a country and recording it, so a site can analyse or act on visitor geography (analytics, geo-based decisions). Because it processes IP addresses (personal data), handle logs per your privacy policy. It's the module shipped by the `country_trace` project. Supports Drupal 9, 10, and 11.

Generate images from a text prompt in image fields and CKEditor 5.

---

AI Image (project `openai_image_for_drupal`) generates images from a text prompt in image fields and CKEditor 5, using any provider supported by the AI module — so editors can type a prompt and get a generated image inserted into an image field or the rich-text editor.

The AI provider/keys are configured via the `ai` module (env-backed via a Key entity); each generation is a (paid) API call, so scope access and watch cost. Depends on `ai` and core `file`/`image`; supports Drupal 11.2+ and 12.

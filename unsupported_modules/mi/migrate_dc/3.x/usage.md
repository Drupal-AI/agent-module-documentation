A migration solution for default/dummy content.

---

Migrate DC provides a migration solution for default/dummy contents — helping ship and import default or demo content into a site via Migrate (migrate_plus), useful for distributions and demos that need seed content. Depends on core `migrate` and `migrate_plus`; supports Drupal 11.

Extension Reference provides a field type to reference extensions.

---

Extension Reference provides a **field type that references installed extensions** (modules/themes) — so an
entity can store a reference to a module or theme by machine name, selectable via an options widget. It depends
on core Field and Options, in the Field package.

Use it to model references to extensions (e.g. documentation, dashboards). It is a developer/fields feature; the
referenced value is an extension machine name and it has no access-control role. Add an extension-reference field
to an entity.

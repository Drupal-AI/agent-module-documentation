Visualize relationships between configuration objects, plus admin helpers.

---

Devel Visualizer visualizes relationships between configuration objects and provides other administrator helper features — rendering a graph of how config entities reference each other, aiding developers in understanding config dependencies. It's a development tool (extends Devel). Depends on `devel`; supports Drupal 10.3+ and 11.

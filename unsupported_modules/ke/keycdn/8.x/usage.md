Purge KeyCDN cache when Drupal content changes.

---

KeyCDN integrates KeyCDN with Drupal — a purger for the Purge module that invalidates KeyCDN's edge cache when content changes, keeping the CDN in sync with the site.

The KeyCDN API key should be stored securely (env-backed), never committed. Depends on `purge`; supports Drupal 8 through 11.

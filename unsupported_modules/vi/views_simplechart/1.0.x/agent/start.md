# Simple Chart (views_simplechart) — agent index

Views **style rendering results as charts** via the **Google Chart API** (bar/line/pie). Depends on
core `views` + `google-chart` library. Version **1.0.x** (dev). Core `^8||^9||^10||^11`.

Display/visualisation — the View's access governs charted data. Uses Google's charting service (mind
data-privacy of charted data).

Simple Chart (views_simplechart) provides a Views style that visualizes View results as charts via the Google Chart API.

---

Simple Chart (views_simplechart) adds a Views display style that renders View results as charts
using the Google Chart API — turning a View's rows/fields into bar, line, pie and similar charts
without custom charting code. It depends on core Views and loads a `google-chart` library.

Use it for lightweight data visualisation driven by Views: dashboards, simple reports, quick charts of
content or field data. Because it uses the Google Chart API, chart rendering involves Google's charting
service (client-side), so consider that dependency and any data-privacy implications of sending chart
data to Google's chart tools. It is a display/visualisation feature; the View's own access governs
which data is charted.

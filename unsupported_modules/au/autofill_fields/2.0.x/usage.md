Autofill Fields automatically fills fields based on the value of other fields.

---

Autofill Fields **automatically fills fields based on other fields' values** — copying/deriving a field's
value from another field on the same form (e.g. auto-populate a slug from a title), to speed up authoring. It is
in the fields package.

Use it to auto-populate dependent fields. It is a content-editing/form-UI feature affecting field entry; values
follow normal field handling and it has no access-control role. Configure the autofill rules.

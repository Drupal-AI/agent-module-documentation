A framework to speed up building entity ListBuilders with pluggable columns/filters.

---

Ultimate list builder allows speeding up the creation of a ListBuilder for an Entity and ConfigEntity — a developer framework: replace an entity's list_builder with `ULBEntityListBuilder`/`ULBConfigEntityListBuilder`, then add header/column elements and filters as tagged services (`ultimate_list_builder.build_header`), so admin list pages get consistent, extensible columns and filters without boilerplate. It's a developer dependency. Supports Drupal 10 and 11.

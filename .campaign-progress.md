# Campaign progress (overnight autonomous run, started 2026-07-25)

Goal: document up to ~5000 more popular Drupal-11 contrib modules, agent-docs + 3-tier
evals (NO human-docs, do NOT run eval harness). Parallel subagents, 6 per wave, 40
projects per wave. User is away; do not ask questions, keep driving waves.

## Work list & tooling
- `.campaign-5000.txt` — 5525 candidate projects, ranks 617-6150 (TSV: rank, name, installs).
- `scripts/next-wave.sh [N]` — prints next N undocumented projects (recomputes from disk).
- `scripts/batch-install.sh --file .wave.txt` — bisecting composer require.
- `scripts/wave-prepare.sh --file .wave.txt` — chunked enable (5 at a time) + auto
  check-default-config --fix + repair-half-installed. Emits project/version/module/subs TSV.
- `scripts/check-default-config.sh [--fix]` — missing default config + unregistered entity types.
- `scripts/repair-half-installed.sh --list|--repair` — fixes modules enabled w/o system.schema.
- Agent brief: scratchpad BRIEF.md (path in task prompts).

## Per-wave loop
1. next-wave.sh 40 > .wave.txt
2. batch-install → wave-prepare (records manifest) → note FAILED/obsolete
3. join ranks from .campaign-5000.txt, split enabled into 6, launch 6 agents w/ BRIEF
4. drain all 6 → validate-docs + JSON/tier + script-ref + rm-before-pmu sweeps
5. check-default-config audit; merge .new-categories (idempotent); commit wave; advance pagination.md

# G2 Glossary — agent index

**Manages a node-based glossary** (term/definition nodes, alphabetical browsing, blocks). Depends on core `node`,
`taxonomy`, `views`, plus `statistics` and contrib `xmlrpc`. Provides permissions. Version **8.x-1.0-beta3**. Core
`^10.3||^11`.

Content-display — entries follow normal node access; note the **contrib XML-RPC** dependency (historically an
attack surface — only enable its server if needed).

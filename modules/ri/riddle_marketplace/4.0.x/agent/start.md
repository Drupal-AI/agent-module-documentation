# Riddle Marketplace — agent index

Imports and displays **Riddle quizzes/polls as media** in Drupal (`media_riddle_marketplace` submodule).
Provides permissions. Version **4.0.1-beta2**. Core `^10.1||^11`.

Media/integration — authenticates with **Riddle API tokens** (secrets, HTTPS); content hosted/served by
**Riddle** (third-party embed; participant data handled externally — privacy). No access role beyond
permission.

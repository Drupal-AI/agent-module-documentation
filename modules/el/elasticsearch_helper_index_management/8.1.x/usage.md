Elasticsearch Helper Index management provides tools for managing Elasticsearch index plugins defined via the Elasticsearch Helper module.

---

Elasticsearch Helper Index management provides management tools/UI for Elasticsearch index plugins —
letting administrators manage (create, update, reindex, delete) the Elasticsearch indices defined via the
Elasticsearch Helper module, without direct Elasticsearch API access. It depends on the Elasticsearch
Helper module.

Use it on Elasticsearch Helper-based sites to manage indices from Drupal. It is an administration/search-
backend tool operating on Elasticsearch indices; because index operations (reindex, delete) are impactful,
access should be restricted to trusted administrators. The Elasticsearch connection/credentials are
configured in Elasticsearch Helper — protect those. It has no content-access role. Manage indices via the
provided tools.

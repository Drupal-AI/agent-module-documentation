Store Drupal files in Oracle Cloud (OCI) Object Storage (S3-compatible).

---

OCI Object Storage File System provides S3-compatible OCI Object Storage integration with an admin UI, file migration, and image-style support — so Drupal's public (and private) files can live in Oracle Cloud Infrastructure Object Storage instead of local disk, for scalable/containerised hosting.

The OCI credentials/namespace/bucket are admin-configured and should be stored securely (env-backed), never committed; scope bucket permissions so private files aren't world-readable. Supports Drupal 10, 11, and 12.

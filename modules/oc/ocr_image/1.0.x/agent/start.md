# OCR image, document parser — agent index

**Converts an uploaded image/document to text (OCR)** into a field (make scanned documents/images searchable/
usable text). Version **1.0.2**. Core `^9||^10||^11`.

Media/content — processes uploaded files server-side via an OCR engine (ensure the tooling is resourced/
secured); extracted text becomes content; no access role.

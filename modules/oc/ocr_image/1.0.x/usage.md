OCR image, document parser converts an image to text into a link field.

---

OCR image, document parser performs OCR — converting an uploaded image/document to extracted text and
storing it (into a field), so scanned documents/images become searchable/usable text. It is in the Ocr
package.

Use it to extract text from images/scanned documents. It is a media/content feature that processes uploaded
files server-side (via an OCR engine); the extracted text becomes content, and it has no access-control role.
Note OCR runs on uploaded files (server-side processing) — ensure the OCR tooling is appropriately resourced/
secured. Configure the OCR field and behaviour.

# Frontify Assets — agent index

Integrates the **Frontify (V2) DAM platform** to use Frontify assets in Drupal media (`frontify_assets_colorbox`
submodule). Provides permissions. Version **2.0.4**. Core `^9||^10||^11`.

Media/integration — connects to the **Frontify API** (token as a secret, HTTPS); assets referenced in Frontify
(external). No access role beyond permission.

Frontify Assets integrates Frontify V2 with Drupal.

---

Frontify Assets integrates the **Frontify (V2) digital-asset-management (DAM) platform** with Drupal —
letting editors browse and use assets stored in Frontify as Drupal media (with a Colorbox submodule). It
provides its own permissions, in the Media package.

Use it to use Frontify-hosted assets in Drupal. It is a media/integration feature. Security/data handling: it
connects to the **Frontify API** — store the **API token/credentials** as **secrets** (env/Key) over HTTPS, and
assets are served from/referenced in **Frontify** (external — mind availability and access on that side). It has
no access-control role beyond its permission. Configure the Frontify connection.

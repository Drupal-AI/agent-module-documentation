# Frontify Integration — agent index

Integrates the **Frontify DAM** with Drupal media — browse/use Frontify-hosted assets as Drupal
media. Integrates core `media`, `media_library`, `block_content`; config at
`frontify.admin_config_frontify`; `frontify_colorbox` submodule for lightbox. Version **3.0.1**. Core
`^10||^11`.

Store Frontify API credentials as secrets. Provides admin permissions. Governs asset sourcing/display,
not content access.

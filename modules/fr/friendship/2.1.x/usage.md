Friendship provides friendship functionality between users.

---

Friendship **provides friendship/connection functionality between users** — friend requests, accept/decline,
and a list of connections, for social/community sites. It provides its own permissions, in the Friendship
package.

Use it to add user friendships/connections. It is a user-engagement/social feature. Data-handling note:
friendship relationships are **personal/social data** — expose friend lists only per your privacy expectations,
and gate friend-management by its permissions. It has no broader access-control role beyond its permissions (a
friendship relationship is not, by itself, a content-access grant unless another module uses it). Configure the
friendship features.

Currency conversion using the FreecurrencyAPI service.

---

Currency Converter (FreecurrencyAPI) provides currency conversion based on the FreecurrencyAPI service — fetching live exchange rates from FreecurrencyAPI so a site can display converted prices/amounts.

The FreecurrencyAPI key is admin-configured and should be stored securely (env-backed), never committed. Supports Drupal 8 through 11.

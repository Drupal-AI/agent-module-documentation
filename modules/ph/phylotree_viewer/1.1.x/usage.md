A field formatter that renders phylogenetic tree files.

---

Phylotree Viewer is a file-field formatter for Phylotree files — rendering phylogenetic tree data files (Newick/PhyloXML) as an interactive tree visualization on the page, useful for biology/bioinformatics sites. Supports Drupal 10 and 11.

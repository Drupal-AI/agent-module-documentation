A block listing recent PHP warnings/errors.

---

PHP Warnings & Errors provides a block listing PHP warnings — surfacing recent PHP warning/error log entries (from dblog) in a block so developers notice PHP issues during development without digging through the reports. It's a development tool. Depends on core `dblog`; supports Drupal 9.3+, 10, and 11.

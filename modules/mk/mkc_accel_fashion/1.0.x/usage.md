Fashion-vertical features for MonkeysCommerce (size charts, lookbooks).

---

MKC Accelerator Fashion is a fashion-vertical accelerator for MonkeysCommerce — size charts, lookbooks, return/exchange workflows, and fit guidance — so a MonkeysCommerce store selling apparel gets the fashion-specific features shoppers expect. Depends on the MonkeysCommerce suite (`mkc_core`, `mkc_catalog`); supports Drupal 11.3+ and 12.

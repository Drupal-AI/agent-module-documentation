A field to display Luzmo (embedded analytics) dashboards.

---

Luzmo Viewer provides a field to display Luzmo dashboards — so a Luzmo (embedded BI/analytics) dashboard can be embedded on content via a field, presenting interactive charts/reports from Luzmo inside Drupal.

The Luzmo API/embed credentials are admin-configured and should be stored securely (env-backed), never committed. Supports Drupal 9, 10, and 11.

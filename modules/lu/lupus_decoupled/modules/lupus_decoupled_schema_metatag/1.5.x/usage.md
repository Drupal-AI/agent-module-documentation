Lupus Decoupled Schema Metatag exposes JSON-LD structured data, generated by Schema Metatag, to the decoupled front end.

---

SEO is the recurring casualty of decoupling. Meta tags, canonical URLs and structured data are computed from the entity and its context, and a front end that renders content without them produces pages that look right to a person and are invisible to a search engine or a rich result.

This submodule carries the JSON-LD half: Schema Metatag builds the structured data in Drupal, where the field values, the content model and the token replacements live, and this exposes it so the front end can emit it in the document head.

The practical benefit is that structured data stays a Drupal configuration task — a site owner adds an Article schema mapping and it takes effect — rather than becoming front-end code that drifts from the content model. The thing to verify is the front end's side: the JSON-LD has to end up in the rendered HTML that crawlers see, which for a server-rendered Nuxt setup is straightforward and for a purely client-rendered one is not.

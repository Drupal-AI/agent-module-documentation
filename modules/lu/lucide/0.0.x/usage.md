Lucide provides the Lucide icon library as an icon pack.

---

Lucide provides the **Lucide icon library as an icon pack** — making Lucide's open-source SVG icons
available through Drupal 11's icon API for use in themes/components. It is in the Media package.

Use it to use Lucide icons on the site. It is a theming/media feature; icons are static assets and it has no
content or access role. Use Lucide icons via the icon API.

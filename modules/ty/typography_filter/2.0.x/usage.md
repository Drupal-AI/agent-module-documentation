Typography Filter is a text filter to improve typography.

---

Typography Filter is a **text-format filter that improves typography** — applying typographic refinements
such as curly ("smart") quotes, proper dashes, ellipses and similar substitutions to rendered text, so content
reads with polished typography without editors typing special characters. It is in the Input filters package.

Use it to auto-improve typography in a text format. It is a content-display/filter feature that transforms
text for display (the stored source is unchanged); place it appropriately in the filter order, and it has no
content or access role. Enable it on the relevant text format.

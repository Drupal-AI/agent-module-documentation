Typed JS Filter adds a text format filter to display text with a typedJS effect.

---

Typed JS Filter provides a text-format filter that renders marked-up text with a typedJS typing
animation — so text can appear with a typewriter-style effect for visual emphasis. It is configured via the
text-format admin (`filter.admin_overview`), in the Filters package.

Use it to add typing animations to content text. It is a content-display/text-filter feature; it processes
content on output to apply the effect, and it has no access-control role. As a text filter it runs on the
filtered content — add it to the appropriate text format and configure the effect.

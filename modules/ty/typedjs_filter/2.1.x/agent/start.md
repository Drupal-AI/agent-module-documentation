# Typed JS Filter — agent index

A text-format **filter that displays text with a typedJS typing animation** (typewriter effect for emphasis).
Config via the text-format admin (`filter.admin_overview`). Version **2.1.0**. Core `^9.2||^10||^11`.

Content-display/text-filter — processes content on output to apply the effect; add to the appropriate text
format. No access role.

Typed.js integrates the Typed.js typing-animation library.

---

Typed.js **integrates the Typed.js library** — a lightweight JavaScript library that animates text as if it's
being typed, for animated headlines/effects. It works across core 8–11.

Use it for typing animations. It is a front-end/theming feature; it provides the Typed.js library and has no
content or access role. Use Typed.js in your theme/markup.

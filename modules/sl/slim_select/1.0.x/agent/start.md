# Slim Select — agent index

Select field **widget using the Slim Select** JS library — searchable/enhanced dropdowns (search, tags,
multi-select). Provides permissions. Version **1.0.0-beta2**. Core `^10.2||^11`.

Form-widget — stores standard select values; no access role. Configure as the widget on option/reference
fields.

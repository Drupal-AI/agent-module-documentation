Slim Select provides a select field widget that uses the Slim Select library for enhanced, searchable dropdowns.

---

Slim Select provides a select field widget using the Slim Select JavaScript library — enhancing select/
multi-select dropdowns with search/filter, tags and a nicer UI than the native select. It provides its own
permissions. It improves the experience of choosing from long option lists.

Use it on option/reference fields where a searchable, enhanced select improves usability. It is a content-
editing/form-widget feature affecting input; the stored values are standard select values and it has no
access-control role. Configure it as the widget on the relevant fields.

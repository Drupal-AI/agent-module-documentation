Slick Pro Customizer provides a customizable Slick Carousel integration.

---

Slick Pro Customizer **provides a customizable Slick Carousel** — a configurable integration of the Slick
Carousel library with settable selectors and options, for building custom carousels/sliders. It works on core
10–11.

Use it to build Slick carousels. It is a front-end/theming feature; it configures a JS carousel and has no content
or access role. Configure the carousel selectors and settings.

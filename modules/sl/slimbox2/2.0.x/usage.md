Slimbox2 integrates the slimbox 2 lightbox effect into your site.

---

Slimbox2 integrates the **Slimbox 2 lightbox** — a lightweight JavaScript lightbox that opens images in
an overlay with next/previous navigation — so image links can pop up in a Slimbox overlay instead of navigating
away. It is in the User interface package.

Use it to add a lightbox to images. It is a content-display/UI feature affecting image presentation; it has no
content or access role. Configure Slimbox on the relevant image links/fields.

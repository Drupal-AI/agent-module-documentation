Slimmer provides an easy way for logging in a central place.

---

Slimmer is a small **developer logging helper** — it gives modules an easy, central way to log messages
(a thin convenience wrapper over Drupal logging), so custom code can log consistently without repeating
boilerplate. It is a developer utility.

Use it as a logging convenience in custom code. It is a developer/API helper — where it writes log entries,
avoid logging **secrets or personal data** (a general logging hygiene point), and it has no content or access
role. Depend on it and use its logging helper.

Slick Layouts (slider_layouts) provides slider layouts, adding carousel-style layouts.

---

Slick Layouts (project `slider_layouts`) provides slider/carousel layouts — layout plugins that arrange
their regions as a slider/carousel, so Layout Builder (or layout) content can be presented as a rotating
slider. It depends on core Layout Discovery and is configured at `slider_layouts.slider_settings`, in the
Layout Builder package.

Use it to build slider/carousel sections via layouts. It is a content-display/layout feature affecting
presentation; the content within comes from blocks/fields (respecting their access) and it has no
access-control role. Select the slider layout and configure the slider settings.

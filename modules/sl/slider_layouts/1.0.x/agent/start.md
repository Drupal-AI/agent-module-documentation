# Slick Layouts (slider_layouts) — agent index

Provides **slider/carousel layouts** (layout plugins arranging regions as a rotating slider — for Layout
Builder). Depends on core `layout_discovery`. Config at `slider_layouts.slider_settings`. Version
**1.0.11**. Core `^9||^10||^11`.

Content-display/layout — inner content from blocks/fields (respects their access); no access role.

# SlidesJS — agent index

A configurable **image-carousel slider provided as a block** (image slideshow in any region). Project
`slidesjs`; **module machine name `slidesjs_slider`**. Depends on core `block`, `image`, `file`,
`media_library`. Version **11.0.0**. Core `^9||^10||^11`.

Content-display — slide images are admin/editor-selected media; no access role.

SlidesJS provides a configurable image carousel slider as a block.

---

SlidesJS provides a **configurable image-carousel slider as a block** — placing an image slideshow
(pulling from image/media fields) in any block region, with slider options. The project is `slidesjs`; the
**module machine name is `slidesjs_slider`**. It depends on core Block, Image, File, Media Library and Config.

Use it to add an image slider block. It is a content-display feature; slide images are admin/editor-selected
media and it has no access-control role. Place and configure the slider block.

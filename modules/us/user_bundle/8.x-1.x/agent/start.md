# User bundle — agent index

Adds **configurable user account types (bundles)** — per-bundle fields and form/display modes on user
entities. Depends on core `user`. Provides permissions. Version **8.x-1.5**. Core `^10.2||^11||^12`.

**Boundary:** bundles organise *fields/display*, **not** permissions — access still comes from roles.
A bundle does not restrict what users can do.

User Email Preview adds a preview tab for account email templates.

---

User Email Preview **previews account email templates** — adding a preview tab on the user account settings
page so admins can see how the account emails (welcome, password, etc.) render before they're sent. It depends on
the Token module.

Use it to preview account emails. It is an administration convenience; it renders email templates (admin-facing)
and has no content or access role. Configure/view the email previews.

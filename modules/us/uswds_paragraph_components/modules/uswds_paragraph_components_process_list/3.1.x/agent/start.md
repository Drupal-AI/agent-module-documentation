# USWDS Process List — agent index

Submodule of [uswds_paragraph_components](../../../../3.1.x/agent/start.md). Installs a USWDS process
list paragraph type. No settings page, no permissions, no CSS library (uses the theme's USWDS assets).
Hooks in `src/Hook/UswdsParagraphComponentsProcessListHooks.php`.

## Paragraph types & fields (config/optional)

- **`uswds_process_list`** (container, expose this): `field_process_items` — nested Paragraphs of
  `uswds_process_item`.
- **`uswds_process_item`** (child, do NOT expose): `field_header` (step heading), `field_text`
  (step body, formatted text).

## Rendering

Theme hook `paragraph__uswds_process_list` → `templates/paragraph--uswds-process-list.html.twig`.
Emits `<ol class="usa-process-list">` and loops `field_process_items`, each as
`<li class="usa-process-list__item"><h4 class="usa-process-list__heading">{{ field_header.value }}</h4>`
followed by `{{ field_text|view }}` (formatter-rendered — safe). Numbering is CSS-generated by USWDS.

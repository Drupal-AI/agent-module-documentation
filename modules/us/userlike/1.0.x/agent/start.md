# Userlike — agent index

Adds the **Userlike live-chat widget** without custom code (configure a widget key; injects the widget JS).
`cookies_userlike` consent submodule. Provides permissions. Version **1.0.0-beta4**. Core `^10.3||^11`.

Third-party integration — loads **third-party JS** (trust the vendor; runs in your origin) and sets
**cookies** / processes visitor data (GDPR/consent — hence `cookies_userlike`). No access role.

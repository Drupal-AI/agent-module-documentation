Userlike adds the Userlike Live-Chat widget to your project without touching code.

---

Userlike adds the **Userlike live-chat** widget to a site without custom code — you configure the
Userlike widget key and it injects the chat widget's JavaScript into pages. It ships a `cookies_userlike`
submodule (Cookie/consent integration), provides its own permissions.

Use it to add live chat. It is a third-party integration/user-engagement feature. Privacy/security notes: it
loads **third-party JavaScript** from Userlike into your pages (that script runs in your origin — trust the
vendor) and the chat sets **cookies** and processes visitor data (a GDPR/consent consideration — the
`cookies_userlike` submodule integrates with the Cookies consent module for exactly this). It has no
access-control role. Configure the Userlike widget key.

# User Agent Class — agent index

Adds **device/browser CSS classes** to the page from the visitor's **user agent** (theme styling by
device/browser). Version **8.x-6.21**. Core `>=9`.

Theming/display — adds classes; no content/access change. UA detection is a **spoofable heuristic** — use
for presentation, not security.

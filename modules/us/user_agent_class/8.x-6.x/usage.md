User Agent Class provides device and browser detection, adding classes to the page based on the visitor's user agent.

---

User Agent Class detects the visitor's device and browser from the user-agent string and adds
corresponding CSS classes to the page — so themes can target styling by device type (mobile/tablet/
desktop) or browser. It provides a device/browser detection class for this purpose. It is in the Custom
package.

Use it where theme styling or behaviour should vary by device/browser. It is a theming/display feature
adding classes based on user-agent; it does not change content or access. Note user-agent detection is a
server-side heuristic (user agents can be spoofed and are imperfect), so use the classes for presentation
enhancements, not for anything security-sensitive. The classes are added to page markup.

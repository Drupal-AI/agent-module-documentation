# User Role Widget — agent index

Provides **widgets for user-reference fields** (select/checkbox/autocomplete + a selection plugin) that
present/filter referenceable users **by role**. Depends on core `field`. Version **1.0.3**. Core `^10||^11`.

Content-editing/reference widget — referenceable users governed by the field's **selection handler + entity
access**; does **not** grant assigning users/roles itself (field access + core role-assignment permissions
still govern). No access role.

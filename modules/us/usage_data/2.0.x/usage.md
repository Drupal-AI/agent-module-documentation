Usage Data logs site usage data for later analysis and visualization, capturing usage metrics.

---

Usage Data logs site usage data — capturing usage metrics (activity, feature usage, or similar) for
later analysis and visualization. It is configured at `usage_data.settings` and provides its own
permissions. This lets site owners understand how the site/features are used without an external analytics
service.

Use it to collect and analyze internal usage metrics. The privacy-relevant point is what usage data is
captured: if it records user-identifiable activity (who did what), that is personal data — be mindful of
what is logged, gate access to the usage reports with the module's permissions, and handle the data per
privacy/retention obligations (avoid logging more than needed). It has no access-control role beyond its
permission. Configure what usage is logged and who can view it.

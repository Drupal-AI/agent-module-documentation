User Reference with Invite extends Drupal user-reference fields with an invitation workflow so editors can add existing users or invite brand-new users by email, who are then auto-attached to the referencing entity after they register.

---

A custom field widget lets a user either pick an existing account or enter an email to invite. Invitations are `user_invite` content entities carrying a secure token generated by `TokenService` (a 256-bit CSPRNG value, `Crypt::randomBytesBase64(32)`) with an expiry. The recipient receives an email with an accept link at `/user/invite/accept/{token}`; `InviteAcceptController::accept()` validates the token (exists, not expired) before finalizing login/registration, making the link a secure single-use capability rather than a guessable id. Event subscribers handle registration access, post-registration attachment to the reference field, login redirect, and cleanup of expired invites; a queue worker processes invitations in batches. Admins manage everything at `/admin/people/invitations`.

Access is permission-gated throughout: `administer user invitations` (restricted) for the admin list/cancel/settings, and `invite users via reference fields` for creating/resending/reminding/transferring/removing members, plus `view own`/`cancel own` permissions. The only `_access: 'TRUE'` route is the token accept endpoint, which must be public by design and is protected by the unguessable, expiring token. It integrates with Drupal's mail system (optionally HTML mail/Symfony Mailer) and the Token module for customizable email templates.

---
- Add a "select existing or invite by email" widget to a user-reference field.
- Invite a new user by email directly from an entity form.
- Auto-attach an invited user to the reference field after they register.
- Send invitation emails using customizable Drupal mail templates.
- Use tokens to personalize invitation email content.
- Generate secure, expiring invitation links.
- Let invitees accept via `/user/invite/accept/{token}` and register.
- Manage all invitations from `/admin/people/invitations`.
- Cancel a pending invitation before it is accepted.
- Resend an invitation with a fresh token and expiry.
- Send a reminder for a pending invitation.
- Transfer ownership of an entity to another referenced member.
- Remove a member from an entity reference field.
- Assign context-specific roles to invited users.
- Let users view and cancel their own sent invitations.
- Automatically clean up expired invitations.
- Process bulk invitations via the queue worker.
- Configure invitation behavior at `/admin/config/people/user-reference-invite`.
- Enable HTML invitation emails via htmlmail/swiftmailer/symfony_mailer.
- Onboard collaborators onto a project/team entity by email.
- Restrict who may invite via the `invite users via reference fields` permission.
- Gate administration behind the restricted `administer user invitations` permission.

User Activity Log creates a User Activity Log module block that records user activity.

---

User Activity Log records user activity and surfaces it via a block — logging user actions on the site
so administrators can review who did what. It depends on core Node, in the User package.

Use it to track and display user activity. It is an administration/audit feature; the activity log can
contain user/action detail (personal data), so gate access to it and handle per privacy — the log/block
should be shown only to trusted admins. It has no access-control role. Configure/place the activity-log
block.

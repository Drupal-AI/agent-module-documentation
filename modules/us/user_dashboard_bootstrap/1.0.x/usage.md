User Dashboard Bootstrap provides an individual Bootstrap-styled dashboard for each user.

---

User Dashboard Bootstrap **provides a per-user dashboard** — a Bootstrap-styled personal dashboard for each
user, aggregating their content/links. It provides its own permissions.

Use it to give users a personal dashboard. It is a user-engagement/UI feature; each dashboard should show only the
owning user's own data (verify the dashboard scopes content to the current user and respects access), and it has no
broad access-control role beyond its permission. Configure the user dashboard.

USWDS Alert provides sitewide alert types styled with USWDS components.

---

USWDS Alert **provides USWDS-styled alerts** — alert types (info/warning/error/success) rendered with U.S. Web
Design System components, for the Sitewide Alert module on USWDS-based government sites. It depends on the Sitewide
Alert module.

Use it for USWDS-styled site alerts. It is a theming/content feature; alerts are admin-managed content and it has no
access-control role. Configure the USWDS alert types.

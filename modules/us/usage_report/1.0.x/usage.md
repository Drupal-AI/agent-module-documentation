Usage Report adds a tab listing entities that reference the current entity.

---

Usage Report **shows what references an entity** — adding a tab on each content entity that lists the other
entities referencing it, so editors can see usage/dependencies before changing or deleting content. It provides its
own permissions.

Use it to check an entity's references before editing/deleting. It is a content-administration feature; it surfaces
reference relationships (respecting normal entity access) and is gated by its permission. It has no broad
access-control role beyond that. View the usage report.

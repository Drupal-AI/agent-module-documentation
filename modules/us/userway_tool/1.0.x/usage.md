---

UserWay tool helps resolve accessibility issues by utilizing the UserWay integration — injecting the UserWay accessibility widget (an overlay offering contrast, font-size, cursor and other accessibility adjustments) so visitors can adapt the site to their needs.

The UserWay account/site ID is admin-configured. Supports Drupal 9, 10, and 11.

User Ban temporarily blocks users and auto-unblocks them after a set period.

---

User Ban **temporarily bans users** — blocking a user account for a specified time period and automatically
unblocking it when the period ends, for temporary suspensions. It provides its own permissions.

Use it to time-limit user suspensions. It is an access/moderation feature; it leverages Drupal's account **blocked
status** (a blocked user cannot log in — core enforces this at authentication) and lifts the block on schedule.
Gate the ban permission to trusted moderators/admins. It complements core user status. Configure the ban.

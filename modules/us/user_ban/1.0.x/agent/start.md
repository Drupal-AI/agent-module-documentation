# User Ban — agent index

**Temporarily block users and unblock them after a specified time period**. Provides permissions. Version
**1.0.0-alpha1**. Core `^9||^10||^11`.

Access/moderation — leverages core's **blocked account status** (core prevents blocked users from logging in);
auto-unblocks on schedule. Gate the ban permission to trusted moderators/admins.

User Manual provides a place to build a User Manual for your site, for in-site help documentation.

---

User Manual provides a structure to build an in-site user manual — documentation/help content for the
site's users/editors, organized and accessible within Drupal (often via the toolbar). It depends on core
Views, Toolbar and the Entity module, and provides its own permissions. This gives teams a place to document
how to use the site without external docs.

Use it to build and surface user/editor documentation in-site. It is a content/administration feature for
help documentation; manual content is authored and access is governed by its permissions (decide who can
view/edit the manual — internal editor docs typically shouldn't be public). It has no access-control role
beyond that gating. Configure the manual content and access.

Let editors choose which formatter renders a field.

---

User Selected Formatter allows the editor to select the formatter they want to render a field — so instead of a fixed display formatter, an editor can pick, per content, how a field should be rendered (from the allowed formatters), giving per-item display flexibility. Depends on core `field`; supports Drupal 10.3+.

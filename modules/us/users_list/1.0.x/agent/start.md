# Users List — agent index

**Creates several user-directory lists** viewable as pages (`/userslist/…`) and blocks. Gated by `access users
lists`. Depends on core `node`, `block`. Provides permissions. Version **1.0.7**. Core `^9||^10||^11`.

User-engagement/directory — **exposes a directory of user accounts** to holders of `access users lists` (grant
deliberately; a directory reveals who has accounts). Access-gated by that permission.

An AJAX toggle to activate/block users on the people listing.

---

User Status Switch adds a quick AJAX-powered toggle switch to the user listing page to activate or block users — so administrators can flip an account between active and blocked directly from `/admin/people` without opening the edit form. It is gated by the appropriate user-administration permission. Depends on core `user` and `views`; supports Drupal 9.4+, 10, and 11.

An entity-reference selection handler that queries as a configurable user.

---

Fixed User Entity Reference Selection provides an entity reference selection handler that runs as a configurable user account — so an entity-reference field's allowed-values query executes with the access rights of a chosen user (rather than the current user), giving consistent, predictable reference options regardless of who is editing (a 'fixed' selection). It's a field/developer feature. Supports Drupal 10 and 11.

# User Account Emails — agent index

**Allows administrators to send account emails to users**. Depends on core `user`. Provides permissions. Version
**1.0.x** (dev). Core `^9||^10||^11`.

Administration/mail — emails users (PII); gate to admins (account emails can include one-time-login links). No
broader access role.

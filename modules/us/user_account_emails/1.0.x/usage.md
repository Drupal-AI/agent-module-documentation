User Account Emails lets admins send account emails to users.

---

User Account Emails **lets admins send account emails** — enabling administrators to send the standard account
emails (welcome, password, etc.) to users on demand. It depends on core User and provides its own permissions, in
the Mail package.

Use it to (re)send account emails. It is an administration/mail feature; it triggers emails to users (their
addresses = PII) and is gated by its permission (restrict to admins — sending account emails can include
sensitive links like one-time login). It has no broader access-control role. Configure and send account emails.

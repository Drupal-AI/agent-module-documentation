# User Preference Login Redirect — agent index

**Lets users select their preferred post-login redirect destination (an internal route) from their profile**.
Provides permissions. Version **1.0.0-beta2**. Core `^11`.

User-preference/UX — redirects to **internal routes** (admin-configured options), **not arbitrary URLs**, so not an
open-redirect. No access role beyond permission.

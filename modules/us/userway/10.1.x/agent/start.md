# UserWay — agent index

Adds the **UserWay accessibility widget/overlay** (on-page contrast/text/spacing adjustments) by injecting
UserWay's script with your site ID. Version **10.1.1**. Core `>=8`.

Third-party accessibility/integration — loads **third-party JS** (trust the vendor; runs in your origin; may
process visitor data — privacy). An overlay **supplements, not replaces** real WCAG work (conformance comes
from your own markup). No access role.

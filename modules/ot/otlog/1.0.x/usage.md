Ship Drupal log events to an OpenTelemetry log endpoint.

---

OpenTelemetry Log (otlog) logs events to an OpenTelemetry log endpoint — forwarding Drupal's log/watchdog entries to an OTLP-compatible collector so logs are aggregated alongside traces/metrics in an observability backend (Grafana, Honeycomb, etc.).

The OTLP endpoint/credentials are admin-configured and should be stored securely (env-backed). Supports Drupal 10 and 11.

Integrate the OpenTelemetry SDK into Drupal.

---

OpenTelemetry SDK (otsdk) integrates the OpenTelemetry SDK — providing the base OpenTelemetry instrumentation (traces/metrics/logs SDK) so other modules can emit telemetry to an observability backend, the foundation for OpenTelemetry-based monitoring in Drupal.

The OTLP endpoint/credentials are admin-configured and should be stored securely (env-backed). Depends on Drupal core only; supports Drupal 10 and 11.

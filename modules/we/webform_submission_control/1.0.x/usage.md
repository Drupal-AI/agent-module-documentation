Webform Submission Control limits webform submissions per referenced entity.

---

Webform Submission Control **limits submissions per entity** — restricting how many times a webform can be
submitted in relation to a referenced entity (e.g. one submission per node), for controlled data collection. It
depends on the Webform module.

Use it to cap submissions per entity. It is a webform/business-rule feature; it enforces a submission limit and has
no access-control role. Configure the submission control.

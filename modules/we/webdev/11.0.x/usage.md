Webdev bundles the most needed contributed modules.

---

Webdev is a **meta-package bundling commonly-needed contributed modules** — a convenience module (part of
the `web*` suite) that pulls in a curated set of frequently-used contrib modules so a new site starts with them
available. It targets core 11.4.

Use it to bootstrap a site with common modules. It is a site-building/convenience meta-module; it enables/pulls
in other modules (each with its own behaviour and access model), so **review what it brings in** and remove
anything you don't need. It has no functionality or access role of its own. Enable it to pull in the bundled
modules.

WebConfig provides web configuration management.

---

WebConfig provides **web-based configuration-management helpers** — tools/config for managing site
configuration (part of the `web*` suite), targeting core 11.4.

Use it as part of the web* suite for config management. It is a site-building/devops convenience module; it
manages configuration (an admin-privileged area) and has no content or access role of its own beyond that.
Enable it with the web* stack.

Show a Webform popup on node pages, hidden after submission via cookies.

---

Webform Popup Cookie Aware shows a popup with a Webform on node pages — the popup is hidden after submission using cookies, with per-content-type configuration, so a site can present a lead/signup form as a popup that doesn't nag users who've already submitted it. Depends on `webform`; supports Drupal 10 and 11.

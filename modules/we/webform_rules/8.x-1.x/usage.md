Webform Rules adds Rules integration for webform submissions, firing Rules events when a webform is submitted.

---

Webform Rules adds Rules integration for Webform — firing Rules events when a webform is submitted, so
site builders can trigger Rules-based reactions (send a notification, create/update an entity, call a
service) in response to submissions, without custom code. It depends on the Webform and Rules modules.

Use it to automate behaviour on webform submission via Rules. It is an automation/business-rules feature
bridging Webform and Rules; the reactions run the configured Rules logic, so — as with any Rules
automation — review what the rules do (especially any that change access, create privileged entities, or
send communications) so a submission can't trigger unintended privileged actions. Configure the Rules
reactions on the submission events.

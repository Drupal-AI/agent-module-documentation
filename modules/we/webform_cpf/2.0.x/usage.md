Webform Cpf provides the Brazilian individual taxpayer identification number (CPF) for Webform.

---

Webform Cpf adds a CPF field to Webform — the Brazilian individual taxpayer identification number (CPF),
with format masking and validation (checksum) so submissions capture a valid CPF. It depends on the Webform
module, in the Webform Cpf package.

Use it on Brazilian-audience webforms that collect a CPF. Privacy-relevant note: a **CPF is sensitive
personal/government identification data** — treat submissions accordingly (collect only if necessary, secure
storage/transmission over HTTPS, restrict access to submissions, and handle per privacy law / LGPD). It has
no access-control role. Configure the CPF element on the webform.

# Webform Cpf — agent index

Adds a **Brazilian CPF (individual taxpayer ID) element** to Webform (format mask + checksum validation).
Depends on `webform`. Version **2.0.5**. Core `^9||^10||^11`.

**Privacy:** CPF is **sensitive personal/government ID data** — collect only if necessary, secure storage/
transmission (HTTPS), restrict submission access, handle per privacy law (LGPD). No access role.

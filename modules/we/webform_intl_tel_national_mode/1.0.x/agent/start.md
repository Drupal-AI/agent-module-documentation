# Webform International Telephone National Mode — agent index

Enhances the Webform **international telephone element** with **national-mode** input (users enter
national format; widget handles country/formatting). Depends on `webform` (>=6.3 beta). Version
**1.0.1**. Core `^10.3||^11`.

Forms/UX enhancement (input presentation/formatting; no content/access). Apply to Webform telephone
elements.

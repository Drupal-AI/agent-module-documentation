Webform International Telephone National Mode enhances the international telephone input UX for Webform, supporting national-format entry.

---

Webform International Telephone National Mode enhances the international-telephone input experience in
Webform — enabling the intl-tel-input "national mode" so users enter phone numbers in familiar national
format (without the country code prefix) while the widget still handles country selection and
formatting behind the scenes. It depends on the Webform module (>=6.3 beta).

Use it on webforms collecting phone numbers where national-format entry is friendlier for users. It is
a forms/UX enhancement to the telephone element; it affects input presentation/formatting, not content
or access. Apply it to the relevant Webform telephone elements.

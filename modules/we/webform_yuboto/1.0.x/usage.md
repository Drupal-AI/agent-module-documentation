Webform Yuboto sends SMS via the Yuboto gateway when a webform is submitted.

---

Webform Yuboto SMS handler provides a Webform handler that sends SMS messages to configured recipients via Yuboto (a Greek SMS/communication gateway) when a webform is submitted — useful for notifications, confirmations, or alerts triggered by form submissions.

Yuboto API credentials should be stored securely (env-backed); sending SMS incurs cost. Administration is gated by `administer webform yuboto settings`. Depends on `webform`; supports Drupal 10.1+, 11, and 12.

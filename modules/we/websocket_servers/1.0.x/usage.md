Define Ratchet-powered WebSocket servers as configuration with pluggable handlers.

---

Websocket Servers lets you define websocket servers as configuration and run them as Ratchet-powered instances with pluggable handlers — so a Drupal site can host real-time WebSocket endpoints (defined via config entities, each with a message handler plugin) for live features, without hand-rolling the server. Supports Drupal 10.3+ and 11.

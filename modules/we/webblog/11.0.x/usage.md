Webblog enhances your Drupal site by introducing a blog.

---

Webblog **adds a full-featured blog to a Drupal site** — a blog content type with Layout Builder, content
moderation, media library, entityqueue and manage-display integration (part of the `web*` suite), giving an
out-of-the-box blogging setup. It depends on many core modules plus manage_display, entityqueue and webassets.

Use it to add a structured blog. It is a content/publishing feature; blog content follows core node/content-
moderation access and it has no access-control role. Configure the blog content and layouts.

# Webblog — agent index

**Adds a full-featured blog** (blog content type, Layout Builder, content moderation, media, entityqueue; part of
the `web*` suite). Depends on core `node`/`layout_builder`/`content_moderation`/… plus `manage_display`,
`entityqueue`, `webassets`. Version **11.0.2**. Core `~11.4.0`.

Content/publishing — follows core node/content-moderation access; no access role.

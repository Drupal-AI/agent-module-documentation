# Webform phpList — agent index

A **Webform handler that adds submitters' emails to a phpList mailing list**. Depends on `webform`. Version
**1.1.1**. Core `^8||^9||^10||^11`.

Forms/integration — sends **submitter emails (PII) to phpList** (egress; trusted HTTPS endpoint, secret
credentials; respect consent/opt-in/unsubscribe). No access role.

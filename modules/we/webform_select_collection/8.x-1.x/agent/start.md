# Webform select collection — agent index

Webform **element grouping multiple select dropdowns into a single collection** (related selects managed/
submitted together). Depends on `webform`. Version **8.x-1.3**. Core `^9||^10||^11`.

Forms/Webform-element feature — submitted values are standard select values; no access role. Add the
element + configure member selects.

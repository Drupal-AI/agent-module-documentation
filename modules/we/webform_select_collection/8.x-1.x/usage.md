Webform select collection provides a webform element that groups multiple select elements into a single collection element.

---

Webform select collection provides a Webform element that groups multiple `select` dropdowns into a
single "collection" element — so a set of related selects (for example a series of ratings, or multiple
related choices) can be managed and submitted as one cohesive element rather than many separate ones. It
depends on the Webform module.

Use it on webforms that need groups of related selects presented and handled together. It is a forms/
Webform-element feature affecting how the selects are grouped/submitted; the submitted values are standard
select values and it has no access-control role. Add the element to the webform and configure the member
selects.

Webform Error Field provides a validation-message webform element for displaying errors.

---

Webform Error Field **adds a validation-message element** — a webform element type that displays error/
validation messages inline within the form, for clearer feedback. It depends on the Webform module.

Use it to show inline validation messages. It is a webform/UX feature; it renders messages and has no content or
access role. Add the element to a webform.

Webform Number Limit allows webforms with a number element to have submission limits based on the sum of those numbers.

---

Webform Number Limit lets a webform enforce a limit based on the **sum** of a number element's values
across submissions — so instead of (or alongside) a submission-count limit, the form stops accepting when the
cumulative total of a number field reaches a threshold (e.g. limited-quantity signups, capped totals,
inventory-style limits). It depends on the Webform module, in the Webform package.

Use it for quantity/total-based webform limits. It is a forms/validation feature enforcing a sum-based cap on
submissions; it shapes what submissions are accepted and has no access-control role. Configure the number
element and the total limit.

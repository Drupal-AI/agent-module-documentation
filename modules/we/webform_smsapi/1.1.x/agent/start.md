# Webform SMSAPI — agent index

**Provides SMS sending via the SMSAPI module for Webforms**. Depends on `webform`, `smsapi`. Version **1.1.2**.
Core `^10.2||^11`.

Webform/integration — sends **recipient phone numbers (PII) + content to the SMSAPI service** (egress — disclose);
**credentials** as secrets (env/Key, HTTPS). No access role.

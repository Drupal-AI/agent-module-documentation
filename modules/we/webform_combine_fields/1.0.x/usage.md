Webform Combine Fields merges several webform element values into one combined value.

---

Webform Combine Fields combines Webform submissions into a single field — merging the values of multiple webform elements into one combined value (e.g. building a full name from first/last, or an address from parts), useful for downstream storage, display, or export where a single combined value is wanted.

It's a Webform enhancement with no content or access role of its own. Depends on `webform`; supports Drupal 10 and 11.

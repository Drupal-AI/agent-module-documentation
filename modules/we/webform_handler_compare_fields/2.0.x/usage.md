Webform Handler: Compare Fields provides a configurable Webform handler that compares the values of two fields on a webform.

---

Webform Handler: Compare Fields adds a configurable Webform handler that compares two fields on a
form — for example confirming two values match (email/confirm-email, password/confirm) or enforcing an
ordering/relationship between fields — as part of submission handling/validation. It depends on the
Webform module and is configured on the webform's handlers.

Use it to enforce cross-field rules on webforms without custom code — the classic "these two fields
must match" validation, among other comparisons. It is a forms/validation feature operating within the
Webform submission pipeline; it validates or acts on submitted data and has no access-control role.
Configure the two fields and the comparison on the handler.

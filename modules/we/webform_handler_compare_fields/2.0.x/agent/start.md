# Webform Handler: Compare Fields — agent index

Configurable **Webform handler that compares two fields** (e.g. email/confirm match, cross-field
validation) in the submission pipeline. Depends on `webform`. Version **2.0.4**. Core `^10.1||^11`.

Forms/validation feature (no access role). Configure the two fields + comparison on the webform's
handlers.

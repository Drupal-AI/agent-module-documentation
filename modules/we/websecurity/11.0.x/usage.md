WebSecurity bundles security modules and configurations.

---

WebSecurity **bundles commonly-needed security modules and configuration** — a convenience module (part of
the `web*` suite) that pulls in and configures a curated set of security-hardening modules/settings so a site
starts with sensible security defaults, targeting core 11.4.

Use it to bootstrap security hardening. This is a **security-positive** convenience meta-module. It enables/pulls
in other security modules (each with its own behaviour), so **review what it brings in and its configuration**,
and remember it complements — not replaces — ongoing security practice (updates, permissions review, monitoring).
It has no access-control role of its own. Enable it to apply the security baseline.

Webpage provides a Webpage content type.

---

Webpage **provides a general-purpose Webpage content type** — a ready-made flexible page content type
(part of the `web*` suite) for building standard site pages, targeting core 11.4.

Use it as a base page type. It is a content/site-building convenience; it installs a content type that follows
normal node access, and it has no access-control role. Enable it to add the Webpage type.

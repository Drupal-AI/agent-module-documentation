# Webform Submit Timer — agent index

Adds a **submit-delay timer to Webforms** (block submission until a minimum time elapses — deters instant bot
submits). Depends on `webform`. Version **1.0.2**. Core `^10.3||^11`.

Forms — a client-assisted anti-bot deterrent (pair with server-side Honeypot/CAPTCHA); no access role.

Webform Submit Timer adds a submit delay timer to Webforms.

---

Webform Submit Timer **adds a submit-delay timer to Webforms** — preventing a form from being submitted
until a minimum time has elapsed since it loaded, which deters automated/bot submissions that submit instantly.
It depends on the Webform module, in the Webform package.

Use it as a lightweight anti-bot/anti-spam measure on forms. It is a forms feature; the timer is a
client-assisted deterrent (combine with server-side anti-spam like Honeypot/CAPTCHA for stronger protection),
and it has no access-control role. Configure the minimum submit delay on a webform.

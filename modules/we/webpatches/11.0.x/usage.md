Webpatches provides additional local patching.

---

Webpatches **provides additional local patching support** — a mechanism to apply local code patches (part of
the `web*` suite), for maintaining custom fixes on top of contrib/core. It provides its own permissions, core
11.1+.

Use it to manage local patches. It is a developer/devops tool. Security note: applying patches **modifies code**,
so patches are trusted input — only apply patches from **trusted sources** (a malicious patch is arbitrary code),
keep patch management to trusted developers (its permission), and review patches before applying. It has no
content or access role beyond its permission. Configure and apply patches.

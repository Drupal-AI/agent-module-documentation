# Webform Redis Limit Handler — agent index

**A Webform handler that supports submission limits using Redis**. Depends on `webform`, `redis`. Version
**1.0.2**. Core `^9||^10||^11`.

Webform/anti-abuse — counts/limits submissions in Redis (use a trusted/access-controlled Redis); no content/access
role.

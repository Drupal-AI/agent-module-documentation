Webform Redis Limit Handler enforces webform submission limits using Redis.

---

Webform Redis Limit Handler **limits submissions via Redis** — a webform handler that enforces submission
limits (per user/time) backed by Redis, for accurate/high-performance rate limiting across a cluster. It depends on
the Webform and Redis modules.

Use it to rate-limit form submissions at scale. It is a webform/anti-abuse feature; it counts/limits submissions in
Redis and has no content or access role. Note: the Redis instance should be trusted/access-controlled. Configure
the submission limit.

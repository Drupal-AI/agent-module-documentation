Webform Payment Element adds payment-collecting elements to webforms.

---

Webform Payment Element provides webform elements to collect multiple payment amounts with a payment provider — so a webform can include payment fields (e.g. donations with several amounts, fees) and process the payment as part of submission, turning forms into payment/donation forms.

Payment provider credentials should be stored securely (env-backed), and payment processing must be verified server-side; configure the provider carefully. Depends on `webform`; supports Drupal 10 and 11.

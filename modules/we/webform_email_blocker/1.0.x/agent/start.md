# Webform Email Blocker — agent index

**Create a denylist of known bad emails from submitting forms** (spam control). Depends on `webform`. Provides
permissions. Version **1.0.3**. Core `^9||^10||^11`.

Spam-control — validates the submitted email against a denylist (pair with CAPTCHA/honeypot/flood control); no broad
access role beyond permission.

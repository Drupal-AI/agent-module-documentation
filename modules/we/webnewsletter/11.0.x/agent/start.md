# WebNewsletter — agent index

**Simplifies newsletter management (subscriptions + sending)**, built on Webform (part of the `web*` suite).
Depends on `webform`. Provides permissions. Version **11.0.2**. Core `~11.4.0`.

Marketing/email — stores **subscriber PII** + **sends bulk email** (consent/double opt-in/unsubscribe; protect
the list; gate sending — spam/relay risk). No access role beyond permission.

Webform Portuguese NIF collects and validates Portuguese NIF numbers.

---

Webform Portuguese NIF provides a **Webform element that collects and validates a Portuguese NIF** (Número
de Identificação Fiscal — tax ID), applying the NIF checksum/format rules so submissions carry a valid number.
It depends on the Webform module, in the Webform package.

Use it to collect valid Portuguese tax IDs in forms. It is a forms/validation feature. Data-handling note: a
NIF is **personal/fiscal identifying data (PII)** — handle submissions per your privacy obligations (retention,
access to submission data), though the validation itself is local (no external call). It has no access-control
role. Add the NIF element to a webform.

# Webform Email Reply — agent index

Lets authorized users **send an email reply to webform submissions** (staff replies to a submitter from
Drupal). Depends on `webform`; provides permissions. Version **3.0.0**. Core `^10||^11`.

Webform/messaging — replying gated by its permission (restrict who can reply); uses the submission's email
(mind PII), reply body composed by staff. No access role beyond permission.

Web Admin bundles website administration utilities and tools.

---

Web Admin provides a set of website administration tools — bundled utilities to help administrators manage and maintain a Drupal site (administrative shortcuts, maintenance helpers, and management features), consolidating common admin tasks.

As an administration toolset, its features should be restricted to trusted administrators. Requires Drupal 11.4.

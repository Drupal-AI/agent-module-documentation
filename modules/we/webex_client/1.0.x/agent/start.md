# Webex Client — agent index

**Integrates Cisco Webex** (schedule meetings, share content, collaboration). Provides permissions. Version
**1.0.12**. Core `^10||^11`.

Integration — calls the **Webex API** (egress); **OAuth credentials/tokens** as secrets (env/Key, HTTPS). No access
role beyond permission.

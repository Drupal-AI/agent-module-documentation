Webex Client integrates Cisco Webex for meetings, content sharing and collaboration.

---

Webex Client **integrates Cisco Webex** — enabling users to schedule Webex meetings, share content and add
collaboration features into Drupal workflows via the Webex API. It provides its own permissions, in the
Administration package.

Use it to add Webex collaboration. It is an integration feature. Security/data handling: it **calls the external
Webex API** (egress) and authenticates with **Webex OAuth credentials/tokens** (store as secrets — env/Key — over
HTTPS; a Webex token can act on behalf of accounts). It has no access-control role beyond its permission. Configure
the Webex credentials.

# Webform Entity Email — agent index

A **Webform email handler that sends a rendered entity (node) in a chosen display mode**. `scheduled` submodule
(scheduled sending). Depends on `webform`. Version **1.1.1**. Core `^8||^9||^10||^11`.

Forms/email — email includes **rendered entity content** (ensure the display mode hides sensitive fields);
validate recipients (avoid mail relay). No access role.

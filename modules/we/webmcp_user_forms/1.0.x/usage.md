WebMCP User Forms annotates user forms with WebMCP attributes for AI agents.

---

WebMCP User Forms provides WebMCP (Web Model Context Protocol) attributes for Drupal's user forms — annotating the login/register/edit user forms with WebMCP metadata so AI agents/assistants can understand and interact with them programmatically, part of making Drupal forms agent-consumable.

Administration is gated by `administer webmcp user forms`. It's an AI-integration/annotation module with no content role of its own. Supports Drupal 10, 11, and 12.

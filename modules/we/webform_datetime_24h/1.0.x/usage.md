Webform Datetime 24h forces 24-hour time format on Webform datetime elements.

---

Webform Datetime 24h **forces 24-hour time on webforms** — overriding datetime/time element formatting to use
a 24-hour clock for selected languages, for consistent time entry. It depends on the Webform module.

Use it to standardize time format on forms. It is a webform/UX feature; it changes time display/entry and has no
content or access role. Configure the 24h formatting.

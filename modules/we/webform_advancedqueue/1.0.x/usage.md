Webform Advancedqueue provides a webform handler that processes submissions via Advanced Queue.

---

Webform Advancedqueue **processes webform submissions via a queue** — a webform handler that defers submission
processing to the Advanced Queue module, so heavy submission handling runs asynchronously in the background. It
depends on the Advanced Queue module.

Use it to process submissions asynchronously. It is a webform/queue feature; it queues submission handling and has
no content or access role. Configure the queue handler on a webform.

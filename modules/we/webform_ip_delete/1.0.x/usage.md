Webform IP Delete helps delete IP addresses collected in webform submissions.

---

Webform IP Delete **helps delete collected IP addresses** — providing a way to remove the IP addresses stored
with webform submissions, for privacy/GDPR data-minimization. It depends on the Webform module.

Use it to purge submission IPs. It is a privacy/data-protection feature — a **security-positive**, since removing
stored IP addresses (personal data) reduces retained PII and helps meet data-minimization/GDPR obligations. It has
no access-control role. Configure the IP deletion.

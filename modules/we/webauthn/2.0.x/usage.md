Support the W3C WebAuthn API for passwordless/strong authentication.

---

WebAuthn supports the W3C WebAuthn API — enabling passwordless / strong authentication in Drupal using platform authenticators and security keys (passkeys, fingerprint, FIDO2), so users can register a credential and log in with it instead of (or in addition to) a password. Depends on core `user`; supports Drupal 10.2+, 11, and 12.

# Webform CraftyClicks (Fetchify) — agent index

A **Webform Address element with Fetchify (CraftyClicks) UK postcode lookup** (autocomplete an address from a
postcode). Depends on `webform`. Version **8.x-1.1**. Core `>=8`.

Forms/integration — calls the **Fetchify API** with an **API key** (secret, HTTPS); postcodes/addresses sent to
Fetchify (egress/privacy). No access role.

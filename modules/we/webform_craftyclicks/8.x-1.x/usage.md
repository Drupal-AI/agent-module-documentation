Webform CraftyClicks is a Webform plugin for the Address element with Fetchify postcode lookup.

---

Webform CraftyClicks provides a **Webform Address element with Fetchify (CraftyClicks) postcode lookup** —
so a webform address field can autocomplete a UK address from a postcode via the Fetchify service. It depends
on the Webform module, in the Webform package.

Use it to add postcode-lookup address entry to webforms. It is a forms/integration feature. Security/data
handling: it calls the **Fetchify/CraftyClicks API** with an **API key** (store as a secret, HTTPS), and the
postcode/address the user enters is sent to Fetchify for lookup (a data-egress/privacy consideration). It has
no access-control role. Configure the Fetchify API key.

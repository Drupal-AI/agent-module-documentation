Build e-petitions in Webform using the TheyWorkForYou API.

---

Webform E-petition provides plugin elements that help create e-petitions using the TheyWorkForYou API — so a Webform can include petition elements (e.g. find your MP/constituency by postcode via TheyWorkForYou) to build UK-style e-petition forms that route to representatives. Depends on `webform`; supports Drupal 8 and later.

Webform Handler Defer defers selected webform handlers until the next cron run.

---

Webform Handler Defer **defers webform handlers to cron** — delaying processing of selected webform handlers
until the next cron run, so slow/heavy handlers don't block submission. It depends on the Webform module.

Use it to run heavy handlers asynchronously. It is a webform/performance feature; it changes when handlers run and
has no content or access role. Configure which handlers to defer.

WebDoc provides a quick basic setup for Web documentation.

---

WebDoc **provides a quick, basic setup for documentation pages** — a WebDoc content type and configuration
for publishing documentation (part of the `web*` suite), targeting core 11.4.

Use it to bootstrap documentation content. It is a content/site-building convenience; it installs config
(content type) that follows normal access, and it has no access-control role. Enable it to add the WebDoc
type.

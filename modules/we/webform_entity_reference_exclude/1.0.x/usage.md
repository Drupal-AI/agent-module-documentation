Webform Entity Reference Exclude provides a webform entity reference field widget that allows excluding options.

---

Webform Entity Reference Exclude provides a **webform entity-reference widget that can exclude specific
options** — so an entity-reference element on a webform can omit certain referenceable entities from its
option list (e.g. hide specific items). It depends on the Webform module, in the Webform package.

Use it to trim entity-reference options on webforms. It is a forms/webform feature affecting which options are
offered; it changes the selectable list (a form-building convenience, not an access boundary on the excluded
entities) and has no access-control role. Configure the exclusions on the webform element.

# Webform Entity Reference Exclude — agent index

A **webform entity-reference field widget that can exclude specific options** (omit certain referenceable
entities from the list). Depends on `webform`. Version **1.0.2**. Core `^10.2||^11`.

Forms/webform — changes which options are offered (a form-building convenience, **not** an access boundary on
the excluded entities); no access role.

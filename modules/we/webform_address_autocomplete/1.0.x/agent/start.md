# Webform Address Autocomplete (webform_address_autocomplete) — agent index

Adds an autocompleting Address element to Webform. A respondent starts typing a street and
picks a real address from a suggestion list; the composite sub-fields (street, city, postal
code, state) are then filled by JS. Address lookups are served by a **swappable provider
plugin type** (`WebformAddressProvider`) that queries an external geocoding API server-side.

- Dependency: `webform:webform` (`^6.2 || ^6.3`). Core: `^9.5 || ^10 || ^11`. Package: Webform.
- Configure: `webform_address_autocomplete.settings` → `/admin/config/webform-address-autocomplete`
  (permission `administer site configuration`). Pick the active provider there, then configure
  the chosen provider (e.g. its API key) on its own sub-page.
- No custom permissions, no Drush, no config schema, no hooks beyond `hook_help`. Defines one
  plugin type and four bundled providers.

## Key facts

- Config object: `webform_address_autocomplete.settings`. Key `active_plugin` = the active
  provider plugin id (string). Each provider's own settings are stored under a config key named
  after its plugin id, holding a **PHP-serialized** array (there is no config schema).
- Plugin type `WebformAddressProvider`: manager service `plugin.manager.webform_address_provider`,
  base `WebformAddressProviderBase`, interface method `processQuery($string)`, annotation
  `@WebformAddressProvider(id, label)`, directory `src/Plugin/WebformAddressProvider`,
  alter hook `hook_webform_address_autocomplete_address_provider_info_alter()`.
- Bundled provider plugin ids: `france_address`, `google_maps`, `mapbox_geocoding`, `post_ch`.
- Webform element: FormElement + WebformElement plugin both id `webform_address_autocomplete`,
  label "Address autocomplete", category "Advanced elements", composite; extends Webform's
  `WebformAddress`.
- Routes: `webform_address_autocomplete.settings` (settings form); `webform_address_autocomplete.addresses`
  at `/webform-address-autocomplete/addresses` (`_format: json`) — the suggestion endpoint the
  element's JS calls; plus one dynamic route per provider
  (`webform_address_autocomplete.webform_address_provider.<id>`, permission
  `access administration pages`) generated by `Routing\WebformAddressProviderRoutes::routes()`.
- JS libraries (`webform_address_autocomplete/webform_address_autocomplete`): builds on core
  `drupal.autocomplete`; `webform_address_autocomplete.js` fills the sub-fields on select,
  `webform_address_autocomplete_override.js` stops commas in a one-line address from splitting
  the search term.

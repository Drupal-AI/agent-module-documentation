# Webform Browser Info — agent index

A **hidden Webform element that captures the submitter's browser/device info** (user-agent/screen details).
Depends on `webform`. Version **1.0.0-alpha3**. Core `^10.3||^11`.

Forms — browser/device details are **personal data** (fingerprinting potential): collect minimally, disclose,
apply submission retention/access policy. No access role.

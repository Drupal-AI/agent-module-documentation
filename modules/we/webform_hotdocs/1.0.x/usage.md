Webform HotDocs generates HotDocs documents from webform submission data.

---

Webform HotDocs integrates the Webform module with HotDocs — a document-automation platform — to fill in templated documents using webform submission data, so a submitted form can automatically produce a completed document (contracts, legal forms) via HotDocs.

HotDocs API credentials should be stored securely (env-backed); submission data is sent to HotDocs (privacy). Depends on `webform`; supports Drupal 10 and 11.

Webassets manages local and remote media assets.

---

Webassets **manages local and remote media assets** — a media-asset management layer (part of a `web*`
module suite, e.g. used by webblog) for handling images/files from local storage and remote sources. It targets
core 11.4.

Use it as the asset layer for the web* suite. It is a media feature. Security/data handling: where it handles
**remote assets**, remote URLs/content come from an external source (use trusted sources over HTTPS; treat remote
files as untrusted), and local assets follow core media/file access. It has no access-control role. Configure the
asset sources.

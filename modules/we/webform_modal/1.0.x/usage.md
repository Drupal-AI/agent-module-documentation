Webform Modal displays a webform in a modal based on a configured webform id.

---

Webform Modal displays a webform in a modal dialog — opening a configured webform (by ID) in a modal
overlay (e.g. from a link/button), so forms can be presented as popups rather than on a dedicated page. It
depends on the Webform module, is configured at `webform_modal.config_form`, provides its own permissions.

Use it to present webforms as modals. It is a forms/display feature affecting how a webform is presented; the
webform's own access and submission handling still apply, and it has no access-control role. Configure which
webform opens in the modal.

# Webform Modal — agent index

Displays a **configured webform in a modal dialog** (open a webform by ID in a modal — forms as popups).
Depends on `webform`; provides permissions. Config at `webform_modal.config_form`. Version **1.0.1**. Core
`^10.3||^11`.

Forms/display — affects presentation; the webform's own access/submission handling still applies. No access
role.

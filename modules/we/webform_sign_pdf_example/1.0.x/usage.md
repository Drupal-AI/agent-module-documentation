Webform Sign PDF Example digitally signs and prints to a PDF.

---

Webform Sign PDF (Example) is an **example module demonstrating how to digitally sign and print a Webform to
a PDF** — a reference implementation showing the signing/PDF-generation flow for webform submissions. It is in
the webform package.

Use it as a reference/example, not a production module. It is a developer/example feature. Security note (for any
real signing implementation): digital signing and generated PDFs must handle the signing **key/credential** as a
secret and validate/verify signatures properly — treat this as illustrative, and build a hardened version for
production. It has no content or access role. Read it to learn the signing flow.

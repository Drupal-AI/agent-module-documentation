A media type for storing internal Gherkin (BDD) scripts with an editor.

---

Gherkin Script provides a media entity of type 'gherkin' to add internal Gherkin scripts, with a field-type widget and formatter (using the Ace editor for syntax highlighting) — so BDD/test scenarios written in Gherkin can be stored, edited and displayed as media on the site. Depends on core `editor`, `media`, and `ace_editor`; supports Drupal 10.4 and 11.

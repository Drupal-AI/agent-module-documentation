Fetch and display upcoming events from a Promogogo partner feed.

---

Promogogo Events fetches upcoming events from a Promogogo partner feed and displays them in a configurable, filterable block — so a venue/partner site can show its Promogogo-listed events without manual entry.

The Promogogo feed/partner details are admin-configured. The block's 'load more' endpoint is a public read-only pagination endpoint (events are public). Depends on core `block`; supports Drupal 10.3+ and 11.

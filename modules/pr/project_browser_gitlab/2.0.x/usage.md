A GitLab source plugin for the Project Browser.

---

Project Browser Gitlab provides a plugin to integrate Project Browser with GitLab — so the core Project Browser can list and install modules from a GitLab-hosted source (e.g. a private/company module registry) in addition to drupal.org. Depends on `project_browser`; supports Drupal 10 and 11.

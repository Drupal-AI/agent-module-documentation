# Previewer — agent index

Lets editors **preview content while editing** (see rendered output before saving). Depends on core
`node`. Version **1.0.9**. Core `^9||^10||^11`.

Content-editing/preview — reflects edited content, respects viewer access; changes the editing
experience, not content/access.

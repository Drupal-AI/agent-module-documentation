Prehome displays a prehome (splash/intro) page.

---

Prehome displays a pre-home page — a splash/intro/landing page shown before (or in place of) the site's
normal homepage, for a campaign splash, age gate, language chooser or an intro experience. It is configured
at `prehome.settings_form`, provides its own permissions, in the Other package.

Use it to show a splash/intro page. It is a content-display/routing feature affecting what the front page
shows; the prehome content is admin-authored and it has no access-control role (a splash page is presentation,
not access control — if used as an "age gate" or similar, note it's a soft gate, not enforcement). Configure
the prehome content and display.

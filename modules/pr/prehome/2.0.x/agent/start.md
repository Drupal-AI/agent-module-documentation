# Prehome — agent index

Displays a **pre-home (splash/intro) page** before the homepage (campaign splash / age gate / language
chooser / intro). Config at `prehome.settings_form`; provides permissions. Version **2.0.5**. Core
`^9||^10||^11`.

Content-display/routing — admin-authored splash content; presentation, not access control (an "age gate" here
is a **soft** gate, not enforcement). No access role.

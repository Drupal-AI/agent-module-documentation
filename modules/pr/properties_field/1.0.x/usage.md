Properties Field provides a Properties field that stores arbitrary properties.

---

Properties Field provides a **field for storing arbitrary key/value properties** — a flexible bag of
name/value pairs on an entity, for metadata/attributes that don't warrant dedicated fields. It works across
core 9–11.

Use it to attach ad-hoc properties to content. It is a fields/content-modelling feature; the values are content
and it has no content or access role. Add the properties field to a bundle. If property values are emitted into
markup/attributes, output them safely (they are field content).

# Properties Field — agent index

A field that stores **arbitrary key/value properties on an entity** (a flexible name/value bag for ad-hoc
metadata). Version **1.2.0**. Core `^9||^10||^11`.

Fields/content-modelling — values are content; no content/access role. Output property values safely if
emitted into markup/attributes.

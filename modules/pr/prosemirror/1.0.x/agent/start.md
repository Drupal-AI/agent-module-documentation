# ProseMirror — agent index

**A ProseMirror-based rich text editor for Drupal** (open-source CKEditor alternative; headless/decoupled-friendly).
Provides permissions. Version **1.0.0-beta2**. Core `^10||^11`.

Content-editing/WYSIWYG — output safety depends on the **text format's filters** (ensure it sanitizes/restricts HTML
to prevent XSS, as with CKEditor). No access role beyond permission.

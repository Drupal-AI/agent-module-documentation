Preprocessor Plugins turns theme preprocessing into discoverable, reusable plugins.

---

Preprocessor Plugins provides the ability to manage Drupal template preprocessing through the Plugin API — so instead of scattering `hook_preprocess_*` functions across a theme/module, developers implement preprocessing as discoverable, reusable plugins. It brings structure and reuse to template preprocessing.

It's a developer/theming API with no content or access role of its own. Supports Drupal 8 through 11.

Project Wiki provides an editable wiki for a Drupal project.

---

Project Wiki **provides an editable wiki** — an in-site wiki for documenting a Drupal project, with searchable/
listable pages. It depends on the List.js and core Help modules, and provides its own permissions.

Use it for project documentation. It is a content/collaboration feature; wiki pages are editable content following
its permissions, and it has no broad access-control role beyond that. Note: wiki content is user-editable — sanitize
input and gate editing appropriately. Configure the wiki.

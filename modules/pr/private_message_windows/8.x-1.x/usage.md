Private Message Windows provides a window interface for the Private Message module like in LinkedIn.

---

Private Message Windows adds a **LinkedIn-style chat-window UI** to the Private Message module — pop-up
message windows docked in the corner of the page for ongoing conversations, instead of only the full-page
message thread view. It depends on the Private Message module, in the Private Message package.

Use it to give private messaging a chat-window experience. It is a user-engagement/UI layer over Private
Message; message access, threads and who-can-message-whom are all governed by **Private Message** (this module
only changes the presentation), and it has no access-control role of its own. Enable it for the windowed UI.

# Private Message Windows — agent index

Adds a **LinkedIn-style chat-window interface to the Private Message module** (docked pop-up message windows
vs the full-page thread). Depends on `private_message`. Version **8.x-1.2**. Core `^8.8||^9||^10||^11`.

User-engagement/UI layer — message access/threads/permissions all governed by **Private Message** (this only
changes presentation); no access role of its own.

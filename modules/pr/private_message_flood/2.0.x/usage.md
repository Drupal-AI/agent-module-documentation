Private Message Flood sets up flood protection for the Private Message module.

---

Private Message Flood adds **flood (rate-limit) protection to the Private Message module** — limiting how
many private messages a user may send in a time window, configurable **per role**, to curb messaging spam/
abuse. It depends on the Private Message and Duration Field modules, in the Private Message package.

Use it to rate-limit private messaging. This is a **security/anti-abuse-positive** feature: per-role flood
limits on message sending prevent a user from spamming or flooding others via private messages. It reads the
user's roles and applies the configured flood limit; it has no access-control role of its own. Configure the
per-role flood limits.

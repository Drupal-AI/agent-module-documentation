Profile Manager helps manage custom profile user experiences.

---

Profile Manager is a **helper module for managing custom user-profile experiences** — providing tooling to
build/manage profile-related pages/flows for users. It depends on core Node, provides its own permissions.

Use it to build custom profile experiences. It is an administration/user feature; it works within core node/user
access and it has no access-control role beyond its permission. Configure the profile experiences.

Progressive Admin adapts the admin UI to configurable settings.

---

Progressive Admin provides a **progressive admin experience** — adapting the administrative UI (built on
core Navigation) to configurable settings, so the admin interface can be tailored/simplified per configuration.
It depends on core Navigation, provides its own permissions, in the FlexSite package.

Use it to tailor the admin experience. It is an administration/UI feature affecting the admin interface; it has
no content or access role beyond its permission. Configure the progressive-admin settings.

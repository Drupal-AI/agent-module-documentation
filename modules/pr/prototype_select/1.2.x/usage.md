Prototype Select provides accessible enhancements to select HTML elements.

---

Prototype Select provides **accessible enhancements to native `<select>` elements** — improving the
usability and accessibility of dropdowns (keyboard/screen-reader support, styling) while keeping them standard
selects. It is in the Prototype package.

Use it to make selects more accessible/usable. This is an **accessibility-positive** UI feature; it enhances
form select widgets and has no content or access role. Enable it on the relevant selects.

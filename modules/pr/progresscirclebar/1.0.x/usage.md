Progress Circle OR Bar creates progress circles or progress bars to display percentages or progress visually.

---

Progress Circle OR Bar creates visual progress indicators — circular progress rings or horizontal
progress bars — to display percentages or progress values attractively (skills, completion, statistics).
It is configured at `progresscirclebar.settings`.

Use it to present percentage/progress data visually (e.g. "80% complete", skill meters). It is a
content-display/presentation feature; the values are content/config-driven and it has no access-control
role. Configure the progress values and appearance.

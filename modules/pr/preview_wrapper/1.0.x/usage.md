Preview Wrapper customizes the content preview so it more closely matches the real rendered page.

---

Preview Wrapper allows site builders to interact with the content preview to provide more accurate previews — wrapping the preview output so it renders closer to how content will actually appear (regions, layout), improving the editorial preview experience.

Management is gated by `manage preview wrappers`. It's an editorial/site-builder tool with no front-end role. Supports Drupal 9, 10, and 11.

# Primary Entity Reference — agent index

Entity reference **field type designating one referenced item as the primary** (primary category / lead
author / main related item) without a separate field. Version **1.0.0-beta8**. Core `>=11.1`.

Fields/content feature — references respect entity access; adds no access of its own. Use the primary
designation in displays/logic.

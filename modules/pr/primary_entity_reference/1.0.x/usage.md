Primary Entity Reference provides an entity reference field with the ability to mark one of the referenced entities as the primary.

---

Primary Entity Reference provides an entity reference field type that lets one of the referenced
entities be marked as the "primary" — so a multi-value reference (e.g. multiple related items,
categories or authors) can designate which one is the main/canonical reference. This supports patterns
like a primary category, a lead author, or a main related item, without a separate field. It is in the
Field types package.

Use it where a set of references needs one distinguished as primary. It is a fields/content feature
providing the field type and its primary flag; the references themselves respect entity access, and
this adds no access of its own. Configure the field and use the primary designation in displays/logic.

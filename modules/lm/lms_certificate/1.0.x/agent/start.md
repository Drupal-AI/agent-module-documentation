# LMS Certificate — agent index

Associates **completion certificates with LMS courses** (learners who complete get one);
`lms_certificate_fillpdf` submodule generates PDFs. Depends on `lms`, `dynamic_entity_reference`. Version
**1.0.0-alpha3**. Core `^10.3||^11`.

Learning/engagement — certificates tie to learners (personal/achievement data); gate access so learners
see their own; handle with privacy in mind.

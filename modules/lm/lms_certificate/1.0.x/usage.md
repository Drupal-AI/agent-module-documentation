LMS Certificate allows certificates to be associated with courses in the LMS module, with a FillPDF submodule for PDF generation.

---

LMS Certificate lets courses in the LMS module award completion certificates — associating a
certificate with a course so learners who complete it receive one. It ships an `lms_certificate_fillpdf`
submodule for generating certificate PDFs (via FillPDF). It depends on the LMS module and Dynamic Entity
Reference.

Use it on LMS-based e-learning sites that issue completion certificates. It is a learning/engagement
feature; certificates are tied to learners (who completed what), so that is personal/achievement data —
gate access appropriately so learners see their own certificates and the completion data is handled with
privacy in mind. Configure certificate templates per course.

LMS Membership Request allows setting a course as requiring membership validation.

---

LMS Membership Request lets an LMS course be marked as requiring membership validation — so enrolling in
(or accessing) the course requires a membership request that must be validated/approved, rather than open
self-enrollment. It depends on the LMS Classes module, in the LMS package.

Use it to gate course enrollment behind approval. It is an e-learning/access feature: it adds a
request/approval step before a user gains course membership, so course access depends on the validation
outcome — verify the approval workflow and who can approve requests (approvers effectively grant course
access). The actual course-content access is governed by the LMS module's access model; this adds the
enrollment gate. Configure which courses require validation.

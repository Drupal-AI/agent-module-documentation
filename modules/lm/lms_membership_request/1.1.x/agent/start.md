# LMS Membership Request — agent index

Lets an LMS course **require membership validation** (request/approval gate for enrollment vs open
self-enrollment). Depends on `lms_classes`. Version **1.1.0-beta4**. Core `^10.3||^11`.

E-learning/access — adds a request/approval step before course membership (approvers effectively grant course
access — verify the workflow); course-content access governed by the LMS module.

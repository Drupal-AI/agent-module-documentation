# LMS Webform — agent index

Integrates **Webform with the LMS module** (webforms as course/lesson activities — quiz/survey/assignment
steps tied into learner progress). Depends on `webform`, `lms`. Version **1.0.0-beta2**. Core `^10.3||^11`.

Integration/e-learning — webform access follows Webform, course/enrolment access follows LMS; no access role
of its own.

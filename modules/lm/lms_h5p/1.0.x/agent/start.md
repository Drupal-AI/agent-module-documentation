# LMS H5P Activity — agent index

Adds an **H5P interactive-content activity plugin to the LMS module** (quizzes/interactive video/presentations
as course activities). Depends on `lms`. Version **1.0.0-alpha4**. Core `^10.3||^11`.

E-learning — H5P is authored course content; access follows the LMS course/activity model. No access role of
its own.

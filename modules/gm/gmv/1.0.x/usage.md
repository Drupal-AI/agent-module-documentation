Google Model Viewer easily displays interactive 3D models on the web.

---

Google Model Viewer (gmv) displays interactive 3D models — using Google's `<model-viewer>` web component
to render 3D/AR models (glTF/GLB) that visitors can rotate and view, for product visualization and 3D
content. It is in the Field types package.

Use it to show interactive 3D models. It is a content-display/media feature rendering 3D assets client-side;
the models are managed content (respecting file access) and it has no access-control role. Add the model-
viewer field and configure the 3D model.

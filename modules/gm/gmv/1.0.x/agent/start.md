# Google Model Viewer (gmv) — agent index

Displays **interactive 3D models** via Google's `<model-viewer>` web component (glTF/GLB, rotate/AR — product
visualization). Version **1.0.1**. Core `^9||^10||^11`.

Content-display/media — renders 3D assets client-side (managed content, respects file access); no access
role.

# Entity Association (association) — agent index

Groups content entities into an **association** container governed by a **behavior plugin**, with a
pluggable **landing page**, a shared "active association" **context**, per-bundle access control, and
entity **updaters** that run over members on save. Version **2.0.0-alpha9**. Core `^10.2 || ^11`.
Package *Content Building*. License GPL-2.0-or-later.

- **Depends on** core `node`, `token` (drupal/token), `toolshed` (drupal/toolshed). Recommends `pathauto`.
- **Submodules** (each documented in its own tree under `modules/<sub>/2.0.x/`):
  - [`association_autogen`](../modules/association_autogen/2.0.x/agent/start.md) — auto-generate member entities when an association is created.
  - [`association_menu`](../modules/association_menu/2.0.x/agent/start.md) — per-association menus & breadcrumbs.
  - [`association_page`](../modules/association_page/2.0.x/agent/start.md) — revisionable dedicated landing-page entity.

## What it provides (from source)

- **Entities**
  - `association` (content, bundle = `association_type`; `src/Entity/Association.php`) — the container; publishable, translatable, owned. Canonical URL is delegated to the landing-page handler.
  - `association_type` (config bundle; `src/Entity/AssociationType.php`) — stores the chosen `behavior` and `landingPage` plugin config, `searchable`, `useTaskLabel`.
  - `association_link` (content, **internal**; `src/Entity/AssociationLink.php`) — join row between an association and a target entity (`entity_type` + `target` + `tag` + `bundle`). Not user-facing; its route provider adds add/edit/delete-content forms rendered inside the association manage UI.
- **Plugin types**: `@AssociationBehavior` (mgr `plugin.manager.association.behavior`) and `@AssociationLandingPage` (mgr `plugin.manager.association.landing_page`). Ships behaviors `entity_list`, `entity_manifest`; landing pages `none`, `associated_entity`.
- **Entity adapters** (Toolshed YAML strategy, `strategy.manager.association.entity_adapter`): declared in `<module>.association.entity_adapter.yml`; ships `node`. `src/Adapter/EntityAdapter.php` handles create/form/access per entity type.
- **Services**: `association.negotiator` (tagged `association_negotiator` collector; default `DefaultAssociationNegotiator`), `association.pathauto.helper`, three route access checkers, two cache contexts (`route.association`, `route.association_type`), a `context_provider`, config-validation + route event subscribers.
- **Block**: `association_block` (`src/Plugin/Block/AssociationBlock.php`) renders the active association; integrates association_menu when present.
- **Permissions**: `administer entity association configurations`, `access entity association overview page`, plus per-`association_type` operation perms generated by `AssociationPermissions` (`{op} association of type {id}` for publish/create/update/delete/manage/create_content/delete_content).
- **Views**, **tokens** (`association.tokens.inc`), a Search API processor, a `AssociationType` condition, and Views argument plugins.

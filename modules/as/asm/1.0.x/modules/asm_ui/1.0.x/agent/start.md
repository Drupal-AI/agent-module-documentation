# Avoid sending mail UI (asm_ui) — agent index

Optional admin UI for the parent **asm** module's `asm_email_blocked` blocklist entity. Adds no
entity, no permission, no config, no service — it only attaches UI handlers and routes to the
entity that **asm** already defines. Version **1.0.0-beta2**. Core `^10 || ^11`. Depends on
`asm:asm`. Package *Other*. License GPL-2.0-or-later.

## What it provides

- **`hook_entity_type_alter()`** (`asm_ui.module`) on `asm_email_blocked`:
  - `list_builder` = `Drupal\asm_ui\EmailBlockedListBuilder`
  - `route_provider[html]` = `Drupal\asm_ui\Routing\EmailBlockedHtmlRouteProvider`
  - form handlers: `add`/`edit` = `Drupal\asm_ui\Form\EmailBlockedForm`,
    `delete` = core `ContentEntityDeleteForm`
  - link templates: `collection` `/admin/config/people/mail-blocked`, `add-form` `.../add`,
    `canonical` & `edit-form` `.../{asm_email_blocked}`, `delete-form` `.../{asm_email_blocked}/delete`
- **Menu link** `entity.asm_email_blocked.collection` ("Emails Blocked", parent `user.admin_index`)
  and **action link** "Add email" on the collection (`asm_ui.links.menu.yml` /
  `asm_ui.links.action.yml`).
- Routes generated by `AdminHtmlRouteProvider` carry `_entity_access` requirements, resolved to the
  entity's `admin_permission = "administer asm email blocked"` (defined by **asm**). asm_ui adds no
  permission of its own.

## Classes

- `EmailBlockedListBuilder` (extends `EntityListBuilder`) — columns ID / Mail / Reason / Created
  (`created` via injected `date.formatter`); `render()` appends a "Total emails blocked: N" line
  from an `accessCheck(FALSE)->count()` query (a display-only total, admin-gated route).
- `EmailBlockedForm` (extends `ContentEntityForm`) — `save()` sets a status message, logs a
  notice to the `asm` channel, and redirects to `entity.asm_email_blocked.collection`.
- `EmailBlockedHtmlRouteProvider` (extends `AdminHtmlRouteProvider`) — overrides
  `getCanonicalRoute()` to return the **edit-form** route, so the canonical link opens the edit
  form rather than a separate view page.

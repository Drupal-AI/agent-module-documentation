Pager For Node provides personalized pagers for browsing node listings.

---

Pager For Node **provides prev/next pagers for nodes** — letting admins set up personalized pagers so visitors
can browse through node listings (previous/next) in a defined order. It works across core 9–11.

Use it to add node browsing pagers. It is a content-display/navigation feature; navigation follows normal node
access and it has no access-control role. Configure the node pager.

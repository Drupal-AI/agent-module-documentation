Pagedesigner Responsive Images extends the Pagedesigner page builder with responsive image handling and WebP optimization.

---

Pagedesigner Responsive Images is an extension for Pagedesigner, a drag-and-drop page building
tool. It adds responsive image handling to images placed in Pagedesigner content, integrating with
imageapi_optimize_webp so images are served in responsive sizes and WebP format for performance. It
depends on Pagedesigner, its image submodule, and the WebP optimize pipeline.

Use it on a Pagedesigner-based site to improve image delivery — correctly-sized responsive images and
modern formats reduce page weight. It is a media/performance enhancement layered on Pagedesigner; it
governs how images render, not access. It provides its own permissions for the Pagedesigner image
feature.

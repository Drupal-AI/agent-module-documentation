# Pagedesigner Responsive Images — agent index

Extends the **Pagedesigner** page builder with **responsive images + WebP** (via
`imageapi_optimize_webp`). Depends on `pagedesigner`, `pagedesigner_image`,
`imageapi_optimize_webp`. Version **4.2.4**. Core `^10||^11`.

Media/performance enhancement (no access role). Provides Pagedesigner image permissions.

---

Paragraphs Modal Add **lets users add paragraphs via a modal** — presenting the add-paragraph action in a
modal dialog for a cleaner add experience. It depends on the Paragraphs module.

Use it to add paragraphs in a modal. It is a content-editing/UX feature; it affects the add-paragraph flow and has
no access-control role. Enable it for modal add.

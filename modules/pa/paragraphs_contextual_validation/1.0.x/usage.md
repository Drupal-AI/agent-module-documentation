Paragraphs Contextual Validation adds configurable validation constraints to paragraph reference fields.

---

Paragraphs Contextual Validation adds **configurable validation constraints to paragraph reference
fields** — letting you enforce rules on the paragraphs added to a field (e.g. required counts, allowed
combinations, per-context requirements) beyond the basic field settings. It depends on Entity Reference
Revisions and Paragraphs, in the Custom package.

Use it to enforce paragraph composition rules. It is a content-editing/validation feature; it constrains what
editors can save and has no access-control role. Configure the validation constraints on the paragraph
field.

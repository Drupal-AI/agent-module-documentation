Sort Alphabetically Widget provides widgets to sort edit-field values alphabetically.

---

Sort Alphabetically Widget **provides widgets that sort field values alphabetically** — a collection of simple
field widgets that keep multi-value entries sorted A→Z in the edit form, for tidy ordered data. It works across core
10.3–12.

Use it to auto-sort multi-value fields alphabetically. It is a content-editing/field-widget feature; it orders
values in the widget and has no access-control role. Configure the widget on a field.

Page Metatag allows meta tags for all pages and entities.

---

Page Metatag **allows configuring meta tags for pages and entities** — adding SEO/social meta tags
site-wide (and per entity), using tokens for dynamic values. It depends on the Token module.

Use it to manage meta tags across the site. It is an SEO feature; meta values reflect on-page/entity content
(tokens resolve against access-respecting data) and it has no content or access role. Configure the meta
tags.

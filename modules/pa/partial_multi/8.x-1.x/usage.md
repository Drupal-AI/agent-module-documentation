Partially Multilingual provides functionality for an only partially multilingual site.

---

Partially Multilingual (partial_multi) provides functionality for sites that are only partially
multilingual — where some content/sections are translated and others are single-language, helping manage the
mixed state cleanly (rather than requiring full multilingual everywhere). It is in the Multilingual package.

Use it on sites with partial translation coverage. It is a multilingual feature affecting how partially-
translated content is handled; it has no content or access role. Configure the partial-multilingual
behaviour.

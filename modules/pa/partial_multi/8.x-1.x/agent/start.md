# Partially Multilingual (partial_multi) — agent index

Provides functionality for **sites that are only partially multilingual** (some content translated, some
single-language — manage the mixed state cleanly). Version **8.x-1.0-alpha3**. Core `^10||^11`.

Multilingual — affects handling of partially-translated content; no content/access role.

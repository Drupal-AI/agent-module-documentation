Page Body Attributes allows specific page body attributes.

---

Page Body Attributes lets you **add specific attributes to the page `<body>` element** — configuring
classes/data-attributes on `<body>` (e.g. per page or condition) for theming/JS hooks, without a custom
preprocess hook. It works across core 8–11.

Use it to add body attributes for theming/JS. It is a theming feature affecting the body markup; attribute
values are admin-configured (keep them trusted, as with any attribute output) and it has no content or access
role. Configure the body attributes.

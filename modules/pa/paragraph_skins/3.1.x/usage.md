Paragraphs Skins implements skins (style variants) for the Paragraphs module.

---

Paragraphs Skins implements "skins" for Paragraphs — letting editors choose a style variant (a skin/CSS
class) per paragraph, so the same paragraph type can be presented in different visual styles without separate
types. It depends on the Paragraphs module, in the Paragraphs package.

Use it to offer style variants for paragraphs. It is a content-display/site-building feature affecting
paragraph presentation (applying a CSS class/skin); it does not change content or access and has no
access-control role. Configure the available skins per paragraph type.

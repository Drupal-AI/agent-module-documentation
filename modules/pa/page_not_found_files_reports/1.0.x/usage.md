Page Not Found Files Report scans pages for broken image URLs and reports them in admin.

---

Page Not Found Files Report **scans pages for broken image URLs** — crawling content for image references that
return 404 and listing them in an admin report, so editors can fix missing images. It works on core 10–11.

Use it to find broken images. It is a content-maintenance/reporting tool; it makes requests to check image URLs and
reports results (admin-facing) and has no content or access role. Configure and run the report.

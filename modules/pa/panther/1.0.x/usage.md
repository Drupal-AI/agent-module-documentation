Panther integrates Symfony Panther, a browser testing tool.

---

Panther **integrates Symfony Panther** — a real-browser (Chrome/Firefox via WebDriver) testing tool — into
Drupal, so tests can drive an actual browser (JavaScript, rendering) rather than a headless HTTP client, with a
`panther_examples` submodule. It is in the Testing package.

Use it to write real-browser tests for Drupal. It is a developer/testing tool for **development/CI only** — it
is not something to enable on production (it drives browsers/WebDriver and is test infrastructure). It has no
content or access role. Use it in your test suite.

Pattern.css integrates the Pattern.css library.

---

Pattern.css **integrates Pattern.css** — a CSS-only library of decorative background patterns (dots, lines,
grids), making them available as classes for theming. It is in the User interface package.

Use it to add CSS background patterns. It is a theming feature affecting presentation; patterns are pure CSS and
it has no content or access role. Use the Pattern.css classes in your theme.

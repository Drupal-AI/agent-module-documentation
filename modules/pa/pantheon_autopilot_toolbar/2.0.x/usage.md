Pantheon Autopilot Toolbar provides an admin toolbar button linked directly to the Autopilot Status for the site.

---

Pantheon Autopilot Toolbar adds a button to the admin Toolbar that links directly to the site's Pantheon
Autopilot status page — so maintainers of Pantheon-hosted sites can jump to Autopilot (Pantheon's automated
update/visual-regression service) from within Drupal. It provides its own permissions, in the Development
package.

Use it on Pantheon-hosted sites using Autopilot. It is an administration/UI convenience adding a toolbar
link; the link points to Pantheon's dashboard (which enforces its own access), and it has no access-control
role beyond its permission (gating who sees the button). Enable it to add the Autopilot link.

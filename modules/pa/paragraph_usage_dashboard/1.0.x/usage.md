Paragraph Usage Dashboard provides a visual dashboard showing where each Paragraph Type is used, with content types, path aliases and view links.

---

Paragraph Usage Dashboard provides a visual dashboard of paragraph-type usage — showing, for each
Paragraph Type, where it is used across the site (content types, specific content with path aliases, view
links, and icons), so editors/admins can see the footprint of each paragraph type before changing or
removing it. It depends on Paragraphs and Path Alias and provides its own permissions.

Use it to audit paragraph usage and understand impact before restructuring paragraph types. It is an
administration/content-audit tool that reads content to build the dashboard; it is informational (surfaces
usage the viewer is entitled to see) and has no access-control role. View the dashboard to explore usage.

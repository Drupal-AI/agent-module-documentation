# Paragraph Usage Dashboard — agent index

Visual **dashboard of where each Paragraph Type is used** (content types, content with path aliases, view
links, icons) — audit footprint before changing/removing a type. Depends on `paragraphs`, `path_alias`;
provides permissions. Version **1.0.8**. Core `^11`.

Admin/content-audit tool — reads content to report (informational; no access role).

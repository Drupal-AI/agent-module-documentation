Replace one page with another via a swap mechanism.

---

Page Swap provides a page swap mechanism to replace one page with another — so a request for page A is served the content of page B (transparently), useful for A/B tests, temporary replacements, or serving an alternate page without changing the URL. Depends on core `path_alias` and `menu_link_content`; supports Drupal 10 and 11.

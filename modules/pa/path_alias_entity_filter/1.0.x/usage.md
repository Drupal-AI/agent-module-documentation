Path Alias Entity Filter adds an entity-type filter to the URL aliases admin list.

---

Path Alias Entity Filter **adds an entity-type dropdown to the URL aliases admin filter** — letting site
builders narrow the aliases list by the entity type each alias points at, easing alias management. It depends on
core Path.

Use it to filter aliases by target entity type. It is a site-building/admin convenience; it filters the alias
admin list and has no content or access role. Use the filter on the aliases page.

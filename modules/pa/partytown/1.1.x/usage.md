Partytown integrates Partytown to offload third-party scripts to a web worker.

---

Partytown **integrates the Partytown library** — moving third-party scripts (analytics, tags) off the main
thread into a web worker to improve page performance. It works on core 10–11.

Use it to speed up pages laden with third-party scripts. It is a performance/front-end feature; it relocates
script execution and has no content or access role. Note: third-party scripts still run (in a worker) — the
privacy/consent considerations of those scripts are unchanged. Configure the Partytown integration.

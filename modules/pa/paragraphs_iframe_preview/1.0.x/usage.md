Paragraphs iFrame Preview renders closed-mode paragraph previews in an iframe using the front-end theme.

---

Paragraphs iFrame Preview **renders paragraph previews in an iframe** — showing a closed/collapsed paragraph's
preview using the **front-end theme** inside an iframe, so editors see how it will actually look. It depends on the
Paragraphs module.

Use it for accurate front-end paragraph previews. It is a content-editing/UX feature; it renders a preview in an
iframe (using the site theme) and has no access-control role. Enable it for iframe previews.

# Paragraphs wrap by field — agent index

Wraps **consecutive Paragraphs in a row/wrapper based on a specific field value** (group flat paragraphs
into rows/columns via a field marker, without nesting). Version **1.0.x** (dev). Core `^9||^10||^11`.

Content-display/site-building — affects paragraph wrapping in output, not paragraphs/access. Configure the
driver field.

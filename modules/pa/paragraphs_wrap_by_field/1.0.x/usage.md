Paragraphs wrap by field wraps Paragraphs in a row/wrapper based on a specific field value — grouping
consecutive paragraphs that share a field value (e.g. a "row" or "group" field) into a single wrapping
element, so editors can build multi-column/grouped layouts by tagging paragraphs rather than nesting them.
It is in the Custom package.

Use it to create grouped/row layouts from a flat paragraphs list via a field marker. It is a content-
display/site-building feature affecting how paragraphs are wrapped in output; it does not change the
paragraphs or access. Configure the field that drives the wrapping.

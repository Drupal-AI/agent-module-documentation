Paragraphs Sets Plugins UI provides a UI to simplify creation of paragraph sets.

---

Paragraphs Sets Plugins UI provides a user interface for creating paragraph sets — simplifying the
definition of Paragraphs Sets (predefined groups/templates of paragraphs) through the admin UI rather than
code/config, so editors/site builders can assemble reusable paragraph sets more easily. It depends on the
Paragraphs Sets module.

Use it to build paragraph sets via a UI. It is a content-editing/site-building feature affecting how
paragraph sets are defined; it does not change content or access and has no access-control role. Configure
the paragraph sets.

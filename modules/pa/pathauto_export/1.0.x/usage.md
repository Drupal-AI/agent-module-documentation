Pathauto export exports the URL aliases from the Pathauto module, for backup or transfer.

---

Pathauto export exports the URL aliases managed by the Pathauto module — producing an export of the
site's path aliases for backup, review, or transfer to another environment. It depends on the Pathauto
module.

Use it to capture or move the alias set (e.g. before a migration, or to review generated aliases). It is
an import/export utility operating on path aliases; it reads and exports alias data and has no
access-control role. Run the export and use the output as needed for your backup/transfer workflow.

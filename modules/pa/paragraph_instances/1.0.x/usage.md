Paragraph Instances finds and lists uses of a paragraph type across all nodes, for auditing paragraph usage.

---

Paragraph Instances helps audit paragraph usage — finding and listing where a given paragraph type is
used across all nodes, so site builders can see the impact before changing or removing a paragraph type
(which content would be affected). It provides its own permissions.

Use it before restructuring paragraph types to understand their footprint. It is an
administration/content-audit tool that reads content to build the usage report; it is informational (it
surfaces usage the viewer is entitled to see) and has no access-control role. Run the report to find
paragraph-type instances.

Panolens is a JavaScript 360 panorama viewer.

---

Panolens integrates the Panolens.js JavaScript library — a 360° panorama viewer — so panoramic/immersive
images can be displayed with pan/zoom/hotspot interaction on the site. It provides Drush commands, in the
Content display package.

Use it to display 360° panoramas. It is a content-display/media feature rendering panoramas client-side; the
panorama images are managed content (respecting file access) and it has no access-control role. Configure the
panorama display.

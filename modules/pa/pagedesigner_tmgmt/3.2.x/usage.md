Pagedesigner TMGMT integrates Pagedesigner with TMGMT for translating designed pages.

---

Pagedesigner TMGMT **integrates Pagedesigner with TMGMT** — enabling translation of Pagedesigner-built pages
through the Translation Management (TMGMT) workflow (including DeepL), so designed pages can be translated like
other content. It depends on the Pagedesigner, TMGMT (and TMGMT Content/DeepL) modules.

Use it to translate Pagedesigner pages via TMGMT. It is a multilingual/integration feature. Security/data handling:
translating via TMGMT/DeepL **sends page content to the translation provider** (external egress — confirm
acceptable) and provider credentials should be stored as secrets. It has no access-control role. Configure the
translation integration.

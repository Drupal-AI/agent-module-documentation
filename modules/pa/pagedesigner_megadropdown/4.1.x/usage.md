Pagedesigner Megadropdown adds megadropdowns to the main navigation with the pagedesigner module.

---

Pagedesigner Megadropdown adds mega-dropdown menus to the main navigation — letting site builders create
rich, multi-column mega-menu dropdowns (with Pagedesigner-built content) in the main menu. It depends on the
Pagedesigner module, in the pagedesigner package.

Use it to build mega menus with Pagedesigner. It is a site-structure/navigation feature; the mega-menu
content comes from Pagedesigner (respecting its access) and it has no access-control role. Configure the
mega-dropdown content.

Path tools suite offers utilities for working with paths and URL aliases.

---

Path tools suite provides path-based functionality for both site builders and developers — utilities for working with paths, URL aliases, and routing (e.g. path manipulation, alias helpers). It builds on the Form Decorator module.

It's a developer/site-builder utility with no content or access role of its own. Depends on `form_decorator`; supports Drupal 10 and 11.

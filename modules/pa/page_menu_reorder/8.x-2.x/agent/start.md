# Page Menu Reorder — agent index

Lets editors **drag-and-drop to reorder menu items directly on pages** (in-context vs the menu admin UI).
Config at `page_menu_reorder.admin_settings`; provides permissions. Version **8.x-2.0**. Core
`^8||^9||^10||^11`.

Site-structure/navigation editing — reordering is privileged (menu admin); gated by its permission, grant to
trusted editors. No access role beyond permission.

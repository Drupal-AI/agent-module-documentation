Page Menu Reorder provides drag and drop to reorder menu items on pages.

---

Page Menu Reorder lets editors reorder menu items via drag-and-drop directly on the front-end pages —
so menu ordering can be adjusted in context rather than through the menu admin UI. It is configured at
`page_menu_reorder.admin_settings` and provides its own permissions, in the Custom package.

Use it for in-context menu reordering. It is a site-structure/navigation editing feature; reordering menus is
governed by its permission (menu administration is privileged), so grant it only to trusted editors. It has
no access-control role beyond its permission. Configure where reordering is available.

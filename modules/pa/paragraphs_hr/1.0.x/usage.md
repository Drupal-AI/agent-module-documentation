Paragraphs HR provides a horizontal rule paragraph.

---

Paragraphs Horizontal Rule provides a **horizontal-rule (divider) Paragraph type** — a simple `<hr>`
divider block editors can add between Paragraphs to separate sections visually. It works across core 8–11.

Use it to add visual dividers in Paragraphs content. It is a content-editing/display feature; it is a
presentation element and has no content or access role. Add the HR paragraph.

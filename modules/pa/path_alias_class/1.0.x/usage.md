Path Alias Class adds the path alias as a class to the body tag on every page.

---

Path Alias Class adds the current page's path alias as a CSS class on the `<body>` tag of every page —
so themers can target pages by their alias in CSS/JS (e.g. `.about-us`), enabling per-page styling based on
the URL alias. It depends on core Path and is configured at `path_alias_class.settings`.

Use it for alias-based per-page theming. It is a theming/display feature adding a body class derived from
the path alias; aliases are admin/pathauto-generated (not arbitrary user input), and the value is emitted as
a CSS class. It has no access-control role. Enable it and configure how the class is generated.

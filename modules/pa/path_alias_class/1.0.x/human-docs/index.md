# Path Alias Class — manual setup guide

**Path Alias Class** (`path_alias_class`) adds the current page's path — and its
URL alias — to the `<body>` tag as CSS classes, so themers can target individual
pages by their alias in CSS or JavaScript. If a node titled "Training" has the
alias `/training` and node ID 77, the module adds classes such as `training` and
`node-77` to the body element. From there you can write `.training { … }` and
style that page (or that section) without touching a template or writing a
preprocess hook.

It's a small theming convenience with no content or access-control role. The
classes come from the page's alias, which is generated by an administrator or by
Pathauto — not from arbitrary visitor input — and they are emitted purely as CSS
class names. The module depends only on core's **Path** module.

Beyond the automatic classes, its settings form lets you fine-tune how the class
is generated and even add your own custom CSS, so simple per-page styling can be
done entirely from the admin UI.

This guide is written for a **human** clicking through the admin UI. If you want
terse, token‑cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Where it lives in the admin menu

Once enabled the body classes appear automatically on every page — there is
nothing you *must* configure. An optional settings form (route
`path_alias_class.settings`) lets you adjust how classes are derived from the path
and alias and add custom CSS rules; you'll find it alongside the site's
configuration pages. Because the module works the moment it is enabled, this guide
does not include a separate configuration chapter — just enable it and start
targeting pages by their alias in your theme's stylesheet.

## How to use it

1. Enable the module (see [Installation](installation/index.md)).
2. Load any aliased page and inspect the `<body>` element — you'll see classes
   derived from the path and alias (for example `training` and `node-77`).
3. In your theme's CSS, target those classes to style the page or section, e.g.
   `.training .region-content { … }`.

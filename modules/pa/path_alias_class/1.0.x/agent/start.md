# Path Alias Class — agent index

Adds the current page's **path alias as a class on the `<body>` tag** (target pages by alias in CSS/JS —
per-page styling). Depends on core `path`. Config at `path_alias_class.settings`. Version **1.0.1**. Core
`^9||^10||^11`.

Theming/display — body class derived from the (admin/pathauto-generated) alias; no access role.

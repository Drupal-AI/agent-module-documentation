Paragraphs Responsive Background Image Formatter renders responsive background images.

---

Paragraphs Responsive Background Image Formatter provides a **field formatter that renders a media image as
a responsive CSS background** on a Paragraph — outputting responsive `background-image` CSS (via BG Image
Formatter) so Paragraph sections can have full-bleed responsive backgrounds. It depends on core Media, BG Image
Formatter (and its responsive variant) and Paragraphs.

Use it for responsive background images on Paragraphs. It is a content-display/theming feature; the image is an
admin/editor-selected media item and it has no content or access role. Use the formatter on a Paragraph's image
field.

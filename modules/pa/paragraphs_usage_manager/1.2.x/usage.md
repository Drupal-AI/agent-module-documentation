Paragraphs Usage Manager centrally manages where paragraph types are allowed across entities.

---

Paragraphs Usage Manager **centrally manages paragraph-type usage** — an admin UI to control, in one place,
which paragraph types are allowed on which entity/field references across the site. It depends on the Paragraphs
module and provides its own permissions.

Use it to govern paragraph-type availability. It is a site-building/administration feature; it configures paragraph
allowances and has no access-control role beyond its permission. Configure the paragraph usage.

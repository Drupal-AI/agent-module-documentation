Page popup shows a configurable popup message on specific pages, for announcements or notices.

---

Page popup displays a configurable popup/modal message on selected pages — for announcements,
notices, promotions or consent-style messages that should appear when a visitor lands on particular
pages. Administrators configure the message content and which pages it shows on, at `page_popup.admin`.
It provides its own permissions and is in the User Interface package.

Use it to surface a timely message (a notice, campaign, or important update) on chosen pages without
custom code. It is a content-display/UI feature; the popup content is admin-authored and rendered
through Drupal's layers, and it has no access-control role. Configure the message and its page
targeting.

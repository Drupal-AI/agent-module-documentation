# Page popup — agent index

Shows a configurable **popup message on specific pages** (announcements/notices/promotions). Config at
`page_popup.admin`; provides permissions. Version **2.0.0**. Core `^9||^10||^11`.

Content-display/UI feature — admin-authored popup content rendered through Drupal's layers; no access
role. Configure message + page targeting.

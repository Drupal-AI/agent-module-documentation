# Payson Checkout — agent index

A Drupal Commerce **payment gateway implementing the Payson Checkout 2.0 API**. Depends on `commerce_payment`,
`commerce_tax`. Version **2.0.4**. Core `^10||^11`.

E-commerce/payment — communicates with the **Payson API server-to-server** and reads the authoritative API
status (not a client value). Credentials as secrets, HTTPS. No access role.

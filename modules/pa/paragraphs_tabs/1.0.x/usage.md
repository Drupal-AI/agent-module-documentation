Paragraphs Tabs embeds horizontal or vertical tabs using paragraphs.

---

Paragraphs Tabs provides a way to present paragraph content as horizontal or vertical tabs — so editors
can build tabbed content sections using paragraphs, organizing content into switchable tabs. It depends on
the Paragraphs module.

Use it to build tabbed content with paragraphs. It is a content-display/site-building feature affecting
presentation; the tab content is authored paragraphs (respecting their access) and it has no access-control
role. Configure the tabs paragraph.

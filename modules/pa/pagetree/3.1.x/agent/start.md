# Page Tree — agent index

Browse/manage site **menus as a page-tree** widget (page hierarchy = menu structure), for a
menu-driven editorial IA. Part of a **Frontend Publishing** / decoupled stack. Version **3.1.2**.
Core `^10||^11`.

Depends on `node`, `block`, `hal`, `menu_link_content`, `pathauto`, `restconsumer`,
`frontendpublishing` — not standalone. Provides permissions for tree/page management.

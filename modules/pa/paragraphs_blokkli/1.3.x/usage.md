Paragraphs Blokkli provides functionality to edit paragraphs without forms, using the blökkli visual editor.

---

Paragraphs Blokkli integrates the blökkli visual editor with Paragraphs — letting editors build and
edit paragraph-based content visually (drag-and-drop, in-place) rather than through traditional nested
forms, for a page-builder-like experience. It ships many submodules (comment, conversion, fragments,
GraphQL, library, scheduler, search, search_api, transform), depends on Paragraphs, provides its own
permissions, in the Paragraphs package.

Use it for a modern visual Paragraphs editing experience. It is a content-editing/page-building feature.
Editing capability is governed by its permissions plus the underlying paragraph/entity edit access — so
verify that visual editing is only available to users who may edit the content (the visual editor shouldn't
bypass entity/field edit access). Configure the blökkli editing and permissions.

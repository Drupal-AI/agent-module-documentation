# Paragraphs Media Icons — agent index

Replaces **Paragraphs' config-stored icons with Media-entity icons** (manage paragraph-type icons as
uploadable/reusable media). Requires PHP 8.1. Depends on core `media`, `file`, `paragraphs`. Version **1.1.0**.
Core `^11.3||^12`.

Content-editing/media — icons follow core media/file access; no access role.

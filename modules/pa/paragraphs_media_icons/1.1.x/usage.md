Paragraphs Media Icons replaces Paragraphs config-stored icons with Media entities.

---

Paragraphs Media Icons **replaces the config-stored icons Paragraphs uses (for paragraph type icons) with
Media entities** — so paragraph-type icons are managed as media (uploadable/reusable) instead of static config
files. It requires PHP 8.1, depends on core Media/File and Paragraphs.

Use it to manage paragraph icons as media. It is a content-editing/media feature; icons follow core media/file
access and it has no access-control role. Configure paragraph-type icons as media.

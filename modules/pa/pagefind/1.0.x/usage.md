Pagefind Search integrates the Pagefind static search engine for fast client-side search.

---

Pagefind Search integrates Pagefind — a high-performance, standalone (static) search engine — into Drupal, building a search index over content that runs client-side, so sites get fast full-text search without a server-side search backend (Search API/Solr). It indexes nodes and serves results via Pagefind.

Index administration is gated by `administer pagefind index`. Depends on core `node`, `system`, `path_alias`, and `views`; supports Drupal 10.3+, 11, and 12.

Paragraphs Browser Deploy makes Paragraphs Browser configuration deployable, so browser setups can be exported and deployed like other config.

---

Paragraphs Browser Deploy makes Paragraphs Browser configuration deployable — so the paragraph-browser
setup (the categorized palette editors use to add paragraphs) can be exported as configuration and moved
between environments via the standard config workflow, rather than being recreated by hand. It depends on
Paragraphs and Paragraphs Browser and provides Drush commands.

Use it in deployment workflows for Paragraphs Browser-based sites so browser configuration is
version-controlled and deployable. It is a developer/deployment tool operating on configuration; it has no
runtime access role. Export and deploy the Paragraphs Browser config through your config pipeline.

Pagedesigner View Modes Display allows defining display options per view mode.

---

Pagedesigner View Modes Display **lets you define display options for Pagedesigner elements per view mode**
— so a Pagedesigner-built element renders differently depending on the view mode it's shown in. It depends on
the Pagedesigner module, provides its own permissions, in the Pagedesigner package.

Use it to vary Pagedesigner element display by view mode. It is a site-building/display feature; it affects
rendering and has no content or access role beyond its permission. Configure the per-view-mode display.

Paragraphs List Filter provides filters for listing paragraph types, making it easier to work with paragraph type lists.

---

Paragraphs List Filter (machine name `paragraphs_list_filter`, module name
`paragraph_type_list_filter`) provides filters for listing paragraph types. On sites that use the
Paragraphs module heavily, the list of paragraph types can grow large; this module adds filtering so
paragraph types can be narrowed down when browsing or selecting them, improving manageability of the
paragraph-type administration/listing experience.

Use it where a site has many paragraph types and editors or admins need to filter that list. It
depends on the Paragraphs module and is an administrative/editorial convenience layered on paragraph
types — no access-control implications. It targets the paragraph-type listing rather than content
paragraphs themselves.

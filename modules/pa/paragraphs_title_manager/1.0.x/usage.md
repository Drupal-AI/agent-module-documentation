Paragraphs Title Manager provides global alignment configuration for paragraph title fields.

---

Paragraphs Title Manager **manages paragraph title fields globally** — providing site-wide configuration for
the alignment/handling of title fields across paragraph types, for consistent titling. It depends on the Paragraphs
module and provides its own permissions.

Use it to standardize paragraph titles. It is a content-editing/site-building feature; it configures title display
and has no access-control role beyond its permission. Configure the global title settings.

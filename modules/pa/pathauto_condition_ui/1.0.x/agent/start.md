# Pathauto Condition UI — agent index

Provides a **UI for managing additional conditions on Pathauto alias generation** (configure *when* an alias is
generated, without code). Depends on `pathauto`. Version **1.0.0**. Core `^9.4||^10||^11`.

Site-structure/URL — governs alias creation (not access); no access role.

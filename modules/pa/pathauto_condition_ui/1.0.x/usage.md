Pathauto Condition UI provides a UI for managing additional conditions on Pathauto aliases.

---

Pathauto Condition UI adds a **UI for managing conditions on Pathauto** alias generation — so you can
configure, in the admin interface, extra conditions that determine **when** a Pathauto URL alias is generated
(rather than always), without code. It depends on the Pathauto module.

Use it to conditionally control automatic alias generation. It is a site-structure/URL feature; it governs
alias creation (not access) and has no access-control role. Configure the Pathauto conditions.

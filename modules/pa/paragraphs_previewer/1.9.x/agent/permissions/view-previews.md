# Permission and route

One permission, declared in `paragraphs_previewer.permissions.yml`:

| Machine name | Title | `restrict access` |
|---|---|---|
| `view any paragraphs previewer` | View any paragraphs previewer | not set (FALSE) |

It guards the only route the module adds:

```yaml
paragraphs_previewer.form_preview:
  path: 'paragraphs-previewer/form/{form_build_id}/{element_parents}'
  defaults:
    _controller: '\Drupal\paragraphs_previewer\Controller\ParagraphsPreviewController::onForm'
  requirements:
    _permission: 'view any paragraphs previewer'
    _csrf_token: 'TRUE'
```

Consequences:

- Without the permission the *Preview* button still renders, but the iframe inside the modal
  returns **403** — grant the permission to every role that edits paragraphs.
- `_csrf_token: TRUE` means the URL is only valid when generated by Drupal (a `token` query
  argument is appended); you cannot hand-craft or share a preview URL.
- Per-paragraph `view` access is checked separately via `#access => $paragraph->access('view')`
  on the button, so the permission is necessary but not sufficient.

Grant it:

```bash
drush role:perm:add editor 'view any paragraphs previewer'
```

```php
user_role_grant_permissions('editor', ['view any paragraphs previewer']);
```

Check it: `drush role:list --filter='view any paragraphs previewer'` or
`\Drupal\user\Entity\Role::load('editor')->hasPermission('view any paragraphs previewer')`.

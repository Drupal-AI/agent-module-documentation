Glue between Drupal and the Parameter Verification library.

---

BE Param Verify provides the glue between Drupal and the Parameter Verification library — exposing that library's declarative parameter/argument validation to Drupal code, so developers can validate method/route parameters with a consistent, reusable ruleset. It's a developer library integration. Supports Drupal 9, 10, and 11.

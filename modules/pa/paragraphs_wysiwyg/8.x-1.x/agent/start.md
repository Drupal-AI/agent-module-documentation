# Paragraphs WYSIWYG — agent index

**Allows embedding paragraphs within WYSIWYG/rich-text fields** (via Allowed Formats). Depends on `allowed_formats`,
core `field`, `text`, `paragraphs`. Version **8.x-1.x** (dev). Core `^9||^10||^11`.

Content-editing — embedded paragraphs follow normal handling + text-format filtering (ensure the format sanitizes);
no access role.

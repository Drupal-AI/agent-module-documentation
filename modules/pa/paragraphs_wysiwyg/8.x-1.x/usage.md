Paragraphs WYSIWYG allows embedding paragraphs within WYSIWYG/rich-text fields.

---

Paragraphs WYSIWYG **lets editors embed paragraphs in rich-text fields** — inserting paragraph items inline
within a WYSIWYG/text field (using Allowed Formats), so structured paragraph content can live inside body text. It
depends on the Allowed Formats, core Field/Text and Paragraphs modules.

Use it to embed paragraphs in body content. It is a content-editing feature; embedded paragraphs follow normal
paragraph/field handling and text-format filtering, and it has no access-control role. Note: as with any rich-text
embedding, ensure the text format sanitizes output. Configure the WYSIWYG paragraph embedding.

Pagedesigner block filter allows customizing the output of blocks per element within the Pagedesigner page builder.

---

Pagedesigner block filter (pagedesigner_block_adaptable) allows customizing the output of blocks on a
per-element basis within Pagedesigner — the drag-and-drop page builder — so blocks placed in Pagedesigner
content can have their output adapted/filtered per element. It depends on the Pagedesigner module.

Use it on Pagedesigner-based sites to fine-tune block output within built pages. It is a content-display/
site-building feature affecting block rendering in Pagedesigner; the blocks keep their own access and it has
no access-control role. Configure the block output customization.

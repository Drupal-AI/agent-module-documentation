# Pagedesigner block filter — agent index

Allows **customizing block output per element** within the **Pagedesigner** page builder (adapt/filter block
output). Depends on `pagedesigner`. Version **4.1.0**. Core `^10.1||^11`.

Content-display/site-building — affects block rendering in Pagedesigner; blocks keep their own access; no
access role.

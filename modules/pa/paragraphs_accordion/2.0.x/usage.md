Paragraphs Accordion embeds an accordion of text and titles in a paragraph.

---

Paragraphs Accordion provides a **pre-configured paragraph type that renders an accordion** — collapsible
title/text sections — so editors can add an accordion of FAQ-style content as a paragraph without building the
type themselves. It works across core 8–11.

Use it to add accordions via paragraphs. It is a content-editing/display feature; the accordion content is
authored (rendered normally) and it has no access-control role. Add the accordion paragraph type.

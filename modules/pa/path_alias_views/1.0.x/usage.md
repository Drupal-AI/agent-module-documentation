Path Alias Views provides Views integration for path alias entities.

---

Path Alias Views provides **Views integration for path-alias entities** — exposing URL aliases to Views so
you can build lists/reports of aliases (with a `path_alias_views_cshs_filter` submodule for hierarchical
filtering). It depends on core Views.

Use it to build views of URL aliases. It is a developer/site-building feature; alias data is admin/site
metadata and it has no content or access role of its own (Views' own access applies). Build a view of path
aliases.

Paragraph SDC provides adapters for using Single Directory Components (SDC) with Paragraphs, rendering paragraph types through SDC components.

---

Single Directory Components (SDC) is Drupal's component system; Paragraphs models structured content. Paragraph SDC bridges them, so paragraph types render through SDC components. It is a theming/component integration with no security surface — SDC components are theme-layer code rendering access-controlled paragraph field data. Adopt where paragraphs and SDC are both used.

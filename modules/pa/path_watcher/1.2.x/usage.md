Path Watcher collects path/page browsing statistics.

---

Path Watcher **collects path browsing statistics** — recording which paths/pages are visited to provide usage
statistics, as a lightweight alternative to full analytics. It depends on core Path Alias and provides its own
permissions.

Use it for basic page-visit stats. It is a statistics feature. Privacy note: it records **browsing activity**
(which can be linked to users/sessions and is personal data in many jurisdictions) — minimize/anonymize what's
stored, disclose per your privacy policy, and gate the stats report to trusted users. It has no access-control role
beyond its permission. Configure path-watching.

# Paragraph Feeds Target — agent index

A **Feeds target plugin that maps feed values into paragraphs** (build paragraph content from a Feeds import).
Depends on `feeds`, `paragraphs`, `entity_reference_revisions`. Version **1.0.0-beta1**. Core `^10.2||^11`.

Import/content — processes **external feed data** into paragraphs (validate source; apply **safe text
formats**). No access role.

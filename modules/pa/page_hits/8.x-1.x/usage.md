Page Hits tracks page views and displays page-hit statistics (view counts) for content.

---

Page Hits tracks page views and displays page-hit statistics — counting how many times pages/content
are viewed and surfacing those counts, a self-hosted view counter (as opposed to fetching from an external
analytics service). It is configured at `page_hits.settings`.

Use it to show view counts on content or report on page popularity without a third-party analytics service.
It is a statistics/reporting feature that records hits locally; be mindful of what per-hit data it stores
(avoid logging unnecessary personal data, and consider privacy for any IP/user tracking). It has no
access-control role. Configure tracking and display.

# Configuration

Page Hits works as soon as you enable it and place the block — the settings page
is for adjusting how tracking and display behave, not a required step.

## Open the settings form

1. Log in as a user with the **Administer site configuration** permission (an
   administrator by default).
2. Go to **Configuration → System → Page Hits**, or navigate directly to the
   module's settings page (config route `page_hits.settings`).

## What it controls

The form lets you tune the counter's **tracking** (how hits are recorded) and its
**display** (how the count is presented through the Page Hits block). Adjust these
to match how you want popularity reflected on your site.

Because the counter records data on every hit, keep privacy in mind: record only
the per‑hit detail you actually need, and consider the implications of any IP or
user tracking for your site's privacy policy.

## Save

Click **Save configuration**. Changes apply to subsequent page views. Reload a
page that carries the Page Hits block to confirm the behavior.

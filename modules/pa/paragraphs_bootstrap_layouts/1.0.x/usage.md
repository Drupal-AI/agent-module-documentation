---

Paragraphs Bootstrap Layouts provides a Bootstrap-based layout system for paragraphs — letting editors
arrange paragraphs into Bootstrap grid layouts (rows/columns), with 12-column and 24-column grid submodules.
It builds on Classy Paragraphs and depends on the Paragraphs module. This suits Bootstrap-themed sites where
paragraphs should follow the Bootstrap grid.

Use it to build responsive Bootstrap grid layouts from paragraphs. It is a content-display/site-building
feature affecting how paragraphs are laid out; it emits Bootstrap grid classes/markup and has no
access-control role. Configure the layout on paragraph content.

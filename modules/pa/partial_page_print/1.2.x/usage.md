Partial Page Print Element allows a visitor to print part of a page rather than the whole page.

---

Partial Page Print Element lets a visitor print only part of a page — providing an element/button that
prints a designated region (an article body, a section) instead of the entire page, for cleaner printouts.
It requires PHP 8.1, in the User Interface package.

Use it to offer partial-page printing. It is a UI/display feature affecting what is sent to the browser's
print; the printed content is whatever region is designated (content the user can already see) and it has no
access-control role. Configure the printable region and the print element.

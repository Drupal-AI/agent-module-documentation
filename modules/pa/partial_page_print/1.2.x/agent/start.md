# Partial Page Print Element — agent index

Lets visitors **print a selected part of a page** (print a designated region — article body/section — vs the
whole page). Requires PHP 8.1. Version **1.2.0**. Core `^9.5||^10||^11`.

UI/display — prints content the user can already see; no access role.

Render Paragraphs fields as a Gantt chart.

---

Paragraphs Gantt renders paragraphs fields with a gantt chart — so a set of Paragraphs holding tasks (with start/end dates) is displayed as an interactive Gantt timeline, useful for project/schedule content. Depends on `paragraphs`; supports Drupal 8.8 through 12.

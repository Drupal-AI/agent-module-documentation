Page Attributes allows adding custom attributes to pages.

---

Page Attributes lets you **add custom attributes to nodes/pages** — attaching configurable attribute values
to content (usable in theming, body classes or metadata), per node/type. It depends on core Node.

Use it to attach custom attributes to content for theming. It is a theming/site-building feature; attribute
values are admin/editor-configured (keep them trusted where output as markup) and it has no content or access
role. Configure the page attributes.

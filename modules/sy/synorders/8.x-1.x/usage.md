SynOrders is a custom orders module in the SynapseF package.

---

SynOrders is a **vendor-specific (SynapseF) custom orders module** — part of a supplier's e-commerce suite
(paired with syncart/syncabinet), handling order processing in that vendor's context. Its public description is
minimal ("Custom synorders").

Use it only within the Synapse suite it belongs to. It is an e-commerce/custom module; because it is
vendor-specific and lightly documented publicly and it touches **orders** (money/fulfilment), **review its
actual behaviour in context** — especially order ownership, status transitions and any price/total handling —
before relying on it. It layers on the suite's own access; consult the vendor's documentation for
configuration.

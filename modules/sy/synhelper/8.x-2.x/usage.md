Synapse Helper provides helper functions and Drush commands (Synapse-helpers) for developers.

---

Synapse Helper (synhelper) is a developer utility providing helper functions and Drush commands — the
"Synapse-helpers" toolkit (from Synatix) that fills gaps and provides conveniences for developers working
on these projects. It depends on the `idna` library and is in the Synapse package; it provides Drush
commands.

Use it as a developer dependency/toolkit where its helpers/commands are needed. It is a developer utility;
it provides code and CLI helpers and has no content or access behaviour of its own. Its value is to
developers/modules building on it.

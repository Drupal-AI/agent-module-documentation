Synlang provides language-related field functionality.

---

Synlang provides language-related field functionality (from the Synatix module family) — a
language-oriented field/utility, providing Drush commands. As a vendor/utility module its features are
specific to that context; it depends on core Field.

Use it where the Synlang language field/utility is needed. It is a multilingual/fields utility; its behaviour
depends on the specific functionality it provides, and it has no documented access-control role. Configure as
required.

SynUsers is a custom users module in the SynapseF package.

---

SynUsers is a **vendor-specific custom users module** in the SynapseF package — part of a supplier's
Drupal suite for managing users in that vendor's context. Its public description is minimal ("Custom
synusers").

Use it only as part of the SynapseF/vendor stack it belongs to. It is a user-management/custom module; because
it is vendor-specific and lightly documented publicly, **review its actual behaviour in context** — especially
any user creation/roles/authentication paths — before relying on it. It has no documented general-purpose
access-control contract here. Consult the vendor's documentation for configuration.

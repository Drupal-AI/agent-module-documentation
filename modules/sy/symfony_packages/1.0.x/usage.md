Symfony Packages lists the installed Symfony components and their versions.

---

Symfony Packages displays all installed Symfony packages with version information — a diagnostic report showing which Symfony components (and versions) the Drupal installation uses, useful for debugging compatibility issues or auditing the Symfony dependency stack.

Viewing is gated by `view symfony packages`. It's a developer/diagnostic tool with no content role of its own. Requires Drupal 11.

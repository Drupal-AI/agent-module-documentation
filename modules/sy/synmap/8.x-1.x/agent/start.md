# SynMap — agent index

Provides a **small map block** using **Yandex or OpenStreetMap** (show a location compactly). Config at
`synmap.settings`. Version **8.x-1.29**. Core `^8||^9||^10||^11`.

Content-display/mapping — uses a map provider client-side (if Yandex: store any API key as a secret, mind
third-party script). No access role.

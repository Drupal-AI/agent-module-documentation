SynMap provides a small map (Yandex / OSM), displaying a simple map block.

---

SynMap provides a small map — displaying a simple map using Yandex Maps or OpenStreetMap (OSM), for
showing a location (an office, a point of interest) as a compact map. It is configured at `synmap.settings`
and is from the Synapse/Synatix family.

Use it to show a small location map. It uses a mapping provider (Yandex or OSM) client-side — if using
Yandex, note the third-party script/data-flow (and any API key should be stored as a secret and restricted).
It is a content-display/mapping feature with no access-control role. Configure the map provider and
location.

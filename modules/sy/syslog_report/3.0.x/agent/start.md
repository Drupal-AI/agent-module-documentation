# Syslog Report — agent index

**View the log records from syslog** in an admin UI. Depends on core `syslog`, `jquery_ui_accordion`. Provides
permissions. Version **3.0.1**. Core `^10||^11`.

Administration/logging — **log records can contain sensitive data** (gate the report strictly to trusted admins);
no content/access role beyond permission.

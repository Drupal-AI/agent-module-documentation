Entity Overlay displays a content entity as an overlay (modal) rather than a full page navigation.

---

Showing content in an overlay — a quick-view of a product, a detail popup — keeps the user in context. Entity Overlay displays a content entity as a modal overlay. It is a display/UX feature; the overlaid entity renders with its normal access, so the overlay does not bypass access (an entity the user cannot view will not render in the overlay either). Confirm the overlay's loading respects access and works with the entity's view modes.

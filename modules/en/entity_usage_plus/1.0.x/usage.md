Entity Usage Plus provides enhancements to the entity usage module.

---

Entity Usage Plus adds **enhancements to the Entity Usage module** — extending how entity-usage
relationships (which entities reference which) are tracked/displayed, improving the base module's usage
tracking. It depends on the Entity Usage module.

Use it to improve entity-usage tracking. It is a site-structure/data-integrity feature; it surfaces where
entities are used (which can reveal that referencing content exists) and follows Entity Usage's behaviour, and
it has no access-control role. Enable it alongside Entity Usage.

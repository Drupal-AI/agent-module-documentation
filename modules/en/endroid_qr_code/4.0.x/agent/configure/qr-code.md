# Endroid QR Code — configuration & formatter

## Site-wide settings

Form `QRCodeConfigurationForm` at route `endroid_qr_code.admin_settings`
(`/admin/config/endroid_qr_code`), gated by core `administer site configuration`. Values persist in
the `endroid_qr_code.settings` config object (schema `config/schema/endroid_qr_code.schema.yml`):

| Key | Type | Default | Notes / form constraints |
|---|---|---|---|
| `set_size` | int | 600 | QR size in px; form enforces 100–1000, required. |
| `set_margin` | int | 100 | Quiet-zone margin in px; form enforces 0–200, required. |
| `logo_file` | string (fid) | `''` | Optional center logo, `managed_file` uploaded to `public://`; on save the file is set permanent and its **fid** is stored. |
| `logo_width` | int | 50 | Logo width in px (max 1000). |
| `label` | string | `''` | Optional text label drawn under the QR code. |

These settings apply to **all** QR codes generated by the image routes (the anonymous routes read
the same config). Drush: `drush cget endroid_qr_code.settings`, `drush cset endroid_qr_code.settings set_size 400 -y`.

## Displaying a field as a QR code

Add or reuse a **string** or **link** field on your entity, then on *Manage display* set that
field's format to **"Endroid Qr Code"** (`endroid_qr_code_formatter`). At render, the formatter
(`EndroidQrCodeFormatter::viewElements`) emits an `#theme => 'image'` element whose `#uri` is a QR
route URL built from the field value (see [../api/endpoints.md](../api/endpoints.md)):

- Link fields use the `uri` value; string fields use `value`.
- If `UrlHelper::isValid($value)` → uses `endroid_qr_code.qr.url` with `?path=<value>`.
- Otherwise → uses `endroid_qr_code.qr.generator` with `{content}=<value>`.

No formatter settings exist beyond the summary line; sizing/logo/label come from the global config.

## Deprecated field type & widget (do not use for new fields)

- Field type `endroid_qr_code` (`EndroidQrCodeItem`, `no_ui = TRUE`) and widget
  `endroid_qr_code_widget` (`EndroidQrCodeWidget`, a 256-char textfield) are **@deprecated in 4.1.0,
  removed in 5.0.0** (issue 3580030). Migrate existing instances to a plain string/link field and
  apply the formatter above.

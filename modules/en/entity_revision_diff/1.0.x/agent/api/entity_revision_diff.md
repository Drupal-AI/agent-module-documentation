# Entity Revision Diff — routes, permissions & extension

## Supported entity types
`entity_revision_diff_supported_entity_types()` lists: `group`, `block_content`, `media`, `taxonomy_term` (node is intentionally excluded — Diff handles it). Each is wired only if the entity type actually exists and is revisionable.

## How routes are produced
- `hook_entity_type_alter()` attaches Diff 2.0's `DiffRouteProvider` as the `diff` route provider and sets `revisions-diff` + `revision` link templates.
- `EntityDiffRouteSubscriber` (priority -200, after Entity module) rewrites each `entity.{type}.version_history` route to use `EntityRevisionOverviewForm` (list + diff radio buttons).
- Static routes in `entity_revision_diff.routing.yml` define single-revision view (`entity.{type}.revision`) and `*_revision_revert_translation` forms for block_content/media/taxonomy_term.
- `GroupRouteProvider::routes()` adds the equivalent Group routes **only when the group module is installed**.

### Paths (per README)
| Entity | Version history | Diff comparison |
|--------|-----------------|-----------------|
| Block Content | `/admin/content/block/{id}/revisions` | `.../revisions/view/{left}/{right}` |
| Media | `/media/{id}/revisions` | `.../revisions/view/{left}/{right}` |
| Taxonomy Term | `/taxonomy/term/{id}/revisions` | `.../revisions/view/{left}/{right}` |
| Group | `/group/{id}/revisions` | `.../revisions/view/{left}/{right}` |

## Access control
Every route sets `_entity_access` — `{type}.view` for viewing a revision, `{type}.update` for revert. On top of that the module's permissions gate the operations:
- Global: `view|revert|delete all {type} revisions` (static for block_content/media/taxonomy_term; dynamic for group).
- Bundle-specific: `view|revert|delete {bundle} revisions` (generated by `EntityDiffPermissions::bundlePermissions()`).

## Views
`entity_revision_diff_views_data_alter()` adds an `entity_revision_diff_current_vid` field on each entity's `*_field_revision` table to expose the current revision ID.

## Extending to another entity type
Add the entity type + link templates to `entity_revision_diff_supported_entity_types()`; the alter hook, route subscriber and permission generator all iterate that list.

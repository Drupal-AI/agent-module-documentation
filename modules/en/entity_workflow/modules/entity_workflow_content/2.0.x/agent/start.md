# Entity Workflow Content (entity_workflow_content) — agent index

Submodule of **entity_workflow**. Provides the default **Content** workflow (Draft → Ready for Review
→ Approved) for workspace-supported content entities. Version-dir **2.0.x** (release `2.0.0-beta8`).
Core `^11.3 || ^12`. Depends on `drupal:workspaces_ui` and `entity_workflow:entity_workflow`
(`entity_workflow_content.info.yml`).

## What it provides (from source)

- **WorkflowType plugin** `entity_workflow_content` —
  `src/Plugin/WorkflowType/EntityWorkflowContent.php` (extends
  `Drupal\entity_workflow\WorkflowType\EntityWorkflowTypeBase`). `required_states` draft/review/approved;
  forms `configure` = `EntityWorkflowConfigureForm`, `transition` = `EntityWorkflowTransitionForm`.
- **Config**: installs `workflows.workflow.content` (`config/install/workflows.workflow.content.yml`);
  schema `config/schema/entity_workflow_content.schema.yml` adds `additional_access_callbacks` to
  transitions and `exclude_from_workspace_requirement` to type settings.
- **Permissions** (generated by the plugin's `getPermissions()`, exposed through the parent's
  permission callback): `use all content transitions` + `use content transition <id>` for each
  transition.
- **Access callback** `entity_workflow_content_transition_access()` (`entity_workflow_content.module`)
  — mandatory `hasPermission()` check, then muxes `additional_access_callbacks`
  (`entity_workflow_content_can_not_approve` for `approve_immediately`) via `orIf`.
- **Config alter** `hook_entity_workflow_type_alter()` fills default entity types (all
  workspace-supported types), default state/transition, and back-fills the access callback on every
  transition.
- **Cascade**: `EntityWorkflowContent::onPostTransition()` system-transitions the node's path aliases /
  menu links that the workspace tracks, and invalidates workspace cache tags.
- **Routing**: `Routing\RouteSubscriber` + `Routing\RouteEnhancer` require an active workspace for
  content operations and swap in `Controller\WorkspaceSwitcherController` (switcher / closed / locked)
  when there is no usable workspace. `hook_form_alter()` hides Views bulk operations on Live.
- `src/Hook/HookOrder.php` orders hook execution.

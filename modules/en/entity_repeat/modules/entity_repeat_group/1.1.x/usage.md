Entity Repeat Group adds each entity generated by Entity Repeat to the same Group (contrib Group module) that the original entity belongs to.

---

Entity Repeat Group is an optional submodule of Entity Repeat. On its own Entity Repeat clones a dated entity once per recurrence occurrence, but the clones are not placed in any Group. This submodule fills that gap: via `hook_form_alter()` on entity forms it records the entity's Group (from the add form) or its existing group relationship (on the edit form), and attaches a submit handler that, after generation, reads Entity Repeat's replication log (key/value `replications:{uuid}`) and adds every generated clone to that same group. It supports both the Group 2 API (`group_content` / `addContent()`) and the Group 3+ API (`group_relationship` / `addRelationship()`), choosing at runtime by checking whether the `group_relationship` entity type exists. It depends on `entity_repeat` and the contributed `group` module and has no configuration of its own.

---

- Keep recurring event instances inside the same Group as the original event.
- Ensure generated class/session clones inherit the parent's group membership.
- Preserve group-scoped access on every generated occurrence automatically.
- Repeat group content without manually re-adding each instance to the group.
- Support both Group 2 (group_content) and Group 3+ (group_relationship) sites.
- Attach clones created from a group *add* form to the group being added to.
- Attach clones created from an *edit* form to the group the original already belongs to.
- Maintain consistent group membership across a whole recurring series.
- Combine group-based access control with Entity Repeat's recurrence generation.
- Avoid orphaned recurring instances that sit outside their intended group.
- Automate roster/shift series that must stay within a team's group.
- Keep recurring publications in the correct editorial group.
- Mirror the original entity's group onto batches of generated content.
- Use with any Group-managed content type that also has a Date Recur field.
- Bridge Entity Repeat and Group without writing custom submit handlers.

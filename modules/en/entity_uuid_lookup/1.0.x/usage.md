---

Entity UUID Lookup **provides an admin form to look up an entity by UUID** — enter any entity's UUID and be
redirected to its canonical or edit URL, useful for debugging/support when you have a UUID but not the path. It
provides its own permissions, in the User interface package.

Use it to resolve UUIDs to entities. It is an administration/developer convenience; the redirect targets follow
normal entity access, and the lookup form should be gated to trusted admins via its permission. Enter a UUID to
jump to the entity.

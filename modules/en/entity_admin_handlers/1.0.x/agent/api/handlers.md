# Handler sets, routes, and how to opt an entity type in

Enable: `drush en entity_admin_handlers` (pulls in core `field_ui`). Nothing else installs — no config,
schema, permissions, services, block/plugin definitions, or `.routing.yml`. All routing is generated by
the route-provider classes when your entity type references them.

## Contract your entity type must satisfy

Both route providers run identical sanity checks in `getRoutes()` and throw
`UnsupportedEntityTypeDefinitionException` if any fail. The entity type must define:

- a `field-ui-base` **link template** (e.g. `/admin/structure/my-entity-type`);
- an `admin_permission` (via `getAdminPermission()`);
- the `field_ui_base_route` property set **exactly** to `entity.ENTITY_TYPE.field_ui_base`.

You reference the handlers from the entity type's annotation/attribute:

- `route_provider["html"]` → the set's `*HtmlRouteProvider` (replace the one Module Builder scaffolds).
- `link_provider` → the set's `*LinksProvider` (only with the core patch, issue 2976861).
- Without the patch, copy the YAML in the set's `links_templates/` folder into your module's
  `MODULE.links.menu.yml` / `MODULE.links.task.yml`, replacing `ENTITY_TYPE` with your id.

## Set 1 — SingleBundleEntity (`src/SingleBundleEntity/`)

For bundleless entity types (single implicit bundle, like core `user`).

- `SingleBundleEntityHtmlRouteProvider` extends core `AdminHtmlRouteProvider`. After
  `parent::getRoutes()`, `getFieldUIBaseRoute()` builds one route added as
  `entity.ENTITY_TYPE.field_ui_base` at the `field-ui-base` path. Route defaults:
  `_controller = SingleBundleAdminController::content`, a title `@entity-label field settings`, and
  `entity_type_id`. Requirement `_permission = getAdminPermission()`.
- `SingleBundleAdminController::content()` returns a `#markup` line ("@label entity settings.") — a
  placeholder page for Field UI to add tabs beside.
- `SingleBundleEntityLinksProvider` extends `DefaultContentEntityLinksProvider`; adds a menu link
  (parent `system.admin_structure`) and a `Settings` task link, both on the field_ui_base route, guarded
  by `routeExists()`.

## Set 2 — PlainBundleEntity (`src/PlainBundleEntity/`)

For multi-bundle types whose bundles come from code (hook_entity_bundle_info() or Entity API bundle
plugins), with **no** config bundle entity type.

- `PlainBundleHtmlRouteProvider` extends `AdminHtmlRouteProvider`, adds **two** routes:
  - `entity.ENTITY_TYPE.admin` — `getAdminBaseRoute()`, path = `field-ui-base`, controller
    `PlainBundleAdminController::adminPage` (bundle overview).
  - `entity.ENTITY_TYPE.field_ui_base` — `getFieldUIBaseRoute()`, path = `field-ui-base` + `/{bundle}`
    (the `{bundle}` name is required by `field_ui\Routing\RouteSubscriber::alterRoutes()`), controller
    `PlainBundleAdminController::bundlePage`.
  - Both routes set `_permission = getAdminPermission()` and default `entity_type_id`.
- `PlainBundleAdminController::adminPage()` renders a `#type => table` listing each bundle from
  `entity_type.bundle.info`: Name, Description, and an `#type => operations` block from
  `buildOperations()` linking to core Field UI routes `entity.ETID.field_ui_fields`,
  `entity.entity_form_display.ETID.default`, `entity.entity_view_display.ETID.default` (each per bundle).
  `bundlePage()` returns a `#markup` placeholder ("The @bundle-label bundle has no settings.").
- `PlainBundleLinksProvider` adds a menu link on the `.admin` route (parent `system.admin_structure`);
  deliberately provides **no** task link for the field_ui_base route (the route exists only for Field UI's
  assumptions; its page is dummy content, so it's intentionally unlinked in the UI).

## Notes

- The parent `AdminHtmlRouteProvider` still supplies core's standard entity routes; these handlers only
  add the field-ui-base wiring on top, using core's access model.
- `links_templates/MODULE.links.menu.yml` and `.task.yml` are templates to copy, not active plugin files.
- The `field-ui-base` link template's path is the base; the SingleBundle set uses it as-is, the
  PlainBundle set appends `/{bundle}` for the per-bundle route.

# Ordering interface — `EntityOrderForm`

`src/Form/EntityOrderForm.php`, `FormBase`, form id `entity_weight_order_form`. Route
`entity_weight.order` at `/admin/structure/entity-weight/{entity_type_id}/{bundle}/order`,
permission `assign entity weight`. Landing page `entity_weight.list`
(`/admin/structure/entity-weight`) lists the per-bundle links generated by the menu deriver.
Services injected via `create()`: `entity_type.manager`, `entity_type.bundle.info`, `language_manager`.

## Title
`title(RouteMatchInterface)` → "Order @type: @bundle" resolved from the entity type label and bundle
info.

## buildForm
1. Guards: returns an error markup element if `entity_type_id`/`bundle` are missing, or if the bundle
   is not present in `entity_weight.settings:enabled_bundles`.
2. Builds a **count query** via `$storage->getQuery()->accessCheck(TRUE)` filtered by the bundle key
   and current-language `langcode` key; when `include_unpublished` is FALSE it also filters on the
   `published` key. If the total is 0 it shows "No entities found."
3. Creates a pager (`pager.manager`, 50 items per page), then runs the main query with the same
   filters plus `->sort('field_entity_weight', 'ASC')` and `->range(page*50, 50)`.
4. Loads the entities, resolving the current-language translation when available, reads each weight
   from `field_entity_weight`, and builds a `#type => table` with `#tabledrag` (order/sibling on group
   `entity-weight-order-weight`). Each row: escaped label (`htmlspecialchars`), a `#type => weight`
   element (`#delta = max(abs(min), abs(max))`), and an operations column. The **View** op is added
   only when the entity has a canonical link **and** `$entity->access('view')`; **Edit** only when it
   has an edit-form link **and** `$entity->access('update')`.
5. Adds a "Showing @from-@to of @total" info line, a note that drag-and-drop applies only to the
   current page when `total > 50`, and a pager. To move an entity across pages, edit its weight value
   directly.

## submitForm & batch
`submitForm()` reads the submitted `entities` values and builds a batch (`batch_set`) with one
`batchUpdateWeight` operation per row. `batchUpdateWeight()` (static) loads the entity, switches to the
current-language translation when present, sets `field_entity_weight`, calls `setNewRevision(FALSE)`
when supported (so reordering does not spawn revisions), and saves. `batchFinished()` reports a status
or error message. The batch avoids memory exhaustion on large bundles.

## Notes
- CSRF is handled by the Form API (standard `FormBase` POST with form token); the mutation route is a
  POST form, not a state-changing GET.
- Listing uses `accessCheck(TRUE)`, so only entities the current user may access appear.

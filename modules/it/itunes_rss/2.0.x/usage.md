A Views RSS style plugin for iTunes/podcast feeds.

---

Itunes RSS provides a Views plugin to display an RSS feed for iTunes — a Views feed-style plugin that outputs an iTunes/Apple-Podcasts-compatible RSS feed (with the required `itunes:` namespace elements) from a View, so a site can publish a podcast feed. Depends on core `views`; supports Drupal 11.3+ and 12.

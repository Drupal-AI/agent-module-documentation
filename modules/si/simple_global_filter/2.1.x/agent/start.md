# Simple Global Filter — agent index

Sets a **site-wide global filter** (typically a taxonomy term) that persists across the session and that
blocks/Views can react to (filter content globally by region/category/brand). Depends on core `taxonomy`.
Version **2.1.4**. Core `^9.1||^10||^11`.

Content-display/filtering — shapes what's displayed, not access (restricted content still governed by its
own access).

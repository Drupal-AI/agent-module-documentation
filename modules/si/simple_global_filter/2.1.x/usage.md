Simple Global Filter lets you set global filters on the site in a simple way, typically based on taxonomy, that persist and affect displays.

---

Simple Global Filter lets site builders set a global filter on the site — a site-wide selection
(typically a taxonomy term) that persists across the visitor's session and that other components (blocks,
Views) can react to, so content can be filtered globally by a chosen dimension (region, category, brand). It
depends on core Taxonomy.

Use it to offer a persistent site-wide filter (e.g. "show content for region X"). It is a content-display/
filtering feature; the global filter shapes what is displayed, not access — restricted content is still
governed by its own access, and the filter is a presentation/selection layer. Configure the global filter
and how components use it.

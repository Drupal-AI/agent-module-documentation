# Smart Imaging Styles (sis) — agent index

Serves **layout-aware responsive images** — picks the image variant/size appropriate to the layout
context (not a single fixed style). Depends on core `responsive_image`, `system`. Config at
`sis.settings`. Version **2.2.0**. Core `^9||^10||^11`.

Media/performance feature (variant selection for display; no content/access role).

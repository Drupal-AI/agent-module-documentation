Smart Imaging Styles (sis) serves layout-aware responsive images, choosing image variants appropriate to the layout/context in which the image appears.

---

Smart Imaging Styles (sis) serves responsive images that are aware of the layout context — choosing
the appropriate image variant/size based on where and how the image is placed, rather than a single
fixed responsive image style. This helps deliver correctly-sized images across different layouts
(columns, grids, features) for better performance and appearance. It depends on core Responsive Image
and System, configured at `sis.settings`.

Use it on sites where the same image appears in multiple layout contexts and each needs a different
optimal size. It is a media/performance feature building on core responsive images; it governs image
variant selection for display, with no content or access role. Configure the layout-aware styles and
apply them to image displays.

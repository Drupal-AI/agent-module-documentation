Simple Taxonomy Menu is a simple version of taxonomy menu.

---

Simple Taxonomy Menu **generates and keeps a menu in sync with a taxonomy vocabulary** — creating menu
links for terms (and their hierarchy) so a vocabulary can drive site navigation, aiming to always stay
consistent with the vocabulary. It depends on core Taxonomy, in the Taxonomy package.

Use it to build navigation from a vocabulary. It is a site-structure/navigation feature; the generated menu
links follow normal menu/term access and it has no access-control role. Configure which vocabulary drives the
menu.

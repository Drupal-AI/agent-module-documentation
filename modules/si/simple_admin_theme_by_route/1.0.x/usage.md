Simple Admin Theme by Route allows using the admin theme on any route.

---

Simple Admin Theme by Route **applies the admin theme to chosen routes** — letting site builders use the
current administrative theme on any route (not just admin paths), for consistent admin-styled pages. It works on
core 10–11.

Use it to admin-theme specific routes. It is a theming feature; it selects the theme for matched routes and has no
content or access role. Configure which routes use the admin theme.

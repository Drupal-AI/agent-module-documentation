Simple XML Sitemap Extensions provides extensions for the Simple XML Sitemap module.

---

Simple XML Sitemap Extensions adds extra features to the Simple XML Sitemap module — extending its
sitemap generation (e.g. a `sse_dynamic_monthly` submodule for dynamic/monthly sitemap behaviour), for more
control over XML sitemaps. It depends on the Simple XML Sitemap module, in the SEO package.

Use it to extend Simple XML Sitemap. It is an SEO feature enhancing sitemap generation; sitemaps advertise
URLs, so (as with any sitemap) ensure only public content is included. It has no access-control role.
Configure the sitemap extensions.

# Simple XML Sitemap Extensions — agent index

Adds **extensions to the Simple XML Sitemap module** (extended sitemap generation — e.g. `sse_dynamic_monthly`
submodule). Depends on `simple_sitemap`. Version **2.0.0-beta5**. Core `^10||^11`.

SEO — enhances sitemap generation; sitemaps advertise URLs (include only public content). No access role.

Sites Simple Sitemap provides XML sitemaps for sites.

---

Sites Simple Sitemap **provides per-site XML sitemaps** — extending Simple XML Sitemap to generate/serve
distinct sitemaps per site (e.g. in a multi-site or domain setup), so each site surfaces its own URLs to search
engines. It depends on the Simple Sitemap module, in the Sites package.

Use it for per-site sitemaps in a multi-site setup. It is an SEO feature; sitemap contents follow the sitemap's
inclusion config (which respects access) and it has no access-control role. Configure the per-site sitemaps.

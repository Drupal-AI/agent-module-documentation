Simple Menu Tree provides an SDC component for a menu tree.

---

Simple Menu Tree provides an **SDC (Single Directory Component) for rendering a menu as a tree** — a
reusable component that outputs a menu's hierarchical structure, usable in templates/layouts. It is in the
Custom package.

Use it to render a menu tree component. It is a site-structure/theming feature; the menu follows normal menu
access and it has no access-control role. Use the component with a menu.

Simple Message sends private messages between users.

---

Simple Message provides **private messaging between users** — a lightweight way for site users to send
each other private messages, with a Views-based listing (and "show more" paging via `views_show_more`). It
depends on core Views and views_show_more, provides its own permissions, in the Simple message package.

Use it for basic user-to-user private messaging. It is a user-engagement feature. Security note: private
messages are **personal/private content** — its permissions gate who can send/read messages, so grant them
appropriately, and (as with any messaging) messages are visible to site administrators with database/permission
access. It has no other access-control role. Configure the messaging permissions.

# Simple Message — agent index

Lets users **send private messages to each other** (lightweight user-to-user messaging; Views listing +
`views_show_more`). Depends on core `views`, `views_show_more`. Provides permissions. Version **2.0.0**. Core
`^10||^11`.

User-engagement — messages are **private/personal content**; permissions gate send/read (grant carefully;
admins can access). No other access role.

Similar Reference uses Views to show similar entities based on a shared reference.

---

Similar Reference uses **Views to show similar entities based on a shared entity-reference field** — e.g.
"related articles" that reference the same term/entity as the current one, via a Views relationship/argument. It
depends on core Views.

Use it to build "similar/related" listings from shared references. It is a content-display/Views feature;
results respect the View's/entity's access and it has no access-control role. Configure the similar-reference
View.

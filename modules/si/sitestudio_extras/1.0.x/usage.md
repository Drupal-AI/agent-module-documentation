Site Studio Extras provides functionality to extend Site Studio features.

---

Site Studio Extras extends **Acquia Site Studio (Cohesion)** with additional features/helpers — filling
gaps in the low-code Site Studio builder for sites that use it. It depends on the Cohesion (Site Studio)
module.

Use it on Site Studio sites to add extra Site Studio functionality. It is a site-building feature layered on
Site Studio; Site Studio content/components follow Site Studio's own handling, and it has no access-control
role. Enable it alongside Site Studio.

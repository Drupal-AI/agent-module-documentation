Check XML-sitemap URLs and report HTTP status issues.

---

Sitemap URL Checker checks URLs listed in XML sitemaps and reports HTTP status issues such as 404 and 500 — so an administrator can audit the site's Simple XML Sitemap entries for broken/erroring URLs and fix them, keeping the sitemap clean for search engines. Depends on `simple_sitemap`; supports Drupal 10 and 11.

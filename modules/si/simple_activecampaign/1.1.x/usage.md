A block form to subscribe visitors to an ActiveCampaign list.

---

Simple ActiveCampaign provides a form in a block that allows visitors to subscribe to an ActiveCampaign newsletter list — so a site can collect newsletter sign-ups and push them to ActiveCampaign (email marketing / CRM) via its API.

The ActiveCampaign API credentials are admin-configured; store them securely (env-backed). Supports Drupal 10 and 11.

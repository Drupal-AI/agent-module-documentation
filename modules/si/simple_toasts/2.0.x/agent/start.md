# Simple Toasts — agent index

Displays Drupal **status messages as dismissible floating toasts** (vs default inline messages). Config at
`simple_toasts.settings`. Version **2.0.0-beta1**. Core `^9.0||^10||^11`.

Front-end/UI feature — affects message display only (no change to generated messages or access).

Simple Toasts displays status messages as dismissible floating notifications (toasts) instead of the default inline messages.

---

Simple Toasts renders Drupal's status/warning/error messages as dismissible floating "toast"
notifications — small pop-up notices (usually in a corner) that can be dismissed — instead of the default
inline messages block. This gives a more modern, less layout-disruptive way to show messages. It is
configured at `simple_toasts.settings` and is in the User interface package.

Use it to modernize message presentation. It is a front-end/UI feature affecting how messages display; it
does not change what messages are generated or any access behaviour. Configure toast appearance/position
and enable it.

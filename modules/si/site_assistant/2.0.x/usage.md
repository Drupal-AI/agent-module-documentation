Site Assistant builds guided assistant entities that shortcut users to helpful content.

---

Site Assistant lets you create site assistants — configurable guided helpers (assistant entities with library items and list entries) that give users a shortcut to the most helpful content or actions, improving onboarding and self-service on complex sites.

It exposes a set of CRUD permissions across assistant, library-item, and list-entry entity types plus `administer site_assistant` — grant editing/admin to trusted roles. Depends on `inline_entity_form`; supports Drupal 10.6+ and 11.

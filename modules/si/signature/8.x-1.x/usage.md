Signature enables user signature.

---

Signature enables a user signature — a field where users can store a signature (text/HTML), commonly
appended to their posts/comments, in the Field types package.

Use it to give users a signature field. It is a content-editing/fields feature; the signature is
**user-entered content** that is displayed, so — as with any user-provided HTML — ensure it is filtered
through a restricted text format (so a user can't inject scripts via their signature = stored XSS), and be
mindful signatures may contain personal data. It has no access-control role. Configure the signature field
and its text format.

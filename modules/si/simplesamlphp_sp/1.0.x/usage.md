SAML 2.0 Service Provider integration via SimpleSAMLphp.

---

SimpleSAMLphp SP provides SimpleSAMLphp Service Provider integration — letting Drupal act as a SAML 2.0 Service Provider so users authenticate against an external SAML Identity Provider (SSO), with account linking/provisioning on successful assertion.

SAML assertion signatures are validated by the SimpleSAMLphp library; configure the SP/IdP metadata and certificates carefully, and store any secrets securely. Depends on core `user`; supports Drupal 11.3.

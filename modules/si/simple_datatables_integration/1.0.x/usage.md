Simple Datatables Integration integrates the simple-datatables library with Drupal, adding interactive sortable/searchable tables.

---

Simple Datatables Integration integrates the `simple-datatables` JavaScript library with Drupal —
turning tables into interactive tables with client-side sorting, searching and pagination, a lightweight
alternative to heavier DataTables libraries. It is in the Integrations package.

Use it to make tables interactive (sort/search/paginate client-side). It is a content-display/UI
integration adding front-end table behaviour; the table data comes from the page and it has no access-control
role. Note client-side features (search/sort) operate on data already sent to the browser — they are a
display convenience, not a way to restrict which rows a user can see. Enable and attach the library to the
target tables.

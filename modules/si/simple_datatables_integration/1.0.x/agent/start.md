# Simple Datatables Integration — agent index

Integrates the **simple-datatables** JS library (interactive client-side sort/search/pagination for tables —
lightweight DataTables alternative). Version **1.0.4-rc1**. Core `^10||^11`.

Content-display/UI — client-side features operate on data **already sent to the browser** (display
convenience, not row-level access). No access role.

# Simple WT Metatags — agent index

A **UI to configure fields used as meta description / meta tags** for SEO (lightweight, no full Metatag module).
Provides permissions. Version **1.1.5**. Core `^11.2`.

SEO — meta values reflect on-page content; no access role beyond permission.

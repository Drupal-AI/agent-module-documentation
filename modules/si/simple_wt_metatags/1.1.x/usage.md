Simple WT Metatags provides a UI to configure fields for meta data.

---

Simple WT Metatags provides a **UI to configure which fields supply meta data** (meta description and
related tags) for SEO — a lightweight way to map content fields to meta tags without the full Metatag module. It
provides its own permissions, in the SEO package (core 11.2+).

Use it for lightweight SEO meta-tag configuration. It is an SEO feature; meta values reflect on-page content and
it has no access-control role beyond its permission. Configure the field-to-metatag mapping.

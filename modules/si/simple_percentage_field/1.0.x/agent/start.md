# Simple Percentage Field — agent index

Provides a **`simple_percentage` field type** with widget (`SimplePercentageDefaultWidget`), formatter (`SimplePercentageDefaultFormatter`) and a `simple_percentage` theme; formatter supports prefix/suffix, position, absolute value and min/max. Depends on core `field`. Version **1.0.3**, core 8–10.

Pure field module: no routes, no permissions, no external calls.

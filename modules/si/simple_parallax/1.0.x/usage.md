Add parallax scroll animations to images.

---

Simple Parallax JS is a JavaScript-based library that adds parallax animations to images — so images move at a different speed than the page as the visitor scrolls, creating a depth/parallax effect, with minimal configuration. Supports Drupal 10.3+, 11, and 12.

Simple Sitemap Page Manager integrates Simple XML Sitemap with Page Manager.

---

Simple Sitemap Page Manager **integrates Simple XML Sitemap with Page Manager** — letting Page Manager
(Panels) pages be included in the XML sitemap with their own sitemap settings, so custom-routed pages aren't
missed by search engines. It depends on Panels and Simple Sitemap, in the SEO package.

Use it to add Page Manager pages to your sitemap. It is an SEO feature; sitemap inclusion is admin-configured and
it has no content or access role. Configure sitemap settings for Page Manager pages.

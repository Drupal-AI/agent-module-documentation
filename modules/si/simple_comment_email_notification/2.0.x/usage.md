Simple Comment eMail Notification notifies the site administrator by email when new comments are posted.

---

Simple Comment eMail Notification sends the site administrator an email when a new comment is posted —
so admins/moderators are alerted to new comments (for moderation or awareness) without checking the site. It
is in the Comments package.

Use it to get notified of new comments. It is a user-engagement/notification feature; it sends
notifications to the admin and has no content or access role. Note the notification includes comment content
(user input) — as with any email of user content, be aware it's forwarding user-submitted data to the admin.
Configure the notification.

Anonymize the unique site key sent by the core Update module.

---

Site Key Mutator anonymizes the deployment-unique site key transferred by the Drupal core Update module — so the identifier Drupal sends to drupal.org during update checks (which can fingerprint/track a specific deployment) is replaced with an anonymized value, improving deployment privacy. Depends on core `update`; supports Drupal 10.3+ and 11.

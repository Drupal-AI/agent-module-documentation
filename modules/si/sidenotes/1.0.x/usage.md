Sidenotes adds responsive Tufte-style sidenotes to content.

---

Sidenotes **adds Tufte-style sidenotes** — responsive margin/sidenotes (with optional numbering and placement,
and a mobile fallback) for richly-annotated long-form content, in the style of Edward Tufte. It is in the Content
package.

Use it for margin notes on articles. It is a content-display/theming feature; sidenote content is authored content
rendered alongside the main text and it has no access-control role. Configure the sidenotes.

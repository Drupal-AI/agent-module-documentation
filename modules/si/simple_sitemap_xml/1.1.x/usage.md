Simple Sitemap XML generates sitemap.xml from content types or menus with customizable priorities, exclusions and filtering.

---

Simple Sitemap XML generates an XML sitemap (`sitemap.xml`) from content types or menus — with
customizable per-item priorities, exclusions and filtering — so search engines can discover the site's URLs.
It depends on core Menu Link Content, is configured at `simple_sitemap_xml.settings`, in the SEO package.

Use it to publish an XML sitemap for SEO. It is an SEO feature listing URLs for crawlers. The one thing to
keep in mind: a sitemap **advertises URLs**, so ensure only content that should be public is included (use
the exclusions/filtering to keep unpublished/private/admin URLs out) — the sitemap doesn't grant access, but
listing a URL invites crawling. It has no access-control role. Configure which content/menus are included
and their priorities.

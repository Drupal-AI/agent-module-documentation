# Simple Sitemap XML — agent index

Generates **sitemap.xml from content types or menus** (customizable priorities/exclusions/filtering — URL
discovery for search engines). Depends on core `menu_link_content`. Config at `simple_sitemap_xml.settings`.
Version **1.1.0**. Core `^9||^10||^11`.

SEO — a sitemap **advertises URLs**; use exclusions/filtering to include only public content (keep private/
admin URLs out). Doesn't grant access; no access role.

Turn any entity into a site with a dedicated domain.

---

Sites allows making everything a site with a dedicated domain — mapping entities to their own domains so a single Drupal install can serve multiple domain-scoped 'sites' (e.g. per-group or per-brand microsites) from shared content and configuration. Supports Drupal 10.3+ and 11.

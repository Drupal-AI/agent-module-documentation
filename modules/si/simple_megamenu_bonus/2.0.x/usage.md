Simple megamenu bonus provides enhancements/extra features for the Simple Megamenu module.

---

Simple megamenu bonus provides additional features and enhancements for the Simple Megamenu module —
extending its mega-menu building capabilities (extra options, display tweaks) beyond the base module. It
depends on the Simple Megamenu module.

Use it on sites using Simple Megamenu that want its extra features. It is a site-structure/navigation
enhancement layered on Simple Megamenu; it affects mega-menu building and display, not access. Enable it
alongside Simple Megamenu and use the added options.

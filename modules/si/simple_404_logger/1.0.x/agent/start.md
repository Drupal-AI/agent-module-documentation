# Simple 404 Logger — agent index

**Logs 404 (page not found) requests and provides an admin report**. Depends on core `system`. Version **1.0.0**.
Core `^10||^11`.

SEO/maintenance — 404 logs record **requested URLs (possibly referrers/IPs = personal data)** and grow under
scanning: minimize/prune, gate the report. No access role.

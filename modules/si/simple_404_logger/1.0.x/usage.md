Simple 404 Logger logs 404 (page not found) requests and provides an admin report.

---

Simple 404 Logger **logs 404 requests** — recording page-not-found requests and surfacing them in an admin
report, so you can find broken links/missing pages to fix or redirect (SEO). It depends on core System.

Use it to track 404s. It is an SEO/maintenance feature. Privacy/robustness note: 404 logs record **requested URLs
(and possibly referrers/IPs)** — these can include personal data and can grow large under scanning/attack, so
minimize what's stored, prune old entries, and gate the report to trusted users. It has no access-control role.
Configure 404 logging.

# Signature pad — agent index

File/image **widget to draw a signature** (or image) on a canvas, saved as an image file (consent/
acknowledgement capture). Depends on core `image`. Version **1.0.3**. Core `^10||^11`.

**Note:** captures an *image of a drawing* — not a cryptographically-verifiable e-signature; use for
lightweight consent, not legally-binding digital signatures. Configure on the image field.

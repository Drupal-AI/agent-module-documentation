Signature pad provides a file widget where users draw a signature (or image) on a canvas, saved as an image file.

---

Signature pad provides a field widget that lets users draw on a canvas — capturing a hand-drawn
signature (or simple image) and saving it as an image file on the entity. It is used for e-signature-style
capture on forms (agreements, consent, delivery confirmation). It depends on core Image and is in the
Fields package.

Use it where a drawn signature/image needs to be captured and stored as a file. It is a fields/form-widget
feature producing an image file; the drawn image is user-supplied content stored as a managed file. Note
that a drawn "signature" captured this way is not a cryptographically-verifiable e-signature — it is an
image of a drawing, appropriate for lightweight consent/acknowledgement, not for legally-binding digital
signatures (which need a proper e-signature service). Configure the widget on the image field.

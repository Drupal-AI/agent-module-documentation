Node Title PS adds a configurable static prefix and/or suffix to node titles.

---

Node Title Prefix/Suffix (node_title_ps) **adds a configurable static prefix and/or suffix to node titles**
on display — e.g. prepend a category label or append a site tag to titles per content type, with a
`taxonomy_term_title_ps` submodule for terms. It depends on core Node.

Use it to decorate titles consistently. It is a content-display feature affecting title rendering; the prefix/
suffix is admin-configured and it has no content or access role. Configure the prefix/suffix per type.

Node RSS provides an RSS feed render path for the node.

---

Node RSS provides an **RSS-feed render path for a node** — so a node (e.g. a blog or listing node) can be
output as an RSS feed at its own path, for syndication. It depends on core Node and Path Alias, provides its
own permissions.

Use it to expose node content as an RSS feed. It is a content-display/syndication feature; the feed lists
content following normal node access (published/accessible only) and it has no access-control role beyond its
permission. Configure the RSS feed path.

# Node RSS — agent index

Provides an **RSS-feed render path for a node** (output a node as an RSS feed for syndication). Depends on core
`node`, `path_alias`. Provides permissions. Version **1.0.1**. Core `^9||^10||^11`.

Content-display/syndication — feed lists content following normal node access (published/accessible only); no
access role beyond permission.

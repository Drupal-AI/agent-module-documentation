# Node Menus — agent index

Lets you configure **which menus are available for placing nodes** (select exactly which menus editors may
add nodes to, vs core's fixed allowed set). Depends on core `content_translation`. Version **3.0.x** (dev).
Core `^10|^11`.

Site-structure/content-editing — affects node menu-placement options, not access. No access role.

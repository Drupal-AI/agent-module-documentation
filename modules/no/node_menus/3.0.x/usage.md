Node Menus allows selecting menus that are available for nodes.

---

Node Menus lets you configure which menus are available when placing a node in a menu — so instead of
core's fixed set of allowed menus per content type, you can select exactly which menus editors may add nodes
to. It depends on core Content Translation.

Use it to control which menus nodes can be placed in. It is a site-structure/content-editing feature
affecting the node menu-placement options; it does not change access and has no access-control role. Configure
the available menus per content type.

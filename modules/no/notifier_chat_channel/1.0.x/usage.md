A Chatter channel for the Symfony Notifier integration.

---

Notifier Chat Channel provides the Chatter Channel for Symfony Notifier — so Drupal's Notifier integration can deliver notifications to chat services (Slack, Discord, Telegram, etc. via Symfony's Chatter transports). Depends on `notifier`; supports Drupal 10.3+.

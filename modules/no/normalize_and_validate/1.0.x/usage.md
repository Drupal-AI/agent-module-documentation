Normalize and Validate provides reusable helpers for normalizing and validating data.

---

Normalize and Validate is a general helper module providing reusable routines to normalize (clean/standardize) and validate data — used by other modules/custom code to enforce consistent, valid input without reimplementing the same logic. It's developer infrastructure.

It's a developer library with no content or access role of its own. Supports Drupal 9, 10, and 11.

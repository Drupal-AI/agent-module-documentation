Adds visibility condition plugins based on nodes.

---

Node Visibility adds visibility condition plugins to nodes — so blocks (and other things using condition plugins) can be shown/hidden based on node-related criteria (e.g. specific nodes, node fields), giving finer control over where content appears. Depends on core `node`; supports Drupal 8 through 11.

# Node Change Default Language — agent index

**Allows changing the default/source language of nodes via the UI**. Depends on core `node`, `language`,
`content_translation`. Provides permissions. Version **1.1.2**. Core `^10||^11`.

Multilingual/content-editing — changes translation metadata (affects relationships; do deliberately); no access
role beyond permission.

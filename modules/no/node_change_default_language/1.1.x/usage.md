Node Change Default Language allows changing a node's default/source language via the UI.

---

Node Change Default Language **lets editors change a node's default/source language** — providing a UI to
switch which language is the source/original for a translated node, useful when content was created in the wrong
language. It depends on core Node, Language and Content Translation, and provides its own permissions.

Use it to correct a node's source language. It is a multilingual/content-editing feature; it changes translation
metadata and has no access-control role beyond its permission. Note: changing the source language affects
translation relationships — do it deliberately. Configure/permission the feature.

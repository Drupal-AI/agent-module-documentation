# Nodeinfo(2) — agent index

Exposes **NodeInfo / NodeInfo2** server-metadata endpoints (software/version, protocols, usage stats)
for **fediverse** instance discovery. Version **1.0.1**. Core `^10||^11`.

**Discloses server metadata publicly** (version disclosure can aid fingerprinting) — publish only what
you're comfortable revealing. Integration/protocol feature (no access role beyond the public
document).

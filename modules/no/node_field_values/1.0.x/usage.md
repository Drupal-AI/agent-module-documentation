Node Values provides a helper to get field values from a node.

---

Node Values (node_field_values) **provides a helper to get a node's field values** — a small developer utility
to read/extract field values from a node programmatically or in templates. It works across core 9–11.

Use it as a developer convenience for reading node fields. It is a developer/utility feature; it reads field values
(respecting normal field access when used correctly) and has no access-control role. Use its helper in code/
templates.

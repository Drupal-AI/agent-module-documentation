# Node Swapper — agent index

**Swaps an old node for a new one, preserving aliases and redirects**. Depends on `redirect`, `pathauto`. Provides
permissions. Version **1.3.0**. Core `^10||^11||^12`.

Content-administration — a privileged swap (moves aliases + creates redirects); restrict the permission to trusted
editors. No broader access role.

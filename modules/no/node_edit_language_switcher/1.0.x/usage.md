Node Edit Language Switcher lets editors switch between a node's translations while editing.

---

Node Edit Language Switcher provides a custom feature to easily switch and add content for a node entity across all of its languages from the node edit form — so editors can move between translations (or create new ones) without leaving the edit screen, streamlining multilingual editing.

It's an editorial-UX enhancement with no content or access role of its own (translation access still follows core). Supports Drupal 8 through 11.

# No Table Drag — agent index

Allows **disabling the tabledrag (drag-and-drop reorder) UI** on certain multi-value field widgets
(where drag handles are unnecessary/confusing, or for touch). Version **2.0.0**. Core `^9||^10||^11`.

Form/UI feature — affects the widget's reordering control; no data/access change. Configure on the
field widgets.

No Table Drag allows table drag (drag-and-drop reordering) to be disabled on certain field widgets.

---

No Table Drag lets site builders disable the tabledrag (drag-and-drop row reordering) interface on
certain multi-value field widgets — useful where the drag handles are unnecessary, confusing, or
interfere with the editing experience (or on touch devices where dragging is awkward). It is in the User
interface package.

Use it to simplify multi-value field editing by removing drag reordering where order doesn't matter or
should be controlled another way. It is a form/UI feature affecting the widget's reordering control; it
does not change data or access. Configure it on the relevant field widgets' display.

Serve a NIP-05 DNS-based identifier mapping names to Nostr keys.

---

Nostr internet identifier NIP-05 lets you add your Nostr keys for a DNS-based internet identifier (NIP-05) — the site serves the standard `/.well-known/nostr.json` mapping `name@domain` handles to Nostr public keys, so Nostr clients can verify that a handle belongs to this domain.

The `/.well-known/nostr.json` endpoint is public by design (it publishes public keys only). Supports Drupal 10 and 11.

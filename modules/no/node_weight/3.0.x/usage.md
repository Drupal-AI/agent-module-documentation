Node Weight adds an integer `field_node_weight` field to chosen content types and a drag-and-drop "Manage order" screen so editors can manually order nodes, with the weight available as a Views sort criterion.

---

Enable Node Weight per content type from the settings form at `/admin/config/node-weight` (route `node_weight.form`, the module's `configure` target) or from the node-type edit form's "Node weight settings" section. When a type is enabled, the module creates a `FieldConfig` for the shared, locked `field_node_weight` storage (integer, cardinality 1, min/max from settings) on that bundle and sets its form widget to the module's `weight_selector` widget (a select of the min..max range). A per-type ordering UI lives at `/admin/structure/types/manage/{node_type}/order` (route `node_weight.order`, `NodeOrderForm`): it lists that type's nodes in a `#tabledrag` table sorted by weight, with an enabled/status checkbox and edit/delete operations per row; saving runs a batch that writes each node's weight (and status) **without creating a new revision**. Menu links to each enabled type's order screen are generated by a derivative (`NodeWeightMenuLink`), and an entity-operation link "Manage order" is added on the content-types list for users with `assign node weight`. Global settings are stored in `node_weight.settings`: `checked_node_types` (enabled types), `min_weight`/`max_weight` (default -10/10, validated min<max), and `include_unpublished` (whether the order screen lists unpublished nodes). Two permissions gate it — `administer node weight` (settings) and `assign node weight` (ordering). Depends only on core `node`; sort your content by adding `field_node_weight` as a Views sort criterion.

---

- Let editors manually drag-and-drop the order of nodes within a content type.
- Add a weight field to Article, Page, or any chosen content type.
- Order a "Featured" or "Staff" content type for a custom homepage listing.
- Use `field_node_weight` as a Views sort criterion to control listing order.
- Set a min/max range for allowed weights (default -10 to 10).
- Enable node weighting only for specific content types via the settings form.
- Reorder nodes without editing each node individually.
- Include or exclude unpublished nodes from the ordering screen.
- Toggle a node's published status directly from the Manage order table.
- Provide a curated ordering for landing-page or promotional content.
- Sort menu/teaser lists by an editor-controlled weight instead of date.
- Batch-reorder large content sets (processed 25 nodes per batch run).
- Reorder content per language (the order screen operates on the current language's nodes).
- Set a node's weight inline on its edit form via the weight selector widget.
- Give a marketing role the `assign node weight` permission to manage order without full admin.
- Add a "Manage order" tab to a content type's edit screen.
- Keep node ordering changes revision-free (weights saved without new revisions).
- Order case studies, testimonials, or product highlights for a Views block.
- Establish a stable manual sort for a slideshow or carousel source list.
- Remove weighting from a type later, which deletes that type's weight field.

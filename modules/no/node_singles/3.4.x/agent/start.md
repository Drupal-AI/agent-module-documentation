# Node Singles — agent index

Provides **"single" node types** — content types intended for a **single one-off page each** (Home/About/
Contact) with unique fields, managed as singletons. Requires PHP 7.1; depends on core `node`; provides
permissions. Version **3.4.7**. Core `^8.8||^9||^10||^11`.

Site-structure/content — single nodes governed by node access + the module's permissions. Configure
single types + fields.

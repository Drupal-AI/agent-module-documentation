List and manage nodes with a restorable trash bin and duplicate detection.

---

Node Cleanup lets you list and manage nodes by content type and status, with a restorable trash bin (with scheduled auto-purge) and duplicate-content detection — so admins can bulk-review content, soft-delete to a recoverable trash (auto-purged on a schedule), and find duplicate nodes to clean up. Depends on core `node`; supports Drupal 10.3+ and 11.

Free automatic translation via a Node.js translation service.

---

Node.js Translate provides free automatic translation — using a Node.js-based (unofficial Google) translation service to auto-translate content/strings without a paid API key.

Because it relies on an unofficial free translation endpoint, review translation quality and reliability, and don't send sensitive content. Depends on core `language`; supports Drupal 8.8 through 12.

---

Node XML Sitemap provides a node-based XML sitemap — generating XML sitemap entries for nodes, built on
the XML Sitemap module. It focuses the sitemap on node content, useful where you want a straightforward
node-driven sitemap for search engines. It depends on `xmlsitemap` and is configured at
`node_xml_sitemap.form`.

Use it to publish an XML sitemap of node content for SEO. It is an SEO feature generating a sitemap; the
sitemap should include only content that is public/indexable (respect published/access state), and it has
no access-control role. Configure which nodes are included.

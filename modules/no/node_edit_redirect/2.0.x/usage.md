Node Edit Redirect ensures the node edit form redirects correctly.

---

Node Edit Redirect **ensures the node edit form redirects to the correct destination after save** — notably
handling multilingual cases so an editor lands on the right (translated) node rather than a wrong language/page.
It is in the Multilingual - Internationalization package.

Use it to fix post-edit redirects on multilingual sites. It is a content-editing/multilingual UX feature
affecting the redirect after save; it has no content or access role. Enable it to correct edit redirects.

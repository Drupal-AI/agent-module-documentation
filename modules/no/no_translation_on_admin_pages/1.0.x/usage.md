Disable Google translation on admin pages.

---

No Translation on Admin Pages disables Google translation on admin pages — so the browser's/Google's automatic page translation doesn't run on `/admin` pages (where machine-translating the UI can garble commands and confuse admins), keeping the admin interface in its intended language. Supports Drupal 9, 10, and 11.

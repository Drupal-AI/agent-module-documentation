Node Type Defaults customizes default values for new nodes.

---

Node Type Defaults **customizes the default values for new nodes** — pre-filling fields (and menu settings)
with configured defaults when creating content of a given type, to speed up authoring and enforce conventions.
It depends on core Menu Link Content and Node.

Use it to set per-type creation defaults. It is a content-editing/site-building feature affecting the node
create form; defaults are admin-configured and it has no content or access role. Configure the defaults per
content type.

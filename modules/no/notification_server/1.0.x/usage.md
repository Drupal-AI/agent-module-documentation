Real-time notifications over HTTP and WebSocket.

---

Notification Server provides real-time notification capabilities through both HTTP and WebSocket protocols — so Drupal can push live notifications to connected clients (browsers/apps) via WebSocket, with an HTTP fallback, for activity feeds, alerts and dashboards.

It requires a companion WebSocket server process; secure the connection and authenticate clients appropriately. Supports Drupal 10 and 11.

Notifybar provides a notification bar block message.

---

Notifybar displays a **site-wide notification bar** — a dismissible announcement banner (message) shown via
a block, for site-wide notices (maintenance, promotions, alerts). It depends on core Block.

Use it to show a site-wide notice. It is a content-display/user-engagement feature; the message is
admin-configured and it has no content or access role. Configure the notification bar message and placement.

# Node Menu Placer — agent index

Speeds up **positioning a node in the menu** on node edit forms — replaces the parent-link dropdown (loads
whole menu tree; slow) with **placement buttons**. Depends on `menu_link_weight`. Config at
`node_menu_placer.config`. Version **2.0.6**. Core `^10||^11`.

Content-editing/navigation UI — respects existing menu permissions; no access role.

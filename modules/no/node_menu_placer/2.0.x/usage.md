Node Menu Placer improves performance and speed of positioning a node in the menu structure on node edit pages, replacing the parent link field with buttons.

---

Node Menu Placer improves the node menu-placement experience on node edit forms — replacing the default
"Parent link" dropdown (which loads the entire menu tree, slow on large menus) with buttons to place the
node within potential parents, improving performance and ease of positioning. It depends on Menu Link
Weight and is configured at `node_menu_placer.config`.

Use it on sites with large menus where the default parent selector is slow/unwieldy. It is a content-
editing/navigation UI feature affecting menu-placement UX; it respects existing menu permissions and has no
access-control role. Configure the placement behaviour.

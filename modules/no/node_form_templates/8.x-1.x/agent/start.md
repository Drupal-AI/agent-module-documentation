# Node Form Templates — agent index

Lets you create **templates with prefilled field values for node forms** (start a new node from a boilerplate
that pre-populates fields). Config at `node_form_templates.settings_form`; provides permissions. Version
**8.x-1.7**. Core `^8||^9||^10||^11`.

Content-editing/workflow — prefills the node form; created node still goes through normal validation/access.
No access role beyond permission.

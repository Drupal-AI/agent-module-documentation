Node Form Templates lets you create templates with prefilled fields for node forms.

---

Node Form Templates lets you define templates of prefilled field values for node creation — so editors
can start a new node from a template that pre-populates fields (a boilerplate/starter), speeding up creating
similar content. It is configured at `node_form_templates.settings_form` and provides its own permissions.

Use it to give editors starter templates for node forms. It is a content-editing/workflow feature that
prefills the node form; the created node still goes through normal validation and access, and it has no
access-control role beyond its permission. Configure the templates.

Vocabulary Clone clones a vocabulary and its terms.

---

Vocabulary Clone **clones a taxonomy vocabulary and its terms** — duplicating a vocabulary (its settings
and all its terms, including hierarchy) into a new vocabulary, saving manual re-creation when you need a
similar taxonomy. It depends on core Taxonomy, in the Taxonomy package.

Use it to duplicate a vocabulary. It is a site-structure/administration feature run by admins; cloning creates
new terms (governed by normal taxonomy access) and it has no access-control role. Run the clone on a
vocabulary.

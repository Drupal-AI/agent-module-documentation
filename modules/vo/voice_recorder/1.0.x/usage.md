Voice Recorder provides a field widget for in-browser voice recording, saving the recording as an audio file.

---

Voice Recorder provides a field widget that records audio directly in the browser (using the
microphone) and saves the recording as an audio file on the entity — for voice notes, audio submissions,
or spoken feedback without a separate recording tool. It depends on core File.

Use it where users should record audio inline on a form. It is a fields/form-widget feature producing an
audio file; the recording is user-supplied content stored as a managed file. Privacy note: it captures
microphone audio, so the browser will prompt for microphone permission, and you should disclose that audio
is recorded and handle the resulting audio (which may contain personal/voice data) with appropriate
consent and access control. Configure the widget on a file/audio field.

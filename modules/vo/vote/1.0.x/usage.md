Vote provides a voting widget for content entities.

---

Vote provides a **voting widget for content entities** — letting users vote/rate entities using the Voting
API, as part of the RulesFinder toolset. It depends on the Voting API module, provides its own permissions, in
the RulesFinder package.

Use it to add voting/rating to entities. It is a user-engagement feature. Note: like any user voting, guard
against abuse (repeat/bot votes) — Voting API tracks votes per user/session; anonymous votes are weaker
(spoofable). It has no access-control role beyond its permission. Configure the voting widget.

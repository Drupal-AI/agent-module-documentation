# Vote (RulesFinder) — agent index

A **voting widget for content entities** (built on Voting API; part of the RulesFinder toolset). Depends on
`votingapi`. Provides permissions. Version **1.0.x**. Core `^10.3||^11`.

User-engagement — guard against vote abuse; anonymous votes spoofable. No access role beyond permission.

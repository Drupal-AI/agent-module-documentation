Wires a decoupled JavaScript front end (the DKAN React app) to the Drupal back end, providing the routing that lets client-side pages be served under Drupal's control while consuming the metastore and datastore APIs. It is the seam between DKAN's data APIs and a modern single-page catalog UI.

---

- Serve a decoupled DKAN front end.
- Route client-side pages through Drupal.
- Connect the React app to DKAN APIs.
- Back a single-page catalog UI.
- Consume the metastore API from JS.
- Consume the datastore API from JS.
- Keep front-end routing under Drupal.
- Serve a modern dataset browser.
- Bridge decoupled UI and Drupal auth.
- Deploy the DKAN React frontend.
- Handle client-side deep links.
- Pair with metastore search.
- Render dataset pages client-side.
- Fall back to Drupal routing where needed.
- Support a headless portal architecture.
- Integrate a custom JS catalog UI.

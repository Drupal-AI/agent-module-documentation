Provides search over dataset metadata, so the catalog is findable by keyword rather than only browsable. Together with facets it is the discovery layer of the portal, and it is a base DKAN dependency.

---

- Search dataset metadata by keyword.
- Find a dataset by title.
- Find datasets by description text.
- Back a catalog search box.
- Rank datasets by relevance.
- Combine search with facets.
- Index dataset metadata.
- Expose search to the front end.
- Make the catalog findable.
- Ship with the base DKAN install.
- Support full-text dataset search.
- Return search results via the API.
- Discover datasets across themes.
- Improve open-data findability.
- Feed a search UI.
- Re-index after metadata changes.

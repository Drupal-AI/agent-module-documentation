Adds faceted filtering to the dataset catalog, so users can narrow by theme, publisher, format and other metadata fields. It is the browse experience of an open-data portal — the difference between a flat list and a navigable catalog.

- Improve dataset discovery.

- Expose facets to the front end.
- Make a big catalog navigable.
- Filter by license.
- Filter by tag.
- Support catalog exploration.
- Back a faceted browse UI.
- Refine results interactively.

Provides the form widget for authoring a data dictionary — the column definitions, types and descriptions — for a dataset's tabular resource, so consumers know what each field in the datastore means. A required dependency of the base DKAN install.

---

- Define a data dictionary for a resource.
- Describe each datastore column.
- Set column types and formats.
- Document field meanings for consumers.
- Edit a dictionary in the dataset form.
- Improve datastore discoverability.
- Validate data against the dictionary.
- Attach a dictionary to a resource.
- Ship with the base DKAN install.
- Help API consumers interpret columns.
- Standardise column metadata.
- Expose the dictionary via the API.
- Author dictionaries in the admin UI.
- Keep column semantics with the dataset.
- Support data-quality workflows.
- Render dictionary details on a dataset page.

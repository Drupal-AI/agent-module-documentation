Ships sample datasets for tests and demos. It is a convenience for standing up a DKAN instance quickly or exercising the pipeline in automated tests — not something to enable on a production portal, where it would add fixture data to a real catalog.

---

- Stand up a DKAN demo quickly.
- Populate a portal with sample datasets.
- Exercise the pipeline in tests.
- Demo the datastore with real rows.
- Show the catalog UI with content.
- Seed a development environment.
- Provide fixtures for kernel tests.
- Preview harvest and metastore features.
- Avoid enabling on production.
- Remove after evaluating DKAN.
- Test import against known data.
- Demonstrate search and facets.
- Give a new install visible content.
- Validate a deployment end-to-end.
- Train editors on realistic examples.
- Bootstrap a proof-of-concept portal.

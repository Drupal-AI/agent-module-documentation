# dkan_harvest — agent index

Submodule of **dkan** (project **dkan**). Harvests dataset catalogs from external open-data portals into the local metastore. Version **4.1.2**.
Core `^10.2 || ^11`. Depends on: `dkan:dkan_metastore`, `dkan:dkan_common`.
Permissions: `harvest_api_run`, `harvest_api_register`, `harvest_api_info`, `harvest_api_index`, `dkan.harvest.dashboard`.

Part of the DKAN open-data portal pipeline. See [[dkan]] for the whole flow and the API access
model.

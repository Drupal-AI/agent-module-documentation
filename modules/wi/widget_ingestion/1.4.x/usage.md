Widget Ingestion provides integration with a widget API and pluggable widget ingestion.

---

Widget Ingestion provides integration with a widget API and pluggable widget functionality — a framework for ingesting widgets (embeddable third-party components/content) into Drupal via an API, so external widgets can be brought in and managed as part of the widget system (with widget_type/widget_instance).

Widget API credentials should be stored securely (env-backed). It's a developer/integration framework with no content role of its own. Depends on core `serialization` and `widget_type`; supports Drupal 9, 10, and 11.

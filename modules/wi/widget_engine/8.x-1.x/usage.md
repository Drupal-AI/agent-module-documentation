Widget Engine provides a widget content system for building reusable content components (widgets) and placing them, with domain-access and entity-form submodules.

---

Widget Engine provides a "widget" content system for Drupal — reusable content components (widgets)
that editors build once and place across pages, an approach to structured page building. It depends on
Inline Entity Form, core Node, Path, Text and Image, ships submodules for a custom-page node type,
domain-access integration and entity-form handling, and provides its own permissions.

Use it to build sites from reusable content widgets rather than one-off content. It is a
content-editing/site-building feature; widgets are content authored and rendered through Drupal's layers,
and access is governed by its permissions and the underlying entity access. Configure widget types and
placement; if using the domain-access submodule, verify widgets are scoped to the intended domains.

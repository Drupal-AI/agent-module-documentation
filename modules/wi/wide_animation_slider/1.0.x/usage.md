3D Wide Image Animation Slider renders an animated wide-image slider as a block.

---

**3D Wide Image Animation Slider** provides a block that renders a configurable 3D/wide animated image slider. Slides and options are managed through the module settings form (`wide_animation_slider.settings`), which is protected by the module's own `wide animation slider settings` permission (marked restrict access). A block plugin (`WideSliderBlock`) places the slider anywhere in the theme.

Use it to build hero/banner areas with an animated 3D wide slider.

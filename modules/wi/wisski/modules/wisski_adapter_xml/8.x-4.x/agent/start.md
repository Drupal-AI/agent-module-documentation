# WissKI XML Adapter (wisski_adapter_xml) — agent index

Submodule of **wisski**, under the project's **`legacy/`** directory. Parses an **XML file** for
entity information. Version **8.x-4.3**. Core `>=10.4 <12`.

Cultural heritage runs on XML — TEI, EAD, LIDO, METS/MODS. Reading it keeps **one authoritative
version** where converting creates a second copy that diverges.

**The underlying question, whatever the mechanism:** is the XML the *record of truth* (read it) or
a *delivery format* (import and move on)?

**Legacy directory** — check what a current project should use.

# WissKI SKOS Adapter (wisski_adapter_skos) — agent index

Submodule of **wisski**. Reads a **SKOS** vocabulary from a SPARQL 1.1 store.
Version **8.x-4.3**. Core `>=10.4 <12`.

SKOS is the W3C model for thesauri — concepts, broader/narrower, preferred/alternative labels — and
how most institutional vocabularies are published as linked data. Referencing beats duplicating as
taxonomy terms: corrections and multilingual labels keep propagating.

**Ships under the project's `legacy/` directory.** That is a statement about its status, not about
SKOS. Establish whether a project depends on it and what the current recommended path is before
building new work on it.

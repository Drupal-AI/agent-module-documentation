WissKI DMS Adapter queries the documentation management system of the Germanisches Nationalmuseum directly.

---

This is an institution-specific adapter, and saying so is the most useful thing documentation can do with it. The Germanisches Nationalmuseum was one of WissKI's founding partners, and its DMS is a particular system at a particular institution; the adapter exists so GNM's WissKI installations can read their existing documentation system alongside project data.

For anyone else, its value is as a worked example rather than as a feature: it shows what an adapter against a bespoke institutional system looks like, which is the situation many museums are in when they have a legacy catalogue that will outlive the project connecting to it.

If you find it enabled on a site that is not GNM's, that is worth investigating — most likely it was enabled during evaluation and never removed, which is harmless but adds a service dependency nobody is monitoring.

# WissKI Statistics (wisski_statistics) — agent index

Submodule of **wisski**. **Statistics** about the system's contents and growth.
Version **8.x-4.3**. Core `>=10.4 <12`.

**Point it at completeness, not headline counts.** Records created is easy and flattering; records
with an authority-controlled maker, a resolvable place, an image — those measure whether the data
is doing what the model promised.

**Check what it counts and at what cost.** Statistics over a triple store are expensive queries; a
dashboard recalculating on every page load slows the system it reports on.

# WissKI DOI (wisski_doi) — agent index

Submodule of **wisski**. Requests **DOIs** for WissKI entities.
Version **8.x-4.3**. Core `>=10.4 <12`.

**State what minting commits an institution to.** A DOI is an undertaking to keep the identifier
resolving through site migrations, platform changes and the end of the project that created it.
Minting for records you may delete or restructure is **worse than not minting** — a broken DOI
damages trust in the whole registry.

Decide up front: what is DOI-worthy, what happens on merge or withdrawal, and who is responsible
after the project ends. The registration agency's metadata requirements are a **cataloguing**
obligation, not a technical one.

# WissKI APUS (wisski_apus) — agent index

Submodule of **wisski**. Base for **content and annotation processing**; `wisski_triplify` and
`wisski_merge` nest under it. Version **8.x-4.3**. Core `>=10.4 <12`.

Why it matters in research: much of a collection's value is locked in prose. Extracting entities,
dates and places from a catalogue paragraph turns it into queryable data without retyping.

**Ships under the project's `legacy/` directory — while its nested processors do not.** The family
is partly current and partly not. Establish what a project actually depends on and check upstream
documentation for the current processing path before building new work here.

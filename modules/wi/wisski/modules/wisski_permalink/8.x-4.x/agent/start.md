# WissKI Permalink (wisski_permalink) — agent index

Submodule of **wisski**. Presents an entity's **URI as a permalink** and puts it in the browser
address bar. Version **8.x-4.3**. Core `>=10.4 <12`.

**Why it matters more than it sounds:** people cite what they can see and copy. If the visible URL
is a title-derived path, that is what appears in publications — and it breaks the first time anyone
tidies the titles.

Pairs with `wisski_doi` (permalinks for everything, DOIs for what warrants registration) and with
the linked-data publisher's standing obligation: **cool URIs don't change**.

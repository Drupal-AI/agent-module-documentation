# WissKI Getty AAT Adapter (wisski_adapter_aat) — agent index

Submodule of **wisski**. Queries the **Getty Art and Architecture Thesaurus**.
Version **8.x-4.3**. Core `>=10.4 <12`.

The standard controlled vocabulary for art and material culture — object types, materials,
techniques, styles, periods.

**The argument for it is aggregation.** A collection with free-text material terms cannot be
filtered by material in a national or European portal; one catalogued against AAT can. That is
often the difference between a digitisation project ending at its own website and one that reaches
an audience. AAT terms also carry multilingual labels, so translation does not mean
re-cataloguing.

Compare with `wisski_adapter_getty_new`.

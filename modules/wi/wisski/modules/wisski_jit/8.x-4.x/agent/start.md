# WissKI JIT (wisski_jit) — agent index

Submodule of **wisski**, under the project's **`legacy/`** directory. Integrates the **JavaScript
InfoVis Toolkit**. Version **8.x-4.3**. Core `>=10.4 <12`.

**Historical interest.** JIT's development stopped over a decade ago; D3, Cytoscape and Vis.js
replaced it comprehensively. Recognise it on an inherited installation; do not build on it.

**If a project needs graph visualisation, the question is what to visualise, not which library.** A
graph view of a whole collection is unreadable; useful views are narrow — one record's immediate
connections, one relationship type across a subset, a comparison of two records.

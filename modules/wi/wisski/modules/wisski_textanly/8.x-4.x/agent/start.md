# WissKI Text Analysis (wisski_textanly) — agent index

Submodule of **wisski**, under the project's **`legacy/`** directory. Text analysis API + editor UI
for **annotation proposals**. Version **8.x-4.3**. Core `>=10.4 <12`.

**The pattern is the point: propose, do not apply.** Proposals surface in the editor and a
cataloguer accepts or rejects. An algorithm deciding "Turner" is the painter rather than the place
will be wrong often enough to matter, and a collection that absorbs those decisions silently loses
the reliability that justifies it.

Also the efficient workflow — confirming four entities by clicking beats typing them.

**Legacy directory** — check the current path, but carry **propose-don't-apply** into whatever
replaces it.

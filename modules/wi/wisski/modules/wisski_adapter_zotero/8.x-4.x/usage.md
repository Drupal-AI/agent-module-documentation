WissKI Zotero Adapter reads Zotero libraries, so bibliographic references in a collection come from where researchers already manage them.

---

Researchers keep their references in Zotero. A collection database that asks them to re-enter citations gets incomplete, inconsistent bibliography, because the work is duplicated and the second copy is always the stale one.

This adapter reads a Zotero library through SALZ, so a record can reference a publication that lives in the group library the project already maintains, with the citation data coming from there.

The practical benefit is that bibliography stops being a data entry task and becomes a linking one. A researcher adds a source to Zotero as part of their normal work; the collection references it; a correction in Zotero appears everywhere.

Worth checking at setup: whether the adapter reads a group library or a personal one, and what happens to references when a library's sharing changes — a bibliography that resolves for the project lead and not for anyone else is a familiar and avoidable failure.

# WissKI Zotero Adapter (wisski_adapter_zotero) — agent index

Submodule of **wisski**. Queries **Zotero** for bibliographic records.
Version **8.x-4.3**. Core `>=10.4 <12`.

Researchers keep references in Zotero. A database asking them to re-enter citations gets
incomplete, inconsistent bibliography — the duplicated copy is always the stale one.

**Check at setup:** whether the adapter reads a **group** or **personal** library, and what happens
when sharing changes. A bibliography that resolves for the project lead and nobody else is a
familiar and avoidable failure.

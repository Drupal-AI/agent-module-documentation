# WissKI Getty Adapter, new (wisski_adapter_getty_new) — agent index

Submodule of **wisski**. Newer **Getty AAT** adapter, alongside `wisski_adapter_aat`.
Version **8.x-4.3**. Core `>=10.4 <12`.

Reflects a provider change — Getty exposes vocabularies via a SPARQL endpoint as well as older
paths. Newer adapter for new projects; for existing ones establish which is configured and confirm
it still resolves.

Everything about *why* controlled vocabulary matters is under `wisski_adapter_aat` — same
vocabulary, different access path.

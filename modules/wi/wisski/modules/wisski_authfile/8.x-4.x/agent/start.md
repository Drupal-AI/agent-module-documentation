# WissKI Authority File (wisski_authfile) — agent index

Submodule of **wisski**. Import, linking and handling of **external authority files**.
Version **8.x-4.3**. Core `>=10.4 <12`.

For authorities that are not live services — local name lists, project vocabularies, files
inherited from predecessor systems.

**Plan the file's future.** An imported authority is a **snapshot** and snapshots go stale. Decide
who maintains it, how updates apply, and whether the original source still exists. A local
authority file nobody owns becomes, within a few years, a list of names with no provenance — which
is where the project started.

# Y Donate (y_donate) — agent index

Embeds **donation forms from multiple providers** (Open Y / YMCA). Version **3.0.1**. Submodule
`lb_donate` (Layout Builder block).

**Security:** embeds third-party donation forms handling money/financial data — confirm each provider
keeps **card data off your server** (PCI scope), protect provider credentials, gate provider scripts
behind consent (third-party origins/tracking).

# Japanese NLP (jnlp) — agent index

Provides **Japanese natural-language-processing (tokenization/word segmentation)** via pluggable engines
(`jnlp_igo_php`/`jnlp_mecab`/`jnlp_sudachi`/`jnlp_tinysegmenter`). Provides permissions. Version
**1.0.0-beta2**. Core `^10||^11`.

Developer/language-processing — processes text; no content/access role. Engines differ (some need a system
binary like MeCab).

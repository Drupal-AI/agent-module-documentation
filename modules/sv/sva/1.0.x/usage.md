Simple Views Accordion provides a Views style plugin that renders results as an accordion (collapsible sections).

---

Simple Views Accordion adds a Views display style that renders results as an accordion — each row
becomes a collapsible section with a header and expandable content. It is a lightweight way to present
FAQs, feature lists or grouped content compactly, letting visitors expand the item they want. It
depends on core Views.

Use it on any View whose rows read well as expand/collapse sections (FAQs are the classic case). It is
a display/presentation style; it changes how View results are rendered, not the results or their access
— the View's own access still governs what appears. Select "Simple Views Accordion" as the View's
format and map the header/content fields.

GraphQL (v3) integration for the SVG Image module.

---

SVG Image GraphQL provides GraphQL (v3) integration for the SVG Image module — exposing SVG image field data through the GraphQL schema so a decoupled/headless front end can query SVG images (and their metadata) managed by SVG Image. Depends on `svg_image` and `graphql` (3.x); supports Drupal 10 and 11.

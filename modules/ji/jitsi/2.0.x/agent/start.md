# Jitsi — agent index

Integrates **Jitsi Meet video conferencing** (embed meeting rooms; module machine name **`ek_jitsi`**).
Provides permissions. Version **2.0.1**. Core `>=9.4`.

Communications/integration — calls run on a **Jitsi server** (prefer self-hosted/trusted for sensitive
meetings); consider **room-name guessability** (use non-guessable rooms / Jitsi-side auth). Loads Jitsi's
external script.

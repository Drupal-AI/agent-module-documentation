An Intercom-like AI chatbot widget with OpenAI integration.

---

Knova is a powerful, Intercom-like AI chatbot widget for Drupal with OpenAI integration — a floating chat widget with customizable appearance and advanced AI settings, so visitors can chat with an AI assistant grounded in the site's configuration.

The OpenAI API key is admin-configured and should be stored securely (env-backed); each chat turn is an LLM call, so scope access and watch cost/abuse. Depends on core `config` and `user`; supports Drupal 10 and 11.

Rules Flag integrates Rules and Flag, adding Rules events that fire when an entity is flagged/unflagged, with example rules.

---

Rules Flag integrates the Rules and Flag modules — adding Rules events that fire when an entity is
flagged or unflagged, so site builders can trigger Rules-based reactions (send an email, update a field,
grant access) in response to flagging actions. It ships example rules and depends on Flag, Rules and Job
Scheduler.

Use it to automate behaviour around flags (bookmarks, "report", "approve" flags) via Rules. It is an
automation/business-rules feature bridging Flag and Rules; the reactions it enables run with the
configured Rules logic, so — as with any Rules automation — review what the rules do (especially any that
change access or send communications) so flagging can't trigger unintended privileged actions. Configure
the Rules reactions on the flag events.

RumbleTalk allows you to embed a RumbleTalk group chat in your site.

---

RumbleTalk embeds a **RumbleTalk group chat** into Drupal — placing a hosted RumbleTalk chat room on the
site so visitors can chat in real time. The project is `rumbletalk`; the module machine name is
**`rumbletalk_chat`**, in the RumbleTalk package.

Use it to add a hosted group chat. It is a third-party integration/user-engagement feature — the chat runs on
**RumbleTalk's** service and the module loads **RumbleTalk's third-party JavaScript** (trust the vendor; runs
in your origin), and chat data/participants are handled by RumbleTalk (a privacy/consent consideration). It has
no access-control role. Configure the RumbleTalk chat ID/embed.

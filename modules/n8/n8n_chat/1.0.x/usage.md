n8n Chat integrates n8n chat functionality into Drupal.

---

n8n Chat **integrates n8n chat functionality** — embedding an n8n-powered chat widget so visitor messages
are handled by an n8n automation workflow (which can call AI, APIs, etc.). It depends on core Block and System,
in the AI and Automation package.

Use it to add an n8n-driven chat. It is an automation/AI-integration feature. Security/data handling: chat
messages are **sent to your n8n instance/webhook** (external egress to whatever the n8n workflow does — confirm
the endpoint is trusted and over HTTPS, and that the workflow doesn't expose data/actions it shouldn't); store
any **webhook secret/credentials** securely. It has no access-control role. Configure the n8n chat webhook.

Let users RSVP to events and give admins the attendee list.

---

RSVP List allows users to RSVP for an event and provides a contact list for administrators — attaching an RSVP form to configured content so visitors can sign up to attend, while admins see the collected list of respondents (with their contact details) per event. Supports Drupal 9.4+, 10, and 11. Project `rsvp_list`.

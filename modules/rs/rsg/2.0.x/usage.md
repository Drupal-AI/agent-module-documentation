Random String Generator (rsg) generates a random string based on length and type.

---

Random String Generator (rsg) generates random strings — of a configurable length and character type
(alphabetic, numeric, alphanumeric, etc.) — as a utility for producing random values (codes, identifiers). It
is in the String package.

Use it as a utility to generate random strings. It is a developer/utility feature. Note on use: if you use
the generated strings for **security-sensitive** purposes (tokens, passwords, secrets), ensure the generation
uses a cryptographically-secure source and sufficient length/character-space — for non-security uses (display
codes, sample data) ordinary randomness is fine. It has no access-control role. Configure the length and
type.

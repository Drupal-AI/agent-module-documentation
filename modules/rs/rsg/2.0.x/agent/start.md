# Random String Generator (rsg) — agent index

Generates **random strings of a configurable length and character type** (codes/identifiers utility). Version
**2.0.0**. Core `^10.1||^11||^12`.

Developer/utility. **Note:** for **security-sensitive** strings (tokens/passwords/secrets) ensure a
cryptographically-secure source + sufficient length/character-space; ordinary randomness is fine for display
codes/sample data. No access role.

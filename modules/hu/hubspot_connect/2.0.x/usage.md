Hubspot connect allows your site to be tracked by HubSpot by adding a JavaScript tracking code to every page.

---

Hubspot connect adds the HubSpot tracking JavaScript to every page — so visitor activity is tracked in
HubSpot for analytics, marketing automation and CRM. It is configured at `hubspot_connect.settings`, provides
its own permissions, in the Statistics package.

Use it to enable HubSpot visitor tracking. Like any third-party marketing tracker, it is a privacy/consent
consideration: it loads external JS that tracks visitors and can set cookies, so disclose it in your privacy
policy and gate it behind cookie/consent management (GDPR/CCPA) where required. It has no access-control role
beyond its permission. Configure the HubSpot tracking ID.

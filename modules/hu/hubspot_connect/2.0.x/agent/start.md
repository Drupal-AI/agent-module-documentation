# Hubspot connect — agent index

Adds the **HubSpot tracking JavaScript to every page** (track visitors for analytics/marketing/CRM). Config at
`hubspot_connect.settings`; provides permissions. Version **2.0.0**. Core `^10||^11`.

Third-party marketing tracker — **privacy/consent:** disclose in the privacy policy, gate behind cookie
consent (GDPR/CCPA). No access role beyond permission.

XY Grid Layouts provides ZURB Foundation XY grid system layouts.

---

XY Grid Layouts provides **layouts based on ZURB Foundation's XY grid system** — ready-made layout plugins
(rows/columns) that use Foundation's XY grid, for use with Layout Builder / the Layout API. It depends on core
Layout Discovery, in the Layout package.

Use it on Foundation-based sites to lay out content with the XY grid. It is a site-building/layout feature
providing layout plugins; it has no content or access role. Use the XY grid layouts.

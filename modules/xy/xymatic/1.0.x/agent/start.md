# Xymatic — agent index

Integrates **Xymatic video** with Drupal media (embed/manage Xymatic-hosted videos; `xymatic_migrate`
submodule). Depends on core `media`. Version **1.0.0-beta6**. Core `^10||^11`.

Media/integration — videos hosted/served by **Xymatic** and embedded (third-party); media access follows core
media/file access; no access role.

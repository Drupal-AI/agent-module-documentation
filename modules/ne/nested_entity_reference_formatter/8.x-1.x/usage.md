Nested Entity Reference Formatter provides a formatter for entity reference fields that allows choosing a nested field and formatter for a related entity-reference via ajax.

---

Nested Entity Reference Formatter provides an entity-reference field formatter that can render a **nested
field** of the referenced entity — letting you pick, via AJAX, a field on the referenced entity (or its own
references) and a formatter for it, so a reference can display a specific deep value rather than the whole
target. It is in the Fields package.

Use it to display a nested field of a referenced entity. It is a content-display/formatter feature; the
referenced entities and their fields are rendered respecting their own access (only accessible targets/fields
render), and it has no access-control role. Configure the nested field and formatter.

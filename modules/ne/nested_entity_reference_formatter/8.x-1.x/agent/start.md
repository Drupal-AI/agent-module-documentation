# Nested Entity Reference Formatter — agent index

A field **formatter rendering a chosen nested field of a related entity-reference (via AJAX)** (display a deep
value vs the whole target). Version **8.x-1.35**. Core `^8.8||^9||^10||^11`.

Content-display/formatter — referenced entities/fields rendered respecting their own access; no access
role.

Next Views Entity Reference provides next/prior links for an entity in an entity reference list.

---

Next Views Entity Reference provides **next/previous ("prior") links for an entity** based on its position
in an entity-reference field's ordering — so you can navigate between referenced items (e.g. chapters, gallery
items) in sequence. It depends on core Views and Twig Tweak, in the Views package.

Use it to add sequential navigation between referenced entities. It is a content-display/navigation feature;
the sequence follows an access-respecting Views/reference list, and it has no access-control role. Configure the
next/prior links.

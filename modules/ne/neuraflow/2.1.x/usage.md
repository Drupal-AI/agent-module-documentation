Neuraflow connects Drupal to Neuraflow's AI/automation products.

---

Neuraflow provides integrations for Neuraflow products — connecting Drupal to Neuraflow's AI/automation platform so content and workflows can leverage Neuraflow services. It's the integration layer for those products.

Neuraflow API credentials should be stored securely (env-backed); administration is gated by `administer neuraflow`. Supports Drupal 10.3+ and 11.

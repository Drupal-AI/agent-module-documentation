Next Custom Tags provides a plugin system for extracting custom cache tags from entities (for Next.js).

---

Next Custom Tags **extracts custom cache tags from entities** — a plugin system that derives additional cache
tags from Drupal entities so a decoupled Next.js front end can revalidate precisely on content changes. It depends
on the Next.js (Next) module and provides its own permissions.

Use it to drive fine-grained Next.js cache revalidation. It is a decoupled/developer feature; it computes cache
tags and has no content or access role beyond its permission. Configure the custom-tag plugins.

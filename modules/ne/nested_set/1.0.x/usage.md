Nested Set provides a field type storing entity hierarchy via the nested-set (MPTT) model.

---

Nested Set defines a field type to organize entities into a hierarchy using the nested-set model (a.k.a. modified preorder tree traversal) — an efficient way to store and query tree structures, useful for building hierarchical relationships (categories, org charts) with fast subtree queries.

It's a field-provider/developer tool with no content or access role of its own. Depends on core `field`; supports Drupal 10.1+ and 11.

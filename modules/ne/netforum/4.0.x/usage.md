Connect Drupal to the NetForum xWeb API for association-management integrations.

---

NetForum xWeb API enables Drupal to easily connect with the NetForum xWeb API — offering a developer-friendly foundation for building custom NetForum integrations (NetForum is an association-management system), so a site can sync members/events/data with NetForum.

The NetForum xWeb credentials are admin-configured and should be stored securely (env-backed), never committed. Supports Drupal 10.4+ and 11.

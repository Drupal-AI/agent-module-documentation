Next.js Generator scaffolds Next.js front-end code from Drupal using Drush commands.

---

Next.js Generator (nextgen) provides Drush commands that generate Next.js code from a Drupal site — scaffolding front-end components/pages for a decoupled Next.js front end based on the Drupal content model, speeding up decoupled site setup.

It's a developer/scaffolding tool (CLI) with no content or access role of its own. Supports Drupal 10, 11, and 12.

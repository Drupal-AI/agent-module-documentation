Azure AI Services provides a base integration for Azure's AI/Cognitive services.

---

Azure AI Services integrates Azure's AI services into Drupal — providing the connectivity/framework to call Azure Cognitive/AI services (language, vision, etc.) so other modules/features can use Azure AI capabilities.

Azure credentials should be stored securely (env-backed); requests send data to Azure (cost + egress). It's a connectivity/integration module. Supports Drupal 10 and 11.

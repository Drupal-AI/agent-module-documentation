Geofield Directions is a field formatter for geofields to display directions links.

---

Geofield Directions provides a field formatter for Geofield fields that renders a "get directions" link
— turning a stored geographic point into a link to a maps directions service (Google Maps etc.) for the
location. It depends on the Geofield module, in the Geofield package.

Use it to add directions links to location fields. It is a content-display/formatter feature; the location
comes from the geofield (respecting its access) and it has no access-control role. Select the directions
formatter on the geofield.

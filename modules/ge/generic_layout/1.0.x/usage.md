Generic Layout provides one configurable, responsive layout with arbitrary regions and UI Styles.

---

Generic Layout provides a single, extremely customizable and responsive Layout plugin with arbitrary layout regions — so instead of many fixed layouts, site builders configure one flexible layout (regions, responsiveness, styling via UI Styles) to fit most needs in Layout Builder.

It's a layout/site-building tool with no content or access role of its own. Depends on core `layout_discovery` and `ui_styles`; supports Drupal 10.3+ and 11.

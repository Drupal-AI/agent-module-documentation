An AI Agent tool that extracts predominant colors from images.

---

Generic Colors is an AI Agent Tool for retrieving predominant colors from images using a local library — so an AI agent (via the AI Agents framework) can call this tool to analyse an image and return its dominant colors, useful for tagging, theming, or accessibility workflows. It runs locally (no external color API). Depends on `ai`, `ai_agents`, and `tool`; supports Drupal 10 and 11.

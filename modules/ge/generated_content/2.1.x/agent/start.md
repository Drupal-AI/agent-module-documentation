# Generated Content — agent index

Framework to **programmatically generate content** (nodes/terms/users/media) declared in code, for
demos/tests/dev — reproducible + cleanup. Example submodules `generated_content_example1/2`. Provides
**Drush commands** + permissions. Version **2.1.0**. Core `^11.2`.

Developer tool — **don't run generation on production**. Gated by permission + CLI context.

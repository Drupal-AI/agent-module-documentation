Geolocation Leaflet Center Node centers on the current node location in a view.

---

Geolocation Leaflet Center Node **centers a Geolocation Leaflet map on the current node's location** — in a
view context, so a map of related items centers on the node being viewed. It depends on the Geolocation module
and core Views, in the Geolocation package.

Use it to center maps on the current node. It is a content-display/maps feature affecting presentation; the
locations follow the view's/entity's access and it has no access-control role. Configure the map to center on
the node.

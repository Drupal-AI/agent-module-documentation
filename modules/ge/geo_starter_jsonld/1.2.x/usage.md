GEO Starter JSON-LD adds schema.org JSON-LD structured data to GEO Starter pages.

---

GEO Starter JSON-LD **adds schema.org JSON-LD to GEO Starter pages** — emitting structured data so search/
answer engines (and AI retrieval systems) can read the page's governed, sourced content. It depends on core Node
and the Paragraphs module.

Use it to add structured data for GEO/SEO. It is an SEO feature; JSON-LD reflects on-page content and it has no
content or access role. Note: JSON-LD exposes structured content to consumers, so only include data intended to be
public. Configure the JSON-LD output.

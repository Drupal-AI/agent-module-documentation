Load a GTM/tag-manager snippet in the head with an optional noscript.

---

GTM Snippet Loader loads a Google Tag Manager (or custom tag manager) snippet in the <head> and an optional noscript snippet after <body> — so a site can add GTM/tag-manager tracking correctly (head + noscript) from configuration without editing templates. Supports Drupal 10 and 11.

# Barebones GTM — agent index

Minimal **Google Tag Manager** integration — just the essential container snippet (enter GTM ID). Requires
**PHP 8.2**. Version **1.2.0**. Core `^10.2||^11`.

**Privacy/consent:** GTM loads third-party tracking/cookies — pair with cookie-consent + disclose. Tags
defined in the GTM console. No access role.

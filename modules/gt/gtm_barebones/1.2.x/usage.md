Barebones GTM provides a minimal Google Tag Manager integration, adding just the essential GTM container snippet.

---

Barebones GTM provides a deliberately minimal Google Tag Manager integration — just the essential GTM
container snippet, without the extensive configuration of larger GTM/analytics modules. An administrator
provides the GTM container ID and the module injects the snippet. It requires PHP 8.2 and is in the SEO
package.

Use it when you want GTM on the site with minimal overhead. As with all tag-manager integrations, there
are privacy/consent implications: GTM can load third-party tracking and set cookies — pair it with cookie-
consent handling and disclose the tracking per your jurisdiction. The actual tags are defined in the GTM
console, not in Drupal. It has no access-control role.

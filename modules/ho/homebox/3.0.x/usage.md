Homebox allows site administrators to create dashboards for their users, using draggable portlets.

---

Homebox lets site administrators build **personal dashboards** for users out of **draggable portlets** —
each user can arrange configured portlet blocks into their own dashboard layout (a My-Yahoo-style homepage).
It ships `homebox_portlet_type_block` and `homebox_portlet_type_examples` submodules, uses core Layout
Discovery and Path, provides its own permissions, in the Homebox package.

Use it to give users a customizable dashboard. It is a user-engagement/layout feature; each user's arrangement
is per-user and the portlets render blocks (whose own access applies), and it has no access-control role
beyond its permission (who can use/administer dashboards). Configure the available portlets and dashboards.

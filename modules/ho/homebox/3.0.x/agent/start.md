# Homebox — agent index

Lets admins build **draggable, portlet-based personal dashboards** for users (each user arranges portlet
blocks into their own layout). Submodules: `homebox_portlet_type_block`, `homebox_portlet_type_examples`. Uses
core `layout_discovery`, `path`. Provides permissions. Version **3.0.1**. Core `^10.5||^11`.

User-engagement/layout — arrangements per-user; portlets render blocks (their own access applies); no access
role beyond permission.

# Home Redirect Language — agent index

Redirects **visitors landing on the homepage to their language's homepage** (localized front page for the
preferred language). Provides permissions. Version **1.1.4**. Core `^10.5||^11`.

Multilingual — affects the homepage redirect; no content/access role beyond permission.

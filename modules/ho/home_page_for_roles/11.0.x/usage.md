Homepage by role configures different homepage redirections based on user roles.

---

Homepage by role (home_page_for_roles) configures different front-page redirections based on the user's
roles — so when a user visits the site's front page, they are redirected to a role-appropriate homepage
(e.g. members to a dashboard, anonymous to a landing page). It is configured at
`home_page_for_roles.settings`, in the Administration package.

Use it to route users to role-specific homepages. It is a routing/UX feature affecting where the front page
sends a user; it is a **redirect convenience, not access control** — the destination pages still enforce
their own access (redirecting a user somewhere doesn't grant or deny them access to it). It has no
access-control role. Configure the per-role homepage redirects.

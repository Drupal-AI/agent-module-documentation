# Homepage by role (home_page_for_roles) — agent index

Redirects users to **different homepages based on their roles** (front-page redirect — members→dashboard,
anon→landing). Config at `home_page_for_roles.settings`. Version **11.0.1**. Core `^11`.

Routing/UX — a **redirect convenience, NOT access control** (destination pages still enforce their own
access). No access role.

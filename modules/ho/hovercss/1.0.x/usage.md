HoverCSS integrates Hover.css, a collection of CSS3-powered hover effects for links, buttons, images and more.

---

HoverCSS integrates the Hover.css library — a collection of CSS3-powered hover effects that can be
applied to links, buttons, logos, SVGs, featured images and other elements. It ships a `hovercss_ui`
submodule (a UI for applying effects). It is in the User interface package.

Use it to add polished hover effects without writing the CSS. It is a theming/front-end feature providing
hover-effect styles; it affects presentation and has no content or access role. Apply the effect classes
to elements (or use the UI submodule).

# Hospital Price Transparency — agent index

**Supports posting standard hospital charge/price-transparency files** (US CMS compliance). Depends on core
`file`, `path_alias`. Provides permissions. Version **2.0.0-beta1**. Core `^10.1||^11`.

Compliance/publishing — charge files are **public compliance data** (served at the required public path); no
access role beyond permission.

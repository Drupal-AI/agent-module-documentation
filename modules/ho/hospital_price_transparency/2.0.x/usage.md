Hospital Price Transparency supports posting standard hospital charge files.

---

Hospital Price Transparency **supports posting standard hospital charge files** — helping US hospitals
publish the machine-readable standard-charges file required by CMS price-transparency rules, in the required
format/location. It depends on core File and Path Alias, provides its own permissions, in the SEO package.

Use it for US hospital price-transparency compliance. It is a compliance/publishing feature. Data-handling note:
the charge files are **public compliance data** (published for consumers/regulators), served as files — ensure
the file is served at the required public path and the data is accurate; it has no access-control role beyond
its permission. Configure and publish the charge file.

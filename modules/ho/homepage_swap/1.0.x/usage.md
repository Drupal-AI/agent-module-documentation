Homepage Swap allows easy switching of the site's current homepage.

---

Homepage Swap **allows easy switching of the current homepage** — quickly changing which page the site's front
page points to (e.g. for campaigns/seasonal homepages) without editing site settings each time. It provides its own
permissions.

Use it to swap the homepage on demand. It is a site-building/administration feature; it changes the front-page
setting and is gated by its permission (restrict to trusted admins — the homepage is high-visibility). It has no
broader access-control role. Configure the homepage options.

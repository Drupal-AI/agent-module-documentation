# Hold My Draft — agent index

Lets editors **"hold" the latest revision (draft) and block further editing until released** (freeze a draft
pending review, without publishing). Depends on core `node`, `content_moderation`. Provides permissions. Version
**3.0.1**. Core `^10||^11`.

Editorial-workflow — place/release governed by its permissions; works with Content Moderation. No broad access
role beyond permissions.

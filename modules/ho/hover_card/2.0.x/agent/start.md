# Hover Card — agent index

Displays **configurable user information in a popup card when hovering a username**. Provides permissions.
Version **2.0.2**. Core `^10.3||^11`.

User-engagement/display — **privacy**: shows **user profile data**; configure it to reveal **only safe fields**
(don't expose email/sensitive fields to unauthorized viewers). Permission gates who sees the card.

Language Links On Menu (llom) provides a language switcher to be placed as a menu item.

---

Language Links On Menu (llom) provides a language switcher that can be placed as a menu item — so the
language-switching links live inside a menu (main menu, footer) rather than only as a block, integrating
language switching into site navigation. It depends on core Language and Menu UI and provides its own
permissions, in the Multilingual package.

Use it to put language switching in a menu. It is a multilingual/navigation feature that renders language
links; it reflects the site's configured languages and has no access-control role. Add the language menu
item to the relevant menu.

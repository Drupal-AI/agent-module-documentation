# Language Links On Menu (llom) — agent index

A **language switcher placed as a menu item** (language links inside a menu — main/footer — vs only a
block). Depends on core `language`, `menu_ui`; provides permissions. Version **1.0.3**. Core `^9||^10||^11`.

Multilingual/navigation — renders language links reflecting configured languages; no access role.

llms.txt AI Generator automatically generates an llms.txt file for the site using AI.

---

llms.txt AI Generator **generates an llms.txt file using AI** — producing the emerging `llms.txt` standard
file (a guide to your content for large language models) automatically via the AI module, to make site content
discoverable by ChatGPT, Claude, Perplexity, Gemini, etc. It depends on the AI, Metatag, Menu UI and System
modules, and provides its own permissions.

Use it to publish an AI-generated llms.txt. It is a content-authoring/SEO feature. Security/data handling: it
**sends site content/structure to the configured AI provider** (external egress — confirm acceptable) to generate
the file, and the resulting `llms.txt` is **published for LLM crawlers**, so only include content you intend to be
publicly discoverable. Store the AI provider key as a secret (via the AI module/Key). It has no access-control role
beyond its permission. Configure the AI provider and generation.

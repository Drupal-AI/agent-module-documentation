Gamify adds gamification (points, rewards) to the community UI via ECA and User Points.

---

Gamify **adds gamification to the community UI** — awarding points/rewards for user activity to drive
engagement, built on ECA (Event-Condition-Action) and its User Points submodule. It depends on ECA and provides
its own permissions.

Use it to gamify user engagement. It is a user-engagement/automation feature. Data-handling note: it tracks
**per-user activity and points** (personal data) — expose leaderboards/points appropriately and handle the activity
data per your privacy policy. Point-awarding rules are ECA models (powerful — keep authoring to trusted admins). It
has no access-control role beyond its permission. Configure the gamification rules.

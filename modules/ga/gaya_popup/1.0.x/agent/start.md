# Gaya Popup Module — agent index

Configurable **popup/dialog box** for messages/content (announcements/promotions in a modal). Depends
on core `field`, `user`, `system`; provides permissions. Version **1.0.0-rc2**. Core `^10.4||^11`.

Content-display/UI — admin-authored popup content; no access role. Part of the GAYA family.

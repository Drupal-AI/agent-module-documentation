Gaya Popup Module provides a configurable popup dialog box to show messages or content to visitors.

---

Gaya Popup Module provides a configurable popup/dialog box for showing messages or content to
visitors — announcements, promotions, notices displayed in a modal. It depends on core Field, User and
System, and provides its own permissions. It is part of the GAYA theme/module family.

Use it to present a modal message on the site. It is a content-display/UI feature; the popup content is
admin-authored and rendered through Drupal's layers, and it has no access-control role beyond its admin
permission. Configure the popup content and display conditions.

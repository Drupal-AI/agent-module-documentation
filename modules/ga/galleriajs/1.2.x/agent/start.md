# Galleriajs — agent index

Integrates the **Galleria JS** gallery plugin with **Views** — render results as a gallery/slideshow
(thumbnails, transitions). Depends on core `views`. Version **1.2.0**. Core `^10.3||^11||^12`.

Content-display/Views — gallery content from the View, respects the View's access; no access role.

Galleriajs provides integration between the Galleria JS gallery plugin and Views, rendering a View as a Galleria gallery.

---

Galleriajs integrates the Galleria JavaScript gallery plugin with Views — providing a Views style that
renders results (typically images) as a Galleria gallery/slideshow with thumbnails and transitions. It
depends on core Views. This lets site builders build image galleries from Views without custom JS.

Use it on image-listing Views where a Galleria gallery presentation fits. It is a content-display/Views
feature; the gallery content comes from the View and respects the View's access, with no access-control
role. Select the Galleria style as the View's format and configure the gallery options.

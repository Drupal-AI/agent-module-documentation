Gantt uses the dhtmlxGantt JavaScript library to display Views results (tasks with dates) as a Gantt chart.

---

Gantt displays Views results as a Gantt chart — using the dhtmlxGantt JavaScript library to render
tasks (with start/end dates and dependencies) as an interactive project timeline. It ships a `gantt_node`
submodule and provides its own permissions. This suits project/task content that benefits from a timeline
view.

Use it to visualize date-based content (projects, schedules) as a Gantt chart from a View. It is a
content-display/Views feature; the chart content comes from the View and respects the View's access, and it
has no access-control role. Select the Gantt style on a View with date fields and configure the mapping.

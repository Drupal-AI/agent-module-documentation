Single File Components enables modules to provide single file components.

---

Single File Components (sfc) enables modules to define single-file components — co-locating a component's
Twig template, CSS and JavaScript in one file/unit — for a component-driven development approach where each
component's assets live together. It ships `sfc_dev` and `sfc_example` submodules and provides Drush commands.

Use it as a developer/theming framework for single-file components. It is a developer/theming feature
providing a component system; the components render content through Drupal's normal layers and it has no
access-control role. Use the SFC API to build components.

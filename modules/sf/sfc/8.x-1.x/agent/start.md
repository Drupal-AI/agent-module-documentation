# Single File Components (sfc) — agent index

Enables modules to provide **single-file components** (co-located Twig template + CSS + JS — component-driven
development). `sfc_dev`/`sfc_example` submodules; Drush commands. Version **8.x-1.12**. Core `^9||^10|^11`.

Developer/theming — a component system; components render through Drupal's normal layers; no access role.

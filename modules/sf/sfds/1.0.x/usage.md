Shared Field Display Settings shares entity field display settings across all fields.

---

Shared Field Display Settings (sfds) **shares field display settings** — a way to define field display/formatter
settings once and apply them across all instances of a field, for consistent field display. It works on core
10.2–11.

Use it to standardize field display. It is a site-building/theming feature; it configures field display and has no
content or access role. Configure the shared display settings.

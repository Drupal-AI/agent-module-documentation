# Configuration

ERR Delete has a small settings form for tuning how its delete option is presented.
The recursive delete works without touching it, so these are optional adjustments.

## Open the settings form

1. Log in as an administrator (a user who can administer site configuration).
2. Go to **Configuration → Content authoring → ERR Delete settings**.

## The settings

- **Delete button label** — change the text shown on the recursive delete button.
  Because it's editable here, you can also use this to translate the label into
  your site's language.
- **Hide the old delete button** — when enabled, the standard core delete button is
  hidden so editors use the recursive ERR Delete flow instead. Leave it off if you
  want both the normal delete and the recursive delete available side by side.

## Save

Click **Save configuration**. The change takes effect on the node edit form the next
time you open it.

Schema Diff shows schema diff in detail.

---

Schema Diff **shows a detailed diff of the database schema** — comparing what modules declare (in
`hook_schema`/entity definitions) against what's actually installed, to spot mismatches (a common cause of
update/entity errors). It works across core 9+.

Use it as a developer/diagnostic tool for schema mismatches. It is an administration/developer tool that
surfaces schema detail (internal structure); keep it to **developers/admins** and note the output reveals
database structure. It has no access-control role. Review the schema diff.

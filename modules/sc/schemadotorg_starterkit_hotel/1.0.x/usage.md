A Schema.org Blueprints starter kit for hotel websites.

---

Schema.org Blueprints Starter Kit: Hotel provides the Schema.org types required to build a hotel website — a starter kit built on Schema.org Blueprints that scaffolds the entity types, fields and mappings (Hotel, Room, etc.) with Schema.org structured data, so a hotel site starts with a semantically-modelled content structure. Depends on Schema.org Blueprints (many submodules), `views`, and `menu_ui`; supports Drupal 10.3+ and 11.

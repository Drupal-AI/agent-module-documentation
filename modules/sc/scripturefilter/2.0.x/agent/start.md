# Scripture Filter — agent index

A text-format **filter that turns Scripture references into links to online Bibles** ("John 3:16" → a
clickable passage link). Version **2.0.4**. Core `^10||^11`.

Content-display/text-filter — rewrites references into links on output; add to the appropriate text format.
No access role.

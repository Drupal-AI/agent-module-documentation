Scripture Filter turns any Scripture reference into a link to one of several online Bibles.

---

Scripture Filter provides a text-format filter that detects Scripture (Bible) references in content and
turns them into links to a chosen online Bible — so references like "John 3:16" become clickable links to
read the passage. It is in the Text Formats package.

Use it on faith/church sites to auto-link Scripture references. It is a content-display/text-filter feature
that rewrites references into links on output; it processes text and has no access-control role. As a text
filter, it runs on filtered content — add it to the appropriate text format. Configure the target Bible.

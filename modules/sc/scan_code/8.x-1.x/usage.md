---

Scan code - Barcode lets users scan barcodes — reading the information encoded in a barcode image (using
the device camera or an uploaded image) and extracting the data for use in a form/field. This supports
barcode-driven data entry (product codes, tickets, inventory). It is configured at `scan_code.admin_config`
and provides its own permissions.

Use it for barcode-based input. It is a content-editing/input feature capturing scanned data; the scanned
value is user-supplied input, so validate/escape it as with any user input, and (if camera-based) the
browser will prompt for camera permission. It has no access-control role. Configure the scanning behaviour.

# Scolta — agent index

**AI-powered client-side search with Pagefind** (Search API backend, static browser-side index). Depends on
`search_api`. Provides permissions. Version **1.2.0**. Core `^10.3||^11`.

Search — the static index is **served to the browser** (indexed content is effectively **public**): index only
public content, respect Search API access. No access role beyond permission.

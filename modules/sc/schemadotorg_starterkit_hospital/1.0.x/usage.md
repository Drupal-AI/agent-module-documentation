Hospital Starter Kit scaffolds Schema.org Blueprints content types for a hospital site.

---

Schema.org Blueprints Starter Kit: Hospital provides the Schema.org types and configuration required to build a hospital website — scaffolding content types, fields, and mappings (Hospital, MedicalOrganization, etc.) via Schema.org Blueprints, plus default content, so a hospital site can be stood up quickly with structured data built in.

It's a starter kit (installs config/content) built on the schemadotorg suite and Paragraphs; run on a fresh/eval site. Depends on the schemadotorg suite, `paragraphs`, `config_rewrite`, and `default_content`; supports Drupal 10.3+ and 11.

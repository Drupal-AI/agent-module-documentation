Scrape web content into content-type fields with background processing.

---

Scrape to field provides web scraping functionality for content type fields with background processing — so a configured field can be populated by scraping data from a web page (via admin-defined scrape rules), with the fetching done in background queue processing to avoid blocking.

The scrape configuration is gated by the `administer scrape to field` permission (admin-only); the scrape target URL is admin-supplied. Depends on core `field`; supports Drupal 11.

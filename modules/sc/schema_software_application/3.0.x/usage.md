Schema.org SoftwareApplication adds SoftwareApplication schema.org structured data (JSON-LD) to pages via the Schema.org Metatag module.

---

Schema.org SoftwareApplication adds the `SoftwareApplication` schema.org type to a page's JSON-LD
structured data, via the Schema.org Metatag (schema_metatag) framework — so pages describing software/
apps can emit structured data (name, operating system, price, ratings) eligible for software rich
results in search. It depends on `schema_metatag`.

Use it on pages representing software applications to improve their structured-data/SEO. It is an
SEO/structured-data feature producing JSON-LD markup; keep the emitted values accurate to the software
described, and it has no access-control role. Configure the SoftwareApplication metatag fields on the
relevant content.

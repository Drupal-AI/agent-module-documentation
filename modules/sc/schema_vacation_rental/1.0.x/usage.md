Schema.org VacationRental emits VacationRental structured data via Schema Metatag.

---

Schema.org VacationRental adds the Schema.org VacationRental type to the JSON-LD structured-data array produced by Schema Metatag — so vacation-rental listings can emit rich structured data for search engines. It builds on Schema Metatag and Schema Accommodation.

It's an SEO/structured-data submodule with no content or access role of its own. Depends on `schema_metatag` and `schema_accommodation`; supports Drupal 9, 10, and 11.

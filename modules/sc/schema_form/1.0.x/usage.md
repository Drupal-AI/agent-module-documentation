Schema Form builds Drupal forms from a schema definition.

---

Schema Form provides schema-based forms — generating Drupal Form API forms from a schema definition (e.g. JSON Schema), so developers can define form structure declaratively and have it rendered/validated automatically rather than hand-building each form.

It's a developer/form-building tool with no content or access role of its own. Supports Drupal 10 and 11.

Schema.org PublicationIssue adds PublicationIssue structured data to Schema Metatag JSON-LD.

---

Schema.org PublicationIssue adds the Schema.org PublicationIssue type to the JSON-LD structured-data array produced by Schema Metatag — so publications (magazine/journal issues) can emit rich structured data for search engines, useful for periodical/scholarly publishing sites.

It's an SEO/structured-data submodule with no content or access role of its own. Depends on `schema_metatag`; supports Drupal 8 through 11.

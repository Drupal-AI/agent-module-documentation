---

Schema.org EducationalOccupationalCredential **adds a credential schema type** — extending Schema.org Metatag
to output `EducationalOccupationalCredential` structured data (JSON-LD) for describing certifications/credentials,
improving SEO/rich results. It depends on the Schema.org Metatag module.

Use it to mark up educational/occupational credentials. It is an SEO feature; JSON-LD reflects on-page content and
it has no content or access role. Configure the credential schema.

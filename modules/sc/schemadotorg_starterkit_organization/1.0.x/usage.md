Organization Starter Kit scaffolds Schema.org Organization/LocalBusiness content types.

---

Schema.org Blueprints Starter Kit: Organization creates Schema.org Organization and LocalBusiness types with the required fields and mappings — scaffolding the content model (via Schema.org Blueprints) needed to represent an organization/local business with structured data, so sites get SEO-ready org content quickly.

It's a starter kit (installs config) built on the schemadotorg suite; run on a fresh/eval site. Depends on the schemadotorg suite, core `menu_ui`, and `config_rewrite`; supports Drupal 10.3+ and 11.

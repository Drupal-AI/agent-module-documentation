---

ScrollReveal JS integrates ScrollReveal.js — a JavaScript library for easily animating elements as they enter/leave the viewport — so builders can add reveal-on-scroll animations (fade, slide, scale) to elements without writing the animation code. Supports Drupal 8.8 through 11.

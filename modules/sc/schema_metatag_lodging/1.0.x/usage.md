Schema Metatag Lodging provides Schema.org support for the lodging industry.

---

Schema.org Lodging adds **Schema.org lodging-industry structured data** to the JSON-LD output — Hotel,
BedAndBreakfast and VacationRental types (via submodules) — extending Schema.org Metatag for accommodation
sites' rich results. It depends on the Schema.org Metatag module, in the SEO package.

Use it to mark up lodging content for search engines. It is an SEO feature adding structured-data metadata; it
reflects on-page content and has no content or access role. Configure the Schema.org lodging mappings.

Integrate the Scrollama scrollytelling library.

---

Scrollama JS integrates Scrollama — a modern, lightweight JavaScript library for scrollytelling using IntersectionObserver (in favour of scroll events) — so builders can create scroll-driven storytelling experiences (triggering steps/animations as elements enter the viewport) efficiently. Supports Drupal 8.8 through 11.

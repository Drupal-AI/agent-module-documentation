Schema.org/Occupation adds Occupation structured data to Schema Metatag JSON-LD.

---

Schema.org/Occupation adds the Schema.org Occupation type to the JSON-LD structured-data array produced by Schema Metatag — so content describing occupations/jobs can emit rich structured data that search engines use for enhanced results.

It's an SEO/structured-data submodule with no content or access role of its own. Depends on `schema_metatag`; supports Drupal 9, 10, and 11.

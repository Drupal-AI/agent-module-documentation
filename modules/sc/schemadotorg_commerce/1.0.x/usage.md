Schema.org Blueprints Commerce maps Commerce entities to Schema.org types via Blueprints.

---

Schema.org Blueprints Commerce integrates the Commerce module with Schema.org Blueprints — so Commerce products and related entities can be mapped to Schema.org types (Product, Offer, etc.) and emit rich structured data, improving SEO for e-commerce content built with Schema.org Blueprints.

It's an SEO/structured-data integration with no content or access role of its own. Depends on `commerce` and `schemadotorg`; supports Drupal 10.3+ and 11.

ScrollMagic integrates the ScrollMagic JavaScript library for magical scroll interactions.

---

ScrollMagic integrates the ScrollMagic JavaScript library — enabling scroll-based interactions and
animations (triggering effects, pins, parallax as the visitor scrolls). It ships a `scrollmagic_ui`
submodule for configuration, in the User interface package.

Use it to add scroll-driven animations/interactions. It is a front-end/UI feature affecting presentation
behaviour; it does not change content or access and has no access-control role. Configure the scroll scenes/
effects.

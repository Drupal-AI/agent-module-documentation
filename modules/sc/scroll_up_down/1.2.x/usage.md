Scroll Up Down adds two hover buttons for scrolling.

---

Scroll Up Down **adds hover buttons to scroll to the top and bottom of the page** — floating "scroll up"
and "scroll down" controls for long pages, improving navigation. It provides its own permissions, in the User
interface package.

Use it to add scroll-to-top/bottom controls. It is a front-end/UX feature affecting presentation; it has no
content or access role beyond its permission. Configure the scroll buttons.

Schema.org Blueprints Starter Kit: Podcast creates Schema.org PodcastSeries/PodcastEpisode content types with Views and RSS feeds.

---

Schema.org Blueprints Starter Kit: Podcast **scaffolds a podcast content model** — a Schema.org Blueprints
starter kit that creates `PodcastSeries` and `PodcastEpisode` content types (with Schema.org mappings), plus Views
and **RSS feeds** for publishing podcasts. It depends on the Schema.org Blueprints stack (schemadotorg,
schemadotorg_node), Podcast, EVA, EPP, Auto Entity Label, Config Rewrite and Views modules.

Use it to stand up a podcast section quickly. It is a content-model/site-building starter kit; it creates content
types/config and has no access-control role. Data-handling note: it publishes **RSS feeds** of podcast content
(designed to be public for podcast directories) — so only publish content intended to be public. As a starter kit,
review the generated types/config and adapt for production. Install it to scaffold the podcast model.

`schemadotorg`, `schemadotorg_node`, `podcast`, `eva`, `epp`, `config_rewrite`, `auto_entitylabel`,
`views_add_button`. Version **1.0.0-alpha37**. Core `^10.3||^11`.

Content-model/site-building starter kit — publishes **RSS feeds** (public for podcast directories; publish only
public content); review/adapt generated config for production. No access role.

Schema.org Accommodation emits Accommodation structured data via Schema Metatag.

---

Schema.org Accommodation adds the Schema.org Accommodation type to the JSON-LD structured-data array produced by Schema Metatag — so accommodation listings (rooms, lodgings) can emit rich structured data for search engines. It is the base type that Schema.org VacationRental and similar submodules build on.

It's an SEO/structured-data submodule with no content or access role of its own. Depends on `schema_metatag`; supports Drupal 9, 10, and 11.

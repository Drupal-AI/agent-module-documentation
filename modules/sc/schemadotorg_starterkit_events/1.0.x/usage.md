Schema.org Starter Kit Events creates an event content type.

---

Schema.org Starter Kit: Events **creates an Event content type with Schema.org mapping** — a ready-made
event setup (fields, Smart Date, views, default content) built on the Schema.org Blueprints module, so a site
gets standards-aligned events out of the box. It depends on Schema.org Blueprints (and its node/smart-date/
pathauto/starterkit submodules), core Views, Shortcut, Default Content, Smart Date and Views Add Button.

Use it to bootstrap Schema.org-aligned events. It is a site-building/starter-kit; it installs config (content
type/views/default content) that follows normal access, and it has no access-control role. Enable it to create
the events setup.

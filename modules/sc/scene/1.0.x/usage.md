Scene integrates the Scene.js timeline-based animation library.

---

Scene **integrates the Scene.js library** — a JavaScript/CSS timeline-based animation library for building
animated, sequenced website effects. It provides its own permissions, in the User interface package.

Use it to add timeline animations. It is a front-end/theming feature; it provides the Scene.js library and has no
content or access role beyond its permission. Use Scene.js in your theme/components.

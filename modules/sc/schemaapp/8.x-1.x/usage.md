Schema App provides integration with the Schema App service for adding schema.org structured data to a site.

---

Schema App integrates the Schema App platform — a hosted service for creating and managing
schema.org structured data — with Drupal, so pages emit rich structured data (JSON-LD) managed via
Schema App for improved search-engine rich results. It requires PHP 7.4 and is configured under
`admin/config/development/schema`.

Use it where structured-data/SEO is managed through Schema App rather than hand-built markup. It
connects to the Schema App service (account/credentials), so store any API credentials as secrets and
note that the integration involves the external Schema App service. It is an SEO/integration feature
producing structured-data markup; it has no access-control role. Keep emitted structured data accurate
to the page content.

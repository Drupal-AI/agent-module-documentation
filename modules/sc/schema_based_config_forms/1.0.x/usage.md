Schema Based Config Forms provides a foundation for building config forms from config schema.

---

Schema Based Config Forms **builds config forms from config schema** — a developer foundation that generates
configuration form elements based on a module's config schema, reducing hand-written settings forms. It works on
core 10.2–11.

Use it as a developer base for schema-driven config forms. It is a developer/framework feature; the forms are admin
config forms and it has no content or access role. Build config forms on this foundation.

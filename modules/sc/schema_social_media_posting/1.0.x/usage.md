Schema.org SocialMediaPosting adds the full Schema.org/SocialMediaPosting to the JSON-LD array.

---

Schema.org SocialMediaPosting adds the **Schema.org `SocialMediaPosting`** type to the **JSON-LD**
structured-data output — extending Schema.org Metatag so content representing social-media posts (and a
`LiveBlogPosting` submodule) is marked up for search engines/rich results. It depends on Schema.org Metatag
(schema_article), in the SEO package.

Use it to add SocialMediaPosting structured data. It is an SEO feature adding JSON-LD metadata to pages; it
reflects content already on the page and has no content or access role. Configure the Schema.org mappings.

A developer tool to view a database table's schema by name.

---

Schema Viewer provides a backend developer tool to view table schema by table name — so a developer can inspect the columns/structure of any database table from within Drupal, aiding debugging and understanding of the schema without a separate DB client.

As a schema-inspection tool it should be restricted to trusted developers/admins. Depends on core `system`; supports Drupal 9, 10, and 11.

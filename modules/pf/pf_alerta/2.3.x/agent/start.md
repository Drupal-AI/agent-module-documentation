# Push Framework Alerta — agent index

An **Alerta push-notification channel for the Push Framework** (deliver Push campaigns via Alerta). Depends on
`push_framework`. Version **2.3.1**. Core `^10||^11`.

Notifications/integration — handle any Alerta **API credentials** as secrets (Key/env, HTTPS). No access
role.

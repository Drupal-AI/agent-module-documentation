Push Framework Alerta is a push notification channel for the Push Framework.

---

Push Framework Alerta adds an **Alerta channel to the Push Framework** — so Push Framework campaigns can
deliver notifications via **Alerta** (an alerting/monitoring notification system), alongside its other
channels. It depends on the Push Framework module, in the Push package.

Use it to route Push Framework notifications through Alerta. It is a notifications/integration feature. If it
talks to an Alerta API endpoint, handle any **API key/credentials** as secrets (env/Key, HTTPS). It has no
access-control role. Configure the Alerta channel.

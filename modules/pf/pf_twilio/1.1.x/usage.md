Push Framework Twilio adds Twilio SMS as a delivery channel for the Push Framework.

---

Push Framework Twilio adds Twilio as a mobile/SMS delivery channel for the Push Framework — so notifications sent through the Push Framework can be delivered as SMS messages via Twilio, extending push delivery to phone numbers.

Twilio API credentials should be stored securely (env-backed); sending SMS incurs Twilio cost. Depends on core `user` and `push_framework`; supports Drupal 10 and 11.

An API for various music streaming services.

---

Musica provides an API for various music streaming services — a unified client layer so Drupal modules can query multiple music-streaming providers (search tracks, fetch metadata) through one interface.

Each provider's API credentials are admin-configured and should be stored securely (env-backed), never committed. Supports Drupal 10 and 11.

Multilingual plus extends the multilanguage features of the site, adding utilities on top of core multilingual.

---

Multilingual plus extends Drupal's multilanguage features — adding utilities/enhancements on top of core
multilingual (language handling, translation helpers or language-related conveniences) to smooth
multilingual site building. It is in the Language package.

Use it to augment core multilingual behaviour. It is a multilingual feature; its enhancements affect language
handling/translation presentation and it has no access-control role. Configure the multilingual
enhancements as needed.

# Multivalue Field Restriction — agent index

Restricts **how many values of a multivalue field are displayed** (e.g. first 3 tags) — applied at
display; all values remain stored. Version **8.x-1.7**. Core `^8||^9||^10||^11`.

Presentation only (no data/access change) — other display paths still show all values. Configure the
limit on the field's display settings.

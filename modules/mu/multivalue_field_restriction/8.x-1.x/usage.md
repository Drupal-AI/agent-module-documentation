Multivalue Field Restriction limits the number of values shown for multivalue fields on display.

---

Multivalue Field Restriction limits how many items of a multi-value field are rendered — for
example showing only the first 3 tags, authors or images of a field that may hold many. It is applied
at display, so the field can store any number of values while the output is capped, useful for teasers,
compact listings or summaries where showing every value would be cluttered.

Use it to keep multi-value field output tidy in listing or teaser contexts. It is a
display/presentation feature; it changes what is rendered, not the stored data or access — all values
remain in the field and are accessible through paths that don't apply this restriction. Configure the
limit on the field's display settings.

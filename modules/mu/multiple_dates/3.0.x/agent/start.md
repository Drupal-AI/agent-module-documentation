# Multiple Dates — agent index

An **advanced multiple-date picker field** (select several individual dates via a calendar; **no external JS
library**). Depends on core `field`. Version **3.0.1**. Core `^10||^11`.

Fields/content-editing — dates stored as normal field values; no content/access role.

Multiple Dates provides an advanced multiple date picker field with no external library dependencies.

---

Multiple Dates provides an **advanced multiple-date picker field** — a field/widget that lets editors
select several individual dates (not just a range) through a calendar picker, implemented **without external
JavaScript library dependencies**. It depends on core Field, in the Multiple Dates package.

Use it where content needs a set of specific dates (event dates, availability, closures). It is a fields/
content-editing feature; the dates are stored as normal field values and it has no content or access role. Add
the multiple-dates field to a bundle.

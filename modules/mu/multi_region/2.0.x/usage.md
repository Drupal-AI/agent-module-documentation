Multi Region provides a multi-region content solution for Drupal.

---

Multi Region **provides a multi-region solution** — supporting content/configuration that varies by
geographic region (region-specific pages/variants), often combined with language, for sites serving multiple
regions. It depends on core Language and provides its own permissions.

Use it to run region-specific content. It is a site-building/content feature; it scopes content by region and has
no access-control role beyond its permission. Note: if regions are used to segment content, verify region logic
composes with your access/publishing needs. Configure the regions.

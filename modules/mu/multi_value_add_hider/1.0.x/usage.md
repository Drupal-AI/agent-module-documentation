Multi Value Add Hider prevents the automatic display of an empty add form.

---

Multi Value Add Hider **prevents the automatic empty "add another" row** on multi-value field widgets —
so an unlimited-cardinality field doesn't always show an extra blank row, tidying the edit form. It depends on
core Field, in the Fields package.

Use it to tidy multi-value field entry. It is a content-editing/form feature affecting the widget display; it
has no content or access role. Configure it on the relevant multi-value fields.

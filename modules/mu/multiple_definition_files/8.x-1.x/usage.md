Multiple Definition Files enables multiple definition files for theme asset libraries and layouts.

---

Multiple Definition Files lets themes/modules split their asset-library (`*.libraries.yml`) and layout
(`*.layouts.yml`) definitions across **multiple** files instead of one large file — so large libraries/layout
sets can be organized into separate, maintainable definition files. It depends on core Layout Discovery.

Use it to organize library/layout definitions across files. It is a developer/theming feature affecting how
definitions are loaded; it has no content or access role. Split your definitions into multiple files as
needed.

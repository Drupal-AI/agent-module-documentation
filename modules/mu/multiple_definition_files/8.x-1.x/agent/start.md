# Multiple Definition Files — agent index

Enables **splitting theme asset-library (`*.libraries.yml`) and layout (`*.layouts.yml`) definitions across
multiple files** (organize large sets into maintainable files). Depends on core `layout_discovery`. Version
**8.x-1.3**. Core `^8||^9||^10||^11`.

Developer/theming — affects how definitions are loaded; no content/access role.

Multilingual Google Web Page Language Translator adds a Google Translate widget/block so visitors can translate the page into their selected language client-side.

---

Multilingual Google Web Page Language Translator adds the Google Website Translate widget as a block
— visitors pick a language and Google's client-side widget translates the current page in the browser.
It is a quick way to offer on-the-fly translation into many languages without building real Drupal
translations. It is configured at `multilingual_google_web_translator.settings`.

Use it when full content translation isn't feasible and machine translation in the visitor's browser is
"good enough" for accessibility/reach. Note the trade-offs: translation happens through Google's
client-side widget, so page content is processed by Google's service (a privacy/data consideration to
disclose), the translation quality is machine-level, and it is a display convenience rather than
genuine multilingual content (no translated URLs, SEO, or editorial control). It has no access-control
role.

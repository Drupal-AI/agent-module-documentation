# Multilingual Google Web Page Language Translator — agent index

**Google Translate block/widget** — visitors pick a language and Google's **client-side** widget
translates the page. Config at `multilingual_google_web_translator.settings`. Version **11.0.1**. Core
`^10||^11`.

Display convenience (machine translation, no translated URLs/SEO/editorial control). **Privacy:** page
content is processed by Google's client-side service — disclose accordingly. No access role.

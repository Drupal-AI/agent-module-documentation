Musaed integrates the Musaed accessibility tool.

---

Musaed **integrates the Musaed accessibility tool** — adding the Musaed accessibility assistant/widget to the
site to help users with accessibility needs. It works on core 10–11.

Use it to add the Musaed accessibility widget. It is an accessibility feature; it adds the third-party Musaed
tool/widget and has no content or access role. Note: it may load a third-party script — confirm privacy/consent
implications. Configure the Musaed integration.

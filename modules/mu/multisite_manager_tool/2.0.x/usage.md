Multisite Manager Tool simplifies the management of multisite installations.

---

Multisite Manager Tool is designed to **simplify managing Drupal multisite installations** — providing
tooling to oversee/administer multiple sites in a multisite setup from one place. It provides its own
permissions.

Use it to manage a multisite setup. It is a powerful **administration** feature. Security note: a tool that
manages **multiple sites** is a high-privilege capability (actions can affect several sites at once), so gate
its permission to **fully-trusted administrators** only, and be aware that cross-site management concentrates
risk. It has no other access-control role beyond its permission. Configure the multisite management.

# Multisite Manager Tool — agent index

Simplifies **management of Drupal multisite installations** (oversee multiple sites from one place). Provides
permissions. Version **2.0.0**. Core `^10||^11`.

**Administration** — a high-privilege, cross-site management capability: gate the permission to **fully-trusted
admins** only (actions can affect several sites; concentrates risk). No other access role beyond permission.

Muuri integrates the Muuri responsive draggable grid-layout library.

---

Muuri **integrates the Muuri JavaScript library** — a responsive, sortable, filterable, draggable grid-layout
library, for building dynamic card/grid layouts in the front end. It works across core 8–11.

Use it to build Muuri-based grid layouts. It is a front-end/theming feature; it provides the Muuri library and has
no content or access role. Use Muuri in your theme/components.

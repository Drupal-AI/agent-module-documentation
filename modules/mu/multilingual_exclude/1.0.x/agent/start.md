# Multilingual exclude — agent index

**Excludes selected pages/routes from translation handling** (keep admin/API/utility paths out of the
multilingual URL/language scheme). Config at `multilingual_exclude.settings`; provides permissions. Version
**1.0.0-alpha3**. Core `^9||^10||^11`.

Multilingual/routing — affects which routes participate in translation; no content/access change. No access
role.

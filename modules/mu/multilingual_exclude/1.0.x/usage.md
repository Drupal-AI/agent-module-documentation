Multilingual exclude allows excluding pages and routes from translations.

---

Multilingual exclude lets you exclude specific pages/routes from translation handling — so certain
routes are not treated as translatable/language-prefixed (e.g. admin, API or utility paths that shouldn't be
part of the multilingual URL scheme). It is configured at `multilingual_exclude.settings`, provides its own
permissions, in the Administration package.

Use it to keep certain routes out of the multilingual system. It is a multilingual/routing feature affecting
which routes participate in translation/language negotiation; it does not change content or access and has no
access-control role. Configure the excluded routes.

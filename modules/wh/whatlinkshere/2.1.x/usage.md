What Links Here shows content references to node, taxonomy term and media entities, detecting references from text, link and entity-reference field types on nodes.

---

What Links Here reports the inbound references to an entity — which content links to or references a
given node, taxonomy term or media item. It scans text, link and entity-reference field types on Node
entities to find references, so before changing or deleting an entity an editor can see what depends on
it (avoiding broken links and dangling references). It provides Drush commands and its own permissions.

Use it as an editorial/maintenance aid to understand content relationships and the impact of removing
or moving an item. It reads content to build the reference report; it is an informational tool with no
access-control role (it surfaces references the viewing user is otherwise entitled to see). Handy when
auditing before content deletion or restructuring.

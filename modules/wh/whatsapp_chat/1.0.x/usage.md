WhatsApp Chat adds a floating WhatsApp click-to-chat widget for agents/teams.

---

WhatsApp Chat provides a floating WhatsApp chat widget for a Drupal site — a click-to-chat button that opens a WhatsApp conversation with a single agent or a whole team (multiple agents), so visitors can quickly reach support/sales via WhatsApp. Agent details/avatars are configurable.

It opens WhatsApp with the configured number(s) (no server-side data handling of the chat itself). Administration is gated by `administer whatsapp_chat`. Depends on core `block` and `file`; supports Drupal 10 and 11.

WhatsApp Formatter provides a field formatter for the telephone field type to format numbers as WhatsApp links.

---

WhatsApp Formatter provides a **field formatter for the telephone field type** that renders a phone number
as a **WhatsApp chat link** (a `wa.me`/`https://wa.me/…` link that opens a WhatsApp conversation), so a stored
phone number becomes a click-to-chat link. It depends on core Telephone, in the Fields package.

Use it to turn phone-number fields into WhatsApp links. It is a content-display/formatter feature affecting how
the number renders; it has no content or access role. Note the number is exposed as a public WhatsApp link
(don't apply it to numbers that shouldn't be public). Choose the WhatsApp formatter on a telephone field.

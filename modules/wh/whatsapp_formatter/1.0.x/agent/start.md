# WhatsApp Formatter — agent index

A **telephone field formatter that renders numbers as WhatsApp chat links** (`wa.me` click-to-chat). Depends on
core `telephone`. Version **1.0.3**. Core `^10||^11`.

Content-display/formatter — affects rendering; exposes the number as a **public WhatsApp link** (don't apply to
private numbers); no content/access role.

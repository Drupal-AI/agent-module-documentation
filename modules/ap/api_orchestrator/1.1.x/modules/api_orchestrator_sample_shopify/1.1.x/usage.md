A ready-to-use Shopify Storefront GraphQL sample for API Orchestrator, backed by the public mock.shop endpoint.

---

This sample installs an API Orchestrator GraphQL integration against Shopify's public mock.shop endpoint, with endpoints for product listing, product detail, collections and search that work out of the box. It demonstrates GraphQL queries, variables and operation names, and pairs with the Mirror submodule to display products as a listing. Requires `api_orchestrator`, `api_orchestrator_integration_samples` and `api_orchestrator_mirror`.

---

- Try Shopify Storefront GraphQL with no account or API key.
- See how GraphQL query/variables/operation are modeled on an endpoint.
- List products from the mock.shop storefront.
- Fetch a single product's detail by handle/id.
- Browse collections.
- Run a product search query.
- Mirror Shopify products into a filterable, sortable listing.
- Use it as a template for a real Shopify Storefront integration.

# Free-form documentation for Apigee (apigee_freeform_doc) — agent index

**Experimental** submodule of [apigee_api_catalog](../../../../3.1.x/agent/start.md). Package is
`Apigee (Experimental)`.

Key facts:
- Dependencies: `apigee_api_catalog`, core `file`, `file_link`, `text`.
- Adds support for documenting APIs in this format alongside the parent module's OpenAPI-based
  `apidoc` nodes; node creation, access, revisions and the catalogue UI all come from the parent.
- No configuration, permissions, config schema or Drush commands of its own.
- Being experimental, expect field names and rendering to change between releases — pin the
  version if you depend on it.

# Group finder — agent index

Pluggable **API for locating the relevant Group** in different scenarios (finder plugins: group-by-content,
group-by-route, create-group). Depends on `group`. Version **2.1.0-alpha1**. Core `^10||^11`.

Developer/API helper — **locates** groups, does not grant/check access (group membership/permissions still
govern). No access role of its own.

Group Features lets admins enable/disable feature sets per group type.

---

Group Features lets administrators manage 'features' per group type — toggling optional capabilities on and off for each group type from an admin UI (`/admin/group/types/manage/{group_type}/features`). It builds on the Flexible Permissions system to structure what each group type offers.

Administration is gated by `administer group_feature`. Depends on `group` and `flexible_permissions`; supports Drupal 10 and 11.

Graupl Libraries provides common Graupl libraries.

---

Graupl Libraries provides **common Graupl JavaScript libraries** — bundling the Graupl accessible-menu
library so other modules/themes can depend on it for keyboard/ARIA-accessible dropdown menus, in the Graupl
package.

Use it as a shared library dependency for Graupl-based menus. It is a theming/front-end library provider; it has
no content or access role. Depend on it from a module/theme that uses Graupl.

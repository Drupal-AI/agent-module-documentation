Gradient provides a gradient builder form element.

---

Gradient provides a **gradient-builder form element** — a UI widget for composing a CSS gradient (colors,
stops, direction), for use in page-building/theming configuration where an editor picks a gradient. It is in
the Page Building package.

Use it to let editors build CSS gradients. It is a form-element/theming utility; the gradient value is
admin/editor-configured (a CSS value — output it safely where used) and it has no content or access role. Use
the gradient element in your forms/config.

Group relationship tokens provides tokens for entities referenced by group relationships, for use in the Group module.

---

Group relationship tokens provides tokens for the entities referenced by Group relationships — so
token-based text (emails, messages, patterns) can reference the group or group-content entities involved in
a relationship (e.g. the group a piece of content belongs to, or a member). It depends on the Group module.

Use it on Group-based sites where tokens need to reference group relationships. It is a developer/tokens
feature exposing group-relationship data as tokens; the token values reflect existing group relationships
and it has no access-control role. Use the tokens where group-relationship data is needed.

# GraphQL (graphql) — agent index

**Framework for building GraphQL servers on Drupal.** Depends on `typed_data`; bundles
`webonyx/graphql-php` as the executor. Configure route: `entity.graphql_server.collection`
(`/admin/config/graphql`). A bare install has the plugin types + the server config entity but
**no servers and no usable schema** — you write a schema, or enable the `graphql_composable`
submodule (schema id `composable_example`) for a working endpoint. 5.1.x is architecturally
identical to 5.0.x.

Central object = the **`graphql_server` config entity** (class `Drupal\graphql\Entity\Server`,
config prefix `graphql_servers`): it names a Schema plugin, holds `schema_configuration`, and
declares an `endpoint` path. On save, `RouteProvider::routes()` mints the JSON route
`graphql.query.<server_id>` at that path (controller `RequestController::handleRequest`).

- The `graphql_server` config entity, its keys, the endpoint route, drush/admin UI → [configure/servers.md](configure/servers.md)
- The four plugin types (Schema, SchemaExtension, DataProducer, PersistedQuery) → [plugins/plugin-types.md](plugins/plugin-types.md)
- Write a schema / extension / data producer (SDL + resolvers) → [extend/build-a-schema.md](extend/build-a-schema.md)
- Services, entity API, executing operations programmatically → [api/services.md](api/services.md)
- The access model: dynamic per-server permissions + endpoint CSRF handling → [permissions/access.md](permissions/access.md)
- Drush commands (`graphql:dump`, `graphql:detect-breaking-changes`) → [drush/commands.md](drush/commands.md)

Key names: config entity `graphql_server` (id key = `name`; config keys `schema`, `endpoint`,
`schema_configuration`, `caching`, `batching`, `disable_introspection`, `query_depth`,
`query_complexity`, `debug_flag`, `persisted_queries_settings`). Endpoint route
`graphql.query.<id>`, controller `Drupal\graphql\Controller\RequestController::handleRequest`,
access check `_graphql_query_access` (`QueryAccessCheck`), route enhancer `QueryRouteEnhancer`.
Plugin managers: `plugin.manager.graphql.schema`, `.schema_extension`, `.data_producer`,
`.persisted_query`. Base classes `SdlSchemaPluginBase`, `ComposableSchema`,
`SdlSchemaExtensionPluginBase`, `DataProducerPluginBase`. Static permissions
`administer graphql configuration`, `bypass graphql access`; per-server permissions generated by
`PermissionProvider`. Submodules: `graphql_composable`, `graphql_examples` (under `examples/`).

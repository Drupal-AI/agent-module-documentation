Group Media Library Extra provides extra functionality for group media.

---

Group Media Library Extra adds **extra functionality to Group Media Library** — enhancing how media is
managed within Groups (group-scoped media), with a `group_media_library_extra_groupmedia` submodule. It depends
on the Group Media Library module, in the Group package.

Use it on Group-based sites to improve group media management. It is a media/Group integration feature; media
access within groups follows **Group / Group Media Library** access, and it has no access-control role of its
own. Enable it alongside Group Media Library.

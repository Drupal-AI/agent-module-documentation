# Group Computed Field — agent index

Adds a **computed field referencing the group(s) an entity belongs to** (from Group relationships) — for
Views/displays/logic on Group sites. Depends on `group`. Version **3.0.1**. Core `^10||^11`.

Fields/access-adjacent — reflects existing group memberships; does **not** grant access (Group's controls
govern).

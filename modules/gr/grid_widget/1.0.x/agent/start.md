# Grid Widget — agent index

Field **widget** rendering checkboxes/radios in a **CSS-grid** layout for text, numeric and entity reference fields. Version **1.0.1**. Core `^8.7.7 || ^9 || ^10`.

- Plugin: `OptionsGridWidget` (`src/Plugin/Field/FieldWidget/`), extends core options widget; select in Manage form display.
- Depends on `field`, `text`. Display-layer only — no access-control role.

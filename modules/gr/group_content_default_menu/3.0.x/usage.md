Group Content Default Menu auto-configures menus for groups using Group Content Menu.

---

Group Content Default Menu automatically configures group menus — setting up default group-content menus so new groups get a working menu structure without manual configuration. It builds on the Group Content Menu module.

Administration is gated by `administer group content default menu`; group access follows the Group module. Depends on `group` and `group_content_menu`; supports Drupal 10 and 11.

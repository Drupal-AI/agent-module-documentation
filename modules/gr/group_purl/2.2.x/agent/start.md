# group_purl — agent index

A **Persistent URL (PURL) provider for the Group module** (derive the active group from a URL modifier —
prefix/domain). Depends on `group`, `purl`. Version **2.2.1**. Core `^9||^10||^11`.

Site-structure/group-context — **resolves** the active group from the URL but relies on Group's membership/
permissions for access (doesn't grant). No access role of its own.

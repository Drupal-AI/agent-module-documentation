Relate referenced entities to the same groups as the referencing content.

---

Group relationship inheritance relates each referenced entity to the same groups as the referencing content — so when a node that belongs to a Group references other entities, those referenced entities are automatically added to the same group(s), keeping related content grouped together for access. Depends on `group`; supports Drupal 10 and 11.

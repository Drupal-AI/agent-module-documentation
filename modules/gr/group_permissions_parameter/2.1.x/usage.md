Set group permissions based on custom parameters.

---

Group Permissions parameter allows setting group permissions based on custom parameters, using the Group Permissions module — so a group's effective permissions can vary by contextual parameters (e.g. a field value or state) rather than being fixed, enabling more dynamic group access rules. Depends on `group_permissions`; supports Drupal 10.3+ and 11.

# Group Scheduled Transitions — agent index

Lets **group members use Scheduled Transitions** to schedule content-moderation state changes (auto-publish/
unpublish) on group content, governed by group permissions. Depends on `group`, `scheduled_transitions`.
Version **3.0.0**. Core `^10.3||^11`.

Editorial-workflow/Group integration — who may schedule is governed by **group permissions**; no access role
of its own.

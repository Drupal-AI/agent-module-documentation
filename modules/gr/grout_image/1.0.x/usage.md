Grout API fallback images (avatars/placeholders) for empty media fields.

---

Grout Image provides Grout API fallback images (avatars and placeholders) for empty media fields — with a Twig filter/function and a field formatter sized to match your image styles — so content with no image still shows a consistent generated avatar/placeholder instead of a broken/blank image. Depends on core `media`, `field`, and `system`; supports Drupal 10 and 11.

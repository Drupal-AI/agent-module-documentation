Group Permissions Template applies a defined permission template to a group.

---

Group Permissions Template lets you **define reusable permission templates and apply them to Groups** —
using the Group Permissions module to stamp a predefined set of group-role permissions onto one or many groups,
so group configuration is consistent and repeatable. It depends on the Group and Group Permissions modules,
provides its own permissions, in the Group package.

Use it to standardize group permissions at scale. It is an access-control **administration tool** — it configures
group permissions (a privileged action), so gate its permissions to trusted admins; the actual runtime
access enforcement is done by **Group / Group Permissions** (this just applies templates to them). Because
applying a template can change what group members can do, review templates carefully before bulk-applying. It
adds no runtime access decision of its own. Configure and apply the permission templates.

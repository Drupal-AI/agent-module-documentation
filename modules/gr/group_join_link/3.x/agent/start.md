# Group Join Link (group_join_link) — agent index

Adds a **join/leave link field for a Group**. Version **3.0.2**. Depends on Group.

Works within Group's permission model — the link surfaces an allowed action (no bypass of join
rules). **Note:** joining can grant access to group content — confirm the group's **join settings**
(open-join = anyone can join and gain that access).

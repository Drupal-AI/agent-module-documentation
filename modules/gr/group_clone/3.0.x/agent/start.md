# Group Clone — agent index

**Allows cloning a Group and its content** (duplicate a group from a template). Depends on `group`. Provides
permissions. Version **3.0.0-alpha3**. Core `^10||^11`.

Site-building/Group — cloning is **privileged** (copies content/membership): gate the permission, review what's
copied. Layers on Group's access.

Group Clone allows cloning a group and its content.

---

Group Clone **allows cloning a Group and its content** — duplicating a group entity (and optionally its
members/content relationships) to quickly spin up a new group from a template. It depends on the Group module,
provides its own permissions, in the Group package.

Use it to duplicate groups. It is a site-building/Group feature. Security note: cloning is a **privileged
action** — it creates group content and can copy membership/relationships, so gate its permission to trusted
roles and be mindful that cloned content inherits the source's data (review what gets copied, especially any
sensitive group content). It layers on Group's own access. Configure and use the clone action.

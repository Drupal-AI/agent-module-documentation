# GridStack (gridstack) — agent index

**GridStack.js** drag-and-drop multi-column grid layouts. Version **3.0.3**. Core `>=9.4`.
Submodules `gridstack_layouts` (Layout Builder layouts), `gridstack_ui`, `gridstack_example`.

Sits on Layout Builder — editors compose a page as a draggable/resizable grid. Restrict the
layout-building UI to appropriate roles; serve the JS library locally if third-party origins are a
concern.

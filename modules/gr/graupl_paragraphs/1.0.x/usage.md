Graupl Paragraphs provides paragraph behaviors for the Graupl framework.

---

Graupl Paragraphs **provides a set of paragraph behaviors for the Graupl framework** — behavior plugins that
add layout/styling controls to Paragraphs when building pages with the Graupl front-end framework. It depends on
the Paragraphs module.

Use it when building with Graupl + Paragraphs. It is a site-building/theming feature; behaviors add configuration
to paragraphs and it has no content or access role. Configure the paragraph behaviors.

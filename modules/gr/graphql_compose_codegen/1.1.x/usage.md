GraphQL Compose Codegen generates client code/types from the GraphQL Compose schema.

---

GraphQL Compose Codegen **generates client code/types from the GraphQL Compose schema** — producing typed
artifacts (e.g. TypeScript types/operations) for the site's GraphQL schema so decoupled front ends can consume it
with type safety. It depends on the GraphQL Compose module and provides its own permissions.

Use it as a developer tool for schema codegen. It is a developer/decoupled feature; it reads the schema and emits
code (developer-facing) and has no content or access role beyond its permission. Note: the generated schema
artifacts describe your API surface — treat them like API documentation. Configure the codegen output.

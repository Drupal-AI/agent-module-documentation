Graupl Components provides a library of components using Graupl.

---

Graupl Components provides a **library of UI components built on the Graupl libraries** — reusable
components (notably accessible menus/navigation) usable via Layout Builder and UI Patterns. It depends on Graupl
Libraries, core Layout Discovery, Layout Builder and UI Patterns, in the Graupl package.

Use it to add Graupl-based accessible components. It is a theming/site-building feature; components are theme/
authoring constructs and it has no content or access role. Use the components in layouts/patterns.

# Group Domain — agent index

Maps the **current domain to a Group** and its content (multi-domain/multi-tenant Group sites). Depends
on `group`. Version **3.0.3**. Core `^9||^10||^11`.

Site-structure/access-adjacent — ties a domain to a group's content/context. Verify the mapping matches
intended isolation; Group's own access controls still govern member actions.

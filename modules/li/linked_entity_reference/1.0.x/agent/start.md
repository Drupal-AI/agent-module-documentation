# Linked Entity Reference — agent index

Entity reference **field that also relates the entity to an arbitrary URL** (reference + link — linked
logos/sponsors/read-more). Depends on core `link`; `linked_entity_reference_slick` submodule for Slick
display. Version **1.0.1**. Core `^10||^11`.

Fields/content — reference respects entity access; authored URLs rendered via Drupal (validate/escape).
No access role.

Linked Entity Reference lets you relate an entity with an arbitrary URL through a field, combining an entity reference with a link.

---

Linked Entity Reference provides a field that relates an entity to an arbitrary URL — combining an
entity reference with a link, so a referenced item can carry an associated URL (e.g. reference a term/
node and attach a "read more" or external link to it). It depends on core Link and ships a
`linked_entity_reference_slick` submodule for Slick-carousel display.

Use it where references need an accompanying link (linked logos, sponsors with URLs, referenced items
with external destinations). It is a fields/content feature; the reference respects entity access and
the URL is authored, rendered through Drupal's layers — validate/escape user-entered URLs as normal. It
has no access-control role.

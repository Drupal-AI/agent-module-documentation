Link As Popup lets link fields open in a popup/modal via extra target options.

---

Link As Popup extends the core Link field with additional target-attribute options — including opening the linked destination in a popup/modal — so editors can control link behavior (new tab, popup) per link without custom code.

It's a link-field/display enhancement with no content or access role of its own. Depends on core `link`; supports Drupal 10 and 11.

Attach asset libraries using YAML definitions.

---

Library renderer provides functionality for attaching libraries using YAML definitions — so a site builder can declare which asset libraries (CSS/JS) to attach in configuration/YAML rather than in code or preprocess hooks, simplifying library management. It's a developer/site-building helper. Supports Drupal 10 and 11.

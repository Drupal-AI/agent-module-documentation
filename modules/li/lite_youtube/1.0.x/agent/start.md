# Lite YouTube — agent index

A **lightweight, privacy-friendlier YouTube field formatter** — a click-to-load facade (thumbnail + play) that
only loads the player/iframe on click. Depends on `youtube`. Version **1.0.2**. Core `^8.9||^9||^10||^11`.

Media/performance — video loads from **YouTube** on click (usual third-party embed note, deferred until click);
no content/access role.

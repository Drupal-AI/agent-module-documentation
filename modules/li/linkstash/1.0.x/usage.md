A personal bookmarking tool with metadata fetching and categorization.

---

LinkStash is a personal bookmarking tool with automatic metadata fetching, categorization, and video embeds — so users can 'stash' links, and the module fetches each link's title/description/thumbnail, organises them by taxonomy category, and embeds videos. Depends on core `link`, `image`, `taxonomy`, `text`, and `views`; supports Drupal 11.

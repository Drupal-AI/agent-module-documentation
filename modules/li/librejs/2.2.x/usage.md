LibreJS indicates which JavaScript used by the site is software-libre.

---

LibreJS **labels the site's JavaScript as free (libre) or non-free** for the GNU LibreJS browser extension
— adding the license/labels LibreJS looks for so privacy-conscious users running LibreJS can see the site's JS
is free software and run it. It provides its own permissions, requires core 11.1+.

Use it to declare your JavaScript's licensing for LibreJS. It is a compliance/labeling feature affecting how JS
is annotated; it has no content or access role beyond its permission. Configure the JavaScript labels.

---

Link Magician **tidies links in rich-text fields** — cleaning up and normalizing links in body/rich-text
content (e.g. fixing/aliasing internal links, integrating with Redirect), so content links stay tidy and correct.
It depends on core Media, Path Alias and the Redirect module.

Use it to keep content links clean. It is a content-editing/site-building feature; it rewrites links in output and
has no access-control role. Configure the link-tidying behavior.

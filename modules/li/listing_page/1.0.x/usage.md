Create configurable listing pages for entities.

---

Listing page creates listing pages for entities — a configurable way to generate index/listing pages (filtered, sorted lists of nodes/entities) driven by Views and tokens, so site builders can spin up directory/archive pages without building each View by hand. Depends on core `field`, `views`, and `token`; supports Drupal 11.

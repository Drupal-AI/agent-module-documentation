Link Augmenter provides a plugin to inject links into date displays (Date Augmenter).

---

Link Augmenter provides a Date Augmenter plugin that injects links into rendered date displays — for
example turning an event date into an "add to calendar" or details link, augmenting how dates are shown. It
depends on the Date Augmenter module, in the Date Augmenter package.

Use it to add links to date field displays via Date Augmenter. It is a content-display feature augmenting
date rendering; the links are configured/derived and it has no access-control role. Configure the Date
Augmenter with the link plugin.

# Link Augmenter (link_augment) — agent index

A **Date Augmenter plugin that injects links into date displays** (e.g. add-to-calendar/details link on an
event date). Depends on `date_augmenter`. Version **1.0.1**. Core `^8||^9||^10||^11`.

Content-display — augments date rendering with links; no access role.

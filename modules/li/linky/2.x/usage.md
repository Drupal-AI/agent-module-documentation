Linky provides a link-management entity — external links stored as entities so they can be referenced, tracked and managed centrally.

---

External links scattered across content are hard to update or audit — a URL that changes must be found and fixed everywhere. Linky stores external links as entities, so a link is a managed thing that content references, and updating it once updates every reference. It is a content-modelling/link-management tool. No unusual security surface; managing external links centrally can actually help audit outbound links. Confirm that link entities respect the access model you want if some links are internal-only.

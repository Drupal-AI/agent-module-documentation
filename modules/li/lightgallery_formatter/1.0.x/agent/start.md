# LightGallery Formatter — agent index

A **media field formatter that displays media in a lightGallery lightbox** (thumbnails → full-screen gallery,
zoom/swipe). Depends on core `media`. Provides permissions. Version **1.0.9**. Core `^10.3||^11`.

Media/content-display — media follows core media/file access; no access role beyond permission.

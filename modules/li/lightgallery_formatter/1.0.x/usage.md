LightGallery Formatter provides a field formatter to display media fields using lightGallery.

---

LightGallery Formatter provides a **media field formatter using lightGallery** — rendering a media field
as a lightGallery lightbox (thumbnails that open a full-screen gallery with zoom/swipe). It ships demo and
preview submodules, depends on core Media, provides its own permissions, in the LightGallery package.

Use it to present media fields as a lightGallery. It is a media/content-display feature; the media follows
core media/file access and it has no access-control role beyond its permission. Choose the LightGallery
formatter on a media field.

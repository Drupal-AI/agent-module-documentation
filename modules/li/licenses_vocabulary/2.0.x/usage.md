Licenses vocabulary provides a taxonomy of licenses (e.g. Creative Commons) as importable terms.

---

Licenses vocabulary provides a taxonomy vocabulary of licenses as terms — a ready-made set of license definitions (e.g. Creative Commons, open-source licenses) that can be imported and referenced from content, so assets/content can be tagged with a standard license.

Importing terms is gated by `import licenses`. It's a taxonomy content module; depends on core `taxonomy`; supports Drupal 10.1+ and 11.

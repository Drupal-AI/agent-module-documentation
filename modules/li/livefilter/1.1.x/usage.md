LiveFilter provides a block for client side filtering.

---

LiveFilter **provides a block for client-side live filtering** — a search box that filters an on-page list
(e.g. a list of items) instantly in the browser as the user types, without a server round-trip. It works across
core 9–11.

Use it for quick in-page list filtering. It is a content-display/UX feature. Note: because it filters
**client-side on already-rendered content**, it is a presentation convenience — all filterable items are already
sent to the browser, so it must not be used to "hide" sensitive rows (only render rows the user may see). It has
no access-control role. Configure the live filter block.

# Link Field Display Mode Formatter — agent index

Link-field **formatter rendering the linked entity in a chosen display mode** (embed the target as teaser/
card vs plain link). Depends on core `link`. Version **8.x-1.7**. Core `^9||^10||^11`.

Content-display/formatter — linked entity rendered respecting its own access (only accessible targets
render); no access role.

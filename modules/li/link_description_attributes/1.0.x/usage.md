Add the Link Attributes widget to Link with description fields.

---

Link with description - Attributes extends the 'Link with description' module with the 'Link Attributes widget' — so a link field that already has a description can also set link attributes (rel, target, class, etc.) via the Link Attributes UI, combining both features. Depends on `link_attributes` and `link_description`; supports Drupal 10 and 11.

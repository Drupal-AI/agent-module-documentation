# Link Param Propagator — agent index

Appends **configured query parameters to anchor tags within a specific DOM element** (carry UTM/campaign/
tracking params onto links). Config at `link_param_propagator.settings`. Version **1.0.1**. Core `^10||^11`.

SEO/front-end — rewrites link hrefs client-side with admin-configured params; no content/access change. No
access role.

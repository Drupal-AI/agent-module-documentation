Link Selection Handler provides a link widget for selecting links.

---

Link Selection Handler provides a **link field widget for selecting links** — letting editors choose a link
from an allowed set/handler (rather than free-typing any URL) on a Link field, for controlled linking. It
depends on core Link, in the Field widgets package.

Use it to constrain link-field values to allowed options. It is a content-editing/fields feature affecting the
widget; it has no content or access role. Configure the selection handler on a link field.

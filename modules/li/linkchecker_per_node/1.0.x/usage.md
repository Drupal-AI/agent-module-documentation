Link Checker Per Node checks a node's links and reports broken ones on a per-node basis.

---

Link Checker Per Node **checks links in a node and reports broken links** — extending the Link Checker module
to scan an individual node's links and surface broken-link reports per node, for editorial link maintenance. It
depends on the Link Checker module and provides its own permissions.

Use it to find broken links per node. It is a content-maintenance feature; it scans links (making outbound
requests, like Link Checker) and reports results (editor-facing) and has no access-control role beyond its
permission. Configure per-node link checking.

Link Advance Attributes adds advanced attributes (e.g. icons/image bundles) to link fields.

---

Link Advance Attributes **adds advanced attributes to link fields** — extending the core Link field with extra
attributes such as icons/image bundles, so links can carry richer presentation metadata. It depends on core Link,
Media and Media Library.

Use it to enrich link fields with attributes/icons. It is a content-editing/field feature; the attributes are
stored with the link and rendered on output, and it has no access-control role. Note: any attributes rendered into
markup should be output safely. Configure the link attributes.

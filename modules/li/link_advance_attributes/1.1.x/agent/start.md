# Link Advance Attributes — agent index

**Adds advanced attributes (icons/image bundles) to link fields**. Depends on core `link`, `media`,
`media_library`. Version **1.1.0**. Core `^11`.

Content-editing/field — attributes stored with the link + rendered (output safely); no access role.

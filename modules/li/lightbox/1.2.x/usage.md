Lightbox adds a link around the image pointing to another image opened in a lightbox.

---

Lightbox **wraps an image in a link that opens a larger image in a lightbox overlay** — so a thumbnail
opens the full-size image in a modal, with `lightbox_media` (Media) and `lightbox_responsive` submodules. It
depends on core Image, in the Media package.

Use it to add lightbox behaviour to images. It is a content-display feature affecting image presentation;
images follow core media/file access and it has no access-control role. Choose the lightbox formatter on an
image field.

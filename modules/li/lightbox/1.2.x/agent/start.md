# Lightbox — agent index

Wraps images in a link that **opens a larger image in a lightbox overlay** (`lightbox_media`/
`lightbox_responsive` submodules). Depends on core `image`. Version **1.2.1**. Core `^10.3||^11`.

Content-display — images follow core media/file access; no access role.

Tobii Lightbox Image Formatter displays images in a lightbox using the Tobii library.

---

Tobii Lightbox Image Formatter **displays images in a lightbox using the Tobii library** — a field formatter
that opens image fields in an accessible Tobii lightbox/modal on click, for gallery-style viewing. It depends on
the Lightbox module.

Use it for lightbox image display. It is a media/display feature; images render per normal file/field access and it
has no access-control role. Configure the Tobii formatter on an image field.

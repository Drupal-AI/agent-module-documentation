Licenses provides the site's license usage information.

---

Licenses tracks and displays **the site's license usage information** — surfacing which software licenses
apply to the site's components (modules/libraries), useful for compliance and license auditing. It provides
its own permissions, in the Licenses package.

Use it to review license usage/compliance. It is an administration/reporting feature; the information is
administrative and gated by its permission, and it has no access-control role beyond that. Review the license
information.

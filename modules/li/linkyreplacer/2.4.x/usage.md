Linky Replacer converts hyperlink URLs to Linky entities and replaces the URL with the Linky.

---

Linky Replacer converts plain hyperlink URLs in content into **Linky** entities — replacing a raw URL
with a managed Linky link entity, so links become centrally-managed, reusable entities (Linky provides link
management/tracking). It requires PHP 8.1, provides its own permissions, in the Utility package.

Use it to migrate raw links to managed Linky entities. It is a content-editing/link-management feature that
transforms content links; the created Linky entities are content and it has no access-control role beyond its
permission. Configure/run the replacement.

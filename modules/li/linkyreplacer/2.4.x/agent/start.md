# Linky Replacer — agent index

Converts **hyperlink URLs in content into Linky entities** and replaces the URL with the Linky (centrally
managed/reusable link entities). Requires PHP 8.1; provides permissions. Version **2.4.2**. Core `^10.4||^11`.

Content-editing/link-management — transforms content links into Linky entities; no access role beyond
permission.

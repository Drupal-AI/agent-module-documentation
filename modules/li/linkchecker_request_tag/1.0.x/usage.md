Linkchecker Tagger adds a custom header tag to Link Checker's outbound HTTP requests.

---

Linkchecker Tagger **adds a custom header to Link Checker's HTTP requests** — tagging the outbound requests
the Link Checker module makes (with an identifying header) so those requests are easy to recognize/filter on the
receiving side or in logs. It works on core 11.

Use it to identify Link Checker traffic. It is a developer/integration convenience; it only adds a request header
and has no content or access role. Configure the request tag.

# Like! (like) — agent index

A configurable **like button** for any content entity type, supporting **authenticated and
anonymous** visitors. Enabling a like button on an entity type adds a **computed `likes` base
field** and a **`like_default` field formatter** that renders an AJAX toggle; each click
creates/deletes a lightweight **`like` content entity** row. Core requirement `^10.1 || ^11`.
License GPL-2.0-or-later. Version 2.0.4 (branch 2.0.x).

Dependencies (all required): contrib **`entity`** (Entity API — access/permission handlers,
route/task providers), **`cache_control_override`**, **`js_cookie`** (JS Cookie library asset),
and core **`views`**.

## What it provides

- **Entity type** `like` (`src/Entity/Like.php`) — non-fieldable, non-translatable,
  non-revisionable content entity; base table `like`; fields `id`, `uuid`, `langcode`, `uid`
  (owner), `entity_type`, `entity_id` (entity_reference), `value` (default 1), `timestamp`.
  Uses `entity` module's `UncacheableEntityAccessControlHandler` /
  `UncacheableEntityPermissionProvider`; admin_permission `administer like`. Admin collection at
  `/admin/content/like`. Custom storage schema `LikeStorageSchema` adds an index on
  (`entity_type`, `entity_id`).
- **Computed base field `likes`** — added by `like_entity_base_field_info()` in `like.module`
  ONLY on entity types listed in config `enabled_entity_types`. Integer, computed via
  `LikeItemList::computeValue()` → `like.helper::getNumOfLikes()`.
- **Field formatter** `like_default` (`LikeFormatter`, label *"Likes"*, targets `integer`
  fields) — renders the `likes` field as the AJAX like form and attaches library `like/like`.
- **Form** `like_form` (`LikeForm`, a `FormBase`) — the AJAX toggle; on trigger calls
  `like.helper::like()`/`unlike()`. Themed by `templates/like-form.html.twig` (`like_form` theme
  hook).
- **Service** `like.helper` (`LikeHelper` implements `LikeHelperInterface`) — `like()`, `unlike()`,
  `userHasLiked()`, `getNumOfLikes()`.
- **Service** `like.ajax_refresh_like_subscriber` (`AjaxRefreshLikeSubscriber`) — re-enables the
  buttons (`pointer-events: auto`) after the AJAX response.
- **Controller route** `like.handler` → `GET /like/{entity_type}/{entity}`
  (`LikeController::handler`) — returns cacheable JSON `{ "likes": N }` for the count endpoint
  polled by `js/like.js`.
- **Views argument-default plugin** `like_user_cookie` (`LikeUserOrCookie`) — resolves "entities
  the current user/visitor liked" from cookie + DB, for contextual filters.
- **Settings form** `SettingsForm` at `/admin/config/user-interface/like` (route `like.settings`,
  permission **`administer like configuration`**); config object `like.settings`.
- **Bundled view** `views.view.likes` — admin Likes listing (page at `admin/content/like`,
  access perm `access like overview`).

## Permissions

- `administer like configuration` (`like.permissions.yml`, restricted) — access the settings form.
- `administer like`, plus the per-operation `like` entity permissions generated by the `entity`
  module's permission provider — manage recorded like entities.
- The `likes` overview view is gated by `access like overview`.

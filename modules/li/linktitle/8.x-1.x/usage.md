Link Title adds an automated title-attribute to links.

---

Link Title is a **text-format filter that adds a `title` attribute to links** automatically — deriving a
tooltip/title (e.g. from the link text or target) so links get a helpful hover title without editors adding
one manually. It depends on core Filter, in the Input filters package.

Use it to auto-add link titles in a text format. It is a content-display/filter feature that transforms link
markup on output; it has no content or access role. Enable it on the relevant text format.

# Link Title — agent index

A **text filter that adds an automated `title` attribute to links** (hover tooltip derived automatically).
Depends on core `filter`. Version **8.x-1.0-beta4**. Core `^9||^10||^11`.

Content-display/filter — transforms link markup on output; no content/access role.

# Link Text Options — agent index

Adds a setting to **Link fields restricting the link text to predefined options** — editors pick a
label from a controlled list instead of free-typing (consistent CTA/button wording). Depends on core
`link`. Version **1.0.1**. Core `^10||^11`.

Content-editing/field feature — constrains link text (not access); URL behaves normally. Configure
options on the field settings.

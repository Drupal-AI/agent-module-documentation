Link Text Options adds a setting to link fields that restricts the entered link text to a predefined set of options.

---

Link Text Options adds a setting to core Link fields that constrains the link *text* to a predefined
list of allowed options — instead of free-typing link text, editors pick from a controlled vocabulary
of labels. This enforces consistent link wording (useful for CTAs, standardized button labels) and
keeps link text on-brand/on-message. It depends on core Link.

Use it where link text should be standardized rather than arbitrary. It is a content-editing/field
feature constraining input; it affects the link field's text options, not access, and the URL portion
behaves as normal. Configure the allowed options on the link field's settings.

Archive (disable) individual allowed values on List fields.

---

List Value Archive lets you archive (disable) individual allowed values on List fields so they stay valid for existing content but are hidden from new selections — so a deprecated option keeps rendering correctly on old content while no longer appearing in the widget for new entries. Depends on core `options` and `field`; supports Drupal 10.3+ and 11.

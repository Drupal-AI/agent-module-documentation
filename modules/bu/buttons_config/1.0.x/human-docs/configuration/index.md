# Configuration

Buttons Config is configured by setting the submit-button label for each content
type and media type. The labels are stored as site configuration.

## Set the button labels

1. Log in as an administrator.
2. Open the Buttons Config form from the admin **Configuration** area.
3. For each content type and media type, enter the submit-button label you want
   in place of the default "Save".
4. Save the form. The forms for those types now show your wording on their submit
   button.

## Choosing good labels

- **Match the word to the outcome.** The label is a promise about what happens
  when the button is pressed. On a moderated content type whose items go to review,
  a label of "Publish" makes the interface less truthful — "Send for review" is
  more accurate. Consider what any moderation workflow actually does before
  choosing the wording.
- **Reduce hesitation on public forms.** An application form whose button says
  "Save" leaves people unsure whether they have applied — "Submit application" is
  clearer.

## Translation

Button text is user-facing copy. On a multilingual site, translate the labels
through the usual configuration translation route rather than typing them once in
a single language.

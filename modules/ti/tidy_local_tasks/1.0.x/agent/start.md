# Tidy Local Tasks — agent index

Hides Drupal's **local task tabs** behind a **sticky side button**; click to reveal. Version **1.0.0**. Core `^8 || ^9 || ^10`.

Purely front-end: a Twig template + JS/CSS library restyle the local tasks block. No routes, permissions, services, or server-side logic. Presentational only — underlying tab access is unchanged.

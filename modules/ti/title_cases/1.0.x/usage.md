Title Cases displays a node title using a configured title-case style.

---

Title Cases **applies title-case styling to node titles** — displaying a node's title reformatted to a chosen
title-case convention (from a style guide) without changing the stored title. It depends on core Node.

Use it for consistent title casing on display. It is a content-display feature; it reformats the title on output
(stored title unchanged) and has no access-control role. Configure the title-case style.

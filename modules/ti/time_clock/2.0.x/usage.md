Time Clock shows the current date and time according to the site/configured timezone.

---

Time Clock displays the current date and time according to the configured timezone — a block/widget
showing a live clock. It is useful for sites that want to show the current time (a dashboard, an office
site showing local time).

Use it to display a current-time clock. It is a content-display feature showing the date/time; it reflects
the timezone configuration and has no content or access role. Place the clock where it should appear.

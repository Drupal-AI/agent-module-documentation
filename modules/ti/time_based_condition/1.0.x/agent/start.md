# Time-Based Condition — agent index

A **condition plugin that gates visibility by time (schedule/date range)** (e.g. a promo banner only in a
window). Version **1.0.0-alpha3**. Core `^10||^11`.

Site-building/conditions — **visibility, not access**; time-based visibility is **cache-sensitive** (ensure
caching respects the time). No access role.

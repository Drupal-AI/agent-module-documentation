Time-Based Condition provides a flexible time-based condition.

---

Time-Based Condition provides a **condition plugin that gates visibility by time** — showing/hiding blocks
(or other condition-driven behaviour) based on a schedule or date range (e.g. show a banner only during a
promotion window). It works across core 10–11.

Use it to schedule block/element visibility. It is a site-building/conditions feature. Note it controls
**visibility** (presentation), not access — and time-based visibility is **cache-sensitive** (ensure caching
respects the time so the block appears/disappears at the right moment). It has no access-control role.
Configure the time condition.

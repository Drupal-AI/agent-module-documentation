Timestamp Nullable provides a timestamp widget that allows empty values for timestamp fields.

---

Timestamp Nullable provides a timestamp field widget that allows an **empty** value — so a timestamp
field can be left blank (null) rather than forcing a date, useful for optional date/time fields where "no
value" is meaningful. It is a field-widget feature.

Use it for optional timestamp fields that may be empty. It is a content-editing/form-widget feature affecting
timestamp input; it has no content or access role. Select the nullable timestamp widget on the field.

A Views display that outputs JSON for Tiki Toki Timelines.

---

Tiki Toki adds a Views display that outputs data in the specific JSON format for Tiki Toki Timelines software — so a View of dated content can feed an interactive Tiki Toki timeline, exporting the events as the JSON that Tiki Toki expects. Depends on core `serialization` and `views`; supports Drupal 9.3+, 10, and 11.

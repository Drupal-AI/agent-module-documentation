Time Diff provides a Twig filter for displaying relative time differences, like '3 hours ago' or 'in 2 days'.

---

Time Diff provides a Twig filter for rendering relative time differences — turning a date/timestamp
into human-friendly relative text like "3 hours ago" or "in 2 days" directly in templates. This saves
computing relative times in preprocess or PHP. It is in the Custom package.

Use it in themes/templates to show relative times. It is a theming/developer utility (a Twig filter); it
formats time output and has no content or access behaviour. Apply the filter to date values in Twig.

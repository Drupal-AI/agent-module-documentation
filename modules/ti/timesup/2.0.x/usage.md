Time's Up provides cache-tags to deal with time sensitive data.

---

Time's Up provides **cache tags for time-sensitive data** — so content that should change/expire at a
specific time (e.g. an event that ends, a scheduled publish) can be tied to a cache tag that invalidates at the
right moment, keeping caches from serving stale time-dependent content. It provides its own permissions, in the
Cache package.

Use it to correctly cache time-sensitive content. It is a performance/caching feature; it manages cache
invalidation timing and has no content or access role beyond its permission. Configure the time-based cache
tags.

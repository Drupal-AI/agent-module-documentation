# Time's Up — agent index

Provides **cache tags for time-sensitive data** (invalidate caches at the right moment so time-dependent content
isn't served stale). Provides permissions. Version **2.0.8**. Core `^10.5||^11||^12`.

Performance/caching — manages cache-invalidation timing; no content/access role beyond permission.

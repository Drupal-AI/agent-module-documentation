Open Y Mappings provides a Mapping entity type and related features, part of the Open Y (YMCA) distribution ecosystem.

---

Open Y is the YMCA's Drupal distribution for association websites, and it is built from many focused modules. Open Y Mappings supplies one building block: a Mapping entity type and the features around it, used within the distribution to relate or map data as its features require.

Like other distribution components, it is infrastructure meant to work alongside the rest of the Open Y ecosystem rather than a standalone feature — on an Open Y site it plays its part in the distribution's data model, and on an unrelated site it is a generic mapping-entity building block whose value depends entirely on what you build on it. It has no notable security surface of its own; the entity type is governed by standard entity access.

For Open Y sites it is a dependency that comes with the distribution. Elsewhere it is only useful if you specifically need the mapping-entity primitive it provides and are prepared to build the rest.

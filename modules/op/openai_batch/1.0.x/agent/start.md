# OpenAI Batch — agent index

**Drupal integration for OpenAI's Batch API** (async bulk jobs; VBO integration). Depends on `ai`,
`ai_provider_openai`, `views_bulk_operations`. Provides permissions. Version **1.0.0-alpha10**. Core `^10||^11`.

AI/integration — **sends content to OpenAI** in batch (egress — confirm acceptable; key in AI/Key); gate the
permission (cost). No access role beyond permission.

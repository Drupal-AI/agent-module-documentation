# OpenAI Client — agent index

Provides **OpenAI API integration + basic UIs** for calling OpenAI from Drupal. Provides permissions. Version
**1.2.2**. Core `^10.2||^11`.

AI/integration — **sends prompts/content to OpenAI** (data egress — confirm acceptable); **API key** as a
secret (HTTPS); gate invocation UIs to trusted users (usage/cost). No access role beyond permission.

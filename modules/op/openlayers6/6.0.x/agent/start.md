# OpenLayers 6 — agent index

**OpenLayers 6** map renderer for **Geofield** — interactive maps of geofield data (open-source
alternative to Google/Leaflet). Depends on `geofield`. Version **6.0.1**. Core `^9||^10||^11`.

Content-display/mapping — renders geofield values, respects their access; no access role. Configure the
renderer on the geofield display.

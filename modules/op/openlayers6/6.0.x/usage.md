OpenLayers 6 provides an OpenLayers 6-based map renderer for the Geofield module.

---

OpenLayers 6 provides a map renderer based on the OpenLayers 6 JavaScript mapping library for the
Geofield module — rendering geofield data (points, geometries) on interactive OpenLayers maps, an
open-source alternative to Google Maps/Leaflet. It depends on the Geofield module.

Use it to display geographic field data on OpenLayers maps. It is a content-display/mapping feature
rendering geofield values; the data comes from geofield content and respects its access, with no
access-control role of its own. Configure the OpenLayers renderer on the geofield's display and set map
options (base layer, zoom).

Opquast Checklist provides a Checklist API checklist to verify whether a site follows the Opquast web-quality best practices.

---

Opquast Checklist provides a checklist (via the Checklist API module) of the Opquast web-quality
best practices — a well-known set of criteria covering quality, accessibility, SEO, privacy and UX. It
lets teams track which recommendations the site follows, checking items off and recording progress as a
repeatable quality-assurance reference. It depends on `checklistapi`.

Use it as a QA/governance aid to audit a site against Opquast's criteria and document compliance. It is
an administration/quality tool — a checklist that records status; it does not change the site or enforce
anything. Use it alongside actual implementation work to systematically improve quality.

# OpenAgenda — agent index

Integrates the **OpenAgenda** event platform — import/display events (listings, single pages,
filtering) from an OpenAgenda agenda. Depends on `node`, `field`, `serialization`; config at
`openagenda.form`. Version **3.4.27**. Core `^8.8||^9||^10||^11`.

Store the OpenAgenda API key as a secret. Provides permissions. Event data comes from the external
service (availability depends on it).

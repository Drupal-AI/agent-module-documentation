An OpenPGP encryption method for the Encrypt module.

---

OpenPGP Encryption provides OpenPGP encryption for the Encrypt module — so data encrypted via Encrypt can be protected with OpenPGP (public-key) encryption, letting a site encrypt fields/data to an OpenPGP public key that only the private-key holder can decrypt.

The OpenPGP keys are managed via the Encrypt/Key framework (store the private key securely, env-backed, and never on the web server if avoidable). Depends on `encrypt`; supports Drupal 9, 10, and 11.

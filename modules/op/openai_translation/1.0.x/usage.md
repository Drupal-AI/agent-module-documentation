A content-translation toolbox powered by OpenAI.

---

OpenAI Translation Toolbox provides a translation toolbox powered by OpenAI — auto-translating content/strings via the OpenAI API, so a multilingual site can machine-translate using an LLM (often with better context handling than dictionary MT).

The OpenAI API key is admin-configured and should be stored securely (env-backed); review translations and watch cost/PII sent to OpenAI. Supports Drupal 8 through 11.

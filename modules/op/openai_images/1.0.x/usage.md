AI-generated images for Media via the OpenAI API.

---

openAI Images provides AI-generated images for media from the OpenAI API — so a media entity's image can be generated from a text prompt via OpenAI (DALL·E), populating the Media Library with AI imagery.

The OpenAI API key is admin-configured and should be stored securely (env-backed); each generation is a paid API call. Depends on core `media`; supports Drupal 9.2+, 10, and 11.

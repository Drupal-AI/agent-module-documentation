# Access Unpublished Group (access_unpublished_group) — agent index

**Extends Access Unpublished tokens to entities owned by a Group, purely by decorating Group's access-control services.**

- **Version:** 3.0.x
- **Core:** ^10.3 || ^11
- **Dependencies:** access_unpublished, group
- **Key classes:** `AccessUnpublishedGroupServiceProvider::alter()` (decorates `group.relation_handler.access_control.*` and `access_check.group_latest_revision`); `AccessUnpublishedGroupAccessControl::entityAccess()`; `GroupLatestRevisionCheck`.
- **Permissions:** dynamic `access_unpublished_group_<relation_plugin_id>` per group type, generated by `AccessUnpublishedGroupPermissions::groupPermissions()`; configured at `admin/group/types` → Edit permissions.
- **Routes/services of its own:** none (no routing.yml; behaviour is service decoration only).

**Security:** Access-only decorator — it never broadens access beyond the parent handler unless BOTH the group permission is granted AND `access_unpublished_entity_access()` (the token check) allows; no anonymous or mutating endpoints. Sound.

See [configure/permissions.md](configure/permissions.md).

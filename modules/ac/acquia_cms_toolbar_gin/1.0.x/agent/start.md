# acquia_cms_toolbar_gin — agent index

Part of the **Acquia CMS** distribution (Acquia's Drupal distro). Allows your site to use the Gin admin theme with Acquia CMS Toolbar. Version — see
`acquia_cms_toolbar_gin`'s release. Core `^10.3 || ^11`. Depends on: `acquia_cms_toolbar:acquia_cms_toolbar`.

**Distribution configuration/glue, not a standalone feature.** Right on an Acquia CMS site; a strong
set of assumptions elsewhere. Designed to work with `acquia_cms_common` and the rest of the family.

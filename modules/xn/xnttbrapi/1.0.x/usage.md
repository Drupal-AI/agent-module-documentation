An External Entities storage plugin for BrAPI (plant breeding) services.

---

External Entities BrAPI Client is a plugin for External Entities allowing you to work with BrAPI services — so data from a BrAPI (Breeding API, a standard for plant-breeding/agriculture data) server can be surfaced as Drupal entities (read/queried) via the External Entities framework, for research/agriculture sites. Depends on `external_entities` (>=3.0.0-beta1); supports Drupal 9, 10, and 11.

External Entities JSON Files Storage Client is a plugin for External Entities allowing work with JSON files as a data source.

---

External Entities JSON Files Storage Client (xnttjson) provides a storage-client plugin for the External
Entities module — letting JSON files be used as the **data source** backing external entities, so data stored
in JSON files is exposed as browsable/queryable Drupal entities without importing it into the database. It
depends on the External Entities module, in the External Entities package.

Use it to surface JSON-file data as external entities. It is an integration/external-data feature; the data
comes from JSON files (read as configured) and it has no access-control role of its own (external-entity
access follows External Entities' configuration). Ensure the JSON files are from a trusted source and stored
appropriately. Configure the JSON data source.

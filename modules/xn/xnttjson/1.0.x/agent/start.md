# External Entities JSON Files Storage Client (xnttjson) — agent index

An **External Entities storage client using JSON files as a data source** (expose JSON-file data as browsable/
queryable entities without importing to the DB). Depends on `external_entities`. Version **1.0.0-beta5**. Core
`^9||^10||^11`.

Integration/external-data — data from JSON files (external-entity access follows External Entities' config;
ensure the JSON source is trusted). No access role of its own.

An External Entities storage plugin for MediaWiki content.

---

External Entities Storage Client for Mediawiki is a MediaWiki external-entities storage client plugin — so pages/content from a MediaWiki (e.g. Wikipedia or a private wiki) can be surfaced as Drupal entities via the External Entities framework, letting a site read and display wiki content as native-feeling entities. Depends on `external_entities` (>=3.0.0-beta1); supports Drupal 9, 10, and 11.

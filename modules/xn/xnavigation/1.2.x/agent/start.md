# xNavigation — agent index

Adds configurable **color schemes to Drupal core's Navigation module** (restyle the admin sidebar). Depends on
core `navigation`. Provides permissions. Version **1.2.4**. Core `^11.1`.

Administration/theming — affects the navigation UI; no content/access role beyond permission.

xNavigation adds color schemes to the core Navigation module.

---

xNavigation adds **configurable color schemes to Drupal core's Navigation module** — letting you restyle
the new admin Navigation (sidebar) with different color themes. It depends on core Navigation, provides its own
permissions, in the Other package. Requires core 11.1+.

Use it to customize the admin Navigation appearance. It is an administration/theming feature affecting the
navigation UI; it has no content or access role beyond its permission. Configure the navigation color
scheme.

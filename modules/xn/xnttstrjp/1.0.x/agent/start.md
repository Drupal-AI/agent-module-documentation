# External Entities Storage (xnttstrjp) — agent index

An **External Entities storage-client plugin** (JSON-based data source) for the External Entities module. Depends
on `external_entities`. Version **1.0.0-beta4**. Core `^9||^10||^11`.

Integration/external-data — data from an **external source** (credentials as secrets, HTTPS, trusted source;
don't over-expose); external-entity access follows your config. No access role of its own.

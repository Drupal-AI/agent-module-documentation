YMCA Sync suite provides web services to synchronize data with YMCA systems, part of the Open Y / YMCA website platform.

---

YMCA Sync suite provides web-service integrations for synchronizing data with YMCA systems — part of
the Open Y (YMCA website) platform ecosystem, used to sync memberships, programs, schedules or related
data between Drupal and YMCA back-office systems. It provides Drush commands and is in the YMCA package.

Use it on Open Y / YMCA-platform sites needing to sync with external YMCA systems. The security-relevant
points are the credentials for the external systems (store them as secrets) and that synced data may
include member/personal information — handle that PII with appropriate access control and privacy care. It
is an integration/sync feature typically run via Drush/cron; configure the sync sources and credentials.

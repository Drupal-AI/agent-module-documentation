# Ymaps Geolocation — agent index

Field **formatter + widget** for the `geolocation` field type that renders coordinates on a **Yandex Map**; lat/lng/center/zoom/controls + token-replaced balloon content go to JS via `drupalSettings`. Deps `field`, `field_ui`, `geolocation`. Version **8.x-1.6**, core `^8||^9||^10`. Balloon content is admin-config (token-replaced).

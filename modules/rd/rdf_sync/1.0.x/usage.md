Synchronize Drupal entities as RDF triples to an RDF backend.

---

RDF Sync synchronizes entities as triples to an RDF backend — serialising Drupal entities into RDF triples and pushing them to a configured triplestore/RDF store, so entity data is exposed as linked-data/semantic triples for external semantic-web consumers.

The RDF backend endpoint/credentials are admin-configured; store them securely (env-backed). Depends on core `serialization`; supports Drupal 10.2+ and 11.

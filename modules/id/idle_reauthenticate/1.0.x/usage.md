Force re-authentication after a period of browser idle time.

---

Reauthenticate on idle browser forces the current user to re-authenticate after some idle time in the browser — so after a configurable period of inactivity the user must re-enter their password (or re-login) before continuing, protecting sessions on shared/unattended machines. Depends on core `user`; supports Drupal 10.4+ and 11.

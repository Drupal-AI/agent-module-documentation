Idle customizes maintenance-mode appearance and simplifies toggling maintenance mode.

---

Idle **customizes maintenance mode** — changing the appearance of the maintenance page and simplifying
enabling/disabling maintenance mode, for a nicer "site under maintenance" experience. It depends on the Service
module.

Use it to manage maintenance mode more easily. It is an administration feature; it affects the maintenance page and
mode toggle and has no content or access role. Note: putting the site in maintenance mode restricts access to
privileged users — that's core behavior this module fronts. Configure the maintenance appearance.

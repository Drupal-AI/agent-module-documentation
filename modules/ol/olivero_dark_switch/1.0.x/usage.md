Olivero Dark Switch provides a dark switch toggle for the Olivero theme.

---

Olivero Dark Switch adds a **light/dark mode toggle to the Olivero theme** — letting visitors switch
Olivero (Drupal's default front-end theme) between light and dark appearance, remembering the choice. It is in
the Custom package.

Use it to offer dark mode on Olivero. It is a theming/UX feature affecting presentation; it has no content or
access role. Enable it with the Olivero theme.

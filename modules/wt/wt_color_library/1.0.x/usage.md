WT Color Library provides taxonomy-based color selection with styled swatches.

---

WT Color Library **provides a color library via taxonomy** — a lightweight, styled way to select colors
(stored as taxonomy terms) with color swatches, for consistent brand/color choices. It depends on core Options.

Use it for curated color selection. It is a content-editing/site-building feature; colors are taxonomy-term values
and it has no access-control role. Note: colors applied to output should be emitted as sanitized style values.

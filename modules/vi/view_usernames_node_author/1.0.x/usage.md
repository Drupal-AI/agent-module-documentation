Grant permission to view node authors' usernames.

---

View Usernames: Node Author grants access to node authors' usernames — extending the View Usernames module so that (via a dedicated permission) certain roles can see the real username of a node's author even when core would otherwise hide it, useful for editorial/moderation contexts. Depends on core `node` and `view_usernames`; supports Drupal 10.3.2+ and 11.

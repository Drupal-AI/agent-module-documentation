An AI-powered natural-language search box that maps intent to exposed filters.

---

Views Natural Language Filter adds a natural language search box to Views that uses AI to map the visitor's intent to the view's other exposed filters — so a user can type a plain-language query (e.g. 'cheap red shoes in stock') and the module sets the corresponding exposed filter values via the AI module. Depends on core `views` and `ai`; supports Drupal 10.4+ and 11.

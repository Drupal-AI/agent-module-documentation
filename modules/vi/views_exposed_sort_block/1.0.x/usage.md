Views Exposed Sort Block provides a block type which renders a views display's exposed sorts separately from the view.

---

Views Exposed Sort Block provides a block that renders a View's exposed sort controls separately from
the View itself — so the sort options can be placed elsewhere on the page (a sidebar, a header) rather than
only above the results, decoupling the exposed sort UI from the View's display. It depends on core Views.

Use it where the exposed sort controls should live in a different region than the View results. It is a
site-search/Views-UI feature affecting where the sort controls render; it shapes the sort UI, not results or
access (the View's access applies), and it has no access-control role. Place the exposed-sort block where
the controls should appear.

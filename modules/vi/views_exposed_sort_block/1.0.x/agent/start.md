# Views Exposed Sort Block — agent index

Renders a View's **exposed sorts as a separate block** (place the sort controls elsewhere — sidebar/header —
decoupled from the view display). Depends on core `views`. Version **1.0.0-beta4**. Core `^9.2||^10||^11`.

Site-search/Views-UI — shapes where sort controls render, not results/access (View access applies); no
access role.

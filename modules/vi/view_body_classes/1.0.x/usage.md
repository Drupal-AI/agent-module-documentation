View Body Classes adds contextual CSS classes to the page body when a view displays.

---

View Body Classes **adds body classes for views** — attaching contextual CSS classes to the page `<body>` when
a particular view is displayed, so themes can style pages differently based on the view shown. It depends on core
Views.

Use it to theme pages by view. It is a theming/Views feature; it adds body classes and has no content or access
role. Configure the body classes per view.

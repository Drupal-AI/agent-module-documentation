View Transitions enables cross-page transitions.

---

View Transitions **enables cross-page transitions using the browser's View Transitions API** — adding
smooth animated transitions between page navigations (where the browser supports it) for a more app-like feel. It
is in the Other package.

Use it for animated page transitions. It is a front-end/UX feature affecting presentation; content still comes
from normal (access-respecting) page loads, and it has no content or access role. Configure the transitions.

Dynamically slice/group Views data by a filter-selected field.

---

Views Slice Data allows users to dynamically slice (group) Views data by selecting a field exposed in a filter — so a viewer can choose, at runtime, which field to group results by (e.g. group products by brand, then by category), giving pivot-table-like dynamic grouping. Depends on core `views`; supports Drupal 10.1+, 11, and 12.

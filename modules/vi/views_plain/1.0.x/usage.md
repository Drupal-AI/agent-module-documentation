Views Plain is a Views display style that removes all the wrapper markup.

---

Views Plain provides a Views display style that outputs results with **no wrapper markup** — stripping
the div/list wrappers Views normally adds, so the raw field output can be used where surrounding markup would
interfere (e.g. building a comma-separated string, a JSON-ish token, or feeding another component). It depends
on core Views.

Use it when you need a View's output without Views' wrapper markup. It is a content-display/Views feature
affecting output structure; the results respect the View's access and it has no access-control role. Select
the Plain style on the View.

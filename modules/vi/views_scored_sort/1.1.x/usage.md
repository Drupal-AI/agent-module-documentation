Views Scored Sort sorts a view by configurable scoring criteria.

---

Views Scored Sort **sorts views by a computed score** — a Views sort plugin that ranks results by configurable
scoring criteria (weighting multiple factors), for relevance/priority ordering. It depends on core Views.

Use it for score-based view ordering. It is a Views/content-display feature; it computes a sort order and has no
access-control role. Configure the scoring on a view sort.

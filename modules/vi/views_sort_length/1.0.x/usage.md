Views Sort by Length provides a sort by length option in Views.

---

Views Sort by Length adds a **"sort by string length" option to Views** — letting a view order results by
the character length of a field's value (e.g. shortest/longest titles first) rather than alphabetically. It has
no dependencies beyond Views.

Use it when you need length-based ordering in a view. It is a developer/site-building feature; it affects view
ordering only and has no content or access role. Add the length sort to a view.

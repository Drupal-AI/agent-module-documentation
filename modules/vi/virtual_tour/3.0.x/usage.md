Virtual Tour provides a field formatter to apply a virtual-tour (360-degree/panorama) effect to an image.

---

Virtual Tour provides an image field formatter that renders an image with a virtual-tour effect —
turning a 360-degree/panorama image into an interactive virtual tour the visitor can pan/explore. It depends
on core Image and provides its own permissions. This suits real-estate, tourism or venue sites showing
immersive imagery.

Use it to present 360/panorama images interactively. It is a media/content-display feature (a formatter);
the image is content and it has no access-control role. Select the Virtual Tour formatter on an image
field with suitable panorama images.

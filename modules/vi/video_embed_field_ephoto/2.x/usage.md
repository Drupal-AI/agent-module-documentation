Video Embed Field ePhoto integrates the ePhoto DAM (digital asset management) as a video source for the Video Embed Field module.

---

Sites using the ePhoto DAM want to embed its videos. This module adds ePhoto as a Video Embed Field source. It connects to the ePhoto DAM, so any connection credentials are secrets to protect, and it embeds video from that platform (a third-party origin, potentially tracking). For an ePhoto-using site it provides the video integration; secure the connection and gate embeds behind consent where required.

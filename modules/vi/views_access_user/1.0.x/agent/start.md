# Views Access by User — agent index

**Allows access to a view to be restricted by user**. Depends on `views`. Version **1.0.0-beta1**. Core
`^10.3||^11`.

**Access-control** (Views) — gates the **view display** to configured user(s); does not change access to the
underlying entities (entity access still applies). Verify the user list; use to gate a view UI, not as the sole
data protection.

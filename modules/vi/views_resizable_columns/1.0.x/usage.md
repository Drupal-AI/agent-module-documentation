Views Resizable Columns makes Views table columns resizable.

---

Views Resizable Columns **makes Views-generated table columns resizable** — letting users drag column
borders to adjust widths in a table-style view, for a nicer data-table experience. It depends on core Views.

Use it to add resizable columns to table views. It is a content-display/UX feature affecting table rendering; it
has no content or access role. Enable it on a table-format view.

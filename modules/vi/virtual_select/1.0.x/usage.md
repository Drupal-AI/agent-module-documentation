Virtual Select integrates the Virtual Select library for enhanced select form elements.

---

Virtual Select **integrates the Virtual Select library** — a JavaScript library providing enhanced, searchable,
virtualized select/dropdown form elements (good for large option lists). It depends on core Field.

Use it for better select widgets. It is a content-editing/UI feature; it enhances select elements and has no
content or access role. Configure the Virtual Select widget on a field.

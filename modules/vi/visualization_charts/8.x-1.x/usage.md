Visualization Charts allows you to create interactive visualizations.

---

Visualization Charts lets you create **interactive data visualizations / charts** — turning data into
charts (bar, line, pie, etc.) that render on the site, for dashboards and data presentation. It provides its
own permissions, in the Visualization Charts package.

Use it to present data as interactive charts. It is a content-display feature; charts are built from
configured/queried data and it has no access-control role beyond its permission. Note that a chart only shows
the data you feed it — ensure the underlying data source respects access if it contains restricted data.

Views filter handlers with 'OR NULL' operator variants.

---

Views Filter OR NULL provides Views filter handlers with OR NULL operator variants — so an exposed/standard Views filter can match rows where the field equals the value OR is NULL (empty), which the default handlers can't express in one filter, useful for optional fields. Depends on core `views`; supports Drupal 10.1+, 11, and 12.

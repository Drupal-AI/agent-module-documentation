A fast, memory-efficient libvips image toolkit for Drupal.

---

Vips provides libvips as an image toolkit for Drupal — a fast, memory-efficient alternative to GD and ImageMagick for generating image derivatives (thumbnails, styles), using the libvips library which is notably quicker and lighter on RAM for large images. Requires the libvips PHP extension/library. Supports Drupal 11.3.

A Views row plugin that renders entity forms in a chosen form mode.

---

Views Entity Form Row provides a Views row plugin to display entity forms with a specific form mode — so a View can render each result as an editable entity form (in a chosen form mode) rather than a rendered view, enabling bulk inline-editing listings. Depends on core `node`; supports Drupal 9, 10, and 11.

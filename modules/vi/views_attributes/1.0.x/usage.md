Views Attributes allows managing HTML attributes on a views display, adding custom attributes/classes to Views markup.

---

Views Attributes lets site builders manage HTML attributes on a Views display — adding custom
attributes and classes to the View's markup (the wrapper, rows, etc.) through the Views UI, for styling,
JavaScript hooks or data attributes without custom templates. It depends on core Views.

Use it to add attributes/classes to Views output declaratively. It is a content-display/Views feature
affecting markup; it does not change results or access (the View's own access applies). Configure the
attributes on the View display.

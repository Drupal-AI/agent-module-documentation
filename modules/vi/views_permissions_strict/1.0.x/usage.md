Views permissions strict restricts view access to users holding a specific combination of roles.

---

Views permissions strict provides a Views access plugin where only users with a specific role combination (all required roles, not just any one) pass access validation — a stricter alternative to core's single-role/permission view access, useful when a view should only be visible to users holding multiple roles at once. It also offers a role/view-field custom Twig helper.

It's a Views access-control plugin — it tightens (never loosens) access. Requires Drupal 11+.

A Views default argument giving the node title from the URL's node ID.

---

Views Default Argument: Node Title from URL provides the node title as a Views filter argument based on the node ID from the URL — so a View placed on/near a node page can automatically receive that node's title as a contextual argument (e.g. to find related content by title) without manual configuration. Depends on core `node`; supports Drupal 10.5+ and 11.

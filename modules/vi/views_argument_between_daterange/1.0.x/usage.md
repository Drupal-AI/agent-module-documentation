Views Argument Between Date Range provides a contextual filter matching a date within a date-range field.

---

Views Argument Between Date Range **filters by a date within a range** — a Views contextual filter (argument)
that matches nodes whose start/end datetime-range field brackets a given date, for "what's on at date X"-style
listings. It depends on core Views.

Use it for date-range-bracketing view arguments. It is a Views/content-display feature; it filters results by date
and has no access-control role. Configure the contextual filter on a view.

# Views insert blocks — agent index

Inserts **blocks into a View's results at specific row positions** (option under the View's advanced
section) — e.g. a promo/CTA after row 3. Depends on core `views`. Version **1.1.1**. Core `^10.2||^11`.

Display/site-building only. Inserted blocks keep their own access/caching; this module controls
placement.

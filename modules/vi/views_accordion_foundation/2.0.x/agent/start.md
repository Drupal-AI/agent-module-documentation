# Views Accordion Foundation — agent index

A Views display/style plugin rendering results as **ZURB Foundation accordions or tabs** (collapsible panels/
tabbed sections). Depends on core `views`. Version **2.0.6**. Core `^9.3||^10||^11`.

Content-display/Views — affects presentation; results respect the View's access (Foundation must be in the
theme). No access role.

Views Accordion Foundation provides an accordion and tabs views display plugin using ZURB Foundation.

---

Views Accordion Foundation provides a Views display/style plugin that renders results as ZURB
Foundation accordions or tabs — presenting a View's rows as collapsible accordion panels or tabbed sections
using the Foundation framework. It depends on core Views, in the Views package.

Use it to present a View as Foundation accordions/tabs. It is a content-display/Views feature affecting
presentation; the results respect the View's access and it has no access-control role. Select the accordion/
tabs style on the View (Foundation must be available in the theme).

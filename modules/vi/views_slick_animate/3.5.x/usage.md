Views Slick Animation lets custom Views use Slick-based animation for carousels.

---

Views Slick Animation adds animation to Slick-based Views carousels — enabling animated transitions/
effects on Views that use the Slick carousel, for more dynamic slide presentations. It is in the custom
package.

Use it to animate Slick carousels built with Views. It is a content-display/Views feature affecting carousel
presentation; the results respect the View's access and it has no access-control role. Configure the animation
on the Slick View.

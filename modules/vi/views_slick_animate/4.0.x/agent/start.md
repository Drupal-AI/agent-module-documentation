# Views Slick Animation — agent index

Provides a **Views style plugin** (`slickanimate`) that renders View results as a **Slick carousel** with optional **animate.css** slide animations. Version **4.0.0**. Core `^10.1 || ^11 || ^12`. Depends on **Views** (core).

No admin settings page, no permissions, no Drush — everything is configured on the View's Format = "Views slick Animation".

- Configure the carousel + animation options on a View → [configure/views-slick-animate.md](configure/views-slick-animate.md)
- Layouts and template variables (default / card / hero_banner) → [theming/views-slick-animate.md](theming/views-slick-animate.md)

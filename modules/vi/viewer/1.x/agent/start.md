# Viewer (viewer) — agent index

Imports data files (**CSV, XLSX/XLS, PDF**) from an upload, an absolute filesystem path, a remote
URL, FTP or SFTP, caches their parsed contents, and renders them on the fly as **tables, charts,
calendars, tabs/accordions and PDF previews**. Nothing is imported into Drupal entities: two config
content-entities model the data — a **`viewer_source`** (which file, from where, parse settings,
optional cron re-import schedule + Slack/email notifications) and a **`viewer`** (which display
plugin + per-column configuration + filters bound to a source). A viewer is shown three ways: a
**block** (`viewer`), a **field** (field type/widget/formatter all id `viewer`), or a **CKEditor 5**
button + text-format **filter** (`viewer`) that expands `<viewer data-viewer="ID">` tags. At render
time each display plugin emits a small wrapper element carrying the viewer UUID; browser JS then
fetches the parsed rows from the REST endpoint **`/get/viewer/{uuid}?_format=json`**
(`rest.viewer.GET`) and builds the DOM client-side. Everything is extensible through five plugin
types.

- Depends on: `drupal:rest` (info.yml). The REST resource config also pulls `serialization` + `user`.
- Composer libs (required by composer.json, needed for the FTP/SFTP/XLSX features): `league/flysystem-ftp`,
  `league/flysystem-sftp-v3`, `phpoffice/phpspreadsheet ^1.24`, `minnur/array-query` (used for filters).
- Core: `^9 || ^10 || ^11`. Package: `Viewers`.
- Settings/configure route: `entity.viewer.collection` (`/admin/structure/viewers`). Admin UI lives
  under `/admin/structure/viewers` and `/admin/structure/viewer-source`.
- Provides **permissions** (see permissions/permissions.md), a **drush** command (`viewer:import`),
  and **five plugin types**. No `config/schema/` (only a REST resource install config + two tours).
- `hook_install` grants `restful get viewer` to the `authenticated` and `anonymous` roles so the
  data endpoint works for site visitors out of the box.

## Key facts (real machine names)

- Content entities: `viewer` (base `viewer`, data `viewer_data`) and `viewer_source` (base
  `viewer_source`, data `viewer_source_data`). Both `admin_permission` = `administer viewer` /
  `administer viewer source`; access handlers gate view/update/delete on the per-op permissions below.
- Standalone routes: `viewer.new_configuration`, `viewer.new_settings` (both `_permission: add viewer`),
  `viewer_source.new_source` (`add viewer source`), `viewer.support` (`administer site configuration`),
  `viewer.ckeditor5_dialog` `/viewer/dialog/{uuid}` (`use text format advanced`),
  `viewer.ckeditor5_preview` `/viewer/preview/{editor}` (custom access = `use text format <format>`).
  Entity routes are generated by `ViewerHtmlRouteProvider` / `ViewerSourceHtmlRouteProvider`
  (e.g. `entity.viewer.collection`, `entity.viewer.new`, `entity.viewer_source.download` at
  `/admin/structure/viewer-source/{viewer_source}/download`, `entity.viewer_source.import`,
  `entity.viewer_source.bulk_import`).
- REST resource: id `viewer`, `rest.viewer.GET`, path `/get/viewer/{uuid}`, GET/json/cookie
  (`config/install/rest.resource.viewer.yml`); class `Plugin/rest/resource/ViewerResource`.
- Permissions: `administer viewer(+ source)`, `add`, `edit`, `delete`, `view active`, `view inactive`
  (for both `viewer` and `viewer source`), plus `bulk import viewer source`, and the REST perm
  `restful get viewer`.
- Services: `plugin.manager.viewer{,_type,_source,_cell,_processor}`, `viewer.batch`, `viewer.cron`,
  `viewer.notifications`, `viewer.ftp_sftp`, `viewer.module`, `event_subscriber.viewer_source`, and
  paramconverters `paramconverter.viewer{,_type,_source}` + `paramconverter.entity.viewer{,_source}`.
- Plugin types (manager / annotation / subdir): **Viewer** (`plugin.manager.viewer`,
  `Annotation\Viewer`, `Plugin/viewer/viewer`), **ViewerType** (`…viewer_type`, `Plugin/viewer/type`),
  **ViewerSource** (`…viewer_source`, `Plugin/viewer/source`), **ViewerCell** (`…viewer_cell`,
  `Plugin/viewer/cell`), **ViewerProcessor** (`…viewer_processor`, `Plugin/viewer/processor`).
- Bundled Viewer ids: `table`, `datatables`, `footable`, `spreadsheet`, `accordion`, `tabs`,
  `vertical_tabs`, `pdfjs`, `fullcalendar`, `chartjs_{bar,line,mixed,piedoughnut,scatterbubble}`,
  `apexchart_{bar,line,mixed,piedoughnut,scatter,bubble,candlestick,treemap}`.
- ViewerType ids: `csv`, `xlsx`, `pdf`. ViewerSource ids: `upload`, `path`, `url`, `ftp`, `sftp`.
  ViewerCell ids: `as_is`, `img`, `link`, `money`, `number`, `percentage`, `peity`.
  ViewerProcessor ids: `processor_csv`, `processor_xlsx`.
- Field plugins: field type `viewer`, widget `viewer`, formatter `viewer`. Block: `viewer`.
  Filter: `viewer`. CKEditor 5 plugin: `viewer_Viewer` (button `Viewer`, class
  `Plugin/CKEditor5Plugin/Viewer`).
- Queue worker: `Plugin/QueueWorker/ViewerSourcesQueueProcessor` (cron import); drush `viewer:import`
  (alias `vimp`, class `Commands/ViewerCommands`).
- Hooks: `hook_page_attachments`, `hook_mail`, `hook_theme`, `hook_preprocess_html`, `hook_cron`,
  `hook_theme_suggestions_viewer_plugin_alter`; alter hooks `viewer_info`, `viewer_type_info`,
  `viewer_source_info`, `viewer_cell_info`, `viewer_processor_info`.

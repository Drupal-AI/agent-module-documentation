Views AJAX Completed Event raises a JavaScript event when views ajax has completed.

---

Views AJAX Completed Event **fires a JavaScript event when a Views AJAX request finishes** — so custom
front-end code can react after a View updates via AJAX (pager, exposed filters, etc.), e.g. to re-init widgets
or scroll. It depends on core Views, in the Views package.

Use it to hook front-end behaviour to Views AJAX completion. It is a developer/front-end feature emitting a JS
event; it has no content or access role. Listen for the event in your JavaScript.

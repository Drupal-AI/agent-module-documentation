# Views AJAX Completed Event — agent index

Fires a **JavaScript event when a Views AJAX request completes** (react after a View updates — re-init widgets,
scroll). Depends on core `views`. Version **1.0.0-beta2**. Core `^8||^9||^10||^11`.

Developer/front-end — emits a JS event; no content/access role.

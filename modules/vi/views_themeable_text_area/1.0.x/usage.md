Views Themeable Text Area adds themeability to views text areas.

---

Views Themeable Text Area adds theme-ability to Views text areas — the header/footer/empty-text areas of
a View — so themers can target them with template suggestions and render them through templates rather than
raw output. It is in the Custom package.

Use it to theme Views text areas. It is a content-display/Views theming feature affecting how text areas
render; the text is admin-authored View config (rendered through the text format's filtering) and it has no
access-control role. Use the template suggestions in your theme.

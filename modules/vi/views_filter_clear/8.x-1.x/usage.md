Views Filter Clear adds links to clear or reset individual views exposed filters.

---

Views Filter Clear adds "clear"/"reset" links to individual Views exposed filters — so a user can remove
a single exposed-filter value (rather than resetting the whole form), making faceted/filtered listings easier
to refine. It depends on core Views.

Use it on Views with exposed filters where per-filter clearing improves UX. It is a site-search/Views-UI
feature affecting the exposed-filter UI; it shapes filter interaction, not results or access (the View's
access applies), and has no access-control role. Enable it on the relevant exposed filters.

# Views Filter Clear — agent index

Adds **clear/reset links to individual Views exposed filters** (remove a single filter value vs resetting the
whole form). Depends on core `views`. Version **8.x-1.1**. Core `^9||^10||^11`.

Site-search/Views-UI — shapes filter interaction, not results/access (View access applies); no access
role.

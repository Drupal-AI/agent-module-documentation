Views HTMX makes Views exposed filters and pagers reactive via HTMX without full reloads.

---

Views HTMX makes Views exposed filters and pagination reactive using the HTMX library (bundled with recent Drupal core) — so filtering and paging a view update in place via HTMX requests instead of full page reloads, giving a snappier, AJAX-like experience with a lightweight, standards-based approach.

It's a Views/UX enhancement with no content or access role of its own (results still respect view access). Depends on core `views`; requires Drupal 11.2+.

Views Timeline displays interactive timelines using Views, with customizable layouts, colors, and field mappings.

---

Views Timeline provides a Views display/style that renders results as an interactive timeline — mapping
date fields to a visual timeline with customizable layouts, colors and field mappings, for chronological
presentation of events/content. It depends on core Views, in the Views Timeline package.

Use it to present date-based content as a timeline. It is a content-display/Views feature affecting
presentation; the results respect the View's access and it has no access-control role. Select the timeline
style and map the date/label fields.

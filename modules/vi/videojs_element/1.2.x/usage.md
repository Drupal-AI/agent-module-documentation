Video.js Element provides a custom Video.js form element.

---

Video.js Element provides a **custom Video.js form/render element** — rendering a Video.js player as a
reusable element for video playback (with Video.js's controls/skins), usable in forms/render arrays. It is in
the Media package.

Use it to embed a Video.js player. It is a media/content-display feature; the video source is admin/editor-
configured and it has no content or access role. Use the Video.js element for playback.

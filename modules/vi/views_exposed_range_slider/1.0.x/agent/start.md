# Views Exposed Range Slider — agent index

Renders a Views **numeric-range exposed filter as a slider** (drag to filter a range — price/rating vs typing
min/max). Depends on core `views`. Version **1.0.0**. Core `^10||^11`.

Content-display/Views — affects the exposed-filter widget; results respect the View's access; no access
role.

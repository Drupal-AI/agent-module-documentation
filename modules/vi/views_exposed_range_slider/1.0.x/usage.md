Views Exposed Range Slider renders a Views range exposed filter as a slider widget.

---

Views Exposed Range Slider renders a Views numeric-range exposed filter as a **slider** — so instead of
typing min/max values, users drag a range slider to filter (e.g. price range, ratings). It depends on core
Views.

Use it for a friendly range-slider exposed filter. It is a content-display/Views feature affecting the
exposed-filter widget; the results respect the View's access and it has no access-control role. Configure the
slider on the range exposed filter.

A Views sort handler that sorts alphanumeric strings in human order.

---

Views Natural Sort provides a natural sort handler for Views that sorts alphanumeric strings in human-expected order (e.g. Item 1, Item 2, Item 10 — not Item 1, Item 10, Item 2) — so lists with mixed text+number values sort intuitively. Depends on core `views`; supports Drupal 11.3+ and 12.

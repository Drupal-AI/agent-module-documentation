View Mode Selector Field allows users to select a view mode for any content entity.

---

View Mode Selector Field adds a **field that lets editors choose the view mode** used to render a content
entity — so per entity, an editor can pick which display (teaser, full, custom) is used, e.g. when the entity
is referenced/rendered. It depends on core Field, provides its own permissions, in the Custom package.

Use it to let editors control per-entity display. It is a content-display/editing feature; it changes which
view mode renders (presentation), not access, and it has no access-control role beyond its permission. Add the
view-mode selector field.

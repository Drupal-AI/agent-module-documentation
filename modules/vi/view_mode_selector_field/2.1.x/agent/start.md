# View Mode Selector Field — agent index

A field that lets editors **select the view mode used to render a content entity** (pick teaser/full/custom per
entity). Depends on core `field`. Provides permissions. Version **2.1.1**. Core `^9||^10||^11`.

Content-display/editing — changes which view mode renders (presentation, not access); no access role beyond
permission.

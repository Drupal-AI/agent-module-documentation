Views ID provides unique identifiers for Views.

---

Views ID **provides unique identifiers for Views** — assigning a stable id/attribute to a view's output so
it can be reliably targeted (by CSS/JS or other modules), rather than relying on generated markup. It is in the
Views package.

Use it to give views a stable handle for scripting/styling. It is a developer/Views feature affecting markup
attributes; it has no content or access role. Configure the id on a view.

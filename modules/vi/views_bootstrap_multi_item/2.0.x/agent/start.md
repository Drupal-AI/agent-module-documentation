# Views Bootstrap Multi Item — agent index

A **Views style rendering results as a Bootstrap carousel with multiple visible items per slide** (e.g. 3 cards
per slide). Depends on core `views`. Version **2.0.0-rc1**. Core `^10||^11`.

Content-display/Views — affects presentation; results respect the View's access; no access role.

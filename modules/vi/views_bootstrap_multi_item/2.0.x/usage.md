Views Bootstrap Multi Item displays a Views result as a carousel with multiple visible items.

---

Views Bootstrap Multi Item provides a **Views style that renders results as a Bootstrap carousel showing
multiple items per slide** — so a listing displays as a multi-item carousel (e.g. 3 cards per slide) rather
than one item at a time. It depends on core Views, in the Views package.

Use it to present a View as a multi-item carousel. It is a content-display/Views feature affecting
presentation; results respect the View's access and it has no access-control role. Select the style on the
View.

# Views Minimum — agent index

A **Views condition checking whether a View returns results** (drive block/element visibility — show only when
a View has results, hide when empty). Depends on core `views`. Version **1.0.4**. Core `^9||^10||^11`.

Content-display/site-building — the underlying View enforces its own access (condition reflects results the
user can see); no access role.

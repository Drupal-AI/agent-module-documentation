Views Minimum adds a condition that lets you check if a View has results to determine visibility.

---

Views Minimum adds a **condition plugin** that checks whether a given **View returns results** — so you
can drive visibility (e.g. show a block only when a related View has at least some results, or hide it when
empty). It depends on core Views, in the Views package.

Use it to make block/element visibility depend on a View having results. It is a content-display/site-building
feature; the underlying View enforces its own access, so the condition reflects results the current user can
see, and it has no access-control role. Add the condition to a block's visibility.

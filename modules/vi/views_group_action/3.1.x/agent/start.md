# Views Group Action — agent index

Perform an **action on grouped results of a View** (bulk-style action on a group of rows, not individually).
`views_group_action_bootstrap` / `_footable` submodules. Depends on core `views`. Version **3.1.0**. Core
`^9.5||^10||^11`.

Admin/Views feature — actions modify content (govern by the action's permissions + operator access; restrict
destructive group actions). Configure on the View.

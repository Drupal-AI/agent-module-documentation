Views Group Action provides the ability to perform an action on grouped results of a view, with Bootstrap and FooTable submodules.

---

Views Group Action provides the ability to perform an action on grouped results of a View — applying a
bulk-style action to a group of rows (grouped by a field) rather than individually, useful for operating on
sets of related results. It ships `views_group_action_bootstrap` and `views_group_action_footable`
submodules for display integration. It depends on core Views.

Use it on Views where actions should apply to grouped result sets. It is an administration/Views feature
that performs actions on content; because actions modify content, access is governed by the action's own
permissions and the operator's access — as with Views Bulk Operations, ensure the available actions and who
can run them match your intent (destructive actions on groups should be restricted). Configure the grouped
action on the View.

# Video Embed Peertube — agent index

Adds a **PeerTube provider to Video Embed Field** (embed PeerTube — decentralized/self-hostable video —
alongside YouTube/Vimeo). Depends on `video_embed_field`. Config at `video_embed_peertube.settings`. Version
**3.1.0**. Core `^10.3||^11`.

Media/embed — embedded videos are remote content from the PeerTube instance; no access role.

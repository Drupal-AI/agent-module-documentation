Views Split is a Views display plugin that allows the first xx results to be shown in a different view mode than the rest.

---

Views Split is a Views display plugin that splits results — rendering the first N results in one view
mode and the remaining results in another. This supports patterns like a prominent "featured" first item (or
first few) followed by a compact list of the rest, from a single View. It depends on core Views.

Use it for listings with a distinguished lead item (a hero + list, a featured-then-grid layout). It is a
content-display/Views feature affecting how results render; the results and their access are unchanged (the
View's access applies), and it has no access-control role. Configure the split count and the two view
modes.

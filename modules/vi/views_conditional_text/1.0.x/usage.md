Show Views header/footer/empty text based on query results.

---

Views Conditional Text allows Views to display header, footer, or empty text based on query results without rendering fields or rows — so a View can show conditional messaging (e.g. 'you have N items' or a promo) driven by result counts/values, without outputting the actual result rows. Depends on core `views`; supports Drupal 10 and 11.

A Views field showing contextual links for each row's entity.

---

Views: Entity Contextual Links adds a Views field that displays contextual links for the entity represented in each row — so a listing View can show the same contextual (gear) operation links (edit, delete, etc.) that appear on the rendered entity, per row. Depends on core `views`; supports Drupal 11.

Views SQL Twig Fields provides Views support for fields, filter, sort and argument plugins with SQL Twig support.

---

Views SQL Twig Fields adds Views plugins (field, filter, sort, argument) that let site builders define
SQL expressions via Twig — so a View can compute fields/sorts/filters from custom SQL generated by an
admin-authored Twig template, giving advanced flexibility beyond standard Views handlers. It ships
`views_sql_twig_relationship` and `views_sql_twig_webform` submodules, provides its own permissions, in the
Views package.

Use it for advanced Views computed via SQL/Twig. **Security-relevant note:** this is a **powerful, admin-only**
feature — it lets a Views configurer inject SQL (built from Twig) into the query, so it must be treated as a
**trusted-administrator capability** (equivalent in power to writing raw SQL / a PHP snippet). Only grant the
permission to fully-trusted admins, and never expose the Twig/SQL configuration to untrusted users, because a
configurer can craft arbitrary queries. Ensure any Twig that incorporates argument/contextual values is
written safely (parameterize; don't concatenate untrusted input into SQL). It has no content-access role
beyond the query it builds (results still respect the View's access). Configure the SQL Twig handlers.

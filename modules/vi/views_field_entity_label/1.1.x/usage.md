Views Field Entity Label provides an Entity Label views field.

---

Views Field Entity Label provides an **"Entity Label" Views field** — outputting the label (title/name) of a
referenced entity in a view, without needing a relationship, for cleaner reference display. It works across core
9–11.

Use it to show a referenced entity's label in a view. It is a developer/Views feature; results follow the view's
access and it has no access-control role. Add the Entity Label field to a view.

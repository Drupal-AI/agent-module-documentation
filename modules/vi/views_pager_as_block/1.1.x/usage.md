Views Pager as Block renders the current views pager as a block.

---

Views Pager as Block **renders the current view's pager as a separate block** — letting you place the
pager independently of the view's output (e.g. in a different region), for layout flexibility. It is in the
Views package.

Use it to position a view's pager separately. It is a content-display/site-building feature affecting layout; it
has no content or access role. Place the pager block for a view.

Vite React Generator generates Vite + React apps.

---

Vite React Generator is a **developer scaffolding tool** — it generates **Vite + React** application
skeletons (for building decoupled/embedded front-end apps that integrate with Drupal), so developers can
bootstrap a modern JS front end quickly. It is in the Development package.

Use it as a scaffolding aid during development. It is a developer/build tool that generates front-end code; the
generated app's security is the developer's responsibility, and the module itself has no content or access
role. It is a dev-time tool — you don't need it enabled on production. Run the generator.

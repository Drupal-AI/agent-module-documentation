# Vite React Generator — agent index

A developer tool that **scaffolds Vite + React apps** for use with Drupal (bootstrap a decoupled/embedded JS
front end). Version **1.0.9**. Core `^10.3||^11`.

Developer/build tool — generates front-end code (generated-app security is the developer's responsibility);
dev-time only (not needed on production); no content/access role.

Views Exposed Form Mobile shows Views exposed filters in a mobile overlay UI.

---

Views Exposed Form Mobile **improves exposed filters on mobile** — presenting a view's exposed filters as a
multi-page overlay UI on mobile devices, for a better filtering experience on small screens. It works on core
10–11.

Use it for mobile-friendly exposed filters. It is a content-display/UX feature; it restyles the exposed filter form
on mobile and has no content or access role. Enable it for the mobile filter overlay.

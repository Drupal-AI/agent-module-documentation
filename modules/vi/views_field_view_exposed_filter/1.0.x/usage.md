Populate a view's exposed filter options from an Entity Reference view.

---

Views Field View Exposed Filter allows using an Entity Reference view display to populate the exposed-filter options of another view — so a View's exposed filter can be driven by a curated Entity Reference view (its results become the selectable options), giving dynamic, view-controlled filter choices. Depends on core `views`; supports Drupal 10 and 11.

Predefine the view mode per paragraph bundle in formatter settings.

---

View modes formatter settings provides the ability to predefine a view mode per paragraph bundle in the formatter settings — so an entity-reference/paragraphs field formatter can render each referenced paragraph bundle in a specific, pre-chosen view mode, giving fine-grained control over how mixed paragraph types display. Supports Drupal 8 and later.

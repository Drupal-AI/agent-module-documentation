Views Slider integrates the Swiper.js library into Views, displaying content as a responsive, customizable slider/carousel.

---

Views Slider integrates the Swiper.js library into Views — rendering View results as a responsive,
customizable slider/carousel with configuration for transitions, autoplay, navigation, pagination and
responsive breakpoints, all through the Views UI. Content fields (headings, descriptions, images, links) can
populate each slide, making it suitable for hero sliders, image carousels and product showcases. It is in the
Views Slider package.

Use it to build sliders/carousels from Views content without custom JS. It is a content-display/Views feature;
the slider content comes from the View and respects the View's access (only accessible content appears), and
it has no access-control role. Select the slider style on the View and configure the Swiper options.

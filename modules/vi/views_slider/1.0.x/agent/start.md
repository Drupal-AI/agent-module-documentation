# Views Slider — agent index

Renders a **View as a responsive Swiper.js slider/carousel** — configurable transitions/autoplay/navigation/
pagination/breakpoints via the Views UI (hero sliders, carousels, product showcases). Version **1.0.1**.
Core `^10||^11`.

Content-display/Views — slider content from the View, respects the View's access; no access role.

A mini Views pager that also shows current/total page numbers.

---

Views Pager Mini with Count provides a Views pager based on the Mini pager that displays the current page number and total pages — so a compact pager also tells users 'Page 3 of 12', combining the small footprint of the mini pager with useful position info. Depends on core `views`; supports Drupal 10, 11, and 12.

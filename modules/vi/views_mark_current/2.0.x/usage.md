Views mark current highlights the view row that corresponds to the current page.

---

Views mark current marks and highlights the current row in a view — the row that corresponds to the page/entity currently being viewed — by adding a class/marker, so navigation or listing views can visually indicate 'you are here', improving orientation.

It's a Views/display enhancement with no content or access role of its own. Depends on core `views`; supports Drupal 10.3+ and 11.

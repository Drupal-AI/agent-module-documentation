A Views header/footer link to embed an entity with operation links.

---

Views Editable Entity Header Area Plugin provides a Views header/footer link to embed an entity with operations links — so a View can show, in its header/footer, an embedded entity (rendered) together with its edit/delete/other operation links, useful for admin/dashboard views. Depends on core `views`; supports Drupal 10 and 11.

Views CSS Grid displays view results in a configurable CSS Grid layout.

---

Views CSS Grid provides a Views style plugin that renders results in a customizable CSS Grid — so a view's rows can be laid out in a modern CSS Grid (columns, gaps, responsive breakpoints) instead of a table or unformatted list, giving site builders flexible grid layouts without custom CSS.

It's a Views/theming style plugin with no content or access role of its own. Depends on core `views`; supports Drupal 10 and 11.

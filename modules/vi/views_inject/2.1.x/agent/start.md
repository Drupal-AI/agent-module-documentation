# Views Inject Results — agent index

Injects **items from one Views display into another** (mix results — e.g. interleave promoted items,
combine sources). Depends on core `views`. Version **2.1.0**. Core `^9||^10||^11`.

Content-display/Views — injected items respect their own view's access; no access role of its own.

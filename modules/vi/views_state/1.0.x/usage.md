Display Drupal State values in a view.

---

Views State allows displaying the Drupal State on a view — exposing values from Drupal's State system (key/value runtime state) as Views fields, so operational/state data can be surfaced in an admin view for monitoring/debugging. Depends on core `views`; supports Drupal 9, 10, and 11.

Views Layout Row provides layout-based row rendering for Views.

---

Views Layout Row **renders view rows with layouts** — a Views row plugin that renders each row using a Layout
(Layout Discovery/Layout Builder layouts), so view results can use multi-region layouts per row. It depends on core
Views and Layout Discovery.

Use it for layout-driven view rows. It is a content-display/theming feature; it renders content in layouts and has
no access-control role. Configure the layout row on a view.

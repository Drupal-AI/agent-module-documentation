Views CSS Style provides a views style that renders inline css.

---

Views CSS Style provides a Views display style that outputs results with inline CSS — letting a View
generate/attach CSS (e.g. per-row styles driven by field values) inline with its output, for data-driven
styling. It is a Views style plugin.

Use it where a View needs to emit inline CSS. It is a content-display/Views feature affecting output styling;
the CSS is admin-configured (from the View) and the results respect the View's access, and it has no
access-control role. Note: if the inline CSS incorporates field values, ensure those are appropriate for a
CSS context (admin-configured Views typically are). Select the CSS style on the View.

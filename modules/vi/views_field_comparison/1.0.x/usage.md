Views field comparison provides a Views plugin to filter results by comparing the values of two fields.

---

Views field comparison provides a Views filter plugin that filters results by comparing two fields —
so a View can show only rows where one field's value relates to another (equal, greater than, etc.),
comparison that core Views filters (which compare a field to a fixed value) can't do directly. It depends on
core Views.

Use it where filtering depends on the relationship between two fields (e.g. "start date before end date",
"quantity > threshold field"). It is a site-search/Views feature shaping the query; results still respect
the index/entity access, and it has no access-control role. Add the comparison filter to the View.

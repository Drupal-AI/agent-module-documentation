# Views field comparison — agent index

Views **filter plugin comparing two fields** (show rows where one field relates to another — equal/greater/
etc.; core filters can only compare a field to a fixed value). Depends on core `views`. Version **1.0.1**.
Core `^10||^11||^12`.

Site-search/Views — shapes the query, respects index/entity access; no access role.

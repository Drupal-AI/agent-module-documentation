Views Area Menu Block provides a Views area plugin that renders a menu block.

---

Views Area Menu Block **renders a menu in a view area** — a Views area plugin to place a menu (as a block) in
a view's header/footer, for contextual navigation within listings. It depends on core Views.

Use it to add a menu to a view. It is a site-building/Views feature; the menu follows normal menu access and it has
no access-control role. Configure the menu area on a view.

Views Area Library provides a Views area plugin to attach a library to a view.

---

Views Area Library **attaches an asset library to a view** — a Views area plugin that lets you attach a CSS/JS
library to a view's header/footer, so a view can load the assets it needs. It depends on core Views.

Use it to load assets with a view. It is a theming/Views feature; it attaches libraries and has no content or
access role. Configure the library area on a view.

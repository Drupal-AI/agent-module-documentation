Views Row SDC renders each Views row using a Single Directory Component.

---

Views Row SDC **renders view rows with an SDC** — a Views row plugin that displays each result item using a
Single Directory Component (SDC), for component-driven view output. It works on core 11.3+.

Use it for component-based view rows. It is a theming/Views feature; it renders content via SDC and has no
access-control role. Configure the SDC row on a view.

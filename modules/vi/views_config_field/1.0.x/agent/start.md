# Views Config Field — agent index

**Displays a configuration value in a view**. Depends on core `views`. Version **1.0.0**. Core `>=10.3`.

Views/display — outputs **configuration values** (config can be sensitive; expose only keys safe for the audience,
don't surface secret config publicly); no access role.

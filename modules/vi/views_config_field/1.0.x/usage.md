Views Config Field displays a configuration value in a view.

---

Views Config Field **shows a config value in a view** — a Views field that outputs a value from Drupal
configuration, so a view can display site/config settings alongside content. It depends on core Views.

Use it to surface config values in views. It is a Views/display feature. Security note: it can output
**configuration values** — configuration sometimes contains sensitive settings, so only expose config keys that are
safe to show to the view's audience (don't surface secret/settings config publicly). It has no access-control role.
Configure the config field.

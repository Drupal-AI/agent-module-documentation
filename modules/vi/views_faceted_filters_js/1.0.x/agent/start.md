# Views Faceted Filters JS — agent index

A **simple data-attributes-based JS faceted filter for Views results** (client-side, no round-trip). Depends on
core `views`. Version **1.0.x** (dev). Core `^8.9||^9||^10||^11`.

Content-display/Views — filters **already-loaded results** (presentation, not a data boundary — send only rows
the user may see). No access role.

Views Sort Reverse provides a Views sort plugin that reverses the order of view results.

---

Views Sort Reverse provides a **Views sort plugin that reverses the result order** — applied as a sort, it
flips the ordering of the View's results, useful for reversing an otherwise fixed/derived order without
redefining the sort criteria. It depends on core Views, in the Views package.

Use it to reverse a View's result order. It is a content-display/Views feature affecting ordering only; results
respect the View's access and it has no access-control role. Add the reverse sort to a View.

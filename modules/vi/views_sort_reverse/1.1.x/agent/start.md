# Views Sort Reverse — agent index

A **Views sort plugin that reverses the order of results** (flip ordering without redefining sorts). Depends on
core `views`. Version **1.1.1**. Core `^10.3||^11||^12`.

Content-display/Views — affects ordering only; results respect the View's access; no access role.

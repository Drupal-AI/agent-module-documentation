# View Mode Conditional Fields — agent index

Controls the **visibility of form-display fields per view mode** (show a different field subset on the edit
form per view mode). Depends on core `field`. Version **1.0.4**. Core `^9||^10||^11`.

Content-editing/form-display — affects which fields show on the form; field data/access follow normal field
access; no access role.

View Mode Conditional Fields controls the visibility of fields on form display per view mode.

---

View Mode Conditional Fields lets you **control which fields appear on the entity form depending on the
selected view mode** — so the edit form can show a different subset of fields per view mode, tailoring the
authoring experience. It depends on core Field, in the Fields package.

Use it to tailor edit forms by view mode. It is a content-editing/form-display feature affecting which fields
are shown on the form; the fields' data and access follow normal field access, and it has no access-control
role. Configure the per-view-mode field visibility.

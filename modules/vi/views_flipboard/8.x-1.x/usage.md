Views Flipboard provides views for a Flipboard-like RSS feed layout.

---

Views Flipboard provides a Views display/style that renders results in a Flipboard-like layout — a
flip/magazine-style presentation of content (like an RSS/feed reader), for visually browsing a list of items.
It depends on core Views.

Use it to present a View as a Flipboard-style layout. It is a content-display/Views feature affecting
presentation; the results respect the View's access and it has no access-control role. Select the Flipboard
style on the View.

Views Query provides an extensible plugin system for Views queries.

---

Views Query provides an **extensible plugin system for Views queries** — letting developers plug in custom
query alterations/behaviours in a structured, discoverable way rather than scattered hook_views_query_alter
code. It depends on core Views, in the Views package.

Use it as a developer foundation for query customization. It is a developer/API feature; queries it builds still
run through Views' access/filtering, and it has no access-control role. Define query plugins.

# Viber Channel — agent index

**Sends messages to a Viber channel/bot** from Drupal. Provides permissions. Version **1.0.3**. Core
`^9.2||^10||^11`.

Integration/messaging — **Viber token** as a secret (env/Key, HTTPS; leaked token = post as bot); keep content
non-sensitive, gate who can send. No access role beyond permission.

Views Extra Exposed Form Blocks exposes a view's exposed filter form as an embeddable block.

---

Views Extra Exposed Form Blocks provides an embed Views display type which allows an exposed (filter) form to be placed as a block — so a view's exposed filters can appear in any region/block position independently of the view's results, useful for search/filter boxes in sidebars or headers.

It's a Views/site-building tool with no content or access role of its own. Depends on core `views`; supports Drupal 8 through 11.

# ViewerJS Formatter — agent index

A field formatter that **renders document files (PDF/ODF) with the ViewerJS viewer** (inline document display vs
download links). Depends on core `file`. Version **1.0.6**. Core `^8.8||^9||^10||^11`.

Media/content-display — files follow core file access; renders client-side (only expose viewable files); no
access role.

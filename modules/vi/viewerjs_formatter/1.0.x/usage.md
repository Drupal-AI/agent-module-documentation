ViewerJS Formatter renders a list of files with the ViewerJS viewer.

---

ViewerJS Formatter provides a **field formatter that renders document files with ViewerJS** — displaying
PDF and ODF (OpenDocument) files inline in a document viewer instead of as download links. It depends on core
File, in the Fields package.

Use it to display documents inline. It is a media/content-display feature; the files follow core file access
and it has no access-control role. Note ViewerJS renders documents **client-side in the browser** (the file is
served to the viewer) — as with any document display, only expose files meant to be viewable. Choose the
ViewerJS formatter on a file field.

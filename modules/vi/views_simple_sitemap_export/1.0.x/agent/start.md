# Views Simple XML Sitemap Export — agent index

Exports a **View's results (URLs) into a sitemap managed by Simple XML Sitemap** (include arbitrary
View-defined URL sets in the XML sitemap). Depends on core `views`, `simple_sitemap`. Version
**1.0.0-beta5**. Core `^10||^11`.

SEO — a sitemap advertises URLs; ensure the View exposes only **public/crawlable** content (not private/
restricted). No access role.

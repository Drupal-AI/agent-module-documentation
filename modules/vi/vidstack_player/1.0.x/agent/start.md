# Vidstack Player — agent index

Integrates the **Vidstack media player** for video/audio (`vidstack_player_cookies` consent submodule). Depends
on core `media`. Version **1.0.0-beta1**. Core `^10.3||^11`.

Media/content-display — third-party media embeds carry the usual privacy note (cookies submodule gates behind
consent); no content/access role.

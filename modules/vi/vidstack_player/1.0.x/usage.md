Vidstack Player provides an integration for the Vidstack player.

---

Vidstack Player **integrates the Vidstack media player** — a modern, customizable web player for video/audio
(including provider embeds), with a `vidstack_player_cookies` submodule for cookie/consent handling. It depends
on core Media.

Use it for a modern media player. It is a media/content-display feature. Privacy note: if it plays
**third-party-hosted** media (YouTube/Vimeo/etc.), the usual embed privacy considerations apply — the
`vidstack_player_cookies` submodule helps gate cookie-setting behind consent. It has no content or access role.
Configure the Vidstack player on media.

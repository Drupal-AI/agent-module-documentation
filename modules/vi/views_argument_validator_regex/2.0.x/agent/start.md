# Views Contextual Filter Validator: Regex — agent index

**Regex argument validator** for Views contextual filters (accept only argument values matching a configured
regex). Depends on core `views`. Version **2.0.2**. Core `^9.5||^10||^11`.

Site-search/Views — validates argument format (not access control; write anchored patterns). No access
role.

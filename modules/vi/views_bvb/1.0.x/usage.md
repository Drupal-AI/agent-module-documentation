Better Views Block (BVB) lets block displays override views blocks via block configuration.

---

Better Views Block (views_bvb) **lets block config override a views block** — so a placed Views block can have
its arguments/settings overridden per block placement (via the block configuration form), for flexible reuse of one
view in different blocks. It depends on core Views.

Use it to reuse a view block with per-placement settings. It is a site-building/Views feature; block content
follows normal view/block access and it has no access-control role. Configure the overrides per block.

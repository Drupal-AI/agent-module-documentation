View Entity Render Popup provides a field formatter to display entity reference fields' targets in a modal popup.

---

View Entity Render Popup provides a field formatter for entity-reference fields that displays the
referenced entity in a modal popup — so instead of navigating to the referenced entity, a click opens it
rendered in a modal overlay. It depends on core Field. This is useful for quick previews of referenced
content without leaving the page.

Use it where referenced entities should open in a modal preview. It is a content-display/formatter feature;
the referenced entity is rendered respecting its own access (only accessible targets render in the popup),
and it has no access-control role. Select the popup formatter on the reference field.

Views REST Export Field Grouping adds a Views style plugin for REST export that allows grouping results by fields.

---

Views REST Export Field Grouping adds a Views style plugin for REST export that supports grouping —
so a REST-export view can return results grouped by a field value (organizing the JSON/XML output into
grouped structures) rather than a flat list. This lets API consumers receive data organized meaningfully
(e.g. items grouped by category). It depends on core Views and REST.

Use it on REST-export views where the API output should be grouped. It is a decoupled/web-services feature
shaping REST output; the exported data respects the view's access (only accessible content is exported), and
it has no access-control role. Configure the grouping field on the REST-export view.

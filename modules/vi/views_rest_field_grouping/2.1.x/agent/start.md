# Views REST Export Field Grouping — agent index

Views **style plugin for REST export that groups results by field values** (grouped JSON/XML output vs a
flat list). Depends on core `views`, `rest`. Version **2.1.0**. Core `^10||^11`.

Decoupled/web-services — shapes REST output; exported data respects the view's access; no access role.
Configure the grouping field.

Crop images differently per view mode.

---

View Mode Crop allows cropping of images — letting editors define per-view-mode image crops so the same image field can present different crop framings in different displays (e.g. a wide crop in a hero, a square crop in a teaser), building on core image/responsive image. Depends on core `image` and `responsive_image`; supports Drupal 9, 10, and 11.

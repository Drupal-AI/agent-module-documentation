Views Entity Reference brings additional functionality around entity references in Views.

---

Views Entity Reference **adds functionality around entity-reference fields in Views** — improving how
referenced entities are queried/displayed/filtered in views (e.g. reverse references, richer reference
handling). It depends on core Views, in the Views package.

Use it for richer entity-reference behaviour in views. It is a developer/site-building feature; results follow
Views' access/filtering and it has no access-control role. Use it when building reference-based views.

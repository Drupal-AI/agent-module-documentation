Inject admin-defined Twig into entity view/form displays via config.

---

View Mode Twig Field allows admins to inject Twig code into Entity View and Form displays via config — so a site builder can add a computed/templated pseudo-field rendered from Twig directly in a display, without a custom module.

Because it renders admin-authored Twig, it is effectively an admin-only capability equivalent to granting template access — restrict the configuring permission to trusted administrators (do not expose the Twig to untrusted input). Supports Drupal 10.5+ and 11.

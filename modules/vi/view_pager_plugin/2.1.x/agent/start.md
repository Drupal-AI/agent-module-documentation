# View Page Control (view_pager_plugin) — agent index

Controls **how many items show on the first page vs subsequent pages** of a paginated View (asymmetric
per-page counts — e.g. feature more on page 1). Version **2.1.0**. Core `^8||^9||^10||^11||^12`.

Content-display/Views — affects pagination; results respect the View's access; no access role.

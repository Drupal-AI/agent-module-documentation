View Page Control provides control over the item values displayed on the first page and subsequent pages of a View.

---

View Page Control (view_pager_plugin) lets you control the number of items shown on the **first page**
versus **subsequent pages** of a paginated View — so, for example, a listing can show a different count on
page 1 (e.g. featuring more, or fewer) than on later pages. It is in the Views package.

Use it for asymmetric per-page item counts in a View. It is a content-display/Views feature affecting
pagination; the results respect the View's access and it has no access-control role. Configure the first-page
and subsequent-page counts.

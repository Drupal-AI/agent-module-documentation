Views Pager Token lets you use tokens in a view's pager configuration.

---

Views Pager Token allows tokens to be entered in the Views pager settings — so pager configuration (e.g. items per page) can use dynamic token values instead of only static numbers, letting the pager adapt to context (user, entity, config) via the token system.

It's a Views/site-building enhancement with no content or access role of its own. Depends on core `views` and `token`; requires Drupal 10.3+.

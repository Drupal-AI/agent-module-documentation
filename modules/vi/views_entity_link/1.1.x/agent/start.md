# Views Entity Link — agent index

Provides **entity operation links (view/edit/delete)** as **Views fields** (per-row action links in
listings). Depends on core `views`. Version **1.1.1**. Core `^10||^11`.

Content-display/Views — generated links **respect entity access** (surface entitled operations, grant no
new access). Add the link field to the View.

Views Entity Link provides links for entities (such as view, edit, delete) that can be added as fields within a View.

---

Views Entity Link provides entity link fields for Views — adding links (view, edit, delete, or other
entity operations) as Views fields so a listing can include action links for each row's entity. It depends
on core Views. This is handy for building admin/content listings with per-row action links.

Use it to add entity operation links to Views listings. It is a content-display/Views feature; the links
it generates respect the entity's access (an edit link only works for users who can edit, and the links
honour access checks), so it surfaces operations the user is entitled to, not new access. Add the link
field to the View and choose the operation.

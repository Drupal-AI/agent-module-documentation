Views Taxonomy Name Default Argument supplies a term by name as a Views default argument.

---

Views Taxonomy Name Default Argument lets you provide a taxonomy term by name as the default argument for a view's contextual filter — so a view can default its taxonomy contextual filter to a named term (rather than a term ID), making configuration more readable and portable across environments.

It's a Views/site-building enhancement with no content or access role of its own. Depends on core `taxonomy` and `views`; supports Drupal 9, 10, and 11.

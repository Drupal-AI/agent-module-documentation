Views Porter Stemmer ignores suffixes and plurals in Views filters.

---

Views Porter Stemmer provides a **Views filter that applies Porter stemming** — reducing words to their
stem so a text-search filter matches across suffixes/plurals (e.g. "run" matches "running"/"runs"), for more
forgiving in-view search. It is in the views package.

Use it for stemmed text filtering in views. It is a site-search/Views feature affecting query matching; results
follow Views' access and it has no access-control role. Add the stemmer filter to a view.

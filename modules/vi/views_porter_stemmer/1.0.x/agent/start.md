# Views Porter Stemmer — agent index

A **Views filter plugin that applies Porter stemming** (ignore suffixes/plurals in text searches). Version
**1.0.2**. Core `>=9.2 <11.0.0-stable || ^11`.

Site-search/Views — affects query matching; results follow Views' access; no access role.

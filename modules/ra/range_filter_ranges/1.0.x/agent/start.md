# Range Filter Ranges — agent index

A Views **filter that filters by predefined ranges (buckets) over a numeric-range field** (pick "£0–50"/"£50–
100" vs exact values). Depends on core `views`. Version **1.0.x** (dev). Core `^9||^10||^11`.

Content-display/Views — affects the filter; results respect the View's access; no access role.

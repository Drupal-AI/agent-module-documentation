Range Filter Ranges defines a range filter for a numeric range field.

---

Range Filter Ranges provides a Views filter for numeric-range fields — letting a View be filtered by
predefined ranges (buckets), so users pick a range (e.g. "£0–50", "£50–100") rather than entering exact
values. It depends on core Views.

Use it for bucketed range filtering in Views. It is a content-display/Views feature affecting the filter; the
results respect the View's access and it has no access-control role. Configure the range buckets on the
filter.

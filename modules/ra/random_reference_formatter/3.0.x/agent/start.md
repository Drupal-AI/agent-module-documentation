# Random Entity Reference Formatter — agent index

Renders a **random subset of referenced entities via AJAX** (configurable count — rotating featured/related
items; AJAX preserves page caching). Version **3.0.1**. Core `^10.1||^11`.

Content-display/formatter — referenced entities render respecting their own access (only accessible appear);
no access role.

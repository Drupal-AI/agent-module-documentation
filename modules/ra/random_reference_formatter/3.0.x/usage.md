Random Entity Reference Formatter pulls up and renders a given number of random referenced items using AJAX.

---

Random Entity Reference Formatter renders a random subset of an entity-reference field's referenced
items — showing a configurable number of randomly-selected references, loaded via AJAX (so the randomization
happens per-request without breaking page caching of the surrounding page). This is useful for "random
featured items", rotating spotlights, or varied related content. It is in the Field types package.

Use it to show a rotating random selection of referenced content. It is a content-display/formatter feature;
the referenced entities are rendered respecting their own access (only accessible items appear), and it has
no access-control role. Select the formatter on the reference field and set how many random items to show.

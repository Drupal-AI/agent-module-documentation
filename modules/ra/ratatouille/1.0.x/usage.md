Ratatouille generates configuration and content recipes easily.

---

Ratatouille **generates configuration and content recipes** — tooling to build Drupal recipes (packaged
config + default content) more easily, for reusable site setups. It depends on core Default Content and
Serialization.

Use it to author recipes. It is a developer/site-building tool; it exports config/content into recipes and has no
content or access role. Note: recipes can include content/config — review recipe contents before sharing so you
don't leak sensitive config. Use it to generate recipes.

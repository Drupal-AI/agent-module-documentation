Integrate the RAIL Score API for AI content evaluation/moderation.

---

RAIL Score integrates the RAIL Score API for responsible AI content evaluation and moderation — sending content to the RAIL Score service to score it for responsible-AI concerns (toxicity, bias, safety) so a site can flag or moderate problematic content.

The RAIL Score API key is admin-configured; store it securely (env-backed / Key entity), never committed. Depends on core `field`, `node`, and `user`; supports Drupal 9, 10, and 11.

Integrate with the Raisely fundraising platform API.

---

Raisely provides an integration with the Raisely API — connecting Drupal to the Raisely fundraising/donation platform so campaigns, donations and related data can be fetched and displayed (or synced) on the site.

The Raisely API credentials are admin-configured; store them securely (env-backed), never committed. Supports Drupal 10.1+ and 11.

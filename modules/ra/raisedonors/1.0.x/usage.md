RaiseDonors connects Drupal to the RaiseDonors fundraising/donor platform.

---

RaiseDonors integrates Drupal 11 with the RaiseDonors fundraising platform — syncing donors and donation data between Drupal and RaiseDonors so nonprofits can manage supporters and campaigns, with a donors view and address/telephone fields for donor records.

RaiseDonors API credentials are stored via the Key module (env-backed); administration is gated by `administer raisedonors module settings`. Depends on core `user`, `views`, `telephone`, `key`, and `address`; requires Drupal 11.

Radios to Slider provides a field widget using the radios-to-slider jQuery plugin, rendering a set of radio options as an interactive slider.

---

Radios to Slider provides a field widget that turns a set of radio-button options into an
interactive slider using the radios-to-slider jQuery plugin — a friendlier UI for ordered/scaled
choices (ratings, satisfaction levels, ranges of discrete options). It depends on core Options
(list fields) and applies as a widget on options-based fields.

Use it where a field with a small ordered set of allowed values reads better as a slider than as radio
buttons (e.g. a 1–5 scale). It is a content-editing/form-widget feature affecting input presentation;
the stored value is still one of the field's allowed options, and it has no access implications.
Configure it as the widget on the relevant list/options field.

# Radios to Slider — agent index

Field **widget rendering radio options as a slider** (radios-to-slider jQuery plugin) — friendlier UI
for ordered/scaled choices (e.g. 1–5). Depends on core `options`. Version **2.0.4**. Core `^10.3||^11`.

Form-widget/presentation — stores a standard allowed-option value; no access implications.

Rabbit Hole Links alters entity links to use the rabbit_hole settings.

---

Rabbit Hole Links **alters entity links to respect Rabbit Hole settings** — so a link to an entity that
Rabbit Hole configures to redirect / show 403/404 / display-as-content honors that behaviour (e.g. a link
points to the redirect target rather than a page that would just bounce). It depends on the Rabbit Hole module,
in the Rabbit Hole package.

Use it on Rabbit Hole sites for consistent linking. It is a site-structure/navigation feature; the actual
page-behaviour/access is governed by **Rabbit Hole** (this aligns links to it), and it has no access-control
role of its own. Enable it alongside Rabbit Hole.

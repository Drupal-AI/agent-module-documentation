# Rabbit Hole Links — agent index

**Alters entity links to respect the entity's Rabbit Hole (page-behavior) settings** (link to the redirect
target vs a bouncing page). Depends on `rabbit_hole`. Version **1.0.4**. Core `^10||^11`.

Site-structure/navigation — page behaviour/access governed by **Rabbit Hole** (this aligns links); no access
role of its own.

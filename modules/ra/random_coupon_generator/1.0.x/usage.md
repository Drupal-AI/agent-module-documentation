Configure and bulk-generate random coupon codes.

---

Random Coupon Generator provides admin forms to configure and generate random coupon codes — letting a site administrator define a code pattern (length, charset, prefix, quantity) and bulk-generate unique random coupon codes for promotions/campaigns. Supports Drupal 9, 10, and 11.

Zoom on Hover provides an image zoom field formatter with multiple zoom modes.

---

Zoom on Hover **adds image zoom on hover** — a field formatter with a custom JS engine that magnifies images
on hover/touch, supporting box, circle, inside and background zoom modes (with fullscreen, captions, scroll-to-zoom).
It depends on core Image and Field.

Use it for product-style image zoom. It is a media/display feature; images render per normal file/field access and
it has no access-control role. Configure the zoom formatter on an image field.

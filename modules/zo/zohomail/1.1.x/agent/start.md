# Zoho Mail — agent index

**Sends site email via the Zoho Mail (third-party) API**, integrated with Mail System. Depends on `mailsystem`.
Provides permissions. Version **1.1.0**. Core `^8.8||^9||^10||^11`.

Mail/integration — **Zoho API credentials** as a secret (env/Key, HTTPS; can send as your domain); mail content/
recipients pass through **Zoho** (third-party). No access role beyond permission.

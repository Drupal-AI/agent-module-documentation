Integrate Drupal with a Zotero CiteProc JS citation server.

---

Zotero CiteProc JS Server Integration integrates Drupal with a Zotero CiteProc JS server — so bibliographic references can be formatted into citations/bibliographies (in CSL styles) by a CiteProc-JS server, for academic/research sites that manage references with Zotero.

The CiteProc server endpoint is admin-configured. Depends on `auto_config_form`; supports Drupal 8.8 through 11.

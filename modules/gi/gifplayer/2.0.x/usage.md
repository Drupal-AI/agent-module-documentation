GIF Player provides GIF Player field types.

---

GIF Player provides a **GIF-player field type/formatter** — showing an animated GIF as a paused still that
plays on click (and pauses again), reducing motion/bandwidth until the user opts in. It depends on core Field
and File, in the Field package.

Use it to add click-to-play GIFs. It is a media/fields feature; GIF files follow core file access and it has no
content or access role. Add the GIF-player field and formatter.

# GIF Player — agent index

A field type/formatter that **plays animated GIFs on click** (paused still by default — reduce motion/bandwidth).
Depends on core `field`, `file`. Version **2.0.5**. Core `^10.3||^11`.

Media/fields — GIFs follow core file access; no content/access role.

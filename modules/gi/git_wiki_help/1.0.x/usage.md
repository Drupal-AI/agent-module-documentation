Clones a git wiki into Drupal help pages.

---

Git wiki help adds a cloned git wiki into Drupal help pages — pulling documentation from a git wiki repository and rendering it within the site's Help section, so a project's wiki docs are available in-admin. Depends on core `help`, `file`, and `filter`; supports Drupal 10 and 11.

OAI-PMH LAC provides an OAI-PMH XML feed of Dublin Core metadata for Library and Archives Canada.

---

OAI-PMH LAC **provides an OAI-PMH metadata feed** — exposing an OAI-PMH (Open Archives Initiative Protocol for
Metadata Harvesting) XML endpoint with Dublin Core metadata formatted for Library and Archives Canada (LAC)
harvesting. It depends on the Metatag DC and REST OAI-PMH modules.

Use it to let LAC (or other harvesters) harvest your metadata. It is a metadata/interoperability feature.
Data-handling note: OAI-PMH endpoints are **designed to be publicly harvestable**, so the exposed metadata is
effectively public — ensure only **published/public** content's metadata is included, and review the Dublin Core
fields for anything sensitive. It has no access-control role. Configure the OAI-PMH feed.

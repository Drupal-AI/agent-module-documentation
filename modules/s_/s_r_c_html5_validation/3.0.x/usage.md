Auto-apply HTML5 validation to select/radio/checkbox fields.

---

Select Radio Checkbox Field HTML 5 Validation adds HTML5 validation for select, radio and checkbox fields automatically on all forms — so required select/radio/checkbox inputs get native browser HTML5 required-field validation (which Drupal's default markup doesn't reliably provide for these element types), improving client-side form UX. Supports Drupal 10.1+, 11, and 12.

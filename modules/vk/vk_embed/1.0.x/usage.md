VK Embed provides a CKEditor 5 plugin and text filter to embed VK posts.

---

VK Embed **embeds VK (VKontakte) posts** — a CKEditor 5 plugin and text filter for inserting and rendering VK
social posts in content. It depends on core CKEditor 5 and Filter.

Use it to embed VK posts. It is a content-editing/display feature. Note: embedding loads **third-party VK content/
scripts** into the page (privacy/consent for third-party content), and the embed markup passes through the text
filter — ensure the filter renders only intended VK embeds. It has no access-control role. Configure the VK embed
filter.

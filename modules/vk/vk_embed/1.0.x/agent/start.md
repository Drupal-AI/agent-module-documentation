# VK Embed — agent index

**CKEditor 5 plugin and text filter for embedding VK posts**. Depends on core `ckeditor5`, `filter`. Version
**1.0.2**. Core `^10.3||^11||^12`.

Content-editing/display — loads **third-party VK content/scripts** (privacy/consent); embed via the text filter. No
access role.

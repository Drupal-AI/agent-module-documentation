Comment Submissions Limit throttles how many comments can be posted per type and time window.

---

Comment Submissions Limit limits comment submissions per comment type, comment values and time interval — so a site can throttle how many comments a user can post within a given period (and per comment type/value), a simple anti-spam/anti-flood control that reduces comment abuse without a full CAPTCHA.

It's a defensive rate-limiting control for comments. Depends on core `comment`; supports Drupal 10 and 11.

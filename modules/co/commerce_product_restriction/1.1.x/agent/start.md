Commerce Product Restrictions (v1.1.x): plugin-based purchase restrictions. Plugin type ProductRestriction (src/Plugin/Commerce/ProductRestriction/*: Dates, UserRole, User, Password, PurchaseQuantity, PurchasedProduct[Variation]); manager plugin.manager.product_restriction. AvailabilityChecker::checkVariation evaluates rules. SECURITY: the 'commerce_order.availability_checker' service tag is COMMENTED OUT in commerce_product_restriction.services.yml, so restrictions are only enforced by form_alter disabling the submit button -- NOT server-side. A crafted/programmatic add-to-cart bypasses all restrictions (incl. PasswordRestriction). Depends on commerce + commerce_cart.

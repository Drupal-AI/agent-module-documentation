Comment Admin Pages shows comment edit and delete forms as admin pages, rendering them in the admin theme.

---

Comment Admin Pages renders the comment edit and delete forms as admin pages — using the admin theme
for these operations, rather than the front-end theme, giving a more consistent back-end experience for
moderators editing/deleting comments. It depends on core Comment.

Use it where comment moderation should happen in the admin theme. It is an administration/UI feature
affecting where/how comment edit/delete forms render; it respects existing comment permissions (it changes
presentation, not who can edit/delete comments) and has no access-control role. Enable it for admin-themed
comment operations.

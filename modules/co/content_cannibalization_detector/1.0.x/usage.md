Detects SEO keyword cannibalization where multiple pages compete for the same keywords.

---

Content Cannibalization Detector detects SEO keyword cannibalization — where multiple pages compete for the same keywords, hurting search rankings — and provides a dashboard with severity scores and actionable recommendations, so editors can find and fix pages that undermine each other in search. Depends on core `node` and `path_alias`; supports Drupal 10, 11, and 12.

# Entities: App, Marketplace, Item, Fulfillment

Four `ContentEntityType`s, all admin UI under `/admin/commerce/amazon/*`. Regions and
marketplace-ID→country maps are constants on `Entity/AmazonAppInterface`
(`AMAZON_MARKETPLACES`, `AMAZON_REGIONS`).

## Amazon App — `commerce_amazon_app` (`Entity/AmazonApp`)

The SP-API application + its LWA credentials. `admin_permission = administer commerce_amazon_app`
(permissions generated by the `entity` module). Base fields (`baseFieldDefinitions`):

| field | type | notes |
|-------|------|-------|
| `name` | string | admin label |
| `client_id` | string | LWA client id |
| `client_secret` | string | LWA client secret |
| `application_id` | string | Amazon application id |
| `seller_id` | string | Amazon Seller / Merchant token (used in Listings paths) |
| `mode` | boolean | `on_label=Production` / `off_label=Sandbox`; `isProduction()` |
| `region` | list_string | one of `AMAZON_REGIONS` (`us-east-1` / `eu-west-1` / `us-west-2`) |
| `marketplaces` | list_string (multi) | participating marketplace ids; populated from Amazon on auth |
| `refresh_token` | string(1024) | LWA refresh token; **form widget shown only when the entity is new** (`AmazonAppForm`) |
| `access_token` | string(1024) | cached LWA access token (no form widget) |
| `expires_in` | created (timestamp) | access-token expiry |
| `logging` | boolean | when on, `ApiClient` logs API response bodies to the logger (default off) |
| `status`, `uid`, `created`, `changed` | | standard |

Endpoint helpers: `getEndpointByRegion()` maps region → `sellingpartnerapi-{na,fe,eu}.amazon.com`;
`getApiEndpointByCountry()` maps a country code likewise. Both prepend `sandbox.` unless
`isProduction()`. `getApiEndpointById($marketplace_id)` resolves via `AMAZON_MARKETPLACES`.

`AmazonAppForm::save()` calls `ApiClient::refreshAccessToken()` after save — so saving the App
performs the LWA token exchange and pulls the participating marketplaces. The `marketplaces` widget
is shown but disabled on edit (read-only).

## Amazon Marketplace — `commerce_amazon_marketplace` (`Entity/AmazonMarketplace`)

One Amazon region under an App, plus the rules for which Commerce orders get fulfilled there.
Custom access handler `AmazonMarketplaceAccessControlHandler`; storage `AmazonMarketplaceStorage`
(has `loadAvailable($order)`); route provider `AmazonMarketplaceRouteProvider` adds the
`integration` form route (`_entity_access: commerce_amazon_marketplace.update`).
Key fields: `label`, `amazon_app` (ref, required), `marketplace_id` (list_string, constraint
`AmazonMarketplaceId`), `order_types` (ref commerce_order_type), `stores` (ref commerce_store),
`conditions` + `condition_operator` (Commerce condition plugins), `items` (ref
commerce_amazon_item), `sync_items` (bool, default yes), `incremental_sync` (bool),
`preview_fulfillment` (bool), `mapping` (map — serialized integration config), `status`.

Behaviour:
- `preSave()` rejects a marketplace whose `marketplace_id` is not among the parent App's
  participating marketplaces (`EntityMalformedException`).
- `isEligible(OrderInterface $order)` — order qualifies if its shipping-profile country matches the
  marketplace country AND the Commerce `ConditionGroup` (conditions + operator) evaluates true; no
  conditions ⇒ always eligible.
- Mapping accessors: `getFulfillmentPolicy()` (default `FillAll`), `getFulfillmentShippingSpeed()`
  (`Standard`), `getInventorySyncPeriod()` (default 900s), `getLowInventoryThreshold()` (0),
  `getOrderTypesWorkflow($order_type_id)`.

## Amazon Item — `commerce_amazon_item` (`Entity/AmazonItem`)

Links an Amazon SKU to a Commerce purchasable entity. `admin_permission = administer
commerce_amazon_marketplace`; route provider `AmazonItemRouteProvider`. Fields: `marketplace`
(ref), `purchasable_entity` (ref — the Commerce product variation), `sku` (string, validated by the
`AmazonItemSku` constraint), `fulfillable_quantity` (int), `quantity` (decimal), `status`.
A computed field plugin `Plugin/Field/ComputedFulfillableQuantity` and the
`AmazonItemSkuConstraint(Validator)` enforce SKU uniqueness/format.

## Amazon Fulfillment — `commerce_amazon_fulfillment` (`Entity/AmazonFulfillment`)

An Amazon Fulfillment-Outbound order tied to a Commerce order. Fields: `fulfillment_id` (string —
Amazon `sellerFulfillmentOrderId`, default pattern `AMA-DC-{order_id}`), `order` (ref
commerce_order), `marketplace` (ref), `state` (state-machine, workflow `fulfillment_default` from
`.workflows.yml`/`.workflow_groups.yml`), `shipments` (map — Amazon shipment payload). Storage
`AmazonFulfillmentStorage` exposes `loadOpenFulfillmentIds($marketplace)`. State transitions are
mirrored onto the Commerce order by `FulfillmentWorkflowSubscriber` — see
[sync-fulfillment.md](sync-fulfillment.md).

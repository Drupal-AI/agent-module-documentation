# Configuration

Cool Editor Tabs works out of the box — everything on this page is **optional
tuning**. The settings form lets you match the tab colors to your admin theme and
check that your choices stay legible.

## Open the settings form

1. Log in as a user with the **Administer site configuration** permission (an
   administrator by default).
2. Go to **Configuration → User interface → Cool Editor Tabs**.

## Colors

The form lets you configure the colors used for the editor tabs. Set the colors to
suit your admin theme so the restyled row feels like a native part of the
interface rather than a bolted‑on widget.

## Contrast checker

As you pick colors, the form runs a built‑in, real‑time **WCAG 2.1 contrast
checker**. Watch it as you choose: it tells you whether your text and background
colors have enough contrast to remain readable for everyone, including
low‑vision users. Aim to keep the checker in the passing range — the tabs are
navigation an editor relies on, so legibility matters more here than a particular
color.

> **Accessibility tip:** because the tabs are navigation, make sure the active tab
> stays distinguishable by more than color alone, and that keyboard focus remains
> visible when you tab through the row. The contrast checker helps with the first
> of these; keep it in mind when choosing your palette.

## Save

Click **Save configuration** at the bottom of the form. Your color changes take
effect immediately — reload any content page and toggle the tabs to see them.

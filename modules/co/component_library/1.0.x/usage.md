Component Library lets you build a library of components.

---

Component Library lets you **build a library of reusable UI components** — defining components (markup/
templates, editable via CodeMirror) that can be reused across the site and placed with Layout Builder, with
engine/workspaces submodules. It depends on the Entity API, CodeMirror Editor and core Layout Builder, provides
its own permissions, in the User interface package.

Use it to create and reuse UI components. It is a site-building/theming tool. Security note: components can hold
**markup/template code**, so who can create/edit them is powerful (a malicious component could inject markup/JS)
— gate the component-editing permissions to **trusted developers/site builders**. It has no access-control role
beyond its permissions. Configure and build the component library.

Commerce Referral provides a referral system integrating with Commerce.

---

Commerce Referral provides a **referral system integrating with Commerce promotions** — letting customers
refer others and rewarding referrals via Commerce promotions/discounts, tracking referral attribution. It
depends on Commerce and Commerce Promotion, provides its own permissions, in the Commerce package.

Use it to run a referral/reward program. It is an e-commerce/marketing feature. Security/data handling: referral
codes are **user-visible** — don't trust them for security decisions, validate attribution server-side, and
guard against self-referral/abuse (rewards have monetary value); referral/reward data ties to users (personal/
financial). It has no access-control role beyond its permission. Configure the referral program.

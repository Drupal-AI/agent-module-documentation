Component Schema adds schema definitions/validation for components and integrates them with the Styleguide module.

---

Component Schema provides schema support for components — letting component definitions declare a schema for their props/slots (validated at render), and integrating with the Styleguide module so components appear in a living styleguide. It's a foundation other component libraries (e.g. Bulma Components) build on.

It's a developer/theming framework with no content or access role of its own. Supports Drupal 10.2+, 11, and 12.

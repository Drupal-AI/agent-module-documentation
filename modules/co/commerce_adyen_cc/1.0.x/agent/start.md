# Commerce Adyen (Credit Card) — agent index

A Drupal Commerce **credit-card payment gateway for Adyen**. Depends on `commerce`. Version **1.0.x** (dev).
Core `^9.3||^10`.

E-commerce/payment — confirm outcomes **server-side with Adyen** and **verify Adyen's HMAC-signed
notifications** (not a client return); API/HMAC keys as secrets, HTTPS. No access role.

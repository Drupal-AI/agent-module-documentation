Manage configuration workflows through config layers.

---

Config Layers lets you manage configuration workflows through config layers — organising configuration into layered sets (e.g. base / environment / site overrides) so that different layers can be applied and combined, giving teams a structured configuration-management workflow beyond a single flat config export. It's a config-management tool. Supports Drupal 11.

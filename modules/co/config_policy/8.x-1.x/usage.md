Add config policies to stay consistent and enforce best practices.

---

Config Policy lets you add config policies to stay consistent and enforce best practices — defining rules that configuration must satisfy (naming, required values, disallowed settings) so a team can catch config that violates conventions, keeping large sites consistent. It's a config-governance tool (from SWIS). Depends on core `field`; supports Drupal 10 and 11.

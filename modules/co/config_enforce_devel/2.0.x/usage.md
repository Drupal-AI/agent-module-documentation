Development helper for Config Enforce: make some configuration read-only.

---

Config Enforce - Devel is the development companion for Config Enforce — it allows some configuration to be read-only (enforced), giving developers tooling to mark and manage which config a module enforces so that sites cannot drift from the intended values. It builds on Config Enforce and Config Devel. Depends on `config_devel`, `config_enforce`, and `multiselect`; supports Drupal 10.1+ and 11.

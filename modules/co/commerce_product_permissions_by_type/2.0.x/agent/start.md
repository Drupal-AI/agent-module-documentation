Commerce Product Permissions by Type (v2.0.x): dynamic per-bundle Commerce product permissions. Permissions from ProductTypePermissions.php (view/add per product type). .module: hook_commerce_product_access returns AccessResult::allowedIfHasPermission('view <bundle> commerce_product') for view (additive allow, so pair it with removing core's blanket view grant); form alter hides the add-to-cart widgets when the user lacks 'add <bundle> commerce_product to cart'. Add-to-cart gating is form-level (consistent with the module design). Depends on commerce_cart.

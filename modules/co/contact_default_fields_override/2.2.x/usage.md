Contact Default Field Override allows overriding the default fields of core contact forms.

---

Contact Default Field Override lets you override the default fields of core Contact forms — the built-in
name, email, subject and message fields — so their labels, requirements or behaviour can be adjusted per
contact form, which core doesn't allow out of the box. It depends on core Contact and Field UI.

Use it to customize the standard contact-form fields. It is a forms/contact feature affecting the default
fields; it does not change access (contact-form access is governed by core's contact permissions) and has no
access-control role. Configure the field overrides on the contact form.

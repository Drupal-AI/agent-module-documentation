# Configuration

Convivial Core is a base module for the Convivial CXP, so its configuration is
mostly the shared settings the other Convivial components rely on.

## Open the settings

1. Log in as a user with permission to administer the site (Convivial Core provides
   its own permission for its administration).
2. Go to **Configuration → Convivial**, or navigate directly to
   `/admin/config/convivial`.

## Set the options

On the Convivial configuration page, review and set the available options for your
Convivial setup, then save. What appears here supports the broader Convivial stack
(components such as Convivial Enricher and Convivial Profiler); the meaningful
front‑end behaviour comes from those components once configured against this shared
base.

If you installed Convivial Core only because another Convivial module required it,
you generally do not need to change anything here beyond what that module's own
setup documentation asks for.

Controls which content-moderation states are visible per user role and content type.

---

Content Moderation Roles controls which content moderation states are visible on node forms and in admin views based on the current user role and content type — so, on top of core Content Moderation's transition permissions, a site can hide states that a given role shouldn't see for a given content type, simplifying editors' choices. Depends on core `content_moderation`, `node`, `views`, and `workflows`; supports Drupal 9, 10, and 11.

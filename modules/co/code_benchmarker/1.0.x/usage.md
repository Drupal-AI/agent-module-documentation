Code benchmarker is a developer dashboard that times competing implementations of the same operation.

---

Code benchmarker is a dev-only dashboard for comparing the runtime cost of two (or more) implementations of the same operation — other modules contribute scenarios as tagged services, and the dashboard runs and times them so developers can see which implementation is faster before committing to one.

It's a development/profiling tool (not for production); scenarios are registered as tagged services in code. Depends on core `help` and `user`; supports Drupal 10 and 11.

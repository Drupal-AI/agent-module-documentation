Colorizer Classes maps Drupal data to CSS classes for colorizing markup.

---

Colorizer Classes **maps Drupal data to CSS classes** — providing the ability to attach CSS classes derived
from content/data so elements can be colorized/styled consistently via theme CSS. It works on core 9–11.

Use it to drive CSS classes from data. It is a theming/site-building feature; it adds class names to markup and
has no content or access role. Note: class values derived from data should be output safely (as valid class
names). Configure the data-to-class mapping.

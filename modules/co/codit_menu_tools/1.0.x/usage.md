Codit: Menu Tools gives developers helper methods and examples for managing menus in code.

---

Codit: Menu Tools provides code methods and examples for developers to use while managing menus — helper functions/services for creating, updating and querying menu links programmatically, so developers building site-deployment or update code have a tested toolkit for menu manipulation rather than writing it each time.

It's a developer utility (part of the Codit family) with no end-user UI of its own. Depends on core `menu_link_content`; supports Drupal 10 and 11.

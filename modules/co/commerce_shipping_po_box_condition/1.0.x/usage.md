Commerce Shipping PO Box Condition provides a condition to include/exclude shipping methods when an address is a PO Box or Highway Contract Box.

---

Commerce Shipping PO Box Condition **provides a shipping condition for PO Box / Highway Contract Box
addresses** — so a shipping method can be shown or hidden when the customer's address is a Post Office Box or
Highway Contract Box (carriers that don't deliver to PO Boxes). It depends on Commerce Shipping.

Use it to gate shipping methods on PO-Box addresses. It is an e-commerce/shipping business-rule feature; it
evaluates the address and has no access-control role. Configure the condition on shipping methods.

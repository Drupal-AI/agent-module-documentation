Color Swatch adds color swatch pickers to theme settings, letting site builders choose colors visually.

---

Color Swatch adds color-swatch pickers to theme settings — giving site builders a visual swatch UI to
select colors for theme options instead of typing hex codes. It improves the theming configuration
experience where a theme exposes color settings.

Use it in themes that offer color configuration to make picking colors easier and more consistent. It is a
theming/admin-UI feature affecting how color settings are chosen; it has no content or access behaviour.
Integrate it with the theme's settings that expose colors.

Commerce MultiSafepay Payments (v4.1.x): Drupal Commerce 2.x payment provider for the MultiSafepay PSP. Each payment method is an offsite CommercePaymentGateway plugin under src/Plugin/Commerce/PaymentGateway/. Global config (API key + mode) lives at /admin/config/commerce_multisafepay_payments (route commerce_multisafepay_payments.settings, requires 'administer site configuration'). Payment confirmation: GatewayStandardMethodsHelper::onNotify() and SecondChanceController re-fetch the order from the MultiSafepay API (merchant key) and set state from the authoritative gateway status -- request data is not trusted. TLS verification is explicitly on. Depends on commerce_payment and commerce_log.

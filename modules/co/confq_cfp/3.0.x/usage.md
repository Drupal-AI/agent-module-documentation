Call for papers (CFP) for a conference, built on Webform.

---

ConfQ CFP provides a call for papers (CFP) for a conference — a Webform-based submission flow so conference organisers can collect and manage paper/talk proposals from speakers, part of the ConfQ conference toolset. Depends on core `user` and `webform`; supports Drupal 10.2+ and 11.

Coveo Atomic Search embeds Coveo's Atomic web-component search UI in Drupal as a placeable block, one per Coveo search component.

---

`coveo_atomic` is a submodule of Coveo (depends on `coveo`). It provides a derivative block plugin (`coveo_atomic`) that renders one block per `coveo_search_component`, a `coveo_atomic_search` theme hook with a default Twig template built from Coveo Atomic components (search box, tabs, facets, sort, results, pager), and a Twig extension exposing `atomic_field` / `atomic_fields` filters that map Drupal field names to Coveo field names (applying the organization prefix). On render, `template_preprocess_coveo_atomic_search()` attaches the `coveo_atomic/atomic` library, loads Coveo's Atomic ESM bundle from `static.cloud.coveo.com`, and injects per-instance `drupalSettings` (search id, organization id, and a per-user access token obtained from the search component's security provider). Client JS (`coveo_atomic.js`) initializes the `atomic-search-interface` with that token and a `renewAccessToken` callback hitting `/coveo/refresh`. Results are fetched and rendered entirely by Coveo's client-side web components.

---

- Place a Coveo Atomic search interface on any page via the block layout.
- Get one block automatically per Coveo search component you define.
- Render a full search UI: search box, facets, tabs, sort dropdown, results, pager.
- Feed the interface a per-user Coveo access token generated by the component's security provider.
- Refresh expiring search tokens client-side through the `/coveo/refresh` endpoint.
- Override the default Atomic template per search id or component using theme suggestions.
- Add a standalone search box or custom Atomic components in a theme override.
- Map Drupal field machine names to Coveo field names in Twig with `atomic_field`.
- Emit a JSON field list for `fields-to-include` with `atomic_fields`.
- Apply organization prefixing automatically when converting field names.
- Configure a widget/placement id per block instance.
- Use Coveo's hosted Atomic v3 bundle without bundling assets locally.
- Build faceted, tabbed search experiences backed by a Coveo organization.
- Preview search components created under the Coveo admin section.
- Integrate Coveo analytics (legacy analytics mode) with the search interface.

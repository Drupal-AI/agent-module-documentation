Commerce Order Amend provides admin forms to edit placed Commerce orders (swap/add/remove items, coupons) with audit logging.

---

Commerce Order Amend **provides admin forms to edit placed orders** — swapping order items, adding/removing
items and managing coupons on already-placed orders, with audit logging and event-driven extensibility. It depends
on Commerce Order and Commerce Promotion, provides its own permissions.

Use it to amend placed orders. It is an e-commerce/order-management tool for staff. Security: amending placed
orders is a **privileged, financially-sensitive** operation — it is gated by its own permission (grant only to
trusted order administrators), and it records an **audit log** of changes (good practice). Ensure amendments
recompute totals/payment correctly. It has no access-control role beyond its permission. Configure and use the
amend forms.

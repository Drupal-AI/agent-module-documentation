Configurable Theme Libraries lets a theme define libraries that can be enabled/configured through the theme settings UI.

---

Configurable Theme Libraries lets theme developers define asset libraries that site builders can then
enable, disable or configure from the theme settings UI — instead of libraries being always-on. This makes
optional theme features (a slider library, an animation library) toggleable per site without code changes.
It is in the Theming package.

Use it in themes that ship optional libraries you want configurable. It is a theming/developer feature
affecting which theme assets load; it has no content or access behaviour. Define the configurable
libraries in the theme and expose them in theme settings.

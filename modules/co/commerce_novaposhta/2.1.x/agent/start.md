Commerce Novaposhta (v2.1.x): Nova Poshta shipping integration for commerce_shipping. Shipping plugin src/Plugin/Commerce/ShippingMethod/Novaposhta.php; API in src/Service/NovaposhtaManager.php (Guzzle POST, default TLS verify, apiKey from config). Config form at /admin/config/services/commerce-novaposhta behind 'administer commerce novaposhta configuration' (restrict access: true). Custom field type/widget/formatter select city+warehouse. No anonymous routes. Minor hardening: API key lives in plain module config rather than a Key entity.

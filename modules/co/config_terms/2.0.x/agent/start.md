# Config Terms (config_terms) — agent index

A configuration-entity clone of taxonomy. Defines two config entity types — `config_terms_vocab`
(vocabulary) and `config_terms_term` (term, with parents/weight/hierarchy) — so a controlled list
is exported with `drush cex` and deployed with `cim` instead of living as content. Core
`^10.6 || ^11.0`, no other dependencies. Managed at `/admin/structure/config-terms`. No settings
page (`configure` null); its `config_terms.settings` object is edited only via config/drush.
Submodule `config_terms_views` adds a Views filter. Provides permissions; no Drush, no new plugin types.

**They are NOT `taxonomy_term` entities.** Terms are not fieldable and anything expecting a
`taxonomy_term` (most taxonomy contrib, term reference via `taxonomy_term`, pathauto term patterns)
will not work. Reference them with a core `entity_reference` field whose `target_type` is
`config_terms_term`. State this constraint before recommending the module.

Key facts:
- Config entity types: `config_terms_vocab` (prefix `config_terms.config_terms_vocab.*`) and
  `config_terms_term` (prefix `config_terms.config_terms_term.*`). Vocab `config_export`:
  `label,id,description,weight,hierarchy`. Term `config_export`: `id,vid,label,parents,description,weight`.
- Vocab `admin_permission` = `administer config terms`; Term `admin_permission` = `administer site configuration`,
  but the Term entity has a custom access handler `TermAccessControlHandler`.
- Collection/admin routes: `entity.config_terms_vocab.collection` (`/admin/structure/config-terms`),
  `.add_form`, `.edit_form`, `.delete_form`, `.reset_form`, `.overview_form`;
  `entity.config_terms_term.add_form|edit_form|delete_form`.
- Static permission `administer config terms`; dynamic per-vocab `edit terms in <vid>` /
  `delete terms in <vid>` generated by `Drupal\config_terms\ConfigTermsPermissions::permissions`.
- Term add is gated by `_entity_create_access: 'config_terms_term:{config_terms_vocab}'`.
- Settings config object `config_terms.settings`: `maintain_index_table` (bool, unused),
  `override_selector` (bool), `terms_per_page_admin` (int, default 100).
- Storage handlers: `VocabStorage` (`getToplevelTids`, `getVocabsList`) and `TermStorage`
  (`loadTree`, `loadChildren`, `loadParents`, `getTermOptions`, `resetWeights`).
- Reference selection plugin id `default:config_terms_term` (`TermSelection`), keyed by `target_vocab`.
- Views filter plugin id `config_terms_index` (submodule `config_terms_views`).

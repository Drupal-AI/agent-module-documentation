Attaches a UI Icons (Icon API) icon to any config entity via third-party settings.

---

Config Entity Icon attaches an Icon API (ui_icons) icon to any config entity via third-party settings — node types, taxonomy vocabularies, menus, custom config entities — a generic alternative to per-entity-type icon modules, so admins can give config entities a visual icon reused across the admin UI. Depends on core `system` and `ui_icons`; supports Drupal 11.1+.

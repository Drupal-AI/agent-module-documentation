Contact Tools provides helpers for the Contact module, including extra blueprints for AJAX contact forms.

---

Contact Tools provides developer helpers for Drupal's core Contact module — including blueprints/
utilities for rendering contact forms via AJAX (e.g. in a modal), plus convenience helpers for embedding and
handling contact forms. It depends on core Contact.

Use it to build enhanced (AJAX/modal) contact-form experiences. It is a forms/contact developer feature; the
contact forms themselves are governed by core's contact permissions and it has no access-control role. Use
the helpers where AJAX contact forms are needed.

Comma Separated String Widget provides a string widget that accepts comma separated values in a single text input.

---

Comma Separated String Widget provides a **field widget** that lets editors enter **multiple values as a
single comma-separated string** — the widget splits the input into the multi-value field's separate values, so
a multi-value string/text field can be filled from one compact text box instead of many rows.

Use it to speed up entering multi-value string fields. It is a content-editing/widget feature affecting input
only (values are stored normally per the field); it has no content or access role. Choose the widget on a
multi-value string field.

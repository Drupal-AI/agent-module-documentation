AJAX like/unlike for nodes and custom blocks, for authenticated users and anonymous (cookie) visitors.

---

Content Like provides AJAX like/unlike functionality for node and custom block content, with authenticated user and anonymous cookie support — so visitors can like content without a page reload, and anonymous likes are tracked via a cookie. The like route is gated by the `access content` permission; anonymous liking is by design (like other social-engagement widgets), so treat like counts as non-authoritative. Depends on core `node` and `block_content`; supports Drupal 10, 11, and 12.

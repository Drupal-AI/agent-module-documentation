Comment Limit restricts how many comments a user may post on a given comment field, capping per-user comment volume.

---

On busy or contentious content, a single user posting dozens of comments can dominate a thread or be a spam/abuse vector. Core does not cap how many comments a user may leave. Comment Limit adds that: a configurable maximum number of comments per user on a comment field, so once a user reaches the limit they cannot add more.

It works per comment field and per user, which makes it a moderation and anti-abuse tool — a way to keep one voice from flooding a discussion and to blunt automated comment spam that relies on volume. It is enforced at submission, so it governs what gets created rather than hiding existing comments.

The consideration is that the limit is a blunt instrument: it counts comments, not quality, so a legitimate active participant hits the same cap as a flooder. Set the limit high enough not to frustrate genuine discussion while still bounding abuse, and pair it with the usual anti-spam measures — the limit reduces volume-based abuse but is not a substitute for moderation or CAPTCHA.

For sites with active commenting that need a volume guardrail, it is a simple, targeted control.

Commerce Order Item Fields collects per-order-item field data during checkout.

---

Commerce Order Item Fields adds a checkout pane that collects per-product/per-order-item field data during checkout — for example engraving text, gift messages, or configuration options attached to each line item rather than the whole order. The collected values are stored on the order items.

It's a checkout-UX module with no access role of its own. Depends on core `field` and Commerce (`commerce_checkout`, `commerce_order`, `commerce_cart`); requires Drupal 11.

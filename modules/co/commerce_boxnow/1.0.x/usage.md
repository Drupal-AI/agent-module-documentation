Commerce BOXNOW integrates the BOX NOW parcel-locker API as a Commerce shipping method.

---

Commerce BOXNOW **integrates the BOX NOW parcel-locker service** as a Drupal Commerce shipping method —
letting customers choose a BOX NOW locker for delivery and syncing shipment data with the BOX NOW API. It depends
on Commerce Shipping.

Use it to offer BOX NOW locker delivery. It is an e-commerce/shipping integration. Security/data handling: it
**calls the external BOX NOW API** (egress) with **API credentials** (store as secrets — env/Key — over HTTPS) and
sends **order/recipient details** (PII) for delivery — disclose per your privacy policy. It has no access-control
role. Configure the BOX NOW credentials.

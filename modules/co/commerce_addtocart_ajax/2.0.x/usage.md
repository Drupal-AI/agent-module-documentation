Commerce Add to Cart Ajax ajaxifies the add to cart form from the Commerce cart module.

---

Commerce Add to Cart Ajax makes the Drupal Commerce add-to-cart form submit via AJAX — so adding a
product to the cart happens in place (no full page reload), with feedback, for a smoother shopping
experience. It depends on Drupal Commerce and provides its own permissions.

Use it to ajaxify add-to-cart. It is an e-commerce/UX feature affecting the add-to-cart form; the add-to-cart
operation still goes through Commerce's normal handling and access, and it has no access-control role. Enable
it on the add-to-cart form.

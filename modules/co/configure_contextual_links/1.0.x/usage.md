Configure Contextual Links provides the ability to enable, disable and modify contextual links (the pencil edit links) across the site.

---

Configure Contextual Links gives administrators control over Drupal's contextual links — the
"pencil" quick-edit links that appear on blocks, nodes and other elements — letting them enable, disable
or modify which contextual links are shown. This is useful for decluttering the editor UI or hiding
contextual links that aren't wanted. It depends on core Contextual, is configured at
`configure_contextual_links.settings`, and provides its own permissions.

Use it to tailor which contextual links editors see. It is an administration/UI feature affecting the
contextual-links display; it does not change the underlying access to the linked operations (contextual
links already respect permissions), only which are shown. Configure the links to enable/disable.

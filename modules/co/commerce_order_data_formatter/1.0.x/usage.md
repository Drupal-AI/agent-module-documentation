Commerce Order Data Formatter provides a field formatter for the commerce order data field that displays the value of a particular key.

---

Commerce Order Data Formatter provides a field formatter for Drupal Commerce's order `data` field — a
serialized catch-all field on orders — letting you display the value of a specific key within it, so
order-data values can be surfaced in displays/Views without custom code. It depends on Commerce Order, in the
Commerce package.

Use it to display specific order-data values. It is an e-commerce/display feature; the order data is order
content (respecting order access) and it has no access-control role. Select the formatter and the key to
display.

Content Moderation Edit Notify emails users when a new revision is saved on content they are editing under content moderation, warning of concurrent edits.

---

Two editors working on the same moderated content can clobber each other's changes. Content Moderation Edit Notify notifies a user when a new revision is saved on content they are editing, so concurrent edits are surfaced rather than silently lost. It is an editorial-workflow convenience built on content moderation. No unusual security surface; it sends notifications about editorial activity, so the recipients are editorial users.

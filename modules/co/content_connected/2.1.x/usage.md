Content Connected shows how content is connected with other content.

---

Content Connected **shows how a node is connected to other content** — it scans other nodes and reports which
**published** nodes reference the current node (incoming references via entity reference, link, or long-text
fields), so editors understand impact before editing or deleting it. It depends on core Field and provides its
own permissions. It searches node entities only (not users, terms, or other entity types).

Use it to see which content points at a node. It is a content-editing/authoring aid; the report table reflects
references following the current user's access (published nodes only) and it has no access-control role beyond
its permissions. View the connections from the node's "Content connected" sub-tab, the node delete form, or the
provided block.

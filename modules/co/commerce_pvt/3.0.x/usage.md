Commerce Product Variations Table creates a table of variations with add-to-cart.

---

Commerce Product Variations Table (commerce_pvt) displays a **Commerce product's variations as a table** —
listing each variation (attributes, price) in a configurable grid with per-row add-to-cart, useful for
products with many variations (sizes, packs). It depends on core System/Views and Commerce Product/Order/Cart,
in the Commerce package.

Use it to present product variations in a table. It is an e-commerce/content-display feature; pricing and
add-to-cart go through Commerce (server-authoritative) and it has no access-control role. Configure the
variations table.

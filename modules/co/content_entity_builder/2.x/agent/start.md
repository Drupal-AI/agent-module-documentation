# Content Entity Builder (content_entity_builder) — agent index

UI-driven builder for **custom content entity types and their base fields**. You define a
`content_type` config entity (id, label, mode, entity keys, paths, base fields); on "Save and apply
updates" the field storage is written to the DB and the entity type is registered **dynamically in
memory** via `hook_entity_type_build` (`Hook\ContentEntityBuilderHooks::entityTypeBuild`). No PHP is
written to your codebase at runtime. An optional **Export** tab scaffolds a full Drupal module and
downloads it as a `.tar.gz`.

- Core requirement: `^10.3 || ^11 || ^12`. No hard module dependencies in `.info.yml` (uses core
  `views`/`user` for Advanced/Full modes). License GPL-2.0-or-later.
- Config entity: `content_type` (`Entity\ContentType`, config prefix `content_entity_builder.content_type`).
  Runtime entity classes: `Entity\Content` (basic/basic_plus), `Entity\AdvancedContent` (advanced),
  `Entity\FullContent` (full).
- Modes: `basic` (1 entity, 1 table, no bundles), `basic_plus` (+bundles), `advanced`
  (+bundles/translatable/owner/changed/published), `full` (+revisions, like node).
- Plugin type: **base_field_config** (manager `plugin.manager.content_entity_builder.base_field_config`,
  attribute/annotation `BaseFieldConfig`, ~18 plugins in `Plugin/BaseFieldConfig/`).
- Permission: `administer content entity types` (`restrict access: true`) gates the whole builder +
  export. Per-type content permissions (`access|create|edit any|delete any|edit own|delete own <type>
  content entity`) are generated by `ContentEntityBuilderPermissions`.
- Services: `content_entity_builder_uninstall_validator`, `Hook\ContentEntityBuilderHooks` (hooks:
  `entity_type_build`, `file_download`, `theme`), the base-field plugin manager.
- Routes: builder at `/admin/structure/content-types` (+ add/manage/base-field/export/download); dynamic
  per-entity-type routes added by `Routing\ContentEntityBuilderRoutes::routes()`.

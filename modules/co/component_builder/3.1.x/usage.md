Component Builder provides a component builder module.

---

Component Builder lets site builders **create and manage reusable content components** — building blocks
(assembled with inline entity forms) that can be composed into pages, giving a component-driven content model.
It depends on the Entity API and Inline Entity Form modules, ships a `toolbar` submodule, provides its own
permissions, in the Component Builder package.

Use it for a component-based content-building workflow. It is a content-editing/site-building feature;
component content is authored (rendered normally) and access is governed by its permissions and normal entity
access, and it has no special access-control role beyond its permissions. Configure and build components.

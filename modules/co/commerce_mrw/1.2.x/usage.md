Commerce MRW adds MRW courier shipping rates/labels to Commerce via the SAGEC web service.

---

Commerce MRW provides MRW carrier integration for Drupal Commerce via the SAGEC web service — adding MRW (a Spanish courier) as a shipping method so the store can calculate MRW rates and integrate with MRW's SAGEC API for shipments/labels.

It's a Commerce Shipping method; SAGEC credentials are entered per shipping method, with separate PRE (test) and PRO (production) sets and a test-mode toggle. Depends on `commerce_shipping`; supports Drupal 10.3 and 11.

Configuration Share enables sharing of configuration between multiple extensions and distributions.

---

Configuration Share enables configuration to be shared between multiple extensions (modules/themes) and
distributions — so common config can be provided/owned collaboratively rather than by a single extension,
useful for distributions that layer shared configuration. It depends on core Config.

Use it in multi-extension/distribution setups needing shared config ownership. It is a configuration-
management feature affecting how config is provided/shared; it does not change runtime access and has no
access-control role. Configure the shared configuration.

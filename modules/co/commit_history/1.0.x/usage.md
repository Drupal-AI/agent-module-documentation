Commit History surfaces a page listing commit history for the site's repository.

---

Commit History provides a page that lists commit history — useful for showing recent code/deployment changes inside the Drupal admin, so operators can see what has been committed without leaving the site. Access is gated by view/administer permissions.

Permissions separate viewing (`view commit history`) from administration (`administer commit history`). It's a developer/operations utility with no content role. Supports Drupal 10 and 11.

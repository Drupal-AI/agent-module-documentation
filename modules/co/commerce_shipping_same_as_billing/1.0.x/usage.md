Commerce Shipping same as billing provides a 'same as billing' option so customers can reuse their billing address for shipping.

---

Commerce Shipping same as billing adds the familiar "shipping address same as billing" option to
Drupal Commerce checkout — letting customers reuse their billing address for shipping with one checkbox,
instead of re-entering it. It depends on Commerce Shipping.

Use it to streamline checkout on stores that collect both billing and shipping addresses. It is an
e-commerce/checkout UX feature; it copies address data within the order and has no access-control role.
Enable it in the checkout flow where shipping is collected.

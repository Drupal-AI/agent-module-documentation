Colored Field Counter provides a character counter with colored feedback.

---

Colored Field Counter adds a **character counter with colored feedback** to text fields — showing the
current character count against a recommended size, with color changes (green/orange/red) as the user
approaches/exceeds that size, to guide editors on length (e.g. meta descriptions, teasers). It ships
Field API widget plugins only and is in the Field package.

Use it to give editors live length feedback. It is a content-editing/form-widget feature affecting the edit
form only; it has no content or access role. Configure the counter on the relevant fields.

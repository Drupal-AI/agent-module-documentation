Commerce Gallery provides an advanced masonry image gallery block for Drupal Commerce products.

---

Commerce Gallery provides an **advanced masonry image-gallery block for Drupal Commerce products** —
displaying a product's images in a masonry-style gallery layout, improving product image presentation. It
depends on core File/Image and Commerce/Commerce Product, in the Commerce package.

Use it to present product images as a gallery. It is an e-commerce/content-display feature; product images
follow normal media/file access and it has no access-control role. Place and configure the gallery block.

Commerce Store Filter provides filtering by store when multiple Commerce stores exist.

---

Commerce Store Filter adds store-based filtering for Drupal Commerce sites that run multiple stores —
letting admins and listings filter products/orders by store, which is otherwise awkward on multi-store
setups. It depends on Commerce and Commerce Store and provides its own permissions.

Use it on multi-store Commerce installations to manage per-store content more easily. It is an
e-commerce/administration feature that scopes listings by store; it aids management and does not change
store access (store access is governed by Commerce permissions). Configure and use the store filter where
multiple stores are present.

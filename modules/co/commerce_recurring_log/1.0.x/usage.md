Commerce Recurring Log provides activity logs for subscriptions.

---

Commerce Recurring Log **provides activity logs for subscriptions** — recording lifecycle events (renewals,
payments, state changes, cancellations) of Commerce Recurring subscriptions via the Commerce Log system, for an
audit trail. It depends on Commerce Recurring and Commerce Log, in the Commerce (contrib) package.

Use it to track subscription activity. It is an e-commerce/reporting feature; logs reflect subscription events
and follow Commerce Log's access, and it has no access-control role. View the subscription activity logs.

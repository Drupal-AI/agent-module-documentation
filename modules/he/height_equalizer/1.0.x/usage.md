Height Equalizer equalizes the height of elements matched by CSS selectors.

---

Height Equalizer **equalizes element heights via CSS selectors** — a configurable front-end helper that makes
elements matching given selectors share a common height (e.g. card rows), for tidy layouts. It depends on core
System.

Use it to align element heights. It is a theming/front-end feature; it runs client-side sizing and has no content
or access role. Configure the selectors to equalize.

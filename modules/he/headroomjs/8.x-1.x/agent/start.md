# Headroom.js — agent index

Integrates **Headroom.js** — hides an element (e.g. sticky menu) on **scroll down**, reveals on
**scroll up**. Config at `headroomjs.settings` (target selector + behaviour). Version
**8.x-1.0-beta6**. Core `^8||^9||^10||^11`.

Front-end/theming behaviour on a chosen element (no content/access implications).

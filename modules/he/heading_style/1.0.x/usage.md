Heading Style lets you attach configured CSS classes to h1–h6 headings.

---

Heading Style lets site builders add CSS classes to selected heading tags (h1–h6) through configuration — so headings can be styled consistently without editing templates. It's a theming convenience for applying class-based styles to headings.

The classes are admin-configured; it's a theming utility with no content or access role of its own. Supports Drupal 10 and 11.

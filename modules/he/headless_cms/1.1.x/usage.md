Headless CMS bundles conveniences for running Drupal as a decoupled/headless backend.

---

Headless CMS adds features that help Drupal serve as a true headless CMS — conveniences for decoupled setups built on the Consumers module (managing API consumers, exposing content for front-end apps). It packages common headless-backend needs so a decoupled front end can consume Drupal content more easily.

Administration is gated by `administer headless_cms settings`. Because it exposes content to API clients, configure consumers, CORS and authentication carefully. Depends on `consumers`; supports Drupal 10.3+ and 11.

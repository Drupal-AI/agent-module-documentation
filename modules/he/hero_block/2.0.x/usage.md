Hero Block provides a simple way to create hero image blocks for pages.

---

Hero Block provides a simple block type for creating hero images — large banner-style blocks with an
image (and typically a heading/CTA) to place at the top of pages. It depends on core Node and Block. It
saves building hero banners with custom blocks or theming.

Use it to add hero banners to landing or content pages. It is a content-display/site-building block; the
hero content is admin-authored and rendered through Drupal's layers, with no access-control role. Place
and configure the hero block where a banner is needed.

Hello World REST provides a demo custom REST resource for the core REST API.

---

Hello World REST adds example custom resources to Drupal's core REST API — a 'hello world' demonstration showing how to expose a custom REST resource plugin. It's primarily a learning/example module for developers building their own REST endpoints.

The resource is served through core REST, so its access is governed by core REST permissions (each resource needs its GET permission granted). It's a demo/developer module. Depends on core `rest`; supports Drupal 8 through 11.

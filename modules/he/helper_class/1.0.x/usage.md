Helper Class allows adding custom CSS classes to entities, views and more.

---

Helper Class lets you **add custom CSS classes** to entities, views and other render elements — attaching
theming hooks (classes) without writing a preprocess function, for styling flexibility. It works across core
9–11.

Use it to add styling classes to output. It is a theming feature affecting markup; class values are
admin/editor-configured (keep them trusted, as with any class output) and it has no content or access role.
Configure the classes on the target elements.

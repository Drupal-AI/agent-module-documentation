# GitLab for Helpdesk Integration — agent index

**Provides a helpdesk entity type to integrate with GitLab**. Depends on `helpdesk_integration`. Version
**3.0.1**. Core `^11.4||^12`.

Helpdesk/integration — calls the **GitLab API** (egress) with a **GitLab access token** (powerful secret — env/Key,
least privilege, never commit); no access role.

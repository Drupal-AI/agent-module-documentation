Hello World is a Hello World example module.

---

Hello World is a **minimal example module** — a "Hello World" demonstration showing the basic structure of
a Drupal module (a route/controller returning a greeting), useful as a learning/reference starting point. It is
in the Custom package.

Use it as a learning example or scaffold. It is a developer/example module with no real functionality; do not
enable it on production (it is illustrative). It has no content or access role. Read it to learn module
basics.

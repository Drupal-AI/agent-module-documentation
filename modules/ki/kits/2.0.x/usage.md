Kits provides an OO fluent library for constructing Drupal Render API arrays.

---

Kits provides object-oriented 'kits' — reusable, composable builder components for constructing arrays compatible with the Drupal Render API — letting developers build render arrays with fluent, chainable code instead of hand-writing nested arrays. It underpins the Form Factory family and builds on the Query library.

It's a developer library with no content or access role of its own. Depends on `query`; supports Drupal 9, 10, and 11.

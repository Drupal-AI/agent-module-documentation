Display dynamic Kiyoh review ratings.

---

Kiyoh rating displays dynamic Kiyoh ratings — pulling a company's review score/count from Kiyoh (a review platform) and showing it in a block (star rating, badge), so a site can display social-proof review ratings.

The Kiyoh feed/API details are admin-configured. Depends on core `block`; supports Drupal 9, 10, and 11.

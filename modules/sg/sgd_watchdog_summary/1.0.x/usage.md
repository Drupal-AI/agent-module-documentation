Site Guardian Watchdog Summary summarises the entries in the watchdog/dblog.

---

Site Guardian Watchdog Summary summarizes Drupal's watchdog/dblog entries — providing a summary/overview
of recent log entries (as a `hook_site_guardian_status()`-style contributor to the Site Guardian monitoring
framework), so administrators/monitoring can see log-activity patterns at a glance. It is in the
Administration package.

Use it to get a summary of dblog activity. It is an administration/monitoring feature reading the log; the
log data is admin-only (governed by the site-reports permission) and it has no access-control role. View the
watchdog summary.

Site Guardian Dashboard provides the core Site Guardian admin dashboard.

---

Site Guardian Dashboard **provides an admin dashboard** — a Views/exposed-filter-driven dashboard (Site
Guardian) surfacing site management/monitoring information for administrators. It depends on core Views and
Taxonomy, plus Twig Tweak, Ultimate Cron, Better Exposed Filters and Entityreference Filter, and provides its own
permissions.

Use it as an admin management dashboard. It is an administration/monitoring feature; it aggregates site info
(admin-facing) and has no content or access role beyond its permission. Note: the dashboard surfaces operational
data — gate it to trusted admins. Configure the dashboard.

Site Guardian PHP Status provides additional information regarding PHP on the status report.

---

Site Guardian PHP Status adds additional PHP-related information to Drupal's status report — surfacing
PHP configuration/health details (as a `hook_site_guardian_status()` provider for the Site Guardian
monitoring framework), so administrators/monitoring can see PHP status alongside the rest of the status
report. It is in the Administration package.

Use it to expose PHP details on the status report / to Site Guardian. It is an administration/monitoring
feature that surfaces PHP information; that information is shown on the status report, which is already
gated by the core `access site reports` permission (admin-only), so it doesn't expose new public surface. It
has no access-control role. Enable it to add PHP status information.

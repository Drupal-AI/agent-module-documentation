# yunke QRcode — agent index

`yunke_qrcode` **render element** that generates a QR code **client-side** (bundled jquery.qrcode; canvas/table). Props: text/size/colours/level/tag(div|span|p, validated); attributes escaped via `Attribute`/`Xss`. Demo form; no routes/permissions. Version **2.0.0**, core `~8.8||^9||^10`. Front-end only — no server fetch.

HTML5 History exposes the HTML5 History object.

---

HTML5 History **exposes the browser HTML5 History object/API to Drupal JavaScript** — providing a hook so
front-end code can manipulate browser history (pushState/replaceState) for SPA-like URL updates without full
reloads. It is in the Other package.

Use it as a JS integration for history manipulation. It is a developer/front-end feature; it provides a
JavaScript API and has no content or access role. Use it from your front-end code.

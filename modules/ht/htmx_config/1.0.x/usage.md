HTMX Config offers a configuration API for HTMX-powered features.

---

HTMX Config provides an API for configuring HTMX behavior in Drupal — a foundation other modules use to wire up HTMX (the hypermedia library for AJAX-style interactions via HTML attributes) with consistent configuration. It's developer plumbing for HTMX integration.

It's a developer API with no content or access role of its own. Requires Drupal 11.

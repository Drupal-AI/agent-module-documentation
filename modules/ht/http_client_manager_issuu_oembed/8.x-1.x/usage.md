This module adds an Issuu oEmbed API client to HTTP Client Manager.

---

HTTP Client Manager Issuu Oembed provides an Issuu oEmbed metadata API client built on the HTTP Client Manager module — so a site can fetch Issuu publication oEmbed data (to embed Issuu documents/flipbooks) through the managed HTTP client with consistent configuration.

It's an integration/service module with no content or access role of its own. Depends on `http_client_manager`; supports Drupal 9.4, 10, and 11.

Preview the MJML rendering of a node.

---

MJML preview lets you preview the MJML rendering of a node — MJML is an email markup language that compiles to responsive HTML email; this module renders a node's MJML template so editors can preview how the email version will look before sending.

It calls an MJML rendering service (API key via a Key entity, env-backed). Depends on core `node` and `key`; supports Drupal 10 and 11.

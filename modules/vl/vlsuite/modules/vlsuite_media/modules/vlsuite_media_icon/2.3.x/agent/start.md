# VLSuite Media: Icon (vlsuite_media_icon) — agent index

Nested submodule of **vlsuite_media**. **Icon media type**.
Version **2.3.3**. Core `^10.3 || ^11`.

**Complements rather than replaces `vlsuite_icon_font`:** a font suits a fixed UI vocabulary; media
suits icons that are *content* — a partner logo set, editor-managed category markers.

Accessibility: the accessible name usually comes from the media entity, so set it properly **once**
rather than per placement.

# VLSuite Media: Image (vlsuite_media_image) — agent index

Nested submodule of **vlsuite_media**. **Image media type**.
Version **2.3.3**. Core `^10.3 || ^11`.

Single-entity property is the benefit: hero, card thumbnail and gallery tile are **one entity
rendered three ways**. Replace the photograph once, add a credit once, and the media library lets
editors find an existing image rather than uploading a fourth copy.

Core media type — usable outside VLSuite, so check dependencies before removing.

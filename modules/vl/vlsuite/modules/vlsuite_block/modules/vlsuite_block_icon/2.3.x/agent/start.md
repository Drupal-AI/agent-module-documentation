# VLSuite Block: Icon (vlsuite_block_icon) — agent index

Nested submodule of **vlsuite_block**. **Icon** component, drawing from `vlsuite_icon_font`.
Version **2.3.3**. Core `^10.3 || ^11`.

**Accessibility rule, restated because a standalone icon is more likely to be meaningful:** if it
carries information it needs an accessible name; if it decorates text that already says the same
thing, hide it from assistive technology. A row of unlabelled icons is a row of nothing to a
screen reader.

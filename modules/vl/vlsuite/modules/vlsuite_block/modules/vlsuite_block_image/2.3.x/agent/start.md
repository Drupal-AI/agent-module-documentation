# VLSuite Block: Image (vlsuite_block_image) — agent index

Nested submodule of **vlsuite_block**. **Image** component, drawing on `vlsuite_media`'s
responsive image configuration. Version **2.3.3**. Core `^10.3 || ^11`.

**Responsive delivery is the highest-value thing it does** — landing pages are image-heavy and are
the pages a site cares most about. A hand-built image block is exactly what skips this.

**Accessibility:** decorative images need an empty alt, meaningful ones need a description. Check
whether the field enforces it on a site with accessibility obligations.

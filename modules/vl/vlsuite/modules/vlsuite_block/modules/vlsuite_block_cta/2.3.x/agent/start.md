# VLSuite Block: CTA (vlsuite_block_cta) — agent index

Nested submodule of **vlsuite_block**. The **call-to-action** component — heading, text, button.
Version **2.3.3**. Core `^10.3 || ^11`.

A `block_content` entity, so it is revisioned, translatable, and **reusable** — one campaign
message in twenty places, edited once.

**Design point to raise:** if a project needs three visually distinct CTAs, that is a design
conversation before a Drupal one. Utility classes cover most variation; three block types is where
a component library starts to sprawl.

# VLSuite Block: Paragraph (vlsuite_block_paragraph) — agent index

Nested submodule of **vlsuite_block**. Places **paragraph entities** inside the suite's
block-and-layout structure. Version **2.3.3**. Core `^10.3 || ^11`.

**The bridge for sites with years of Paragraphs content** — adopt the suite for new pages without
migrating first.

Also legitimate long-term: Paragraphs suit repeatable structured content *within* a component (a
list of steps, a set of statistics) where per-instance Layout Builder placement is overkill.

**The state to avoid** is the third one: some pages Paragraphs, some Layout Builder, no rule.
That is where editors stop knowing where to add content and template changes get made twice.

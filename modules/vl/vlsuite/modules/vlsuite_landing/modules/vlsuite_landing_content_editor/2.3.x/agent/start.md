# VLSuite Landing: Content Editor (vlsuite_landing_content_editor) — agent index

Nested submodule of **vlsuite_landing**. **Editor role configuration** for landing page building.
Version **2.3.3**. Core `^10.3 || ^11`. `vlsuite_demo` depends on it, so evaluating the demo
installs the role.

**Review what it grants before using it.** A shipped role matches the suite's assumptions, not your
site's policy. Layout Builder permissions are broad — `configure any layout` versus
`configure editable layouts` decides whether an editor can restructure pages they do not own. Read
the list against how the site is actually organised.

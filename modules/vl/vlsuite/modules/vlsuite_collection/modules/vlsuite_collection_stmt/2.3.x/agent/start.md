# VLSuite Collection: Statement (vlsuite_collection_stmt) — agent index

Nested submodule of **vlsuite_collection**. **Statement / pull quote** component.
Version **2.3.3**. Core `^10.3 || ^11`.

Same argument as `ckeditor5_inline_quote` at block level: a quotation **marked up as a quotation**
carries meaning, styles consistently and can be found later. Large italic text in a WYSIWYG is none
of those.

**Get the attribution right:** a quotation attributed in a separate paragraph is not associated
with the quote for assistive technology. A dedicated field plus `blockquote`/`cite` (or
equivalent) is what fixes it — check the template renders the relationship.

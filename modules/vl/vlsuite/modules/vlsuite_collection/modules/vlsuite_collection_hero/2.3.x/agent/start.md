# VLSuite Collection: Hero (vlsuite_collection_hero) — agent index

Nested submodule of **vlsuite_collection**. **Hero band** — full-width page introduction.
Version **2.3.3**. Core `^10.3 || ^11`.

**Two things that matter here more than for other components:**

1. **It is the largest contentful paint** on almost every landing page. Responsive image
   configuration matters most here, and **preloading the hero image** is often the highest-value
   performance change available.
2. **Text over an image is a contrast problem** — legible over one photograph, illegible over the
   next, and editors change the photograph. An overlay, scrim or constrained text area is what
   makes it reliable.

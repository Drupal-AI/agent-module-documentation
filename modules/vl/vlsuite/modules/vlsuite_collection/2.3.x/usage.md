VLSuite Collection provides higher-level components assembled from the suite's building blocks — card sets, galleries, heroes and statements.

---

Where `vlsuite_block` gives individual components, this gives compositions: a row of cards, a gallery grid, a hero band, a pull-quote statement. Each is built from the same blocks and layouts rather than being a new implementation, which is why the module's own description frames them as showing the suite's potential — they are worked examples as much as features.

That framing is useful. A team adopting VLSuite can take the collections as they are, or read them as the reference for building their own compositions from the same parts. Either way they answer the question a component library always raises: what does a real page look like assembled from this?

The `section_library` dependency means collections can be saved and reused as sections, and `vlsuite_bundle_field` supplies the shared fields the collection bundles need.

Four nested submodules: `vlsuite_collection_card`, `_gallery`, `_hero`, `_stmt`.

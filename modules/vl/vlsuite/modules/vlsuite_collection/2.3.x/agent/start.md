# VLSuite Collection (vlsuite_collection) — agent index

Submodule of **vlsuite**. Higher-level **compositions** assembled from the suite's blocks and
layouts: cards, galleries, heroes, statements. Version **2.3.3**. Core `^10.3 || ^11`.
Depends on `vlsuite_block`, `vlsuite_layout`, `section_library`, `vlsuite_bundle_field`.

Its own description frames these as showing the suite's potential — they are **worked examples** as
much as features, and answer the question a component library always raises: *what does a real page
assembled from this look like?*

Nested: `vlsuite_collection_card`, `_gallery`, `_hero`, `_stmt`.

Integrate Drupal with the Oswald chatbot framework.

---

Oswald chatbot provides integration between Drupal and the Oswald chatbot framework — embedding an Oswald conversational chatbot on the site and wiring the endpoints/config it needs, so visitors can chat with an Oswald-powered assistant.

Any Oswald/chatbot API credentials are admin-configured and should be stored securely (env-backed). Supports Drupal 9.2+, 10, and 11.

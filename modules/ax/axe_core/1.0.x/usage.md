Axe Core runs the axe-core accessibility engine against rendered pages for a11y checking.

---

Axe Core integrates the widely-used axe-core accessibility testing engine into Drupal so developers and editors can run automated WCAG/a11y checks against rendered pages and see violations in-browser. It's a development/QA aid for catching accessibility regressions.

It's a front-end/development integration with no content or access role of its own. Requires Drupal 10.4+.

An input filter returning data from books.google.com.

---

Google Books is an input filter module returning data from books.google.com — so content authors can embed a token/tag that the filter replaces with book data (cover, title, details) fetched from the Google Books API, for bibliographies and book listings.

Enable the filter on trusted text formats; store any Google Books API key securely (env-backed). Depends on core `editor`; supports Drupal 10 and 11+.

Registers CA3 as an oEmbed provider and sets up CA3 media fields.

---

GovCMS CA3 Consumer Helper registers CA3 as an oEmbed provider and initializes CA3 media fields — so a GovCMS site consuming the CA3 (Content API) service can embed CA3 media via oEmbed and gets the required media fields configured out of the box. Depends on core `media` and `link`; supports Drupal 10 and 11.

GOV.UK Webform Elements provides GOV.UK form components for Webform.

---

GOV.UK Webform Elements **provides GOV.UK Design System form components for Webform** — form elements (such
as the GOV.UK date input) that follow the UK government's accessible design patterns, for GOV.UK-styled services.
It depends on the Webform module, in the Webform GOV.UK package.

Use it to build GOV.UK-compliant forms. It is a forms/accessibility feature affecting form elements; it has no
content or access role. Add the GOV.UK elements to a webform.

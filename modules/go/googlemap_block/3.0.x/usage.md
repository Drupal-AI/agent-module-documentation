GoogleMap Blocks lets site builders create Google Maps blocks with configurable location and options to place anywhere blocks are used.

---

GoogleMap Blocks provides a block type for embedding Google Maps — site builders configure a
location (and map options) and place the resulting map as a block anywhere the block system is used
(regions, Layout Builder). It is a straightforward way to add maps (a location, directions, an office
address) without custom code.

Use it to show maps on contact pages, location listings or anywhere a map block fits. It uses the
Google Maps service, so a Google Maps API key is required — store it as a secret and restrict the key
(HTTP referrer / API restrictions in the Google Cloud console) to limit abuse if it is exposed in
client-side map requests. It is a content-display/site-building module with no access-control role.

# GoogleMap Blocks — agent index

Creates configurable **Google Maps blocks** (location + options) to place anywhere blocks are used.
Version **3.0.0**. Core `^9||^10||^11`.

Requires a **Google Maps API key** — store as a secret and restrict it (referrer/API restrictions) to
limit abuse. Content-display/site-building (no access role).

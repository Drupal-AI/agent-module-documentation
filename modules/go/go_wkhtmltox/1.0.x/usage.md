Integrate Drupal with a Go-WkhtmltoX PDF/image rendering service.

---

Go-wkhtmltoX Client integrates Drupal with Go-WkhtmltoX — a service that renders HTML to PDF/images (a Go wrapper around wkhtmltopdf/wkhtmltoimage), so Drupal can offload HTML-to-PDF conversion to a remote Go-WkhtmltoX endpoint for higher throughput.

The Go-WkhtmltoX endpoint is admin-configured; keep it on a trusted network and store any credentials securely. Supports Drupal 10.3+ and 11.

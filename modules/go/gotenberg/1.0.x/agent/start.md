# Gotenberg — agent index

Integrates the **Gotenberg service to convert HTML/URLs to PDF** (Chromium rendering). Settings gated by
`administer gotenberg settings`. Version **1.0.2**. Core `^10.3||^11`.

Integration — endpoint is admin-configured: point only at a **trusted Gotenberg instance** you control, keep it
access-restricted (it renders your HTML). No access role of its own.

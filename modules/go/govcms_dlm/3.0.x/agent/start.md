# GovCMS DLM — agent index

Adds an optional **Dissemination Limiting Marker (protective marking — "OFFICIAL", "OFFICIAL: Sensitive") to
emails** Drupal sends. Provides permissions. Version **3.0.0**. Core `^10||^11`.

Compliance/security-labelling — a governance/handling **label, not encryption** (signals classification;
doesn't protect content in transit — use mail transport security). No access role beyond permission.

Design system gov.cz implements the gov.cz design system via Single Directory Components.

---

Design system gov.cz (gov_cz) **implements the gov.cz design system** — providing the Czech government design
system (components/styling) as Single Directory Components for building compliant Czech public-sector sites. It
works on core 11.2.

Use it to build gov.cz-styled sites. It is a theming/component-library feature; it provides SDC components and has
no content or access role. Use the gov.cz components in your theme.

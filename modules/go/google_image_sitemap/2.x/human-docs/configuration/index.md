# Configuration

Configuration is quick: pick the content types whose images should be indexed,
optionally add license details, generate the sitemap, and tell Google about it.

## Open the settings form

1. Log in as a user with permission to administer the module.
2. Go to **Configuration → Search and metadata → Google Image Sitemap**.

## Choose which content types to include

Select the **content types** you want the sitemap to cover. Generating sitemaps on a
per‑content‑type basis gives you granular control over which images are indexed —
include the types whose images you want discovered (product pages, galleries,
articles) and leave out any whose images should not appear in image search.

> **Include only public images.** Make sure the content types you select contain
> images that are meant to be publicly indexed. A sitemap should not list private or
> access‑restricted image URLs, which would fail to serve and would also disclose
> that they exist.

## Add license information (optional)

If you want to communicate usage rights for your images, add a **license URL**. This
attaches license metadata to the sitemap entries, helping protect your intellectual
property and inform users how the images may be used.

## Generate and submit the sitemap

1. **Generate** the sitemap from the settings form. The module includes the essential
   image metadata Google requires and follows the official image‑sitemap guidelines.
2. Copy the **sitemap URL** and submit it in **Google Search Console** so Google
   knows where to find it.
3. As you add new content or change existing images, return here and **update** the
   sitemap so it stays current.

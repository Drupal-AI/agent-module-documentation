---

Image search visibility benefits from an image sitemap. Google Image Sitemap generates one, listing site images for search engines. It is an SEO feature with no unusual security surface. Confirm it includes only public images intended for indexing (a sitemap should not list private/access-restricted image URLs, which would both fail to serve and disclose their existence).

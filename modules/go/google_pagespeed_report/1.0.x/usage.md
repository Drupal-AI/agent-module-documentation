Record page performance and show it in reports.

---

Performance Monitoring (google_pagespeed_report) records the performance of pages and shows it in reports — measuring page performance (e.g. via Google PageSpeed Insights) over time and presenting the results in admin reports/dashboards, so teams can track and improve site speed.

Any PageSpeed API key is admin-configured (store securely, env-backed). Supports Drupal 9, 10, and 11.

Google AdWords Lite provides a simple, quick way to add the Google Ads (AdWords) tracking/conversion code to a site.

---

Google AdWords Lite provides a minimal way to add Google Ads (formerly AdWords) tracking/conversion
code to a site — an administrator provides the conversion ID/label and the module injects the tracking
snippet, without the configuration of larger analytics modules. It is configured at
`google_adwords_lite.admin_settings_form` and provides its own permissions.

Use it to add Google Ads conversion tracking simply. As with all ad/analytics tracking, there are
privacy/consent implications: it loads Google's tracking and can set cookies — pair with cookie-consent
handling and disclose the tracking per your jurisdiction. It has no access-control role. Configure the
conversion tracking.

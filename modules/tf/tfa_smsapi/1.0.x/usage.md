Deliver two-factor authentication codes by SMS via SMS API.

---

Drupal Two Factor Authentication - SMS API is a TFA plugin that delivers the two-factor login code by SMS using the SMS API (smsapi) module — so users completing two-factor login receive their one-time code as a text message. Code validation is handled by the vetted TFA framework.

The SMS API credentials are admin-configured (via the smsapi module); store them securely (env-backed). Depends on `tfa` (>=1.5) and `smsapi`; supports Drupal 10.2+ and 11.

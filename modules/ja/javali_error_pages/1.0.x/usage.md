Javali Error Pages adds custom 403/404/maintenance pages.

---

Javali Error Pages **adds custom 403/404/maintenance error pages** — letting you configure branded,
friendlier pages for access-denied, not-found and maintenance-mode responses instead of the plain defaults. It
is in the Javali package.

Use it to customize error/maintenance pages. It is a site-structure/UX feature affecting error responses; the
pages are admin-configured content and it has no access-control role (it doesn't change WHO gets a 403, only how
the 403 looks). Configure the error pages.

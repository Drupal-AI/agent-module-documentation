# Javascript Scripting — agent index

**JS engine to execute code in Drupal** (script field + `javascript:execute` Drush). Version **1.0.1**. Core `^10||^11`.

Code-execution tool — script authoring is the trust boundary; restrict the script field to trusted roles (like PHP/scripting tools). Execute action gated by field edit access.

# QR Code Generator — agent index

Generates **QR codes** with **self-hosted / offline** generation (no third-party service — encoded data
stays on the server). Depends on core `file`, `rest`; provides permissions. Version **2.0.3**. Core
`^10.3||^11`.

Privacy-friendly (nothing leaves the server). Govern generation via permissions; validate encoded
input as normal.

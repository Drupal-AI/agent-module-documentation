QR Code Fields adds a family of field types (URL, Text, Phone, SMS, Email, WiFi, meCard, vCard v3, Calendar event) and matching blocks that render a scannable QR code image from field/token data, generated on the fly by a pluggable third-party QR-image service.

---

The module ships nine `qrcode_*` field types, each with its own widget and a shared `qrcode_fields_formatter` / `qrcode_fields_formatter_url` formatter, plus nine `QR*Block` blocks for placing standalone QR codes in regions. Each field type collects the structured pieces it needs (e.g. WiFi SSID/password/encryption, vCard name/phone/email, event summary/dates) and every text input supports **Token** replacement against the host entity, so a QR value can be built dynamically from the entity's own fields (`[node:title]`, `[site:url]`, …). At render time the `qrcode_fields.qrimage` service assembles the standard QR payload string (`WIFI:…`, `MECARD:…`, `BEGIN:VCARD…`, `MATMSG:…`, `TEL:…`, `SMSTO:…`, `BEGIN:VCALENDAR…`) and hands it to the selected **QR URL service plugin** (`gchart` = Google Chart API [deprecated], `goqr` = api.qrserver.com [default], `tec_it` = qrcode.tec-it.com), which returns a remote image URL rendered as an `<img>`. The service plugin is chosen per field in the field settings (`qrcode_plugin`, default `goqr`) or per block. Because the image is generated by an **external service** with the payload passed in the URL query string, the encoded data (including WiFi passwords or vCard contact details) is sent to that third party and fetched by the visitor's browser. A config schema is provided for the field/widget/formatter settings; there is no global admin page.

---

- Add a QR code to a content type that links to the node's own URL via `[node:url]`.
- Generate a WiFi-join QR code (SSID, password, encryption) for a venue or event page.
- Put a vCard v3 QR code on a staff/profile content type for one-scan contact saving.
- Add a meCard QR code as a lighter-weight contact alternative to vCard.
- Encode a "call us" phone-number QR (`TEL:`) on a landing page.
- Encode a pre-filled SMS (`SMSTO:` number + message) QR code.
- Encode a pre-filled email (recipient, subject, body) QR code.
- Add a calendar-event QR (vCalendar) so visitors can add an event to their calendar.
- Encode arbitrary text into a QR code with the Text field type.
- Build the QR value dynamically from entity fields using tokens.
- Place a standalone QR code in any region using the QR Code Field blocks.
- Show a "URL only" QR (image-as-link) using the `qrcode_fields_formatter_url` formatter.
- Optionally display the encoded text alongside the QR block image.
- Set the QR image width/height per field, widget, or block.
- Switch the QR generation service per field between goQR, Tec-IT, and Google Chart.
- Preview the generated QR code live in the field widget while editing.
- Add multiple QR fields to one entity (e.g. a URL QR and a WiFi QR).
- Generate event registration links as QR codes on event nodes.
- Produce marketing/print QR codes that resolve to campaign landing pages.
- Add a "save my details" QR to author bylines or footers.
- Combine with `multiple_field_remove_button` to manage multi-value QR fields.

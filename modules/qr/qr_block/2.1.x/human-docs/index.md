# QR Block — manual setup guide

**QR Block** (`qr_block`) provides a placeable **block** that renders a QR-code
image built from text you supply. The text supports **tokens**, so a single block
can produce a dynamic QR code — for example encoding `[site:name] [site:url]`, or
the current node's URL — that changes with context. You place the block from
Drupal's normal Block layout, and everything (text, whether to show a caption, the
image size, and which QR service to use) is set in the block's own configuration.

Under the hood the QR image is generated by a **pluggable QR-URL service**. Two
service plugins ship: **Google Chart API** (`gchart`, the default) and **QR Code
Generator / goQR.me** (`goqr`). Both currently build an image URL against
`https://api.qrserver.com`. Developers can add their own generator by implementing
a `QRUrlServicePlugin`.

> **Privacy note.** The QR image is rendered as an `<img>` whose `src` points at an
> external service. That means the encoded text is sent to a third party
> (`api.qrserver.com`) **by the visitor's browser** when the page loads. Your
> Drupal server does not fetch anything itself (so there is no SSRF), but be aware
> that the QR payload leaves your site. If you need everything to stay on your own
> infrastructure, consider a self-hosted generator instead. This project is not
> covered by Drupal's security advisory policy.

This guide is written for a **human** clicking through the admin UI. If you want
terse, token‑cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

There is **no standalone settings page** — QR Block is configured per block
instance in Block layout, described in "How to use it" below.

## Where it lives in the admin menu

QR Block adds no configuration page of its own. You place and configure it from
**Structure → Block layout** (`/admin/structure/block`), gated by the normal
"Administer blocks" capability.

## How to use it

1. Go to **Structure → Block layout** and click **Place block** in the region you
   want, then choose the **QR Block**.
2. In the block's configuration, set:
   - **QR text** — the text to encode. Tokens are supported, e.g.
     `Welcome to [site:name] [site:url]`.
   - **Display text** — an optional human-readable caption shown under the image
     (you can leave it off to show only the QR code).
   - **Width** and **Height** — the pixel size of the generated image.
   - **QR code service plugin** — pick **Google Chart API** (default) or **goQR.me**
     (or a custom plugin if one is installed).
3. Save the block placement. The QR image renders wherever the block appears.

You can also build a QR image from your own code with the `qr_block.qrimage`
service, for example:

```php
$qr = \Drupal::service('qr_block.qrimage')
  ->setPlugin('gchart')
  ->build(['text' => 'Welcome to [site:name] [site:url]'], 100, 100);
```

A field type that stores configuration for a plugin.

---

Plugin Configuration Field provides a field type that stores configuration for a plugin — so an entity field can hold a plugin selection plus its per-instance configuration, letting site builders attach configurable plugin behaviour to content via a field. It's a developer/field feature. Depends on core `field`; supports Drupal 10.3+ and 11.

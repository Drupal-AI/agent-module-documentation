Display Views results as Plotly.js charts.

---

Plotly charts views adds a Plotly.js chart display for Views — so a View's results can be rendered as an interactive Plotly chart (line, bar, scatter, pie, etc.) instead of a table/list, for data-driven visualizations. Depends on core `views`; supports Drupal 11.

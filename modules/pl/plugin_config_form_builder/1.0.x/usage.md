Plugin Config Form Builder provides an abstract plugin config-form element for developers.

---

Plugin Config Form Builder **provides an abstract plugin config-form element** — a developer helper that
scaffolds configuration forms for plugins, reducing boilerplate when building plugin settings UIs. It works on core
10–11.

Use it as a developer building block for plugin config forms. It is a developer/framework feature; the forms it
helps build are admin config forms and it has no content or access role. Use it in plugin form code.

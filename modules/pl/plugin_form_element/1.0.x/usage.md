Plugin form element provides form elements for plugins.

---

Plugin form element provides Form API elements for plugins — reusable form elements that let a plugin's
configuration form be embedded/rendered as a standard form element, easing building admin UIs that configure
pluggable components. It ships a `plugin_form_element_test` submodule.

Use it as a developer building block for plugin-configuration forms. It is a developer/Form-API feature
providing form elements; it has no content or access role. Use the elements in your plugin configuration
forms.

Plugin Report lists all plugin managers and their plugins on the Drupal Reports page — so a developer can see every registered plugin type (blocks, field types, fields, etc.) and the plugins each provides, aiding discovery and debugging of the plugin system. It's a developer tool. Supports Drupal 10 and 11.

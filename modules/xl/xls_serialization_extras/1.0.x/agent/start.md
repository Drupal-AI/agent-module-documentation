# Excel Serialization Extras — agent index

**Sandbox of extra features for Excel Serialization** (`xls_serialization`) — additional options/formats for
serializing data (e.g. Views results) to Excel/XLS. Depends on `xls_serialization`. Version **1.0.0**. Core
`^9||^10||^11`.

Developer/serialization — exported data reflects what the View/endpoint exposes (respects that endpoint's
access; ensure it doesn't leak fields). No access role of its own.

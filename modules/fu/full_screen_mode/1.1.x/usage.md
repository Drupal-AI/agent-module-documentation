Full Screen Mode provides a full-screen utility.

---

Full Screen Mode provides a **full-screen toggle for the admin interface** — letting administrators hide
toolbars/chrome and use the full viewport when working in the back end, for a distraction-free editing view. It
depends on core Block, in the Full Screen Mode package.

Use it to give admins a full-screen editing mode. It is an administration/UX feature affecting the admin UI
only; it has no content or access role. Enable and use the full-screen toggle.

Fuzzy Term Merge finds near-duplicate taxonomy terms and merges them via a wizard.

---

Fuzzy Term Merge provides a wizard UI for identifying and merging fuzzy-duplicate taxonomy terms within a vocabulary — using fuzzy matching to surface near-duplicates (typos, variants) and merging them with the Term Merge module so references are consolidated. It keeps vocabularies clean.

Merging terms is a content operation that updates references; run it carefully (with a backup). Depends on core `taxonomy` and `term_merge`; supports Drupal 10 and 11.

FullStory Integration adds the FullStory JavaScript snippet to the site.

---

FullStory Integration adds the FullStory tracking JavaScript to the site — enabling FullStory's session
recording, heatmaps and digital-experience analytics, which capture how visitors interact with pages (clicks,
scrolls, navigation, and potentially form input). It is configured at `fullstory.admin_settings_form`,
provides its own permissions.

Use it to gather behavioural analytics via FullStory. **Privacy is the key consideration:** session recording
captures detailed user interaction and can inadvertently record **sensitive input** (passwords, personal data
in forms) unless masked — so use FullStory's field-masking/exclusion features for sensitive elements, disclose
the tracking in your privacy policy, and gate it behind cookie/consent management (GDPR/CCPA — it is
third-party tracking). It has no access-control role beyond its permission. Configure the FullStory org ID and
masking.

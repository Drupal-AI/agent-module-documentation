Fully remove theming/wrapper markup from fields and Layout Builder blocks.

---

Full Reset adds options to fully remove theming from fields and Layout Builder blocks — stripping the default wrapper markup/classes Drupal adds around a field or LB block, so themers get clean, un-wrapped output to style from scratch (a markup 'reset', not a site reset). Depends on core `system` (>=8.7); supports Drupal 8 through 11.

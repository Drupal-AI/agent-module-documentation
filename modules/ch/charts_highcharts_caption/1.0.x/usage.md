Charts Highcharts Caption adds a Views footer "area" that becomes the native Highcharts `caption` displayed inside a Views-built Highcharts chart.

---

This is a tiny add-on for the Charts ecosystem. It supplies a single Views area handler, "Chart Caption", that you place in the footer of a View whose format is a Chart rendered with the Highcharts library. The text you enter (HTML allowed) plus a handful of Highcharts caption positioning options (align, vertical align, floating, margin, x/y offsets, useHTML) are merged into the chart's `caption` definition through `hook_chart_definition_alter()`, so the caption is drawn by Highcharts itself rather than printed as ordinary footer text. A companion preprocess hook strips the same handler out of the normal footer so the caption is not shown twice. There is no admin settings page, no permission, no service, and no Drush — all configuration lives in the Views UI on the area handler.

---

- Add a caption inside a Highcharts chart that is generated by a View.
- Annotate a chart with a source note, methodology note, or data-as-of date.
- Add a legal or attribution line rendered within the chart canvas.
- Place explanatory prose below (or above) the plotted data without a separate block.
- Control caption horizontal alignment: left, center, or right.
- Control caption vertical alignment: top, middle, or bottom of the chart.
- Float the caption over the plot area instead of reserving layout space for it.
- Set the pixel margin between the caption and the plot area.
- Nudge the caption with explicit X and Y pixel offsets.
- Render rich HTML (links, `<em>`, `<strong>`, line breaks) inside the caption via the useHTML option.
- Reuse Views' "Custom text" area features (the handler extends `TextCustom`), including its content textarea.
- Keep captions per-display: each View display can carry its own caption text and positioning.
- Avoid a duplicate footer caption — the module removes the handler from the standard footer output automatically.
- Provide captioned charts for dashboards where each chart needs its own descriptive line.
- Document what a chart represents directly in exported/embedded chart output.
- Add a caption only to Highcharts charts (the alter no-ops for other chart libraries, so it is safe to leave enabled in mixed-library sites).
- Ship caption configuration with a View via configuration export/import (schema `charts_highcharts_caption.area.chart_caption`).
- Give site builders a no-code way to caption charts entirely from the Views UI.

# Configuration

Chatlio's settings live on a single form at **Configuration → Web services →
Chatlio** (`/admin/config/services/chatlio`).

## Before you start

Log in to your account at Chatlio and copy the **embed code** for your widget from
the Chatlio setup page (in the Chatlio dashboard). You'll paste this into Drupal.

## The settings form

1. Go to `/admin/config/services/chatlio`.
2. Paste the snippet you copied into the **Chatlio code** field.
3. *(Optional)* Set any **visibility** rules you need, to control which pages show
   the widget.
4. Save the form.

That's all that's required — once the code is saved, the widget appears on your
site according to the visibility rules (or everywhere, if you leave them open).

## Privacy note

The widget loads Chatlio's third‑party JavaScript, and visitor chat data is sent to
Chatlio's service. Review the privacy implications for your audience and reflect the
Chatlio integration in your site's privacy policy where appropriate.

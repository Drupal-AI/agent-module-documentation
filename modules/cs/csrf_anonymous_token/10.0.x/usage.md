# Anonymous CSRF token

Adds a hidden token element to forms that do not already carry Drupal's `#token`, intended to bring CSRF-style protection to forms submitted by anonymous users.

- Drupal core only adds a form build token for authenticated users; this module targets the anonymous case.
- Works via `hook_form_alter`: any form without `$form['#token']` gets an extra `anon_token` element.
- Also stashes the current session id in `$_SESSION['anon_session_id']`.

---

## Installation & configuration

- Install and enable the module; there is **no** configuration form and no permissions.
- Once enabled, the alter runs on every form build that lacks a core `#token`.
- No routes, services, or schema are provided.
- Behaviour is global — you cannot scope it to specific forms via UI.
- To limit its effect you must alter or unset the added element in a custom module.
- Review compatibility carefully before use on production (see caveats below).

---

## Usage & behaviour / caveats

- On build, a `token` render element named `anon_token` is added with `\Drupal::csrfToken()->get()` as its default value.
- A validator `anonymous_token_validate_anon_token` is unshifted to the front of `#validate`.
- The validator's condition (`$token !== null`) is effectively always true for the string token value, so its error branch can fire on normal submissions.
- Net effect: it can break legitimate anonymous form submissions; treat it as experimental.
- The token generated by `csrfToken()->get()` with no seed is the generic per-session token, not a per-form value.
- The module touches `$_SESSION` directly rather than the Symfony session API.
- No admin UI means you cannot allowlist forms; it affects login, register, contact, search, etc.
- Consider Drupal core's built-in protections and dedicated anti-spam modules instead.
- Because it runs on all tokenless forms, test thoroughly with cached pages and the internal page cache for anonymous users.
- Uninstalling removes all altered behaviour immediately.
- The module ships only `.info.yml` and `.module` — no classes to override.
- File to read: `csrf_anonymous_token.module`.
- Reported version string is `10.0.1`; normalized doc version `10.0.x`.

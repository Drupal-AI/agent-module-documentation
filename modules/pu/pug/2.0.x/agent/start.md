# Pug (Password Update Guidance) — agent index

**Provides dynamic control over password recommendation** (guidance). Depends on core `user`. Version **2.0.x**
(dev). Core `^10||^11`.

Security-adjacent/UX — **advises** on passwords (not enforced policy); use a password-policy module for enforcement.
Complements, not replaces, real password controls. No access role.

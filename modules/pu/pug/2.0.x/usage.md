Pug (Password Update Guidance) provides dynamic control over password recommendations.

---

Pug **provides dynamic password recommendations** — giving configurable guidance/recommendations to users about
their passwords (strength hints, update prompts). It depends on core User.

Use it to nudge better passwords. It is a security-adjacent/UX feature: it **advises** on passwords (recommendations)
but is not itself a password policy — for enforced rules use a password-policy module. Treat it as guidance that
complements, not replaces, real password policy and authentication controls. It has no access-control role.
Configure the password recommendations.

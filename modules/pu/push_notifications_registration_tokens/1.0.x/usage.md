An entity type for storing push-notification registration tokens.

---

Push Notifications Registration Tokens provides an entity type for push notifications registration tokens — a storage entity where per-user/device push tokens (from web/mobile push registration) are recorded, so other modules can target notifications to registered devices. Depends on core `options` and `user`; supports Drupal 11.2+.

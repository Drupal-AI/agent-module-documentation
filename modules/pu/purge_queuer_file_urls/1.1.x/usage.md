Queue file URLs from file fields for purging.

---

File URLs Queuer is a purger/queuer for file URLs derived from file upload fields — so when content changes, the URLs of files attached via file fields are queued for cache invalidation through Purge, keeping CDNs and reverse proxies from serving stale file URLs. Depends on core `file` and `purge`; supports Drupal 9, 10, and 11.

---

Publishing options (machine name `publishing_options`) provides an admin interface to create custom
publishing options — additional boolean flags on content alongside core's Published/Promoted/Sticky, that
site builders can define and use to drive display/logic (e.g. a "Featured", "Archived" or "Show in
sidebar" flag). It is configured at `publishing_options.settings` and provides its own permissions.

Use it to add custom on/off flags to content without a full field for each. It is a content-editing/
publishing feature adding flags; the flags themselves are metadata and their effect (visibility, logic)
depends on how the site uses them — the flags are not access controls unless you build access logic around
them. Configure the custom options.

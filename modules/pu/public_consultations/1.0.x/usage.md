Public Consultations provides a public-consultation content type with webform submissions.

---

Public Consultations **provides a public-consultation feature** — a content type for running public
consultations (proposals open for public comment/response) with associated Webform submissions and clean URLs. It
depends on the Webform and Pathauto modules, and provides its own permissions.

Use it to run public consultations. It is a content/engagement feature. Data-handling note: consultations collect
**public submissions** which may include **personal data/opinions (PII)** — handle submissions per your privacy
policy, moderate submitted content (it's user-supplied — sanitize/consider spam), and control who can view
submissions. It has its own permissions. Configure the consultation content type and forms.

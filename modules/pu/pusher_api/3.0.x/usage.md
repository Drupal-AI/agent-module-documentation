Integration between Drupal and pusher.com.

---

Pusher API provides integration between Drupal and pusher.com — a base client for the Pusher Channels real-time messaging service, so other modules can publish events to Pusher channels and browsers can subscribe for live updates (notifications, presence, chat).

The Pusher app id/key/secret are admin-configured and should be stored securely (env-backed), never committed. Supports Drupal 10.2+ and 11.

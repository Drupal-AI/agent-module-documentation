Push Drupal log entries to an external receiving service.

---

Push my logs pushes Drupal logs to an external receiving service — forwarding watchdog/log entries to a remote log-aggregation endpoint so operators can centralise and monitor site logs off-box.

The receiving-service endpoint/credentials are admin-configured and should be stored securely (env-backed), never committed. Supports Drupal 8 through 11.

# Persistent URL (purl) — agent index

A framework for **modifying URLs based on context** (modules define URL modifiers — path prefix/subdomain/
domain — that establish context from the URL and rewrite outbound links). Foundation for per-group/per-
workspace URLs etc. Version **2.0.1**. Core `^10.1||^11`.

Site-structure/routing framework — establishes context (consuming modules enforce their own access); resolves/
rewrites URLs. No access role.

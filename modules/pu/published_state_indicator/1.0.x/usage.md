Display a node's moderation state alongside its title.

---

Published State Indicator displays the moderation state alongside the node title — a field formatter that shows the content-moderation state (Draft, Published, Archived, …) next to a node's title, so editors can see at a glance what workflow state a piece of content is in. Supports Drupal 10 and 11.

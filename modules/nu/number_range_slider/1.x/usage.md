Number Range Slider provides an HTML-native number range slider field widget.

---

Entering a number within a range is nicer with a slider than a text box. Number Range Slider provides an HTML-native range-slider widget for number fields. It is a form-widget with no security surface — the field's own validation (min/max) still applies regardless of the widget. Confirm the number field's range constraints are set.

Webform Numeric Element Validation extends the Webform textfield to support flexible decimal number validation.

---

Webform Numeric Element Validation (number_element) **adds a numeric Webform element** — an extension of the
Webform textfield that supports flexible decimal properties/validation (precision, separators), for better numeric
input in webforms. It depends on the Webform module.

Use it for validated numeric webform fields. It is a forms/webform feature; it validates numeric input and has no
access-control role. Configure the numeric element in a webform.

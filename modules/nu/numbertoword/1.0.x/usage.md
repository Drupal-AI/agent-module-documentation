Number to Word provides a field formatter that renders numeric field values as words.

---

Number to Word (numbertoword) **provides a field formatter that renders numbers as words** — a formatter for
numeric fields that outputs the spelled-out word representation of the value on display. It depends on core Field.

Use it to display numeric fields as words. It is a content-display/field-formatter feature; the stored value is
unchanged and only the display is worded, and it has no access-control role. Configure the formatter on a numeric
field.

# Number Double — agent index

Defines a **field/schema for a MySQL DOUBLE-precision numeric field** (higher range/precision than core number
fields). Version **8.x-1.5**. Core `^8||^9||^10||^11`.

Fields/content — values follow normal field handling; no content/access role.

Number Double defines schema for a MySQL double field.

---

Number Double **defines a field with a MySQL DOUBLE-precision schema** — a numeric field type that stores
values as a database `DOUBLE`, for cases needing higher-range/precision floating-point storage than the core
number fields provide.

Use it when you need double-precision numeric storage. It is a fields/content feature; values follow normal
field handling and it has no content or access role. Add the number-double field to an entity.

# Ouibounce Exit Modal — agent index

Displays an **exit-intent modal (Ouibounce)** before a user leaves the site (last-chance offer/sign-up/
message). Depends on core `block`, `views`. Version **4.0.1**. Core `^10.3||^11`.

User-engagement/UI — modal content from a block/View (respects its access); no access role.

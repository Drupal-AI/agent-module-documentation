Ouibounce Exit Modal integrates the Ouibounce library to display a modal before a user leaves your website.

---

Ouibounce Exit Modal integrates the Ouibounce JavaScript library to show an exit-intent modal — a popup
displayed when the visitor's cursor moves to leave the page (e.g. a last-chance offer, newsletter sign-up or
message). It depends on core Block and Views, in the Block package.

Use it to show an exit-intent popup. It is a user-engagement/UI feature; the modal content comes from a
block/View (respecting its access) and it has no access-control role. Note exit-intent popups affect UX —
use judiciously. Configure the trigger and modal content.

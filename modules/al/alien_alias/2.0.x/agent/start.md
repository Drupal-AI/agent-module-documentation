# Alien Alias — agent orientation

**Machine name:** `alien_alias`  
**Version dir:** `2.0.x`  
**Core:** `^9 || ^10`  
**Dependencies:** none  
**Configure route:** `n/a`

## What it does
Provides a redirect system of alias entities that link internal paths to external URLs.

## Where to look
- `alien_alias.info.yml` — metadata and dependencies.
- `alien_alias.routing.yml` / `.permissions.yml` / `.services.yml` — routes, permissions, services (where present).
- `src/` — controllers, forms, plugins and services.

See `../usage.md` for install, configuration and usage details.

# Alter blocks element markup — agent orientation

**Machine name:** `alter_blocks_element_markup`  
**Version dir:** `1.0.x`  
**Core:** `^9.3 || ^10`  
**Dependencies:** drupal:block  
**Configure route:** `n/a`

## What it does
Lets site builders alter the wrapper element, markup and classes of rendered blocks.

- `alter_blocks_element_markup.info.yml` — metadata and dependencies.
- `alter_blocks_element_markup.routing.yml` / `.permissions.yml` / `.services.yml` — routes, permissions, services (where present).
- `src/` — controllers, forms, plugins and services.

# Alerts Format — manual setup guide

**Alerts Format** (`alerts_format`) provides styling and presentation for alert
and notice components — the colours, icons, and layout that make a warning look
like a warning and a success message look like a success. It is a small theming
helper that ships as part of the "Recipes Support" family of modules.

It has no content, no permissions, and no access-control role of its own. Once
enabled it simply affects how alert/notice components are presented on the site.
There is nothing you have to fill in to make it work — enable it and the styling
is available.

This guide is written for a **human** clicking through the admin UI. If you want
terse, token-cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Contents

## Where it lives in the admin menu

Alerts Format has no settings page and adds no menu items. It works purely as a
presentation layer for alert components once enabled.

## How to use it

Enable the module (see [Installation](installation/index.md)). From that point
the alert/notice styling it provides is applied to the alert components on your
site. There is nothing further to configure — it is a pure theming helper.

Alertbox creates alert boxes to display information across the site, built on custom block content with a modal submodule.

---

Install the module (requires block_content, text and options). Configure at /admin/structure/alertbox (permission: administer alertbox). Create alertbox block content and place it, optionally enabling the alertbox_modal submodule for modal display.

---

- Display site-wide alert/notification banners.
- Build alerts on core block_content.
- Provide a settings form at /admin/structure/alertbox.
- Gate configuration behind 'administer alertbox'.
- Offer an alertbox_modal submodule for modal alerts.
- Depend on block_content, text and options.
- Show announcements across pages.
- Let editors manage alert content as blocks.
- Configure appearance/behaviour centrally.
- Serve as a content-display/notification feature.
- Have a defined config schema.
- Place alerts in theme regions.
- Support option-based alert types.
- Keep alerts on public pages.
- Add a single admin permission.
- Work across Drupal 8.8+ to 10.
- Reuse block placement for targeting.
- Provide announcement banner UX.

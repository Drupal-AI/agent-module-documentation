# Allowed Values Functions — manual setup guide

**Allowed Values Functions** (`allowed_values_functions`) is a developer tool that
makes it easy to generate a list/options field's choices **dynamically** — by
pointing the field at a PHP method — instead of typing a fixed list of allowed
values. This is useful when the options a field should offer depend on other data
or on context, and can't be hard-coded.

Drupal has long supported an "allowed values function" for options fields, but
wiring one up is fiddly. This module makes setting a method as that function
straightforward, so a site builder or developer can drive a field's options from
code.

Because the configured method runs on the server whenever the options are needed,
this is a tool to hand only to trusted users — restrict who is allowed to
configure it. It has no content or access-control role of its own, and it
requires **Drupal 11**.

This guide is written for a **human** clicking through the admin UI. If you want
terse, token-cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Where it lives in the admin menu

There is no central settings page. You use it when configuring a list/options
field, where it lets you set a PHP method as the field's allowed-values function.

## How to use it

1. Enable the module and grant its configuration permission only to trusted
   developers or site builders — the configured method runs server-side.
2. When configuring a list/options field, set the desired PHP method as the
   field's allowed-values function.
3. The field's choices are then generated by that method at runtime, so they can
   reflect other data or context rather than a static list.

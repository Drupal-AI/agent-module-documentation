# Ironstar — agent index

Drupal/AWS). Configuration/helpers + settings at `ironstar.settings`. Version **1.0.3**. Core
`^10||^11`.

Operational/host-integration (reverse-proxy, environment, deployment) — follow the host's guidance.
Provides admin permissions. No purpose off-platform.

Render a View as a form with rows as select/radio/checkbox options.

---

Views style plugin: Form options is a Views style plugin that renders a View as a form and its result rows as options (select box, radio buttons or checkboxes) — so a View can become an interactive chooser (e.g. pick one/more of the listed entities), useful for building selection forms from view results. Depends on core `views`; supports Drupal 8 through 11.

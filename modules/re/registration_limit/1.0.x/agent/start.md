# Registration Limit — agent index

**Limits account registration per IP when an account already exists for that IP**. Provides permissions. Version
**1.0.1**. Core `^10.3||^11`.

Access/anti-spam — keys on **IP** (imperfect: blocks shared/NAT users, bypassable by IP rotation). One weak signal;
combine with CAPTCHA/email verification/flood control. No broad access role beyond permission.

Required by Content Moderation State makes fields required only in certain moderation states.

---

Required by Content Moderation State lets **fields be required only in specific moderation states** — e.g. a
field can be optional in Draft but required when moving to Published, using the Required API and Content
Moderation. It depends on the Required API and core Content Moderation.

Use it for state-dependent field requirements in editorial workflows. It is a content-editing/workflow feature
affecting form validation; it has no content or access role. Configure which fields are required in which
states.

# Reader — agent index

A **Progressive Web App (PWA) reader interface** for site content (app-like, offline/installable;
`reader_theme` submodule). Provides permissions. Version **1.0.4**. Core `^10||^11`.

Front-end/user-engagement — surfaces content following normal content access; no access role beyond
permission.

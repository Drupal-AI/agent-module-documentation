# Responsive Voice Text to Audio — agent index

Adds **text-to-speech (read-aloud)** to content via **ResponsiveVoice.js** (accessibility/convenience).
Depends on core `node`; provides permissions. Version **1.1.0**. Core `^10||^11`.

Content-display/accessibility — reads content the user can see; no access role. Loads third-party
ResponsiveVoice.js (review its terms/licensing; text sent for synthesis = privacy consideration).

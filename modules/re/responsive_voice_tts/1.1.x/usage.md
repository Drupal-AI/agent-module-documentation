Responsive Voice Text to Audio adds text-to-speech functionality using ResponsiveVoice.js.

---

Responsive Voice Text to Audio adds text-to-speech (read-aloud) to content — using the ResponsiveVoice.js
library to let visitors have page/node text read aloud, an accessibility/convenience feature. It depends on
core Node and provides its own permissions.

Use it to offer read-aloud of content. It is a content-display/accessibility feature; it reads content the
user can see and has no access-control role. Note it loads the third-party ResponsiveVoice.js (which may have
its own usage terms/licensing and sends text to its service for synthesis — a privacy/data consideration for
sensitive content); review ResponsiveVoice's terms. Configure the text-to-speech behaviour.

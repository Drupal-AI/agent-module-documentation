# Responsive Image Field — agent index

Field type for **responsive images with a different image per breakpoint** (true art-direction — not
just sized variants of one source). **Requires PHP 8.1**; depends on core `responsive_image`,
`media_library`, `media_library_form_element`. Version **1.1.1**. Core `^10||^11`.

Media/field feature (no access role). Configure breakpoints via responsive image styles.

Responsive Image Field defines a field type for responsive images, letting editors supply different images for individual breakpoints (art direction).

---

Responsive Image Field defines a field type for responsive images where editors can supply
different images for individual breakpoints — true art-direction, choosing a distinct image (not just a
resized variant) for mobile, tablet and desktop. This goes beyond core Responsive Image (which serves
sized variants of one source) by letting the source itself differ per breakpoint. It requires PHP 8.1,
depends on core Responsive Image, Media Library and the Media Library form element, and is configured
via responsive image styles.

Use it where design calls for genuinely different images at different screen sizes (a wide hero on
desktop, a cropped portrait on mobile). It is a media/field feature governing image display; it stores
and renders images with no access-control role. Configure breakpoints via core responsive image styles
and supply per-breakpoint images through the field.

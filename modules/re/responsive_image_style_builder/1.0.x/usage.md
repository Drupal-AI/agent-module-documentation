Responsive Image Style Builder auto-creates image styles connected to theme breakpoints.

---

Responsive Image Style Builder **auto-creates responsive image styles from breakpoints** — generating image
styles tied to a theme's breakpoints and assembling new responsive image styles, reducing manual image-style setup.
It depends on core Responsive Image.

Use it to scaffold responsive image styles. It is a media/site-building tool; it creates image-style config and has
no content or access role. Configure the breakpoint-to-style generation.

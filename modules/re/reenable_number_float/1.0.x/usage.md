Reenable Number Float re-enables the Number (float) and List (float) field types in the UI.

---

Reenable Number Float **re-enables the float field types** — restoring the "Number (float)" and "List (float)"
field types to the Field UI, which core hides/deprecates, for sites that still need float fields. It depends on core
Field.

Use it if you need float fields in the UI. It is a fields/compatibility feature; it exposes existing core field
types and has no content or access role. Note: float fields have precision caveats — prefer decimal for exact
values. Enable it for float field types.

Registration Extras provides extra functionality for user registration.

---

Registration Extras **provides extra user-registration functionality** — adding features/behaviors to the user
registration process (form additions, handling). It works across core 9–11.

Use it to enhance user registration. It is a user/registration feature. Security note: user registration is
**account-creation** and a common abuse target — verify any added behavior does **not weaken registration controls**
(e.g. don't auto-assign privileged roles, don't bypass admin approval or email verification), apply anti-spam, and
handle registration data (PII) per your privacy policy. It has no explicit access-control role. Configure the
registration extras.

Required If Field Has Value makes a field required only if another field has a value.

---

Required If Field Has Value **conditionally requires a field** — making a field mandatory only when another
field has a value, across all fieldable entity types (nodes, users, terms, custom entities). It provides its own
permissions.

Use it for conditional field requirements. It is a content-editing/validation feature; it enforces
form/entity validation and has no access-control role beyond its permission. Configure the conditional-required
rules.

Responsive Layout Builder controls display of blocks in Layout Builder using breakpoints (media queries).

---

Responsive Layout Builder lets you control the display of blocks in Layout Builder per breakpoint —
using media queries to show/hide or adjust blocks at different screen sizes, so a Layout Builder layout can
be made responsive (e.g. hide a block on mobile). It depends on core Layout Builder and Breakpoint, and is
configured at `responsive_layout_builder.settings`.

Use it to make Layout Builder layouts responsive. It is a content-display/layout feature affecting how
blocks render across breakpoints; blocks keep their own access and it has no access-control role. Note:
hiding a block via CSS/media queries is a *display* choice, not access control — a CSS-hidden block's
content is still in the page. Configure the breakpoints and per-block visibility.

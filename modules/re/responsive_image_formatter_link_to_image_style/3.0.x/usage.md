# Responsive Image formatter link to image style

This module adds an image field formatter
(`responsive_image_formatter_link_to_image_style`) that combines two core capabilities:

- Render the image using a **responsive image style** (art-directed `<picture>` output).
- **Link** that image to a derivative generated by a chosen **image style** (e.g. a large or
  original version).

You can also add custom classes and `rel` attributes to the link, and classes to the `<img>`
element — making it ideal for thumbnail-to-large linking and lightbox integrations.

---

## Installation & configuration

- Requires core `image` and `responsive_image`.
- Install with `drush en responsive_image_formatter_link_to_image_style`.
- On an image field's *Manage display*, choose **Responsive Image link to image style** and set:
  the responsive image style, the link target image style, link class(es), link rel(s), and
  image class(es).
- Leaving the link image style empty links to the original image.
- Output is themed via `responsive_image_formatter_link_to_image_style_formatter` with cache
  tags merged from the responsive/image styles and file.

---

## Use cases

- Show a responsive thumbnail that links to a large image-style derivative.
- Build lightbox galleries where responsive thumbs open bigger images.
- Link responsive images to the original file for download/zoom.
- Add `rel="lightbox"` (or similar) to responsive image links.
- Apply CSS classes to both the link and the image element.
- Serve art-directed responsive images while keeping click-through.
- Provide print/large versions behind responsive previews.
- Integrate with Colorbox/PhotoSwipe-style front ends via rel/class.
- Keep responsive performance benefits plus a full-size link.
- Reuse across multiple image fields and view modes.
- Configure different link styles per display mode.
- Avoid custom Twig to combine responsive images with links.
- Support product galleries with responsive thumbs and large views.
- Link editorial images to high-resolution derivatives.
- Add tracking/utility classes to image links.
- Cache-correctly render responsive linked images.

# Recipe Code Installer — agent index

Lets **Drupal Recipes package and install bundled code as a custom module**. Version **1.0.2**. Core
`^10.4.0||^11.1.0`.

Developer/devops — **installing bundled code = arbitrary code** (runs with full privileges once enabled): only
apply **trusted** recipes, review the code first, treat as privileged deployment. No runtime access role.

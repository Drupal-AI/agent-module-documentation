Provide React JavaScript libraries for use in Drupal.

---

React provides React libraries for use in Drupal — registering the React/ReactDOM JavaScript libraries (via import maps) so other modules and custom code can build React-based UI components on a Drupal site without bundling their own copy of React. Depends on `importmaps`; supports Drupal 9+.

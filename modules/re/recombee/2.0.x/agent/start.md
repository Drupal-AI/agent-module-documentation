# Recombee — agent index

Configurable **recommendation blocks** powered by the **Recombee** hosted recommendation API
(personalized/related items). Depends on `js_cookie`, `json_template`. Config at `recombee.settings`.
Version **2.0.7**. Core `^10.3||^11||^12`.

**Privacy:** sends **user behaviour data** (views/clicks/identifiers) to Recombee + API credentials —
store credentials as secrets; obtain consent + disclose (GDPR/ePrivacy; gate behind consent where
required).

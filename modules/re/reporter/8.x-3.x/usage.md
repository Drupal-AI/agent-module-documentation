Reporter a report writer for building re-runnable tabular reports.

---

Reporter **is a report writer** — letting admins build tabular reports (queries over site data) that can be
saved and re-run at any time, for custom reporting. It works across core 10–12.

Use it to build custom tabular reports. It is an administration/reporting tool. Security note: reports can query
and expose **site data** (potentially including sensitive fields), so restrict who can build and view reports to
trusted admins, and be careful that report definitions don't surface data beyond the audience's access. It has no
content or access role of its own. Configure and run reports.

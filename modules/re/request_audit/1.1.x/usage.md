Request Audit records per-request telemetry for auditing and analysis.

---

Request Audit collects telemetry data from requests — recording information about incoming requests for auditing, debugging, or analysis (paths, timing, and related signals). It gives operators visibility into request patterns on the site.

Because request data can include sensitive information (paths, parameters), configure what is captured and its retention with care, and restrict access to the audit data. It's an operations/telemetry module. Supports Drupal 10, 11, and 12.

Redirects Fixer helps find links that point to redirected paths.

---

Redirects Fixer **finds internal links that point to redirected (old) paths** and helps update them to the
final destination — reducing redirect hops and broken-link risk, using Linkit, core Node, Block Content and
Views. It provides its own permissions.

Use it to clean up stale internal links. It is an administration/SEO maintenance tool run by editors/admins; it
scans and rewrites site content links, so gate it to trusted operators (rewriting content is a privileged
action) via its permissions, and it has no access-control role beyond that. Run the link scan and apply fixes.

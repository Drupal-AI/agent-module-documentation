# Permissions

All permissions are **dynamic**, generated by
`RegistrationWorkflowPermissionProvider::buildPermissions` — one per transition of every workflow of
type `registration`:

```
use <workflow_id> <transition_id> transition
```

For the shipped `registration` workflow that means:

| Permission | Allows |
|---|---|
| `use registration complete transition` | move pending/held registrations to **complete** |
| `use registration hold transition` | move pending registrations to **held** |
| `use registration cancel transition` | move registrations to **canceled** |

Custom registration workflows contribute their own `use <workflow> <transition> transition`
permissions automatically.

Holding the permission is necessary but not always sufficient: with `require_update_access` (default
true) the account must also have update access to the registration, and `prevent_complete_own`
(default false) can block completing one's own registration. See
[../configure/workflow.md](../configure/workflow.md).

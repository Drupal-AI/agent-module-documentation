Reference Number Trimmer removes ids from reference fields.

---

Reference Number Trimmer **removes entity IDs from the rendered output of reference fields** — so a
reference that would otherwise display with an ID/number shows a cleaner label without the trailing id. It is
in the Custom package.

Use it to clean up reference-field display. It is a content-display/formatter feature affecting presentation
only; it has no content or access role. Apply it to the relevant reference fields.

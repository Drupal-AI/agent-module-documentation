Absolute URLs converts relative URLs in exported data to absolute URLs.

---

Absolute URLs (relative_to_absolute_urls) **converts relative URLs to absolute** — rewriting relative paths in
exported/serialized data into absolute URLs, so content exported for use elsewhere resolves correctly. It works on
core 10–11.

Use it when exporting content that must carry absolute links. It is a data-transformation/export feature; it
rewrites URLs in output and has no content or access role. Configure the URL conversion.

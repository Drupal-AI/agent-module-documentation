# Render Menu Token — agent index

A **token/text-filter that renders a menu tree inside content** (embed navigation via the Token filter).
Depends on core `filter`, `token`. Version **1.0.0**. Core `^10||^11`.

Content-display — use with the **Token filter** on **trusted text formats**; rendered menu respects the menu's
normal access; no access role.

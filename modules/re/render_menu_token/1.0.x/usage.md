Render Menu Token provides a menu token to render a menu tree.

---

Render Menu Token provides a **token that renders a menu tree** — so a menu can be embedded into content/
text (via the Token filter) by placing a token, useful for dropping navigation into a body or block. It depends
on core Filter and Token.

Use it to embed menus in content. It is a content-display feature. Security note: it is used with the **Token
filter**, so it should only be available on **trusted text formats** (a token that renders a menu is low-risk,
but as a general rule token-rendering filters belong on formats editors — not anonymous users — can use). The
rendered menu respects the menu's normal access. It has no access-control role. Use the menu token in
content.

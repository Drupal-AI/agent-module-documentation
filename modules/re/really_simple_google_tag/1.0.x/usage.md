Really Simple Google Tag is a small module that lets administrators add one or more Google Tag Manager (GTM) container tags to a website quickly and reliably.

---

Really Simple Google Tag is a minimal module for adding Google Tag Manager container tags to a site.
An administrator enters one or more GTM container IDs and the module injects the corresponding GTM
snippet into pages, deliberately keeping configuration to the essentials rather than the broader
options of larger tag/analytics modules.

Use it when you just need GTM on the site without extensive conditions. Be aware of the privacy/consent
implications common to all tag-manager integrations: GTM can load third-party tracking and set cookies,
so pair it with appropriate cookie-consent handling and privacy disclosures per your jurisdiction. It
is an integrations/analytics module; the tags themselves and what they load are defined in the GTM
console, not in Drupal.

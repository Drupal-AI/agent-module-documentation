# Really Simple Google Tag — agent index

Minimal module to add **Google Tag Manager** container tags — enter GTM container ID(s), it injects the
snippet. Version **1.0.4**. Core `^8.9||^9||^10||^11`.

**Privacy/consent:** GTM can load third-party tracking and set cookies — pair with cookie-consent and
disclosures. Tags are defined in the GTM console, not Drupal.

An improved widget for managing redirect entities on node edit pages.

---

Redirect Widget provides an improved widget for adding redirect entities on node edit pages — surfacing the creation/management of URL redirects directly in the node form so editors can add redirects to a page while editing it, instead of using the separate Redirect admin UI. Depends on `redirect`; supports Drupal 10 and 11.

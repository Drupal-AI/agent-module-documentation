Responsive Image Debugger prints the image-style name on displayed images for debugging.

---

Responsive Image Debugger **prints the image-style name on images** — overlaying the name of the image style
used directly on each displayed image, so developers can debug which style/responsive variant is rendering. It
depends on the Image Effects module.

Use it in development to debug image styles. It is a developer/debugging tool; it annotates image output
(developer-facing) and has no content or access role. Note: disable it in production (it alters image display).
Enable it to debug image styles.

Regions Override disables regions from appearing on specific pages.

---

Regions Override lets you disable specific theme regions on specific pages — so a region (sidebar,
header, footer) can be suppressed on chosen paths, for landing pages or special layouts that need a cleaner
template. It provides its own permissions, in the Layout package.

Use it to suppress regions per page. It is a content-display/layout feature affecting which regions render on
a page; the blocks in those regions are simply not rendered there (their own access is unchanged), and it has
no access-control role. Configure which regions are disabled on which pages.

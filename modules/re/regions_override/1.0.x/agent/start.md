# Regions Override — agent index

Lets you **disable theme regions from appearing on specific pages** (suppress sidebar/header/footer on chosen
paths — cleaner landing-page layouts). Provides permissions. Version **1.0.0-alpha7**. Core
`^9||^10||^11`.

Content-display/layout — affects which regions render (blocks in them simply aren't rendered there; their
access unchanged); no access role.

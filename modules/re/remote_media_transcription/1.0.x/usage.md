Add a transcription field to remote-video media types.

---

Remote Media Transcription adds a transcription field to the remote video media type — so remote-hosted videos (e.g. YouTube/Vimeo via oEmbed) can carry a text transcription for accessibility and search, stored and displayed alongside the media. Depends on core `media` and `media_library`; supports Drupal 9, 10, and 11.

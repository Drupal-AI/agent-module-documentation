# ReplayWeb.page — agent index

Plays **web archive files (WARC/WACZ) in the browser using ReplayWeb.page**. Depends on core `media`. Version
**1.0.1**. Core `^9.3||^10||^11`.

Media/display — **replays archived web content** (potentially untrusted third-party content; ReplayWeb.page
sandboxes replay via a service worker — host trusted archives). No access role.

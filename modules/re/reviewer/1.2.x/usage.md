Reviewer automates reviews of Drupal configuration.

---

Reviewer **automates reviews of Drupal configuration** — running checks against the site's config to flag
issues/best-practice deviations (with a `reviewer_ui` submodule), useful for auditing config quality. It
requires PHP 8.2, in the Development package.

Use it to audit configuration. It is a developer/administration tool that inspects config; its report can
reveal configuration detail (keep it to developers/admins), and it has no access-control role. Run the config
review.

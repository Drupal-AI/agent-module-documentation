# Reviewer — agent index

**Automates reviews of Drupal configuration** (best-practice/issue checks; `reviewer_ui` submodule). Requires
PHP 8.2. Version **1.2.1**. Core `^10.2||^11`.

Developer/admin — inspects config; reports can reveal configuration detail (keep to developers/admins); no
access role.

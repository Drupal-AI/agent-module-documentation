RenderViz provides tools to help debug cache metadata.

---

RenderViz provides **tools to help debug render cache metadata** — visualizing the cacheability
(cache tags, contexts, max-age) attached to render arrays, so developers can understand and fix caching
behaviour. It requires core 11.2+, in the Development package.

Use it to debug caching/cacheability during development. It is a developer/debugging tool. **Security note:**
like any debug tool it can surface **internal render/cache detail** (which can hint at structure and data
dependencies), so keep it to **developers** and prefer **not enabling it on production**. It has no
access-control role. Use it to inspect cache metadata.

# RenderViz — agent index

A developer tool for **debugging render cache metadata** (visualize cache tags/contexts/max-age on render
arrays). Version **2.0.1**. Core `^11.2||^12`.

Developer/debug — surfaces **internal render/cache detail**; keep to developers, prefer not enabling on
production. No access role.

Render referenced entities as an accessible unordered list.

---

Rendered Entity List formatter provides a custom field formatter that extends the rendered-entity formatter and displays the referenced entities in an unordered list `<ul>` for accessibility purposes — so a multi-value entity-reference field renders as a proper semantic list rather than a flat sequence, improving screen-reader navigation. Supports Drupal 10.3+ and 11.

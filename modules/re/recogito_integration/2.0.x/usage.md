API storage for Recogito text/image annotations.

---

Recogito Integration creates API storage for Recogito annotations — integrating the Recogito/Annotorious annotation tooling so users can annotate text and images on the site and the annotations are stored and served via an API, useful for scholarly/archival content. Depends on core `node`, `field`, `paragraphs`, and `user`; supports Drupal 8.8 through 11.

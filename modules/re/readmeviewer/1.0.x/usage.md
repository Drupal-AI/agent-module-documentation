README Viewer displays README files from installed modules in an admin interface.

---

README Viewer **displays module README files** — providing an admin interface to browse and read the README
files of installed modules, so documentation is accessible in-site. It works across core 9–11.

Use it to read module docs in admin. It is a developer/administration convenience; it renders README content
(module-provided docs) and has no content or access role. Note: gate it to admins (module docs are developer-facing).

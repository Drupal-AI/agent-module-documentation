Base classes/framework for building custom RESTful API endpoints.

---

REST Easy provides base classes for building custom RESTful API endpoints — with endpoint documentation, parameters and routes organized as single files, so developers can define a REST endpoint (its route, params and docs) in one place. Endpoints use a `_custom_access` callback and an access event, so each implementer is responsible for its own authorization.

It's a developer framework; the security of any endpoint depends on the access logic the implementer supplies. Depends on Drupal core only; supports Drupal 10.2+ and 11.

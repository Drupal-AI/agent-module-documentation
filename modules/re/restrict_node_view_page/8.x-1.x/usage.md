Restrict node view page access controls who may open the full node page (`/node/{nid}`) on a per-content-type basis, using dynamically generated permissions.

---

The module implements `hook_node_access()` for the `view` operation: if the current user has `view all content type full node pages` or the per-type permission `view full node pages of <type>`, it returns a neutral result (defers to normal access); otherwise it returns `AccessResultForbidden`, blocking the canonical node page. Per-bundle permissions are generated by `NodePermissions::nodeTypePermissions()`. The check is fail-closed for the view operation and adds the node as a cacheable dependency. Note that it does not add a `user.permissions` cache context on the access result, and because `hook_node_access` view forbids the whole view grant, restricted nodes can still surface where only fields/teasers are rendered by code paths that bypass node access — administer nodes / 'bypass node access' still override it as usual. Use it to hide full pages while leaving teasers or view listings visible depending on how those are built.

---

- Hide the full `/node/{nid}` page for a specific content type from most users.
- Grant selected roles access to full pages of one bundle only.
- Keep landing/teaser displays public while locking the canonical page.
- Generate a per-content-type 'view full node pages of X' permission automatically.
- Provide a blanket 'view all content type full node pages' permission for staff.
- Fail closed: without the permission the node page returns 403.
- Layer on top of core node access without custom code.
- Restrict brochure/detail pages to authenticated users.
- Combine with Views to expose summaries but not detail pages.
- Prevent direct URL access to sensitive content-type pages.
- Assign the permission to editors so they can preview full pages.
- Use per-bundle control for mixed public/private content models.
- Keep administrators unaffected via bypass node access.
- Add node cacheability to the access decision.
- Model 'members only' full pages by role and content type.

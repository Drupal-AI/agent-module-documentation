# Required by Form mode — agent index

Makes **fields required based on the active form mode** (optional in one form display, required in another).
Provides permissions. Version **3.0.0**. Core `^9||^10||^11`.

Content-editing/validation — per-form-mode required rule (form validation, **not** a data constraint on all
writes — other modes/API aren't forced). No access role.

Renderable Options makes exposed-filter option labels renderable (rich markup).

---

Renderable Options **makes option labels renderable** — allowing exposed-filter option labels (via Better
Exposed Filters) to contain rendered markup (icons/HTML) instead of plain text, for richer filter UIs. It depends
on the Better Exposed Filters module.

Use it for rich exposed-filter labels. It is a content-display/UI feature; option labels are admin-configured and
rendered, and it has no access-control role. Note: rendered labels are admin-supplied markup — output them safely.
Configure the renderable options.

# Responsive views pager — agent index

Shows a **different number of View items per device** (mobile/tablet/desktop) via device detection.
Depends on `mobile_detect`. Version **2.0.1**. Core `^9.2||^10||^11`.

Content-display/Views — affects item counts per device, not results' access (View access applies).
Detection is user-agent heuristic (presentation only).

Responsive views pager provides the ability to display a different number of view items for different devices.

---

Responsive views pager lets a View show a different number of items depending on the device — e.g.
fewer items on mobile, more on desktop — using device detection so pagination/item counts adapt to screen
size. It depends on the Mobile Detect module.

Use it on listing Views where the ideal item count differs by device. It is a content-display/Views feature
affecting how many items show per device; it does not change the results' access (the View's own access
applies). Note device detection is based on user-agent (server-side), which is a heuristic — it affects
presentation only, so imperfect detection is a display nuance, not a security concern. Configure per-device
counts on the View's pager.

Integration between Drupal and the Remix web framework.

---

Remix provides a Remix ↔ Drupal integration — wiring Drupal up as the backend/data source for a Remix (React-based full-stack) front end, so a decoupled/progressively-decoupled site can consume Drupal content in a Remix application. Supports Drupal 9, 10, and 11.

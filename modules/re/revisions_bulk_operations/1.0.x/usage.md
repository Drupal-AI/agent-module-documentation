Revisions Bulk Operations lets editors bulk-select and delete node revisions.

---

Revisions Bulk Operations allows multiple selection and deletion of revisions for nodes — so editors/administrators can clean up accumulated old revisions in bulk (freeing storage, reducing clutter) instead of deleting them one at a time.

Bulk selection is gated by `bulk select revisions`; deleting revisions is destructive, so grant it only to trusted roles and back up first. Depends on core `node`; supports Drupal 10.3+ and 11.

# Reserved Paths — agent index

Prevents users from creating **URL aliases/paths matching a configured reserved list** (validation +
pathauto-alias alter — stop aliases shadowing key routes / name-squatting). Provides permissions. Version
**1.0.2**. Core `^10||^11`.

Small hardening/anti-abuse — coverage is exactly what you list. No broad access role beyond permission.

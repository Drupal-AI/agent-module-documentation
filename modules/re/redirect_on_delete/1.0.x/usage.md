Create a redirect when deleting content.

---

Redirect on Delete allows users to create redirects when deleting content — prompting for a redirect target as content is deleted so the old URL doesn't 404 afterwards, preserving inbound links and SEO by sending visitors to a replacement page. Depends on `redirect`; supports Drupal 10.2+ and 11.

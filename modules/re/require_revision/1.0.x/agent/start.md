# Require Revision — agent index

Lets admins **configure which entity types must create a new revision on save** (enforce revisioning for audit/
rollback). Depends on core `block_content`, `node`, `taxonomy`. Provides permissions. Version **1.0.5**. Core
`^10.2||^11`.

Content-authoring/governance — changes save behaviour; no access role beyond permission.

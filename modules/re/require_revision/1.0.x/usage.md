Require Revision allows admins to configure which entities require revisions.

---

Require Revision lets **administrators configure which entity types/bundles must create a new revision on
every save** — enforcing revisioning (for audit trails/rollback) on nodes, block content and taxonomy terms even
if an editor doesn't check the "create new revision" box. It depends on core Block Content, Node and Taxonomy,
provides its own permissions, in the Content Authoring package.

Use it to enforce revision history. It is a content-authoring/governance feature; it changes save behaviour and
has no access-control role beyond its permission. Configure which entities require revisions.

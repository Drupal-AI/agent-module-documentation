Redirect Entity Manager provides management tools for entity redirects, extending the Redirect module.

---

Redirect Entity Manager provides additional management tools for redirects — extending the Redirect
module with easier ways to view, create and manage the URL redirects associated with entities (so, for
example, redirects tied to nodes/entities are simpler to administer in bulk). It depends on the Redirect
module and is configured at `redirect_entity_manager.settings`.

Use it on sites with many redirects (especially entity-related ones) to manage them more efficiently. It
is an administration/site-structure tool operating on redirects; it manages URL redirects and — since
redirects influence where URLs send visitors — the usual caution applies (a bad redirect can send users
to unexpected destinations), but the redirects are admin-defined. It has no content-access role beyond
managing redirect configuration.

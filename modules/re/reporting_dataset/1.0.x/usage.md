Flatten entity data into analytics-friendly SQL views/tables.

---

Reporting Dataset Builder flattens Drupal entity data into analytics-friendly reporting datasets as SQL VIEWs or materialized tables — so complex entity/field structures become flat, queryable datasets that BI/reporting tools can consume directly, without navigating Drupal's normalized schema. Depends on core `node` and `field`; supports Drupal 10 and 11.

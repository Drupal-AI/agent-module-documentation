Responsive breakpoint mappings and a formatter for Video styles.

---

Responsive video style provides responsive breakpoint mappings and a file formatter for Video styles — the video analogue of responsive image styles, so uploaded videos are delivered at breakpoint-appropriate renditions and rendered via a responsive formatter. Depends on core `breakpoint`, `file`, and `video_style`; supports Drupal 11.3+ and 12.

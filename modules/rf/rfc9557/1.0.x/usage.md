A data type and validator for the RFC 9557 extended date-time format.

---

RFC9557 provides a Data Type and Validator for the RFC 9557 extended date-time format — the IXDTF extension of RFC 3339 that adds time-zone identifiers and tags (e.g. `2024-01-01T00:00:00+01:00[Europe/Paris]`), so field/config values can be typed and validated against that format. It's a developer/data-modelling primitive. Supports Drupal 11.

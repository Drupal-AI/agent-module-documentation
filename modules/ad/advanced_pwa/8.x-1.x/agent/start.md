# Advanced PWA — agent orientation

**Machine name:** `advanced_pwa`  
**Version dir:** `8.x-1.x`  
**Core:** `^8 || ^9 || ^10`  
**Dependencies:** none  
**Configure route:** `advanced_pwa.settings`

## What it does
Turns the site into a Progressive Web App and sends web push notifications to subscribers.

## Where to look
- `advanced_pwa.info.yml` — metadata and dependencies.
- `advanced_pwa.routing.yml` / `.permissions.yml` / `.services.yml` — routes, permissions, services (where present).
- `src/` — controllers, forms, plugins and services.

See `../usage.md` for install, configuration and usage details.

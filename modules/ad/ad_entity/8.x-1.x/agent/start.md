# Advertising Entity (ad_entity) — agent index

Framework for managing and displaying third-party ads. Defines two **config entities**
(`ad_entity`, `ad_display`), three **plugin types** (AdType / AdView / AdContext), and renders
provider ad tags into the page. Package `Advertising`. Depends on contrib **`entity`** (`~1.0`).
Core `^9 || ^10 || ^11`. License GPL-2.0-or-later. Version 8.x-1.6 (dir `8.x-1.x`).
Ships **no provider** — enable a submodule (`ad_entity_dfp`, `ad_entity_adtech_v2`,
`ad_entity_adtech`, `ad_entity_generic`, `ad_entity_fallback`).

- **Global settings, config objects, schema, personalization/consent** → [config/settings.md](config/settings.md)
- **The `ad_entity` + `ad_display` config entities, view builders, blocks, canonical/iFrame route** → [entities/entities.md](entities/entities.md)
- **The AdType / AdView / AdContext plugin types + managers (how providers plug in)** → [plugins/plugin-types.md](plugins/plugin-types.md)
- **The Advertising context field (type/widget/formatters) and targeting collection** → [fields/context.md](fields/context.md)

## What it actually is (from source)

- Two `ConfigEntityType`s in `src/Entity/`: **`ad_entity`** (`AdEntity`, config prefix
  `ad_entity`; keys `type_plugin_id`, `view_plugin_id`, `disable_initialization`) and
  **`ad_display`** (`AdDisplay`, config prefix `display`; keys `theme_canonical`, `variants`,
  `fallback`). Both use `Drupal\entity\EntityAccessControlHandler` + `EntityPermissionProvider`
  and `admin_permission = "administer ad_entity"`.
- Three plugin managers (`ad_entity.services.yml`): `ad_entity.type_manager` (`AdTypeManager`,
  `Plugin/ad_entity/AdType`), `ad_entity.view_manager` (`AdViewManager`, `Plugin/ad_entity/AdView`),
  `ad_entity.context_manager` (`AdContextManager`, `Plugin/ad_entity/AdContext`). `AdEntityServices`
  (service `ad_entity`) is the shared accessor; `AdEntityUsage` (service `ad_entity.usage`) reports
  which AdView/AdType plugins are actually used.
- Rendering: `AdEntityViewBuilder::view()` builds `#theme => 'ad_entity'`; the assigned AdView
  plugin's `build()` supplies the inner content and the target container (`html` / `iframe` / `fia`).
  `AdDisplayViewBuilder` loads the Ad entity per active-theme variant and gates each on
  `$ad_entity->access('view')`. Ad container attrs and the JSON targeting blob are assembled in
  `ad_entity.theme.inc` (`template_preprocess_ad_entity`).
- **Only in-repo AdContext plugins:** `targeting` (`TargetingContext`) and `turnoff`
  (`TurnoffContext`), in `src/Plugin/ad_entity/AdContext/`. AdType/AdView plugins live in submodules.
- Context/targeting text is filtered before output: `TargetingCollection::filter()` runs
  `Xss::filter(strip_tags())` (or a configured filter format), and JSON is encoded with
  `JSON_HEX_TAG|JSON_HEX_APOS|JSON_HEX_QUOT`.

## Routes / permissions

- `ad_entity.settings` — `GET /admin/structure/ad_entity/global-settings`, form
  `GlobalSettingsForm`, permission **`administer ad_entity`** (`ad_entity.routing.yml`).
- Entity CRUD/collection routes are generated by `AdEntityHtmlRouteProvider` /
  `AdDisplayHtmlRouteProvider` (AdminHtmlRouteProvider), all under `administer ad_entity`.
- `ad_display` **canonical** `/ad-display/{ad_display}` → `AdDisplayController::view()`, guarded by
  `_entity_access: ad_display.view` (used as the iFrame `src`).
- Permissions are generated by the entity `permission_provider`: `administer ad_entity`,
  plus `view/update/delete` per entity type ("View Advertising entities", "View Display configs…").
  No `*.permissions.yml` file.

## Services / hooks

- Services: `ad_entity`, `ad_entity.type_manager`, `ad_entity.view_manager`,
  `ad_entity.context_manager`, `ad_entity.usage`.
- Key hooks in `ad_entity.module`: `hook_theme`, `hook_library_info_build`/`_alter`,
  `hook_page_attachments` (injects the `#ad-entity-settings` JSON tag into `<head>`),
  `hook_entity_prepare_view`/`hook_entity_view` (context reset), `hook_ad_context_data_reset`,
  `hook_ad_context_include`. Extension hooks documented in `ad_entity.api.php`
  (`hook_ad_entity_module_info`, `hook_ad_entity_js_settings_alter`, `hook_ad_context_*`).
- Libraries (`ad_entity.libraries.yml`): `base`, `helpers`, `view`, `context`,
  `targeting_context`, `turnoff_context`, `provider.googletag` (loads external GPT
  `//securepubads.g.doubleclick.net/tag/js/gpt.js`).

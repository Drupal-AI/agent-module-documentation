Add to Homescreen prompts mobile users to add the site to their device homescreen using the cubiq add-to-homescreen JS library.

---

Install the module and configure it at /admin/config/user-interface/addtohomescreen (permission: administer add to homescreen). Settings control the prompt text, timing and appearance; the library is attached to front-end pages.

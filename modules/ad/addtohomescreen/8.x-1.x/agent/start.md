# Add to Homescreen — agent orientation

**Machine name:** `addtohomescreen`  
**Version dir:** `8.x-1.x`  
**Core:** `^8 || ^9 || ^10`  
**Dependencies:** none  
**Configure route:** `addtohomescreen.settings`

## What it does
Invites users to add the site to their device homescreen using the add-to-homescreen library.

## Where to look
- `addtohomescreen.info.yml` — metadata and dependencies.
- `addtohomescreen.routing.yml` / `.permissions.yml` / `.services.yml` — routes, permissions, services (where present).
- `src/` — controllers, forms, plugins and services.

See `../usage.md` for install, configuration and usage details.

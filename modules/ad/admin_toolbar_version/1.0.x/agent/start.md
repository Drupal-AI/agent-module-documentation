# Admin toolbar version — agent orientation

**Machine name:** `admin_toolbar_version`  
**Version dir:** `1.0.x`  
**Core:** `^8.8 || ^9 || ^10`  
**Dependencies:** admin_toolbar:admin_toolbar_tools  
**Configure route:** `n/a`

## What it does
Adds Drupal core and module version information to the Admin Toolbar tools menu.

## Where to look
- `admin_toolbar_version.info.yml` — metadata and dependencies.
- `admin_toolbar_version.routing.yml` / `.permissions.yml` / `.services.yml` — routes, permissions, services (where present).
- `src/` — controllers, forms, plugins and services.

See `../usage.md` for install, configuration and usage details.

# Spotify Now Playing — agent index

**Now-playing widgets and endpoints from Spotify**. Provides permissions. Version **1.1.2**. Core `^11`.

Integration — Spotify **OAuth credentials/tokens** as secrets (env/Key, HTTPS); calls Spotify (egress); expose only
intended now-playing data on any endpoint. No access role beyond permission.

# Speech to Text — agent index

**Integrates browser speech-to-text (dictation) with text-box fields** (Web Speech API). Provides permissions.
Version **1.0.0**. Core `^10||^11`.

Accessibility/content-editing — runs **client-side**; the browser (e.g. Chrome) may send **audio to its vendor
(Google)** for recognition (disclose). No content/access role beyond permission.

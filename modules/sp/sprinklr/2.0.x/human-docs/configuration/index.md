# Configuration

Sprinklr needs two things from you: the App Id that identifies your Sprinklr
chatbot, and a decision about where on the site it should appear.

## Open the settings

1. Log in as an administrator.
2. Open the Sprinklr module's settings form.

## What you configure

- **App Id** — the identifier Sprinklr gives you for your chatbot. The module uses
  it to load the correct widget. Treat this value as configuration you provide;
  handle any associated API key appropriately.
- **Where the chatbot appears** — restrict the widget to specific **pages** and
  **content types** rather than showing it site‑wide, so it only surfaces where you
  want it.

## Save

Save the form and visit one of the pages you enabled — the Sprinklr chat widget
should load there.

## Things to keep in mind

- The widget loads **Sprinklr's third‑party JavaScript**, which runs in your
  site's origin. You are trusting the vendor's script, so keep that in mind as you
  would for any embedded third‑party code.
- Chat and visitor data is handled by **Sprinklr**, not your site. Account for this
  in your privacy policy and any consent requirements you are subject to.

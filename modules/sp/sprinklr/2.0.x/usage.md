Sprinklr provides integration for the Sprinklr chatbot.

---

Sprinklr integrates the **Sprinklr chatbot** — placing Sprinklr's customer-experience/chat widget on the
site so visitors can interact with the Sprinklr-powered bot/agent. It is in the Web services package.

Use it to add the Sprinklr chatbot. It is a third-party integration/user-engagement feature — it loads
**Sprinklr's third-party JavaScript** (trust the vendor; runs in your origin) and chat/visitor data is handled
by **Sprinklr** (a privacy/consent consideration), and any Sprinklr **API key/app ID** should be handled as
config/secret. It has no access-control role. Configure the Sprinklr widget.

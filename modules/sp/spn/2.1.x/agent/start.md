# Simple Petitions (spn) — agent index

Lets users **create and manage petitions** (sign, list/manage via Views). Depends on core `link`, `views`,
`node`, `field`, etc. Version **2.1.1**. Core `^9||^10||^11`.

Content/user-engagement — **signatures are personal data** (store/expose per policy; apply spam/bot protection
to signing forms); access follows normal content/entity access.

Splitting integrates the Splitting.js library, splitting text into words and characters and adding CSS variables for granular animation.

---

Splitting integrates the Splitting.js JavaScript library — which splits text (and other content) into
individual words and characters, wrapping each and adding CSS custom properties (indices, positions) — so
designers can animate text at the word/character level (staggered reveals, per-letter effects). It ships a
`splitting_ui` submodule. It is in the User interface package.

Use it for advanced text/typography animations. It is a front-end/theming feature affecting markup and
adding CSS variables for animation; it does not change content or access. Apply it to the elements you
want to animate and drive the effects with CSS.

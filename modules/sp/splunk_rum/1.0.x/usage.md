Add the Splunk RUM (Real User Monitoring) script to pages.

---

Splunk Real User Monitoring adds the Splunk RUM script to every page — instrumenting the front end with Splunk's browser Real User Monitoring so page-load performance, errors and user experience are collected and reported to Splunk Observability.

The Splunk RUM token/realm are admin-configured. Supports Drupal 10 and 11.

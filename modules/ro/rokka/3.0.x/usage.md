Rokka integrates Rokka.io, a digital-image-processing service and CDN, with Drupal's file system.

---

Rokka integrates Rokka.io — a digital image processing service and CDN — with Drupal's file system, so
images are stored in and served from Rokka, with derivatives (resize, crop, optimize) generated by Rokka.
This offloads image storage, processing and delivery. It is configured at `rokka.admin_settings`, provides
its own permissions and Drush commands.

Use it to offload image handling to Rokka. The security-relevant point is credentials: it authenticates to
Rokka with API credentials (an organization/API key) — store them as secrets. Images are served from Rokka's
CDN, so consider the data-flow (don't route access-restricted images through a public CDN). It uses TLS for
Rokka requests (not disabled). It is a media/performance feature with no access-control role. Configure the
Rokka connection.

Roles Nested provides a draggable UI to arrange roles into a parent/child hierarchy (organizational only).

---

Roles Nested **lets admins arrange roles into a parent/child hierarchy** — a draggable UI to organize the site's
roles into a nested tree, stored for display/organization. It works across core 8–11.

Use it to organize a long role list visually. Understand its scope: it is **organizational only** — it stores a
nesting/arrangement of roles but does **not** make a child role inherit its parent's permissions (there is no
permission-inheritance logic in the module). So nesting is a UI/organization aid, not an access-control mechanism:
permissions remain assigned per-role via core, and you should not assume a nested child gains the parent's
permissions. It has no access-control role. Configure the role nesting.

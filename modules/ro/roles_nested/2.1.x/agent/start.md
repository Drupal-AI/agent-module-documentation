# Roles Nested — agent index

**Draggable UI to arrange roles into a parent/child hierarchy**. Version **2.1.1**. Core `^8||^9||^10||^11`.

**Organizational only** — stores a role nesting for display but does **not** make child roles inherit parent
permissions (no inheritance logic; permissions stay per-role via core). Not an access-control mechanism.

A PHP enum of user roles for bundle classes and testing.

---

Role Enum provides a role enum, suitable for bundle classes and testing — a typed PHP enumeration of the site's user roles so developer code (bundle classes, tests, custom logic) can reference roles as enum cases instead of magic-string role IDs, improving type-safety. It's a developer utility. Depends on core `user`; supports Drupal 11.1+.

ROI Solutions provides an API client for the ROI Solutions nonprofit CRM.

---

ROI Solutions provides an API client service for ROI Solutions — a nonprofit constituent-relationship (CRM/fundraising) platform (Revolution CRM) — so Drupal can integrate with ROI Solutions to sync constituents, donations, or other data via its API.

ROI Solutions API credentials are stored via the Key module (env-backed); administration is gated by `administer roisolutions`. Depends on `key`; supports Drupal 9, 10, and 11.

Route Path Alias adds language-aware, pattern-based URL aliases to custom entity routes.

---

Route Path Alias provides language-aware URL aliasing for custom entity routes using configurable patterns — so custom entities/routes (not just nodes) get clean, per-language URL aliases generated from a pattern, extending alias support beyond what core/Pathauto cover by default.

Administration is gated by `administer route path aliases`. It's a routing/URL utility with no content role of its own. Requires Drupal 11.

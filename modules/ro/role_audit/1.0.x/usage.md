Role Audit provides a report under Reports that compares the permissions between two user roles.

---

Role Audit adds an administrative report (under Reports) that compares the permissions of two user
roles side by side — showing what each role can do and where they differ. It is an auditing aid for
understanding and reviewing the permission model: verifying least privilege, spotting unexpected grants,
and documenting role differences. It provides its own permissions.

Use it during security reviews and role design to see exactly how two roles' permission sets diverge
without hand-comparing the permissions page. It is a read-only reporting tool — it does not change
permissions, only displays a comparison — so it is a positive governance/security aid. Restrict access
to the report itself, since it reveals the permission model.

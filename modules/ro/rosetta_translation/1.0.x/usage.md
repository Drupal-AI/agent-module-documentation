Rosetta Translation integrates the au5ton/rosetta translation project with Drupal.

---

Rosetta Translation **integrates the au5ton/rosetta translation project** — connecting Drupal to the Rosetta
translation library/service to translate content/strings. It works on core 10–11.

Use it for Rosetta-based translation. It is a multilingual/integration feature. Security/data handling: depending
on configuration, translation may **send content to an external translation service** (egress — confirm acceptable)
and any provider credentials should be stored as secrets. It has no access-control role. Configure the Rosetta
translation integration.

Quick Links Kit provides a configurable block of quick links for the home page.

---

Quick Links Kit **provides a quick-links block** — an initial configuration kit that adds a block of curated
quick links (with icons/images, draggable ordering) for the home page. It depends on Media Library, Link, SVG Image
Field, Add Content by Bundle, Display Link Plus, Draggable Views and Storage.

Use it to add a home-page quick-links block. It is a site-building/content-display feature; links are
admin/editor-managed and it has no access-control role. Configure the quick links.

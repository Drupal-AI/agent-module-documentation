# Queue Throttle — agent index

Provides **throttled (rate-limited) queue processing** (pace consumption so heavy queue work / rate-limited
APIs aren't overwhelmed). Provides permissions. Version **2.0.0**. Core `^10||^11`.

Operations/automation — queue items run with the site's privileges; no access role beyond permission.

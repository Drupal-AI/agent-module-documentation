Quickchat provides a Quickchat API client service.

---

Quickchat provides a **Quickchat API client service** — integrating the Quickchat AI chat platform into
Drupal, with `quickchat_chatbot` (embed a chatbot) and `quickchat_sync` (sync content) submodules.

Use it to integrate Quickchat's chatbot/AI. It is an AI/integration feature. Security/data handling: it talks to
the **external Quickchat API** — store the **API key/credentials** as a **secret** (env/Key) over HTTPS, and be
aware content synced or sent to the chatbot leaves the site (external egress — confirm acceptable). It has no
access-control role. Configure the Quickchat credentials.

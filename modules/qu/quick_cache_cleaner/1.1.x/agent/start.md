# Quick Cache Cleaner — agent index

Adds an **admin menu item to quickly clear all Drupal core + Views caches** (fast flush vs the performance
page/Drush). Provides permissions. Version **1.1.1**. Core `^8||^9||^10||^11||^12`.

Admin/performance utility — cache clear is privileged (perf cost); gated by its permission, grant only to
trusted admins. No content-access role beyond permission.

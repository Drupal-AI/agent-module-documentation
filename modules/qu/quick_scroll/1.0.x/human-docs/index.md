# Quick Scroll — manual setup guide

**Quick Scroll** (`quick_scroll`) is a simple front‑end convenience: it adds a
**scroll‑to‑top button** to every page. Visitors who have scrolled down a long page
can click it to jump straight back to the top with a single mouse click.

It works by attaching a small JavaScript/CSS library on every page, so there is
nothing to place and nothing to configure — the button is site‑wide the moment the
module is enabled. The module has no routes, permissions, or settings; it is purely
a front‑end asset.

This guide is written for a **human** clicking through the admin UI. If you want
terse, token‑cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Contents

1. [Installation](installation/index.md) — install with Composer and enable the
   module.

There is **no settings form** for this module — the scroll‑to‑top button appears
automatically once the module is enabled.

## How to use it

Enable the module and you're done. Visit any page, scroll down, and the
scroll‑to‑top button appears; click it to return to the top. There are no options to
set.

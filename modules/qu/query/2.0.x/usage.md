Query provides OO interfaces for building query-related structures.

---

Query provides object-oriented, query-related interfaces — a foundational developer library that offers structured, fluent building blocks used by other modules (such as Kits and the Form Factory family) to construct query/array structures in an object-oriented way.

It's a developer library with no content or access role of its own. Supports Drupal 9, 10, and 11.

# Announcements (announcements) — agent index

Provides a fieldable **content entity** `announcements_announcement` (revisionable, translatable,
publishable) shown to visitors as banners/alerts, plus config entities for **Types** (bundles), **Styles**
and **Regions**. Rendered by a per-region **block**; per-announcement **visibility conditions** come from the
`condition_field` plugin field; dismissible types set a per-announcement cookie via `js_cookie`.
Version **2.0.0-rc2**, `core_version_requirement: ^10.1 || ^11 || ^12`, license GPL-2.0-or-later.

## Dependencies
- `js_cookie:js_cookie` — client-side dismissal cookie (`announcements/dismiss` library).
- `condition_field:condition_field` — the `visibility` base field (condition plugin storage/widget).
- No external HTTP calls.

## What it provides
- Content entity `announcements_announcement` (`src/Entity/Announcement.php`): base_table `announcements`;
  base fields `title`, `body` (text_with_summary), `style` (ref → announcements_style, required), `region`
  (ref → announcements_region, cardinality -1), `status`, `user_id`, `visibility` (condition_field). Handlers:
  storage `AnnouncementStorage`, access `AnnouncementAccessControlHandler`, route provider
  `AnnouncementHtmlRouteProvider`, translation `AnnouncementTranslationHandler`, views data
  `AnnouncementViewsData`, list builder `AnnouncementListBuilder`.
- Config entity bundle `announcements_type` (`src/Entity/AnnouncementType.php`): `dismissible` bool +
  `enabled_conditions` list; admin_permission `administer site configuration`.
- Config entities `announcements_style` (`src/Entity/Style.php`, `extra_classes`) and `announcements_region`
  (`src/Entity/Region.php`).
- Block plugin `announcements_region_block` (`src/Plugin/Block/AnnouncementsRegionBlock.php`) derived per
  region by `src/Plugin/Derivative/AnnouncementRegions.php`.
- Dynamic per-bundle permissions (`src/AnnouncementPermissions.php`) + static perms
  (`announcements.permissions.yml`).
- Theme hook `announcements_announcement` + template + preprocess (`announcements.page.inc`,
  `templates/announcements_announcement.html.twig`); JS `js/dismiss.js`.

## Routes
- `announcements.structure` → `/admin/structure/announcements` (perm `access administration pages`),
  hosts Types / Styles / Regions collections (menu links).
- Entity CRUD + revision routes generated by `AnnouncementHtmlRouteProvider` (canonical `/announcements/{id}`,
  add/edit/delete, `version-history`, `revision`, `revision_revert`, `revision_delete`, `translation_revert`).
- `RouteSubscriber` (`src/Routing/RouteSubscriber.php`) sets the announcement collection route to require
  `access announcements_announcement overview`.

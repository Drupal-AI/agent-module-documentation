# announcement_modal

Sitewide announcement shown in a modal.

- Admin form `AnnouncementSettings` at `/admin/config/announcement_modal` (`administer site configuration`, `no_cache`).
- Block plugin `src/Plugin/Block/Announcement.php`; library `announcement_modal/announcement_modal.announcements` (css/, js/).
- Permission: `administer announcement modal configuration`.

See [../usage.md](../usage.md).

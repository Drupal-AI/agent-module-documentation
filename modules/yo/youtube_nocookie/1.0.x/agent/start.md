# YouTube No-Cookie — agent index

Provides a **privacy-friendly youtube-nocookie handler for Video Embed Field** (embeds via
`youtube-nocookie.com`, defers tracking cookies until play). Depends on `video_embed_field`. Version **1.0.1**.
Core `^9.2||^10||^11`.

Media/privacy — video still loads from **YouTube** (fewer cookies until play, not zero contact); no content/
access role.

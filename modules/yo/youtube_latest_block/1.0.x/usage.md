Youtube Latest Block displays the latest video from a YouTube channel in a block.

---

Youtube Latest Block **shows a channel's latest YouTube video** — a block that requests and displays the most
recent video from a configured YouTube channel. It works on core 10–11.

Use it to feature a channel's newest video. It is a media/integration feature. Security/data handling: it **calls
the YouTube (Google) Data API** (egress) and typically needs a **YouTube API key** (store as a secret — env/Key —
over HTTPS); embedding videos loads third-party YouTube content (privacy/consent). It has no access-control role.
Configure the channel and API key.

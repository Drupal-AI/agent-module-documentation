# Youtube API — agent index

Developer **toolkit** for the **YouTube Data API v3**: per-resource classes build requests to a **fixed** googleapis host, executed via Guzzle (default TLS) with a configured API key. Admin settings `youtubeapi.settings` + test page (`access administration pages`). Version **2.0.0**, core `^8.8||^9||^10`. Fixed host — no SSRF surface.

Common developer tools/utilities shared by the Qtools suite.

---

Qtools Common provides common dev tools — a shared utility/dependency module for the Qtools suite (e.g. Qtools Profiler), bundling helper services and a `TerminatedRedirectResponse` and other primitives that the suite's modules build on. It's a developer dependency with no standalone site features. Supports Drupal 10 and 11.

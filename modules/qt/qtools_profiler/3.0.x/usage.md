A performance profiler for Drupal requests.

---

Qtools Profiler v2 is a Qtools performance profiler — instrumenting Drupal requests to measure timing/queries and help developers find performance bottlenecks, with a preview summary and (for authorised operators) an impersonation/auto-login helper for profiling a given user's experience.

The auto-login route reuses Drupal core's one-time-login hash validation (unforgeable without the user's credentials + site secret), so it is not an authentication bypass. Depends on `qtools_common`; supports Drupal 10 and 11.

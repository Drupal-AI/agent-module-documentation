# IXM Blocks: Boilerplate (ixm_blocks_boilerplate) — agent index

Nested submodule of **ixm_blocks**. A complete, empty **block type to copy**.
Version **1.1.3**. Core `^10 || ^11`.

**Read this first when evaluating the family** — it documents, by being one, what a properly
packaged block type looks like (bundle, fields, form display, view display, template, wiring).
Useful to any team building a component library, IXM or not.

**Do not enable in production** — it contributes an empty component to the editor's block list.

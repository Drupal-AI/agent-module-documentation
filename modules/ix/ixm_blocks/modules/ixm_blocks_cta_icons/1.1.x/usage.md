IXM Blocks CTA Icons presents a set of icon-and-label calls to action.

---

A row of icons with short labels, each linking somewhere: the pattern used for quick links, service categories or a set of next steps. It works because an icon plus two words is scannable in a way a list of sentences is not.

**Icons carry the meaning here, which makes the accessibility requirement stronger than usual.** Where an icon sits beside text that says the same thing, the icon is decorative and should be hidden from assistive technology. Where the icon *is* the distinction between one link and the next — and in a row of otherwise identical CTAs it often is — the link needs an accessible name that conveys it. A row of links all announced as "Learn more" is a common and avoidable failure.

Also worth deciding: whether the whole tile is the link or only the label. The whole tile is a bigger target and better on touch, but only if the link's accessible name is the label rather than everything inside the tile.

# IXM Blocks: Statistics (ixm_blocks_statistics) — agent index

Nested submodule of **ixm_blocks**. Row of headline figures with labels.
Version **1.1.3**. Core `^10 || ^11`.

**Two editorial points:**

1. **A figure without a source is an assertion.** On charity, public-sector or research sites,
   headline statistics are what a sceptical reader checks. If the component has no source or date
   field, the page around it needs one.
2. **Animated counters are motion** — respect `prefers-reduced-motion`, and make sure the **final
   value is present** for anyone who never triggers the animation (screen reader, no JS). An empty
   element or a zero is a failure.

IXM Blocks Carousel rotates through a set of items in one region of the page.

---

Carousels are requested constantly and perform poorly at what they are usually asked to do. Usability research has consistently found that content past the first slide is rarely seen, so a carousel is a reasonable way to present optional extras and a poor way to present anything that matters. That is worth saying out loud when someone proposes putting the primary call to action on slide three.

Where it does fit: a set of equally optional items — partner logos, testimonials, gallery images — where no individual one needs to be seen.

**Accessibility takes deliberate work.** The controls need keyboard operation and visible focus; every slide's content must be reachable; and if it auto-advances there must be a pause control, because moving content is a barrier for people with cognitive and vestibular conditions. Verify all of that against the shipped implementation.

---

- Rotate through partner logos.
- Show testimonials in sequence.
- Present a set of gallery images.
- Give equally optional items one region.
- Avoid putting the primary CTA in rotation.
- Advise against a carousel where it will not work.
- Check keyboard operation of controls.
- Ensure visible focus on controls.
- Make every slide's content reachable.
- Provide a pause control for auto-advance.
- Respect reduced-motion preferences.
- Style the carousel with the theme.
- Order slides deliberately.
- Audit carousels for accessibility.
- Measure whether later slides are seen.

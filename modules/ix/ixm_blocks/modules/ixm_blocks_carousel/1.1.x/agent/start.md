# IXM Blocks: Carousel (ixm_blocks_carousel) — agent index

Nested submodule of **ixm_blocks**. Rotating item set.
Version **1.1.3**. Core `^10 || ^11`.

**Say it plainly when a carousel is proposed:** usability research consistently finds content past
the first slide is rarely seen. Fine for **equally optional** items (partner logos, testimonials);
wrong for the primary CTA.

**Verify:** keyboard-operable controls with visible focus, every slide's content reachable, and a
**pause control** if it auto-advances — moving content is a barrier for cognitive and vestibular
conditions.

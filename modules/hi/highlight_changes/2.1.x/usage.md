Highlight Changes visually marks fields that have changed on an entity form.

---

Highlight Changes visually highlights active changes on entity forms — marking which fields a user has modified before saving, so editors can see at a glance what they've changed. It's an editorial-UX aid for reviewing edits.

It's a front-end form enhancement with no content or access role of its own. Supports Drupal 10, 11, and 12.

Hijri Format provides the ability to show dates in Hijri format, with an adjustment option to match Umm al-Qura.

---

Hijri Format lets you display dates in the Hijri (Islamic lunar) calendar — converting/rendering dates
in Hijri format, with an adjustment option to align with the Umm al-Qura calendar, for sites serving
audiences that use the Hijri calendar. It is configured at `hijri_format.hijri_settings` and provides its own
permissions, in the Fields package.

Use it to show Hijri dates. It is a content-display/date feature affecting date presentation; the underlying
date value is unchanged and it has no access-control role. Configure the Hijri display and adjustment.

# Hide Node Title — agent index

Hides a node's title on display when a per-node **`hide_title` checkbox** is checked (suppress titles on
chosen nodes — landing pages). Version **2.0.0**. Core `>=8`.

Content-display — a **display toggle, NOT access control** (the title still exists / is API-accessible). No
access role.

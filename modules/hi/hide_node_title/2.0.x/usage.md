Hide Node Title allows hiding a node title when a hide_title field is checked.

---

Hide Node Title lets editors hide a node's title on display — via a per-node `hide_title` checkbox
field, so specific nodes can suppress their title (e.g. a landing page where the title is baked into the
hero). It is in the Custom package.

Use it to hide titles on chosen nodes. It is a content-display feature affecting title presentation; the
title is still the node's data (this is a **display** toggle, not access control — the title still exists and
is accessible via the API/other displays), and it has no access-control role. Add the hide_title field and
configure the display.

Connects Drupal to the Hivo digital-asset platform.

---

Hivo Connector integrates Drupal with Hivo — connecting to the Hivo digital-asset-management platform so editors can browse and use Hivo-managed assets (images, etc.) within Drupal media and the CKEditor 5 editor.

The Hivo API credentials are admin-configured and should be stored securely (env-backed), never committed. Depends on core `file`, `media`, and `ckeditor5`; supports Drupal 11.

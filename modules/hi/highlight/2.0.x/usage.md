Highlight highlights the key words from a search within the search results, emphasizing matched terms.

---

Highlight emphasizes search keywords within search results — wrapping/highlighting the matched search
terms in the result text so users can quickly see why a result matched and where their terms appear. It is
configured at `highlight.settings`.

Use it to improve search-result readability by highlighting matched terms. It is a site-search/content-
display feature affecting how results render; it highlights output text and has no content or access role.
Configure the highlighting behaviour and apply it to search results.

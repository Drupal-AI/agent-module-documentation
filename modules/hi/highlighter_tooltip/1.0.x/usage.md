Highlighter Tooltip shows a tooltip to copy a highlighted URL to the clipboard.

---

Highlighter Tooltip **shows a copy-to-clipboard tooltip on highlighted text** — when a user selects text, a
small tooltip offers to copy a URL (e.g. a shareable link) to the clipboard, aiding sharing. It depends on core
Path Alias.

Use it to add share/copy tooltips. It is a front-end/UX feature; it runs client-side and has no content or access
role. Enable it for the highlight tooltip.

Hierarchical Select Ajax provides an AJAX hierarchical-select widget for taxonomy terms.

---

Hierarchical Select Ajax **provides an AJAX hierarchical-select widget for taxonomy terms** — letting editors
pick a term by drilling down parent→child levels via AJAX-loaded selects, easing selection in deep vocabularies. It
depends on core Field and Taxonomy.

Use it for drill-down term selection. It is a content-editing/field-widget feature; selection follows normal
taxonomy/field handling and it has no access-control role. Configure the widget on a term reference field.

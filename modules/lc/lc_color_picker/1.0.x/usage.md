LC Color Picker provides a JavaScript color picker for color fields.

---

LC Color Picker **provides a JS color picker** — a modern JavaScript color-picker widget for selecting colors
on color fields. It works on core 10–11.

Use it for color selection widgets. It is a content-editing/field-widget feature; the stored value is a color and
it has no access-control role. Note: colors applied to output should be emitted as sanitized style values.
Configure the color picker.

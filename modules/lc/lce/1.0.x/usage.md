LCE lets you link to content entities using aliases.

---

LCE (Link Content Entities) lets you **link to content entities using an alias/reference** — creating stable
links to entities that resolve to their canonical URL, so links keep working even as paths change. It provides
its own permissions, in the Other package.

Use it for stable internal entity links. It is a content/site-structure feature; links resolve to entities that
follow their own access on view, and it has no access-control role beyond its permission. Configure the entity
links.

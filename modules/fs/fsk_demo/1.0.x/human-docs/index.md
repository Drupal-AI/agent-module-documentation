# Factorial Starter Kit Demo — manual setup guide

**Factorial Starter Kit Demo** (`fsk_demo`) is a small demonstration module that
exposes an example form. It is part of the Factorial Starter Kit and exists to show
how a form is built and exposed in Drupal — reference and demonstration code rather
than a feature you would run on a live site.

Because it is example code, there is nothing to configure and no reason to keep it
enabled in production. Enable it on a development or learning site to look at how the
form is put together, then disable it when you are done.

This guide is written for a **human** clicking through the admin UI. If you want
terse, token‑cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Contents

1. [Installation](installation/index.md) — install the module with Composer and
   enable it.

This module has **no configuration page** — it simply provides an example form for
reference.

## How to use it

Once enabled, the module exposes its demo form so you can see it in action and read
the source to learn the pattern. Keep it to development environments; it is not
intended for production use.

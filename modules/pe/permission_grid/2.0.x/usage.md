Permissions Grid provides an admin page showing related permissions in a grid.

---

Permissions Grid **shows related permissions in a grid** — an administrative page that visualizes permissions
in a grid/matrix format so admins can more easily review which roles have which related permissions. It works
across core 9–11.

Use it to review permissions visually. It is an administration/visualization tool; it is a read-only view of
permission assignments (gate to trusted admins, as it reveals your access model) and has no content or access role.
View the permissions grid.

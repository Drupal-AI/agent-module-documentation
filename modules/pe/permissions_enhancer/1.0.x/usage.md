Enhance the permissions admin page with collapsible sections and a summary.

---

Permissions Enhancer enhances the permissions page with collapsible sections and an active-permissions summary — so the (often huge) `/admin/people/permissions` page becomes navigable: grouped modules collapse/expand and a summary shows which permissions each role has. It's an admin-UX enhancement (no permission-model change). Depends on core `user` and `system`; supports Drupal 10 and 11.

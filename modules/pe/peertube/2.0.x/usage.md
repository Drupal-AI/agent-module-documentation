Peertube allows contributing PeerTube videos as Remote Video media in Drupal, via oEmbed providers.

---

Peertube lets editors embed PeerTube videos as Drupal Remote Video media. PeerTube is the
federated, open-source video platform; this module registers it as an oEmbed provider so a PeerTube URL
can be added like a YouTube/Vimeo remote video and rendered through the media system. It depends on
core Media and the oEmbed Providers module, configured at `peertube.settings`.

Use it to embed self-hosted or federated PeerTube videos alongside other media, avoiding proprietary
platforms. It is a media/integration feature; embedded videos are fetched via oEmbed from the PeerTube
instance and rendered as remote media. As with any oEmbed/remote media, the content and its
availability depend on the source PeerTube instance.

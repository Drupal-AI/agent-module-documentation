# Peertube — agent index

Adds **PeerTube videos as Remote Video media** (via oEmbed) — the federated open-source video platform,
embedded like YouTube/Vimeo. Depends on core `media`, `oembed_providers`. Config at `peertube.settings`.
Version **2.0.0**. Core `^10||^11`.

Media/integration — videos fetched via oEmbed from the source PeerTube instance (availability depends
on it).

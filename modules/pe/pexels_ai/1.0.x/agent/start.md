# Pexels AI — agent index

Adds **AI-agent functionality to search/fetch Pexels stock media** into Drupal media. Depends on `ai`,
`ai_agents`, `key`, core `media`. Provides permissions. Version **1.0.0-alpha3**. Core `^10||^11`.

AI/media/integration — Pexels **API key via the Key module** (correct); **scope** agent actions (usage/cost);
mind stock licensing. No access role beyond permission.

Personified provides configurable blocks that render JSON results.

---

Personified **renders JSON results in blocks** — configurable blocks that display data from JSON (e.g. from an
API or a stored template), with cookie-aware personalization, using JS Cookie and JSON Template. It depends on the
JS Cookie and JSON Template modules.

Use it to render JSON-driven personalized blocks. It is a content-display/integration feature. Security/data
handling: if the JSON comes from an **external source**, that's egress/ingress to confirm; and rendered JSON values
should be **output safely** (escape) to avoid injecting markup. It has no access-control role. Configure the JSON
blocks.

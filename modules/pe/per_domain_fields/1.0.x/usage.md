Per Domain Fields provides field types storing values per domain.

---

Per Domain Fields **provides field types that store different values per domain** — so a single entity can
present different field values on each domain in a Domain-module multi-domain setup (e.g. a different title/image
per domain). It depends on the Domain module, in the Field types package.

Use it for domain-specific field values in a multi-domain site. It is a fields/multi-domain feature; values are
per-domain content following normal field handling, and it has no access-control role. Add the per-domain field
to an entity.

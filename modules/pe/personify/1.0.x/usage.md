Personify provides a Personify integration.

---

Personify provides an **integration with the Personify CRM/membership platform** — connecting Drupal to
Personify (used by associations/YMCAs for membership, events, transactions), part of the YMCA Website Services
ecosystem. It is in the YMCA Website Services package.

Use it to integrate membership data with Personify. It is an integration/CRM feature. Security/data handling: it
calls the **Personify API** and exchanges **member PII** (personal/membership data — external egress, handle per
privacy obligations) — store the **API credentials** as **secrets** (env/Key) over HTTPS. It has no access-
control role. Configure the Personify connection.

A no-code rule builder for personalizing content.

---

Personalization Rule is a no-code rule builder for personalizing content — define rules like 'If user visited X → show Y block' without any external tools, so a site can vary blocks/content by visitor behaviour (visited pages, roles, path) using an in-Drupal rules UI. Depends on core `block`, `user`, and `path_alias`; supports Drupal 10.3+ and 11.

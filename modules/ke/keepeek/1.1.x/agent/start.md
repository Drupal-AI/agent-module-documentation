# Keepeek — agent index

Integrates the **Keepeek DAM** with Drupal media (browse/use Keepeek-hosted assets). Depends on core
`media`, `media_library`, `responsive_image`. Config at `keepeek.settings`. Version **1.1.8**. Core
`^10||^11`.

Store Keepeek API credentials as secrets. Media/DAM integration — governs asset sourcing/display, not
content access.

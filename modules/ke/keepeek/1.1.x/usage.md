Keepeek integrates the Keepeek DAM platform, letting editors use Keepeek-hosted assets as Drupal media.

---

Keepeek integrates Keepeek — a digital-asset-management (DAM) platform — with Drupal's media system,
so editors can browse and use Keepeek-hosted assets (images and other media) within Drupal, keeping a
single managed asset library in Keepeek. It depends on core Media, Media Library and Responsive Image, and
is configured at `keepeek.settings`.

Use it where an organization manages assets centrally in Keepeek and wants editors to pull from that
library. The connection uses Keepeek API credentials — store them as secrets and scope them appropriately.
It is a media/DAM integration; it governs asset sourcing/display, not content access. Configure the Keepeek
connection and use the assets in media.

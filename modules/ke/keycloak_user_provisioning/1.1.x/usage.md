Provision and de-provision users to/from Keycloak.

---

miniOrange Keycloak User Provisioning provides user provisioning and de-provisioning into Keycloak and from Keycloak — so Drupal users are created/updated/disabled in Keycloak (and/or synced back), keeping identity in sync between Drupal and the Keycloak IdP.

The Keycloak admin API credentials are admin-configured and should be stored securely (env-backed), never committed. Depends on `user_provisioning`; supports Drupal 9.3+, 10, and 11.

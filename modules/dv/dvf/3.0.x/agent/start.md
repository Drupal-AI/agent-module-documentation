# Data Visualisation Framework (`dvf`)

A framework for generating charts and visualisations (bar, line, pie, scatter, radar, etc.) from CSV, JSON or CKAN data sources, exposed as entity fields.

- Project: `dvf`, version `3.0.x`, core `^9 || ^10`. Submodules: dvf_ckan, dvf_csv, dvf_json.
- Category: Content display / Charts / data visualization.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

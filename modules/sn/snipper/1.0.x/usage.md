Snipper adds single-item import/export to the config sync page.

---

Snipper **adds single-item config import/export** — enabling import/export of individual configuration items on
the configuration synchronization page, for granular config transfer. It depends on core Config.

Use it for single-config-item transfer. It is a configuration-management/developer tool; it moves **configuration**
(admin-facing). Security note: exported config can include sensitive settings — review a config item's contents
before sharing/importing so you don't leak or overwrite secrets. It has no content or access role. Use the
single-item import/export.

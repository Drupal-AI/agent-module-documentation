# Configuration

Snowflakes has a small settings form (config object `snowflakes.settings`) where
you switch the effect on and control how and when the snow appears.

## Open the settings

1. Log in as a user with permission to administer the snowflakes effect (an
   administrator by default).
2. Go to the **Snowflakes settings** form in the Configuration area.

## Turn the snow on

The effect can be **toggled on** from this form — enable it and the animated
snowflakes begin falling across your site's pages. Turn it back off when the
season is over. The remaining options on the form let you tune the decorative
snow effect (how the snowflakes are shown). Because the module is purely
decorative, none of these settings affect content or access — they only change
the on‑screen snow.

## Save

Save the form and reload a page on the front end to see the snow. If you don't
see anything, confirm the effect is toggled on and clear the site cache so the
CSS is re‑applied.

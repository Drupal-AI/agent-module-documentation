Snowflakes adds pure CSS animated snowflakes to your Drupal site.

---

Snowflakes adds pure-CSS animated snowflakes to the site — a lightweight, JavaScript-free seasonal
decoration (falling snow) that can be toggled on. It is configured at `snowflakes.settings` and provides its
own permissions, in the User interface package.

Use it for a seasonal snow effect. It is a purely decorative content-display feature; it has no content or
access role. Configure the snowflakes and when they show.

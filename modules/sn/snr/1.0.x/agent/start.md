# Search and Replace (snr) — agent index

Bulk **search-and-replace text across field content** (fix a repeated typo, update a URL/brand site-wide).
Ships `snr_safe` (preview/safer mode). Version **1.0.1**. Core `^8.7.7||^9||^10||^11`.

**Caution:** bulk, potentially irreversible content modification — restrict to trusted admins, back up
(or use `snr_safe` preview), test on a small scope first. Acts with operator's privileges; no access role.

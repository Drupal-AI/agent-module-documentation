# Logged In — agent index

A **Views field plugin to show whether the row's user is currently logged in** (online-now indicator). Version
**1.0.0**. Core `^10||^11`.

Developer/Views — online status is **presence data** (expose to appropriate roles only); results follow the
view's access. No access role.

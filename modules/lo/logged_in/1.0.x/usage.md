Logged In provides a Views field plugin to check if a user is logged in.

---

Logged In provides a **Views field plugin that indicates whether a user is currently logged in** — adding a
column/flag to a user-based view showing each user's active-session/logged-in state (e.g. an "online now"
indicator). It is in the Views package.

Use it to show online/logged-in status in a view. It is a developer/Views feature. Data-handling note: showing
who is **currently online** is user activity/presence data — expose it only to appropriate roles (it can reveal
usage patterns). Results follow the view's own access. It has no access-control role. Add the field to a user
view.

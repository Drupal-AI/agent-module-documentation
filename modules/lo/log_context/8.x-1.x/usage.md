Log the Drupal.attachBehaviors context for debugging.

---

Log Context logs the context variable any time `Drupal.attachBehaviors` is called — a front-end debugging tool that records what context each JS behavior attachment runs against, helping developers diagnose Ajax/behavior issues. It's a development tool (not for production). Supports Drupal 9.2+, 10, and 11.

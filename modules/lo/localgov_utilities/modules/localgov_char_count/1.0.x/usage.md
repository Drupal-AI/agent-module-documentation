LocalGov Char Count is a LocalGov Utilities submodule that adds character-count feedback to text fields, wrapping Textfield Counter for the LocalGov distribution.

---

LocalGov Char Count is a submodule of LocalGov Utilities that adds character-count feedback to text
fields — showing editors how many characters they have used or have remaining as they type. It builds
on the Textfield Counter module, applying it with LocalGov-appropriate defaults so that fields like
titles and summaries stay within recommended lengths (important for consistent presentation and SEO on
local-government sites).

Use it as part of the LocalGov Drupal distribution to guide editors toward well-sized field content.
It is an editorial/UX aid with no access-control role; the counter is advisory (and/or enforcing a max
via Textfield Counter) on the fields it is configured for. It is enabled as part of the LocalGov
ecosystem via its parent LocalGov Utilities.

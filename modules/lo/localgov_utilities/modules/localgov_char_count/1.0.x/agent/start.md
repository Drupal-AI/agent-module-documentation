# LocalGov Char Count — agent index

**LocalGov Utilities** submodule adding **character-count feedback** to text fields (used/remaining as
you type), wrapping `textfield_counter` with LocalGov defaults — keeps titles/summaries within
recommended lengths. Version **1.0.x**. Core `^10||^11`.

Editorial/UX aid (no access control); advisory or max-enforcing per field. Enabled via the LocalGov
ecosystem.

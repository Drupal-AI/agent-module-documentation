# LocalGov Utilities — agent index

Small **utility helpers** for the **LocalGov Drupal** distribution (UK local government). `hidden`
(distribution support module). Depends on `textfield_counter`. Ships `localgov_char_count` submodule
(character-count feedback on text fields). Version **1.0.0**. Core `^10||^11`.

Editorial/utility only (no access control); typically enabled by the distribution.

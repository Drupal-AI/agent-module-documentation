# LocalGov Sa11y — agent index

Applies the **Sa11y accessibility checker** to **LocalGov Drupal** sites (in-page a11y issue highlighting
for editors — alt/headings/contrast). Provides permissions. Version **1.0.0-beta11**. Core `^10||^11`.

Accessibility/editorial tooling — **restrict the checker to editors** (visitors shouldn't see the audit
overlay) via its permission. No content/access role beyond that.

Locale Download allows downloading translation files to the local translation directory in a controlled way, for managing interface translations.

---

Locale Download allows downloading interface-translation (`.po`) files to the local translations
directory in a controlled manner — giving administrators a managed way to fetch/update translations into
the site's translation directory (rather than relying on automatic downloads). It is in the Administration
package and provides Drush commands.

Use it to manage how interface translations are downloaded/updated. It is a multilingual/administration
tool operating on translation files (typically Drush-driven); it fetches translation files (from the
localization server) into the local directory and has no content-access role. Note it downloads files to
the filesystem, so run it in appropriate environments. Configure/run the download.

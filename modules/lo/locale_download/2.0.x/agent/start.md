Downloads **interface-translation (`.po`) files to the local translations directory** in a controlled
manner (managed translation fetch/update). Provides **Drush commands**. Version **2.0.0**. Core `^10||^11`.

Multilingual/admin tool (Drush-driven) — fetches translation files to the filesystem; no content-access
role. Run in appropriate environments.

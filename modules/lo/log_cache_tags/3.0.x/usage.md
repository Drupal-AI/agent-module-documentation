Log Cache Tags logs all cache tags for debugging.

---

Log Cache Tags is a **development tool that logs all cache tags** — recording which cache tags are used/
invalidated, to help developers debug caching and cache-invalidation issues. It is in the Development package.

Use it only in development to diagnose caching. It is a developer/debugging tool. Operational note: logging all
cache tags is **noisy and has overhead** — enable it only on dev/staging and turn it off (and don't leave it on
production), as with any verbose debug logger. It has no content or access role. Enable and view the cache-tag
log.

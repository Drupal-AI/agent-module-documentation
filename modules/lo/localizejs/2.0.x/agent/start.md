# Localize.js — agent index

Integrates the **Localize.js (localizejs.com) JavaScript translation service** (client-side page translation via
an injected widget). Provides permissions. Version **2.0.5**. Core `^8.8||^9||^10||^11`.

Third-party integration/multilingual — loads **third-party JS** (trust the vendor; reads/translates page
content); content processed by Localize.js (privacy); project **key** as config/secret. No access role beyond
permission.

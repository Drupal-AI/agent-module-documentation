# Locale Deploy — agent index

Makes it easy to **deploy locale (interface) translations for core, contrib and custom code** (export/import
deterministically in a deployment pipeline). Depends on core `locale`. Version **2.0.0**. Core `^11.4.2||^12`.

Multilingual/dev-ops — manages translation strings (not content); no access role.

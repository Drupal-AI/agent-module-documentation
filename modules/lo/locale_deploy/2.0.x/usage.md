Locale Deploy makes it easy to deploy locale translations for core, contrib and custom code.

---

Locale Deploy makes it easy to **deploy interface (locale) translations** across environments — so
translations of core/contrib/custom strings can be exported and re-imported deterministically as part of a
deployment, instead of relying on ad-hoc translation imports. It depends on core Locale, core 11.4.2+, in the
Multilingual package.

Use it to move interface translations through a deployment pipeline. It is a multilingual/developer-ops
feature; it manages translation strings (not content) and has no access-control role. Configure and run the
translation deployment.

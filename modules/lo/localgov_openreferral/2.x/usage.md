LocalGov Open Referral provides support for creating Open Referral UK (services directory) endpoints, for LocalGov Drupal council sites.

---

Open Referral UK is a data standard for publishing directories of community services (a council's services directory) in a machine-readable API. LocalGov Open Referral helps a LocalGov Drupal site expose Open Referral UK endpoints. It is a distribution-specific data-publishing feature. It exposes service-directory data via an API, so the standard API consideration applies: confirm the exposed endpoints publish only intended, public directory data (a services directory is typically public, but verify), and that the API is not inadvertently exposing internal fields. Adopt on a LocalGov council site publishing a services directory.

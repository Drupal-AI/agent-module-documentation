LocalGov Editoria11y configures the Editoria11y module for LocalGov Drupal.

---

LocalGov Editoria11y provides ready-made configuration of the Editoria11y accessibility checker for
LocalGov Drupal sites — so the in-page accessibility checker (which flags accessibility issues to editors as
they work) is set up appropriately for the LocalGov distribution out of the box. It depends on the
Editoria11y module, in the LocalGov Drupal package.

Use it on LocalGov Drupal sites to get Editoria11y pre-configured. It is an accessibility/editorial feature;
it configures the accessibility checker and has no content or access role. Enable it to apply the LocalGov
Editoria11y configuration.

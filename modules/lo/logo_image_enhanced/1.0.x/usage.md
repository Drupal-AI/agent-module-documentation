Logo Image Enhanced applies image styles to theme logos with accessibility attributes.

---

Logo Image Enhanced lets you **apply image styles to a theme's logo and add accessibility attributes**
(alt text) — so the logo can be responsive/optimized via image styles and carries proper alt text, rather than
being a raw unprocessed image. It depends on core Image, in the Media package.

Use it to optimize and make accessible the site logo. It is a theming/media/accessibility feature affecting
logo rendering; it has no content or access role. Configure the logo image style and alt text.

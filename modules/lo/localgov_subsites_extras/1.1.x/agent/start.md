# LocalGov Subsites Extras — agent index

Enables **menu-driven subsites** (microsites) for **LocalGov Drupal** — subsite page hierarchy and
navigation determined by the **menu system**. Depends on core `menu_ui`, `node`. Version
**1.1.0-alpha3**. Core `^10||^11`.

Site-structure/editorial feature on the LocalGov subsites system (no access control). Expects base
subsites functionality present.

LocalGov Extra Layouts adds custom layout types for Layout Builder.

---

LocalGov Extra Layouts **adds custom layout types for Layout Builder** — extra section layouts tailored for
the LocalGov Drupal distribution (local-government sites), giving editors more layout options when building
pages. It is in the LocalGov Drupal package.

Use it to add LocalGov layout options. It is a site-building/theming feature; layouts are used within the Layout
Builder edit flow (gated by layout/edit access) and it has no access-control role. Use the layouts when
configuring sections.

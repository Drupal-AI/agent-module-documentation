Local Tasks More adds a show more tasks toggle.

---

Local Tasks More **adds a "show more" toggle to local task menus** — collapsing overflowing local-task tabs
(the secondary tabs on admin/content pages) behind a toggle so busy tab rows stay tidy. It is in the
Administration package.

Use it to tidy crowded local-task tabs. It is an administration/UX feature affecting the admin UI; it has no
content or access role. Enable it to collapse local tasks.

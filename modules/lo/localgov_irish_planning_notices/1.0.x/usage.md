LocalGov Irish Planning Notices creates a content type and list for weekly planning notices.

---

LocalGov Irish Planning Notices provides a **content type and listing for weekly Irish planning notices** —
for LocalGov Drupal (council) sites in Ireland to publish the statutory weekly planning-notice lists, with file
handling via Filefield Paths. It depends on the Filefield Paths module, in the LocalGov Drupal package.

Use it on Irish council sites to publish planning notices. It is a content/public-services feature; the notices
are published content (public by intent) following normal content access, and it has no access-control role.
Configure and create planning notices.

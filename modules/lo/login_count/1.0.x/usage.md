Login Count counts the amount of times a user has logged in.

---

Login Count **counts and records how many times each user has logged in** — incrementing a per-user login
counter (and typically last-login data) for reporting/engagement metrics. It depends on core User.

Use it to track user login activity. It is a user/reporting feature. Data-handling note: login counts/times are
**per-user activity data** — expose them only to appropriate roles (they can reveal usage patterns). It has no
access-control role. View the login counts.

# Login Count — agent index

**Counts and records how many times each user has logged in** (per-user counter/last-login). Depends on core
`user`. Version **1.0.x** (dev). Core `^9||^10||^11`.

User/reporting — login counts are **per-user activity data** (expose only to appropriate roles). No access
role.

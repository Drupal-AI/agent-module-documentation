Configure inheritance (fallback) between locale languages.

---

Locale fallback allows users to configure inheritance between locale languages — so a language can fall back to another (e.g. `de-AT` → `de` → English) for untranslated interface strings, giving finer control over translation fallback chains than core's default. Depends on core `language`; supports Drupal 9, 10, and 11.

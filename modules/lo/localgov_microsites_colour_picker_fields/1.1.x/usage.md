LocalGov Microsites Colour Picker Fields adds a colour picker to certain fields on LGD Microsites.

---

LocalGov Microsites Colour Picker Fields adds a colour-picker widget to specific fields on LocalGov
Drupal (LGD) Microsites — letting microsite editors choose colours (for theming/branding a microsite) via a
picker rather than typing hex values. It is in the LocalGov package.

Use it on LGD Microsites for colour selection. It is a content-editing/widget feature; the colour value is
authored data (used for microsite theming) and it has no access-control role. Configure the colour-picker
fields.

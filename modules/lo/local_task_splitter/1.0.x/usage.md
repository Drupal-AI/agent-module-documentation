Split local tasks into separate blocks, optionally as dropbuttons.

---

Local Task Splitter allows splitting local tasks (the tabs on an entity/admin page) into different blocks based on configuration, and optionally rendering them in dropbuttons — with icons on the dropbuttons when UI Icons is installed — so a site can lay out those tabs flexibly instead of the single default tab bar. Depends on core `block`; supports Drupal 10 and 11.

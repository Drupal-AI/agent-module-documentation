# LocalGov EU Cookie Compliance — agent index

A **block that embeds the EU Cookie Compliance settings form** (LocalGov Drupal — let visitors review/update
cookie choices). Depends on `eu_cookie_compliance`. Version **1.x** (dev). Core `^10||^11`.

Privacy/consent presentation — actual consent handled by **EU Cookie Compliance** (this embeds its form); no
access role.

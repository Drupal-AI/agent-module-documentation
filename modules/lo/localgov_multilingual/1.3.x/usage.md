LocalGov Multilingual enables multilingual support for LGD sites, with sub-modules for specific content types.

---

LocalGov Multilingual enables multilingual support for LocalGov Drupal (LGD) sites — configuring
translation for LGD's content types, with a large set of submodules to enable multilingual for specific
content types (services, guides, news, events, directories, step-by-step, alert banners, etc.). It is in the
LocalGov Drupal package.

Use it on LGD sites needing multilingual content. It is a multilingual/distribution feature configuring
content translation for LGD; content access is unchanged (translations respect the same access) and it has no
access-control role. Enable the submodules for the content types you need.

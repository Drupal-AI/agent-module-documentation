Import events from the Localist event platform.

---

Localist Drupal provides integration with the Localist event platform to import events — using Migrate to pull events from a Localist calendar into Drupal content (with Smart Date for the event dates), so a Localist-managed calendar appears as native Drupal event content. Depends on core `taxonomy` and `migrate`, plus `migrate_plus`, `migrate_tools`, and `smart_date`; supports Drupal 10.3+ and 11.

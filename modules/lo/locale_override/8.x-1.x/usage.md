Store overridden UI-string translations in a config entity.

---

Locale Override stores translated user interface strings in a config entity — so custom overrides of interface translations (via 'Translate interface') are captured as configuration that can be exported and deployed between environments, instead of living only in the database. Depends on core `config_translation` and `webform`; supports Drupal 10 and 11.

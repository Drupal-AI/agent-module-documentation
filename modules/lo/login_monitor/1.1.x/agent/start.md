# Login Monitor — agent index

Comprehensive **login-activity tracking** — logs login events, sends notifications, statistical reports
(visibility into who/when/where). Config at `login_monitor.settings`; provides permissions. Version
**1.1.1**. Core `^11`.

**Positive** security-monitoring (detect compromised accounts/brute-force, alert on unexpected logins).
Login logs are **PII** (handle per privacy, gate reports to trusted admins). Monitors, doesn't block. No
access role.

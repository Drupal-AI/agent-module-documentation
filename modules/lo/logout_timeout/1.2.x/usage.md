Log a user out after an inactive timeout.

---

Logout on Timeout logs a user out after an inactive timeout — so after a configurable period of inactivity the user's session is ended (with an optional message and a JS keepalive to reset the timer on activity), improving security on shared/unattended machines. Depends on core `user`; supports Drupal 10 and 11.

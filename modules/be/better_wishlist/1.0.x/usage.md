Better Wishlist provides wishlist functionality for users to save items/entities.

---

Better Wishlist **provides wishlist functionality** — letting users save items/entities to a personal
wishlist (for e-commerce or content bookmarking). It depends on the Entity API module, provides its own
permissions.

Use it to add wishlists. It is a user-engagement/e-commerce feature. Data-handling note: a wishlist ties **users
to items** (personal data) — expose each user's wishlist only to that user (and admins), per its permissions. It
has no broad access-control role beyond its permission. Configure the wishlist.

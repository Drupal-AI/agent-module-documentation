IPI adds extra functionality to improve Paragraphs.

---

IPI **adds extra functionality to improve the Paragraphs editing experience** — enhancing how editors add/
manage Paragraphs, integrating Paragraphs Library, Paragraphs Browser and Entity Browser for a richer authoring
UI. It depends on those modules, in the AB package.

Use it to improve Paragraphs authoring. It is a content-editing/site-building feature affecting the Paragraphs
UI; it has no content or access role. Enable it alongside Paragraphs.

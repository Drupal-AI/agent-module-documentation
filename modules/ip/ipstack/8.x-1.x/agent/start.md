# IPstack — agent index

Integrates the **ipstack.com IP-geolocation API** (country/region/city for an IP). Provides permissions. Version
**8.x-1.7**. Core `^9||^10||^11`.

Integration — sends **IPs to ipstack** (egress; IP is personal data); **access key** as a secret (env/Key,
HTTPS). No access role beyond permission.

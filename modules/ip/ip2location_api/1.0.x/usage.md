IP geolocation via the IP2Location service.

---

IP2Location API provides an IP-to-location service — resolving a visitor's IP address to geographic data (country, region, city, etc.) via IP2Location, so other modules/code can act on visitor geography (analytics, geo-targeting, compliance).

The IP2Location API key is stored via a Key entity (`key` dependency, env-backed), never committed; IPs are personal data — handle per your privacy policy. Depends on `key`; supports Drupal 10 and 11.

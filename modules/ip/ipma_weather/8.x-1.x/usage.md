IPMA Weather provides a weather block with IPMA data.

---

IPMA Weather **provides a weather block using IPMA data** — showing current/forecast weather for a location
from IPMA (Instituto Português do Mar e da Atmosfera), Portugal's meteorological service. It depends on core
Block, in the User interface package.

Use it to show Portuguese weather. It is a content-display/integration feature. Note: it fetches data from the
**external IPMA API** (public weather data, no credentials typically), and the weather is public content; it has
no access-control role. Configure the weather block location.

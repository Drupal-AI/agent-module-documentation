# Leaflet MapTiler — agent index

Adds **MapTiler map styles/tiles to Leaflet** maps. `leaflet_maptiler_token` submodule (API token). Depends on
`leaflet`. Provides permissions. Version **2.0.2**. Core `^9.3||^10||^11`.

Content-display/maps — needs a MapTiler **API token** (managed by the token submodule — treat as a secret);
tiles load from **MapTiler** (third-party request). No access role beyond permission.

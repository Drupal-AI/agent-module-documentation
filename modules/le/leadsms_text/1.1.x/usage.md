Support visitors and generate leads via SMS/text messaging.

---

LEADsms offers Drupal webmasters an easy way to support site visitors and generate leads and new business via SMS / text message — adding an SMS click-to-text/lead widget so visitors can start a text conversation, backed by the LEADsms service.

The LEADsms account/API credentials are admin-configured and should be stored securely (env-backed). Supports Drupal 9, 10, and 11.

# Leaflet Choropleth — agent index

**Choropleth maps** for **Leaflet** — shade geographic regions by a data value (from a View). Depends
on `leaflet_views`. Version **1.0.6**. Core `^10.2||^11`.

Data-visualisation/mapping display; the View's access governs the data shown (no access role).

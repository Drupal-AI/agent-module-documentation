Leaflet Choropleth provides choropleth map functionality for Leaflet maps, shading geographic regions by a data value.

---

Leaflet Choropleth extends the Leaflet mapping integration with choropleth maps — maps that shade
geographic regions (countries, states, districts) by a data value, so a metric can be visualised
across areas with a colour gradient. It builds on `leaflet_views`, so the region data and values come
from a View, and renders them as a shaded Leaflet layer.

Use it to visualise per-region statistics — population, sales, incidence — on an interactive Leaflet
map driven by Drupal content. It is a data-visualisation/mapping display feature; the underlying
View's access governs which data is shown, and this module handles the choropleth rendering. No
access-control role of its own.

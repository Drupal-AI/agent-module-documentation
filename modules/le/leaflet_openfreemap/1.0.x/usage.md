Leaflet OpenFreeMap provides OpenFreeMap tile layers for Leaflet maps.

---

Leaflet OpenFreeMap adds OpenFreeMap map tiles as an option for the Leaflet module — so Leaflet maps can use OpenFreeMap's free, open vector/raster tiles instead of commercial providers, avoiding API keys and usage costs for basic mapping.

It's a Leaflet tile-provider add-on with no content or access role of its own. Depends on `leaflet`; supports Drupal 10 and 11.

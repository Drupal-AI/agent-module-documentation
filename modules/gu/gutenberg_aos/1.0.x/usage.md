Gutenberg AOS adds AOS animation options to Gutenberg blocks.

---

Gutenberg AOS adds **AOS (Animate On Scroll) animation options to Gutenberg blocks** — so editors using
the Gutenberg editor can apply scroll-in animations (fade, slide, etc.) to blocks from the block settings. It
depends on the Gutenberg and AOS modules, in the Custom package.

Use it to animate Gutenberg blocks on scroll. It is a content-editing/theming feature affecting presentation;
it has no content or access role. Apply AOS options to Gutenberg blocks.

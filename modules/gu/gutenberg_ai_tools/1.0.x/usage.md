A Gutenberg block for generative-AI prompt/response.

---

Gutenberg AI Tools exposes a Gutenberg block for creating a Generative AI prompt/response — so editors using the Gutenberg editor can insert a block that sends a prompt to the AI module and works with the response inline while authoring content.

The AI provider/keys are configured through the `ai` module (env-backed via a Key entity); each prompt is an LLM call (watch cost). Depends on `ai`, `gutenberg`, and core `rest`; supports Drupal 10.3+ and 11.

# Gutenberg Span — agent index

Adds a **span-tag formatting option to the Gutenberg editor** (wrap text in `<span>` for styling hooks/
classes). Version **1.0.4**. Core `^9.5||^10||^11`.

Content-editing — inserts `<span>` markup (ensure the format allows it); no access role.

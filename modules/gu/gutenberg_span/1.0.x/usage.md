Gutenberg Span creates a span tag in the Gutenberg editor.

---

Gutenberg Span adds the ability to **wrap text in a `<span>`** within the **Gutenberg** editor — giving
editors inline `span` formatting (for styling hooks/classes) that Gutenberg doesn't provide out of the box. It
is in the Gutenberg package.

Use it to add inline span formatting in Gutenberg. It is a content-editing feature; it inserts `<span>` markup
into content (ensure the text format allows it) and it has no access-control role. Enable it in the Gutenberg
editor.

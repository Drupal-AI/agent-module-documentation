Gutenberg Advanced Link adds advanced link options (attributes) when creating links in the Gutenberg editor.

---

The Gutenberg editor's link tool is basic; advanced link handling (attributes, target, rel) is often wanted. Gutenberg Advanced Link adds those options. It is a Gutenberg authoring enhancement. As with any link-attribute feature, if it lets authors add arbitrary attributes there is a theoretical XSS consideration (an on* handler), but link attributes in an editor are typically constrained; confirm it restricts to safe link attributes (target, rel, class) and that target=_blank pairs with noopener. For editorial link control it improves the Gutenberg experience.

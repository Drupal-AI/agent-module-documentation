Guided Tour provides Driver.js-based onboarding tours for any visitor.

---

Guided Tour provides guided, step-by-step tours built with the Driver.js library for both anonymous and authenticated users — highlighting UI elements with tooltips to onboard visitors or explain features. It is compatible with web components.

It's a front-end onboarding/UX feature with no content or access role of its own. Depends on core `user`; supports Drupal 10 and 11.

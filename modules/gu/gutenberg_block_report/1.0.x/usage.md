Report which Gutenberg blocks are used in which nodes.

---

Gutenberg Block Report reports which Gutenberg blocks are used in which nodes — scanning Gutenberg-authored content and listing, per block type, the nodes that use it, so site owners can audit block usage (e.g. before deprecating a block). Depends on core `node`; supports Drupal 9, 10, and 11.

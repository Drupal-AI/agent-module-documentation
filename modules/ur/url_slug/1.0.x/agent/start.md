# URL Slug — agent index

Adds a **URL-slug field to content types, derived from the node title** (editable slug; integrates with Token +
Pathauto). Depends on core `node`, `token`, `pathauto`. Provides permissions. Version **1.0.1**. Core `^11`.

Site-structure/URL — slug feeds URL alias generation (via Pathauto); no access role beyond permission.

URL Slug adds a URL slug field to selected content types, using the node title.

---

URL Slug adds a **URL-slug field** to selected content types — generating a slug from the node title
(and integrating with Token and Pathauto), so content has an explicit, editable slug used in its URL. It
depends on core Node, Token and Pathauto, provides its own permissions, requires core 11.

Use it to give content editable URL slugs. It is a site-structure/URL feature; the slug feeds URL alias
generation (governed by Pathauto) and it has no access-control role beyond its permission. Configure the slug
field on the content types.

URL Text Field provides an entity field for URL text.

---

URL Text Field (url_text) **provides a URL text field** — a field type for storing a URL as text on entities,
for capturing web addresses. It works across core 9.4–11.

Use it to store URLs on entities. It is a content-editing/field feature; the stored value is a URL string and it
has no access-control role. Note: when a stored URL is output as a link, ensure it's sanitized (e.g. block
`javascript:` schemes) as with any user-entered URL. Configure the URL field.

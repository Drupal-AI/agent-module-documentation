URCT exposes User Referral cookie data as tokens for use across the site.

---

User Referral Cookie Tokens (URCT) provides tokens for the referral cookie set by the User Referral module — so the referral information (who referred a visitor) can be used via Drupal's token system in fields, messages, or configurations, supporting referral tracking/attribution.

It's a token-provider/integration utility with no content or access role of its own. Depends on `user_referral` and core `views_ui`; supports Drupal 10.4+ and 11.

# H5P Analytics — agent index

Sends **H5P interaction data (xAPI) to a Learning Record Store (LRS)** (`h5p_analytics_tip` submodule). Depends
on `h5p`. Version **8.x-1.0-rc11**. Core `^10||^11`.

E-learning/integration — xAPI statements carry **learner PII/records** sent to an **external LRS** (credentials
as secrets, HTTPS, privacy policy). No access role.

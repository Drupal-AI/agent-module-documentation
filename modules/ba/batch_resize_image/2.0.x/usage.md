Batch Resize Image provides an easy way to resize images in the files folder.

---

Batch Resize Image provides an **easy way to batch-resize images** in the site's files folder — running a
batch that resizes existing image files (e.g. to cap dimensions/reduce size), useful for cleaning up
oversized uploads. It is in the Images package.

Use it to bulk-resize existing image files. It is a media/administration developer tool run by admins; it
**modifies files in place** (resizing the actual stored images), so **back up first** and be aware the
original dimensions are lost. It has no content or access role. Run the batch resize.

# Basic Slider - agent index

**Basic Slider** renders an image slideshow as a block. Version **2.0.4** (`2.0.x`). Core `^10`. Depends on core `block`.

## Key files
- `src/Plugin/Block/BasicSliderBlock.php` - the block plugin.
- `js/basic-slider.js`, `templates/basic-slider.html.twig`, `basic_slider.libraries.yml`.

No routes, no permissions - purely a display block.

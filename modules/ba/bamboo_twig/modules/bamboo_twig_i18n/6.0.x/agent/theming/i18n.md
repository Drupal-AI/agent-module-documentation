# Internationalization helpers

Class `I18n`, service `bamboo_twig_i18n.twig.i18n`.

- `bamboo_i18n_current_lang()` (function) → current language id, e.g. `en`.
  ```twig
  <html lang="{{ bamboo_i18n_current_lang() }}">
  ```
- `bamboo_i18n_format_date` (filter, needs the Twig environment) —
  `date | bamboo_i18n_format_date(type = 'medium', format = '', timezone = null, langcode = null)`.
  Converts the date and formats it via `date.formatter` using the current language for text.
  `type` is a built-in ('short','medium','long','html_date',…), a date-format config id, or 'custom'.
  ```twig
  {{ node.getCreatedTime | bamboo_i18n_format_date('long') }}
  {{ node.getCreatedTime | bamboo_i18n_format_date('custom', 'd/m/Y') }}
  ```
- `bamboo_i18n_get_translation` (filter) — `entity | bamboo_i18n_get_translation(langcode = null)` →
  the entity's translation for the given (or current) language via
  `entity.repository->getTranslationFromContext()`.
  ```twig
  {% set translated = node | bamboo_i18n_get_translation('fr') %}
  {{ translated.label }}
  ```

BAWstats surfaces AWStats web-statistics reports in the Drupal admin.

---

BAWstats lets you view web statistics generated by the AWStats tool — surfacing AWStats reports (visitors, pages, referrers) inside the Drupal admin, so operators can see server-log-based web analytics without a separate AWStats interface.

Permissions cover viewing statistics (`view site statistics`) and administration (`statistics admin`). It reads AWStats data (configure paths securely). Supports Drupal 8+.

Integrate with the NfP365 (nonprofit Dynamics 365) CRM API.

---

NfP365 CRM API provides an integration with the NfP365 CRM API — connecting Drupal to NfP365 (a Microsoft Dynamics 365-based CRM for nonprofits) so members/donors/data can sync between the site and the CRM.

The NfP365/Dynamics credentials are admin-configured and should be stored securely (env-backed), never committed; communication uses HTTPS. Supports Drupal 8 through 11.

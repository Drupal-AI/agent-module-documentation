Manage customizable lists of shortcut links.

---

Shortcut View allows users to manage customizable lists of shortcut links — extending core Shortcut with user-managed, orderable link lists (via draggableviews) so users can build and reorder their own quick-access shortcut sets. Depends on core `shortcut` and `draggableviews`; supports Drupal 9, 10, and 11.

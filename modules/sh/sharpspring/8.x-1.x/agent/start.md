# SharpSpring — agent index

Adds **SharpSpring tracking JavaScript to every page** (track visitors for lead generation / marketing
automation). Config at `sharpspring.settings`; provides permissions. Version **8.x-1.7**. Core `^10.2||^11`.

Third-party marketing tracker — **privacy/consent:** disclose in the privacy policy, gate behind cookie
consent (GDPR/CCPA). No access role beyond permission.

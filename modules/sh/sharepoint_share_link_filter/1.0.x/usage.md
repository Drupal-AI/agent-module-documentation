Sharepoint share link filter renders SharePoint share links via SharePoint file download.

---

Sharepoint share link (filter) provides a text filter that handles SharePoint share links in content — integrating with the SharePoint File Download module so shared SharePoint documents can be embedded/linked and served through Drupal, useful for intranets pulling documents from SharePoint.

It relies on the SharePoint File Download module's connection/credentials (store securely, env-backed). Enable the filter on the relevant text formats. Depends on `sharepoint_file_download`; supports Drupal 8 through 11.

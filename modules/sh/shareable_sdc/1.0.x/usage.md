Shareable SDC lets Single Directory Components live in a global /components directory for reuse.

---

Shareable Single Directory Components extends the core SDC (Single Directory Components) functionality to support components placed in a global `/components` directory — so components can be shared across themes/modules from one central location instead of being confined to a single theme or module.

It's a developer/theming tool with no content or access role of its own. Requires Drupal 11.

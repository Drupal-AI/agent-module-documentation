# SharpSpring Webforms — agent index

Adds **SharpSpring tracking to admin-selected Webforms** (link form submissions to SharpSpring leads).
Depends on `webform`, `sharpspring`; provides permissions. Version **2.0.5**. Core `^9||^10||^11`.

Privacy/consent — form data flows to SharpSpring (disclose, gate by consent, mind PII in forms). No access
role beyond permission.

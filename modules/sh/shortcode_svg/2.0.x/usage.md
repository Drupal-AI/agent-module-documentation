Embed SVG sprite icons in content via a shortcode.

---

Shortcode SVG lets you upload and use an SVG image sprite in a shortcode — so editors can insert individual icons from an uploaded SVG sprite into content using a simple `[svg …]` shortcode, keeping icon markup out of the body while rendering crisp vector icons. Depends on `shortcode`; supports Drupal 10 and 11.

A URL shortener with QR codes, visit tracking and a REST API.

---

Short URL is a URL shortener with QR codes, visit tracking, and a REST API — generating short aliases for content/URLs, producing QR codes for them, counting visits, and exposing a REST API for programmatic shortening, e.g. for campaigns and print. Depends on core `link`, `node`, `options`, and `redirect`; supports Drupal 10.2+ and 11.

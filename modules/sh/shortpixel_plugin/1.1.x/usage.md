A ShortPixel optimizer plugin for ImageAPI Optimize.

---

ShortPixel ImageAPI Optimize processor plugin provides a Shortpixel optimizer for ImageAPI Optimize — so image derivatives can be compressed/optimised through the ShortPixel image-optimisation API, reducing file sizes for faster pages.

The ShortPixel API key is admin-configured; store it securely (env-backed). Depends on `imageapi_optimize`; supports Drupal 9, 10, and 11.

NSW Feedback provides blocks for OneGov feedback and sentiment widgets.

---

NSW Feedback provides **blocks for the NSW (New South Wales) OneGov feedback and sentiment widgets** — so
a NSW-government Drupal site can place standard "was this page helpful?" feedback and sentiment-collection
widgets in block regions. It ships an `nsw_feedback_assist` submodule and depends on core Block, in the
Contrib package.

Use it on NSW-gov sites to collect page feedback. It is a user-engagement/integration feature; the widgets
collect visitor feedback/sentiment (which may be sent to the OneGov service — a data/privacy consideration)
and it has no access-control role. Place and configure the feedback blocks.

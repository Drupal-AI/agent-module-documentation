# Views Node Title Selector (vnts) — agent index

Adds a **Views exposed filter with a dropdown of existing node titles** (filter by title via a picklist vs
free-text). Version **3.0.0**. Core `^10||^11`.

Content-display/Views — offered titles come from nodes; results respect the View's access (ensure the
dropdown only lists titles the user should see on access-sensitive Views). No access role.

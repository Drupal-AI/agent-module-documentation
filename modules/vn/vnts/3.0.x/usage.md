Views Node Title Selector adds a Views filter providing a dropdown/select list of existing node titles for easy filtering.

---

Views Node Title Selector (vnts) adds a Views exposed filter that presents existing node titles as a
**dropdown/select list** — so a View can be filtered by node title via a picklist rather than free-text
entry, easier for users choosing a specific known node. It is in the Views package.

Use it for a title-picklist exposed filter. It is a content-display/Views feature affecting the exposed
filter; the offered titles come from nodes (and results respect the View's access), and it has no
access-control role. Note the dropdown lists node titles — on an access-sensitive View, ensure it only lists
titles the user should see. Configure the exposed filter.

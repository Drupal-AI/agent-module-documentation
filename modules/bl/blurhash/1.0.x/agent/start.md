# Blurhash - agent index

**Blurhash** generates BlurHash placeholder previews for images. Version **1.0.4** (`1.0.x`). Core `^9 || ^10`.

## Key files
- `src/BlurhashService.php` / `BlurhashServiceInterface.php` - encodes images to BlurHash strings.

Service-based image enhancement; no routes or permissions.

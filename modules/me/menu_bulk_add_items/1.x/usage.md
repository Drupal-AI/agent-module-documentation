Menu Bulk Add Items lets you bulk add multiple items to a menu at once, saving adding them one by one.

---

Menu Bulk Add Items lets administrators add multiple menu items to a menu in one operation — entering
several links at once rather than creating each menu link individually, speeding up building menus. It is
in the Custom package.

Use it to build or populate menus quickly. It is an administration/navigation feature for menu management;
it respects existing menu-administration permissions (it speeds up an action editors could already perform)
and has no access-control role. Use the bulk-add form to add items.

Media Entity Datawrapper creates a media source for embedding visualizations from Datawrapper.

---

Media Entity Datawrapper adds a media source for Datawrapper — letting editors embed Datawrapper charts/
maps/visualizations as core media, so data visualizations created in Datawrapper can be added and reused like
any other media. It depends on core Media.

Use it to embed Datawrapper visualizations as media. It is a media/embed feature; the visualization is remote
content from Datawrapper (an embed) and it has no access-control role. Configure the Datawrapper media
type.

# Media Remote Image — agent index

Provides a **media source for oEmbed image providers** (embed remote images via oEmbed, like core Media video).
Depends on core `media`. Version **1.0.0**. Core `^10||^11`.

Media/integration — remote content from **allowlisted oEmbed providers** (bounded SSRF); images load from the
third-party provider. No access role.

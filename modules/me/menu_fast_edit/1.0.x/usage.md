Menu Fast Edit enhances the Drupal admin UI to let menu links be added and edited quickly, streamlining menu management.

---

Menu Fast Edit enhances the menu administration UI to make adding and editing menu links faster —
streamlining the common menu-management actions (quick add/edit inline) so building and maintaining menus
is less tedious. It depends on core Menu UI and is in the Administration package.

Use it on sites with frequently-edited menus to speed up menu work. It is an administration/UI convenience
for menu management; it respects the existing menu-administration permissions (it speeds up actions
editors could already perform) and has no access-control role. Enable it to improve the menu editing
experience.

Media Entity Podbean adds a media source for embedding Podbean podcasts.

---

Media Entity Podbean **provides a media source for Podbean podcasts** — letting editors add Podbean podcast
episodes as media entities (via their URL/embed) for display on the site. It depends on core Media.

Use it to embed Podbean podcasts as media. It is a media-integration feature; it embeds third-party Podbean content
(loaded from Podbean) and has no access-control role. Configure the Podbean media source.

Media Entity: Unsplash provides a media source plugin for Unsplash — letting editors search and use
Unsplash stock photos as Drupal media entities, sourcing images from the Unsplash API. It depends on core
Image, in the Media package.

Use it to bring Unsplash images into media. Security note: it authenticates to the Unsplash API with an API
key — **store that key as a secret** (Key entity / environment variable), not in exported config, and comply
with Unsplash's API/attribution terms. Images sourced are external content. It has no access-control role.
Configure the Unsplash connection.

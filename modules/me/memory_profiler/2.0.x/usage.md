Memory Profiler is a lightweight module for profiling memory usage.

---

Memory Profiler is a lightweight tool for profiling memory usage — reporting how much memory requests/
operations consume, so developers can identify memory-heavy code paths. It is in the Development package.

Use it during development/profiling to find memory hotspots. It is a developer/debugging tool; it adds
profiling overhead and has no content or access role — use it on development/staging or briefly for a
specific investigation, not permanently on production. Enable it while profiling.

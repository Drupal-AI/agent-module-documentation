# Media Reference Override — agent index

**Override media source field properties (alt, title) per reference instance** via an off-canvas form. Depends on
core `media`, `media_library`, `image`, `file`. Provides permissions. Version **1.0.1**. Core `^10.3||^11`.

Content-editing/media — overrides stored on the reference (aids accessibility); no access role beyond
permission.

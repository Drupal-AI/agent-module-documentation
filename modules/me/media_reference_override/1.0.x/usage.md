Media Reference Override overrides media alt/title per reference instance via an off-canvas form.

---

Media Reference Override **overrides media alt/title per reference** — letting each place a media item is
referenced set its own `alt`/`title` (via an off-canvas form) without changing the source media, so the same image
can have context-appropriate alt text in different places. It depends on core Media, Media Library, Image and File,
and provides its own permissions.

Use it for per-instance media alt/title. It is a content-editing/media feature; overrides are stored on the
reference and it has no access-control role beyond its permission. Note: alt text is important for accessibility —
per-instance overrides help provide context-correct alt. Configure the override on a media reference field.

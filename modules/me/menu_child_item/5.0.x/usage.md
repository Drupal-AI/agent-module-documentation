Menu Child Item lets editors add a child menu link with a single click from an existing menu item, then edit and save it.

---

Menu Child Item streamlines building menu hierarchies: from an existing menu link it adds a child
item with a single click, dropping the editor straight into editing the new child to set its title and
link before saving. It removes the friction of navigating the menu admin to create nested items one at
a time. It depends on core Menu UI.

Use it on sites with deep or frequently-edited menus where building child items quickly matters. It is
an editorial convenience for menu management; it respects the existing menu administration permissions
(it speeds up an action editors could already perform) and has no access-control role of its own.

# Menu Child Item — agent index

Adds a **child menu link in one click** from a menu item, then drops you into editing it. Depends on
core `menu_ui`. Version **5.0.1**. Core `^10.3||^11||^12`.

Editorial convenience for building menu hierarchies; respects existing menu permissions (no access
role).

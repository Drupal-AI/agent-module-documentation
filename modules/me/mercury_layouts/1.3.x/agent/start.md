# Mercury Layouts — agent index

**Composable layouts** for **Mercury Editor** (drag-and-drop page builder) — nestable rows/columns/
sections with configurable style options. Built on core Layout Discovery + `style_options` (>=1.1.0).
Version **1.3.0**. Core `^10.3||^11`.

Presentation/site-building only (no access control). Expects Mercury Editor present to consume the
layouts.

Mercury Layouts provides a set of composable layouts for use with Mercury Editor, built on core Layout Discovery and Style Options.

---

Mercury Layouts supplies composable layout plugins for Mercury Editor, the drag-and-drop page
builder. It builds on core's Layout Discovery API and the Style Options module (>=1.1.0) to offer
flexible, nestable layouts (rows/columns/sections) with configurable style options that editors
arrange within Mercury Editor to compose pages.

Use it as the layout library backing a Mercury Editor–based site: it gives content editors a palette
of responsive, composable sections to build landing pages and rich content without code. It is a
presentation/site-building module — the layouts and their style options define structure and styling,
not access control. It expects Mercury Editor to be present (it provides the layouts that Mercury
consumes) and Style Options for the per-layout styling controls.

Messages provides beautiful, modern status message cards.

---

Messages replaces Drupal's default status messages with **modern, styled message cards** — restyling the
status/warning/error messages (the "message" region) into nicer cards. It provides its own permissions, in the
User Interface package.

Use it to improve status-message styling. It is a theming/UI feature affecting how messages render; the message
content is generated by Drupal/modules (not by this module) and it has no content or access role beyond its
permission. Enable it to restyle messages.

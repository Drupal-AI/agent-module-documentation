# Messages — manual setup guide

**Messages** (`messages`) restyles Drupal's status messages — the "saved", warning
and error notices that appear at the top of the page — into modern, card-based
designs. Instead of the default flat notices, you get styled cards with color-coded
message types, icons, SVG wave backgrounds, smooth CSS animations and manual close
buttons, aimed at making status feedback look more polished and easier to notice.

It is purely a **presentation** layer. The message *content* is still generated by
Drupal and other modules exactly as before; Messages only changes how those notices
are rendered. That means there is nothing to break in your existing workflows — enable
it and your status messages take on the new look. It ships in the User Interface
package, has no other module dependencies and no external libraries, and supports
Drupal 10.2+ and 11 (a modern browser with CSS Grid support is expected on the
visitor side).

Beyond the visual defaults, a settings form gives you administrative control: you can
enable or disable styling per message type, adjust positioning and timing, and toggle
the animation and visual effects. If you never open that form, the module still works
with its default styling.

This guide is written for a **human** clicking through the admin UI. If you want
terse, token‑cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Where it lives in the admin menu

The styling is active as soon as the module is enabled. Its optional settings form
lives under **Configuration → User interface** — look for the Messages (status
messages) settings link there. Everything on that form is optional tuning; the
card styling works out of the box.

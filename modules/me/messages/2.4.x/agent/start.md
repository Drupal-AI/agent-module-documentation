# Messages — agent index

Renders **Drupal status messages as modern, styled message cards** (restyle status/warning/error). Provides
permissions. Version **2.4.0**. Core `^10.2||^11`.

Theming/UI — affects how messages render (content generated by core/modules); no content/access role beyond
permission.

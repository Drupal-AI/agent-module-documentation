# Menu Migration — manual setup guide

**Menu Migration** (`menu_migration`) imports, exports, and clones **menu link
content** hierarchies — the menu links editors create by hand — between Drupal sites,
or between menus on the same site. Instead of re-building a menu link by link when
you move from staging to production (or spin up a new multisite instance), you export
the menu tree to a file, move the file, and import it back. You can also clone one
menu's links straight into another menu.

It works through a small, plug-in-based system. Reusable **Menu Export** and **Menu
Import** configuration entities each pick a *destination* or *source* (write to the
codebase, stream a download, read an uploaded file, or clone into another menu), a
*format* (JSON, YAML, or raw), and a set of menus. You drive all of it from an admin
UI, or from a set of Drush commands. For quick one-off jobs there are also "quick
action" Drush commands that export, import, or clone menus by menu ID without
creating any configuration entity first.

Only manually-created menu link content links are handled — links generated by Views,
taxonomy menus, or other dynamic sources are ignored. The whole thing is extensible:
developers can add custom destinations, sources, and formats, and an import event lets
other modules rewrite each link as it comes in (for example to swap a domain).

This guide is written for a **human** clicking through the admin UI and running Drush.
If you want terse, token-cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Where it lives in the admin menu

The whole UI sits at **Configuration → Development → Menu Migration**
(`/admin/config/development/menu-migration`), a section with three parts:

- **Menu Exports** — create and run reusable export definitions.
- **Menu Imports** — create and run reusable import definitions.
- **Quick Action Settings** — the default format and directory used by the "quick"
  Drush commands.

Access is controlled by the module's five permissions on **People → Permissions**
(`/admin/people/permissions`).

## How to use it

At a high level: create a **Menu Export** to write a menu to a file (or download it),
move that file to the other site, and create a **Menu Import** to read it back — or
skip the entities entirely and use the quick Drush commands (`mmqe` / `mmqi` /
`mmqc`) to export, import, and clone menus by ID. Full step-by-step instructions and
the complete command list are in [Configuration](configuration/index.md).

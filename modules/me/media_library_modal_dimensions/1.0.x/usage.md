Media Library Modal Dimensions sets the media-library modal size on a per-field basis.

---

Media Library Modal Dimensions lets site builders configure the width and height of the Media Library modal on a per-field basis — so different media fields can open a larger or smaller media-selection modal to suit their content, improving the selection UX.

It's a UI configuration enhancement with no content or access role of its own. Depends on core `media_library`; requires Drupal 11.

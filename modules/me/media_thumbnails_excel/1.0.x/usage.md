---

Media Thumbnails Excel generates thumbnails for Excel (spreadsheet) media entities — producing a preview
image for uploaded Excel files so they display with a meaningful thumbnail in the media library/listings
rather than a generic icon. It is in the Media package.

Use it to give Excel media proper thumbnails. It is a media/display feature that generates preview images
from uploaded spreadsheets; it processes the uploaded file server-side to render a thumbnail and has no
access-control role. Enable it for Excel media types.

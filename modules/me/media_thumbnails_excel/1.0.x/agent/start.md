# Media Thumbnails Excel — agent index

Generates **custom thumbnails for Excel media entities** (preview image for uploaded spreadsheets vs a
generic icon). Version **1.0.0-rc1**. Core `^9.3||^10||^11`.

Media/display — processes the uploaded spreadsheet server-side to render a thumbnail; no access role.

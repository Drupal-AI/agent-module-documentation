Media Taxonomy Filter provides a taxonomy filter with depth for filtering media entities in the media library by term.

---

Finding media in a large library is easier when filtered by taxonomy (category, type). Media Taxonomy Filter adds a depth-aware taxonomy filter to the media library. It is a media-management UX feature with no security surface — it filters what the media library already shows, subject to media access. Confirm the filter's depth setting suits your vocabulary.

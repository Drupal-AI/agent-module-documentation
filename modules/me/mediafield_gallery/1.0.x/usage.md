Media Field Gallery provides a responsive gallery formatter for media fields in Views.

---

Media Field Gallery provides a **responsive gallery formatter for media fields in Views** — rendering a
media field (images, video, and other media) as a responsive gallery/grid layout. It requires PHP 8.1, depends
on core Views, Media and Field, provides its own permissions, in the Media package.

Use it to present media fields as a gallery in a View. It is a media/content-display feature; the media shown
follows core media/file access and it has no access-control role beyond its permission. Choose the gallery
formatter on a media field in a View.

Associate an entity with a Message.

---

Message associated entity allows you to associate an entity with a message — adding a dynamic entity reference so a Message (from the Message module) can point at any related entity (the node/user/etc. the message is about), enabling context-aware notifications and activity streams. Depends on `dynamic_entity_reference` and `message`; supports Drupal 10 and 11.

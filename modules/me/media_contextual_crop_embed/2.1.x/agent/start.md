# Media Contextual Crop Embed — agent index

Provides **contextual cropping for media embedded in CKEditor 5** (crop an embedded image per-placement in
rich text). Depends on `media_contextual_crop`, core `media_library`. Version **2.1.0**. Core `^10.3||^11`.

Content-editing/media — per-embed crop (underlying file unchanged); no access role.

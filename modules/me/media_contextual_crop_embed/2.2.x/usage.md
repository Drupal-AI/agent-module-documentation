Media Contextual Crop Embed provides contextual cropping for embedded media in CKEditor 5.

---

Media Contextual Crop Embed provides contextual cropping for media embedded via CKEditor 5 — letting
editors crop an embedded image per-placement (a different crop for this specific embed) directly in the rich
text editor, building on the Media Contextual Crop module. It depends on Media Contextual Crop and core Media
Library.

Use it to allow per-embed image crops in CKEditor 5. It is a content-editing/media feature affecting how
embedded images are cropped for display; the underlying media file is unchanged (the crop is contextual/
per-embed), and it has no access-control role. Configure the crop types and the CKEditor integration.

# Installation

## Requirements

- **Drupal 9 or 10** (`core_version_requirement: ^9 || ^10`).
- The **State Machine** module (`state_machine`) — drives the membership status
  workflow.
- The **Entity API** module (`entity`) — provides the entity access control and the
  per‑bundle CRUD permissions this module relies on.
- **Drupal Commerce** (`commerce`) — a hard dependency; memberships tie into
  store/order/customer flows. Note the module itself does **not** process payments,
  it delegates that to Commerce.

Installing Membership with Composer pulls in these dependencies. There are no PHP
library requirements.

## Install with Composer

From the project root:

```bash
composer require drupal/membership -W
```

The `-W` (`--with-all-dependencies`) flag lets Composer install State Machine,
Entity API and Commerce and update any shared dependencies as needed.

> **Using DDEV?** Prefix Composer and Drush with `ddev` when you run from your host
> machine — `ddev composer require drupal/membership -W`, `ddev drush …`. Inside the
> container (`ddev ssh`) run them without the prefix.

## Enable the module

```bash
drush en membership -y
```

State Machine, Entity API and Commerce are enabled automatically as dependencies if
they are not already on.

## Grant permissions

Membership does not define permissions of its own — access uses the **per‑bundle CRUD
permissions generated by the Entity API module** for each membership type. After
creating your membership types, grant the relevant create/view/update/delete
permissions to the appropriate roles at **People → Permissions**
(`/admin/people/permissions`).

## Verify it worked

Once enabled, you should be able to manage **membership types** under **Structure**
and create **memberships** as content entities. Create a test membership type bound
to the bundled **Manual (on‑site)** provider and confirm you can add a membership of
that type. See "How to use it" on the [overview page](../index.md) for the full
workflow — and reconsider whether **Commerce License** better fits your case before
building on this framework.

Media Stream adds HTML5 audio/video formatters for link fields on media entities.

---

Media Stream enables HTML5 `<audio>` and `<video>` formatters for link fields on Media entities — so a media entity that stores a stream/file URL in a link field can render it as a native HTML5 player, supporting streaming audio/video without extra embed code.

It's a display formatter with no content or access role of its own. Depends on core `media`; supports Drupal 9, 10, and 11.

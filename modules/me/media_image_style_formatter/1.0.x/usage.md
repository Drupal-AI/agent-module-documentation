Media Image Style Formatter extends the media formatter with image styles.

---

Media Image Style Formatter **extends the media formatter to render a media image through a chosen image
style** — so a media (image) reference field can output a styled derivative directly, rather than the original.
It depends on core Media, in the Custom package.

Use it to apply image styles to media references. It is a media/content-display feature; images follow core
media/image access and it has no access-control role. Select an image style on the media formatter.

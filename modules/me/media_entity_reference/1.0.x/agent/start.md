# Media Entity Reference — agent index

Provides a **media entity type/field to reference other entities** (use referenced content via the media
library/field). Depends on core `media_library`, `media`. Version **1.0.0**. Core `^10||^11`.

Media/fields — referenced entities follow their own access; no access role.

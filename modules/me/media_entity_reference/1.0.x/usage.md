Media Entity Reference provides a media entity to reference entities.

---

Media Entity Reference provides a **media type that references other entities** — letting a media item wrap
an entity reference, so referenced content can be used through the media library/field workflow. It depends on
core Media Library and Media.

Use it to surface referenced entities as media. It is a media/fields feature; referenced entities follow their
own access on display and it has no access-control role. Configure the media-reference type and field.

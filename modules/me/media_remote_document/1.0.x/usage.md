Remote Document adds a media source that embeds documents from oEmbed providers.

---

Remote Document provides a media source for various oEmbed document providers — letting editors add documents (e.g. hosted document viewers) as media entities via their oEmbed URL, so remote documents can be embedded consistently through the Media system.

It embeds via oEmbed providers (the document is hosted remotely). Depends on core `media`; supports Drupal 10 and 11.

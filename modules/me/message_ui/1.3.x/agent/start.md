# Message UI — agent index

Web UI (routes + forms) for **Message** entities: create/view/edit/delete + bulk delete, with
granular per-template permissions. Depends on `message` and `views`. No settings page
(`configure: null`), no config object, no Drush.

- **Routes & forms (add/view/edit/delete/multi-delete)** → [configure/routes.md](configure/routes.md)
- **Permissions, including the per-template permission callback** → [permissions/permissions.md](permissions/permissions.md)
- **The `message_ui_views_contextual_links` plugin type (view/edit/delete)** → [plugins/contextual-links.md](plugins/contextual-links.md)
- **Hooks the module invites (`message_ui.api.php`)** → [hooks/hooks.md](hooks/hooks.md)

Submodule: **message_notify_ui** (adds a "Send" form) →
`../modules/message_notify_ui/1.3.x/agent/start.md`.

Key facts: create form route `message_ui.add` = `/message/add/{message_template}`; list route
`message_ui.add_page` = `/message/add`; view `entity.message.canonical` = `/message/{message}`.
Per-template permissions are generated by `MessagePermissions::messageTemplatePermissions()`:
`view|update|create|delete <template_id> message`.

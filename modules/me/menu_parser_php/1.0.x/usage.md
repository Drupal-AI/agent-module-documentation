Parse decoupled-menu linksets in PHP.

---

Decoupled Menu Parser PHP parses menu linksets as served by decoupled menus — a PHP parser for the linkset format that core's Decoupled Menus feature exposes, so server-side code can consume/normalise a decoupled menu structure. It's a developer utility (no code execution — it parses the linkset data). Supports Drupal 9, 10, and 11.

Menu Export CSV provides a CSV export for menu links.

---

Menu Export CSV **provides a CSV export of menu links** — exporting a menu's link structure (titles, URLs,
hierarchy) to CSV for review, documentation or migration. It depends on core Menu UI, in the Custom package.

Use it to export a menu to CSV. It is an administration/export feature run by admins; the export reflects menu
config (admin data) and it has no access-control role. Export the menu to CSV.

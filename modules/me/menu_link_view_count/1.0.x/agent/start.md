# Menu Link View Count — agent index

Adds a **view/usage count to menu link items** (show a number/badge alongside a menu link — "Messages (3)").
Depends on core `views`; provides permissions. Version **1.0.0-beta3**. Core `^10||^11`.

Site-structure/navigation — count is derived data affecting menu presentation; no access role.

Menu Link View Count allows a count to be added to menu link items.

---

Menu Link View Count lets you add a count to menu link items — displaying a number (e.g. a view count,
item count, or badge) alongside a menu link, useful for showing counts like "Messages (3)" in navigation. It
depends on core Views, provides its own permissions.

Use it to show counts on menu links. It is a site-structure/navigation feature affecting menu presentation;
the count is derived data and it has no access-control role. Configure the count on the menu link.

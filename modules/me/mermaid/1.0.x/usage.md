Mermaid provides integration with the Mermaid diagram library.

---

Mermaid integrates the **Mermaid JavaScript library** — rendering diagrams (flowcharts, sequence, gantt,
etc.) from a simple text syntax, with a `mermaid_filter` (render Mermaid in text-format content) and
`mermaid_graphapi` submodule. It is in the Mermaid package.

Use it to render text-defined diagrams. It is a content-display feature. Note: the `mermaid_filter` renders
diagram **source that authors write** — Mermaid runs client-side on that text, so keep the filter on text
formats available to **trusted authors** (as with any content that becomes active client-side rendering) and
rely on the text format's overall configuration. It has no access-control role. Enable the diagram rendering.

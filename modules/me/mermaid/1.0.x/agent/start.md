# Mermaid — agent index

Integrates the **Mermaid JS library to render diagrams from text** (`mermaid_filter`, `mermaid_graphapi`
submodules). Version **1.0.0-alpha4**. Core `^10||^11`.

Content-display — the `mermaid_filter` renders **author-written** diagram source client-side (keep the filter to
trusted-author text formats). No access role.

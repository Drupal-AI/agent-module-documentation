# Media Thumbnails Client Video — agent index

**Generates video thumbnails client-side via JavaScript**, bypassing server FFmpeg. Depends on `media_thumbnails`.
Version **1.0.0**. Core `^9.3||^10||^11`.

Media — generation runs in the uploader's browser; the thumbnail is handled as uploaded image data; no access
role.

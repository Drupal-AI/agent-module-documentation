Media Thumbnails Client Video generates video thumbnails client-side via JavaScript (no server FFmpeg).

---

Media Thumbnails Client Video **generates video thumbnails in the browser** — using JavaScript to capture a
frame from an uploaded video and produce a thumbnail client-side, avoiding the need for server-side FFmpeg. It
depends on the Media Thumbnails module.

Use it to get video thumbnails without FFmpeg. It is a media feature; thumbnail generation runs in the uploader's
browser and the result is stored as the media thumbnail, and it has no access-control role. Note: because
generation is client-side, the produced thumbnail is supplied by the client (a benign image), so it's handled as
uploaded image data. Configure the thumbnail generation.

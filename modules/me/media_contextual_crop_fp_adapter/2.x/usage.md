Media Contextual Crop Focal Point Adapter provides a plugin for using Focal Point within Media Contextual Crop, adapting focal-point cropping to contextual crops.

---

Contextual cropping (different crops per usage context) and Focal Point (focus-aware cropping) are two cropping approaches; this adapter lets Focal Point be used within Media Contextual Crop. It is a media-cropping integration with no security surface. Adopt where both modules are used and focal-point-driven contextual crops are wanted.

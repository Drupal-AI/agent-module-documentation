# Metatag Paths — agent index

Assigns **meta tags based on URL path patterns** (e.g. `/products/*` → specific metatags, without per-entity
config). Depends on core `path_alias`, `metatag`. Version **1.0.0-alpha4**. Core `^10.4||^11`.

SEO — adds meta tags to matching pages; no content/access role.

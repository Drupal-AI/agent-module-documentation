Metatag Paths allows assigning meta tags based on URL path patterns.

---

Metatag Paths lets you **assign meta tags based on URL path patterns** — so pages matching a path pattern
(e.g. `/products/*`) get specific meta tags, without attaching metatag config to each entity. It depends on
core Path Alias and the Metatag module, in the SEO package.

Use it to set path-based meta tags. It is an SEO feature adding meta tags to matching pages; it reflects
SEO/metadata and has no content or access role. Configure the path→metatag rules.

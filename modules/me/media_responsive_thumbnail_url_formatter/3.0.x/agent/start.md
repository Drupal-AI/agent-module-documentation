# Media Responsive Thumbnail URL Formatter — agent index

A media-reference field **formatter that outputs a responsive thumbnail's URL** (the derivative URL vs a
rendered image — for decoupled/JS/template use). Depends on core `media`. Version **3.0.0**. Core
`^9.3||^10||^11`.

Content-display/formatter — media/derivative respects normal file access; no access role.

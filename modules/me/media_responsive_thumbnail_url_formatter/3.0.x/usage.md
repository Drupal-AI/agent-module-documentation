Media Responsive Thumbnail URL Formatter provides a field formatter for media reference fields.

---

Media Responsive Thumbnail URL Formatter provides a field formatter for media-reference fields that
outputs a responsive thumbnail's **URL** (rather than a rendered image) — useful for decoupled/JS contexts or
templates that need the derivative URL to build their own markup. It depends on core Media, in the Custom
package.

Use it to get a responsive thumbnail URL from a media reference. It is a content-display/formatter feature;
the media/derivative respects normal file access and it has no access-control role. Select the URL formatter
on the media field.

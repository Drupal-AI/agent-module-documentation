Message Push relays Message-module notifications through the Push Framework.

---

Message Push integrates the Message module with the Push Framework — so messages generated in Drupal can be delivered as push notifications through the Push Framework's channels, unifying on-site messages with push delivery. It adds a subscription type.

Administration is gated by `administer subscription_type`. Depends on `message` and `push_framework`; supports Drupal 10.2+ and 11.

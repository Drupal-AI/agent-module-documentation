# Menu UI Asynchronous Widget — agent index

Provides an **asynchronous (AJAX) menu-selection widget on node forms** (load menu/parent options on demand —
performance on very large menus). Depends on core `menu_ui`. Version **1.0.3**. Core `^9.2||^10||^11`.

Admin/UX — affects the node-form menu widget; no content/access change. No access role.

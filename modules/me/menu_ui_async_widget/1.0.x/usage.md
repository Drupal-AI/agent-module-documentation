Menu UI Asynchronous Widget provides an asynchronous widget for menu UI on node forms.

---

Menu UI Asynchronous Widget replaces the node form's menu-selection widget with an asynchronous (AJAX)
one — loading menu/parent options on demand, which improves performance and usability on sites with very
large menus (where the default synchronous widget is slow to build). It depends on core Menu UI, in the
Administration package.

Use it on sites with large menus to speed up the node menu widget. It is an administration/UX feature
affecting the node-form menu widget; it does not change content or access and has no access-control role.
Enable it to use the async widget.

Media integration for Ubicast videos.

---

Media Ubicast provides Media integration for Ubicast videos — a media source/type for embedding videos hosted on Ubicast (an enterprise video platform), so editors add Ubicast videos through the Media Library and they render with the Ubicast player. Depends on core `media`; supports Drupal 10 and 11.

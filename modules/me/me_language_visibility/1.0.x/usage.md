Language Visibility - Mercury Editor provides a language-visibility behavior within Mercury Editor.

---

Language Visibility - Mercury Editor **adds a language-visibility behavior to Mercury Editor** — letting
components built in Mercury Editor be shown/hidden based on the current language, for multilingual page building. It
depends on the Mercury Editor module.

Use it to vary Mercury Editor components by language. It is a content-editing/multilingual feature; it controls
component display by language and has no access-control role. Configure the language visibility on components.

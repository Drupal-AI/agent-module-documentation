Media Image Display Entity View allows selecting a display mode when rendering a media reference.

---

Media Image Display Entity View lets you **choose the view mode used when rendering a referenced media
image** — so a media-reference field renders the media entity in a selected display mode (rather than a fixed
one), with a `ckeditor_support` submodule for embeds. It depends on core Media, in the AB package, core 11.4+.

Use it to control how referenced media renders. It is a media/content-display feature; media follows core
media/file access and it has no access-control role. Select the display mode on the media reference.

Media Library Favorites lets users mark media items as favorites in the media library.

---

Media Library Favorites adds a favorite-toggle field to the media library view — so editors can mark frequently used media as favorites and filter/find them quickly, improving media reuse in a large library.

Access to favoriting is gated by `allow media favorites`. Depends on core `media` and `media_library`; supports Drupal 10 and 11.

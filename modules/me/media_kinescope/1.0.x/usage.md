Media Kinescope adds a media source for embedding Kinescope.io videos.

---

Media Kinescope **provides a media source for Kinescope.io videos** — letting editors add Kinescope-hosted
videos as media entities for display, integrating the Kinescope video platform. It depends on core Media.

Use it to embed Kinescope videos as media. It is a media-integration feature; it embeds third-party Kinescope
content (loaded from Kinescope) and has no access-control role. Configure the Kinescope media source.

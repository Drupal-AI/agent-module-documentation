Media Entity Podigee creates a media source for embedding Podigee.

---

Media Entity Podigee **creates a media source for embedding Podigee podcast episodes** — adding Podigee as
a Drupal media source (via the oEmbed Providers module) so episodes can be managed as media and embedded. It
depends on core Media and oEmbed Providers.

Use it to embed Podigee podcasts as media. It is a media/integration feature. Note: like other oEmbed sources,
remote content comes from **Podigee via oEmbed** (a configured provider — bounded), and the player loads from
Podigee (third-party embed). It has no access-control role. Configure the Podigee media source.

# Media Entity Podigee — agent index

Creates a **media source for embedding Podigee podcast episodes** (via oEmbed Providers). Depends on core
`media`, `oembed_providers`. Version **1.0.0-alpha3**. Core `>=10`.

Media/integration — remote content via **Podigee oEmbed** (bounded); player from Podigee (third-party). No access
role.

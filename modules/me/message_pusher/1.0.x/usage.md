Deliver Message entities to clients in real time via Pusher/Soketi.

---

Message Pusher adds a Pusher (or Soketi / pws) notifier to Message Notify, delivering Message entities to subscribed clients in real time — for notifications, activity streams, chat, dashboards, broadcasts — anything modeled as a Message.

The Pusher app credentials are handled via the `pusher_api` module (store securely, env-backed). Depends on `message`, `message_notify`, and `pusher_api`; supports Drupal 10.2+, 11, and 12.

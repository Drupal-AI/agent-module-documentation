Menu Animate applies Animate.css animations to Drupal menus.

---

Menu Animate integrates cross-browser CSS animations from Animate.css into Drupal menus — so dropdown/menu transitions can use polished, configurable CSS animations (fade, slide, etc.) without custom code.

It's a theming enhancement with no content or access role of its own. Depends on core `menu_ui`; supports Drupal 8.8+ through 11.

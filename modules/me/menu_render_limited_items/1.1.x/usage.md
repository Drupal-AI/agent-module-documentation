Limit the number of menu items rendered (level one).

---

Menu Render Limited Items limits the number of menu items to display (render) instead of limiting the entries in admin — so a menu can show only the first N top-level items (currently level one), useful for compact navigation or 'more' patterns, without deleting the extra menu links. Depends on core `block` and `menu_ui`; supports Drupal 10 and 11.

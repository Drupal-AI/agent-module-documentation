# Media Remote HLS — agent index

Adds a media type for **embedding remote HLS (HTTP Live Streaming) streams** (`.m3u8`). Depends on
`media_remote`. Version **1.1.0**. Core `^9||^10||^11`.

Media — stream served from its **remote source** (third-party URL); media access follows core media/file
access; no access role.

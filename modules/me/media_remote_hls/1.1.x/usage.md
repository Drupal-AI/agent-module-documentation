Media Remote HLS allows embedding remote HLS streams.

---

Media Remote HLS extends **Media Remote** to embed **remote HLS (HTTP Live Streaming)** streams — so an
HLS stream URL (`.m3u8`) can be added as a media entity and played on the site. It depends on the Media Remote
module, in the Media package.

Use it to embed HLS video/live streams as media. It is a media feature; the stream is served from its **remote
source** (a third-party URL played in the browser), media access follows core media/file access, and it has no
access-control role. Configure the HLS media.

Metatag UI Enhancements improves Metatag image management with defaults, better tokens and Media Library.

---

Metatag UI Enhancements **improves the Metatag image UI** — adding default images, better tokens and Media
Library integration for image meta tags (Open Graph/Twitter images), making image metadata easier to manage. It
depends on core Media Library and the Metatag module.

Use it for easier Metatag image management. It is an SEO feature; it enhances the meta tag admin UI and has no
content or access role. Configure the metatag defaults and image handling.

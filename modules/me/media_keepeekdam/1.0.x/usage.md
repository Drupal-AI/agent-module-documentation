Integrate the Media ecosystem with the Keepeek DAM.

---

Media: Keepeek DAM integrates the Media module ecosystem with Keepeek DAM — so editors can browse and use Keepeek-managed assets (images, responsive images, videos) from the Media Library, with the DAM handling storage/delivery.

The Keepeek API credentials are admin-configured and should be stored securely (env-backed), never committed. Depends on core `media`, `media_library`, `file`, `image`, `responsive_image`, and `language`; supports Drupal 10.2+ and 11.

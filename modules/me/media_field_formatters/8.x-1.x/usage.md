Media Field Formatters provides a collection of miscellaneous field formatters for working with media entities.

---

Media Field Formatters provides a collection of miscellaneous field formatters for media — extra ways to
render media-reference fields (e.g. rendering specific media properties, source values or alternative
displays) beyond the defaults. It depends on core Media, in the Media package.

Use it for additional media-field display options. It is a content-display/formatter feature; the media is
rendered respecting its own access (only accessible media renders), and it has no access-control role. Select
the desired formatter on the media-reference field.

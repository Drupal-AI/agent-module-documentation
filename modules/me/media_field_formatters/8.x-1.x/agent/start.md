# Media Field Formatters — agent index

A collection of **miscellaneous field formatters for media entities** (extra ways to render media-reference
fields). Depends on core `media`. Version **8.x-1.1**. Core `^10.3||^11`.

Content-display/formatter — media rendered respecting its own access; no access role.

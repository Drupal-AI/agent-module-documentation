Metatag Simple Widget provides a simplified field widget for metatag.

---

Metatag Simple Widget provides a **simplified field widget for the Metatag module** — exposing only selected
meta-tag fields in a compact widget, instead of Metatag's full editor, so editors see a focused set of tags. It
depends on the Metatag module.

Use it to simplify meta-tag entry for editors. It is an SEO/content-editing feature affecting the Metatag
widget; it has no content or access role. Configure the simplified widget on metatag fields.

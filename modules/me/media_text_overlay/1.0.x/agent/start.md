# Media Text Overlay — agent index

**Helps create text overlay on images** (captions/hero text, responsive). Depends on core `image`,
`responsive_image`. Version **1.0.0-alpha5**. Core `^10||^11`.

Content-editing/display — overlay text is content rendered over the image (output safely); no access role.

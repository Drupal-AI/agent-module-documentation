Media Text Overlay helps create a text overlay on images.

---

Media Text Overlay **helps create text overlays on images** — a field type/formatter to place caption/overlay
text on top of images (hero banners, cards), with responsive image support. It depends on core Image and Responsive
Image.

Use it for text-over-image displays. It is a content-editing/display feature; the overlay text is content rendered
over the image and it has no access-control role. Note: overlay text is regular content — ensure it's output
safely. Configure the text overlay.

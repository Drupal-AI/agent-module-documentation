Media Entity Calameo provides a Calameo media provider.

---

Media Entity Calaméo adds a **Media provider for Calaméo** — the online document/publication platform — so
a Calaméo publication URL can be added as a Drupal media entity and embedded (flipbook viewer). It depends on
core Media, provides its own permissions, in the Media package.

Use it to embed Calaméo publications as media. It is a media/integration feature; the publication is hosted by
**Calaméo** and embedded (third-party content), media access follows core media/file access, and it has no
access-control role beyond its permission. Configure the Calaméo media.

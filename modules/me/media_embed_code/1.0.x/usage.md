A media source/field for embedding third-party script/iframe snippets.

---

Media Embed Code provides an Embed Code media source and field type for embedding third-party script/iframe snippets as media — so an editor can paste an embed code (from a service that provides script/iframe snippets) and manage it as a media entity in the Media Library.

Because it stores raw embed HTML (script/iframe), restrict who can add embed-code media (a stored-XSS/embed risk if untrusted users can paste arbitrary script). Depends on core `media` and `media_library`; supports Drupal 10.3+ and 11.

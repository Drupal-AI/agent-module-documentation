Menu Link Revisions provides revision management for menu links.

---

Menu Link Revisions **provides revision management for menu links** — keeping a revision history of
menu-link-content changes (title, URL, weight) so edits can be reviewed or reverted. It depends on core Menu Link
Content and Menu UI, provides its own permissions, in the Custom package.

Use it to track/revert menu link changes. It is a site-structure/governance feature; menu links are
admin/editor content and it has no access-control role beyond its permission. Configure revisioning for menu
links.

Make Media Library widget texts configurable.

---

Media Library Widget Texts makes media library widget texts configurable — so the labels/help/empty-state text shown in the Media Library selection widget can be customised (per-site wording, translations, clearer guidance) without overriding templates. Depends on core `media_library`; supports Drupal 10 and 11.

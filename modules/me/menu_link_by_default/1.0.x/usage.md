Enable 'Provide menu link' by default on chosen content types.

---

Menu Link by Default enables 'Provide menu link' on specified content types by default — so when creating content of those types, the menu-settings widget defaults to on (with a chosen parent), reducing the chance editors forget to add a page to the menu. Depends on core `menu_ui` and `node`; supports Drupal 10.2+ and 11.

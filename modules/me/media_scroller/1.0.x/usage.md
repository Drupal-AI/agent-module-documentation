Media Scroller provides a Media Scroller field formatter for image fields.

---

Media Scroller provides a **field formatter that renders image/media fields as a horizontal scroller** —
using the Slick carousel — so multiple images display as a swipeable scrolling strip. It depends on core Image
and Slick, in the Field package.

Use it to display media as a scroller. It is a media/content-display feature; images follow core media/file
access and it has no content or access role. Choose the Media Scroller formatter on an image field.

# Media Scroller — agent index

A **Slick-based media/image field formatter that renders a horizontal scroller** (swipeable image strip).
Depends on core `image`, `slick`. Version **1.0.6**. Core `^10.3||^11`.

Media/content-display — images follow core media/file access; no content/access role.

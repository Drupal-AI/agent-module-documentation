# Mercury Editor Inline Editor — agent index

**DEPRECATED, empty submodule.** Ships only `mercury_editor_inline_editor.info.yml` (no code,
no services, routes, config, or permissions). Kept for backwards compatibility. Its
functionality now lives in the separate project **`mercury_editor_live_edit`** — install that
instead.

There are no capabilities to document (nothing to configure, extend, or call). Depends on
`layout_paragraphs`. If found enabled, it is safe to uninstall once you have moved to
`mercury_editor_live_edit`.

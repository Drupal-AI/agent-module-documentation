Message Time adds options for message time delay, controlling how long status messages are shown.

---

Message Time adds time-delay options for messages — letting you configure how long status/notification
messages are displayed (e.g. auto-dismiss after N seconds) rather than staying until dismissed. It is
configured at `message_time.settings_form`.

Use it to control message display duration. It is a UI/messaging feature affecting how long messages show;
it has no content or access role. Configure the message time/delay settings.

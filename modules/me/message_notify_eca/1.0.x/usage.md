Message Notify ECA provides an ECA action to send a Message Notify notification email.

---

Message Notify ECA **provides an ECA action to send message notifications** — letting Event-Condition-Action
models trigger a Message Notify email/notification (from the Message stack), so notification emails can be
automated with no-code ECA. It depends on the ECA and Message Notify modules.

Use it to send notification emails from ECA. It is an automation feature. Data-handling note: notifications go to
**recipients (email/PII)** and can be triggered by events — ensure automated sends respect consent and don't leak
message content to unintended recipients. It has no access-control role. Use its action in ECA models.

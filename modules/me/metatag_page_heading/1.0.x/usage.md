Metatag Page Heading allows the user to override the page heading (h1) for SEO purposes.

---

Metatag Page Heading extends the Metatag module to let you override a page's heading (the `<h1>`) —
separately from the page title/meta title — for SEO, so the visible H1 can be optimized independently. It
depends on the Metatag module, in the SEO package.

Use it to control the H1 independently for SEO. It is an SEO/display feature affecting the page heading; it
does not change content or access and has no access-control role. Configure the page-heading meta tag.

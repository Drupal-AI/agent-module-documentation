# Metatag Page Heading — agent index

Lets you **override the page heading (`<h1>`) for SEO** (independently of the page/meta title) via Metatag.
Depends on `metatag`. Version **1.0.0-beta4**. Core `^10||^11`.

SEO/display — affects the page heading; no content/access change. No access role.

MediaWiki API integrates Drupal with a MediaWiki instance via its API (e.g. rendering wiki content).

---

MediaWiki API allows Drupal to use the MediaWiki API — providing access to an existing MediaWiki instance so content (e.g. wiki pages) can be fetched and rendered in Drupal, including a text filter that pulls MediaWiki content from the configured wiki API URL.

The API URL is admin-configured (not user-supplied), so it fetches only the trusted wiki. Supports Drupal 8 through 11.

Media Filter provides a text filter for embedding media in content.

---

Media Filter **provides a text filter for media** — enabling media embeds/references to be rendered from
within processed text (a filter that turns media tokens/markup into rendered media). It works across core 8–11.

Use it to render media embeds in text. It is a content-display/filter feature; embedded media follows normal media
access and it has no access-control role. Enable the filter in a text format.

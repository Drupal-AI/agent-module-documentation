Media Library Media Modify Focal Point adds Focal Point (image crop point) support within the Media Library Media Modify modals.

---

Media Library Media Modify Focal Point adds Focal Point support to the Media Library Media Modify
modals — so editors can set an image's focal point (the crop-focus point used by focal-point image styles)
directly while modifying media in the media library, rather than in a separate step. It bridges the Media
Library Media Modify and Focal Point features.

Use it where editors work with focal points in the media library modify workflow. It is a media/editorial
feature affecting image crop-focus configuration; it does not change media access. Enable it alongside the
relevant Media Library Media Modify and Focal Point setup.

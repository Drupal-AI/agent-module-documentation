# Media Library Media Modify Focal Point — agent index

Adds **Focal Point** (image crop-focus) support to **Media Library Media Modify** modals — set an image's
focal point while modifying media in the library. Version **1.0.0-alpha2**. Core `^9.3||^10||^11`.

Media/editorial feature — affects crop-focus config, not media access. Enable alongside Media Modify +
Focal Point.

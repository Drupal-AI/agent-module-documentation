Embed configurable MeetMy.bot chatbot blocks.

---

MeetMy.bot Clone is an integration module for MeetMy.bot Clone (by Eternity.ac) for business — it provides configurable bot interface blocks so a site can embed a MeetMy.bot conversational assistant widget on pages.

The MeetMy.bot account/embed credentials are admin-configured and should be stored securely (env-backed). Depends on core `block` and `system`; supports Drupal 10 and 11.

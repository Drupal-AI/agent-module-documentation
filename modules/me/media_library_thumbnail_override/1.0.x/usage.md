Media Library Thumbnail Override overrides thumbnails for non-image media in the Media Library.

---

Media Library Thumbnail Override **overrides the thumbnails shown for non-image media** (video, audio,
documents, remote media) in the Media Library — so non-image media items show a more meaningful thumbnail
instead of a generic icon. It depends on core Media and Media Library.

Use it to improve non-image media thumbnails in the library. It is a media/admin-UX feature affecting the
library display; it has no content or access role. Configure the thumbnail overrides.

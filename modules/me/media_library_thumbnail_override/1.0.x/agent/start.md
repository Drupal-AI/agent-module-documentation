# Media Library Thumbnail Override — agent index

Overrides the **thumbnails shown for non-image media (video/audio/docs) in the Media Library** (vs a generic
icon). Depends on core `media`, `media_library`. Version **1.0.0**. Core `^10||^11`.

Media/admin-UX — affects the library display; no content/access role.

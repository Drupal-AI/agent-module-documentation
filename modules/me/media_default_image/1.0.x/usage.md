Media Default Image provides a default image to replace missing/not-found images.

---

Media Default Image **provides a fallback default image** — showing a configured default/placeholder image when
a referenced image/media is missing or not found, so broken images are replaced gracefully. It depends on core
Media and File.

Use it to avoid broken images. It is a media/display feature; it substitutes a default image and has no access-control
role. Configure the default image.

Mercury Editor Content Lock provides lightweight integration with the Content Lock module.

---

Mercury Editor Content Lock integrates the Content Lock module with the Mercury Editor — so when a user
edits content in Mercury Editor, Content Lock's pessimistic locking applies (preventing two users editing the
same content simultaneously and clobbering each other). It depends on the Mercury Editor and Content Lock
modules, in the Mercury Editor package.

Use it on Mercury Editor sites to add edit-locking. It is a content-editing/workflow feature; the locking is
governed by Content Lock, and it has no access-control role of its own. Enable it to apply content locking in
Mercury Editor.

Use a single file input for multiple media types.

---

Media Abstract lets you use a single file input for multiple media types — so instead of separate fields per media type (image, video, document), one upload field accepts any of them and routes the file to the right media type based on its kind, simplifying the editing UI. Depends on core `file` and `media`; supports Drupal 9, 10, and 11.

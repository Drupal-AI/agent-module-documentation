Message Filter filters Drupal status messages with role-based rules and bypass strategies.

---

Message Filter **provides advanced filtering of Drupal status messages** — suppressing/altering the system
status messages shown to users based on role-based rules (with bypass strategies), to declutter the UI or hide
technical messages from non-admins. It depends on core System and provides its own permissions.

Use it to control which status messages users see. It is a UI/administration feature; it filters displayed
messages and has no content or access role beyond its permission. Note: hide only cosmetic/technical messages —
don't suppress messages users need (errors/validation). Configure the message filter rules.

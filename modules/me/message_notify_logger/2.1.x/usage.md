Advanced logging for Message Notify.

---

Message Notify Logger provides advanced logging for the Message Notify module — recording detailed logs of notification deliveries (which message, recipient, channel, success/failure) so teams can audit and debug message-based notifications. Depends on `message_notify`; supports Drupal 9, 10, and 11.

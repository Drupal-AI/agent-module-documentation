# Media Bulk Zip Upload (media_bulk_zip_upload) — agent index

Adds a bulk-upload form that expands one uploaded **ZIP archive** into a separate media
entity per contained file, for the media types you opt in. Depends on core `media`.
PHP >= 8.1, core `^10.2 || ^11`. info.yml declares no `configure:` key, but a real settings
page exists at `/admin/config/media/media-bulk-zip-upload-config`
(route `media_bulk_zip_upload.settings`, gated by `administer media`).

Provides generated per-media-type permissions, one config object, a `media_bulk_zip_upload`
form mode, and a pre-save event. No Drush commands, no plugin types.

- **Enable media types, the settings/config object, the bulk form mode, and exactly how the
  upload + ZIP extraction + media creation work** → [configure/settings.md](configure/settings.md)
- **Who can use the form (generated per-type permission + the access model)** → [permissions/permissions.md](permissions/permissions.md)
- **Altering each media entity before it is saved** → [events/presave.md](events/presave.md)

Key facts:
- Config object `media_bulk_zip_upload.settings`, single key `media_types` (sequence of enabled
  media-type ids). Schema: `config/schema/media_library_bulk_upload.schema.yml` (file misnamed;
  it declares `media_bulk_zip_upload.settings`).
- Upload form route `media_bulk_zip_upload.form`, path `/media/add/{media_type}/bulk`, form class
  `MediaBulkZipUploadForm` (form id `media_bulk_zip_upload_form`), access via
  `_custom_access: MediaBulkZipUploadForm::checkAccess`.
- Permission per type: `use media bulk zip upload for {media_type_id}`, generated by
  `MediaBulkZipUploadPermissions::permissions()` through a `permission_callbacks` entry — not
  literal strings in the YAML.
- A local action ("Bulk upload &lt;type&gt; media") is derived onto `entity.media.collection`
  (`/admin/content/media`) for each enabled type (deriver `MediaBulkZipUploadLocalActions`,
  base plugin id `media_bulk_zip_upload.actions`).
- Event `Drupal\media_bulk_zip_upload\Event\MediaBulkZipUploadPreSaveEvent`, dispatched by class
  name via the `event_dispatcher` service.
- Form mode `media_bulk_zip_upload` (form-display `media.{type}.media_bulk_zip_upload`) decides
  which shared fields the bulk form shows; created for existing types by `hook_install` and for
  newly added types by `media_bulk_zip_upload_form_alter` in the `.module` file.

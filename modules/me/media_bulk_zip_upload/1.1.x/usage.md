Media Bulk Zip Upload lets an editor upload one ZIP archive and have every file inside it become a separate media entity, instead of adding hundreds of items one at a time.

---

Populating a media library from an existing folder of assets is a chore the media library was not designed for, and the workarounds — a migration, a Drush script, or an afternoon of clicking — are all disproportionate for what is conceptually one action. This module adds a bulk form at `/media/add/{media_type}/bulk`, alongside the normal media add form, that accepts a `.zip` archive and expands it into media entities of the chosen type. You opt each media type in from a settings page at `/admin/config/media/media-bulk-zip-upload-config` (behind `administer media`); doing so also adds a "Bulk upload {type} media" action to the media collection at `/admin/content/media`. Two design details are worth noting. Access to the bulk form uses a `_custom_access` callback (`MediaBulkZipUploadForm::checkAccess`) rather than a flat permission, so it combines this module's per-type permission with the media type's own core create access; and the permissions themselves are generated by `MediaBulkZipUploadPermissions::permissions()` through a `permission_callbacks` entry, which means they are per media type and will not be found by grepping the YAML. On extraction each file is filtered against the target media type's allowed file extensions, saved to that type's source-field directory, and turned into a media entity whose name is taken from the filename; a dedicated `media_bulk_zip_upload` form mode controls which shared fields the form shows, and a `MediaBulkZipUploadPreSaveEvent` lets a subscriber alter each media before it is saved. Requirements are PHP 8.1+, core `media`, and core `^10.2 || ^11`.

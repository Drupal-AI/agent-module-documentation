Bulk Metatag AI Generator generates SEO metatags for multiple nodes at once using AI.

---

Bulk Metatag AI Generator **generates SEO metatags for many nodes at once using AI** — running nodes through
an AI provider (via the Metatag AI module) to auto-fill meta title/description in bulk, saving manual SEO work. It
depends on the Metatag AI module.

Use it to bulk-generate meta tags. It is an SEO/AI feature. Security/data handling: it **sends node content to the
AI provider** (external egress — confirm acceptable) to generate meta tags; store the AI provider key as a secret
(via the AI/Metatag AI module). Note bulk AI runs can incur cost and should be reviewed before publishing. It has no
access-control role. Configure the AI provider and run the bulk update.

# Menu Parent Form UI — agent index

Replaces the single combined **parent-menu dropdown with cascading select boxes** (menu → parent →
sub-parent) — easier on large/deep menus. Depends on core `menu_ui`. Config at
`menu_parent_form_ui.settings`. Version **1.0.0**. Core `^10.2||^11`.

Content-editing/form-UI — affects how the parent is chosen, not menus/access.

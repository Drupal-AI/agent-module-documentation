Menu Parent Form UI adjusts the parent-menu-item selector to be a series of cascading select boxes instead of one long combined dropdown.

---

Menu Parent Form UI improves the parent-menu-item selector on menu-link forms — replacing the single,
long combined dropdown (which flattens the whole menu tree into one list) with a series of cascading
select boxes (choose menu, then parent, then sub-parent). On large menus this is far easier to navigate
than the giant flat list. It depends on core Menu UI and is configured at `menu_parent_form_ui.settings`.

Use it on sites with large/deep menus where the default parent selector is unwieldy. It is a
content-editing/form-UI feature affecting how the parent is chosen; it does not change menus or access.
Enable it to improve the menu-link editing experience.

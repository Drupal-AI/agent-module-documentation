Mercury Editor Page Templates provides configurable page templates for Mercury Editor.

---

Mercury Editor Page Templates **provides configurable page templates for Mercury Editor** — predefined page
layouts/starting points editors can pick when building pages in Mercury Editor (with Layout Paragraphs), speeding
up consistent page creation. It depends on core File, Mercury Editor, Layout Paragraphs and Paragraphs, and
provides its own permissions.

Use it to give editors page-template starting points. It is a content-editing/site-building feature; templates are
admin-defined starting content and it has no access-control role beyond its permission. Configure the page
templates.

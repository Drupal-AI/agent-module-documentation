Pinto Entity renders entities via Pinto components (object-oriented rendering).

---

Pinto Entity provides a render takeover for entities using Pinto components — Pinto is an object-oriented component/render system, and this module lets entities be rendered through Pinto components instead of the standard render pipeline, for developers adopting a component-driven rendering approach.

It's a developer/rendering tool with no content or access role of its own. Depends on `pinto`; supports Drupal 10.5+ and 11.2+.

Pipedrive integrates Drupal with the Pipedrive CRM, syncing data such as leads/deals to Pipedrive.

---

Pipedrive integrates Drupal with the Pipedrive CRM — connecting to a Pipedrive account to sync data
(leads, deals, contacts) from Drupal into Pipedrive, for example turning form submissions into Pipedrive
leads. It connects via the Pipedrive API.

Use it to push Drupal data into Pipedrive CRM. The security/privacy-relevant points: store the Pipedrive API
token as a secret (not plaintext config), and the data synced (contact/lead details — personal data) is
transmitted to Pipedrive — obtain appropriate consent and disclose the data sharing (GDPR). It is an
integration/CRM feature with no access-control role. Configure the Pipedrive connection and what syncs.

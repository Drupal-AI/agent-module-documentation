# Pipedrive — agent index

Integrates Drupal with the **Pipedrive CRM** (sync leads/deals/contacts via the Pipedrive API). Version
**2.x** (dev). Core `9.x||^10||^11`.

**Privacy:** store the Pipedrive API token as a secret; synced data (contact/lead details = PII) goes to
Pipedrive — consent + disclose (GDPR). No access role.

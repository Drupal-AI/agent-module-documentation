PID Field Set adds fields for minting/storing persistent identifiers (DOI, Handle, etc.).

---

Persistent Identifiers Field Set allows creating persistent identifiers (PIDs) of different types — such as DOIs, Handles, or ARKs — on content, building on the Persistent Identifiers module. It's aimed at research/repository sites that need to mint and store stable, citable identifiers for content.

Administration is gated by `administer pid_field_set configuration`. Depends on `persistent_identifiers`; supports Drupal 10 and 11.

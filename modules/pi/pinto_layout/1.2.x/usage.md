Pinto Layout provides Layout Discovery layouts built with the Pinto theming framework.

---

Pinto Layout **provides layouts built with Pinto** — registering Layout Discovery layouts defined via the
Pinto PHP theming framework, so Pinto-built layouts are available to Layout Builder/blocks. It depends on the Pinto
and core Layout Discovery modules.

Use it to use Pinto layouts. It is a theming/site-building feature; it registers layout plugins and has no content
or access role. Use the Pinto layouts in Layout Builder.

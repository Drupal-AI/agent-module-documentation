# Piano Analytics — agent index

Integrates **AT Internet / Piano Analytics** tracking (client tracker + `pianoanalytics_server` server-side
submodule). Provides permissions. Version **2.4.0**. Core `^10.3||^11`.

Third-party analytics — enables **visitor tracking** (GDPR/consent — combine with consent tooling); loads
Piano's **third-party JS** and/or sends events server-side; server **credentials** as secrets. No access role
beyond permission.

Picture Everywhere standardizes Drupal image rendering to always use a picture element.

---

Picture Everywhere **standardizes image rendering to always use a `<picture>` element** — so images are
consistently output as responsive `<picture>` markup (with sources), improving responsive-image consistency
across the site. It requires PHP 8.0 and depends on core Image, in the Media package.

Use it for consistent responsive `<picture>` output. It is a media/display feature affecting image markup; it
has no content or access role. Enable it to standardize image rendering.

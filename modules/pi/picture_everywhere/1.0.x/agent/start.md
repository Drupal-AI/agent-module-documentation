# Picture Everywhere — agent index

Standardizes **Drupal image rendering to always use a `<picture>` element** (consistent responsive markup).
Requires PHP 8.0. Depends on core `image`. Version **1.0.1**. Core `^9.4||^10||^11`.

Media/display — affects image markup; no content/access role.

Pinto Theme Helper helps build full themes using the Pinto framework.

---

Pinto Theme Helper **helps build full themes with Pinto** — providing rendering/helpers so themes can be built
with the Pinto PHP component/theming framework (a code-first theming approach). It works on core 10.5–11.2.

Use it to build Pinto-based themes. It is a theming/developer framework; it supports theme rendering and has no
content or access role. Build themes with Pinto.

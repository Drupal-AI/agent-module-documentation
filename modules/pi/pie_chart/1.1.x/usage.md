Pie Chart provides content and user data pie charts.

---

Pie Chart **provides a block/element to display a pie chart** — visualizing content or user data (e.g.
distribution by type/status) as a pie chart. It works across core 9–11.

Use it to add a pie-chart visualization. It is a content-display/visualization feature; the data reflects
content/user counts (following access where applicable) and it has no access-control role. Configure the pie
chart.

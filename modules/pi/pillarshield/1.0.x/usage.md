A Drupal connector for the PillarShield governance SaaS.

---

PillarShield is a Drupal connector for the PillarShield governance SaaS — sending site governance/compliance signals to PillarShield (pillarshield.co) so an organisation can monitor and govern its Drupal sites from that platform.

The PillarShield API credentials are stored via a Key entity (`key` dependency, env-backed), never committed; review what site data is sent to the SaaS. Depends on core `node` and `key`; supports Drupal 10 and 11.

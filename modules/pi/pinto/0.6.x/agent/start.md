# Pinto — agent index

A **theme object system** for building typed, reusable theme components as PHP objects (structured/OO vs loose
render arrays). Requires PHP 8.2. Version **0.6.0**. Core `^10.2||^11`.

Developer/theming — a component-object API; components render through normal theming; no content/access
role.

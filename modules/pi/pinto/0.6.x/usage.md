Pinto is a theme object system.

---

Pinto provides a theme object system — a way to define theme components as typed PHP objects (rather than
loose render arrays/preprocess), for a more structured, object-oriented approach to building reusable theme
components/patterns. It requires PHP 8.2.

Use it as a developer/theming framework for object-based components. It is a developer/theming feature
providing a component-object API; components render through Drupal's normal theming and it has no content or
access role. Use the Pinto API to build theme objects.

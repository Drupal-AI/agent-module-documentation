Embed Pinterest widgets with XSS protection.

---

Pinterest Widget provides Pinterest widgets and integration with comprehensive security and XSS protection — so editors can embed Pinterest boards/pins/profiles as widgets, with the module sanitising configuration to prevent XSS from widget parameters. Depends on core `user`; supports Drupal 10 and 11.

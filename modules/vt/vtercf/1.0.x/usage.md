Views Term Entity Reference Custom Field creates a related term list from an entity reference field.

---

Views Term Entity Reference Custom Field (vtercf) provides a **Views field that builds a related-term
list** — from an entity-reference field, it renders the referenced taxonomy terms (e.g. a "related topics"
list), so a View row can display the terms an entity references. It depends on core Views and Taxonomy, in the
Views package.

Use it to show referenced terms as a related list in a View. It is a content-display/Views feature; the terms
shown follow the View's/entity's access and it has no access-control role. Add the field to a View.

# Views Term Entity Reference Custom Field (vtercf) — agent index

A **Views field that builds a related-term list from an entity-reference field** (render referenced taxonomy
terms — a "related topics" list). Depends on core `views`, `taxonomy`. Version **1.0.3**. Core `^10||^11`.

Content-display/Views — terms shown follow the View's/entity's access; no access role.

Nice ImageField Widget creates an image-field widget to upload multiple files at once using HTML5 and display them as a draggable grid.

---

Nice ImageField Widget provides an improved image-field widget — letting editors upload multiple images
at once (via HTML5 multi-file upload) and manage them as a draggable grid (reorder by dragging), a nicer UX
than the default one-at-a-time image widget. It depends on jQuery UI Sortable (for the drag reordering).

Use it on multi-value image fields where bulk upload and visual reordering help. It is a content-editing/
form-widget feature affecting image upload/management; the uploaded images are managed files governed by
normal file access, and it has no access-control role. Configure it as the widget on the image field.

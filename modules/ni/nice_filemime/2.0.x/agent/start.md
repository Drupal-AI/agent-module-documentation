# Nice Filemime — agent index

Provides **nicer, more user-friendly file MIME type names** (readable labels — "Word document" — vs raw MIME
strings). Version **2.0.3**. Core `^8||^9||^10||^11`.

Content-display/media — affects how MIME types are labelled; no content/access role.

Nice Filemime provides nicer, more logical and user friendly filemime names.

---

Nice Filemime provides friendlier display names for file MIME types — so instead of raw MIME strings
(e.g. `application/vnd.openxmlformats-officedocument.wordprocessingml.document`) files show a readable label
(e.g. "Word document"), improving how file types are presented to users. It is a display utility.

Use it to show human-friendly file-type labels. It is a content-display/media feature affecting how MIME
types are labelled; it has no content or access role. Enable it to use nicer filemime names.

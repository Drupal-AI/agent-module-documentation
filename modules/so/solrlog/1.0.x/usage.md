Log Drupal system events into Solr.

---

Solr Log logs system events using Solr — writing Drupal's log entries into a Solr index (via Search API Solr) so logs can be searched, aggregated and analysed at scale in Solr rather than the database, useful for high-volume sites. Depends on `search_api` and `search_api_solr`; supports Drupal 10.2+ and 11.

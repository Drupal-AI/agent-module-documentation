Auto-post site content to Mastodon via Social Post.

---

Social Post Mastodon provides Social Post integration for Mastodon — so a site can automatically publish posts/toots to a configured Mastodon account when content is created, for social distribution.

The Mastodon API credentials are admin-configured; store them securely (env-backed). Depends on `social_post` (>=3.x); supports Drupal 10 and 11.

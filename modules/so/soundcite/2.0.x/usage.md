SoundCite is a CKEditor 5 plugin for Soundcite clips with field formatter support for audio files.

---

SoundCite integrates **SoundCite** (Knight Lab's inline-audio tool) as a **CKEditor 5 plugin** — editors
can wrap text so a click plays an inline audio clip (a segment of an audio file), plus a **field formatter**
for audio-file fields. It depends on core File, provides its own permissions, in the CKEditor 5 package.

Use it to add inline "click-to-play" audio to content. It is a content-editing/media feature; audio is
uploaded/managed as files (core file handling) and the SoundCite markup is inserted into rich text — ensure
the text format's allowed tags permit the SoundCite markup and restrict the plugin to trusted formats. It has
no access-control role beyond its permission. Enable it in CKEditor 5 and on audio fields.

# SoundCite — agent index

A CKEditor 5 plugin for **inline SoundCite audio clips** (click text → play an audio segment) plus an
audio-file **field formatter**. Depends on core `file`. Provides permissions. Version **2.0.7**. Core
`^10.5||^11`.

Content-editing/media — audio uploaded as files (core file handling); inserts SoundCite markup into rich text
(ensure the format allows it; restrict to trusted formats). No access role beyond permission.

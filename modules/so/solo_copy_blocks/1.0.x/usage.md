Solo Copy Blocks copies blocks and configuration from the W3CSS Theme or any sub-theme into the Solo Theme, easing migration between them.

---

Solo Copy Blocks is a helper for the Solo theme ecosystem: it copies blocks and related
configuration from the W3CSS Theme (or any sub-theme) into the Solo Theme, easing the migration or
setup when moving to Solo. Rather than manually recreating block placements and settings, an
administrator runs the copy. It is configured at `solo_copy_blocks.admin_form`.

Use it when adopting the Solo theme and you want to carry over an existing theme's block configuration.
It is a theming/site-building utility that duplicates configuration; run it deliberately (it creates/
copies config) and review the result. It has no content or access-control role beyond the config it
copies.

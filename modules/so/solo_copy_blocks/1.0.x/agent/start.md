# Solo Copy Blocks — agent index

Copies **blocks + config from the W3CSS Theme (or a sub-theme) into the Solo Theme** — eases migration/
setup to Solo. Config at `solo_copy_blocks.admin_form`. Version **1.0.2**. Core `^10.1||^11`.

Theming/site-building utility (duplicates config) — run deliberately and review. No content/access
role.

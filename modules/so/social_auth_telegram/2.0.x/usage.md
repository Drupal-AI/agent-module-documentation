Log in with Telegram via Social Auth (OIDC + PKCE).

---

Social Auth Telegram provides Social Auth integration for Telegram — letting users authenticate with their Telegram account, implemented as a modern OIDC flow with PKCE, nonce and OAuth-state (CSRF) validation (all constant-time compared).

The Telegram bot token is admin-configured; store it securely (env-backed). Depends on `social_auth`; supports Drupal 9.5+, 10, and 11.

Songbook provides ChordPro format support for Drupal.

---

Songbook **adds ChordPro format support to Drupal** — a text filter/format that renders ChordPro-notated
song lyrics (chords above lyrics) into formatted output, for songbook/worship/music sites. It depends on core
Filter.

Use it to publish chorded song lyrics. It is a content-display/filter feature affecting rendering; output goes
through the text format's filtering and it has no content or access role. Enable the ChordPro filter on a text
format.

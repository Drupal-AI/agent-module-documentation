# Social Post X — agent index

**Social Post integration for X (formerly Twitter)** — auto-post content to an X account via the X API. Config
at `social_post_x.settings_form`; provides permissions. Version **1.0.0**. Core `^8.8||^9||^10||^11`.

**Security:** store X OAuth **credentials/tokens** as **secrets**; HTTPS; be deliberate about auto-posts
(public reach) — restrict who can trigger. No access role beyond permission.

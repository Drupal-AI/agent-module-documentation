# Soft hyphen — agent index

Enables **soft hyphens** (`&shy;`) in plain-text fields + a **Twig filter** for soft-hyphenation (long
words break gracefully on narrow screens). Version **1.0.1**. Core `^9||^10||^11`.

Content-display/typography — affects rendering, not stored values/access.

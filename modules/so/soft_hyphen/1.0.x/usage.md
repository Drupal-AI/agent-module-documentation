Soft hyphen enables soft hyphens in plain text fields and provides a Twig filter for adding soft hyphens.

---

Soft hyphen enables soft hyphens (`&shy;`) in plain-text field output and provides a Twig filter for
inserting soft hyphens — allowing long words to break gracefully at appropriate points on narrow screens
without visible hyphens when not needed. This improves typography/readability, especially for long
compound words (common in some languages) and narrow columns. It is in the Field type package.

Use it to improve text wrapping/hyphenation for long words. It is a content-display/typography feature
affecting rendering; the stored value is unchanged and it has no access-control role. Apply the formatter/
Twig filter where soft hyphenation helps.

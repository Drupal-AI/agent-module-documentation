# Global settings, routes & permissions

## Install & enable

```bash
composer require drupal/a12s_maps_sync
drush en a12s_maps_sync -y
```

Only Drupal dependency is core **`content_translation`**. `hook_install()` (in
`a12s_maps_sync.install`) installs the `contextualized_attribute` content entity type via
`entityDefinitionUpdateManager()->installEntityType()`.

## Connect to MaPS (environment variables, not config)

`MapsApi::getBaseUrl()` reads env var **`A12S_MAPS_SYNC_API_URL`** (throws `MapsApiException` if
unset) and every request sends header `X-Maps-Api-Key: <A12S_MAPS_SYNC_API_KEY>`. Set both in the
container environment (DDEV dotenv, a Key entity's env provider, or `settings.php` `putenv`), then
restart. Requests go over whatever scheme the base URL specifies — use `https://`.

## Config objects (`config/install/`)

- **`a12s_maps_sync.settings`** — global module settings, edited by `Form/SettingsForm.php` at
  `/admin/config/a12s-maps-sync/settings`:

  | Key | Default | Meaning |
  |---|---|---|
  | `allowed_entity_types` | `[]` (form default checks taxonomy_term, media, file, content) | Entity types that may receive the GID base field and the "reimport" route. |
  | `ignore_lock` | `false` | Skip per-profile import locking entirely (equivalent to always passing `--force`). |
  | `import_batch_size` | `100` | Objects processed per batch set. |
  | `batch_max_iterations_count` | `4` | Max retries of a stuck batch item before it is dropped from state. |

  Toggling `allowed_entity_types` on the form installs/keeps the `GID_FIELD` storage
  (`SettingsForm::createGidField()` via a batch); disabling a type warns that the existing GID
  field is left in place.

- **`a12s_maps_sync.languages_mapping`** — maps Drupal langcodes to MaPS System language ids
  (defaults `fr:1, en:2, de:3, …`). Used to align imported translations with MaPS languages.

## Routes (`a12s_maps_sync.routing.yml`)

| Route | Path | Permission |
|---|---|---|
| `a12s_maps_sync.admin` | `/admin/config/a12s-maps-sync` | `administer a12s maps sync` |
| `a12s_maps_sync.settings_form` | `…/settings` | `administer a12s maps sync` |
| `a12s_maps_sync.dashboard_form` | `…/dashboard` | `use a12s maps sync dashboard` |
| `a12s_maps_sync.config_explorer_form` | `…/config-explorer` | `use a12s maps sync config explorer` |
| `a12s_maps_sync.import_object_form` | `…/import-object` | `import a12s maps sync object` |

Entity CRUD routes (profiles, converters, contextualized attributes) are generated by the route
providers in `src/Routing/` under `/admin/a12s_maps_sync/…`; profile/converter edit routes require
`_entity_access … .update` (mapped to `administer site configuration`). `RouteSubscriber` adds an
`entity.<type>.reimport_entity` route (permission `reimport a12s maps sync entities`) for each
allowed entity type that declares a `reimport-entity` link template.

## Permissions (`a12s_maps_sync.permissions.yml`)

`administer a12s maps sync`; `use a12s maps sync dashboard`; `use a12s maps sync config explorer`;
`import a12s maps sync object` / `… profile` / `… converter`; `reimport a12s maps sync entities`;
and the contextualized-attribute set: `administer contextualized attribute types` (restricted),
`create` / `view` / `edit` / `delete contextualized attribute`.

## Hooks (`a12s_maps_sync.module`)

- `hook_entity_base_field_info_alter()` — adds the `MaPS Sync ID` (`GID_FIELD`, string, 128) base
  field to each configured allowed entity type.
- `hook_entity_type_alter()` / `hook_entity_operation()` — delegate to `EntityTypeInfo` to add the
  reimport link template and per-entity operation.
- `hook_element_info_alter()` — attaches the `a12s_maps_sync/toolbar` icon CSS library.

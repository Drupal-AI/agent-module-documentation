Jouve Project Version is a project version manager.

---

Jouve Project Version manages the project's version — tracking/displaying the deployed project version/
release, so teams can see which version of the codebase a site is running (useful for support and release
verification). It is in the Jouve package.

Use it to surface the project version. It is an administration/DevOps feature displaying version info; the
version is operational metadata and it has no access-control role. Note version/release info can be
sensitive operational detail — keep its display admin-gated where appropriate. Configure the version
manager.

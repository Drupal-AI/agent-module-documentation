Render Jotform forms as native Drupal forms via the Jotform REST API.

---

Jotform API renders Jotform forms as native Drupal forms via the Jotform REST API — with server-side validation, submission, automation triggering, and webhook handling — so a Jotform-built form is presented and processed inside Drupal rather than embedded as an iframe.

The Jotform API key is stored via a Key entity (`key` dependency, env-backed), never committed. Depends on core `system` and `key`; supports Drupal 10.3+ and 11.

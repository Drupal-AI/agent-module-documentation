A field widget for embedding/selecting a Jotform form.

---

Jotform Field Widget provides a Jotform Field Widget and access to the Jotform API — a field type/widget where an editor selects/embeds a Jotform form on content, backed by the Jotform API for form data. Depends on core `field`; supports Drupal 10 and 11.

# UtiliKit — agent index

A **dynamic utility-first CSS framework with live class generation** (spacing/layout/color utilities; example/
help/playground submodules). Provides permissions. Version **1.0.4**. Core `^10||^11`.

Theming/front-end — classes are theme/authoring constructs; no content/access role.

UtiliKit provides a dynamic utility-first CSS framework with live class generation.

---

UtiliKit provides a **dynamic utility-first CSS framework** for Drupal — utility classes (spacing, layout,
color, etc.) with live/on-demand class generation, plus example/help/playground submodules. It provides its own
permissions, in the UtiliKit package.

Use it to style with utility classes. It is a theming/front-end feature; classes are theme/authoring constructs
and it has no content or access role. Configure UtiliKit and use its utility classes.

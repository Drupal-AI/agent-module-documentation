# Configure AutoAlt.ai

Route `autoalt.settings` → `/admin/config/content/autoalt`, permission `administer site configuration`.

- **API Key** (`autoalt.settings:api_key`) — obtained from https://autoalt.ai; used to authenticate outbound calls to the AutoAlt.ai service.
- **Default language** and **Short alt text length** thresholds.
- Bulk operations UI lives separately at `/admin/config/media/autoalt/bulk-alt` (perm `administer site configuration`).

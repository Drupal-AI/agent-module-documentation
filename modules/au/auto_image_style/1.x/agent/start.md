# Auto Image Style (auto_image_style) — agent index

Applies an **image style by the original's orientation** (portrait/landscape/square). Version **dev**.
Core `^9.3 || ^10 || ^11`.

Display-layer, no security surface. Define a style per orientation and map them — the right crop
applies automatically at render for mixed-orientation content. Confirm the mapping produces the
crops you want.

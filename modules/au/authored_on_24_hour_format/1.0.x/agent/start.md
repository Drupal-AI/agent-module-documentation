# authored_on_24_hour_format

Forces 24-hour time on the node 'Authored on' widget.

- `authored_on_24_hour_format_form_node_form_alter()` attaches library `authored_on_24_hour_format/set_24_hour_format` (js/).
- No routes/permissions/services/config. Client-side widget tweak only, all content types.

See [../usage.md](../usage.md).

Podigee lets you listen to an audio file with the Podigee HTML player.

---

Podigee **embeds the Podigee podcast player** — rendering an audio file (podcast episode) with Podigee's
HTML5 player for playback. It depends on core File, in the Media package.

Use it to play podcast audio via Podigee. It is a media/integration feature. Note: the player and its assets
load from the **external Podigee service** (third-party embed — trust the provider; it may load remote JS), and
the audio is public content; it has no access-control role. Configure the Podigee player on audio content.

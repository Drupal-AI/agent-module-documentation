Popup Lite provides a lightweight popup/modal system using the iziModal JavaScript library.

---

Popup Lite provides a lightweight popup/modal system built on the iziModal JavaScript library —
showing configurable modal popups (messages, promotions, content) with minimal overhead. It ships a
`popup_lite_ext` submodule for extended features, depends on core System, and provides its own
permissions.

Use it to display modal popups without a heavy framework. It is a content-display/UI feature; popup
content is admin-authored and rendered through Drupal's layers, and it has no access-control role beyond
its admin permission. Configure the popup content, appearance and trigger conditions.

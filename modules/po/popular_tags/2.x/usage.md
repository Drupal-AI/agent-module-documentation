Popular Tags lets users select taxonomy terms/tags by clicking from a list of popular/existing tags, easing tagging.

---

Free-tagging works better when authors can pick existing popular tags rather than retyping (avoiding near-duplicate terms). Popular Tags shows clickable popular tags for selection. It is an editorial-UX feature with no security surface — it suggests existing terms for a tag field. Confirm it suggests from the intended vocabulary.

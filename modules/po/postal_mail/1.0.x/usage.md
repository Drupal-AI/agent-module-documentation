Postal Mail routes Drupal email through the Postal mail-delivery platform via Mail System.

---

Postal Mail Delivery Platform Integration allows site emails to be sent through Postal — an open-source mail delivery platform — by providing a Mail System plugin, so Drupal's outbound mail is delivered via Postal's API/SMTP for better deliverability and tracking.

Postal API credentials should be stored securely (env-backed); administration is gated by `administer postal mail`. Depends on `mailsystem`; supports Drupal 10 and 11.

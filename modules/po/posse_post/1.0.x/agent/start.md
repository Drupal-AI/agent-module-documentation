# POSSE Post — agent index

**Publish on your Own Site, Syndicate Elsewhere** (cross-post to social platforms). Depends on core `system`,
`user`, `node`. Provides permissions. Version **1.0.0**. Core `^10||^11||^12`.

Social/integration — **posts to external platforms via their APIs** (egress); **per-platform OAuth tokens** as
secrets (env/Key, HTTPS; a token can post as your account). No access role beyond permission.

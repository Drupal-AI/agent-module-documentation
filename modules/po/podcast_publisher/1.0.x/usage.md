Podcast Publisher provides a podcast entity type for publishing podcast episodes, with an analytics submodule.

---

Podcast Publisher provides a podcast entity — a content structure for publishing podcast episodes
(audio file, metadata, links) so a site can host and publish a podcast. It ships a
`podcast_publisher_analytics` submodule for episode analytics, depends on core File and Link, and provides
its own permissions.

Use it to publish a podcast on a Drupal site. It is a media/content feature providing podcast entities;
episodes are content governed by normal entity access, and the analytics submodule tracks episode metrics
(be mindful of what listener data it records — privacy). Configure the podcast/episodes and, if used, the
analytics.

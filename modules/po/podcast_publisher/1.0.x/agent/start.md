# Podcast Publisher — agent index

Provides a **podcast entity** for publishing podcast episodes (audio + metadata); `podcast_publisher_analytics`
submodule for episode metrics. Depends on core `file`, `link`; provides permissions. Version
**1.0.0-alpha9**. Core `^9||^10||^11`.

Media/content — episodes governed by entity access; analytics tracks listener metrics (privacy). Configure
podcast/episodes.

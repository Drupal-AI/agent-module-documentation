NYS Design System Libraries packages the New York State Design System for use in Drupal themes.

---

NYS Design System Libraries incorporates the NYS (New York State) Design System as Drupal libraries so themes can use its components, styles and assets directly in Twig templates — helping NYS/government sites build consistent, accessible interfaces aligned to the state design standard.

It's a theming/asset library with no content or access role of its own. Requires Drupal 11.

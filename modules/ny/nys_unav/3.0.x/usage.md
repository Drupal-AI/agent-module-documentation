NYS Universal Navigation adds blocks and support to display the NYS (New York State) Universal Navigation.

---

NYS Universal Navigation adds blocks and support for displaying the New York State (NYS) Universal
Navigation — the standardized header/footer navigation used across New York State government websites, for
consistent branding and cross-site navigation. It is configured at `nys_unav.form` and provides its own
permissions. It targets NYS government sites that must display the official universal navigation.

Use it on NYS government sites needing the universal navigation. It embeds the NYS universal navigation
(typically loading NYS-hosted assets), so it is specific to that ecosystem. It is a site-structure/branding
integration with no access-control role. Configure and place the universal navigation blocks.

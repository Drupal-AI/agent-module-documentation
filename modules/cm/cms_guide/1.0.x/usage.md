CMS Guide delivers editor documentation as Markdown that imports into an in-admin guide.

---

CMS Guide is a docs-as-code in-admin help system for Drupal — editor guide content ships as Markdown inside a module and is imported into the site, so site builders can maintain editorial documentation in version control (Markdown files) and have it presented to editors as an in-admin guide with clean URLs.

It imports Markdown into content and generates aliases (via Pathauto). Depends on core `filter`, `text`, and `pathauto`; supports Drupal 10 and 11.

# cmlmerchant (cmlmerchant) — agent index
**Generates static Google Merchant / Yandex / VK product feed files from Commerce products under a `catalog` taxonomy and serves them at fixed URLs.**

> **Enable note (2.0.4):** installed but FAILS TO ENABLE here — `cmlmerchant.info.yml` requires `drupal:catalog` and `drupal:cmlstarter`, neither of which is present under `web/modules/contrib` (the feed service also hard-references absent `commerce_product` classes). Documented from source only.

- **version:** 2.0.x (new major; was 8.x-1.x)
- **core:** ^11 || ^12
- **depends on:** catalog, cmlstarter (+ Drupal Commerce `commerce_product` at runtime)
- **routes:** `/cmlmerchant/{google,yandex}-feed.xml` + six `vk-*` variants (`_permission: access content`, read-only file streaming); `/cmlmerchant/debug` (`administer site configuration`); settings `/admin/config/cmlmerchant/settings` (`administer site configuration`).
- **service:** `cmlmerchant.yml` (`YmlService`) renders feeds to `sites/default/files/YML/`; regenerated by `hook_cron` (`src/Hook/Cron.php`) and `drush cmlmerchant:feeds` (alias `feeds`).
- **config:** `cmlmerchant.settings` (shop_name, company_name, site_url, vk_* toggles); installs `field_catalog_google_id` string field on the `catalog` vocabulary. No config/schema shipped. No module permissions (core perms only).
- **Security:** feed routes are read-only and only stream pre-generated files; `access content` suits public product feeds. Admin/debug routes are permission-gated. No external HTTP, no webhook/payment callback. No mutating anonymous endpoints.

See [configure/feeds.md](configure/feeds.md)

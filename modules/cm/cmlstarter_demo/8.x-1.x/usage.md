CML Starter Demo imports demonstration content for a Commerce ML Starter setup.

---

CML Starter Demo supplies demonstration content for the Commerce ML (CML) Starter, imported through the Migrate framework (migrate_tools/migrate_plus) with a YAML-editable configuration. It's meant to quickly populate a demo/evaluation site with example commerce content.

It's a demo/starter helper, not for production use — the imported content is illustrative. Depends on core `system`, `migrate_tools`, `migrate_plus`, and `yaml_editor`; supports Drupal 8 through 11.

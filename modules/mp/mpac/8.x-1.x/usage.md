An autocomplete for finding paths when creating menu items, shortcuts, or aliases.

---

Multi-Path Autocomplete (mpac) helps find paths while creating menu items, shortcuts, or URL aliases using autocomplete fields — so instead of typing an internal path by hand, an editor searches and picks it (backed by core's entity-reference selection plugins).

The autocomplete respects entity access (it reuses core's selection plugin system with access checks), so it returns only content the current user may access — anonymous requests see only public content. Depends on core `path`; supports Drupal 8.8 through 11.

A Layout Builder flip-card layout plugin.

---

Flipcard Layout (lb_flipcard) provides a flip-card layout for Layout Builder — a layout that renders its regions as a card with a front and back face that flips on hover/click, for interactive teaser/feature sections. Supports Drupal 8.8 through 11.

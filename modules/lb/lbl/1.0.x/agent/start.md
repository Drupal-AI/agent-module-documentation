# Layouts (lbl) - agent index

Adds **configurable, responsive Layout Builder layouts** (version **1.0.4**, core `^9||^10`; depends on `layout_discovery`, `layout_builder`). Machine name `lbl`, project 'Layouts'.

- Defines layouts in `.layouts.yml`, declares breakpoints, and a `CssGenerator` service emits per-breakpoint CSS. Templates under `templates/`.
- No routes or entities; section access via core Layout Builder.
- Category: Content display / Layout Builder.

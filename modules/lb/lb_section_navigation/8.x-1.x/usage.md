LB Section Navigation creates a block with links to the components in a layout builder section.

---

LB Section Navigation provides a **block that links to the components in a Layout Builder section** —
generating in-page anchor navigation to the blocks/components within a layout section, so long layout-built
pages get a jump-to navigation. It is in the Layout package.

Use it to add jump navigation over Layout Builder components. It is a site-structure/layout feature affecting
presentation; it has no content or access role. Place the section-navigation block.

# Server sided code highlighting (ssch) — agent index

Highlights **code snippets via server-side rendering** (a code field type — highlighted output generated
server-side, no client-side highlighter). Depends on core `field`, `vendor_stream_wrapper`. Version
**2.0.2**. Core `^10||^11`.

Content-display/fields — code rendered as highlighted (escaped) markup; no access role.

Yext Search integrates Yext's hosted search with configurable blocks.

---

**Yext Search** connects Drupal to Yext's hosted search. It provides a settings form (`yext_search_config.settings`, gated by `administer site configuration`) for Yext account credentials and a search-bar block plus a search-result block that render Yext's front-end and return results from the Yext SaaS. It is a sibling of the Yext AI Search project focused on the standard Yext search experience.

Use it to add Yext-powered search to a Drupal site without maintaining a local search index.

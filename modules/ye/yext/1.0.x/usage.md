Yext AI Search embeds a Yext Answers experience through blocks.

---

**Yext AI Search** integrates Yext's hosted Answers search into Drupal. It provides blocks — a Yext search bar and a Yext search results block — that load Yext's front-end experience using site-configured Yext account settings (API key, experience/business identifiers). Search runs against Yext's SaaS, not the local database. No custom routes or permissions are added beyond block placement.

Use it to deliver a hosted, AI-style search/answers UI powered by your Yext account.

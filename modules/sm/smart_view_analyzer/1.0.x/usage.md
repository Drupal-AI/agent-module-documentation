---

Smart View Query Analyzer **analyzes Views performance** — inspecting Views for query complexity, execution
time and performance issues, flagging dangerous/slow views and suggesting optimizations. It depends on core Views
and provides its own permissions.

Use it to find slow Views. It is a developer/performance tool; it analyzes view definitions and query performance
(admin-facing) and has no content or access role beyond its permission. Note: analysis may run/inspect queries —
gate it to trusted developers. Configure and run the analyzer.

# Smart View Query Analyzer — agent index

**Analyzes Drupal Views for query complexity, execution time and performance issues** (flags dangerous views,
suggests optimizations). Depends on core `views`. Provides permissions. Version **1.0.1**. Core `^10.3||^11`.

Developer/performance — analyzes view definitions + query performance (gate to trusted developers); no content/access
role beyond permission.

Load/stress-testing for Symfony Messenger.

---

SM Stressor is a load/stress-testing tool for Symfony Messenger — dispatching bursts of test messages through the sm message bus so developers can benchmark throughput, latency and worker behaviour under load before production. It's a developer/testing module. Depends on `sm` and `sm_scheduler`; supports Drupal 10.6+ and 11.3.

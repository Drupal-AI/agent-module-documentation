Smart Cache Recommendations analyzes caching and suggests improvements (uncached blocks, cache tags).

---

Smart Cache Recommendations provides AI-assisted cache-optimization insights — detecting uncached blocks, suggesting cache metadata/context improvements, and surfacing caching issues, so developers can improve a site's cacheability and performance with guided recommendations.

Permissions cover access (`access smart cache recommendations`) and administration (`administer smart cache recommendations`). Depends on core `block` and `system`; supports Drupal 10 and 11.

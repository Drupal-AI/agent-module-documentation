Smart Date Extra Tokens provides additional token support for Smart Dates.

---

Smart Date Extra Tokens **adds additional tokens for the Smart Date module** — extra token replacements for
smart-date field values (e.g. formatted parts, ranges) usable anywhere tokens are supported. It depends on the
Smart Date module, in the Token package.

Use it to expose more Smart Date values as tokens. It is a content-display/token feature; tokens reflect field
values that already respect access, and it has no content or access role. Use the extra tokens where tokens are
supported.

A UI for Symfony Messenger metrics.

---

Symfony Messenger Monitor provides a UI for Symfony Messenger metrics — visualising the data collected by Symfony Messenger Metrics (queue latency, throughput) in an admin dashboard so operators can monitor the message bus at a glance. Depends on `pinto` and `sm_metrics`; supports Drupal 11.3.

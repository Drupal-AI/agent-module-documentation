Smart Date Starter Kit is a configuration kit that imports a ready-made Event content type and an Events view on install, giving a site a working example of Smart Date without any custom code.

---

Smart Date Starter Kit ships installed configuration only: enabling it creates an Event node type with an unlimited-cardinality Smart Date field (`field_when`), inline date-entry form widget, teaser and default view displays, and an Events view whose Upcoming and Past pages appear as menu tabs (split on the event end time versus now). It requires Smart Date and Add Content by Bundle, adds no runtime behavior, and can be uninstalled once the type and view exist; it pairs with Smart Date Calendar Kit for calendar output and Smart Date Recur for recurring events.

---

- Bootstrap a site's use of Smart Date with a working example.
- Get a ready-made Event content type without building it by hand.
- Add a Smart Date "When" field to events out of the box.
- Provide an Events listing with Upcoming and Past tabs.
- Show upcoming events sorted by start time.
- Show past events in reverse-chronological order.
- Place an "Upcoming Events" block that links to the full list.
- Give editors an "Add an Event" button on the events page.
- Model events that span a start and end time.
- Support all-day events via the inline Smart Date widget.
- Prepare a content type for recurring events (with Smart Date Recur).
- Learn how to configure a Smart Date field by example.
- Demonstrate the smartdate_inline widget and smartdate_default formatter.
- Provide a pathauto pattern (/events/[title]) for event nodes.
- Skip building event view modes and displays from scratch.
- Seed an events section under /events/upcoming and /events/past.
- Restrict events listings to published content via 'access content'.
- Extend the starter type by adding location or other fields.
- Reduce the When field to a single value before adding content.
- Pair with Smart Date Calendar Kit to add a calendar display.
- Serve as a reference for structuring event content in Drupal.
- Uninstall cleanly after the configuration has been imported.

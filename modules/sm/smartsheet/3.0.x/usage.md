Integration with the Smartsheet HTTP API.

---

Smartsheet is an integration module for the Smartsheet HTTP API — connecting Drupal to Smartsheet (a work/spreadsheet management SaaS) so sheets, rows and data can be read/written between the two, e.g. syncing content or collecting submissions into Smartsheet.

The Smartsheet API credentials are admin-configured; store them securely (env-backed). Supports Drupal 9, 10, and 11.

Smart Menu Links creates links relative to path-determined entities, with validation, for dynamic menu linking.

---

Smart Menu Links creates menu links that are relative to path-determined entities — so a menu link can
resolve dynamically based on the current context/path (rather than a fixed target), with validation of the
resolved links. This supports dynamic navigation where a link should point to a contextually-relevant entity.
It provides its own permissions.

Use it for context-aware menu links. It is a site-structure/navigation feature; the links resolve to entities
and respect those entities' access (a link to content the user can't see behaves accordingly), and it has no
access-control role of its own. Configure the smart menu links and their resolution/validation.

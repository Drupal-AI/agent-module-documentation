Smart Date Calendar Kit installs a ready-made "Events Calendar" view that shows Smart Date event nodes on a FullCalendar month/week/day/list calendar at /events/calendar.

---

Smart Date Calendar Kit is a configuration-only companion to Smart Date and Smart Date Starter Kit. On install it imports a single Views configuration, events_calendar, that renders published Event nodes (from Smart Date Starter Kit's event content type and its field_when Smart Date field) on a FullCalendar calendar. The page display lives at /events/calendar and registers as a "Calendar" menu tab beside the Starter Kit's Upcoming/Past listings, offering month, week, day, and list views, an "Add an Event" button, and optional drag-and-drop rescheduling. It ships no PHP: it is a starting point you customise through the Views UI (event colours, popups, per-bundle colouring) and can uninstall without losing the imported view.

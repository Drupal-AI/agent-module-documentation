Redis for Symfony Messenger provides a Redis transport for Symfony Messenger.

---

Redis for Symfony Messenger (sm_transport_redis) **provides a Redis transport** — enabling Symfony Messenger
(used for async message/queue handling) to use Redis as its transport backend, for scalable background processing.
It works on core 10.3+.

Use it to run Messenger queues on Redis. It is an infrastructure/performance feature; it configures a queue
transport and has no content or access role. Note: the Redis connection should be to a **trusted, access-controlled**
Redis instance (queue payloads pass through it). Configure the Redis transport.

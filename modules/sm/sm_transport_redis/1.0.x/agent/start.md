# Redis for Symfony Messenger — agent index

**Provides a Redis transport for Symfony Messenger** (async queues). Version **1.0.0-rc3**. Core `>=10.3`.

Infrastructure/performance — configures a queue transport (use a trusted/access-controlled Redis; payloads pass
through it); no content/access role.

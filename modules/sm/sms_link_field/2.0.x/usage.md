A link field type supporting sms: URIs with a compatible formatter.

---

SMS Link Field provides a link field type that supports `sms:` URIs and a compatible formatter — so content can store click-to-text links (e.g. `sms:+15551234567`) as a proper field and render them as tappable SMS links, useful on mobile-facing sites. Depends on core `link`; supports Drupal 11.

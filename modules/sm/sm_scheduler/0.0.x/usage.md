Schedule messages to be dispatched cron-like on Symfony Messenger.

---

Scheduler for Symfony Messenger + Drupal lets you schedule messages to be dispatched similar to a cron — so a Symfony Messenger (sm) message can be enqueued to fire at a future time or on a recurring schedule, giving cron-like scheduling on the message bus. It's a developer/infrastructure module. Supports Drupal 10.1+.

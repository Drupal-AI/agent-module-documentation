SMSOL (Searchable Multi-Select Option List) provides a searchable multi-select option list widget.

---

SMSOL **provides a searchable multi-select option list** — a form widget for selecting multiple options from a
searchable list, for easier selection among many options. It works on core 10–11.

Use it for searchable multi-select fields. It is a content-editing/field-widget feature; selection follows normal
field handling and it has no access-control role. Configure the widget on a field.

Symfony Messenger Prometheus exposes Messenger queue metrics for Prometheus scraping.

---

Symfony Messenger Prometheus exports metrics about Symfony Messenger (the SM module) to Prometheus — so operations teams can monitor message queue throughput, failures, and processing metrics via Prometheus/Grafana dashboards, giving observability into async message processing.

It's a monitoring/observability integration with no content or access role of its own. Depends on `sm` (Symfony Messenger) and `prometheus_exporter`; requires Drupal 11.3+.

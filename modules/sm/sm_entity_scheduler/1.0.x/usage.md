Config-driven entity scheduling on Symfony Messenger.

---

SM Entity Scheduler provides config-driven scheduling that publishes, unpublishes or deletes entities when a date field passes — run on Symfony Messenger plus a scheduler, with pluggable enforcement strategies. So time-based entity actions run reliably through the message queue rather than only on cron. Depends on core `datetime`, `sm`, and `sm_scheduler`; supports Drupal 11.3.

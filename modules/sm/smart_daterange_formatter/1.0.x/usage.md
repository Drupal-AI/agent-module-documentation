Smart Date Range Formatter provides a date-range field formatter with smart display logic.

---

Smart Date Range Formatter **formats date ranges intelligently** — a field formatter for Datetime Range fields
that applies smart display logic (e.g. collapsing same-day ranges, omitting repeated year/month) for cleaner date
output. It depends on core Datetime Range.

Use it for tidy date-range display. It is a content-display/field-formatter feature; it formats stored dates and
has no access-control role. Configure the smart date-range formatter.

Smileys Field provides a field for selecting smileys/emoji.

---

Smileys Field **provides a smileys field** — a field type/widget for selecting a smiley/emoji value on
entities, for lightweight mood/reaction data. It depends on core Field.

Use it to add a smiley field. It is a content-editing/field feature; the stored value is a smiley and it has no
access-control role. Configure the smileys field.

Collect Symfony Messenger dispatch/handle latency metrics.

---

Symfony Messenger Metrics collects Symfony Messenger metrics — tracking how long messages wait between being dispatched and being handled — so operators can measure queue latency and throughput of the Symfony Messenger (sm) message bus. Depends on `sm`; supports Drupal 11.3.

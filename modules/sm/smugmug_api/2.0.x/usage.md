SmugMug API provides API access to SmugMug for Drupal.

---

SmugMug API provides Drupal access to the SmugMug photo-hosting API — a base integration for fetching
albums/photos from SmugMug to display or import into the site. It is configured at `smugmug_api.settings`, in
the Media package.

Use it as the base for SmugMug integrations. Security note: it authenticates to SmugMug with API credentials
(API key / OAuth) — **store those as secrets** (not in exported config) and operate over HTTPS. Fetched
photos/albums are external content. It has no access-control role. Configure the SmugMug connection.

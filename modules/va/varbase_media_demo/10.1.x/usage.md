Varbase Media Demo Assets provides a pre-set of default media assets for all Varbase Media Types, for development, testing and demos.

---

Varbase Media Demo Assets provides a pre-set of default media assets for all Varbase Media types —
sample images/files needed during development, testing and demos of a Varbase-based site, so media-dependent
features have content to work with out of the box. It depends on Varbase Media and Pathauto, in the Varbase
Demos package.

Use it to seed demo media on Varbase development/demo sites. It is demo/sample content. As with any demo
module: it is intended for development/testing/demo environments, **not production** — uninstall it (and its
sample assets) on live sites to avoid shipping placeholder media. It has no access-control role. Install it
only where demo content is wanted.

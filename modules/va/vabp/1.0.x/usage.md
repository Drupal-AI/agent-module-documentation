Views area block plugin lets you place any block plugin into a view's area regions.

---

Views area block plugin provides a Views area handler that renders block plugins — so any Drupal block plugin can be placed into a view's header, footer, or empty-text area, giving site builders a flexible way to add block content directly within a view without a separate region.

It's a Views/site-building tool with no content or access role of its own (block access follows the block's own access). Supports Drupal 8 through 11.

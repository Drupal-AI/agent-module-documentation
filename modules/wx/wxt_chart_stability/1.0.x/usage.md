WxT Chart Stability provides a text filter for stable chart markup.

---

WxT Chart Stability provides a **text filter that keeps WET-BOEW chart markup stable/valid** — ensuring
chart-related markup produced for the WxT (WET-BOEW) distribution renders reliably, part of the Canada.ca/WxT
theming ecosystem. It is in the WxT package.

Use it on WxT-distribution sites using WET-BOEW charts. It is a content-display/filter feature affecting chart
markup; output flows through the text format and it has no content or access role. Enable the filter on the
relevant text format.

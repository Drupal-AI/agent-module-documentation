# ECA Entity Import — agent index

Provides an **ECA migrate process plugin for the Entity Import module** (automate entity imports with ECA).
Depends on core `migrate`, `entity_import`, `eca_migrate`. Version **3.0.0**. Core `^11.2`.

Developer/automation/migration — imports run with migration privileges (validate sources, trusted operator); no
access role.

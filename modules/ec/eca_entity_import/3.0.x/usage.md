ECA Entity Import provides an ECA migrate process plugin for entity import.

---

ECA Entity Import provides an **ECA migrate process plugin for the Entity Import module** — letting ECA
(Event-Condition-Action) automations drive/transform entity imports via Migrate, connecting no-code automation
to import pipelines. It depends on core Migrate, Entity Import and ECA Migrate, in the Migration package.

Use it to automate entity imports with ECA. It is a developer/automation/migration feature run by privileged
users; imports process source data with migration privileges (validate sources; run as trusted operator) and it
has no access-control role. Build ECA models that import entities.

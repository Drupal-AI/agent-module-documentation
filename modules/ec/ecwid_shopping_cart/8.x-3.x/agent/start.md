# Ecwid Ecommerce Shopping Cart (`ecwid_shopping_cart`)

Embeds an Ecwid hosted online store into Drupal via OAuth-connected store pages, a control-panel iframe, and storefront blocks/pages.

- Project: `ecwid_shopping_cart`, version `8.x-3.x`, core `^8 || ^9 || ^10`.
- Category: E-commerce / Storefront platform.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

MTC lets you set multiple clocks based on time zone.

---

MTC (Multiple Time Clock) **displays multiple clocks for different time zones** — showing the current time
in several configured zones (e.g. for offices/regions) via a block or widget. It is in the Custom package.

Use it to show multiple time-zone clocks. It is a content-display feature; the zones are admin-configured and it
has no content or access role. Configure the clocks and place them.

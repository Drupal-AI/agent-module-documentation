# External Entity (external_entity) — agent index

Framework that consumes remote data as native, **read-only** Drupal content entities, rendered with
view modes, Views, and entity reference — no import/duplication. Data is fetched on demand over HTTP
and cached in a dedicated bin. Version **1.0.0-rc1** (pre-release). Core `^9 || ^10 || ^11`, **PHP 8.3**.

- **Dependencies:** none outside Drupal core (`composer require` only `ext-json`). The shipped
  `external_entity_server` connection type targets the companion **External Entity Server** contrib
  module on a remote site, but that is not a hard dependency of this module.
- **No Drush commands.** Provides **config schema** and **5 permissions**.

## Entity types provided
- `external_entity` — the fetched content entity (`@EntityType`, bundle_entity_type
  `external_entity_type`). Storage `ExternalEntityStorage` (fetches remote, no local persistence);
  view builder `ExternalEntityViewBuilder`; access handler `ExternalEntityAccessHandler`; views_data
  `ExternalEntityViewsData`. See `src/Entity/ExternalEntity.php`.
- `external_entity_type` (config, prefix `type`) — bundles; admin perm `administer external entity type`.
- `external_entity_connection` (config, prefix `connection`) — remote connection + auth settings.
- `external_entity_resource_display` (config, prefix `resource_display`) — resource+variation → render type.
- `external_entity_resource_alter` (config, prefix `resource_alteration`) — per-property alterations.

## Plugin types provided (annotation-based, dir `src/Plugin/ExternalEntity/`)
- **ExternalEntityConnectionType** — manager `plugin.manager.external_entity.connection_type`.
  Ships `external_entity_server` (`ExternalEntityServer`, HTTP via `http_client_factory`).
- **ExternalEntityAuthenticationType** — manager `plugin.manager.external_entity.authentication_type`.
  Ships `basic_authentication` (`BasicAuthenticationType`, HTTP basic auth).
- **ExternalEntityRenderType** — manager `plugin.manager.external_entity.render_type`.
  Ships `internal_entity` (`InternalEntityRenderType`, maps remote props onto a local entity display).

## Key services
`external_entity.options`, `external_entity.entity_type.info` (`Service\EntityTypeInfo`),
`external_entity.views_data_helper`, `external_entity.route_subscriber`, `cache.external_entity`
(+ `cache_factory.external_entity`, `cache.external_entity.backend.database`), the three plugin
managers, and query factories `entity.query.stub` / `entity.query.api`. See `external_entity.services.yml`.

## Routes
Admin CRUD routes for the four config entities are generated by their `route_provider` (under
`/admin/structure/external-entity/…` and `/admin/config/services/external-entity/connection`). One
explicit route: `external_entity.api.cache.invalidator` (POST `/external-entity/api/cache/invalidator`,
`Controller\ExternalEntityAPICacheController::invalidateCache`) — the integration endpoint the remote
server calls to invalidate cached entities. A route subscriber
(`Routing\ExternalEntityRouteSubscriber`) swaps the `views_ui.form_add_handler` controller for
`Form\ViewUI\AddHandler`.

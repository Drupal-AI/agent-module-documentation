# Discord (`discord`)

Integration with Discord: sends text and rich embed messages to a Discord channel via an incoming webhook, with a service API and Rules actions.

- Project: `discord`, version `1.0.x`, core `^8 || ^9 || ^10`.
- Category: Integrations / Chat / messaging.
- Configure via route `discord.admin_settings`.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

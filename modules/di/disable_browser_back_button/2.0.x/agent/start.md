# Disable Back Button (`disable_browser_back_button`)

Disables the browser back button on configured pages by injecting JavaScript, preventing users from navigating back to cached (e.g. post-logout) pages.

- Project: `disable_browser_back_button`, version `2.0.x`, core `^9 || ^10`.
- Category: Security / Session management.
- Configure via route `disable_back_button.config_form`.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

# Discord Widget (`discord_widget`)

Provides a configurable block that embeds the official Discord server widget (member list / join iframe) into a Drupal page.

- Project: `discord_widget`, version `8.x-1.x`, core `^8 || ^9 || ^10`.
- Category: Integrations / Chat / messaging.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

# Configuration

Dismiss needs no configuration to do its main job — the close button on messages
appears as soon as the module is enabled. It offers just **one optional setting**.

## The auto‑hide option

Dismiss can automatically hide **status** messages after a short time, so routine
"success" notices clear themselves without the user clicking anything. This applies
only to status messages: **warnings and errors are deliberately left in place**,
because those usually need to be read and acted on.

To change this setting, open the module's small settings form. The quickest way to
reach it is from the **Extend** page (`/admin/modules`) — find **Dismiss** in the
list and click its **Configure** link, which takes you straight to the settings
form. Toggle the auto‑hide option to suit your preference and save.

If you never open this form, Dismiss still works — you simply get the manual close
button with no auto‑hiding.

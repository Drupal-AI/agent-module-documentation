# Disk Space Alert (`disk_space_alert`)

Monitors free disk space and notifies site administrators (email/log) when available space crosses a configured threshold, via cron and an admin report.

- Project: `disk_space_alert`, version `1.0.x`, core `^10`. Depends on: system, user.
- Category: Administration tools / Status report management.
- Configure via route `disk_space_alert.settings`.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

# Display Mode Extras (`display_mode_extras`)

Adds per-role access control for entity form modes and view modes, letting administrators grant or restrict specific display modes by user role.

- Project: `display_mode_extras`, version `2.0.x`, core `^8.8 || ^9 || ^10`.
- Category: Content editing experience / Display mode governance.
- Configure via route `display_mode_extras.settings`.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

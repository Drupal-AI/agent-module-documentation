# Disk Quota (disk_quota) — agent index

Enforces per-user file-storage limits. Sums the byte size of a user's owned files and blocks
uploads that would exceed the user's effective quota, via core's `hook_file_validate()`. Limits
are set per **user role** on a settings form and can be **overridden per user** on the user edit
form. Package `User`. Depends on core **`user`** and **`file`**. Core `^10 || ^11 || ^12`.
License GPL-2.0-or-later. Version 1.0.0-beta4. Suggests `drupal/markdown` (help-page rendering).

## What it actually is (from source)

Procedural, hook-driven; **no entities, no plugin types, no services, no Drush**. Everything lives
in `disk_quota.module`, `disk_quota.theme.inc`, one config form, and one permissions callback class.

- **Config form** `Drupal\disk_quota\Form\DiskQuotaSettingsForm` (`src/Form/DiskQuotaSettingsForm.php`),
  route `disk_quota.admin` at `admin/config/people/accounts/disk-quota`, a local task under the
  user account-settings form. Writes config object **`disk_quota.settings`**.
- **Permissions**: static list in `disk_quota.permissions.yml` (`view own`/`edit own`/`edit any`/
  `create`/`administer user roles storage quota`) plus a **dynamic per-role** permission
  `edit {role} role storage quota` generated by `Drupal\disk_quota\DiskQuotaPermissions::permissions()`
  (`src/DiskQuotaPermissions.php`).
- **Enforcement**: `disk_quota_file_validate()` (a `hook_file_validate()`) rejects a file when the
  owner's used bytes ≥ effective max, or when file size + used > max. **User 1 is exempt.**
- **Usage counting**: `disk_quota_file_space_used()` runs a `file` storage aggregate query
  (`SUM(filesize)`), optionally filtered by MIME (images/videos/documents).
- **Effective limit**: per-user override (stored in `user.data`, key `disk_quota:limit`) if set,
  else the **highest** `role_<rid>` limit among the user's roles.
- **Display**: extra field `disk_quota` on the user view (`hook_entity_extra_field_info` +
  `hook_user_view`) rendered by the `disk_quota` theme hook / `disk-quota.html.twig`.
- **User form**: `hook_form_user_form_alter` adds a "Storage limit" textfield; submit stores/deletes
  the per-user override. `hook_user_delete` clears the override.

## Config object `disk_quota.settings` (schema `config/schema/disk_quota.schema.yml`)

- `file_types` (sequence of strings; subset of `images`/`videos`/`documents`; empty = track all)
- `quota_by_type` (boolean; declared in schema + install default `false`, but **not read anywhere
  in the shipped code**)
- `warning_percentage` (integer 1–100; default `70`)
- `role_<rid>` (integer bytes per role) — written by the settings form; **not declared in schema**.

Install defaults (`config/install/disk_quota.settings.yml`): `file_types: []`, `quota_by_type: false`,
`warning_percentage: 70`.

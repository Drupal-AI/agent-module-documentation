Make the Project Browser searchable in a smart (AI) way.

---

Project Browser AI (pb_ai) makes the Project Browser searchable in a smart way — using AI to improve module discovery in the core Project Browser, so a site builder can describe what they need in natural language and get relevant module suggestions rather than only keyword matches.

The AI provider/keys are admin-configured (env-backed); each smart search may be an LLM call. Supports Drupal 10 and 11.

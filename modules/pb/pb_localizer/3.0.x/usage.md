Project Browser Localizer localizes Project Browser listings with fetched translated metadata.

---

Project Browser Localizer translates the Drupal Project Browser interface/listings by fetching localized project metadata (descriptions, etc.) from a central source — so non-English users see Project Browser content in their language, improving the module-discovery experience for multilingual teams.

It fetches from a central localization source. Depends on core `project_browser`; supports Drupal 10.3+ and 11.

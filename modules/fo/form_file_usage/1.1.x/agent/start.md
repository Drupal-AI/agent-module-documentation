# Form File Usage — agent index

Automatically manages **permanent status + file-usage** for `managed_file`/`text_format` elements in
**custom forms** — prevents uploaded files being GC'd/orphaned. Depends on core `file`. Version **1.1.0**.
Core `^10.1||^11||^12`.

Developer/file-management utility (no content/access role). Apply to custom forms with uploads.

# Footnotes all block — agent index

Displays **all footnotes in a single block** (aggregate footnotes across fields into one references section,
vs at each field's end). Depends on `footnotes` (>=4.0). Version **1.0.0-alpha3**. Core `^8||^9||^10||^11`.

Content-display — footnotes from content; no access role. Place the block where aggregated footnotes should
appear.

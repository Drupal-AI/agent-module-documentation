Footnotes all block displays every footnote in a single block rather than at the end of each field, aggregating footnotes.

---

Footnotes all block aggregates footnotes — displaying every footnote from the page in a single block
(e.g. at the bottom of the page) instead of separately at the end of each field. This suits content with
footnotes across multiple fields that should be collected into one references section. It depends on the
Footnotes module (>=4.0).

Use it to consolidate footnotes into one block. It is a content-display feature affecting footnote
presentation; the footnotes come from content and it has no access-control role. Place the footnotes block
where the aggregated footnotes should appear.

Foundation Layouts provides Layout Builder / layout-plugin layouts based on the ZURB Foundation grid system.

---

Layout Builder and the layout plugin system need layouts to place content into, and which layouts are available shapes what editors can build. A site built on the ZURB Foundation front-end framework wants its layouts to use Foundation's grid classes so the markup matches the framework rather than fighting it.

Foundation Layouts supplies those: a set of layouts using the Foundation grid system, available wherever Drupal layouts are — Layout Builder, Display Suite, and anywhere the layout API is used. On a Foundation-themed site it means editor-built layouts produce Foundation-correct markup out of the box.

It assumes Foundation, which is the main adoption note: the emitted grid classes are Foundation's, so on a theme that is not Foundation-based the layouts render without their intended grid behavior until those classes are given meaning. It is a theming-layer building block with no security surface of its own.

# Foundation Layouts (foundation_layouts) — agent index

Layout plugins using the **ZURB Foundation grid** (Layout Builder / layout API). Version **dev**.
Core `^8 || ^9 || ^10 || ^11`.

**Assumes Foundation** — emitted classes are Foundation's; on a non-Foundation theme the grid
behavior is absent until those classes have meaning. Theming building block, no security surface.

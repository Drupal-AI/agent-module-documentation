Form Factory provides an OO fluent interface for building Form API arrays.

---

Form Factory provides an object-oriented, fluent interface for building Drupal Form API render arrays — letting developers construct forms with chained method calls instead of hand-writing nested arrays. It builds on the Kits array-builder library.

It's a developer API with no content or access role of its own. Depends on `kits`; supports Drupal 9, 10, and 11.

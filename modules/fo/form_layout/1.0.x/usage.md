Form layout provides a lightweight way to organise content entity forms into tabs or accordions.

---

Form layout provides a lightweight, intuitive way to organize content-entity edit forms into tabs or
accordions — grouping fields into collapsible/tabbed sections so long forms are easier to navigate for
editors. It is configured at `form_layout.admin_settings` and is in the Content authoring package.

Use it to make long entity forms more manageable. It is a content-editing/form-UI feature affecting form
layout; it does not change fields, data or access (all fields remain, just grouped). Configure the tab/
accordion grouping on the form.

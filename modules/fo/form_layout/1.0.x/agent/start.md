# Form layout — agent index

Organizes **content-entity forms into tabs or accordions** (group fields into collapsible/tabbed sections —
easier navigation of long forms). Config at `form_layout.admin_settings`. Version **1.0.4**. Core
`^10.3||^11`.

Content-editing/form-UI — affects form layout only (all fields remain; no data/access change).

Foundation Anchor Menu Block provides ZURB Foundation based dynamic anchor menu blocks generated from page content.

---

Foundation Anchor Menu Block provides blocks that build a **ZURB Foundation** anchor menu **dynamically
from the current page's content** — scanning the page for elements with the configured classes/data-attributes
and generating in-page anchor navigation (jump links) styled with Foundation. It provides a `famb_anchor` block
content type and depends on Block, Block Content and Foundation Sites.

Use it for auto-generated on-page anchor navigation on Foundation themes. It is a site-structure/navigation
feature affecting presentation; it has no content or access role. Place the anchor-menu block and configure
the target classes/attributes.

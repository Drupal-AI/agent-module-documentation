# Foundation Anchor Menu Block — agent index

Generates **ZURB Foundation anchor-menu blocks dynamically from the current page's content** (jump links
built by scanning configured classes/data-attributes). Provides a `famb_anchor` block type. Depends on
`block`, `block_content`, `foundation_sites`. Version **1.1.13**. Core `^9||^10||^11`.

Site-structure/navigation — affects presentation; no content/access role.

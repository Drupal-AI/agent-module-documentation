# ZURB Foundation Sites Library — agent index

Registers the **ZURB Foundation Sites** front-end framework as a **Drupal library** (grid/components/
JS) — files in `libraries/foundation-sites` or CDN; variants complete/essential/core/cdn. Config at
`foundation_sites.admin`; provides permissions. Version **2.0.1**. Core `^8.9||^9||^10||^11`.

Theming/front-end integration (asset libraries; no content/access). Attach the chosen variant from your
theme/module.

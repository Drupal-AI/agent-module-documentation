ZURB Foundation Sites Library registers the ZURB Foundation Sites front-end framework as a Drupal library for themes/modules to use.

---

ZURB Foundation Sites Library registers the Foundation Sites front-end framework (CSS/JS) as a Drupal
library, so themes and modules can attach Foundation's grid, components and JavaScript. The framework
files are installed under `libraries/foundation-sites` (or loaded via CDN), and the module exposes
several library variants (complete, essential, core, CDN). It is configured at `foundation_sites.admin`
and provides its own permissions.

Use it when building a Foundation-based theme and you want Foundation registered as a managed Drupal
library to attach. It is a theming/front-end integration; it provides asset libraries, with no content
or access behaviour. Choose the appropriate library variant and attach it from your theme/module.

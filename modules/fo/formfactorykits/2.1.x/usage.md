Form Factory Kits provides reusable OO kits for constructing Form API arrays.

---

Form Factory Kits provides object-oriented 'kits' — reusable builder components for constructing arrays compatible with the Drupal Form API — used together with Form Factory to assemble forms from composable pieces. It's a developer library.

It's a developer API with no content or access role of its own. Depends on `kits` and `formfactory`; supports Drupal 10.2+ and 11.

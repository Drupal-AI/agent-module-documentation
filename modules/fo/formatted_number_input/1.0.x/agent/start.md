# Formatted Number Input — agent index

Provides a **masked number-input widget + matching display formatter** (per-language separators, unit symbols) for
core number/decimal/float fields. Version **1.0.3**. Core `^10||^11`.

Content-editing/field — values stored as normal numbers; no access role.

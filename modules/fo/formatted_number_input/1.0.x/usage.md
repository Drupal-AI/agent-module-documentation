---

Formatted Number Input **provides a masked number-input widget and matching display formatter** — for core
number/decimal/float fields, it offers live masked input with per-language thousand/decimal separators and unit
symbols (prefix/postfix), plus a display formatter that applies the same formatting on output. It works on core
10–11.

Use it for nicely-formatted number entry and display. It is a content-editing/field feature; values are stored as
normal numbers and it has no access-control role. Configure the number mask on the widget/formatter.

This converter migrates fontawesome_iconpicker field values to Micon Symbol fields.

---

Fontawesome Iconpicker to Micon Converter is a one-time migration helper that converts all `fontawesome_iconpicker` fields on a site to Micon Symbol fields — useful when moving iconography from the FontAwesome Iconpicker module to the Micon icon system.

It's a migration utility gated by `convert fontawesome iconpicker to micon fields`; run it once with a backup. Depends on `fontawesome_iconpicker` and `micon`; supports Drupal 8.9 through 11.

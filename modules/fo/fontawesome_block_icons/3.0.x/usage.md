Font Awesome Block Icons provides icons for block titles using Font Awesome.

---

Font Awesome Block Icons lets you **add a Font Awesome icon to a block's title** — so blocks can show an
icon next to their heading, for visual emphasis. It is in the Block package.

Use it to add icons to block titles. It is a content-display/theming feature affecting block rendering; the icon
is admin-configured and it has no content or access role. Configure the icon on a block.

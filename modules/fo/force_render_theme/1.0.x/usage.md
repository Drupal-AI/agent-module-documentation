Force a specific theme when rendering entity view displays.

---

Force Render Theme allows configuring a specific theme to render entity view displays — useful to render entities in the back-office with the front-office theme (or vice versa), so previews/embeds look as they will on the frontend regardless of the active admin theme. Supports Drupal 10.1+, 11, and 12.

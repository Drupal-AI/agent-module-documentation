# Form State Empty — agent index

Extends core Form API **`#states`** to **empty (clear) fields via JavaScript** on a state condition —
core can show/hide/enable but not clear. Version **1.1.0**. Core `^10||^11`.

Form/developer feature (client-side; affects form behaviour, not content/access). Use within a field's
`#states`.

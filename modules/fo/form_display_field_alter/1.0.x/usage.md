Form display field alter lets code adjust field definitions before they render in a form display.

---

Form display field alter provides a programmatic interface for modifying field definitions before they are used by the form-display system — letting developers alter widget settings, labels, or definitions per context without overriding entire forms. It's developer plumbing for finer form-display control.

It's a developer API with no content or access role of its own. Supports Drupal 10.3+ and 11.

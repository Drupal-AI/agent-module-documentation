OneTime LoginLink gives admins a form to generate a Drupal one-time login link for any user by username or email.

---

The module exposes a single form at `/admin/config/system/onetime-loginlink/settings` (`OneTimeLoginLinkForm`), gated by the `administer onetime_loginlink` permission (declared `restrict access: TRUE`). You enter a username or email; the form loads the account (validating it exists) and calls Drupal core's `user_pass_reset_url($account)` to produce the one-time login URL, then displays it to the admin to copy and deliver.

Security review found this sound: the link itself is generated by Drupal core, which derives it from the user's password hash, last-login timestamp, and the site's private key (a secure, time-limited, effectively single-use token) — the module adds no custom token logic to weaken it. The ability to mint a login link for another account is inherently powerful, so the gating permission is correctly `restrict access` and should be granted only to fully trusted administrators; the generated URL should be delivered over a secure channel.

- Generate a one-time login link for a user who is locked out.
- Help a user regain access without resetting their password manually.
- Support account recovery by username or email lookup.
- Produce a secure, time-limited login URL on demand.
- Assist users whose reset emails aren't arriving.
- Give support staff a controlled way to issue login links.
- Rely on Drupal core's secure one-time-login token.
- Restrict link generation to trusted admins via a dedicated permission.
- Onboard a user by sending them a first-login link.
- Recover access to a test/staging account quickly.
- Avoid sharing or resetting real passwords.
- Deliver a login link through your own secure channel.
- Validate that the target account exists before generating.
- Handle both email and username input in one field.
- Provide a simple UI over core's password-reset URL API.
- Keep account-access assistance auditable behind a permission.

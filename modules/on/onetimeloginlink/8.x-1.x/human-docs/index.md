# OneTime LoginLink — manual setup guide

**OneTime LoginLink** (machine name `onetime_loginlink`; project
`onetimeloginlink`) gives administrators a simple form for generating a Drupal
one‑time login link for any user, looked up by **username or email address**. It
is the browser‑based equivalent of running `drush user:login` — useful when a user
is locked out, their password‑reset email is not arriving, or you are onboarding
someone and want to hand them a first‑login link.

The form is deliberately minimal: one text field that accepts either a username or
an email, which the module uses to load the account (validating that it actually
exists) and then to produce a one‑time login URL, which it displays for you to
copy and deliver. The whole module is a single form plus its access control, with
no dependency beyond Drupal core.

**How the link is scoped, and why it is safe.** The link itself is generated by
**Drupal core's `user_pass_reset_url()`**, which derives it from the user's
password hash, their last‑login timestamp, and the site's private key. That makes
it a secure, time‑limited, effectively single‑use token — the module adds no
custom token logic that could weaken it. Because minting a login link for another
account is inherently powerful, the form is gated by a **dedicated permission,
`administer onetime_loginlink`, which is declared *restrict access*** — grant it
only to fully trusted administrators, and deliver the generated URL over a secure
channel.

This guide is written for a **human** clicking through the admin UI. If you want
terse, token‑cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Where it lives in the admin menu

The generation form is at **Configuration → System → OneTime LoginLink**
(`/admin/config/system/onetime-loginlink/settings`), gated by the **`administer
onetime_loginlink`** permission.

## How to use it

1. Grant **`administer onetime_loginlink`** to the trusted role that should be
   able to issue login links (see [Installation](installation/index.md)).
2. Go to `/admin/config/system/onetime-loginlink/settings`.
3. Enter the target user's **username or email** in the field and submit.
4. The module validates the account exists, generates the one‑time login URL, and
   displays it for you to copy.
5. Deliver the URL to the user over a secure channel. It is time‑limited and
   effectively single‑use, so it stops working once used or once it expires.

Because the person generating the link can see (and therefore use) it, treat
generation as an action to perform on a user's behalf and to *send* to them, not
as a way to hold access to their account.

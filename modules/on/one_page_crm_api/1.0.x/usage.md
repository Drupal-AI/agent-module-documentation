Integrate with the OnePageCRM API (contacts, companies, relationships).

---

One Page CRM API integrates with the OnePageCRM API for contacts, companies, and relationship types — so a Drupal site can sync people/companies and their relationships to OnePageCRM (a sales CRM).

The OnePageCRM API credentials are admin-configured and should be stored securely (env-backed), never committed. Depends on core `config`; supports Drupal 10.1+, 11, and 12.

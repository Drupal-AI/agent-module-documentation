Integrate with the 1Pass authentication/SSO service.

---

OnePass provides integration with the 1Pass service — connecting Drupal users to 1Pass (an authentication/single-sign-on service) so users can be authenticated/identified via 1Pass.

The 1Pass client credentials are admin-configured and should be stored securely (env-backed), never committed. Depends on core `user` and `views`; supports Drupal 8 through 11.

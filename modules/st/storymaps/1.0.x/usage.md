ArcGIS StoryMaps embeds ArcGIS StoryMaps with configurable settings.

---

ArcGIS StoryMaps **embeds ArcGIS StoryMaps** — displaying interactive Esri ArcGIS StoryMaps (map-based
narratives) on the site via configurable embeds. It works across core 10.1–12.

Use it to embed StoryMaps. It is a content-display/integration feature; it embeds **third-party ArcGIS content**
(loaded from Esri) and has no access-control role. Note: embedding loads external ArcGIS assets — mind privacy/
consent for third-party content. Configure the StoryMaps embed.

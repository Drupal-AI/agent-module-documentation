Statistics Rolling Period logs access statistics over a rolling time period.

---

Statistics Rolling Period **logs access statistics on a rolling period** — recording content access/view stats
within a moving time window (rather than all-time), so popularity reflects recent activity. It depends on core
Statistics.

Use it for recency-weighted view stats. It is a statistics feature. Privacy note: access statistics record
**viewing activity** (which can be personal data) — minimize/anonymize and disclose per policy, and gate any stats
report. It has no access-control role. Configure the rolling period.

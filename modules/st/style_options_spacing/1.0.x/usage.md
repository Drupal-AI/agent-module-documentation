Style Options: Spacing adds spacing (margin/padding) options available as style options.

---

Style Options: Spacing extends the Style Options system with spacing options — letting site builders
apply margin/padding spacing choices to components/layouts through the Style Options UI (as style options
that emit spacing classes/styles). It depends on the Style Options module.

Use it on Style Options-enabled sites to give editors spacing controls. It is a theming/presentation
feature adding spacing style options; it affects styling and has no content or access role. Configure the
spacing options and apply them where Style Options are used.

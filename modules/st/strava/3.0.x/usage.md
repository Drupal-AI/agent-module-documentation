Integrate the Strava fitness-platform API with Drupal.

---

Strava provides an implementation of the Strava API for Drupal — connecting to Strava (the fitness/activity social platform) so athlete activities and related data can be fetched and displayed or synced on the site, e.g. for clubs or event sites.

Strava uses OAuth; the client credentials/tokens are admin-configured and should be stored securely (env-backed). Depends on core `serialization`; supports Drupal 10.3+ and 11.

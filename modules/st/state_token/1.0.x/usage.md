State Token provides tokens returning state values.

---

State Token **provides tokens returning values from the current request/state** — exposing request/state
context (e.g. current values) as Token-module tokens for use in configuration/text. It works across core 9–11.

Use it to reference state/request values via tokens. It is a developer/site-building feature; tokens resolve
against request/state data and it has no content or access role. Use the state tokens where tokens are
supported.

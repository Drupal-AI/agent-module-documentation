Status dashboard monitors and displays updates available for Drupal core and modules in a dashboard.

---

Status dashboard monitors and displays the update status of Drupal core and contributed modules in a
dashboard — surfacing which components have available updates (including security updates), so administrators
can see the site's update posture at a glance. It depends on core Views, is configured at
`status_dashboard.settings_form`, and provides its own permissions.

Use it to keep on top of available updates. The security-relevant point is twofold: (1) it is a positive
operational aid for staying patched (staying current on security updates is essential), and (2) the update/
version information it shows is sensitive — it reveals exactly which module versions are installed and which
have known-vulnerability updates pending, so **restrict the dashboard to trusted administrators** and never
expose it publicly (that would hand attackers a precise list of the site's outdated, vulnerable components).
Configure the dashboard access accordingly.

# Style Options — Media Reference — agent index

Provides a **media_reference StyleOption plugin** for selecting/rendering a media entity as a style option.
Depends on `style_options`, core `media`. Version **1.0.0**. Core `^10||^11`.

Theming/site-building — referenced media follows normal media access; no access role.

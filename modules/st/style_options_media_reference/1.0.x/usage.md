Style Options — Media Reference provides a media-reference StyleOption plugin for selecting/rendering a media entity.

---

Style Options — Media Reference **adds a media-reference style option** — a StyleOption plugin (for the Style
Options framework) that lets a component/layout reference and render a media entity as a configurable style option
(e.g. a background image). It depends on the Style Options and core Media modules.

Use it to pick media as a style option. It is a theming/site-building feature; the referenced media follows normal
media access and it has no access-control role. Configure the media-reference style option.

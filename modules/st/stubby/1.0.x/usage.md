Stubby creates stub data using a simple UI.

---

Stubby **creates stub/dummy data through a simple UI** — generating placeholder content quickly for
development, testing and demos. It provides its own permissions, in the Development package.

Use it to seed test content. It is a developer tool. Security note: content-generation tools are for
**non-production** use — gate its permission to trusted developers and don't leave it enabled on production
(mass-creating content is a privileged, potentially disruptive action). It has no access-control role beyond its
permission. Use the UI to create stub data.

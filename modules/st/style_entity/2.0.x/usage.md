Entity Style adds CSS classes to nodes, blocks and paragraphs via Style config entities.

---

Entity Style (style_entity) **adds CSS classes to entities via Style config entities** — letting site builders
define reusable "styles" (CSS classes) and apply them to nodes, blocks and paragraphs for consistent styling. It
depends on core Field and Node, and provides its own permissions, in the Theming package.

Use it to apply reusable style classes. It is a theming/site-building feature; styles are admin-defined config
classes added to markup, and it has no access-control role beyond its permission. Note: class values are
admin-configured — output as valid class names. Configure the Style entities.

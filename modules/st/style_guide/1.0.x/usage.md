A simple style guide showing your theme's HTML elements.

---

Style Guide provides a simple style guide for your custom theme — an admin page that renders common HTML elements (headings, lists, tables, forms, buttons, blockquotes, etc.) through your theme, so front-end developers can review how the theme styles each element in one place. Supports Drupal 9.2+, 10, and 11.

Integrate Drupal with a STOMP/AMQP message queue (e.g. ActiveMQ).

---

STOMP integrates Drupal with an external STOMP or AMQP message queue, such as ActiveMQ — providing a Drupal queue backend that pushes/pulls jobs via the STOMP protocol, so background work can be handed off to an external message broker for scalable, decoupled processing.

The broker connection details/credentials are admin-configured; store them securely (env-backed). Supports Drupal 9, 10, and 11.

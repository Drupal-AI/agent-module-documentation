State Machine Automated Transition automates state transitions.

---

State Machine Automated Transition **automatically applies State Machine transitions** — moving an entity
between workflow states without manual action (e.g. auto-publish after a date, auto-archive after a period),
using the State Machine module. It depends on the State Machine module, in the Contrib package.

Use it to automate workflow state changes. It is a workflow/automation feature; the transitions it applies still
respect State Machine's configured transitions/guards, and it has no access-control role. Configure the automated
transitions.

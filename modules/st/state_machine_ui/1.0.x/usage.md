An admin UI for managing State Machine workflows.

---

State Machine UI provides an admin UI for State Machine workflows — letting site builders manage workflow groups, states and transitions (and a custom widget) through the interface instead of only in code/config, making the State Machine module's workflows configurable in the admin. Depends on `state_machine`; supports Drupal 11.1+.

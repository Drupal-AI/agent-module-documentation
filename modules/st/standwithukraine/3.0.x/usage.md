StandWithUkraine displays a message and styles to show support for Ukraine.

---

StandWithUkraine **shows a support message for Ukraine** — adding a banner/message and image styling (Ukrainian
flag colors) to express solidarity. It depends on the Service module and provides its own permissions, in the User
interface package.

Use it to show support. It is a purely cosmetic/front-end feature; it adds a message/styling and has no content or
access role beyond its permission. Configure the message display.

# Styleguide routes, theme negotiation & theme hooks

## Routes

| Route | Path | Renders |
|---|---|---|
| `styleguide.page` | `/admin/appearance/styleguide` | Guide for the **default** theme |
| `styleguide.maintenance_page` | `/admin/appearance/styleguide/maintenance-page` | Maintenance-page preview (default theme) |
| `styleguide.<theme>` | `/admin/appearance/styleguide/<theme>` | Guide for a specific enabled theme (dynamic) |
| `styleguide.maintenance_page.<theme>` | `/admin/appearance/styleguide/maintenance-page/<theme>` | Maintenance preview for that theme (dynamic) |

The per-theme routes are generated by `StyleguideRoutes::routes()` (wired via
`route_callbacks` in `styleguide.routing.yml`) for every enabled, non-hidden theme. After
enabling a theme, rebuild routes/caches (`drush cr`) for its route to appear.

## Theme negotiator

`theme.negotiator.styleguide` (`StyleguideThemeNegotiator`, priority 0) `applies()` to any
`styleguide.*` route matching an enabled theme and returns that theme from
`determineActiveTheme()`, so the guide renders in the target theme rather than the admin theme.

## Theme hooks (override in your theme)

From `styleguide_theme()` (templates in the module's `templates/`):

| Hook | Template | Variables |
|---|---|---|
| `styleguide_header` | `styleguide-header.html.twig` | `theme_info` |
| `styleguide_links` | `styleguide-links.html.twig` | `items` |
| `styleguide_item` | `styleguide-item.html.twig` | `key`, `item`, `content` |
| `styleguide_content` | `styleguide-content.html.twig` | `content` |

Copy any of these into your theme to change how the guide's wrapper, per-item, and navigation
markup render.

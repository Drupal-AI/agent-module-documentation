Starry Rating provides a star-rating field widget using a vanilla-JS library.

---

Starry Rating **provides a star-rating field** — a star-rating widget (using the vanilla-JS Starry Rating
library) for collecting/displaying ratings. It works on core 10–11.

Use it to add star ratings. It is a user-engagement/field feature. Data-handling note: ratings are **user-submitted**
— apply anti-abuse/flood control so ratings can't be gamed, and expose aggregate ratings appropriately. It has no
access-control role. Configure the rating field.

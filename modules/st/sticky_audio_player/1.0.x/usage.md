Sticky Audio Player provides a sticky audio-player field formatter.

---

Sticky Audio Player **provides a sticky audio player** — a field formatter that renders an audio file in a
player that stays fixed (sticky) on screen while the user browses, for continuous listening. It depends on core
File and Media.

Use it for persistent audio playback. It is a media/display feature; audio follows normal file/field access and it
has no access-control role. Configure the sticky audio formatter.

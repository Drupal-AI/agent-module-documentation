# String — agent index

A **framework for managing translatable interface strings** (i18next for JS front-ends, TMGMT integration; demo
submodules). Depends on core `locale`. Provides permissions. Version **2.0.1**. Core `^10.3||^11`.

Multilingual/developer — strings are translator content; no access role beyond permission.

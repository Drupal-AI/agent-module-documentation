String provides strings for translation.

---

String provides a **framework for managing translatable interface strings** — defining and exposing strings
for translation (integrating with i18next for JS front-ends and TMGMT for translation management), with
`string_i18next`, `string_tmgmt` and demo submodules. It depends on core Locale, provides its own permissions,
in the Locale package.

Use it to manage translatable strings for a (decoupled) front-end. It is a multilingual/developer feature;
strings are admin/translator content and it has no access-control role beyond its permission. Configure and
export the strings.

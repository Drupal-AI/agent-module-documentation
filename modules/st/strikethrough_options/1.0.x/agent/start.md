# Strikethrough Options (strikethrough_options) — agent index

**Field widget that renders radio/checkbox options with a colored strikethrough.**

- **Version:** 1.0.x
- **Core:** ^8 || ^9 || ^10 || ^11
- **Widget:** `StrikethroughOptionsWidget` (extends `OptionsWidgetBase`); field types boolean, entity_reference(_revisions), list_integer/float/string.
- **Setting:** `strikethrough_color` (black/red/green/blue); styling via `strikethrough_options` CSS library.
- **Setup:** choose the "Check boxes/radio buttons - Strikethrough" widget on Manage form display.

**Security:** none — presentational field widget only; no routes, permissions, or server-side logic.

Style Options Conditions makes Style Options context-aware via condition plugins.

---

Style Options Conditions extends the Style Options module with a condition plugin system — so styling options (applied to paragraphs) can be shown/applied conditionally based on context (e.g. region, content type), giving site builders context-aware control over which style options are available.

It's a theming/site-building enhancement with no content or access role of its own. Depends on `paragraphs` and `style_options`; supports Drupal 10 and 11.

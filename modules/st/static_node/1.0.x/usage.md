Generate static HTML files for nodes to improve performance.

---

Static Node Generator generates static HTML files for nodes to improve performance — pre-rendering a node's output to a static HTML file that can be served directly (bypassing Drupal's bootstrap for those pages), for very fast delivery of stable content. Depends on core `node` and `file`; supports Drupal 10 and 11.

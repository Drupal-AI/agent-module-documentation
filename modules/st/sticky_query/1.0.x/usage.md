Sticky Query keeps chosen URL query strings persistent across links.

---

Sticky Query provides an API for sticky URL query strings — keeping selected query parameters (e.g. tracking, filters, campaign params) persistent across links/navigation, so they aren't lost as users move through the site. It uses a DOM processor to rewrite links.

It's a developer/URL utility with no content or access role of its own. Depends on `domprocessor`; supports Drupal 9, 10, and 11.

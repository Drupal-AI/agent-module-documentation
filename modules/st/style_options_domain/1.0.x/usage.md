Style Options Domain makes Style Options domain-specific for multi-domain sites.

---

Style Options Domain adds domain context support to the Style Options module — so a multi-domain site (using the Domain module) can offer different style options per domain, letting each domain expose its own set of styling choices to editors.

It's a theming/site-building enhancement with no content or access role of its own. Depends on `style_options`; supports Drupal 10 and 11.

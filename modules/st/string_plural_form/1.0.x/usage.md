String Plural Form helps manage plural forms for translatable strings.

---

String Plural Form helps handle plural rules for translatable strings — supporting the multiple plural forms different languages require (e.g. Slavic languages with several plural categories), so translations render the correct plural form. It builds on core Locale.

It's a multilingual/developer utility with no content or access role of its own. Depends on core `locale`; supports Drupal 10.2+ and 11.

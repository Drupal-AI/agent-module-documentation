Secure Nodes lets admins mark nodes as protected against modification/deletion.

---

Secure Nodes **lets admins protect nodes** — marking selected nodes as "protected" (via Views Bulk Operations
actions to protect/unprotect) so they are guarded against casual modification or deletion, preventing accidental
changes to important content. It depends on core Views and provides its own permissions.

Use it to lock down critical nodes. It is a content-protection feature; protect/unprotect are permission-gated
actions, and the protection guards against edit/delete of marked nodes. Note: verify the protection is enforced on
the paths you care about (edit form, delete, and any API/programmatic paths) and gate the protect/unprotect
permission to trusted admins. It has this protection role. Configure and apply node protection.

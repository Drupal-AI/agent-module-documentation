# Session Inspector — agent index

Lets **users inspect and manage (terminate) their own sessions** ("active sessions / sign out other
devices"). Depends on core `user`; config at `session_inspector.config`; provides permissions. Version
**1.0.7**. Core `^9||^10||^11`.

Positive security feature (self-service session management), scoped to a user's own sessions via
permission.

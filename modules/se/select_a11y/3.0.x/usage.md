Select a11y provides an accessible multiple select widget.

---

Select a11y provides an **accessible multiple-select widget** — a searchable, keyboard- and
screen-reader-friendly replacement for long multi-select lists, improving the accessibility and usability of
selecting several options. It ships a `select_a11y_facets` submodule (Facets integration), in the Search
package.

Use it to make multi-select fields/filters accessible. This is an **accessibility-positive** UI feature; it
changes the select widget's presentation/behaviour and has no content or access role. Enable it and choose the
widget on the relevant fields/filters.

Sector Multipage provides a block for subsection navigation.

---

Sector Multipage provides a subsection-navigation block — for navigating between the pages/sections of a
multi-page piece of content, complementing the Sector Table of Contents module (so long content split into
sections gets prev/next/section navigation). It depends on the Sector TOC module.

Use it to add subsection navigation to multi-page content. It is a content-display/navigation feature; the
navigation reflects the content structure (content the user can see) and it has no access-control role. Place
the subsection-navigation block.

Sector Tonic provides admin and content editor experience improvements for Sector.

---

Sector Tonic provides **admin and content-editor experience improvements** for the Sector distribution/
profile — refinements to the editing/admin UI built on the Gin admin theme (via `gin_toolbar`). It depends on
gin_toolbar, in the Sector package.

Use it on Sector-based sites to improve the editorial UX. It is an administration/UI feature affecting the
admin experience; it has no content or access role. Enable it on a Sector site.

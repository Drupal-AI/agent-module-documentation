Store and display a user's recent search-term history (localStorage).

---

Search Tracker stores and displays search term history via localStorage — so a visitor's recent search terms are remembered client-side and shown (e.g. as recent-search suggestions) on the search form, improving repeat search UX without server-side storage. Supports Drupal 9, 10, and 11.

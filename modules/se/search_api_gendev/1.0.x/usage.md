Search API generic devel adds Devel debug output for Search API indexed items.

---

Search API generic devel provides Devel information for indexed entities — surfacing the indexed data/fields for an item through the Devel module, so developers building Search API indexes can inspect exactly what is indexed for debugging and index tuning.

It's a developer/debugging tool with no content or access role of its own. Depends on `search_api` and `devel`; supports Drupal 9, 10, and 11.

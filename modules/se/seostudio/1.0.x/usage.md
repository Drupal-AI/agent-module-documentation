SEO Studio provides a full preview of a page's meta tags as they would appear across major social platforms and search engines, built on Metatag.

---

SEO Studio gives editors a preview of how a page's meta tags will appear across major search engines
and social platforms — showing the search-result snippet, Facebook/Open Graph card, Twitter/X card, etc.
so they can tune titles, descriptions and images before publishing. It builds on the Metatag module (and
its Open Graph / Twitter Cards submodules) and is configured at `seostudio.settings`; it uses an API key
for its preview service.

Use it to improve how content appears in search and social shares. Because the preview functionality uses
an external service (configured with an API key), store the API key as a secret. It is an SEO/editorial
feature working alongside Metatag; it previews and helps configure meta tags and has no access-control
role. Configure the API key and use the previews while editing.

# SEO Studio — agent index

Previews **meta tags across search engines and social platforms** (search snippet, Open Graph, Twitter/X
cards). Built on `metatag` (+ Open Graph / Twitter Cards submodules). Config at `seostudio.settings`; uses
an **API key** for its preview service. Version **1.0.4**. Core `^8|^9|^10|^11`.

Store the API key as a secret; preview uses an external service. SEO/editorial (no access role).

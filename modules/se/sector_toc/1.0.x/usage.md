Sector Table of Contents provides table-of-contents generation and a sidebar block.

---

Sector Table of Contents generates a table of contents from a page's content (headings/sections) and
provides a sidebar TOC block — so long articles get an automatic, navigable contents list. It depends on the
Chunker module and core Block.

Use it to add an auto-generated TOC/sidebar to long content. It is a content-display/navigation feature; the
TOC reflects the page's headings (content the user can see) and it has no access-control role. Place the TOC
block and configure the content it indexes.

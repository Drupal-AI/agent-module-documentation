# Sector Table of Contents — agent index

Generates a **table of contents + sidebar TOC block** from page content (auto navigable contents for long
articles). Depends on `chunker`, core `block`. Version **1.0.0**. Core `^10.3||^11`.

Content-display/navigation — TOC reflects the page's headings (content the user can see); no access role.

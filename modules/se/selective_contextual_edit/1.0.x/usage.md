Selective Contextual Edit lets editors contextually edit only chosen fields.

---

Selective Contextual Edit provides selective contextual editing for Drupal entity fields — so the contextual 'edit' (quick-edit-style) links target only specific chosen fields rather than the whole entity, giving a more focused in-place editing experience.

It's an editorial-UX enhancement with no content or access role of its own (edit access still follows core). Depends on core `contextual`; supports Drupal 10 and 11.

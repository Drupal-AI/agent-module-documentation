Show section-wise banners by path pattern or Views name.

---

Section Banner provides section-wise banners that can be shown on any page based on path patterns or Views machine names — so a site can display a contextual banner (image/heading) at the top of a section, targeting pages by URL pattern or the View they render, useful for landing-section headers. Depends on core `block`, `file`, `image`, and `filter`; supports Drupal 10 and 11.

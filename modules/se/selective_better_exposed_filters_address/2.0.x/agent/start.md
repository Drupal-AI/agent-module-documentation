# Selective BEF Address — agent index

Adds **selective (only-show-used-values) options to Better Exposed Filters for Address fields** (no empty filter
options). Depends on `address`, `better_exposed_filters`. Version **2.0.0**. Core `^8||^9||^10||^11`.

Content-display/Views — affects exposed-filter options; results respect the View's access; no access role.

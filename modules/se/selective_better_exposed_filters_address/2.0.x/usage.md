Selective Better Exposed Filters Address provides extra options for better exposed filters.

---

Selective BEF Address adds **selective options to Better Exposed Filters for Address fields** — so an
exposed filter on an Address field only offers the values (countries/regions/etc.) that actually appear in the
results, avoiding empty filter options. It depends on the Address and Better Exposed Filters modules, in the
Views package.

Use it to make Address exposed filters selective. It is a content-display/Views feature affecting the exposed-
filter options; results respect the View's access and it has no access-control role. Configure the selective
option on the Address exposed filter.

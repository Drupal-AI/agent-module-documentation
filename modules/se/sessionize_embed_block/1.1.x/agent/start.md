# Sessionize Embed Block — agent index

Provides a **block that embeds a Sessionize schedule/session widget** (event agendas). Provides permissions.
Version **1.1.x** (dev). Core `^9.3||^10.0||^11`.

Content-display/integration — loads a **third-party Sessionize embed/script** (public event data; trust the
provider). No access role beyond permission.

Sessionize Embed Block provides a block embedding a Sessionize widget.

---

Sessionize Embed Block provides a **block that embeds a Sessionize widget** — showing an event schedule/
session list from Sessionize (a conference/session-management service), e.g. for a DrupalCamp agenda. It provides
its own permissions, in the DrupalCampNYC package.

Use it to embed a Sessionize agenda. It is a content-display/integration feature. Note: it loads a **third-party
Sessionize embed/script** (external — the agenda content and assets come from Sessionize), so trust that
provider; the content is public event data. It has no access-control role beyond its permission. Configure the
Sessionize embed.

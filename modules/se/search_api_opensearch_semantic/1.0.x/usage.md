Search API OpenSearch Semantic extends Search API OpenSearch with vector (semantic) search.

---

Search API OpenSearch Semantic **adds vector/semantic search to OpenSearch** — extending Search API OpenSearch
with vector search capabilities so queries can match by semantic similarity (embeddings), not just keywords. It
depends on Search API and Search API OpenSearch.

Use it for semantic search over OpenSearch. It is a search/AI feature. Data-handling note: generating embeddings
may involve sending content to an **embedding model/service** (egress — confirm acceptable), and content is indexed
in **OpenSearch** (respect Search API access so semantic results don't expose restricted content). It has no
access-control role. Configure the vector search.

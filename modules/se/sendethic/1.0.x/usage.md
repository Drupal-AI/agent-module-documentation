SendEthic integrates the SendEthic email/marketing platform with Drupal.

---

SendEthic provides integration with the SendEthic platform — an email/marketing delivery service — so Drupal can send email or sync marketing data through SendEthic's API, extending the site's email/marketing capabilities.

SendEthic API credentials should be stored securely (env-backed); administration is gated by `administer sendethic configuration`. Supports Drupal 9, 10, and 11.

Search API Extras provides additional functionality for Search API.

---

Search API Extras provides **additional functionality for the Search API module** — extra processors/plugins
or helpers that extend Search API indexing/query behaviour. It depends on the Search API module, in the Search
package.

Use it to extend Search API. It is a site-search/developer feature; results follow the search index's access and
it has no access-control role. Configure the extras on your index.

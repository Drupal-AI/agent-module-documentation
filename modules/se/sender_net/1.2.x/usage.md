Sender.net Integration integrates the Sender.net email-marketing service.

---

Sender.net Integration **integrates the Sender.net service** — syncing subscribers and sending email through
the Sender.net email-marketing platform via its API. It is in the Sender.net package.

Use it to integrate Sender.net. It is an integration/marketing feature. Security/data handling: it **sends contact/
subscriber data (PII) to the Sender.net API** (external egress — disclose per privacy policy) and authenticates
with a **Sender.net API key** (store as a secret — env/Key — over HTTPS; don't commit it). It has no access-control
role. Configure the Sender.net credentials.

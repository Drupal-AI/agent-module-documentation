Set Field Defaults allows administrators to configure field default values.

---

Set Field Defaults lets **administrators configure and apply default values for fields** — setting a
default that populates a field on new (or existing) entities, beyond core's per-field default handling. It
depends on core Field and System, in the Configuration package.

Use it to manage field defaults centrally. It is a site-building feature affecting field defaults; defaults are
admin-configured and it has no content or access role. Configure the field defaults.

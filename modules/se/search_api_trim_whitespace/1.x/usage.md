Search API Trim Whitespace adds a processor that removes errant whitespace from indexed content, improving search matching.

---

Content with irregular whitespace (from pasted text, markup) can hurt search matching. Search API Trim Whitespace is an index processor that normalises whitespace during indexing. It is a Search API text-processing feature with no security surface — it cleans indexed text. Confirm it does not strip meaningful whitespace for your content (usually not an issue).

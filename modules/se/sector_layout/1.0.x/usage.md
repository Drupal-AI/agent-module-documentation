Sector Layout provides the default layouts and configuration for Layout Builder.

---

Sector Layout provides **default Layout Builder layouts and configuration** for the Sector distribution —
ready-made layout options and settings so Sector-based sites get a consistent set of layouts out of the box. It
depends on core Layout Builder, in the Sector (Experimental) package.

Use it on Sector sites to get default layouts. It is a site-building/layout feature providing layout
configuration; it has no content or access role. Enable it and use the provided layouts.

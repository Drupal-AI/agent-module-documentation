Search API Value Mapping provides a Search API field to map source values to custom target values.

---

Search API Value Mapping provides a Search API processor/field that maps source values to custom target
values during indexing — so raw field values (codes, statuses, terms) can be translated to friendlier or
normalized values in the search index (e.g. mapping "1" → "Active"). It is in the Search package.

Use it to normalize/translate values in the search index. It is a site-search/indexing feature transforming
indexed values; the mapping is admin-configured and it has no access-control role. Configure the value
mappings on the index.

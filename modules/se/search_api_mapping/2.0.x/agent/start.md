# Search API Value Mapping — agent index

A Search API **field/processor mapping source values to custom target values** during indexing (normalize/
translate codes/statuses — e.g. "1"→"Active"). Version **2.0.2**. Core `^8||^9||^10||^11`.

Site-search/indexing — transforms indexed values (admin-configured mappings); no access role.

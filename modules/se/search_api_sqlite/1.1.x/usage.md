Search API SQLite FTS5 provides a high-performance Search API backend using SQLite's FTS5 full-text search engine — giving sites fast full-text search without an external server (Solr/Elasticsearch), leveraging SQLite for indexing and querying. Good for small/medium sites wanting better-than-DB search cheaply.

It's a Search API backend with no content or access role of its own (result access follows Search API/entity access). Depends on core `sqlite` and `search_api`; supports Drupal 10.3+ and 11.

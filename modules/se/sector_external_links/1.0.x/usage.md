Sector External Links provides Sector Distribution modifications for external links.

---

Sector External Links provides **Sector Distribution-specific modifications to the External Links (extlink)
module** — tailoring external-link marking/behaviour to the conventions of the Sector distribution. It depends
on the External Links (extlink) module, in the Sector package.

Use it on Sector-distribution sites for consistent external-link handling. It is a content-display/theming
feature affecting how external links are marked; it has no content or access role. Enable it alongside extlink
on a Sector site.

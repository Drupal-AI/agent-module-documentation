Search API Kana Convert provides a Japanese kana convert processor.

---

Search API Kana Convert provides a **Search API processor that converts Japanese kana** — normalizing
hiragana/katakana (and related forms) during indexing/query so Japanese-language searches match across kana
variants. It depends on the Search API module, in the Search package.

Use it to improve Japanese search matching. It is a site-search feature affecting index/query text processing;
results follow the search index's access and it has no access-control role. Add the processor to your index.

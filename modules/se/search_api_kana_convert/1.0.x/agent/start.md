# Search API Kana Convert — agent index

A **Search API processor that converts Japanese kana** (hiragana/katakana) for better Japanese matching. Depends
on `search_api`. Version **1.0.2**. Core `^9||^10||^11`.

Site-search — affects index/query text; results follow the index's access; no access role.

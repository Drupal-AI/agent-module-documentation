# Search Api Daterange Filter — agent index

**Date-range exposed filter** for **Search API** date fields in Views (from/to date filtering). Depends
on `search_api`. Version **1.0.1**. Core `^10||^11`.

Site-search/Views feature — shapes the query, respects index + entity access; no access role. Add the
exposed filter to the search View.

Section library reusable creates an aspect ratio CSS container for image and picture elements.

---

Section library reusable creates an aspect-ratio CSS container for image/picture elements — wrapping
images in a container that preserves a defined aspect ratio (avoiding layout shift and keeping consistent
proportions), used with the Section Library module. It depends on the Section Library module, in the User
interface package.

Use it for consistent, layout-shift-free image containers in section-library sections. It is a
content-display/theming feature affecting image presentation; it does not change content or access and has no
access-control role. Configure the aspect-ratio containers.

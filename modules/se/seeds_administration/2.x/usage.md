Seeds Administration is a starter module that enables a curated set of administration modules for the Seeds distribution.

---

Setting up a good admin experience means enabling several modules (admin toolbar, admin theme helpers, content tools). Seeds Administration is a convenience aggregator pulling in a curated administration stack for the Seeds distribution. It adds functionality, not risk; it is an opinionated bundle, so review which modules it brings and whether their configuration suits your site. Usable as a curated admin starter on non-Seeds sites subject to that review.

Search API Layout Block Filter removes chosen blocks from a layout before generating the search-indexed item.

---

Search API Layout Block Filter **excludes blocks from search-indexed rendering** — letting site builders
remove chosen blocks from an entity's layout before Search API renders it for indexing, so navigational/irrelevant
blocks don't pollute the indexed text. It depends on Search API and core Layout Builder, and provides its own
permissions.

Use it to keep search index content clean. It is a search/site-building feature; it affects what gets indexed and
has no access-control role beyond its permission. Configure which blocks to exclude from indexing.

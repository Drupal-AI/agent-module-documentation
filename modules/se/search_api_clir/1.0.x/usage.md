Cross-language information retrieval for Search API.

---

Search API CLIR provides cross-language information retrieval — retrieving search results in a language different from the language of the search terms (e.g. an English query returning relevant French documents), by translating query terms (via TMGMT locale) so multilingual content is searchable across languages. Depends on core `language`, `search_api`, and `tmgmt_locale`; supports Drupal 10 and 11.

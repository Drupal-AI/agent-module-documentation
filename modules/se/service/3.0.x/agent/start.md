# Service — agent index

A **developer helper**: traits + extended base classes to make **dependency injection** easier in custom code
(less DI boilerplate). Requires PHP 8.3. Version **3.0.1**. Core `>=8`.

Pure developer/API utility — no end-user features, no routes, no config; no content/access role. Depend on it
from custom code.

Service provides traits and extended base classes to make dependency injections easier.

---

Service is a **developer helper** module — it provides traits and extended base classes that make
**dependency injection** less boilerplate-heavy in custom code (so controllers/forms/services can pull
dependencies with less wiring). It requires PHP 8.3 and core 8+.

Use it as a scaffolding dependency for your own modules. It is a pure developer/API utility — it ships no
end-user features, no routes and no configuration, and has no content or access role. Depend on it from custom
code that uses its traits/base classes.

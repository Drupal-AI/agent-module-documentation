Search API Japanese Normalizer provides a processor for Japanese text.

---

Search API Japanese Normalizer provides a **Search API processor that normalizes Japanese text** —
normalizing full-/half-width characters, kana and related forms during indexing/query so Japanese searches match
consistently across variants. It depends on the Search API module, in the Search package.

Use it to improve Japanese search matching. It is a site-search feature affecting index/query text processing;
results follow the search index's access and it has no access-control role. Add the processor to your index.

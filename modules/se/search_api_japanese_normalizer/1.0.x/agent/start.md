# Search API Japanese Normalizer — agent index

A **Search API processor that normalizes Japanese text (width/kana)** for better matching. Depends on
`search_api`. Version **1.0.0-beta1**. Core `^10||^11`.

Site-search — affects index/query text; results follow the index's access; no access role.

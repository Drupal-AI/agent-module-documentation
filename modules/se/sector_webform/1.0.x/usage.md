Sector Webform provides the default content and configuration for Webforms in Sector 10.

---

Sector Webform provides default Webform content and configuration for the Sector 10 distribution/theme —
pre-built webforms and settings so Sector-based sites get ready-made forms out of the box. It depends on the
Webform module, in the Sector package.

Use it on Sector-based sites for ready-made webforms. It is a forms/default-content feature; the webforms are
authored config/content governed by Webform's own access, and it has no access-control role. Enable it to get
the default Sector webforms.

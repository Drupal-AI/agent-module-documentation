# Database Logging Search Field — agent index

Adds a **search box to the core Database Logging (dblog)** report (search/filter recent log messages by
keyword). Depends on core `dblog`. Version **2.0.1**. Core `^8.8||^9||^10||^11||^12`.

Admin/UI — enhances the log report; access governed by existing `access site reports` permission; no access
role.

Database Logging Search Field adds a search box to the core Database Logging (dblog) recent log messages report.

---

Database Logging Search Field adds a search box to Drupal's core Database Logging (dblog) report — so
administrators can search/filter the recent log messages by keyword, rather than paging through them, making
it easier to find specific log entries. It depends on core Database Logging (dblog).

Use it to search the log report efficiently. It is an administration/UI feature enhancing the dblog report;
access to the log report is governed by the existing `access site reports` permission (it doesn't change
who can see logs), and it has no access-control role. Enable it to add search to the log page.

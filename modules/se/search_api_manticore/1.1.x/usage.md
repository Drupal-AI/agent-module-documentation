A Manticore Search backend for Search API.

---

Search API Manticore offers an implementation of the Search API that uses a Manticore Search server for indexing content — so a site can use Manticore (a fast open-source search engine) as its Search API backend instead of database/Solr/Elasticsearch, for high-performance full-text search.

The Manticore connection credentials are handled via a Key entity (`key` dependency, env-backed). Depends on core `key`, `language`, and `search_api`; supports Drupal 10.5+ and 11.

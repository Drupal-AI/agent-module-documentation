Select With Search is a field widget rendering a searchable select dropdown.

---

Select With Search provides a field widget (`SelectWithSearch`) that enhances a standard select element with a search/filter box and label, making long option lists easier to use. It ships its own CSS/JS library and is configured per-field on the entity's form display. It is a front-end editing-UX module: no routes, no permissions, and no server-side data handling beyond the normal field widget.

---

- Turn a long select list into a searchable dropdown.
- Filter options as the editor types.
- Apply the widget per field via Manage form display.
- Improve UX for taxonomy/reference select fields.
- Show a label alongside the search box.
- Reduce scrolling through large option sets.
- Use on any field that renders as a select.
- Keep styling via the bundled CSS library.
- Attach behavior via the bundled JS library.
- Avoid third-party autocomplete dependencies.
- Work on Drupal 9 and 10.
- Provide a lightweight select-enhancement.
- Speed up content entry forms.
- Keep the standard select semantics/values.
- Configure without custom code.
- Enhance admin and front-end forms alike.

Boost Solr results by taxonomy terms referenced on the user.

---

Search API Solr Boost By User Term adds a special Views filter which can boost indexed taxonomy term fields — so Solr search results can be ranked higher when they match taxonomy terms referenced on the current user (e.g. their interests), personalising result ordering. Depends on core `views`, `search_api`, `search_api_solr`, and `user_ref_field_cache_context`; supports Drupal 8.8 through 11.

# Session Reminder — agent index

Shows a **modal warning before the user's Drupal session cookie expires** (extend the session / avoid losing
work). Depends on core `user`. Version **1.0.3**. Core `^9||^10||^11`.

Usability/security-adjacent — reflects the session lifetime (core still controls the actual timeout); no access
role.

An example module demonstrating semantic versioning.

---

Semantic versioning example does nothing and does it very well — a deliberately-empty example module used to demonstrate/test Drupal's semantic-versioning support (version numbering, release handling). It ships no functionality; it exists as a reference/testing artifact. Supports Drupal 8 and later.

Send Mails provides an API for sending emails.

---

Send Mails provides an **API for sending emails programmatically** — a helper/service layer for other code
to send mail in a consistent way. It provides its own permissions, in the Mail package.

Use it as a developer mail-sending API. It is a mail/developer feature. Security note: any mail-sending API is
powerful — ensure only trusted code/flows send mail (to avoid it becoming a spam/relay vector), gate its
permission, and keep recipient/content sources trusted. It has no access-control role beyond its permission. Use
the API to send mail.

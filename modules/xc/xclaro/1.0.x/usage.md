xClaro adds a dark display to Claro.

---

xClaro adds a dark display/mode to Drupal's core Claro admin theme — giving the admin UI a dark colour
scheme for reduced eye strain / low-light use. It is in the Other package.

Use it for a dark Claro admin experience. It is an administration/theming feature affecting the admin theme's
appearance; it does not change content or access and has no access-control role. Enable it for dark Claro.

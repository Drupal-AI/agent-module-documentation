# xClaro — agent index

Adds a **dark display (dark mode) to the core Claro admin theme** (dark admin UI — reduced eye strain / low
light). Version **1.0.0-beta3**. Core `^11`.

Admin/theming — affects the admin theme's appearance; no content/access change. No access role.

Field Autovalue provides a pluggable way to provide automatic values to fields.

---

Field Autovalue provides a pluggable system for automatically populating field values — so fields can be
auto-filled from configured plugins (computed values, defaults derived from other data) when content is
created/saved, without custom code. This suits auto-generated identifiers, derived values or computed
defaults.

Use it to auto-populate fields via plugins. It is a content-editing/fields feature setting field values; the
values become content and it has no access-control role. Configure the autovalue plugin on the field.

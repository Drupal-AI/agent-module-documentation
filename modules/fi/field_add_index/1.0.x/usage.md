Field Add Index adds a database index to a custom field.

---

Field Add Index **adds a DB index to a field** — letting site builders add a database index to a custom
field's column(s) to speed up queries/filters on that field. It works on core 10–11.

Use it to index frequently-queried fields. It is a performance/developer feature; it alters the field's database
schema (adds an index) and has no content or access role. Note: adding indexes on large tables can be
resource-intensive — run during maintenance. Configure the field index.

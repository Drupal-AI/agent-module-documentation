# Field translation synchronize — agent index

Provides **actions to synchronize field values across an entity's translations** (keep shared fields — image/
price — consistent across languages). Depends on core `action`, `content_translation`; provides permissions.
Version **1.0.1**. Core `^8.8||^9||^10||^11`.

Multilingual/content — modifies content via actions; no access role beyond permission.

Field translation synchronize provides actions to synchronize field translation values across an entity's translations.

---

Field translation synchronize provides actions to keep field values in sync across an entity's
translations — copying/synchronizing a field's value from one translation to the others, so fields that
should be identical across languages (e.g. a shared image, a price) stay consistent. It depends on core
Action and Content Translation, provides its own permissions, in the Multilingual package.

Use it to synchronize shared field values across translations. It is a multilingual/content feature acting on
translation values; it modifies content (via actions) and has no access-control role beyond its permission.
Configure which fields synchronize.

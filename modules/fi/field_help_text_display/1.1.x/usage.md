Field Help Text Display adds a Help Text column to the Manage Fields page.

---

Field Help Text Display **adds a Help Text column to the Manage Fields page** — showing each field's
configured description/help text directly in the Field UI's field list, so builders can review help text at a
glance. It depends on core Field UI.

Use it to see field help text in the field list. It is a site-building/admin convenience; it surfaces field
configuration (admin-facing) and has no content or access role. Enable it for the Help Text column.

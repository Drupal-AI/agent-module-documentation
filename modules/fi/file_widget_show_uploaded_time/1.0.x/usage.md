File Widget Show Uploaded Time displays each file's upload date in the file field widget.

---

File Widget Show Uploaded Time enhances the file field widget by showing the latest uploaded date for each file, so content editors can quickly see when a file was uploaded and judge whether it may be time for an update. It's a small editorial-UX improvement.

It's a widget enhancement with no content or access role of its own. Depends on core `field` and `file`; supports Drupal 8 through 11.

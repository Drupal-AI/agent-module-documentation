Files to Media Migrate migrates file fields to media fields using Drush batching.

---

Files to Media Migrate **converts file fields to media fields** — migrating existing file-field values into
Media (image/file) entities and references, run via Drush with batching. It depends on core Media, Media
Library, File, Migrate and Migrate Drupal, in the Migration package.

Use it during a media migration to adopt the media library. It is a developer/migration tool run by admins; it
transforms existing content (back up first, as with any migration) and follows core media/file access, and it
has no access-control role. Run the Drush migration to convert fields.

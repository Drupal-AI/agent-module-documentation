# Files to Media Migrate — agent index

Migrates **file fields to media fields** via Drush + batching (adopt the media library). Depends on core
`media`, `media_library`, `file`, `migrate`, `migrate_drupal`. Version **1.0.x** (dev). Core `^9||^10||^11`.

Developer/migration — transforms existing content (back up first); follows core media/file access; no access
role.

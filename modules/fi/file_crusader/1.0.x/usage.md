File Crusader moves files in the public file system.

---

File Crusader **moves and organizes files within the public file system** — relocating managed files into a
structured directory layout (e.g. by date/type) and updating references, to keep the files directory tidy. It
depends on core File.

Use it to reorganize the public files directory. It is a media/file-management admin tool run by privileged
users; moving files rewrites file references and touches the filesystem (a privileged, potentially disruptive
action — back up and run as a trusted operator). It has no access-control role. Run the file reorganization.

Hide individual field labels in forms per content type via Manage form display.

---

Field Label Visibility lets you hide the label of individual fields in forms from 'Manage form display', for selected content types — so a site builder can suppress specific field labels on the entity edit form (e.g. for a cleaner layout) without CSS or code. Depends on core `field` and `node`; supports Drupal 10.3+ and 11.

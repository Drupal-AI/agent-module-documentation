Field Compose composes multi-value fields stored as encoded data.

---

Field Compose **composes multi-value fields as encoded data** — a field type that stores multiple sub-values
as a single encoded field value, for compact structured field data. It depends on core Field.

Use it for composite encoded field values. It is a content-editing/field-types feature; the encoded value is
stored/decoded for display and it has no access-control role. Configure the compose field.

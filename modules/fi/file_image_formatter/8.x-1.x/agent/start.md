# File Image Formatter — agent index

A field **formatter for File fields that renders files that may be images as images** (D6-migrated sites where
images live in file fields). Depends on core `file`. Version **8.x-1.0**. Core `^10.3||^11`.

Content-display/formatter — file rendered (as image) respecting file access; no access role.

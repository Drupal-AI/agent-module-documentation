File Image Formatter provides a field formatter for file fields that may be images, useful for Drupal 6 migrated sites.

---

File Image Formatter provides a formatter for **File** fields (not Image fields) that renders the file
as an image when it is one — useful for Drupal 6-migrated sites where images were stored in file fields, so
those images display properly without re-migrating to image fields. It depends on core File.

Use it to display images stored in file fields. It is a content-display/formatter feature; the file is
rendered (as an image) respecting normal file access, and it has no access-control role. Select the formatter
on the file field.

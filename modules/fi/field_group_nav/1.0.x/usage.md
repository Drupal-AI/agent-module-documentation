Field group nav provides the nav element for the content.

---

Field group nav adds a `<nav>` field-group format to the Field Group module — so grouped fields can be
wrapped in a semantic `<nav>` element (rather than a generic div), improving markup semantics/accessibility
for navigation-like field groups. It depends on the Field Group module.

Use it for semantic nav wrappers on field groups. It is a content-display/field-group feature affecting
markup; it has no content or access role. Select the nav field-group format.

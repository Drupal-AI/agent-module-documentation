Field Default Value Display adds a Default Value column to the Manage Fields overview.

---

Field Default Value Display **adds a Default Value column to the Manage Fields overview** — showing each
field's configured default value directly in the Field UI's field list, so builders can see defaults at a glance.
It depends on core Field and Field UI.

Use it to see field defaults in the field list. It is a site-building/admin convenience; it surfaces field
configuration (admin-facing) and has no content or access role. Enable it for the Default Value column.

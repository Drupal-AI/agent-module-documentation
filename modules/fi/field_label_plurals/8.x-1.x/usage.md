Field Label Plurals allows both singular and plural labels for multi-value fields, showing the appropriate form based on the number of values.

---

Field Label Plurals lets a multi-value field have both a singular and a plural label, displaying the
grammatically correct form based on how many values the field holds — "1 author" vs "3 authors". This
avoids awkward always-plural (or always-singular) labels on cardinality-many fields. It depends on core
Field.

Use it wherever multi-value field labels should read naturally regardless of value count. It is a
content-display/labeling feature affecting how field labels render; it does not change data or access.
Configure the singular and plural label forms on the field.

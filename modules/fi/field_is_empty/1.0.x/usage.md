A computed field reflecting whether another field is empty.

---

Field Is Empty provides a computed field that depends on whether another field is empty or has a value — exposing a boolean-like computed value that other logic (Views filters, conditions, displays) can use to act on emptiness of a source field, without custom code. Depends on core `field`; supports Drupal 8 through 11.

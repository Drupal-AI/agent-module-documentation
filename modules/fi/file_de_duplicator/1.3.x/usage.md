File De-Duplicator helps find duplicate files uploaded.

---

File De-Duplicator **helps find and de-duplicate identical uploaded files** — detecting duplicate managed
files (by hash) so repeated uploads of the same file can be consolidated, saving storage. It depends on core
File, provides its own permissions, in the Field types package.

Use it to reduce duplicate file storage. It is a media/file-management admin tool run by privileged users
(gated by its permission); de-duplicating rewrites file references, so run it as a trusted operator and back up
first. It has no access-control role beyond its permission. Run the de-duplication.

# File De-Duplicator — agent index

**Helps find and de-duplicate identical uploaded files** (by hash; save storage). Depends on core `file`.
Provides permissions. Version **1.3.0**. Core `^8||^9||^10||^11`.

Media/file-management admin tool — rewrites file references (trusted operator, back up first); gated by its
permission. No access role beyond permission.

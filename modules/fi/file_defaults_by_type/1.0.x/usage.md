Adds file types with default files on a File field.

---

File defaults by type adds types on a File field with defaults — so a File field can define multiple 'types' each with its own default file, letting content start with the right default document/asset per type. Depends on core `file` and `multivalue_form_element`; supports Drupal 10.2+ and 11.

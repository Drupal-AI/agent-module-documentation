Field Usage Tracker tracks and displays where fields are used.

---

Field Usage Tracker **tracks and displays where fields are used** across the site — reporting which
content types/entities reference or populate a given field, so site builders can understand field usage before
changing or removing fields. It provides its own permissions, in the Custom package.

Use it to audit field usage before refactoring. It is a developer/site-building reporting tool; its report is
gated by its permission (admin/site-builder), and it has no access-control role beyond that. Review the field
usage report.

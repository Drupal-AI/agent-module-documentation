Common finder functionality: display, index, and filter listings.

---

Finders provides common Finders functionality — display, index, and filter — a framework for building 'finder' listing pages (search/browse UIs over indexed content) using Search API and Views Reference, on which specific finder types build. Depends on core `block`, `views`, `search_api`, and `viewsreference`; supports Drupal 11.3+.

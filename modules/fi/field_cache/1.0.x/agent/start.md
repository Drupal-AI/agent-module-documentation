# Field Cache — agent index

**Adds cache configuration (max-age, contexts, tags) to field formatter settings** and applies it. Version
**1.0.1**. Core `^9||^10||^11`.

Performance/developer — sets render cache metadata (set contexts/tags carefully — wrong values cause stale/over-
varied output); no content/access role.

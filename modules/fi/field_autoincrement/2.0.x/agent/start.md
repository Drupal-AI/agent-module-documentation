# Field Autoincrement — agent index

An **atomic auto-increment field type with configurable prefix/suffix** (sequential invoice/reference/ticket
numbers; atomic → no collisions under concurrency). Depends on core `field`. Version **2.0.0**. Core
`^10.1||^11`.

Fields — generates/stores a number; no content/access role.

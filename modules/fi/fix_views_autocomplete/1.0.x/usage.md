Fix Views Autocomplete fixes the Views autocomplete route parameter error for empty view args.

---

Fix Views Autocomplete **fixes a Views autocomplete routing error** — resolving the "argument must match
[^/]++" error by allowing empty `view_args` in the Views autocomplete route, so autocomplete works when arguments
are empty. It works on core 10–11.

Use it if you hit the Views autocomplete arg error. It is a bug-fix/developer feature; it adjusts a route parameter
and has no content or access role. Enable it to fix the error.

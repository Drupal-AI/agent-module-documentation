# File entity — file types, display & permissions

## File types (bundles)
`/admin/structure/file-types` (permission **`administer file types`**) — create/edit/enable/disable/delete
file types. Types are typically organised by MIME (image, document, video, audio). Each type is an
entity bundle, so you can **attach fields** to it (captions, credits, rights, alt metadata) and give
it **view/form displays** like any fieldable entity.

## File pages, add & manage routes
| Route | Path | Access |
|---|---|---|
| View a file | `/file/{file}` | `_entity_access: file.view` |
| Download | `/file/{file}/download` | `_entity_access: file.download` |
| Edit | `/file/{file}/edit` | `_entity_access: file.update` |
| Inline edit | `/file/{file}/inline-edit` | `_entity_access: file.update` |
| Delete | `/file/{file}/delete` | `_entity_access: file.delete` |
| Add file | `/file/add` | `_entity_create_access: file` |
| File admin listing | `/admin/content/files` | `administer files` |
| Bulk delete / archive | `/admin/content/files/delete`, `/archive` | `administer files` |
| Settings | `/admin/config/media/file-settings` | `administer files` |

> The `/file/add/upload` and `/file/add/upload/file` routes are declared with `_permission: 'access
> content'` but their controller methods (`FileController::FileAddUpload` / `FileAddUploadFile`) are
> **empty stubs** — they perform no upload. The real add flow is `entity.file.add_form` (`FileAddForm`),
> gated by `_entity_create_access: 'file'`.

## Permissions
| Permission | Notes |
|---|---|
| `bypass file access` | View/edit/delete all files regardless of restrictions (`restrict access`) |
| `administer files` | File admin, settings, bulk ops (`restrict access`) |
| `administer file types` | Manage file types (`restrict access`) |
| `create files` | Add/upload new files |
| `view files` / `view own files` | View any / own files |
| `view private files` / `view own private files` | Private-file viewing (any is `restrict access`) |

Per-file-type permissions are generated by `FileEntityPermissions::fileTypePermissions()` /
`extendPermissionDetails()`.

## Integrations
- **Views** — files (and their fields) are exposed to Views for listings.
- **Token** — file fields available as tokens.
- **Entity API / display modes** — files render with field formatters via configured view modes.

## Setup
Enable the module (pulls in `file`, `text`, `views`, `image`, `token`), define file types and their
fields, configure display modes at the type's *Manage display*, and grant the permissions above to the
appropriate roles.

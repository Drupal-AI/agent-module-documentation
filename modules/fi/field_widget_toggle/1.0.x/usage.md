Field Widget Toggle toggles the field widget body content.

---

Field Widget Toggle lets a **field widget's body be collapsed/toggled** in the edit form — adding a toggle
so a field's input area can be hidden/shown, tidying long content-edit forms. It is in the Field types package.

Use it to declutter edit forms. It is a content-editing/form-UI feature affecting the widget display; it has no
content or access role. Configure the toggle on a field widget.

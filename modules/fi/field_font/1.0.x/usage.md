Field Font lets editors attach a chosen font to content via a field.

---

Field Font provides a field type that lets editors select or specify a font to apply to content — attaching typography choices to entities so specific pieces of content can be rendered in a chosen font without theme changes.

Access to font fields is gated by `access font fields`. Because arbitrary fonts can be specified, review font-source configuration (external font URLs have privacy/loading implications). Depends on core `field`; supports Drupal 10 and 11.

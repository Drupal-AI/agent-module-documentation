Filter External Link Icon provides a text filter to mark external links.

---

Filter External Link Icon provides a **text filter that marks external links with an icon** — appending an
"external link" indicator to links pointing off-site, so readers can see a link leaves the site. It depends on
core Filter, in the Input filters package.

Use it to visually flag external links. It is a content-display/filter feature affecting link rendering; it has
no content or access role. Enable it on the relevant text format.

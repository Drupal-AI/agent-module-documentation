# Filter External Link Icon — agent index

A **text filter that marks external links with an icon** (indicate a link leaves the site). Depends on core
`filter`. Version **1.0.4**. Core `^8||^9||^10||^11`.

Content-display/filter — affects link rendering; no content/access role.

Field Display Toggle enables toggling field display.

---

Field Display Toggle **provides functionality to toggle field display on/off** — quickly enabling/disabling
whether a field shows in a view mode from the Manage Display UI, without dragging to the hidden region. It
depends on core Field UI, in the Custom package.

Use it to quickly show/hide fields in view modes. It is a site-building/display feature affecting display
config; it has no content or access role. Toggle fields in Manage Display.

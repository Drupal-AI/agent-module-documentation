Fallback Formatter renders a fallback field when the primary formatted field is empty.

---

Fallback Formatter **renders a fallback field when the primary field is empty** — a field formatter that, if
the field being displayed has no value, renders a configured fallback field instead, so displays always show
something meaningful. It depends on core Field.

Use it to provide display fallbacks. It is a content-display/field-formatter feature; both fields render per their
own handling (and access) and it has no access-control role. Configure the fallback formatter.

Field Formatter Theme provides custom theme-suggestion settings for field formatters.

---

Field Formatter Theme **provides custom theme suggestions for field formatters** — letting builders add
template-suggestion settings on field formatters so a field's markup can be themed with a dedicated template. It
depends on core Field.

Use it to theme specific field formatters. It is a theming/content-display feature; it adds theme suggestions and
has no content or access role. Configure the theme suggestion on a formatter.

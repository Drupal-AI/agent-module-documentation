Field Inline Template renders field output via an inline template edited in a code editor.

---

Field Inline Template lets site builders define an inline template (Twig-style markup) for rendering field output, edited through the CodeMirror code editor for a comfortable editing experience. It gives per-field custom display without creating theme template files.

Because inline templates can contain markup/logic, restrict who can configure them to trusted site builders. Depends on `codemirror_editor`; supports Drupal 10 through 11 (below 12).

Integrates FillPDF with the Media system.

---

FillPDF Media integrates FillPDF with Media — so a FillPDF template (a fillable PDF used to generate filled PDFs from entity data) can be stored/managed as a Media entity, aligning PDF-form generation with the site's media library. Depends on `fillpdf` and core `media`; supports Drupal 10.3+ and 11.

# Field Updater Service — agent index

Provides a **service to copy values between fields** (developer helper — transfer a value field-to-field, e.g.
in migrations/updates). Depends on core `field`. Version **1.0.0**. Core `^10.3||^11||^12`.

Developer/API — operates on field data under the caller's control; no content/access role.

Field Updater Service provides a service to copy values between fields.

---

Field Updater Service provides a **service to copy values between fields** — a developer helper for
programmatically transferring a value from one field to another on an entity (e.g. during migrations, updates
or hook logic), without repeating boilerplate. It depends on core Field, in the Fields package.

Use it as a developer utility to move field values. It is a developer/API module; it operates on field data
under the calling code's control and has no content or access role of its own. Depend on it and use the field-
copy service.

Apply configurable styling to fields.

---

Field Style lets site builders apply configurable styling to fields — attaching style options (classes/wrappers) to a field's output on displays, so fields can be visually styled from the UI without custom CSS/templates. Depends on core `field`, `node`, and `paragraphs`; supports Drupal 9.4+ through 12.

Field Usage Display adds an 'Also used in' column to the Manage Fields page.

---

Field Usage Display **shows shared-field usage** — adding an "Also used in" column to the Field UI's Manage
Fields page, listing which other bundles share each field, so builders understand field reuse. It depends on core
Field UI.

Use it to see where fields are reused. It is a site-building/admin convenience; it surfaces field configuration
(admin-facing) and has no content or access role. Enable it for the usage column.

# Field Usage Display — agent index

**Adds an 'Also used in' column to the Manage Fields page** (shows shared fields across bundles). Depends on core
`field_ui`. Version **1.1.0**. Core `^11`.

Site-building/admin convenience — surfaces admin-facing field config; no content/access role.

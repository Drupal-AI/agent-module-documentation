Integrates the FitText.js library for responsive, scalable headline text.

---

FitText integrates the FitText.js library — a jQuery plugin for 'inflating' web type — so configured headline text scales fluidly to fill its container width, keeping big display text responsive across screen sizes. It's a frontend/theming enhancement. Supports Drupal 8.8 through 11.

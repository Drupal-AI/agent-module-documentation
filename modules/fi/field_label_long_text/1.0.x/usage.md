Field Label Long Text extends the character limit for field labels or switches them to a textarea, allowing longer label text.

---

Field Label Long Text lifts the default character limit on field labels — allowing longer label text,
or switching the label input to a textarea — for cases where a field genuinely needs a long
label/question (surveys, detailed forms). It depends on core Field and is configured at
`field_label_long_text.admin_settings`.

Use it where field labels must be longer than core allows (e.g. full-sentence questions). It is a
content-editing/field feature affecting label length/input; it does not change field data or access.
Configure which fields get extended labels.

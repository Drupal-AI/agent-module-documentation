# Field Label Long Text — agent index

Extends the **character limit of field labels** (or switches to a textarea) — allows longer labels/
questions. Depends on core `field`. Config at `field_label_long_text.admin_settings`. Version **1.0.6**.
Core `^10.1||^11||^12`.

Content-editing/field feature — affects label length/input, not data/access.

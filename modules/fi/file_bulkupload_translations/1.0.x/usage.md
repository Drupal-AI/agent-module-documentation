Bulk-upload files and their translations by filename convention.

---

File Bulkupload Translations allows bulk upload of a file and its translations according to naming — so a set of files following a naming convention (e.g. `doc.en.pdf`, `doc.fr.pdf`) can be uploaded together and imported as a translated media entity, easing multilingual media management. Depends on core `content_translation`, `field_ui`, and `media`; supports Drupal 11.2+.

# Firebase UI — agent index

A **UI for sending and scheduling Firebase push notifications** (compose + schedule FCM delivery). Version
**1.0.5**. Core `^10.3||^11`.

Notifications/integration — uses **Firebase credentials/server key** (store as secrets, HTTPS); gate the
sending UI to trusted staff (broadcast capability). No access role beyond gating.

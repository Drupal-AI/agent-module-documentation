Field Suggestion suggests frequently-used values for a field so editors can pick instead of retype.

---

Field Suggestion collects often-used values of a field and offers them as suggestions, so editors can select a previously-used value to auto-fill the field instead of typing it each time. It supports pinning/unpinning suggestions and ignoring the feature per field.

Permissions cover administration (`administer field suggestion`), ignoring (`ignore field suggestion`), and pinning (`pin and unpin field suggestion`). Depends on core `field`, `user`, `dynamic_entity_reference`, and the `service` module (>=3.0); requires Drupal 10.1+.

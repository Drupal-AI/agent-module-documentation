Shows each field's cardinality on the field overview page.

---

Field Quick Cardinality displays the cardinality setting of a field on the field overview page — so a site builder can see at a glance how many values each field allows (1, N, unlimited) without opening each field's settings, speeding up content-model review. Depends on core `field_ui`; supports Drupal 9, 10, and 11.

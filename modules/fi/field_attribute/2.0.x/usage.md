Field Attribute provides additional field attributes.

---

Field Attribute provides **additional configurable attributes on fields** — letting site builders attach
extra attributes (e.g. HTML attributes/data-attributes or metadata) to a field's output, for theming or
integration hooks, without custom code. It is in the Fields package.

Use it to add extra attributes to field rendering. It is a fields/theming feature affecting markup/attributes;
the attribute values are admin-configured (keep them trusted, as with any attribute output) and it has no
content or access role. Configure the extra field attributes.

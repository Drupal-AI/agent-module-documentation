A Finders finder type for events with recurring dates and calendars.

---

Finders Events provides a finder type for events with recurring dates and calendars — extending the Finders framework with an event finder that indexes recurring-date events (via Date Recur) and offers calendar displays, so visitors can search/browse events. Depends on `finders`, `date_recur` (+ modular/search_api), and `calendar_view`; supports Drupal 11.3+.

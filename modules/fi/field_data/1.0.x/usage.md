Field Data (Local Tasks More) adds a Data tab to Drupal core's Field list report.

---

Field Data **adds a Data tab to core's Field list report** — extending the Field UI's field report with an
additional "Data" view/tab giving more insight into field usage/data. It depends on core Field UI and Options, and
provides its own permissions.

Use it for deeper field reporting in admin. It is a site-building/administration tool; it surfaces field
information (admin-facing) and has no content or access role beyond its permission. View the field Data tab.

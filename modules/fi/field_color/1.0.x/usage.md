Field Color provides a color picker.

---

Field Color provides a **color-picker field type** — letting content store a color value chosen via a
color picker, for per-entity color/theming. It is in the Field package.

Use it to add a color field. It is a fields feature; it stores a color value and has no content or access role.
Add the color field to a bundle. If the stored color is emitted into inline CSS, output it safely (validate it
is a color).

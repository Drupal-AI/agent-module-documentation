# File Metadata PDF — agent index

A **File Metadata Manager plugin that reads metadata from PDF files** (page count/dimensions/title/…). Depends on
`file_mdm`. Version **1.0.0-alpha5**. Core `^11.2`.

Media/developer — **parses PDF files** (untrusted input; parse in a trusted environment); files follow core file
access. No access role.

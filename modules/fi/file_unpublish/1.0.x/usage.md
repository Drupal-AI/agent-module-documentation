Hide (unpublish) public files when their media entity is unpublished.

---

Unpublish Public Files hides (unpublishes) public files when their media entities become unpublished — so when an editor unpublishes a media item, its underlying public file is moved/hidden so it can no longer be accessed directly by URL, closing the gap where unpublished media files stay reachable.

It's an access-hardening module for public-file media. Depends on core `media` and `file`; supports Drupal 10.4+ and 11.

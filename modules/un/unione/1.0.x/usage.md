Send transactional emails through the UniOne email API.

---

UniOne provides a service for sending emails using the UniOne API — a MailSystem plugin that routes Drupal's outgoing mail through UniOne (a transactional email delivery service), for reliable delivery, tracking and attachments.

The UniOne API key is admin-configured; store it securely (env-backed). Depends on `mailsystem` and core `file`; supports Drupal 10 and 11.

Unicode Soft Hyphens adds and highlights soft hyphens in plain text inputs.

---

Unicode Soft Hyphens helps editors **add and see Unicode soft hyphens** (U+00AD) in plain-text inputs —
soft hyphens are invisible characters that tell the browser where a long word may break across lines, and this
module makes inserting and **highlighting** them manageable (since they're otherwise invisible). It is in the
User interface package.

Use it to control line-breaking of long words/URLs. It is a content-editing/UI utility affecting text input;
it has no content or access role. Use it on the relevant text inputs.

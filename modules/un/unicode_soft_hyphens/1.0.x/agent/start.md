# Unicode Soft Hyphens — agent index

Adds and **highlights Unicode soft hyphens (U+00AD)** in plain-text inputs (control where long words break;
soft hyphens are otherwise invisible). Version **1.0.0**. Core `^10||^11`.

Content-editing/UI utility — affects text input; no content/access role.

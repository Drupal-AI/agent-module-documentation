Unlimited/multi-value Fields Extra Settings provides extra settings for unlimited / multi-value fields, adding options to control their behaviour/display.

---

Unlimited/multi-value Fields Extra Settings adds extra configuration options for unlimited (multi-value)
fields — giving finer control over how fields with unlimited cardinality behave or display (limits, ordering,
add-more behaviour, and similar per-field options) beyond core's defaults.

Use it on sites with multi-value fields that need extra behaviour/display control. It is a content-editing/
fields feature affecting field configuration; it has no content-value or access role. Configure the extra
settings on the relevant multi-value fields.

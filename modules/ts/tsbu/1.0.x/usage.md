Theme Switcher by User (tsbu) allows selecting a theme per user.

---

Theme Switcher by User (tsbu) lets each user choose their own theme — selecting which theme they see, so
users can have a per-user theme preference. It is configured at `tsbu.theme_switcher_settings` and provides
its own permissions.

Use it to allow per-user theme selection. It is a display/personalization feature affecting which theme a
user sees; the theme is presentation and it has no access-control role. Gate who may choose a theme with its
permissions, and restrict the selectable themes to trusted/appropriate ones (a theme is code/assets). Configure
the allowed themes.

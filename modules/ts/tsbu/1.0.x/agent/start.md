# Theme Switcher by User (tsbu) — agent index

Lets each **user select their own theme** (per-user theme preference). Config at
`tsbu.theme_switcher_settings`; provides permissions. Version **1.0.9-alpha1**. Core `^9||^10||^11`.

Display/personalization — theme is presentation (no content/access change). Gate who may choose via its
permission; restrict selectable themes to trusted ones. No access role.

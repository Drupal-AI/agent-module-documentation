TSI provides Drush commands and an API to add UI (interface) translations programmatically.

---

Managing interface-string translations at scale — adding many UI translations from code or a script — benefits from a programmatic path. TSI provides Drush commands and an API to add UI translations. It is developer/deployment tooling for translations. No unusual security surface; it modifies interface translations (which affect displayed strings, not access). Run it as a controlled operation and confirm the added translations are the intended strings.

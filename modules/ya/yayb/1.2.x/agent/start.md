# YAYB (Alert Block) — agent index

Lets **content managers post alert messages to a block** (manager-editable site alerts/banners). Provides
permissions. Version **1.2.2**. Core `^11.2||^12`.

User-engagement — alert content is manager-authored (keep trusted); no access role beyond permission.

YAYB allows content managers to post alert messages to a block.

---

YAYB ("Yet Another Alert Block") lets **content managers post alert messages to a block** — configurable
site alerts/banners (announcements, notices) that display in a block region, managed without touching code. It
provides its own permissions, requires core 11.2+.

Use it to show manager-editable site alerts. It is a user-engagement feature; alert content is authored by
managers (rendered markup — keep it trusted) and it has no access-control role beyond its permission. Configure
and post the alerts.

Yaml Toolkit provides YAML validation and read/write utilities for developers.

---

Yaml Toolkit provides a validator and tools for reading and writing YAML files — developer utilities for safely parsing, validating (against schema/structure), and writing YAML, used by modules that need robust YAML handling (config-as-code, data import/export).

It's a developer/utility library with no content or access role of its own. Supports Drupal 10 and 11.

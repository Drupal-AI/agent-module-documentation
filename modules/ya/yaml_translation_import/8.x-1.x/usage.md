YAML Translation Import makes it possible to import interface (locale) translation strings from YAML files.

---

YAML Translation Import is a developer module that imports interface translations from YAML files —
letting developers maintain UI string translations as YAML in the codebase and import them into Drupal's
locale system, rather than only through .po files or the translation UI. It depends on core Locale and
provides its own permissions.

Use it in development/deployment workflows where translations are managed as YAML alongside code. It is a
developer/multilingual tool operating on the locale (translation) system, typically run during setup or
deployment. Imported strings become interface translations; it has no runtime access role. Provide the
YAML translation files and run the import.

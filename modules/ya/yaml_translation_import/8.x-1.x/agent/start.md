# YAML Translation Import — agent index

Developer module to **import interface (locale) translations from YAML files** — maintain UI string
translations as YAML in code instead of only .po/UI. Depends on core `locale`; provides permissions.
Version **8.x-1.3**. Core `^9||^10||^11`.

Developer/multilingual tool (locale system; run at setup/deploy). No runtime access role.

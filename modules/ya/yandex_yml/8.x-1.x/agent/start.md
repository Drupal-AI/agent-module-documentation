# Yandex YML — agent index

Generates a **Yandex Market Language (YML)** product feed — the XML format **Yandex Market** ingests to
list a store's products (prices, availability, attributes). Version **8.x-1.4**. Core `^9||^10||^11`.

Export/integration feed (typically a public endpoint) — expose only intended product data; keep
mappings aligned with the YML spec.

# AI Libraria Chatbot Integration — agent orientation

**Machine name:** `ai_libraria_chatbot`  
**Version dir:** `1.0.x`  
**Core:** `^8 || ^9 || ^10`  
**Dependencies:** none  
**Configure route:** `ai_libraria_chatbot.admin_settings_form`

## What it does
Embeds a Libraria.ai chatbot on the site via a configurable embed script and block.

## Where to look
- `ai_libraria_chatbot.info.yml` — metadata and dependencies.
- `ai_libraria_chatbot.routing.yml` / `.permissions.yml` / `.services.yml` — routes, permissions, services (where present).
- `src/` — controllers, forms, plugins and services.

See `../usage.md` for install, configuration and usage details.

# AI Scraping Bot — manual setup guide

**AI Scraping Bot** (`ai_interpolator_scraping_bot`) lets AI field automation pull
in content from a web page. It plugs into Drupal's AI field-interpolation
workflow: when a field's value is being generated by AI, this add-on can fetch the
data behind a URL so that page's content becomes part of what the AI works with —
for example scraping a product page or an article to help fill in fields.

The actual page fetching is **delegated to the third-party ScrapingBot service's
API** rather than performed as a direct server-side request from your site. That
distinction matters: because the retrieval goes through ScrapingBot, this is not a
classic server-side-request tool, but it is still an outbound integration — the
URLs you point it at (and, through them, the page contents) are handled by an
external service. Treat any URL your editors or automations feed it as untrusted
input, restrict who can trigger it, and be mindful that it can be used to fetch
arbitrary external pages, which has cost and abuse implications on a busy site.

To reach ScrapingBot the module needs an API credential, which it stores through
Drupal's **Key** module — so the secret lives in a Key entity backed by an
environment variable, never pasted into plain configuration.

This guide is written for a **human** clicking through the admin UI. If you want
terse, token‑cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Where it lives in the admin menu

This module has no settings page of its own. It contributes a scraping capability
to the AI field-interpolation system, and its ScrapingBot API credential is stored
as a **Key** entity (managed under **Configuration → System → Keys**). You select
and use its scraping behavior where you configure AI-generated fields.

## How to use it

1. Create a ScrapingBot account and get an API key, then store it as a Key entity
   (see [Installation](installation/index.md)).
2. On a field that is populated by AI field interpolation, choose the scraping
   behavior this module provides and point it at the URL whose content should feed
   the generation.
3. When that field is processed, the module asks ScrapingBot to fetch the page and
   passes the returned data into the AI workflow. Because each fetch is an external
   call, keep the ability to trigger it limited to trusted editors.

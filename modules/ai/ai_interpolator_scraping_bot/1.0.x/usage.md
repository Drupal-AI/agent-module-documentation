AI Scraping Bot fetches website data via the ScrapingBot service for AI field interpolation (scraping is delegated to ScrapingBot's API, not a direct server fetch). It builds on Drupal's AI module and depends on `key`, in the AI Tools package.

Use it for AI-assisted web scraping. It is an AI/integration feature. Security/data handling: it **sends
URLs to the configured AI provider** (external egress — confirm acceptable for the content), the provider **API key** is stored via the Key module (secret),
over HTTPS. It has no access-control role. Configure the AI
provider.

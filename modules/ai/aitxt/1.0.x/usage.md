ai.txt dynamically generates an ai.txt file (directives for AI crawlers/scrapers) and lets you edit it per-site from the web UI.

---

ai.txt dynamically generates an `ai.txt` file — the emerging convention (analogous to robots.txt) for
declaring how AI crawlers/scrapers may use a site's content — and lets administrators edit its contents
from the web UI on a per-site basis. It is configured at `aitxt.admin_settings_form` and provides its own
permissions.

Use it to publish AI-usage directives for your content. It is an SEO/crawler-control feature serving a
generated text file; it declares intent to AI crawlers (which, like robots.txt, is advisory — compliance
is up to the crawler) and has no access-control role. Configure the ai.txt contents in the admin UI.

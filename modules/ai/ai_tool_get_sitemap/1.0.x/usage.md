AI Tool: Get Sitemap provides a single AI Agents tool plugin that returns the site's own XML sitemap (as generated by Simple XML Sitemap) so an agent can use it for further processing.

---

AI Tool: Get Sitemap ships one function-calling tool plugin, `GetSitemap` (id `ai_tool_get_sitemap`), for use with the Drupal AI and Tool frameworks. When an AI agent calls the tool it reads the default sitemap from the local `simple_sitemap.generator` service and returns the generated XML content — it takes no arguments and fetches no remote URL. If the Simple XML Sitemap module is not present or the default sitemap has no links, the tool reports failure and recommends installing/configuring Simple XML Sitemap. It is a read-only tool (declared `ToolOperation::Read`) in the AI Tools package and depends on the `ai` and `tool` modules, plus `drupal/simple_sitemap` ^4 for the actual sitemap data.

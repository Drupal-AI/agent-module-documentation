AI Block provides one configurable Drupal block whose rendered body is the text a chosen AI model returns for an editor-defined prompt.

---

AI Block ships a single block plugin (`ai_block`). An editor places the block through the normal Block layout UI or Layout Builder, writes a prompt, and optionally selects which AI provider/model handles it; when the block renders, the module sends the prompt to the AI module's chat abstraction (`drupal/ai`) and prints the returned text through the `ai_block_response` theme template. The prompt runs through core token replacement (node and user tokens are supplied), so it can pull in contextual data, and two alter hooks (`hook_ai_block_prompt_alter`, `hook_ai_block_response_alter`) let other modules rewrite the prompt before the call or post-process the response after it. It depends on core `block` and `config` and on the contrib AI module, which must have a default chat provider (and provider API key) configured. Supports Drupal 10 and 11.

---

- Place a block whose content is generated by an AI chat model.
- Write a free-text prompt in the block configuration form.
- Summarise page or contextual data into a short block of copy.
- Pick a specific AI provider/model per block, or fall back to the AI module default chat provider.
- Insert `[node:*]` and `[user:*]` tokens into the prompt for per-page/per-user output.
- Render AI text in any theme region via the Block layout UI.
- Add an AI-generated block inside a Layout Builder section.
- Produce marketing or intro copy from a prompt without writing a custom module.
- Generate a per-node summary block driven by node tokens.
- Generate a per-user greeting or hint block driven by user tokens.
- Alter the prompt programmatically with `hook_ai_block_prompt_alter()` (e.g. inject your own `[my-data]` placeholder).
- Post-process the model response with `hook_ai_block_response_alter()` (e.g. convert Markdown to HTML).
- Reuse the same block plugin across many placements, each with its own prompt.
- Override the `ai-block-response.html.twig` template to restyle the output wrapper.
- Prototype AI-driven page elements quickly during a build.
- Surface an AI "explainer" panel next to existing content.
- Drive block copy from configuration so it is deployable via config export.
- Complement the AI module's provider setup with a no-code output surface.
- Keep AI output presentation-only (the block writes no data back to entities).
- Support Drupal 10 and 11 sites that already run the AI module.

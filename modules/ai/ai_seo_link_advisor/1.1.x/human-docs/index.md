# AI SEO Link Advisor — manual setup guide

**AI SEO Link Advisor** (`ai_seo_link_advisor`) checks the SEO metrics for a
URL and returns AI-powered suggestions to improve it. It leans on Drupal's
**AI** module for the model call, so once you have an AI provider configured on
the site, this module hands it a page's URL and content and turns the response
into practical, human-readable advice.

Because the analysis runs through the AI module, the URL and the page content
you ask it to check are **sent to whichever AI provider you have configured**
(for example OpenAI, Anthropic, or a locally hosted model). That is an external
call — only run it on content you are comfortable sending to that provider. The
provider's API key is never stored by this module; it lives in the AI module's
own configuration as a secret (a Key entity or an environment variable), and the
call goes over HTTPS. As with any AI output, treat the suggestions as a draft to
review, not a rule to apply blindly.

The module adds its own permission so you can decide who is allowed to run the
analysis. It has no other access-control role.

This guide is written for a **human** clicking through the admin UI. If you want
terse, token-cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Where it lives in the admin menu

This module builds on the AI module rather than on a standalone settings page.
Before you can use it, an AI **provider** must be configured under
**Configuration → AI** (`/admin/config/ai`) — that is where the model and the
provider API key (a secret) are set. Grant the module's permission to the roles
that should be allowed to run link/SEO analysis.

## How to use it

With the AI module configured and the permission granted, run the advisor
against a URL to get SEO metrics and AI suggestions for improving its internal
linking and on-page signals. Review each suggestion before acting on it — the
advice is generated by a language model and should be checked against your own
editorial and SEO judgement before you publish changes.

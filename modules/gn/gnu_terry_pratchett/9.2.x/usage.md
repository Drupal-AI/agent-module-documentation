GNU Terry Pratchett adds an X-Clacks-Overhead HTTP header set to 'GNU Terry Pratchett'.

---

GNU Terry Pratchett adds an **`X-Clacks-Overhead: GNU Terry Pratchett` HTTP header** to responses — a
long-standing internet tribute to author Terry Pratchett (from his Discworld "clacks" network). It is a small,
harmless response-header addition.

Use it as a tribute. It is a trivial HTTP-header feature; it adds one static response header and has no content
or access role. Enable it to add the header.

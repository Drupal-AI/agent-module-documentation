Let users request to add a node to a Group.

---

Group Node Request allows a request to add a node to a Group — so instead of directly adding content, a user can submit a request that a group manager approves/rejects (a state-machine workflow), useful for moderated group content. Depends on `group`, `gnode`, and `state_machine`; supports Drupal 10 and 11.

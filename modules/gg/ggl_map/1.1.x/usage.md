GGL Map adds a Google Map the easy way.

---

GGL Map lets you **add a Google Map the easy way** — a configurable map (via a field/block) without
manual JavaScript, for showing locations/markers on a Google Map. It depends on YAML Editor and Multiple
Fields Remove Button, provides its own permissions, in the Google Map package.

Use it to embed Google Maps. It is a content-display/maps feature. Security handling: Google Maps requires an
**API key** — store/restrict it appropriately (Google API keys should be **HTTP-referrer-restricted** to your
domain so a leaked key can't be abused/billed elsewhere), and the map loads **Google's third-party JavaScript**.
It has no access-control role beyond its permission. Configure the Google Maps API key and map.

# GGL Map — agent index

Adds a **Google Map the easy way** (configurable map field/block — locations/markers without manual JS).
Depends on `yaml_editor`. Provides permissions. Version **1.1.0**. Core `^9||^10||^11`.

Content-display/maps — needs a Google Maps **API key** (**referrer-restrict** it so a leaked key can't be
abused/billed); loads Google's **third-party JS**. No access role beyond permission.

A floating personal notes/to-do widget for logged-in users.

---

Personal Notes Widget (pnw) provides a floating personal notes/to-do widget for logged-in users — a private, per-user notes/to-do panel that floats over the page, so a user can jot personal reminders while browsing the site (notes are private to each user). Supports Drupal 10 and 11.

# The `views_vvjf` style plugin — enabling & options

## Enable it on a view

1. Edit a View → **Format** → change the display **Format** to *Views Vanilla JavaScript 3D Flipbox*.
2. The **row style is forced to Fields** (`enforceFieldsRowPlugin()` in `VvjStylePluginBase`); a non-Fields
   row is auto-switched, and `validate()` returns `"vvjf requires Fields as row style."` if it still isn't Fields.
3. The **first field** of each row becomes the card **front**; the remaining fields become the **back**
   (see [theming.md](theming.md) for the split contract). Order your fields accordingly, front field first.
4. Working reference: enable the optional `views.view.vvjf_example` view (installs from `config/optional/`
   when the id is free), demo page at `/vvjf-example` (`access administration pages`).

Plugin class: `Drupal\vvjf\Plugin\views\style\Flipbox`
(`#[ViewsStyle(id: 'views_vvjf', theme: 'views_view_vvjf', display_types: ['normal'])]`).
It extends `vvj_core`'s `VvjStylePluginBase`, which contributes the shared Advanced section, `render()`,
library attachment and validation. `Flipbox` only defines the flipbox-specific options
(`definePatternOptions()`) and five form sections (`buildPatternSections()` → Dimensions, Behavior, Style,
Animation, Responsive). It overrides `supportsDeeplinking()` → **FALSE** (per-card state is transient, so
there is no Deep Linking section and no `enable_deeplink`/`deeplink_identifier` options), and overrides
`buildLibraryList()` to append the breakpoint-specific CSS library (see [theming.md](theming.md)).

## Option reference

Config-schema key: **`views.style.views_vvjf`** (`config/schema/vvjf.schema.yml`). Defaults and bounds
come from `Drupal\vvjf\VvjfConstants`. Note this pattern uses its **own** easing list and breakpoint
select, not the shared `buildAnimationSelect()`/`buildBreakpointSelect()` helpers.

| Option key | Type | Default | Notes / constraints |
|---|---|---|---|
| `box_height` | int | `250` | Card height (px). Required. Min `100` (`MIN_BOX_HEIGHT`), step 1. |
| `box_width` | int | `300` | Grid box **minimum** width (px) for the auto-fit column grid. Min `0` (`MIN_BOX_WIDTH`); **`0` disables** the min-width constraint. |
| `grid_gap` | int | `16` | Gap between grid cells (px). Min `1` (`MIN_GRID_GAP`), step 1. |
| `perspective` | int | `1000` | 3D perspective depth. Min `0` (`MIN_PERSPECTIVE`), step `10` (`PERSPECTIVE_STEP`); **`0` disables** perspective. |
| `flip_trigger` | string | `click` | Choice: `hover` \| `click` (`TRIGGER_HOVER`/`TRIGGER_CLICK`). Click adds Enter/Space keyboard flip. |
| `flip_direction` | string | `vertical` | Choice: `horizontal` (Y-axis) \| `vertical` (X-axis) (`DIRECTION_HORIZONTAL`/`DIRECTION_VERTICAL`). |
| `front_bg_color` | string | `#f0fbff` | Front-face background. Form `#type => color` (browser hex). Stored as a plain string in schema. |
| `back_bg_color` | string | `#b8e7ff` | Back-face background. Form `#type => color`. |
| `flip_speed` | float | `0.9` | Flip animation duration (s). Required. Range **0.1–2.0** (`MIN/MAX_FLIP_SPEED`), step `0.1` (`FLIP_SPEED_STEP`). |
| `animation_easing` | string | `ease` | Choice: `ease` \| `linear` \| `ease-in` \| `ease-out` \| `ease-in-out` (`EASING_*`). |
| `available_breakpoints` | string | `576` | Choice: `all` \| `576` \| `768` \| `992` \| `1200` \| `1400`. The flip is **active at viewport widths ≥ this value** (`all` = always active); below it the flip is disabled and both faces show. Also selects the `vvjf/vvjf__<value>` media CSS library. |
| `enable_css` | bool | `TRUE` | Attach `vvjf/vvjf-style` (opt-in visual layer). Uncheck to supply your own CSS. Added by the base **Advanced Options** section. |
| `unique_id` | int | random 8-digit | Stable per-display id (`10000000`–`99999999`), generated by `vvj_core.unique_id_generator`. Not user-edited; carried through form submit (`flattenFormValues()` preserves it). |

## Form structure & submit

`buildPatternSections()` builds five open/closed `details` groups, in weight order:
**Dimensions Settings** (`dimensions_section`, `-40`), **Behavior Settings** (`behavior_section`, `-30`),
**Style Settings** (`style_section`, `-20`), **Animation Settings** (`animation_section`, `-10`), and
**Responsive Settings** (`responsive_section`, `0`, collapsed). The base then adds the **Advanced Options**
section (`enable_css`) and the read-only **Token Documentation** section (weight `100`). There is **no**
Deep Linking section.

On submit, `submitOptionsForm()` (`Flipbox.php:307`) reads `style_options`, runs it through
`flattenFormValues()` (`Flipbox.php:325`) to collapse the sectioned values back into the flat option array
the schema stores (falling back to each `VvjfConstants` default for any missing key), re-injects
`unique_id`, then calls the parent. There is **no** custom `validateOptionsForm()` on this plugin — bounds
are enforced by the form element `#min`/`#max`/`#step`/`#required` attributes plus config-schema typing;
cross-option validation (the accordion's exclusive/deeplink rules) does not apply here.

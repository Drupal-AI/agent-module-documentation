# The `views_vvja` style plugin — enabling & options

## Enable it on a view

1. Edit a View → **Format** → change the display **Format** to *Views Vanilla JavaScript Accordion*.
2. The **row style is forced to Fields** (`enforceFieldsRowPlugin()` in `VvjStylePluginBase`); a non-Fields
   row is auto-switched, and `validate()` returns `"vvja requires Fields as row style."` if it still isn't Fields.
3. The **first field** of the row becomes the panel trigger; the remaining fields render into the pane
   (see [theming.md](theming.md) for the split contract). Order your fields accordingly.
4. Working reference: enable the optional `views.view.vvja_example` view (installs from `config/optional/`
   when the id is free), demo page at `/vvja-example` (`access administration pages`).

Plugin class: `Drupal\vvja\Plugin\views\style\Accordion` (`#[ViewsStyle(id: 'views_vvja', theme: 'views_view_vvja', display_types: ['normal'])]`).
It extends `vvj_core`'s `VvjStylePluginBase`, which contributes the shared Advanced / Deep Linking /
Token-documentation sections, `render()` and library attachment. `Accordion` only defines the
accordion-specific options (`definePatternOptions()`) and sections (`buildPatternSections()` →
Behavior, Animation, Layout, Custom Icons).

## Option reference

Config-schema key: **`views.style.views_vvja`** (`config/schema/vvja.schema.yml`). Defaults come from
`Drupal\vvja\VvjaConstants` and (for speed bounds) `vvj_core`'s `ValidationBounds`.

| Option key | Type | Default | Notes / constraints |
|---|---|---|---|
| `single_toggle` | bool | `TRUE` | Show a per-panel +/- toggle button. |
| `global_toggle` | bool | `TRUE` | Show an "Expand/Collapse all" button. Incompatible with `exclusive_panel`. |
| `exclusive_panel` | bool | `FALSE` | Only one panel open at a time. Incompatible with `global_toggle` and with `expand_default: all`. Form disables it while `global_toggle` is checked. |
| `expand_default` | string | `none` | Panels open on load. Choice: `none` \| `first` \| `all` (`EXPAND_NONE/FIRST/ALL`). `all` is invalid with exclusive mode. |
| `animation` | string | `a-bottom` | Choice: `none` \| `a-top` \| `a-bottom` \| `a-left` \| `a-right` \| `a-zoom` \| `a-fade`. Reduced-motion users get none regardless. |
| `transition_speed` | float | `0.3` | Seconds. Required. Range **0.1–2.0** (`ValidationBounds::MIN/MAX_TRANSITION_SPEED`), `#step 0.1`. |
| `accordion_item_width` | int | `0` | Card width in px; `0` = full-width list layout. Required, min `0`. |
| `pane_padding` | int | `16` | Inner pane padding (px). Required, min `0`. |
| `panel_gap` | int | `16` | Gap between panels (px). Required, min `0`. |
| `enable_css` | bool | `TRUE` | Attach `vvja/vvja-style`. Uncheck to supply your own CSS. |
| `enable_deeplink` | bool | `FALSE` | Emit shareable `#accordion-<id>-<n>` fragments — see [../api/javascript.md](../api/javascript.md). |
| `deeplink_identifier` | string | `''` | URL slug. Required when `enable_deeplink`. Slug-normalized (lowercase, spaces→`-`, must start with a letter); ≤ 20 chars; regex `^[a-z][a-z0-9-]*[a-z0-9]?$`; rejects reserved words `accordion|panel|vvja|vvj`. Cleared when deep linking is off. |
| `svg_expand_content` | string | `''` | Custom SVG for the panel "expand" icon. Sanitized — see [theming.md](theming.md). |
| `svg_collapse_content` | string | `''` | Custom SVG for the panel "collapse" icon. |
| `svg_expand_all` | string | `''` | Custom SVG for the global "expand all" icon. |
| `svg_collapse_all` | string | `''` | Custom SVG for the global "collapse all" icon. |
| `unique_id` | int | random 8-digit | Stable per-display id (`10000000`–`99999999`), generated by `vvj_core.unique_id_generator`. Not user-edited; carried through form submit. |

## Form structure & validation

`buildPatternSections()` builds four `details` groups — **Behavior Settings** (`behavior_section`),
**Animation Settings** (`animation_section`), **Layout Settings** (`layout_section`), **Custom Icons**
(`icons_section`) — then the base adds **Advanced Options** (`enable_css`), **Deep Linking Settings**
and **Token Documentation**. On submit, `submitOptionsForm()` → `flattenFormValues()`
(`Accordion.php:428`) collapses the sectioned values back into the flat option array the schema stores.

`validateOptionsForm()` (`Accordion.php:351`) enforces the cross-option rules:
- `exclusive_panel` + `global_toggle` → error on the exclusive checkbox.
- `exclusive_panel` + `expand_default == all` → error on the expand select.
- `transition_speed` outside `0.1–2.0` → error (belt-and-braces over the `#min/#max`).

Each SVG textarea runs `validateSvgField()` (`Accordion.php:316`), which calls
`vvj_core.svg_sanitizer` `validate()` then `sanitize()` and stores the **sanitized** markup (or sets a
form error). SVG is re-sanitized again at render time (defense in depth) — see [theming.md](theming.md).

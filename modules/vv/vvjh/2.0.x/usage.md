Views Vanilla Javascript Hero (VVJH) provides a responsive hero display format for Views, implemented with vanilla JavaScript.

---

Views Vanilla Javascript Hero (VVJH) adds a responsive "hero" display style for Views — large
banner/slider-style presentation of View results — implemented in vanilla JavaScript (no jQuery or
heavy libraries). It is aimed at building hero sections and feature banners from View content that
adapt across screen sizes. Requires PHP 8.3 and depends on core Views and Filter plus a `vvj_core`
support module.

Use it to present curated content (featured articles, promotions) as a hero on landing pages, driven
by a View so the content stays editable. It is a Views display/theming feature — presentation only,
with no access implications; the Views' own access controls what content appears.

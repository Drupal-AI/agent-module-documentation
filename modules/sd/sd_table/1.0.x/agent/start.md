# SD Table — agent index

Provides the **SD Table field type for building rich, dynamic HTML tables through the UI** (CKEditor 5). Depends on
core `field`, `file`, `editor`, `ckeditor5`. Version **1.0.2**. Core `^11||^12`.

Content-editing/field — editor-built HTML tables render subject to the **text format's filtering** (ensure it
sanitizes to prevent XSS; restrict to trusted editors). No access role.

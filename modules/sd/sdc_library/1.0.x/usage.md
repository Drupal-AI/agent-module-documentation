SDC Library provides functionality to browse Single Directory Components.

---

SDC Library provides a **UI to browse Single Directory Components (SDC)** — listing the SDC components
available on the site (their props, slots and previews), as a developer/designer reference, with an
`sdc_library_paragraphs` submodule. It provides its own permissions.

Use it to explore available SDC components. It is a developer/theming tool; its browser is gated by its
permission (admin/developer), and it has no content or access role beyond that. Browse the component library.

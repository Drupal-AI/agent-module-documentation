A theme engine replacing Twig with React/Vue/Svelte components for SDX.

---

SDX DRAST is a DRAST theme engine for SDX — replacing Twig with React, Vue or Svelte framework components as Drupal's template pipeline, and shipping the `drast` theme engine plus DataProviders for typed JSON props on admin routes. So (with SDX) themes can be authored entirely in a JS framework. Depends on `sdx`; supports Drupal 10.3+ and 11.

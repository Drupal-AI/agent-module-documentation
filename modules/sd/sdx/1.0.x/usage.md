Modular front-end framework integration extending Single Directory Components.

---

SDX is a modular frontend framework integration for Drupal components — extending Single Directory Components (SDC) with React, Vue, Svelte and modern build tooling, so component authors can build Drupal SDC components using a modern JS framework and bundler instead of Twig-only components. It's a developer/theming framework. Supports Drupal 10.3+ and 11.

# SDC CSS Relocator — agent index

Relocates **Single Directory Component (SDC) stylesheets into the theme's CSS group** (correct cascade/
override + better aggregation vs the default library group). Version **1.0.0-alpha2**. Core `^10.3||^11`.

Performance/theming — changes CSS grouping/aggregation, not content/access. No access role.

sdc_css_relocator relocates component (SDC) stylesheets into the theme group, improving CSS ordering/aggregation.

---

SDC CSS Relocator relocates the stylesheets of Single Directory Components (SDC) into the theme's CSS
group — so component CSS is grouped/ordered with theme CSS rather than in the default library group, giving
correct CSS cascade/override behaviour and better aggregation. It is in the Custom package.

Use it on SDC-based themes where component CSS needs to sit in the theme group. It is a performance/theming
feature affecting CSS grouping and aggregation; it changes how stylesheets are ordered/aggregated, not
content or access, and it has no access-control role. Enable it to relocate component CSS.

SD Breadcrumb provides advanced breadcrumb management with a two-mode system.

---

SD Breadcrumb provides **advanced breadcrumb management** — building breadcrumbs with a two-mode system
(e.g. menu-based and path/field-based), for more control over breadcrumb trails than core. It depends on core
Node and Media, provides its own permissions, in the Custom package.

Use it to customize breadcrumb trails. It is a site-structure/navigation feature affecting breadcrumb
presentation; breadcrumbs reflect content the user is viewing and it has no access-control role beyond its
permission. Configure the breadcrumb behaviour.

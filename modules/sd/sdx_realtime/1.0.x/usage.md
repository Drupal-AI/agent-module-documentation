Real-time reactive UI for SDX (reactive components, WebSockets, SSE).

---

SDX Realtime provides a real-time UI layer for SDX — an umbrella that installs `sdx_reactive` (server-driven reactive components), `sdx_websocket` (channels with presence) and `sdx_broadcast` (SSE push + auto-live DataProviders), so SDX components can update live from the server. Enable individual submodules for surgical installs. Depends on its own submodules; supports Drupal 10.3+ and 11.

Shortens the pretty-path URLs produced by Facets Pretty Paths by writing each facet's alias once and joining its active values with a dot.

---

Facets Short Pretty Paths is an add-on for the Facets Pretty Paths module (which turns faceted-search
filters into readable path segments instead of query parameters). On pages with several active facet
values the pretty paths grow long and repeat the facet alias for every value. This module compresses
them: it ships a "Short pretty paths" Facets URL processor (`FacetsShortPrettyPathsUrlProcessor`,
extending the Facets Pretty Paths processor) that emits each facet's alias only once and joins its
multiple values with a dot delimiter, so `/color/black-1/color/yellow-2/color/red-3` becomes
`/color/black.yellow.red`. It also ships a "Taxonomy term machine name" coder (`TaxonomyTermCoder`)
that renders a taxonomy term's machine-name field (default `machine_name`, from Taxonomy Machine Name)
in the path instead of the term id, falling back to a cleaned term name plus id when no machine name
exists so URLs stay unique. A `RouteSubscriber` appends the `{facets_query}` catch-all parameter to
facet-source routes that use this processor, and an overriding `facets_short_pretty_paths.active_filters`
service decodes the shortened path back into active facet selections. There is no settings form; you
select the URL processor on the facet source and the coder on each facet, and tune behaviour through
`settings.php` ($settings['facets_short_pretty_paths_field_name'] and ['facets_short_pretty_paths_use_dashes']).
It changes only the form of facet URLs, not access or which results are returned.

---

- Shorten the pretty-path URLs generated by Facets Pretty Paths.
- Collapse `/color/black-1/color/yellow-2/color/red-3` into `/color/black.yellow.red`.
- Write a facet's URL alias only once even when several of its values are active.
- Join multiple active values of one facet with a dot delimiter.
- Render taxonomy-term machine names in facet paths instead of numeric term ids.
- Produce cleaner, more readable canonical URLs for faceted-search pages.
- Improve SEO by using machine-name slugs (optionally with dashes) in facet paths.
- Keep faceted URLs unique via a term-name-plus-id fallback when a term has no machine name.
- Select the "Short pretty paths" URL processor on a Facets facet source.
- Select the "Taxonomy term machine name" pretty-paths coder on a taxonomy-term facet.
- Override the taxonomy field used for path resolution with `$settings['facets_short_pretty_paths_field_name']`.
- Use dashes instead of underscores in machine-name slugs via `$settings['facets_short_pretty_paths_use_dashes'] = TRUE`.
- Layer shortened URLs onto an existing Facets + Facets Pretty Paths setup without custom code.
- Support hierarchical facets, preserving parent/child enable and disable link behaviour.
- Support the "show only one result" facet mode when building facet links.
- Keep shareable, bookmarkable faceted-search URLs shorter and tidier.
- Reduce URL length on pages that expose many active filters at once.
- Pair with the Taxonomy Machine Name module for machine-name uniqueness within a vocabulary.
- Fall back gracefully to the term id when the configured machine-name field is empty.
- Migrate a site from long repeated pretty paths to compact dotted facet paths.

# Fallback Media (fallback_media) — agent index

Renders an **admin-configured fallback media item when a media entity-reference field is empty**. Two moving
parts: a `fallback_entity` config entity (which media to fall back to) and a `entity_reference_entity_fallback`
field formatter (renders that fallback on empty fields). Package `Media`. License GPL-2.0-or-later. Version
**2.1.0**. Core `^8 || ^9 || ^10 || ^11`.

## Dependencies

- `drupal:media` — core Media. Only dependency. No Composer `require` entries, no external libraries.

## What it provides (from source)

- **One config entity** `fallback_entity` (`src/Entity/FallbackEntity.php`, `@ConfigEntityType`, config_prefix
  `fallback_entity`). Stores `id`, `label`, `fallback` (target media id, int), `uuid`. Admin CRUD routes are
  generated by `FallbackEntityHtmlRouteProvider` (extends core `AdminHtmlRouteProvider`) under
  `/admin/structure/fallback_entity`; `admin_permission = "administer site configuration"`. Add/edit =
  `Form\FallbackEntityForm` (EntityForm, media `entity_autocomplete`); delete = `Form\FallbackEntityDeleteForm`
  (EntityConfirmFormBase); list = `FallbackEntityListBuilder`. → [config/fallback-entity.md](config/fallback-entity.md)
- **One field formatter** `entity_reference_entity_fallback` — *Rendered entity (with fallback)*
  (`src/Plugin/Field/FieldFormatter/EntityReferenceFallbackFormatter.php`, extends core
  `EntityReferenceEntityFormatter`). Applicable only to entity_reference fields with `target_type = media`.
  Populated field → core rendered-entity behaviour; empty field → renders the media pointed to by the selected
  `fallback_entity`. → [fields/formatter.md](fields/formatter.md)
- **Config schema** `config/schema/fallback_entity.schema.yml` for the config entity.
- **Menu/action links** `fallback_media.links.menu.yml` (Structure › *Fallback media* collection) and
  `fallback_media.links.action.yml` (*Add Fallback media*).

## What it does NOT provide

No custom `*.routing.yml` (routes come from the entity route provider), no `*.permissions.yml` (reuses core
`administer site configuration`), no `*.services.yml`, no `.module`/`.install`, no Drush, no controllers, no
external HTTP/credentials.

## Install / operate

1. `composer require drupal/fallback_media` then `drush en fallback_media -y` (pulls core `media`).
2. Create a fallback at `/admin/structure/fallback_entity/add` — label + pick a media item.
3. On a media entity-reference field's **Manage display**, set the format to *Rendered entity (with fallback)*
   and select the fallback definition. Empty fields now render the chosen media.

Curated DSFR components for UI Suite / Display Builder.

---

UI Suite DSFR Components provides curated components for UI Suite DSFR with Display Builder — a set of Single Directory Components implementing the French State Design System (DSFR) (headers, cards, buttons, etc.) for use with the UI Suite / Display Builder tooling.

The components are intended to be used within a DSFR-based theme; enabling the module without that theme context can trigger component-rendering errors, so pair it with the UI Suite DSFR theme. Supports Drupal 11.3+ and 12.

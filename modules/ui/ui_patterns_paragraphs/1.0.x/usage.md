UI Patterns Paragraphs integrates Paragraphs with UI Patterns, letting paragraph types render as UI Patterns components.

---

UI Patterns Paragraphs integrates the Paragraphs module with UI Patterns (>=2.0) — letting paragraph
types be rendered as UI Patterns components, so a design-system component library (defined via UI Patterns)
can be used to render paragraphs. This bridges structured content (paragraphs) with a component-based
theming approach. It depends on Paragraphs and UI Patterns.

Use it on component-driven sites using UI Patterns where paragraphs should render via the component library.
It is a content-editing/site-building integration affecting how paragraphs render; it has no access-control
role. Map paragraph types to UI Patterns components.

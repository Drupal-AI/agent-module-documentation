UIkit Iconpicker provides an icon picker field that uses the UIkit library (version 3).

---

UIkit Iconpicker provides an icon-picker field — letting editors choose an icon from the UIkit v3 icon
library via a picker widget, so content can carry a selected UIkit icon. It is in the UIkit package.

Use it on UIkit-based themes to pick icons in content. It is a content-editing/widget feature; the selected
icon is authored data and it has no access-control role. Add the iconpicker field and configure it.

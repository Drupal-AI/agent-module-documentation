UI Suite USWDS Paragraphs provides a suite of Paragraph bundles built around UI Suite USWDS.

---

UI Suite USWDS Paragraphs provides ready-made Paragraph bundles for UI Suite USWDS — the US Web Design
System component library — so editors can build pages with USWDS components (accordion, alert, card,
collection, hero, icon list, modal, process list, step indicator, summary box) as paragraphs. It ships a
submodule per component, in the UI Suite USWDS package.

Use it on USWDS-based (US government) sites to build with paragraph components. It is a content-editing/site-
building feature; the components are authored content rendered via USWDS, and it has no access-control role.
Enable the component submodules you need.

UI Patterns from Layouts exposes layout definitions as UI Patterns.

---

UI Patterns from Layouts **exposes Drupal layout definitions as UI Patterns components** — bridging the
Layout API and UI Patterns so existing layout plugins become usable as UI Patterns (in Layout Builder, Views,
fields, etc.). It depends on the UI Patterns module, in the User interface package.

Use it to reuse layouts as UI Patterns components. It is a site-building/theming developer feature; it maps
existing definitions and has no content or access role. Enable it alongside UI Patterns.

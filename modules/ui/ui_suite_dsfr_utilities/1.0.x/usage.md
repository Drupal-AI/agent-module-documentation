Curated DSFR utility classes for UI Suite / Display Builder.

---

UI Suite DSFR Utilities provides curated utilities for UI Suite DSFR with Display Builder — a set of DSFR (French State Design System) utility CSS classes (spacing, colour, layout helpers) registered as UI Styles so site builders can apply DSFR utilities visually via Display Builder. Depends on `ui_styles`; supports Drupal 11.2+ and 12.

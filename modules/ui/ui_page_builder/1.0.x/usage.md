A visual low-code page builder storing JSON and rendering clean HTML.

---

UI Builder is a visual, low-code page builder storing data as JSON and rendering pure HTML without 'divitis' — so site builders can visually compose page layouts/components and have them saved as structured JSON and output as clean, minimal semantic HTML (avoiding excessive wrapper divs). Depends on core `media`, `file`, and `image`; supports Drupal 10 and 11.

Solr spatial queries with polygons for Search API.

---

JTS Solr Queries provides Solr spatial queries with polygons — extending Search API Solr / Search API Location so a site can run geospatial searches against Solr using polygon geometries (not just point-radius), for advanced location filtering. Depends on `geofield`, `search_api_solr`, and `search_api_location`; supports Drupal 9, 10, and 11.

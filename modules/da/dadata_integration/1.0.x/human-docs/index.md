# DaData Integration — manual setup guide

**DaData Integration** (`dadata_integration`) connects Drupal forms to the
**DaData Suggestions API** to provide smart autocomplete as users type —
addresses, cities, companies, personal names, and emails. Where the sibling
*DaData API* module is a developer building block, this module is the practical,
UI‑driven one: you point it at specific form fields through the admin interface and
it wires up the suggestions for you, no code required.

Its address autocomplete is granular — you can bind a field to a specific level
(country, region, city, settlement, street, house) — and it also supports company
lookup (`party`), full‑name autofill (`fio`), and email suggestions. It works with
**any text field in Drupal**, including Webform elements, and you can configure
multiple fields, each with its own suggestion type. The API URL is configurable
too, in case you use a self‑hosted gateway or a DaData mirror. It ships with
English and Russian translations.

Two considerations come with it. It authenticates to DaData with an **API key** —
store that as a secret rather than committing it. And because suggestions are
generated by an external service, the values users type (including partial
addresses and other personal data) are **sent to DaData** over the network —
disclose these third‑party lookups in your privacy policy. The module depends only
on core's System module and supports Drupal 10.1+ and 11.

This guide is written for a **human** clicking through the admin UI. If you want
terse, token‑cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Where it lives in the admin menu

Once enabled, the settings form is at **Configuration → Web services → DaData
Integration** (`/admin/config/services/dadata`). That's where you enter your API
key and register which fields should get suggestions — see
[Configuration](configuration/index.md).

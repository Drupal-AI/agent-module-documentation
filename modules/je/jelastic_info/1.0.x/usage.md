Jelastic Info shows Jelastic/Virtuozzo platform environment info in an admin dashboard.

---

Jelastic Info provides an admin-facing dashboard showing information about the Jelastic / Virtuozzo Application Platform environment the site runs on — resources, nodes, and platform details — so operators can see hosting environment status without leaving Drupal.

Permissions cover administration (`administer jelastic info`) and viewing (`view jelastic info`); it reads platform info (keep credentials secure/env-backed if the platform API is used). Supports Drupal 10.3+ and 11.

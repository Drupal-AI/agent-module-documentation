Generate image styles with text overlays based on node data.

---

Generate Social Media Image (gsmi) generates image-styles with text depending on nodes — producing social-sharing (Open Graph/Twitter card) images that overlay node text (title, etc.) onto a base image via Image Effects, so each page gets a tailored share image automatically. Depends on core `image`, `image_effects`, and `token`; supports Drupal 10.4+, 11, and 12.

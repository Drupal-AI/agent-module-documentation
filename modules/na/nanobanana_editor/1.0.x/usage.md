NanoBanana Editor adds AI image manipulation (NanoBanana) to the Media Library.

---

NanoBanana Editor allows editors to manipulate media images using NanoBanana AI directly from the Media Library — applying AI-driven edits/transformations to images without leaving Drupal. It integrates with the AI module and a NanoBanana AI provider.

AI edits run through the configured provider (cost + images sent to the provider); keep usage to trusted editors and store the provider key securely. Depends on core `media`, `ai`, and `ai_provider_nanobanana`; supports Drupal 10 and 11.

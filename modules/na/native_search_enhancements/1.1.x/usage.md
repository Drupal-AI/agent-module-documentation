Native Search Enhancements extends core Search with exclusions, taxonomy results and ranking factors.

---

Native Search Enhancements improves Drupal core's built-in Search by adding content exclusions (hide certain content from results), taxonomy term results, and configurable ranking factors — so sites using core Search (not Search API) get more relevant, controllable results without a separate search backend.

Administration is gated by `administer native search enhancements`. Depends on core `node`, `search`, and `taxonomy`; supports Drupal 10 and 11.

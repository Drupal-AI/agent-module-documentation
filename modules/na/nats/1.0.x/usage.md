NATS Integration connects Drupal to a NATS messaging server for pub/sub messaging.

---

NATS Integration integrates NATS — a high-performance messaging/streaming system — into Drupal via the basis-company/nats library, so modules can publish and subscribe to NATS subjects for event-driven or distributed messaging between Drupal and other services.

NATS server credentials/URL should be stored securely (env-backed). It's a developer/integration library with no content or access role of its own. Supports Drupal 10.3+ and 11.

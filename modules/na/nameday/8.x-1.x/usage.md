Name day shows a block with the current day's name day (the tradition of associating names with calendar days).

---

Name day provides a block that shows the current name day — the tradition (common in many European
countries) of associating given names with each calendar day, so the block displays whose name day it is
today. It is in the Other package.

Use it on sites (often regional/cultural) where displaying the daily name day is a feature. It is a
content-display/block feature showing calendar-based information; it has no content or access role.
Place the block where the name day should appear.

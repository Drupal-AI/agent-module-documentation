Display local tasks in the Navigation toolbar via blocks.

---

Navigation Local Tasks provides blocks to display local tasks (the tabs on an entity/admin page) in the new Navigation toolbar — so contextual local tasks are available within the redesigned Navigation UI (Drupal 11.1+). Depends on core `navigation`; supports Drupal 11.1+.

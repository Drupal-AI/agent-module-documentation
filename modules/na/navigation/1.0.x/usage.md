Navigation provides the new administration navigation — a left-sidebar admin navigation experience (the contrib form of Drupal core's Navigation initiative).

---

Navigation provides the "new administration navigation" — the left-sidebar admin navigation experience
that Drupal's Navigation initiative introduced, replacing/augmenting the horizontal Toolbar with a
collapsible left-hand menu for administrators. It depends on core Block and File, is configured at
`navigation.settings`, and provides its own permissions. (This is the contrib form; the feature has also
been moving into core.)

Use it to give administrators the modern left-sidebar admin navigation. It is an administration/UI feature
affecting the admin navigation experience; the navigation reflects existing access (it shows admin links
the user already has permission for), so it changes presentation, not access. Configure the navigation
blocks/items.

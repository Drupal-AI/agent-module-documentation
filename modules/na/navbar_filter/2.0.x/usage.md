Navbar Filter provides text filtering on the Navbar menu.

---

Navbar Filter adds a text-filtering box to the admin Navbar menu — letting administrators quickly filter/
search the navbar's menu items by typing, easing navigation of large admin menus. It is in the Administration
package.

Use it to filter the admin navbar. It is an administration/UI feature affecting the admin menu's usability;
it does not change content or access and has no access-control role. Enable it to add filtering to the
navbar.

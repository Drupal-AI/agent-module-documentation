Iframe Consent conditionally loads iframes based on cookie-banner consent groups.

---

Iframe Consent **loads iframes conditionally per consent group** — holding back third-party iframes (YouTube,
maps, etc.) until the visitor has granted the matching cookie-banner consent, for GDPR/privacy compliance. It
depends on core Options and provides its own permissions.

Use it to gate third-party iframes on consent. It is a privacy/compliance feature; it defers loading third-party
embeds until consent and has no access-control role beyond its permission. Note: it helps prevent third-party
tracking before consent — pair it with a consent banner that defines the groups. Configure the consent groups per
iframe.

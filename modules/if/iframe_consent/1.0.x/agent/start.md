# Iframe Consent — agent index

**Loads iframes conditionally according to cookie-banner consent groups** (GDPR/privacy). Depends on core
`options`. Provides permissions. Version **1.0.0**. Core `^10||^11`.

Privacy/compliance — defers third-party embeds until consent (prevents pre-consent tracking); pair with a consent
banner. No access role beyond permission.

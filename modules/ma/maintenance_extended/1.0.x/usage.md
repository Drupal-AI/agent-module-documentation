Maintenance Extended extends the maintenance mode page of Drupal core.

---

Maintenance Extended **extends and customizes the core maintenance-mode page** — letting you enrich the
"site under maintenance" page (branding, message, styling) beyond core's plain default. It is in the
Administration package.

Use it to improve the maintenance page. It is an administration/display feature affecting the maintenance
page; core still controls who bypasses maintenance mode (the `access site in maintenance mode` permission), and
this module has no access-control role. Configure the extended maintenance page.

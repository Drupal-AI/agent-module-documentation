A utility to mask (obfuscate) user data.

---

Mask User Data is a utility module to mask user data — obfuscating personally-identifiable user information (names, emails, etc.), useful for creating sanitised copies of a database (dev/staging) so real user data isn't exposed in non-production environments.

Run masking only against non-production copies; it modifies user data. Supports Drupal 8 through 11.

Mason integrates a masonry-style layout library to create gapless grids of variably-sized items, available as layouts/formatters, with UI and example submodules.

---

A masonry grid packs items of different heights into columns without gaps — the Pinterest-style layout. Mason integrates a library for that into Drupal, giving gapless grids for galleries, card lists and mixed-content listings, with `mason_ui` and `mason_example` submodules. It is a front-end layout integration with no security surface; confirm the library is served appropriately and that the grid behaves with your content's item sizes.

Integrate with the Mastodon API.

---

Mastodon API integrates with the Mastodon API — a base client for connecting to a Mastodon instance so other modules can post statuses, fetch timelines, or interact with Mastodon (the decentralised social network) from Drupal.

The Mastodon access token/app credentials are admin-configured and should be stored securely (env-backed), never committed. Supports Drupal 10.1+, 11, and 12.

Add a partner ID to Martinus eshop links.

---

Martinus Partner Link Formatter adds a partner ID into links to the Martinus eshop — a link field formatter that appends an affiliate/partner tracking id to outgoing Martinus (a Slovak bookstore) links, so referral commissions are attributed. Depends on core `link`; supports Drupal 10 and 11.

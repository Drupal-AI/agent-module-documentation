Matterport Embed provides functionality to embed Matterport showcases.

---

Matterport Embed embeds **Matterport 3D spaces / virtual tours** into Drupal — placing a Matterport
"showcase" (an interactive 3D walkthrough hosted by Matterport) on the site via its embed. It provides its own
permissions, requires core 11, in the Custom package.

Use it to add Matterport 3D tours. It is a media/embed feature — the 3D tour is hosted by **Matterport** and
loaded via an embed/iframe (third-party content from the visitor's browser), and it has no access-control role
beyond its permission. Configure the Matterport model/showcase to embed.

MarkIt lets users mark and unmark entities, similar to the Flag module.

---

MarkIt adds functionality similar to the Flag module — letting users mark and unmark entities (bookmark, favorite, follow) — as an alternative for use cases where a lighter marking feature is wanted. Marks are stored as entities.

Permissions cover administration (`administer markit entities`), marking (`mark markit entities`), and unmarking (`unmark markit entities`), plus per-type permission callbacks. Supports Drupal 10.2+ and 11.

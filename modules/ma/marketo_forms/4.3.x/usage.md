Marketo JS Forms Integration displays Marketo forms using the Marketo JS API.

---

Marketo JS Forms Integration embeds Marketo forms into Drupal using Marketo's JavaScript Forms API — so
marketing forms hosted in Marketo render on the Drupal site (as a block/field) and submit leads to Marketo.
It depends on core Block and Field, in the Marketo package.

Use it to surface Marketo lead-capture forms. It is a marketing/integration feature that loads Marketo's
JavaScript and embeds their form; because it injects third-party JS and collects lead data, it is a privacy/
consent consideration (the Marketo script tracks/collects data — gate behind cookie consent where required).
It has no access-control role. Configure the Marketo instance/form IDs.

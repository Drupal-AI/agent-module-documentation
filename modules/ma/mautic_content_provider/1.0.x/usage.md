Expose nodes and views as clean HTML for Mautic emails.

---

Mautic Content Provider exposes nodes and views as clean HTML for Mautic emails — providing endpoints that render selected node/view content as email-friendly HTML so Mautic can pull Drupal content into its email campaigns (dynamic content blocks).

Restrict which content is exposed and keep any endpoint access appropriate. Supports Drupal 10 and 11.

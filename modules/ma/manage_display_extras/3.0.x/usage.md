Manage Display Extras adds more functionality to manage display.

---

Manage Display Extras **adds extra functionality to the Manage Display configuration** — extending the
Manage Display module with additional field-display controls (with a `manage_display_node_created` submodule for
the node-created field). It depends on the Manage Display module, in the Fields package.

Use it for richer control over field display. It is a content-display/site-building feature affecting display
config; it has no content or access role. Configure the extra display options.

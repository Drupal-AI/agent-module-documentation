# Make array associative — agent index

Migrate API **process plugin converting an indexed array to an associative one** (re-key source data to the
destination structure). Depends on `migrate`. Version **1.0.4**. Core `^10.1||^11`.

Developer/migration utility — transforms migration data; no content/access role.

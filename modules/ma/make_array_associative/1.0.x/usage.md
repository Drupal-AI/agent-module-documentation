Make array associative is a Migrate API process plugin that converts an array from indexed to associative.

---

Make array associative provides a Migrate API process plugin — converting an indexed array (numeric
keys) into an associative array (string keys) during a migration, useful for reshaping source data into the
structure a destination expects. It depends on the Migrate module, in the Migrate package.

Use it in migration process pipelines that need to re-key arrays. It is a developer/migration utility acting
on migration data; it transforms data during import and has no content or access role. Use the process
plugin in the relevant migration.

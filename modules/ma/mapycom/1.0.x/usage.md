Mapy.com provides field support for the Mapy.com mapping service.

---

Mapy.com (mapycom) **integrates the Mapy.com mapping service** — a field (and display) for Mapy.com maps/
locations, for embedding Czech Mapy.com maps. It depends on core Field and Inline Form Errors.

Use it to add Mapy.com maps. It is a media/geospatial feature; it embeds third-party Mapy.com map content and may
need a **Mapy.com API key** (store as configuration/secret as appropriate) — embedding loads third-party map assets
(privacy/consent). It has no access-control role. Configure the Mapy.com field.

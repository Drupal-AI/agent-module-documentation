Markdown Importer pulls Markdown docs from public Git repos into Drupal nodes.

---

Markdown Importer imports Markdown files from public GitHub/GitLab repositories into documentation nodes — so a site can keep its docs in a Git repo and sync them into Drupal as content. It fetches files from the configured public repository.

It fetches from admin-configured public repositories (not arbitrary user URLs). Depends on core `filter`; supports Drupal 10 and 11.

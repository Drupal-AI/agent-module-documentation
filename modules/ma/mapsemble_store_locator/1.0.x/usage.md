An out-of-the-box store-locator built on Mapsemble.

---

Mapsemble Store Locator provides an out-of-the-box Mapsemble configuration for store locations — a ready-made store-locator (searchable map + list of store locations with a store content type) built on Mapsemble and Geofield Map, so a site gets a working locator quickly. Depends on `geofield_map` and `mapsemble`; supports Drupal 10 and 11.

# MaxLength Auto — agent index

**Automatically enables the MaxLength counter on fields that have a max length** (live character feedback
without per-field config). Depends on `maxlength`. Version **1.0.0**. Core `^10||^11`.

Content-editing/UX — affects the editing widget (counter); the field's actual max-length constraint is
enforced regardless. No access role.

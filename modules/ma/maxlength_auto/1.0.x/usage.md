MaxLength Auto enables the maxlength module automatically on fields with a max length.

---

MaxLength Auto automatically applies the MaxLength module's character counter/limit UI to fields that
already have a maximum length — so instead of configuring MaxLength per field, any field with a max length
gets the live character-count feedback automatically. It depends on the MaxLength module.

Use it to apply MaxLength everywhere a field has a length limit. It is a content-editing/UX feature affecting
the editing widget (a character counter); the field's actual max-length constraint is enforced by the field/
database regardless, and it has no access-control role. Enable it to auto-apply MaxLength.

Mailchimp Events sends behavioral events to Mailchimp for targeting.

---

Mailchimp Events (a submodule of the Mailchimp project) lets a site create and send events to Mailchimp's Behavioral Targeting — recording visitor/member actions as Mailchimp events so marketing automations can target audiences based on on-site behavior. It manages event definitions as entities.

It builds on Mailchimp Lists and sends data to Mailchimp (privacy/consent + secure API key). Depends on `mailchimp_lists`; supports Drupal 10 and 11.

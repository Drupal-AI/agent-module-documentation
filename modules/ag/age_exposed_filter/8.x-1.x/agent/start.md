# Age Exposed Filter (age_exposed_filter) — agent index

Views **exposed filter on computed age** from a date field (filter by age/age-range, not raw date).
Version **8.x-1.4**. Core `>=8`.

UI/query convenience, no security surface of its own. **Privacy note:** age derived from date-of-
birth is personal data — a public view filterable by age exposes an inferred attribute of real
people; confirm the view's access.

# Configure agreements

Each agreement is a config entity of type `agreement` (class `Drupal\agreement\Entity\Agreement`,
config prefix `agreement.agreement.*`). Manage them at `/admin/config/people/agreement`
(route `entity.agreement.collection`, permission `administer agreements`). Add at
`agreement.add`; edit at `entity.agreement.edit_form`; delete at `entity.agreement.delete_form`.
The admin form is `Drupal\agreement\Entity\AgreementForm`.

Deleting an agreement removes all of its acceptance records (rows in `{agreement}` for that type
are deleted by config/entity teardown — the delete-form warns of this).

## Entity properties (config_export)

| Property | Type | Meaning |
|---|---|---|
| `id` | string (≤32) | Machine name; the acceptance route is `agreement.<id>`. |
| `label` | label | Human name shown in the list/records. |
| `path` | uri | Internal path of the acceptance page (leading slash required, must be unused/unrouted — validated by `path.validator`). |
| `agreement` | text | The agreement body (stored value; rendered through `settings.format`). |
| `settings` | map | All tunables, below. |

## `settings` keys

| Key | Type | Default | Notes |
|---|---|---|---|
| `roles` | string[] | `[]` | Role ids the agreement applies to. `anonymous` enables anonymous (cookie-based) mode. Admin roles are excluded from the form's role options. |
| `frequency` | float | `-1` | `-1` accept once; `0` every login (checked against current session id); `.5` every 12h; `1` daily; `365` yearly. Only `-1` is a valid negative value (validated). |
| `reset_date` | int | `0` | Timestamp floor; acceptances before it no longer count (force everyone to re-accept). |
| `visibility.settings` | int | `-1` | `0` = every page **except** listed; `1` = **only** listed pages. |
| `visibility.pages` | uri[] | `[]` | One Drupal path per line; `*` wildcard, `<front>` for front page. |
| `title` | label | `''` | Agreement page title. |
| `checkbox` | label | `''` | Label next to the "I agree" checkbox. |
| `submit` | label | `''` | Submit button text. |
| `success` | text | `''` | Message shown after accepting. |
| `revoked` | text | `''` | Message shown after revoking. |
| `failure` | text | `''` | Validation error when the box is left unchecked. |
| `destination` | uri | `''` | Where to send the user after accepting. Blank = original destination, else `<front>`. |
| `recipient` | email (nullable) | `''` | If set, emails this address on every accept/revoke (transmits the username + agreement label). |
| `format` | string | `''` | Text format id used to render `agreement`. |

Config schema lives in `config/schema/agreement.schema.yml` (types `agreement.agreement.*`
and `agreement_settings`).

## Default exceptions (always reachable without accepting)

`AgreementHandler::getAgreementByUserAndPath()` hard-excludes: `/user/password`, `/user/register`,
`/user/reset/*`, `/user/login`, `/user/logout`, `/user/logout/*`,
`/admin/config/people/agreement`(`/*`, `/manage/*`), the public files path (`…/*`), and every
agreement's own `path`. Admin pages are generally not affected. README recommends visibility
pages `<front>`, `user/*/edit`, `user/*`, `user` to keep one-time login links working.

## Create one with Drush / PHP

```php
\Drupal\agreement\Entity\Agreement::create([
  'id' => 'nda',
  'label' => 'Contractor NDA',
  'path' => '/nda',
  'agreement' => '<p>By continuing you agree…</p>',
  'settings' => [
    'roles' => ['contractor'],
    'frequency' => 365,            // re-accept yearly
    'format' => 'basic_html',
    'title' => 'Non-Disclosure Agreement',
    'checkbox' => 'I agree',
    'submit' => 'Continue',
    'success' => 'Thank you.',
    'failure' => 'You must accept to continue.',
    'revoked' => 'Acceptance revoked.',
    'destination' => '',
    'recipient' => '',
    'visibility' => ['settings' => 0, 'pages' => []], // every page except listed
  ],
])->save();
```

Run with `drush php:eval '…'`. Agreements are plain config, so they export/deploy with
`drush cex` / `drush cim`. Adding or removing an agreement rebuilds routes (its acceptance route
is generated by `AgreementRouteProvider` from the entity `path`).

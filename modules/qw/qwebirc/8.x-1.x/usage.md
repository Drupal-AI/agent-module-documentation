Embed a qwebirc web IRC client for community chat.

---

Qwebirc IRC allows users to participate in IRC chats via a web page in the community — embedding a qwebirc web-based IRC client so visitors can join the project's/community's IRC channels directly from a Drupal page without a standalone IRC application.

The IRC server/qwebirc endpoint is admin-configured. Supports Drupal 8.8+.

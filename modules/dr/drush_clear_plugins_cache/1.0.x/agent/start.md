# Drush Clear Plugins Cache (`drush_clear_plugins_cache`)

Adds a Drush command to clear cached plugin-manager definitions without a full cache rebuild, aiding plugin development.

- Project: `drush_clear_plugins_cache`, version `1.0.x`, core `^8.7.7 || ^9 || ^10`. Depends on: devel.
- Category: Developer tools / Cache invalidation.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

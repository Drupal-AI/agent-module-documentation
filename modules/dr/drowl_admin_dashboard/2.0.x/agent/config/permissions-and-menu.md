# Permissions, menu link, and the Admin Quicklinks menu

## Permissions — `drowl_admin_dashboard.permissions.yml`

- **`access drowl admin dashboard`** — title "Access the DROWL admin dashboard",
  `restrict access: true`. This is the permission the page_manager page's `user_permission`
  access condition checks; holding it lets a user reach `/admin/dashboard`. (The permission's
  `description` text in the .yml is a leftover boilerplate string and does not reflect what the
  permission grants — it only gates the dashboard page.)
- **`redirect to drowl admin dashboard on login`** — title "Redirect to DROWL admin dashboard on
  login". Opts a role into the post-login redirect implemented in `drowl_admin_dashboard_user_login_submit()`
  (also requires `access drowl admin dashboard`).

Assign at `/admin/people/permissions`. The dashboard shell appears to holders of `access drowl
admin dashboard`; the individual View blocks additionally require their own permissions
(`administer users`, `access content overview`, `access user profiles` — see
[../views/dashboard-views.md](../views/dashboard-views.md)).

## Menu link — `drowl_admin_dashboard.links.menu.yml`

- `drowl_admin_dashboard.dashboard`: title "Dashboard", `parent: system.admin`, `weight: -9`,
  `route_name: page_manager.page_view_admin_dashboard_admin_dashboard-layout_builder-0` (the route
  generated by the page variant). Puts "Dashboard" near the top of the Administration menu.

## Admin Quicklinks menu — `config/optional/system.menu.admin-quicklinks.yml`

- Defines menu `admin-quicklinks` (label "Admin Quicklinks", description "Frequently used
  administrative links", `locked: false`). Shipped **empty** — maintainers add links at
  `/admin/structure/menu/manage/admin-quicklinks`.
- Surfaced on the dashboard via the `menu_block:admin-quicklinks` block component in the page
  variant. Being in `config/optional`, it installs only if its (nil) dependencies are met and is
  editable/removable afterward.

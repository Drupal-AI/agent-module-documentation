# Drupal Bootstrap 5 (`drupal_bootstrap5`)

A helper module that loads the Bootstrap 5 CSS and JavaScript library on the site so any theme can use Bootstrap 5 markup and utilities.

- Project: `drupal_bootstrap5`, version `1.0.x`, core `^8 || ^9 || ^10`.
- Category: Theming / CSS / JS injection.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

# Drupacle (drupacle) — agent index

An **Oracle Database Connection Tool** for Drupal. It stores each Oracle database as a
**`drupacle_connection`** config entity and exposes a service that opens an OCI8 connection to it,
so custom code can run Oracle queries. Package `Development`. Core `^8 || ^9 || ^10 || ^11`.
License GPL-2.0-or-later. Version 2.0.4 (dir 2.0.x).

- **No Drupal module dependencies** (composer `require` is empty; `dependent_modules: []`).
- **Runtime requirement:** the **`oci8`** PHP extension (Oracle Instant Client) must be installed;
  all connecting is done with `oci_connect()`. No Composer library is pulled in for it.
- **No** Drush commands, no plugin types, no hooks, no `.module`/`.install` file.

## What it provides

- **Config entity `drupacle_connection`** (`src/Entity/DrupacleConnection.php`, config prefix
  `drupacle_connection`): fields `id`, `label`, `db_name`, `host`, `port`, `username`, `password`,
  `db_service_name` — all in `config_export`. Schema: `config/schema/drupacle_connection.schema.yml`.
  Helper `getHostWithPortAndService()` builds `host:port/service` (or `host:port`).
  → [config/connection-entity.md](config/connection-entity.md)
- **Service `drupacle.connection_service`** = `DrupacleController` (`src/Controller/DrupacleController.php`).
  `drupalConnectionCallback($connection)` calls `oci_connect(username, password, host:port/service)`
  and returns `[connectionId => resource-or-error]`. It is a **service, not an HTTP route** — the
  module's `drupacle.routing.yml` is empty. → [api/controller.md](api/controller.md)
- **Entity routes + permissions + access handler** — routes are generated by
  `DrupacleConnectionHtmlRouteProvider` (extends `AdminHtmlRouteProvider`); permissions in
  `drupacle.permissions.yml` (+ a dynamic callback class); access via
  `DrupacleConnectionAccessControlHandler`. → [routing/access.md](routing/access.md)
- **List builder** `DrupacleConnectionListBuilder` renders the collection table (incl. a live
  connection test and a copy-paste short-code) — covered in the entity and controller docs.

## Routes (all under `/admin/drupacle`)

| Route | Path | Access |
|---|---|---|
| `entity.drupacle_connection.collection` | `/admin/drupacle/connections` | perm `view drupacle connections` |
| `entity.drupacle_connection.add_form` | `/admin/drupacle/connection/add` | perm `add drupacle connections` |
| `entity.drupacle_connection.edit_form` | `/admin/drupacle/connection/{id}/edit` | entity `update` access |
| `entity.drupacle_connection.delete_form` | `/admin/drupacle/connection/{id}/delete` | entity `delete` access |

Menu link `entity.drupacle_connection.collection` sits under *Configuration* (`system.admin_config`,
title "Drupacle"). Action link "Add Oracle DB connection" appears on the collection.

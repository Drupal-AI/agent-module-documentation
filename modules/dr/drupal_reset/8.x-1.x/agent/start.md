# Drupal Reset (`drupal_reset`)

A destructive development tool that resets a site by dropping all database tables and/or deleting the files directory, then redirecting to install.php for a fresh install.

- Project: `drupal_reset`, version `8.x-1.x`, core `^8 || ^9 || ^10`.
- Category: Developer tools / Deployment / release management.
- Configure via route `drupal_reset.drupal_reset_form`.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

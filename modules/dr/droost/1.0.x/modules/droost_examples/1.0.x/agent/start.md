# Droost Examples (droost_examples) — agent index

Green-by-default **reference implementations** of common Drupal patterns, generated by the Droost scaffolder.
Read the source; not for production. Depends on `droost` and core `text`. Version **1.0.0-rc1** (dir 1.0.x).
Core `^10.3 || ^11 || ^12`.

## What it provides
- **Two entity types**: content entity `ExampleWidget` (+ interface, list builder, forms, access handler, settings
  form) and config entity `ExampleProfile` (+ interface, list builder, form, access handler).
- **Routes** (`droost_examples.routing.yml`): `entity.example_widget.settings`, and the `example_profile`
  collection/add/edit/delete forms — each gated by `administer example_widget` / `administer example_profile`.
- **Permissions** (`droost_examples.permissions.yml`): `administer|view|edit|delete|create example_widget` and the
  same set for `example_profile` (the two `administer` perms are `restrict access: true`).
- **Config**: `droost_examples.settings` (install default + full schema in `config/`), two `system.action` configs.
- **Plugins**: `ExampleTool` (MCP `#[Tool]`), `ExampleBlock`, `ExampleUnpublishAction`, `ExampleTrimmedFormatter`,
  `ExampleTextareaWidget`, `ExampleRatingItem`, `ExampleQueueWorker`, Views field/filter/sort handlers.
- **Services**: `droost_examples.example` (`ExampleService`), `ExampleSubscriber`, `ExampleRouteSubscriber`.
- **Hooks** (OOP `#[Hook]`): `ExampleEntityHooks`, `ExampleViews*` (field/filter/sort views_data, query alter).
- **1 Drush command** (`ExampleCommands`), a kernel test (`ExamplesSmokeTest`) and an SDC (`components/example_card`).

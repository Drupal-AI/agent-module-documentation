# Drush command

Registered via Drush attributes in `src/Drush/Commands/DrushCommands.php`.

## `drd:agent:setup <token>` (alias `drd-agent-setup`)

Configures this site to communicate with a DRD instance. The `<token>` is a **base64- and
JSON-encoded** array of all variables DRD needs to talk to this domain (generated by the DRD
portal when you add the site). The command stashes the token in the session, runs the
`drd_agent.setup` service, and on success logs a portal URL you must then open (authenticated)
to finish adding the agent.

```bash
drush drd:agent:setup <base64-json-token>
# alias:
drush drd-agent-setup <token>
```

It is the CLI equivalent of the `/drd-agent-authorize` form; use it for headless/automated
provisioning of the agent-to-dashboard link.

Cache Review provides a tool to review how internal (render/page) caching behaves for debugging.

---

Cache Review **provides a tool to review how internal caching behaves** — inspecting render/page cache
decisions (hits/misses, tags/contexts) so developers can debug and tune caching. It is in the Development package.

Use it in development to review caching. It is a developer/debugging tool; it exposes **internal cache
information**, so gate it to developers and prefer dev/staging (not production). It has no content or access role.
Use it to review caching behaviour.

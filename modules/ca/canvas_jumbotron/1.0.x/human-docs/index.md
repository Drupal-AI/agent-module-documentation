# Canvas Jumbotron — manual setup guide

**Canvas Jumbotron** (`canvas_jumbotron`) provides a "jumbotron" code component
for **Canvas**, Drupal's Experience Builder page‑building UI. A jumbotron is a
large hero or banner block — the kind of full‑width headline area you often see
at the top of a landing page — and this module makes it available as a
ready‑made building block editors can drop into a Canvas layout.

It is a content‑display / site‑building component. The banner content is authored
by admins and editors, and the module has no content type or access‑control role
of its own.

This guide is written for a **human** clicking through the site. If you want
terse, token‑cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Where it lives in the admin menu

Canvas Jumbotron adds no top‑level admin menu items and no settings form. It
appears as a component in the Canvas page builder.

## How to use it

While building a page in Canvas, add the **Jumbotron** component to your layout
and fill in its content — heading, supporting text, and so on. It renders as a
large hero/banner section at the position you place it.

Calimals is an animal-themed SVG icon pack that plugs into the UI Icons module.

---

Calimals ships a curated set of 33 animal-themed SVG icons (alpaca, capybara, cat, cow, dragon, flamingo, giraffe, hedgehog, hippo, lion, panda, phoenix, unicorn, zebra, and more) packaged as a UI Icons icon pack. It contains no PHP, routes, permissions, services, or config schema — only a single `calimals.icons.yml` pack definition plus the SVG assets. Once enabled alongside `ui_icons`, the Calimals icons become selectable anywhere UI Icons (and UI Patterns) expose an icon picker: menus, links, CKEditor, Icon fields/formatters, blocks, and component/SDC props. The pack uses the built-in `svg` extractor with a configurable render `size` (default 64px) and a `0 0 2400 2400` default viewBox.

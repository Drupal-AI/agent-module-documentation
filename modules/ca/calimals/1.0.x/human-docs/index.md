# Calimals — manual setup guide

**Calimals** (`calimals`) is an animal-friendly icon pack for the **UI Icons**
module. It provides a set of animal-themed icons as a UI Icons pack, so any theme
or module that uses UI Icons can pick from the Calimals set to give the interface
a playful, friendly visual style.

It is purely an asset package: a collection of icons and nothing more. It has no
content type, no settings, and no access role of its own — its only job is to
make its icons available to UI Icons.

This guide is written for a **human**. If you want terse, token-cheap references
for an AI coding agent, read the sibling [`agent/`](../agent/start.md) docs
instead.

## Where it lives

Calimals has no configuration screen. Once enabled, its icons appear as an
available icon pack anywhere the UI Icons module lets you pick an icon.

## How to use it

Enable the module alongside UI Icons, then choose Calimals icons wherever UI
Icons offers an icon picker — for example in the interfaces of themes and modules
that integrate with UI Icons. There is nothing to configure; the icons are simply
available for selection.

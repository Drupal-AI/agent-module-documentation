Cash DOM provides the Cash library (a small jQuery-compatible DOM utility) for Drupal.

---

Cash DOM makes the Cash library available in Drupal — an absurdly small jQuery alternative for modern browsers (IE9+), offering a familiar jQuery-like API at a fraction of the size, so themes/modules can use jQuery-style DOM manipulation without bundling full jQuery.

It's a front-end library integration with no content or access role of its own. Administration is gated by `administer cash`. Supports Drupal 8.8+.

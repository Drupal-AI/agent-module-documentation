# Koality Layout Builder Layouts - agent index

Provides **base Layout Builder layouts + options** (version **2.0.4**, core `^8||^9||^10`, depends on `layout_builder`).

- Defines layout plugins in `.layouts.yml` and attaches CSS; no routes, no entities, no custom access.
- Section-placement permissions are enforced by core Layout Builder, not this module.
- Category: Content display / Layout Builder.

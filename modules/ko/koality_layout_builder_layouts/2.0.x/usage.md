Koality Layout Builder Layouts provides ready-made base layouts and options for Layout Builder.

---

The module registers additional layout plugins (via `.layouts.yml`) and CSS so site builders have a practical set of multi-column and structural layouts to drop into Layout Builder sections. It is a presentation/site-building helper: it defines layouts and attaches a library, but adds no routes, no entities, and no access logic of its own - section placement is governed by core Layout Builder's own access controls.

---

- Add base multi-column layouts to Layout Builder.
- Give site builders a jumping-off point for layouts.
- Provide configurable layout options per section.
- Attach CSS to style the provided layouts.
- Use the layouts in node and entity Layout Builder.
- Speed up page building with prebuilt structures.
- Avoid writing custom layout plugins from scratch.
- Support responsive column arrangements.
- Extend the core Layout Discovery / Layout Builder set.
- Reuse consistent layouts across content types.
- Compose landing pages from provided layouts.
- Support Drupal 8, 9, and 10.
- Rely on core Layout Builder access for permissions.
- Provide a themeable base for further customization.
- Standardize section structure site-wide.
- Enable richer page composition without code.

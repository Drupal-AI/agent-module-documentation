Integrate with the Konfhub event platform to update users.

---

Konfhub Integration integrates with the Konfhub platform to update users — syncing Drupal users/attendees with Konfhub (an event-management/ticketing platform), so event registrations/attendees stay in sync.

The Konfhub API credentials are admin-configured and should be stored securely (env-backed), never committed. Depends on core `system`; supports Drupal 10 and 11.

# VG Wort — agent index

Integrates **VG Wort** (German reproduction-rights society) counting — embeds counting markers
("Zählmarken") in content using **publisher-defined keys** (count text views for author remuneration). Drush
commands. Config at `vgwort.settings`; provides permissions. Version **3.0.2**. Core `^10.3||^11`.

Integration/content — embeds a **tracking pixel/marker** (privacy consideration — disclose); store publisher
keys securely. No access role beyond permission.

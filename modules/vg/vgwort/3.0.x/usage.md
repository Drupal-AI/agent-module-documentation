VG Wort adds VG Wort integration using publisher defined keys, embedding counting markers in content.

---

VG Wort adds integration with VG Wort — the German reproduction-rights organization — embedding the
counting markers ("Zählmarken") in content using publisher-defined keys, so text views can be counted toward
authors' VG Wort remuneration. It provides Drush commands and its own permissions, is configured at
`vgwort.settings`, in the Content package.

Use it on German publishing sites participating in VG Wort. It is an integration/content feature that embeds
tracking pixels/markers; the publisher keys identify your account — **store them securely**, and note the
counting markers are a form of third-party tracking pixel (a privacy consideration to disclose). It has no
access-control role beyond its permission. Configure the VG Wort keys and content.

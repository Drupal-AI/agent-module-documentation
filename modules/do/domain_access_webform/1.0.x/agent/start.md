# Domain Access Webform (`domain_access_webform`)

Extends the Webform module with Domain Access integration: assigns webforms and submissions to domains and restricts submission access and listings per domain.

- Project: `domain_access_webform`, version `1.0.x`, core `^9.5 || ^10`. Depends on: domain, webform.
- Category: Access control / Multi-domain / affiliate sites.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

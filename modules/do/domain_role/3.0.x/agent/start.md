# Domain Role (`domain_role`)

Extends Domain Access with per-domain user roles, remapping domain-prefixed roles to their base role for the active domain via a custom cookie authentication provider.

- Project: `domain_role`, version `3.0.x`, core `^10`. Depends on: domain, domain_config.
- Category: Access control / Multi-domain / affiliate sites.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

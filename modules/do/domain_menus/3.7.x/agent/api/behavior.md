# Blocks, plugins, third-party settings & hooks

## Third-party settings (the domain-menu marker)

Stored on the `menu` config entity, namespace `domain_menus`:
- `domains` — `[<domain_id> => <domain_id>, …]`; a non-empty value makes the menu a domain menu.
- `auto-created` — `1` if the menu was machine-generated by bulk-create / domain-insert.

Helpers in `domain_menus.module`: `_domain_menus_is_domain_menu($menu)`,
`_domain_menus_is_auto_created($menu)`.

## Blocks

- **`domain_menus_active_domain_menu_block`** (`Plugin/Block/DomainMenusMenuBlock`, category
  "Domain") — extends core `SystemMenuBlock`. Block setting `menu_name` is a domain-menu *name*;
  `getDerivativeId()` resolves it to `dm<activeDomainId>-<name>` so the block always renders the
  active domain's version of that menu.
- **`domain_menus_active_domain_superfish_block`** — in the `domain_menus_superfish` submodule
  (extends the Superfish block); same active-domain resolution.

## Entity Reference Selection plugin

`Plugin/EntityReferenceSelection/DomainMenusSelection` (`@EntityReferenceSelection id="domain_menus:node"`,
group `domain_menus`, node only). When `domain_menus_filter_node_autocomplete` is on and a menu link
is added to a domain menu, the node-link autocomplete uses this handler to return only nodes whose
Domain Access (`DOMAIN_ACCESS_FIELD` / `DOMAIN_ACCESS_ALL_FIELD`) matches the menu's domains.

## Notable hooks the module implements

- `hook_domain_insert` / `hook_domain_delete` — auto-create/auto-delete a domain's menus (skipped
  during config sync). Delete un-assigns instead of deleting if the menu has other domains.
- `hook_form_alter` on `menu_add_form`/`menu_edit_form` — adds the **Domain(s)** checkboxes
  (disabled/hidden for auto-created menus or users without `administer menu`).
- `hook_form_alter` on menu-link forms — swaps in the `domain_menus:node` selection handler and
  trims parent-link options to the current domain menu.
- `hook_form_node_form_alter` — makes domain menus available as a menu parent on selected content
  types, honoring domain access and the default parent name.
- `hook_menu_link_content_access` / `_create_access`, `hook_menu_access` — the access logic (see
  permissions doc).
- `hook_entity_type_alter` — swaps the menu list builder to `MenuNoDomainMenusListBuilder` when
  `domain_menus_hide_from_menu_list` is on.
- `hook_menu_links_discovered_alter` — removes auto-created domain menu links from the Admin Toolbar
  when `domain_menus_hide_admin_toolbar_links` is on.

Service: `domain_menus.constants` (`DomainMenusConstants`) exposes
`DOMAIN_MENUS_MENU_ID_PATTERN` (`'dm%u-%s'`) and `DOMAIN_MENUS_SETTINGS` (`'domain_menus.settings'`).
No Drush commands, no plugin types of its own.

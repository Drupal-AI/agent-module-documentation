# Configuration

Domain Menu Links works the moment you enable it — the domain drop-down appears in
the toolbar with no setup. The only thing you can adjust is where that drop-down
sits relative to the other items in the admin toolbar.

## Set the drop-down's position

1. Log in as an administrator.
2. Go to **Configuration → Domain → Domain Menu Link Settings**.
3. Update the **Parent menu link weight** field. As with menu weights everywhere
   in Drupal, a lower (more negative) number moves the domain drop-down further to
   the left/earlier in the toolbar, and a higher number moves it later.
4. Click **Save configuration**.

Reload an admin page and the domain drop-down will appear in its new position.

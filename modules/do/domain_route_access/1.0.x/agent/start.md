# Domain Route Access (`domain_route_access`)

Provides a config entity to restrict access to specific routes by domain, adding a per-domain requirement to selected routes via a route subscriber.

- Project: `domain_route_access`, version `1.0.x`, core `^9 || ^10`. Depends on: domain.
- Category: Access control / Multi-domain / affiliate sites.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

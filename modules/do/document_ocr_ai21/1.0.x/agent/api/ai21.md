# AI21 client service

Service `document_ocr_ai21.client` → `src/AI21.php` (constructed with `@http_client` + `@logger.factory`).

## Credentials
Create `private://document-ocr/ai21-credentials.json`:
```json
{ "apikey": "[API-KEY]" }
```
Get the key at https://studio.ai21.com/account/api-key. When adding an AI21 transformer plugin in Document OCR, point it at this credentials file. The service consumes the array via `->setCredentials($credentials)`; the key is sent as `Authorization: Bearer <apikey>`.

## Methods
- `getSummary($sourceType, $value, $focus)` → POST `/summarize` with `{sourceType, source, focus?}`.
- `getSegmentedText($sourceType, $value)` → POST `/segmentation` with `{sourceType, source}`.

Both call the protected `callApi()` against `https://api.ai21.com/studio/v1`. Responses are `json_decode`d; a non-empty `detail` field is thrown as an exception and logged to the `document_ocr_ai21` logger channel (the method returns null on error).

## Notes
- HTTPS endpoint with default Guzzle TLS verification (not disabled).
- Configure the transformers under `/admin/config/structure/document-ocr`; each run is a paid AI21 API call.

# DonorPerfect Gift (donorperfect_gift) — agent index

Submodule of **donorperfect**. Defines the `donorperfect_gift` content entity (DonorPerfect
gift/pledge record). Package `DonorPerfect`. Core `^10 || ^11`, PHP `^8.0`. GPL-2.0-or-later.
Version 1.0.x (installed 1.0.20). Depends on `donorperfect:donorperfect` only.

- **The entity, its tables/fields, controller and settings form** →
  [entity/gift.md](entity/gift.md)

## What it provides (from source)

- **Entity** `donorperfect_gift` (`src/Entity/Gift.php`, `@ContentEntityType`): base table `dpgift`,
  `udf_table` `dpgiftudf`, id key `gift_id`, label key `gift_id`.
  `admin_permission = donorperfect admin`. Handlers: base `Storage`, `StorageSchema`,
  `AccessControlHandler`, `ViewsData`; `entity` `EntityPermissionProvider`; own `GiftViewBuilder`;
  add/edit form `GiftForm`. Routes under `/admin/donorperfect/gift`.
- **Extra field**: `Gift::baseFieldDefinitions()` adds a `donor_id` entity_reference to
  `donorperfect_donor` **only if** the `donorperfect_donor` module is enabled. Other base fields are
  generated by the base `EntityBase` from the selected `dpgift`/`dpgiftudf` cached fields.
- **Service** `donorperfect_gift.entity_controller` → `Entity\GiftController` (extends base
  `ControllerBase`), tagged `donorperfect.entity_controller` **priority 990**;
  `ENTITY_TYPE_ID = donorperfect_gift`; `getSettingsFormClass()` → `Form\SettingsForm`.
- **Settings form** `Form\SettingsForm` extends base `EntitySettingsFormBase`
  (`ENTITY_TYPE_ID = donorperfect_gift`) — contributes the gift "Entity Fields" checkboxes to the
  base settings form.
- **View builder** `Entity\GiftViewBuilder` clears default `content` (render via Views/fields).

Records live in DonorPerfect and are read/written via the base `DPQuery` client (new gifts use the
`savegift` procedure). Delete is forbidden by the base access handler. No
routing.yml/permissions.yml/config schema/Drush of its own (entity permissions come from
`EntityPermissionProvider`).

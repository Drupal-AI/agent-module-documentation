# DonorPerfect Other (donorperfect_other) — agent index

Submodule of **donorperfect**. Defines the `donorperfect_other` content entity (DonorPerfect
"Other Info" record). Package `DonorPerfect`. Core `^10 || ^11`, PHP `^8.0`. GPL-2.0-or-later.
Version 1.0.x (installed 1.0.20). Depends on `donorperfect:donorperfect` only.

- **The entity, its tables/fields, controller and settings form** →
  [entity/other.md](entity/other.md)

## What it provides (from source)

- **Entity** `donorperfect_other` (`src/Entity/Other.php`, `@ContentEntityType`): base table
  `dpotherinfo`, `udf_table` `dpotherinfoudf`, id key `other_id`, label key `other_id`.
  `admin_permission = donorperfect admin`. Handlers: base `Storage`, `StorageSchema`,
  `AccessControlHandler`, `ViewsData`; `entity` `EntityPermissionProvider`; own `OtherViewBuilder`;
  add/edit form `OtherForm`. Routes under `/admin/donorperfect/other`.
- **Extra field**: `Other::baseFieldDefinitions()` adds a `donor_id` entity_reference to
  `donorperfect_donor` **only if** the `donorperfect_donor` module is enabled. Other base fields are
  generated by the base `EntityBase` from the selected `dpotherinfo`/`dpotherinfoudf` cached fields.
- **Service** `donorperfect_other.entity_controller` → `Entity\OtherController` (extends base
  `ControllerBase`), tagged `donorperfect.entity_controller` **priority 970**;
  `ENTITY_TYPE_ID = donorperfect_other`; `getSettingsFormClass()` → `Form\SettingsForm`.
- **Settings form** `Form\SettingsForm` extends base `EntitySettingsFormBase`
  (`ENTITY_TYPE_ID = donorperfect_other`) — contributes the Other Info "Entity Fields" checkboxes to
  the base settings form.
- **View builder** `Entity\OtherViewBuilder` clears default `content` (render via Views/fields).

Records live in DonorPerfect and are read/written via the base `DPQuery` client (new records use the
`saveotherinfo` procedure). Delete is forbidden by the base access handler. No
routing.yml/permissions.yml/config schema/Drush of its own (entity permissions come from
`EntityPermissionProvider`).

Deepgram registers the Deepgram cloud service as a speech-to-text and text-to-speech provider for the Drupal AI module.

---

Deepgram is a thin provider module for `drupal/ai`. It does not add its own UI for transcribing or synthesising audio; instead it implements the AI module's `SpeechToTextInterface` and `TextToSpeechInterface` as an `AiProvider` plugin, so any consumer that asks the AI module for a `speech_to_text` or `text_to_speech` operation can route the work to Deepgram. Speech-to-text sends an audio file to Deepgram's `listen` endpoint and returns the transcript (with support for model selection, language detection, punctuation, diarization, smart formatting and profanity filtering). Text-to-speech sends text to the `speak` endpoint and returns an audio binary generated by one of Deepgram's Aura English voices. Configuration is a single admin form at `/admin/config/deepgram/settings` where you pick the Key entity that holds your Deepgram API key. Requires a Deepgram account (free trials available), the AI module, and the Key module.

- Transcribe uploaded audio (mp3 and other formats) into text through the AI module's speech-to-text API.
- Build an AI Automator/workflow step that fills a text field from an audio file field.
- Generate an English voice-over audio file from a text field via text-to-speech.
- Add spoken-word audio to nodes or media entities produced from editorial text.
- Produce transcripts with word-level timestamps for captioning or search indexing.
- Enable speaker diarization to label who spoke in multi-speaker recordings.
- Apply smart formatting (dates, numbers, currency) to raw transcripts automatically.
- Add punctuation to otherwise unpunctuated transcription output.
- Auto-detect the spoken language of an audio file instead of specifying it.
- Filter profanity out of generated transcripts.
- Choose transcription accuracy/speed by model (Nova 2, Nova, Base).
- Choose a synthesis voice from Deepgram's Aura set (Asteria, Luna, Stella, Athena, Hera, Orion, Arcas, Perseus, Angus, Orpheus, Helios, Zeus).
- Let other contrib modules consume Deepgram indirectly through the AI provider abstraction, with no Deepgram-specific code.
- Centralise the Deepgram API key in a Key entity (env, file or config provider) rather than scattering it in code.
- Swap the active speech provider site-wide by changing AI module provider settings, keeping Deepgram as one option.
- Convert meeting or interview recordings into searchable text content.
- Generate accessibility audio versions of articles for English-language readers.
- Prototype voice features in Drupal without integrating the Deepgram SDK directly.
- Programmatically call the raw Deepgram client (`deepgram.api` service) for custom transcription/synthesis logic.
- Override the API key per-request at runtime through the provider's `setAuthentication()` when integrating with multi-tenant setups.

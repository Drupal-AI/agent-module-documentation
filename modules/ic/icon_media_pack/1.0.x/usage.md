Use media bundles as icon packs for the Icon API.

---

Icon Media Pack allows defining media bundles as icon packs for the Icon API (UI Icons) — so a set of icons stored as Media entities (SVGs/images in a media bundle) can be registered as a UI Icons icon pack and used wherever icons are picked. Depends on core `media`, `ui_icons`, and `ui_icons_media`; supports Drupal 10.3+, 11, and 12.

Iconset provides tools for managing and organizing icons into sets.

---

Iconset provides tools for managing and organizing icons into sets — so a site can define reusable icon
sets (SVG/font icons) and use them across the site, with submodules for custom icons, embedding icons and
menu icons. It ships `iconset_custom`, `iconset_embed` and `iconset_menu` submodules, is configured at
`iconset.settings`, in the Media package.

Use it to manage reusable icon sets. It is a media/UI feature providing icon management; icons are display
assets and it has no access-control role. Configure the icon sets.

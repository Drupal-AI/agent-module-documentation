# Iconset — agent index

Tools for **managing and organizing icons into sets** (reusable SVG/font icon sets — usable in menus/embeds/
fields; `iconset_custom`/`iconset_embed`/`iconset_menu` submodules). Config at `iconset.settings`. Version
**3.0.0-beta1**. Core `^10.3||^11`.

Media/UI — icon management (display assets); no access role.

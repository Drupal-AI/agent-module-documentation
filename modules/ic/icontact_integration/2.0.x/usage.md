Integrates Drupal with the iContact email-marketing platform (API v2.2).

---

iContact Integration integrates Drupal 10/11 with the iContact email marketing platform via API v2.2 — supporting contact management, list subscriptions, field mapping, custom fields, queue-based async processing, and unsubscription, so site users/contacts sync to iContact for email campaigns.

The iContact API credentials are admin-configured and should be stored securely (env-backed), never committed. Depends on core `user`; supports Drupal 10 and 11.

# Modal Management Module (ik_modals) — agent index

Manages **modal content** — create/control modals/dialogs (content/triggers/behaviour) as managed config.
Config at `ik_modals.settings`; provides permissions. Version **6.0.4**. Core `^10.1||^11`.

Content-display/UI — modal content is admin-authored, shown to visitors; gate who manages via its permission.
No access role.

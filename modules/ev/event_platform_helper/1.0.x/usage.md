Event Platform Helper provides extra capabilities to the event platform.

---

Event Platform Helper **provides extra capabilities for an event-platform** setup — helper config and
integrations (content moderation, date ranges, smart dates, config pages, storage) for building event sites. It
depends on core Content Moderation, Datetime Range, Node, Taxonomy plus Config Pages, Content Moderation Link,
Smart Date and Storage, in the Event Platform package.

Use it as part of an event-platform build. It is a site-building/helper module; it wires config/integrations
that follow normal access, and it has no access-control role of its own. Enable it with the event-platform
stack.

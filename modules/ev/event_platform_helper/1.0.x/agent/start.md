# Event Platform Helper — agent index

Provides **extra capabilities for an event-platform** (moderation, date ranges, config). Depends on core
`content_moderation`, `datetime_range`, `node`, `taxonomy` plus `config_pages`, `smart_date`, `storage`. Version
**1.0.0**. Core `^10.1||^11||^12`.

Site-building/helper — wires config/integrations following normal access; no access role of its own.

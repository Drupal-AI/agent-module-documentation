Token Content Access nodes wires TCA into the **node** entity type: it registers the `tca_node` TcaPlugin (so nodes gain the TCA active/public/token settings and token-based view gating) and hides token-protected nodes from search and Views listings for users without bypass.

---

This submodule contains one `TcaPlugin` (`#[TcaPlugin(id: 'tca_node', entityType: 'node')]`, `isFieldable() = TRUE`) which makes the parent module install the `tca_active`/`tca_public`/`tca_token` base fields on nodes and enforce `TcaAccessCheck` on node view. On top of the parent's `hook_entity_access` gating, `tca_node.module` implements `hook_query_search_node_search_alter()` and `hook_views_query_alter()` to exclude protected nodes from result sets: for users **without** `tca bypass node`, it adds an OR condition keeping only rows where `tca_active` is NULL/0 or whose node type has TCA disabled at bundle level. This prevents protected node titles/teasers from leaking into search pages and Views listings even though the canonical page is token-gated. It adds no config or permissions of its own (the `tca administer node` / `tca bypass node` permissions are generated by the parent from this plugin).

- Enable token-based view access on nodes.
- Protect individual nodes behind a `?tca=<token>` URL.
- Keep token-protected nodes out of core search results for non-bypass users.
- Hide protected nodes from Views-based listings and feeds.
- Grant `tca bypass node` to editors/QA so they see all nodes including protected ones.
- Share an unpublished node preview via a tokenized link (with the `public` flag).
- Force TCA on an entire content type so every node of it needs a token.
- Combine token gating with normal node permissions.
- Regenerate a node's token to revoke previously shared links.
- Provide "secret link" access to gated landing pages built as nodes.
- Prevent protected node titles/teasers from leaking into search snippets.
- Apply consistent token gating across all node types on a site.
- Let external reviewers approve draft nodes without accounts.
- Add token access to an existing content type without code.
- Mark selected nodes `public` so the token link bypasses "view published content".
- Combine bundle-level `force` with per-node tokens for mandatory gating.
- Audit which node types have TCA active via the bundle settings.

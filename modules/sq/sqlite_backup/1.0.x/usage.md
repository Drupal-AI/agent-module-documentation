Create and restore backups of a SQLite database.

---

SQLite Backup creates and restores backups of the SQLite database — for sites running on SQLite, it provides a way to snapshot the database file and restore it, giving simple backup/restore for SQLite-backed installs. Supports Drupal 10 and 11.

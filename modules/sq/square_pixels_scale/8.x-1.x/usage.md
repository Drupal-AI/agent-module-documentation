Square Pixels Scale adds an image effect that scales by total square pixels.

---

Square Pixels Scale **scales images by total pixel count** — an image-style effect that resizes an image to a
target total number of square pixels (area), rather than fixed width/height, for consistent image area. It works
across core 8–11.

Use it for area-based image scaling. It is a media/image-style feature; it produces image derivatives and has no
content or access role. Configure the effect in an image style.

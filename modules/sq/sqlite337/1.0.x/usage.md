SQLite 3.37 provides a SQLite database driver compatible with SQLite 3.37+.

---

SQLite 3.37 **provides a SQLite database driver** — a database driver adding compatibility with SQLite 3.37 or
higher, for running Drupal on newer SQLite versions. It depends on core SQLite.

Use it to run Drupal on SQLite 3.37+. It is a database-driver/infrastructure feature; it configures how Drupal
talks to SQLite and has no content or access role. Configure the database connection to use this driver.

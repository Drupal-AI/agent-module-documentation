Integrate database SQL views into Drupal.

---

SQL Views provides the ability to integrate SQL views in Drupal — exposing native database VIEWs so their data can be read/used within Drupal (as data sources for reporting or further integration), bridging raw SQL views into the Drupal layer. Depends on core `system`; supports Drupal 11.2+.

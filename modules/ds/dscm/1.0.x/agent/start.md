# Did Someone Clone Me (`dscm`)

Detects malicious clones/phishing copies of your site by embedding a beacon link in the page source; when a cloned copy loads, the beacon reports the foreign host.

- Project: `dscm`, version `1.0.x`, core `^8 || ^9 || ^10`.
- Category: Security / Code integrity / tamper detection.
- Configure via route `didsomeonecloneme.settings`.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

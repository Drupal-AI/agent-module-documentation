DSFR for Drupal - Picker provides DSFR icons and pictograms picker fields.

---

DSFR for Drupal - Picker provides picker fields for DSFR icons and pictograms — the official iconography
of the French State Design System (Système de Design de l'État) — so editors on DSFR-compliant (French
government) sites can select DSFR icons/pictograms via a field. It ships example/link/media submodules, is
configured at `dsfr4drupal_picker.settings`, in the DSFR for Drupal package.

Use it on DSFR-based French government sites to pick DSFR icons. It is a content-editing/fields feature; the
selected icon is authored data and it has no access-control role. Add the picker field and configure the
icon set.

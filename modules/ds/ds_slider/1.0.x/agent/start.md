# Responsive Slider (DS Slider) (`ds_slider`)

Provides a configurable responsive image/content slider exposed as a block and a page, built on a bundled slider JavaScript library.

- Project: `ds_slider`, version `1.0.x`, core `^9 || ^10`.
- Category: Content display / Carousel / slider.
- Configure via route `ds_slider.settings`.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

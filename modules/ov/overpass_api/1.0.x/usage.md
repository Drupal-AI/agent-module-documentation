A client for OpenStreetMap's Overpass API.

---

Overpass API provides an API client to OpenStreetMap's Overpass API service — so a site can run Overpass QL queries against OSM data (fetch nodes/ways/relations in an area) and use the results, for mapping and geospatial features. It's a developer/geospatial client. Supports Drupal 10 and 11.

OverlayScrollbars applies the OverlayScrollbars plugin.

---

OverlayScrollbars **applies the OverlayScrollbars JavaScript plugin** — replacing native scrollbars with
custom, cross-browser overlay-style scrollbars for a consistent look, on configured elements. It provides its
own permissions, in the User interface package.

Use it to style scrollbars consistently. It is a theming/front-end feature affecting presentation; it has no
content or access role beyond its permission. Configure where OverlayScrollbars applies.

BirdSeed integrates the BirdSeed platform with Drupal.

---

BirdSeed provides integration with BirdSeed — connecting Drupal to the BirdSeed service (a feedback/engagement or analytics platform) so its features can be used on the site. It's the integration/connectivity layer for that service.

BirdSeed API credentials should be stored securely (env-backed). Administration is gated by `administer birdseed`. Supports Drupal 10.2+ and 11.

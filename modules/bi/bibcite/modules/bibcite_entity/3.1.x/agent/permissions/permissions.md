# Permissions (`bibcite_entity.permissions.yml`)

Granular per-entity permissions (plus dynamic per-reference-type ones via `ReferencePermissions`).

## Reference (`bibcite_reference`)

- `administer bibcite_reference` (restricted) — settings/admin.
- `create bibcite_reference` — create any type.
- `edit own bibcite_reference` / `edit any bibcite_reference`.
- `delete own bibcite_reference` / `delete any bibcite_reference`.
- `view bibcite_reference`, `view own unpublished bibcite_reference`.
- Revisions: `view all bibcite_reference revisions`, `revert all bibcite_reference revisions`,
  `delete all bibcite_reference revisions`.
- Dynamic per-type create/edit/delete permissions are generated by `ReferencePermissions`
  (`bibcite_entity.permissions.yml` `permission_callbacks`).

## Contributor (`bibcite_contributor`)

- `administer bibcite_contributor` (restricted), `create bibcite_contributor`,
  `edit bibcite_contributor`, `delete bibcite_contributor`, `view bibcite_contributor`.

## Keyword (`bibcite_keyword`)

- `administer bibcite_keyword` (restricted), plus create/edit/delete/view analogues.

Grant in code:

```php
use Drupal\user\Entity\Role;
$role = Role::load('editor');
$role->grantPermission('create bibcite_reference');
$role->grantPermission('edit any bibcite_reference');
$role->save();
```

Note: broad site configuration of Bibcite still uses bibcite core's `administer bibcite`
permission; these permissions govern the *content* entities specifically.

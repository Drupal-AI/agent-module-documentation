Output entities as JSON/XML/HTML without the theme wrapper for embedding.

---

Themeless provides a REST API for iframe embedding and headless Drupal — outputting entities (nodes, users, taxonomy terms) as JSON, XML, or HTML without the theme wrapper, for external site embedding, mobile apps and API integrations.

Its output routes use a custom access check; ensure it restricts which entities/bundles are exposed so unpublished or access-controlled content is not leaked. Depends on core `node`; supports Drupal 10 and 11.

# Three.js — agent index

Integrates the **three.js** library to display **WebGL/3D media** (3D models/scenes; `threejs_editor`/
`threejs_fields` submodules). Config at `threejs.settings_form`; provides permissions. Version **1.0.9**.
Core `^10||^11||^12`.

Content-display/media — renders 3D assets client-side (managed content, respects file access); no access
role.

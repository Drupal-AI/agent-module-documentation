Three.js integrates the three.js library to display WebGL media data (3D models/scenes).

---

Three.js integrates the three.js JavaScript library into Drupal — to display WebGL/3D media (3D models,
scenes) on the site, with `threejs_editor` and `threejs_fields` submodules for editing and field integration.
It is configured at `threejs.settings_form`, provides its own permissions, in the WebGL package.

Use it to display 3D/WebGL content. It is a content-display/media feature rendering 3D assets client-side;
the 3D assets are managed content (respecting file access), and it has no access-control role. Configure the
three.js display and add 3D fields.

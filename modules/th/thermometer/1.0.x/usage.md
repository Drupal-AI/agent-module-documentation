Thermometer provides a thermometer block widget for fundraising.

---

Thermometer provides a **thermometer block widget for fundraising** — a visual "how much raised toward the
goal" indicator (a filling thermometer) placed via the block system. It is in the Other package.

Use it to show fundraising progress. It is a content-display/user-engagement feature; the goal/current values
are admin-configured and it has no content or access role. Place and configure the thermometer block.

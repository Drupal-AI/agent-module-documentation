Thumbor Effects Crop allows manual cropping per upload in combination with Thumbor's smart imaging effects.

---

Thumbor Effects Crop extends Thumbor Effects with manual, per-upload cropping — letting editors define
a crop area for a specific image (via the Crop API) that is then combined with Thumbor's smart imaging
when generating derivatives. This gives editorial control over framing on top of Thumbor's automated
processing. It depends on core Crop, core Image and Thumbor Effects.

Use it where automated smart-cropping isn't enough and editors need to set the crop manually for certain
images. It is a media/image feature building on Thumbor Effects; the same Thumbor security-key
considerations apply (store the key as a secret). Configure crop types and use the effect in image
styles.

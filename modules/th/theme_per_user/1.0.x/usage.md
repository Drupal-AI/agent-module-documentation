Theme per User allows selecting a theme per user.

---

Theme per User lets each user choose their own theme — so a user can select which theme they see
(commonly the admin theme, or the front-end theme), giving per-user theme preferences. It is configured at
`theme_per_user.settings` and provides its own permissions.

Use it to allow per-user theme selection. It is a display/personalization feature affecting which theme a
user sees; it does not change content or access (the theme is presentation) and has no access-control role.
Gate who may choose a theme with its permissions, and restrict the selectable themes to trusted/appropriate
ones (a theme is code/assets — only offer themes you control). Configure the allowed themes.

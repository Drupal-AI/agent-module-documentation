# Theme per User — agent index

Lets each **user select their own theme** (per-user theme preference — admin/front-end). Config at
`theme_per_user.settings`; provides permissions. Version **1.0.x** (dev). Core `^8||^9||^10||^11`.

Display/personalization — theme is presentation (no content/access change). Gate who may choose via its
permission; restrict selectable themes to trusted ones. No access role.

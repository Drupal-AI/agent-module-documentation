Theme class namespaces and provider-typed plugin definitions for developers.

---

Themespace provides theme class namespaces and use of provider-typed plugin definitions — a developer API that lets themes register PHP class namespaces and lets modules define plugins whose provider can be a theme, enabling more powerful, class-based theme/plugin architecture. It's a developer dependency (e.g. used by Transmuter). Supports Drupal 11 and 12.

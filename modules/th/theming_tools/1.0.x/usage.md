Theming Tools provides a dashboard and markup generator for admin theme development.

---

Theming Tools **aids admin theme development** — a dashboard and markup/test generator to help developers
build and test admin themes (previewing components/markup). It provides its own permissions, in the Theming tools
package.

Use it as a theme-development aid. It is a developer/theming tool; it generates test markup (developer-facing) and
has no content or access role beyond its permission. Note: gate it to developers and use in development. Use the
theming tools.

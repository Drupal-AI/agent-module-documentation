# Configuration

The Simpsons has almost nothing to configure — placing the block is the main step,
and there is a single optional setting for translation.

## Place the block

1. Go to **Structure → Block layout** (`/admin/structure/block`).
2. Find the region where you want the quote to appear and click **Place block**.
3. Choose the **The Simpsons** block, adjust the standard block settings (title,
   visibility, region) as you like, and save.

The block now shows a random quote on the pages where it is visible.

## Translate the quotes (optional)

If you would like the quotes shown in your website's language rather than the
original English:

1. Go to `/admin/config/system/simpsons`.
2. Tick the box to translate the quotes.
3. Save.

Leave it unchecked to keep the quotes as they are.

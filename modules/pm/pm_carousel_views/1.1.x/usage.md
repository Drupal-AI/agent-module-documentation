PM Carousel Views allows using PM Carousel as a view style.

---

PM Carousel Views provides a Views display/style that renders View results as a PM Carousel — the
accessibility-focused carousel/slider — so a listing can be presented as an accessible carousel from a View.
It depends on the PM Carousel module (and core Views), in the Media package.

Use it to present a View as a PM Carousel. It is a content-display/Views feature affecting presentation; the
results respect the View's access and it has no access-control role. Select the PM Carousel style on the
View.

Use the Tobii lightbox with PM Carousel.

---

PM Carousel integration with Tobii lightbox allows using the Tobii lightbox library with PM Carousel — so images in a PM Carousel open in a Tobii lightbox when clicked, combining the two libraries for a carousel-with-lightbox gallery. Depends on `pm_carousel` and `lightbox_tobii`; supports Drupal 10.3+ and 11.

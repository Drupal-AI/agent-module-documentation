PM Carousel Accessible Slider allows using the PM Carousel accessible JavaScript library.

---

PM Carousel Accessible Slider integrates the PM Carousel JavaScript library — an accessibility-focused
slider/carousel — so content can be presented as an accessible carousel (keyboard/screen-reader friendly). It
is in the Media package.

Use it for an accessible carousel. It is a content-display/UI feature affecting presentation; the carousel
content comes from the page and it has no access-control role. Configure the carousel.

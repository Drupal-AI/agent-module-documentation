# FlowDrop Node Category (flowdrop_node_category) — agent index

Submodule of **flowdrop**. Entity grouping node types into **editor palette sections**.
Version **2.0.0**. Core `^11.3`.

Small submodule, disproportionate effect: with 25+ node types a flat palette is unusable.

**Presentation, not capability.** Restricting what an author may use is `flowdrop_node_type`'s job.
Hiding a node in an obscure category is not a control — say so if anyone treats it as one.

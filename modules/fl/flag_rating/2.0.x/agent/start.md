# Flag Rating — agent index

Provides **rating functionality built on the Flag module** (star/like ratings; Views display). Depends on `flag`,
core `views`, `node`. Version **2.0.x** (dev). Core `^9.3||^10||^11`.

User-engagement/content — guard against rating abuse; anonymous ratings are spoofable/approximate. No access
role.

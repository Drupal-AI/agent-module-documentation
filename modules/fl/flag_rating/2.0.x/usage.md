Flag Rating provides a flag rating functionality.

---

Flag Rating provides **rating functionality built on the Flag module** — letting users rate content (e.g.
stars) using flags, with Views integration to display/aggregate ratings. It depends on Flag, core Views and
Node.

Use it to add flag-based ratings. It is a user-engagement/content feature. Note: like any user-generated rating,
guard against abuse (repeat/bot ratings) — flags are per-user for authenticated users; for anonymous, ratings
are weaker (spoofable) and should be treated as approximate. It has no access-control role. Configure the rating
flag and display.

Entity-context support for FlowDrop sessions (init a workflow with a node/term).

---

FlowDrop Node Session provides entity context support for FlowDrop sessions — allowing workflows to be initialized with a Drupal entity (node, term, etc.) as context, so a FlowDrop AI workflow can operate against a specific piece of content. Depends on the FlowDrop suite (`flowdrop`, `flowdrop_session`, `flowdrop_playground`, `flowdrop_workflow`, `flowdrop_ui_components`, `flowdrop_node_processor`); supports Drupal 11.2+.

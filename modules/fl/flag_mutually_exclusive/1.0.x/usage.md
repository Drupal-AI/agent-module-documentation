Enforce mutual exclusion between configured pairs of Flag flags.

---

Flag mutually exclusive enforces mutual exclusion between configured pairs of Flag flags on the same entity — when a user sets flag A on an entity, flag B is automatically unset, and vice versa (e.g. like/dislike where a user can hold only one at a time). Flag pairs are configurable via the admin UI. Depends on `flag` (>=5.0.0); supports Drupal 11.3+.

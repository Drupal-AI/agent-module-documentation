FlipDown adds a FlipDown JS countdown formatter for Date/Datetime fields.

---

FlipDown provides a field formatter that renders a Date/Datetime field as an animated FlipDown-style
countdown — a flip-clock countdown to the field's date/time, for event launches, sales or deadlines. It
depends on core Field, in the Field formatters package.

Use it to show a countdown to a date field. It is a content-display/formatter feature; the countdown reflects
the date value (content the user can see) and it has no access-control role. Select the FlipDown formatter on
the date field.

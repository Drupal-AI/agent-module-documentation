# FlipDown — agent index

A **FlipDown-style animated countdown formatter for Date/Datetime fields** (flip-clock countdown to the
field's date — events/sales/deadlines). Depends on core `field`. Version **1.0.2**. Core `^9||^10||^11||^12`.

Content-display/formatter — countdown reflects the date value; no access role.

FlowDrop Gin integrates the FlowDrop UI with the Gin admin theme.

---

FlowDrop Gin **integrates the FlowDrop UI with the Gin admin theme** — mapping FlowDrop's UI design tokens to
Gin's accent colors and synchronizing dark mode, so FlowDrop's interface matches the Gin admin experience. It
depends on the FlowDrop UI Components module.

Use it to make FlowDrop look native in Gin. It is a theming/admin-UI integration; it aligns styling and has no
content or access role. Enable it alongside FlowDrop and Gin.

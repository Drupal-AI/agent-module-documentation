FlowDrop UI provides the FlowDrop user interface.

---

FlowDrop UI provides the **FlowDrop visual-editor user interface** — the base UI (canvas/nodes/connections)
for FlowDrop, a visual flow/diagram editor used by other FlowDrop modules to build node-based flows. It is in
the FlowDrop package (core 11).

Use it as the UI foundation for FlowDrop-based tools. It is a developer/UI library; on its own it provides the
editor UI and has no content or access role. Depend on it from FlowDrop modules.

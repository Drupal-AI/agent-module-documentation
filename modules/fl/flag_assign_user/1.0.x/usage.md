Flag Assign User provides a form to assign users a flag.

---

Flag Assign User provides a **form to assign users a Flag** — letting an administrator flag content/entities
on behalf of selected users (using the Flag module), e.g. bulk-subscribe users or set a per-user flag. It
depends on the Flag module, provides its own permissions, in the Flags package.

Use it to manage flags on behalf of users. It is an administration feature gated by its permission. Security
note: assigning flags for other users is a **privileged action** (it changes those users' flag state, which may
drive subscriptions/notifications) — gate the permission to trusted admins. It has no broad access-control role
beyond its permission. Configure and use the assign form.

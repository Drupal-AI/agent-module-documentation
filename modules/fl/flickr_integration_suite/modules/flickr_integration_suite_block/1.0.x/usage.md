Flickr Integration Suite Block places Flickr content as a block, configured per placement through block layout.

---

This is the site-builder's placement option in the suite. A block is configured where blocks are configured, placed in a region, and restricted with the usual visibility conditions — so a photostream in a sidebar, a photoset on one section of the site, or a gallery in a footer are all block layout decisions rather than content or code decisions.

Choosing the block over the field or the filter comes down to who owns the placement. A block belongs to the site's structure: it appears on many pages, it is the same for everyone, and it is managed by whoever manages layout. A field belongs to a content item, and a filter belongs to an editor writing prose.

Because it is a block, everything block layout offers applies — per-theme placement, visibility by path, role or content type, and ordering within a region. And because it is one of three optional submodules, a site that only wants inline photos in body text never has to enable it.

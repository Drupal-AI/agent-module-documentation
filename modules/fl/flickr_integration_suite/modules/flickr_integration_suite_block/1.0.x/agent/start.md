# Flickr Integration Suite Block (flickr_integration_suite_block) — agent index

Submodule of **flickr_integration_suite**. Configurable **block** displaying Flickr content.
Version **1.0.6**. Core `^10.3 || ^11`.

The site-builder placement option. Choose it over the field or filter when placement belongs to
**site structure** rather than to a content item (field) or to an editor writing prose (filter).

Full block layout applies: per-theme placement, visibility by path/role/content type, region
ordering. Cache the block — the Flickr API is rate-limited.

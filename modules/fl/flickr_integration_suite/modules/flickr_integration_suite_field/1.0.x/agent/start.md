# Flickr Integration Suite Field (flickr_integration_suite_field) — agent index

Submodule of **flickr_integration_suite**. **Field type** attaching Flickr content to an entity.
Version **1.0.6**. Core `^10.3 || ^11`.

Choose it when the photos belong to a **specific content item** (an event's gallery, an
exhibition's documentation) rather than to the site.

Field consequences are the point: revisioned with the content, translatable, exported with it,
available in Views, and display is a **Manage display** decision (thumbnail in teaser, gallery in
full view).

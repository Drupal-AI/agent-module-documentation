FlowDrop Agents connects the AI Agents framework to FlowDrop's plugin system.

---

FlowDrop Agents integrates the AI Agents framework with FlowDrop core plugins, letting FlowDrop workflows invoke taskable AI agents as part of their flows. It bridges FlowDrop's node/flow plugins to AI-driven actions.

Agent actions run through the configured AI provider (cost) and can act on site data; keep usage to trusted editors. Depends on `flowdrop`, `flowdrop_interrupt`, `ai_agents`, and `ai`; supports Drupal 10, 11, and 12.

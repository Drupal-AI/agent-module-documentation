# Flipbook HTML5 — agent index

**Transforms PDF file fields into interactive 3D flipbooks** (PDF.js + PageFlip). Depends on core `file`, `pdf`.
Version **1.0.2**. Core `^9.3||^10||^11||^12`.

Media/display — PDF rendered client-side; access follows normal file/field access (private PDFs need private-file
handling); no access role.

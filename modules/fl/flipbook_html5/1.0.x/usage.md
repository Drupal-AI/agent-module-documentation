Flipbook HTML5 transforms PDF file fields into interactive 3D flipbooks using PDF.js and PageFlip.

---

Flipbook HTML5 **transforms PDF file fields into interactive flipbooks** — rendering an uploaded PDF as a
page-flipping 3D "flipbook" in the browser using PDF.js and the PageFlip library, for magazine/brochure-style
display. It depends on core File and the PDF module.

Use it to display PDFs as flipbooks. It is a media/display feature; the PDF is rendered client-side and its access
follows normal file/field access, and it has no access-control role. Note: rendering follows the file's access, so
private PDFs need private-file handling. Configure the flipbook formatter.

Flexible Event Calendar API provides a render element to generate a calendar array from event content for display in a calendar.

---

Flexible Event Calendar API provides a render element that turns event content into a calendar-display
array — a flexible API for rendering events in a calendar layout, letting developers/site builders generate
their own calendar format from event data. It is in the JS libraries package.

Use it to build custom event-calendar displays. It is a content-display/developer feature providing a
calendar render element; it renders event data (respecting the events' access, since it works from event
content) and has no access-control role. Use the render element with your event data to produce a calendar.

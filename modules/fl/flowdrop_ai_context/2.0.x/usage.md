A FlowDrop node processor that injects AI Context into workflows.

---

FlowDrop AI Context is a FlowDrop node processor that injects AI Context into workflows — so a FlowDrop (visual AI-workflow) node can pull in AI Context (from the AI Context module) as part of an automated LLM workflow, giving the AI relevant grounding. Depends on `flowdrop`, `flowdrop_node_category`, and `ai_context`; supports Drupal 11 and 12.

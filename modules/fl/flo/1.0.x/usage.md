Flexible List Options adds advanced ordered-list styles to CKEditor 5 with per-level config.

---

Flexible List Options (flo) **adds advanced ordered-list styles in CKEditor 5** — a CKEditor 5 plugin for
advanced ordered-list styles with per-indentation-level configuration, for richer list formatting. It depends on
core CKEditor 5 and Editor.

Use it for advanced list styling. It is a content-editing/WYSIWYG feature; list markup passes through the text
format and it has no access-control role. Configure the list options.

# Flexible List Options — agent index

**CKEditor 5 plugin for advanced ordered list styles** with per-indentation-level configuration. Depends on core
`ckeditor5`, `editor`. Version **1.0.0**. Core `^11`.

Content-editing/WYSIWYG — list markup passes through the text format; no access role.

Flat Menus prevents menu items from being nested, enforcing a flat menu structure.

---

Flat Menus **prevents menu items from being nested** — enforcing a **flat (single-level) menu structure**
so editors can't create parent/child hierarchies in configured menus, useful where a design or integration
requires flat menus. It depends on core Menu Link Content, provides its own permissions, in the Custom package.

Use it to keep menus flat. It is a site-structure/menu feature affecting menu editing; it has no content or
access role beyond its permission. Configure which menus are kept flat.

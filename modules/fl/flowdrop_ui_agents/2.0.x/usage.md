FlowDrop UI Agents provides FlowDrop visual editor integration for AI agents.

---

FlowDrop UI Agents provides a **FlowDrop visual editor for building AI agents** — a node-based canvas to
compose AI agent flows, integrating AI, AI Agents, AI Assistant API and the Modeler API. It depends on those
plus FlowDrop UI Components, in the FlowDrop package (core 11).

Use it to visually build AI agent workflows. It is an AI/developer tooling feature. Security/data handling:
agents it builds can **call the AI provider** (egress) and **execute tools/actions**, so the agents/tools must be
**scoped and gated** (an over-powered agent triggered by untrusted input is a risk), and provider keys stay in
the AI module's Key config. Building agents is a privileged action — keep it to trusted developers. It has no
access-control role of its own. Build and scope agents in the editor.

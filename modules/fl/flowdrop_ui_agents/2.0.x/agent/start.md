# FlowDrop UI Agents — agent index

A **FlowDrop visual editor for building AI agents** (AI Agents + Modeler API). Depends on `ai`, `ai_agents`,
`ai_assistant_api`, `modeler_api`, `flowdrop_ui_components`. Version **2.0.0**. Core `^11`.

AI/developer tooling — agents **call the AI provider** (egress) + **run tools**: scope/gate them, keep
agent-building to trusted developers; keys in AI/Key. No access role of its own.

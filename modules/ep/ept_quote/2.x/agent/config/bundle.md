# ept_quote — Quote paragraph bundle

Machine name `ept_quote`. A Paragraphs bundle installed entirely from `config/install/`, plus one
widget class and one Twig template. No custom routes, permissions, services, drush, or config
schema.

## Install / enable

- `drush en ept_quote -y` (pulls `ept_core` + `paragraphs`).
- Install-time gate: `ept_quote_requirements()` (`ept_quote.install`) blocks install with a
  `RequirementSeverity::Error` unless an **"Image" media type** exists — create one at
  `/admin/structure/media` first.
- On install, Drupal imports the bundle, its five fields, an `ept_quote_image` image style, and
  the default form/view displays. Add the bundle to any Paragraphs reference field, then edit an
  entity to add a "EPT Quote".

## Fields (config/install/field.field.paragraph.ept_quote.*)

| Field | Type | Label | Notes |
|-------|------|-------|-------|
| `field_ept_title` | text_long | Title | Rendered in `<h2>` when non-empty. |
| `field_ept_text` | text_long | (hidden label) | The quote body. |
| `field_ept_quote_author` | text_long | Quote Author | Attribution line. |
| `field_ept_quote_image` | entity_reference → media (image) | (hidden) | View display: `media_thumbnail`, image style `ept_quote_image`, `image_loading: lazy`. |
| `field_ept_settings` | `ept_settings` (ept_core) | Settings | Shared EPT design options. |

All text fields are non-required, non-translatable by default. `field_ept_title`/`field_ept_text`/
`field_ept_quote_author` use `allowed_formats: {}` (the site's available text formats apply — output
is filtered by the chosen text format, per standard core behavior).

## Form display (config/install/core.entity_form_display.paragraph.ept_quote.default.yml)

- Uses **field_group** tabs: a **Content** tab (title, text, author, image) and a **Settings** tab.
- `field_ept_settings` widget = **`ept_settings_quote`** (weight 2); author/text/title use
  `text_textarea` (5 rows); image uses `media_library_widget`.

## Styles widget (src/Plugin/Field/FieldWidget/EptSettingsQuoteWidget.php)

- `@FieldWidget(id = "ept_settings_quote")`, `field_types = { "ept_settings" }`, extends ept_core's
  `EptSettingsDefaultWidget` (so it inherits all the box/background/container design options).
- `formElement()` adds a `quote_styles` details group with a `styles` **radios** element. Fixed
  options: `persona`, `company`, `persona_with_small_icon`, `with_square_image`,
  `with_frame_and_background_image`. `#default_value` `persona`. The description links to example
  screenshots under `/images/help/`.
- `massageFormValues()` lifts `values[0]['ept_settings']['quote_styles']['styles']` back up to
  `values[0]['ept_settings']['styles']` before save.

## Template & layouts (templates/paragraph--ept-quote--default.html.twig)

- Reads the saved style from
  `content.field_ept_settings['#object'].field_ept_settings.ept_settings.styles`.
- Builds a `classes` array including `ept-quote-<style>` and `paragraph-id-<id>`, then branches
  per style, wrapping title (`<h2>`), image, and remaining content in style-specific divs. Each
  branch `attach_library('ept_quote/<style>')`. The `{% else %}` branch falls back to `persona`.
- `{{ styles|raw }}` at the end prints the per-paragraph `<style>` block generated by ept_core's
  `GenerateCSS::generateFromSettings()` (set in ept_core `preprocess_paragraph`) — this is the
  standard EPT design-options CSS, not free-form user markup.

## Libraries (ept_quote.libraries.yml)

Five component CSS libraries — `persona`, `company`, `persona_with_small_icon`, `with_square_image`,
`with_frame_and_background_image` — each loading one `css/*.css`. No JS. No external dependencies.

## Operate

- Choose a layout on the paragraph's **Settings** tab → "Quote styles".
- Per-quote spacing/background/border/width come from the ept_core design options on the same
  Settings tab; global colors/breakpoints from ept_core's own settings form
  (`/admin/config/content/ept-core-settings`, provided by ept_core, not this module).
- To restyle a layout, override the relevant `css/<style>.css` in your theme.
- No configuration export/import beyond the shipped `config/install/*` (which becomes site config
  after install like any bundle).

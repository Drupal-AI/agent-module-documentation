EPT Sticky Menu adds a Paragraphs type that renders an in-page navigation menu which sticks to the viewport as visitors scroll.

---

Part of the Extra Paragraph Types (EPT) family, this module ships three cooperating paragraph types — a Sticky Menu container, a Sticky Menu Link, and a Sticky Menu Links dropdown group — that let editors build an anchor/navigation bar entirely from content, with no custom code. The container is made "sticky" through the bundled levmyshkin/sticky-js library, and companion JavaScript adds scroll-spy highlighting of the active section, smooth-scrolling to on-page anchors with an offset for the menu height, a mobile hamburger toggle, and expandable second-level dropdowns. Each link and the menu itself reuse ept_core's EPT settings field, so authors also get the standard design options (spacing, borders, background, container width) plus sticky-specific options such as margin-top, activation breakpoint and the stuck CSS class. Because everything is authored as paragraphs referenced from a host entity's paragraph field, the sticky menu can be placed on any content type that uses Paragraphs.

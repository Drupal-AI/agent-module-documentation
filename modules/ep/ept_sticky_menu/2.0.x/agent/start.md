# EPT Sticky Menu (ept_sticky_menu) — agent index

Config-only **Paragraphs** type (EPT family) that renders an **in-page sticky navigation menu**:
a menu container plus link and dropdown-group child paragraphs, made sticky by the bundled
`levmyshkin/sticky-js` library, with scroll-spy, smooth-scroll anchors, a mobile toggle and
second-level dropdowns added by `js/ept-sticky-menu.js`.

- Package `Extra Paragraph Types`. Depends on **`ept_core`** and **`paragraphs`**
  (composer also `levmyshkin/sticky-js:^1.3`). Core `^10.1 || ^11 || ^12`. License GPL-2.0-or-later.
  Version-dir 2.0.x (installed release 2.0.2).
- **No** routes, permissions, services beyond one hook class, config schema, Drush, or plugin types.
  All behaviour is config (`config/install/*`), two field widgets, three Twig templates and JS.

## What it provides (from source)

- **Three paragraph types** (`config/install/paragraphs.paragraphs_type.*`):
  `ept_sticky_menu` (EPT Sticky Menu — the container), `ept_sticky_menu_links` (dropdown group),
  `ept_sticky_menu_link` (single link). Fields + displays → [paragraphs/paragraph-types.md](paragraphs/paragraph-types.md).
- **Two field widgets** for the `ept_settings` field type, both extending
  `ept_core`'s `EptSettingsDefaultWidget`:
  `EptSettingsStickyMenuWidget` (id `ept_settings_sticky_menu`) and
  `EptSettingsStickyMenuLinkWidget` (id `ept_settings_sticky_menu_link`) in
  `src/Plugin/Field/FieldWidget/`. Keys + defaults → [config/widgets.md](config/widgets.md).
- **One hook class** `src/Hook/EptStickyMenuHooks.php` (autowired service, `.module` delegates via
  `#[LegacyHook]`): `hook_theme_registry_alter` (registers the link/links templates) and
  `hook_preprocess_paragraph` (computes `link_url`, `link_text`, `ept_link_settings` for link
  paragraphs). Details → [theming/templates-and-js.md](theming/templates-and-js.md).
- **Templates + JS + libraries**: three `paragraph--ept-sticky-menu*--default.html.twig`, library
  `ept_sticky_menu` (css/styles.css, sticky.min.js, js/ept-sticky-menu.js; deps core/drupal,
  core/once). → [theming/templates-and-js.md](theming/templates-and-js.md).

## Operate it

- Enable `ept_sticky_menu` (pulls in `ept_core` + `paragraphs`). It installs the paragraph types
  and fields; add the `ept_sticky_menu` paragraph type to any entity's paragraph reference field.
- No admin settings form of its own; shared colour/breakpoint config lives in
  `ept_core.settings` (EPT Core). CSS from design options is generated by `ept_core`'s
  `GenerateCSS` service and printed via `{{ styles|raw }}` in the templates.

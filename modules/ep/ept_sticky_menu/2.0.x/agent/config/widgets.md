# EPT settings field widgets

Two `@FieldWidget` plugins in `src/Plugin/Field/FieldWidget/`, both for `field_types = {"ept_settings"}`
and both extending `Drupal\ept_core\Plugin\Field\FieldWidget\EptSettingsDefaultWidget`. Each calls
`parent::formElement()` (which builds ept_core's Design options / colorpicker / background UI) and then
adds or removes fields. Both override `massageFormValues()` only to ensure each delta has an
`ept_settings` key.

## `EptSettingsStickyMenuWidget` (id `ept_settings_sticky_menu`)

Used on the **`ept_sticky_menu`** container's `field_ept_settings`. On top of the inherited
design_options (moved to `#weight -32`), it adds under `ept_settings`:

- `pass_options_to_javascript` — hidden, value `TRUE` (makes ept_core pass options to JS; see
  `ept_core_paragraph_view()`).
- `enable_sticky` — checkbox, default `1`. "Make menu sticky on scroll." Drives the
  `sticky-js-block` class in the container template.
- `margin_top` — number, default `0`. Gap between page top and the stuck element →
  `data-margin-top`.
- `sticky_for` — number, default `0`. Breakpoint above which sticky activates → `data-sticky-for`.
- `sticky_class` — number(!) input, default `'is-sticky'`. CSS class applied when stuck →
  `data-sticky-class` (template falls back to `is-sticky` when empty). (Field is declared
  `#type => 'number'` though the value is a class string — a module quirk, not a setting you
  normally change.)
- `sticky_wrap` — checkbox, default `0`. Wrap the stuck element in a sizing `<span>` to stop content
  "jumping" → `data-sticky-wrap`.

These `data-*` attributes are read by `js/ept-sticky-menu.js` / sticky-js. A `@todo` in the source
notes a planned "select menu to display" feature (not implemented).

## `EptSettingsStickyMenuLinkWidget` (id `ept_settings_sticky_menu_link`)

Used on the **`ept_sticky_menu_link`** link paragraph's `field_ept_settings`. It **removes**
`design_options` and `title_options` from the inherited form, then adds:

- `open_in_new_tab` — checkbox, default `0` → template renders `target="_blank"`.
- `link_classes` — textfield, default `''` → template `class="…"` on the `<a>`.
- `rel` — radios: `''` (None) / `nofollow`, default from `ept_settings['mode']` → template
  `rel="…"`. (Default reads the `mode` key rather than `rel`; a minor inconsistency.)
- `scroll_to_id` — textfield, default `''`. When set, the link URL is replaced with `#<id>` in
  `preprocessParagraph()` (on-page anchor).

## Notes

- The `ept_settings` field **type/schema** and the base widget belong to **ept_core**, not this
  module — this module ships no `config/schema`.
- Design-option CSS (spacing/border/background/etc.) is generated by ept_core's
  `GenerateCSS::generateFromSettings()` and printed via `{{ styles|raw }}`; that service escapes each
  value with `Html::escape()` before building the `<style>` string.

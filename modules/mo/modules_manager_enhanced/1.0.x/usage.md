Modules Manager Enhanced enhances the core Extend (modules) admin page with filtering and performance improvements.

---

Modules Manager Enhanced **improves the core modules admin page** — adding package filtering and server-side
performance optimization to `/admin/modules`, making a long module list easier and faster to work with. It depends
on core System.

Use it to make the Extend page more usable. It is an administration/UI enhancement; it only alters the modules-list
UI (it does not itself download or install code from the web) and has no content or access role. Enable it for the
enhanced modules page.

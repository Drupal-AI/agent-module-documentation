Monolog Extra provides additional Monolog handlers and processors for the Monolog logging module.

---

Monolog Extra provides additional handlers and processors for the Monolog module — extending Drupal's
Monolog integration with extra ways to route or enrich log records (custom handlers, processors that add
context). It depends on the Monolog module and is in the Development package.

Use it where the base Monolog handlers/processors aren't enough. It is a developer/logging feature adding
to the logging pipeline; as with any logging, be mindful that processors adding context/request data could
include sensitive information — scrub as needed. It has no content or access role. Configure the extra
handlers/processors in your Monolog channel configuration.

Access the Moodle API and select Moodle courses via a field widget.

---

Moodle Field Widget provides access to the Moodle API and a Field Widget for selecting Moodle courses — so an editor can pick a course from a connected Moodle LMS via an autocomplete/select widget and store the reference, linking Drupal content to Moodle courses.

The Moodle API token is admin-configured and should be stored securely (env-backed), never committed. Depends on core `field`; supports Drupal 10 and 11.

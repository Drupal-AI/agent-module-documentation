Model Viewer Formatter provides a field formatter to display 3D OBJ files with Google Model Viewer.

---

Model Viewer Formatter **displays 3D models using Google Model Viewer** — a field formatter that renders
uploaded 3D OBJ files as interactive 3D viewers (via the `<model-viewer>` web component) in the browser. It works
on core 10–11.

Use it to show interactive 3D models. It is a media/display feature; models render client-side per normal file/
field access and it has no access-control role. Configure the model-viewer formatter on a file field.

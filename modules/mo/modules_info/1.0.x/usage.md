Modules Info provides a block listing the site's modules and their info.

---

Modules Info **provides a Modules Info block** — displaying information about the site's installed modules
(names/versions/status) in a block. It provides its own permissions.

Use it to surface module info on a page. It is an administration/informational feature. Security note: the list of
installed modules and versions is **fingerprinting data** (it reveals your stack), so gate the block/permission to
trusted users and don't expose it publicly. It has no content or access role beyond its permission. Configure the
modules-info block.

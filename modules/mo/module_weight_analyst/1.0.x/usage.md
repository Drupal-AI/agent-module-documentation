Module Weight Analyst developer utility for monitoring and managing module execution order (weights).

---

Module Weight Analyst **monitors and manages module execution order** — a developer utility showing module
weights, dependency tracking, a real-time "integrity score" and automated conflict detection, to help diagnose
hook-order/module-weight issues. It provides its own permissions, in the Development package.

Use it to analyze/adjust module weights. It is a developer/administration tool; it inspects and can change module
weights (which affects hook execution order) and has no content or access role beyond its permission. Note:
changing module weights can alter behavior — adjust deliberately and gate to trusted developers. Configure/adjust
the weights.

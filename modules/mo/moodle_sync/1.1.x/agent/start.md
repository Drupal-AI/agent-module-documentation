# Moodle Sync — agent index

**Uses Moodle web services to sync data between Drupal and Moodle** (users/courses/enrolments). Version
**1.1.1**. Core `^10||^11`.

Integration — Moodle **web-service token** as a secret (env/Key, HTTPS); exchanges **user/enrolment PII** (handle
per privacy). No access role.

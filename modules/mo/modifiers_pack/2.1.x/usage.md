Modifiers Pack provides a collection of basic Modifier plugins — backgrounds, colors, corners, spacing, gradients, effects and more — for the Modifiers styling framework.

---

Modifiers Pack bundles a broad set of Modifier plugins for the Modifiers module, a framework that
lets site builders apply configurable visual styling to components/layouts without writing CSS. The
pack ships many individual modifiers as submodules — background image/video/parallax, color and custom
gradient backgrounds, corners, padding, shadow, clip-path, fonts, image effects, scroll-reveal
animation, responsive height, hide, and others — each enabling a specific styling control that editors
configure through the UI. It depends on the base `modifiers` module.

Use it to give editors a rich palette of styling options on Modifiers-enabled components. Enable only
the submodule plugins you want to expose. It is a theming/presentation framework — the modifiers emit
styles/markup for visual effect and have no access-control role. As with any editor-facing styling,
values are authored and rendered through Drupal's layers.

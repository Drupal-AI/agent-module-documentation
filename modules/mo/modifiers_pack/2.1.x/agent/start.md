# Modifiers Pack — agent index

A set of **basic Modifier plugins** for the **Modifiers** styling framework — backgrounds (image/
video/parallax/gradient), colors, corners, padding, shadow, clip-path, fonts, image effects,
scroll-reveal, responsive height, hide, etc. — each a submodule. Depends on `modifiers`. Version
**2.1.3**. Core `^10.1||^11||^12`.

Theming/presentation only (no access role). Enable just the submodule plugins you want to expose.

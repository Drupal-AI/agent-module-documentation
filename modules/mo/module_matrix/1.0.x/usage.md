Module Matrix provides an enhanced module management interface with advanced filtering, package navigation and customizable module details.

---

Module Matrix replaces/enhances the Extend (module management) page with a richer interface — advanced
filtering, package-based navigation, and a customizable display of module details — making it easier to
find, understand and manage modules on sites with many modules. It requires PHP 8.1, depends on core
System, is configured at `module_matrix.settings_form`, and provides its own permissions.

Use it to improve the module-administration experience on large sites. It is an administration/UI tool for
managing modules; because enabling/disabling modules is a highly privileged operation, access is (as with
core's Extend page) restricted to administrators — grant its permission only to those trusted to manage
modules. It surfaces module information and does not itself change module code.

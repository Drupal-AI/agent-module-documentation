# Module Matrix — agent index

Enhanced **module-management interface** — advanced filtering, package navigation, customizable module
details. Requires **PHP 8.1**; depends on core `system`. Config at `module_matrix.settings_form`; provides
permissions. Version **1.0.11**. Core `^10||^11`.

Admin/UI tool — module enable/disable is highly privileged; restrict the permission to trusted admins
(like core's Extend page).

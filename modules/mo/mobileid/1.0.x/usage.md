Authenticate users via Mobile ID (mobile-phone-number-based identity).

---

Mobile ID is an advanced user identification technology that uses a unique mobile phone number as a means for authorization and verification in various electronic services — so users can authenticate to Drupal via their Mobile ID (e.g. Swisscom/Megafon Mobile ID), with the phone acting as a secure token.

It exposes a JWKS endpoint (public keys, by design) and a server-sent-events stream (keyed by an unguessable request UUID) for the auth flow. Store any Mobile ID service credentials securely (env-backed). Supports Drupal 10.3+ and 11.

Modified Form Alert shows an alert when a form has been edited and the user is leaving the page.

---

Modified Form Alert warns users about unsaved form changes — showing an alert (the browser's
leave-confirmation) when a configured form has been edited and the user tries to navigate away, preventing
accidental loss of edits. It requires PHP 8.0.

Use it to guard against losing unsaved form edits. It is a content-editing/UX feature affecting the leave-
page behaviour on forms; it does not change content or access and has no access-control role. Configure which
forms show the unsaved-changes alert.

Modules Collapse allows package groups to be closed by default on the modules page.

---

Modules Collapse **collapses the module package groups on the Extend page by default** — so the long
modules list (`/admin/modules`) opens with package groups closed, making it easier to scan on sites with many
modules. It works across core 8–11.

Use it to tidy the Extend page. It is an administration/UI convenience affecting the modules page only; it has
no content or access role. Enable it to collapse the groups.

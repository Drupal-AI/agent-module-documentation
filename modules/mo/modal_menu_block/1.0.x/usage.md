Modal Menu Block provides a block to display a menu in a modal.

---

Modal Menu Block **provides a block that displays a menu inside a modal/overlay** — showing a chosen menu in
a pop-up modal (e.g. a full-screen mobile menu) triggered by a button. It works across core 9.4–11.

Use it for a modal/overlay menu. It is a site-structure/navigation-UI feature; the menu follows normal menu
access and it has no access-control role. Configure the modal menu block.

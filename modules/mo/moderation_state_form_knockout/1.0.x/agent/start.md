# Moderation State Form Knockout — agent index

Shows the Content Moderation **state widget on forms but disables interaction** (editors *see* the state
read-only, can't change it via the widget). Version **1.0.0**. Core `^10||^11`.

**UI-only — NOT access control:** disabling the widget doesn't enforce transition access; **Content
Moderation's transition permissions** remain the authority. Treat as presentation, not a control. No access
role.

monday.com CRM integration sends Webform submissions to monday.com boards.

---

monday.com CRM integration relays Drupal Webform submissions to monday.com boards via monday.com's GraphQL API — so form submissions (leads, requests) are automatically created as items on a monday.com board, connecting site forms to a monday.com CRM/workflow.

The monday.com API token should be stored securely (env-backed); submissions send data to monday.com (privacy). Depends on core `webform` and `options`; supports Drupal 11 and 12.

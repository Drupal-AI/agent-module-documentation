Moderation State Condition provides a condition plugin for content-moderation states, so blocks/logic can be shown based on the moderation state.

---

Moderation State Condition provides a Drupal condition plugin based on content-moderation states — so
a block (or any condition-aware feature) can be shown/applied depending on the current entity's moderation
state (draft, published, archived, etc.). It depends on core Workflows and Content Moderation.

Use it to drive visibility/logic by editorial state — e.g. show an "in review" banner only on draft
content, or a block only when content is published. It is a display/visibility feature built on the
condition system; it governs where things appear based on moderation state, not access to the content
(access is governed by content-moderation permissions). Configure it where Drupal conditions are used.

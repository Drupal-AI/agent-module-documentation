MotaWord provides CDN-based site translation into 100+ languages via MotaWord Active Serve.

---

MotaWord integrates MotaWord Active Serve — a CDN-based translation delivery service — to translate a Drupal site into 100+ languages without maintaining translations in Drupal itself. Translated content is served through MotaWord's CDN layer.

The MotaWord API/project credentials should be stored securely (env-backed); content is processed by MotaWord (privacy). Administration is gated by `administer motaword`. Supports Drupal 9, 10, and 11.

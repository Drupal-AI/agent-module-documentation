# Mouseflow Tracking — agent index

Adds **Mouseflow session-recording/heatmap tracking** (captures mouse/clicks/scroll + potentially form
input). Config at `mouseflow_tracking.settings`. Version **2.0.0**. Core `^9||^10||^11`.

**Privacy (key):** session recording can capture **sensitive input** — enable Mouseflow field masking/
exclusions, disclose in the privacy policy, gate behind **cookie/consent** (GDPR/CCPA — third-party
tracking). No access role.

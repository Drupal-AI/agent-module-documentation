Mouseflow Tracking allows your site to be tracked by Mouseflow, adding the Mouseflow tracking script.

---

Mouseflow Tracking adds the Mouseflow tracking script to the site — enabling Mouseflow's session
recording, heatmaps and behavioural analytics, which capture how visitors interact with pages (mouse
movement, clicks, scrolling, and potentially form input). It is configured at `mouseflow_tracking.settings`,
in the Statistics package.

Use it to gather behavioural analytics via Mouseflow. **Privacy is the key consideration:** session
recording captures detailed user interaction and can inadvertently record sensitive input (passwords,
personal data typed into forms) unless fields are masked — so enable Mouseflow's field masking/exclusions for
sensitive inputs, disclose the tracking in your privacy policy, and gate it behind cookie/consent management
(GDPR/CCPA) since it is third-party tracking. It has no access-control role. Configure the Mouseflow site ID
and masking.

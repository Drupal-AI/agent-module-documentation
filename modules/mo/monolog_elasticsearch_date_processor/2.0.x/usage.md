Monolog Elasticsearch Date Processor provides a Monolog processor that formats dates in log records for Elasticsearch compatibility.

---

Monolog Elasticsearch Date Processor provides a Monolog processor that formats the date field of log
records for Elasticsearch — ensuring log timestamps are in a format Elasticsearch expects, so logs shipped
to Elasticsearch (via Monolog) index correctly. It depends on the Monolog module.

Use it when shipping Drupal logs to Elasticsearch via Monolog and timestamps need Elasticsearch-compatible
formatting. It is a developer/logging feature adding a processor to the Monolog pipeline; it formats log
data and has no content or access role. Add the processor to the relevant Monolog channel.

MO.JS makes the mo.js motion-graphics library available in Drupal.

---

MO.JS integrates MO.js — a fast, retina-ready JavaScript motion-graphics library — into Drupal, so themes and modules can create rich, performant animations and motion graphics on the front end without bundling the library themselves.

It's a front-end library integration with no content or access role of its own. Supports Drupal 8.8+ through 11.

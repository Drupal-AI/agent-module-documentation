Monitoring Memcache adds Monitoring sensors reporting on each configured Memcache cluster.

---

Monitoring Memcache **adds Monitoring sensors for Memcache** — reporting the health/stats of each configured
Memcache cluster through the Monitoring module, for operational visibility. It depends on the Monitoring and
Memcache modules.

Use it to monitor Memcache health. It is an operations/monitoring feature; sensor data is admin/monitoring-facing
and it has no content or access role. Note: monitoring endpoints can expose operational detail — gate them
appropriately (via Monitoring's access). Configure the Memcache sensors.

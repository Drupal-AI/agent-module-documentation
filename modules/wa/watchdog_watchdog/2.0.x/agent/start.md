# Watchdog Watchdog — agent index

Monitors the **Drupal watchdog log** ("watch the watchdog") — react/alert on log events (errors, security
events, patterns). Requires PHP 8.x. Version **2.0.0**. Core `^10||^11`.

Admin/monitoring tool on the log stream — log events can contain sensitive detail (send alerts to
appropriate recipients). No content-access role.

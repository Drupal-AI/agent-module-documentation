Watchdog Watchdog watches the Drupal watchdog log, monitoring log events (and enabling reactions/alerts).

---

Watchdog Watchdog monitors the Drupal watchdog log ("watch the watchdog") — observing log events as
they are recorded so the site can react to or alert on specific log conditions (errors, security events,
patterns). It requires PHP 8.x. This helps turn passive logging into active monitoring/alerting.

Use it where log events should trigger awareness or action (error spikes, specific warnings). It is an
administration/monitoring tool operating on the log stream; log events can contain sensitive detail, so any
alerting/forwarding it configures should go to appropriate recipients. It has no content-access role.
Configure what to watch for and how to react.

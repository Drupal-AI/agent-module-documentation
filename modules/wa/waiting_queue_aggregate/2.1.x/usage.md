A queue class that runs multiple waiting queues together.

---

Waiting Queue Aggregate provides a queue class that will run multiple waiting-queue queues — aggregating several Drupal queues so a single worker/cron run processes items across them, useful for coordinating related background-processing queues. Supports Drupal 9, 10, and 11.

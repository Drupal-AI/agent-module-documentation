Provides Nginx configuration for Drupal.

---

Nginx provides an Nginx config for Drupal — shipping recommended Nginx server/location configuration (and Let's Encrypt integration) so a site deployed behind Nginx has correct, secure defaults for serving Drupal. It's an ops/deployment helper. Depends on `letsencrypt`; supports Drupal 8 through 11.

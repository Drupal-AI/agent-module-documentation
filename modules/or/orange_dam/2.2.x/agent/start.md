# Orange DAM — agent index

**API integration between Drupal and Orange Logic's Orange DAM**. Depends on core `node`, `migrate`,
`migrate_plus`, `pathauto`. Version **2.2.0**. Core `^9.4||^10||^11`.

Media/DAM integration — calls the **Orange DAM API** (egress) with **credentials/API key** (secrets — env/Key,
HTTPS); import audience-appropriate assets. No access role.

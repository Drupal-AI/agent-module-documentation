Orchestra provides a plugin-based workflow-engine kernel with tenants, instances and incidents.

---

Orchestra is a lightweight, plugin-based workflow engine kernel — a foundation for building workflow/automation systems with tenants, workflow instances, and incident resolution. It's aimed at developers who need a structured, extensible workflow runtime inside Drupal.

Permissions cover administration (`administer orchestra`, `administer orchestra tenants`), instance access (`access orchestra instances`), and incident resolution (`resolve orchestra incidents`) — the administer/tenant permissions are powerful, so restrict them. Requires Drupal 11.3+.

A text field storing both a human label and a machine-readable key.

---

Safeword provides a text field with both human- and machine-readable versions of a string — so a single field holds a display label plus its normalized machine key (like core's machine-name widget), useful when content needs a stable identifier alongside a friendly name. Depends on core `field` and `text`; supports Drupal 11.

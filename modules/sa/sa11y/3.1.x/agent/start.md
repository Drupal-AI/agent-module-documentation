# Sa11y — agent index

Applies the **Sa11y in-page accessibility checker** (editor-facing overlay flagging alt text/heading order/
contrast issues on the rendered page). Provides permissions. Version **3.1.0**. Core `^10||^11`.

Accessibility/editorial — shows an a11y-issues overlay (typically to editors); no access role beyond
permission (gates who sees the checker).

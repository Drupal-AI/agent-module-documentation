JS Cloudimage 360 view provides the Cloudimage 360 view image formatter for interactive 360-degree product spins.

---

JS Cloudimage 360 view provides a "Cloudimage 360 view" image formatter — rendering a set of images as an
interactive 360° spin (drag to rotate), using the js-cloudimage-360-view library, for product spins/360°
views. It ships a `lozad_lazyload` submodule (lazy loading), in the Fields package.

Use it to show 360° spin views of a multi-image field. It is a content-display/formatter feature; the images
are rendered (as a spin) respecting normal file access, and it has no access-control role. Select the 360
formatter on the image field.

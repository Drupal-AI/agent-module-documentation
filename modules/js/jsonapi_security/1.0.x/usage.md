JSON:API Security enhances JSON:API with defense-in-depth controls.

---

JSON:API Security **enhances JSON:API security with defense-in-depth controls** — adding privacy
enforcement, extra access controls and **security logging** of JSON:API activity on top of core JSON:API, with a
`jsonapi_security_tfa` (two-factor) submodule. It depends on core JSON:API, provides its own permissions, in the
Web services package.

Use it to harden a JSON:API-exposed site. This is a **security-positive** module: it layers additional
controls and audit logging over JSON:API (which already enforces entity/field access) — useful for decoupled
sites that expose data over the API. Configure its controls to match your exposure, keep the logging where you
can monitor it, and remember it complements (not replaces) proper JSON:API resource/field access configuration.
It has no negative access impact. Configure the security controls.

# JSON:API Security — agent index

**Enhances JSON:API security with defense-in-depth controls** — privacy enforcement, access controls, security
logging (`jsonapi_security_tfa` two-factor submodule). Depends on core `jsonapi`. Provides permissions. Version
**1.0.0-alpha2**. Core `^10.6||^11.2`.

**Security-positive** — layers controls + audit logging over JSON:API's own entity/field access (complements,
not replaces, proper resource/field config). No negative access impact.

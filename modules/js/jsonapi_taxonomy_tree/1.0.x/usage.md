Expose a taxonomy vocabulary as a nested tree via JSON:API.

---

JSON:API Taxonomy Tree exposes a taxonomy vocabulary as a nested tree over JSON:API — so a decoupled frontend can fetch a whole vocabulary's hierarchy (parent/child terms) in one structured response, instead of flat term lists it has to reassemble. Depends on core `jsonapi`; supports Drupal 10 and 11.

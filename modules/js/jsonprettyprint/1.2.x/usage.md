JSON Pretty Print provides a formatter that pretty-prints JSON text fields.

---

JSON Pretty Print **pretty-prints JSON field values** — a field formatter that renders text fields containing
JSON in a readable, indented format on display. It works across core 10–12.

Use it to display JSON nicely. It is a content-display/field-formatter feature; it formats the stored JSON for
display (output should be escaped) and it has no access-control role. Configure the JSON formatter.

JSON:API Query Builder provides a modern, interactive interface for building JSON:API queries, for developers exploring the API.

---

Constructing JSON:API query URLs (filters, includes, sparse fieldsets) by hand is fiddly. JSON:API Query Builder provides an interactive UI to build them, for developers exploring or debugging the API. It is a developer tool. It builds queries against the site's JSON:API, which enforces its own access — the builder does not bypass access, it just constructs URLs. Keep the builder admin/developer-gated (it is a developer aid, and exposing an API query builder to untrusted users offers no benefit), and remember JSON:API's own access controls govern what any built query can actually return.

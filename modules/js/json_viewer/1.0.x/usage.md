JSON Viewer renders JSON stored in a text field as a structured, collapsible tree.

---

JSON Viewer provides a field formatter that displays JSON data stored in a text field as a structured, collapsible tree view — so editors/viewers can read and explore JSON content (config dumps, API payloads) without it being one long string.

It's a display formatter with no content or access role of its own. Supports Drupal 10 and 11.

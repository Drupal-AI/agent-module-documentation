Expose a normalized Layout Builder tree via JSON:API for headless rendering.

---

JSON:API Frontend Layout Builder is an optional Layout Builder integration for jsonapi_frontend — it exposes a normalized layout tree so a decoupled frontend can render Layout Builder layouts true-headlessly (sections, regions, blocks as structured JSON). Depends on `jsonapi_frontend`, core `layout_builder`, and `block_content`; supports Drupal 10, 11, and 12.

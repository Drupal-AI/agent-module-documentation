JSLD provides tools to implement JSON-LD markup on your site.

---

JSLD provides **tools for implementing JSON-LD structured-data markup** — adding schema.org JSON-LD to
pages for search-engine rich results, configured through the module rather than hand-written. It works on core
10.2+.

Use it to add JSON-LD structured data. It is an SEO feature adding structured-data markup that reflects on-page
content; it has no content or access role. Configure the JSON-LD mappings.

Log client-side JavaScript errors from real users into the database.

---

JSerror logs client-side JavaScript errors from real users into the Drupal database — with sampling and flood control for production use — so developers get real-user-monitoring visibility into front-end JS errors (message, stack, URL, browser) without an external service.

It collects errors from browsers via a public endpoint (with sampling + flood control to limit abuse/volume). Supports Drupal 11.

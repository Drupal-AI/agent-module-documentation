jsTree menu allows rendering menus with the jsTree library via custom blocks.

---

jsTree menu renders Drupal menus as interactive, collapsible trees using the jsTree JavaScript library —
provided as custom blocks, so a menu can be displayed as an expandable tree (useful for large hierarchical
menus/navigation). It is configured at `jstree_menu.config`.

Use it to display menus as interactive trees. It is a site-structure/navigation feature affecting menu
presentation; the menu items reflect the menu (and menu-item access), and it has no access-control role.
Place the jsTree menu block and configure the menu/options.

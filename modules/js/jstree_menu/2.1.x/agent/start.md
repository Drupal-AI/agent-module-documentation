# jsTree menu — agent index

Renders Drupal **menus as interactive collapsible trees (jsTree)** via custom blocks (large hierarchical
navigation). Config at `jstree_menu.config`. Version **2.1.1**. Core `^8.7.7||^9||^10||^11`.

Site-structure/navigation — affects menu presentation; menu items reflect menu-item access; no access
role.

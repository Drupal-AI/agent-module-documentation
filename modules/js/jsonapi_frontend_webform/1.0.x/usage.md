Resolve Webform routes as non-headless for frontend proxy/redirect.

---

JSON:API Frontend Webform is an optional integration for jsonapi_frontend that resolves Webform routes as non-headless — so a decoupled frontend knows to proxy/redirect to Drupal for Webform pages (which need server-side handling) rather than trying to render them client-side. Depends on `jsonapi_frontend` and `webform`; supports Drupal 10, 11, and 12.

Resolve JSON templates with dynamic token replacement.

---

JSON Resolver provides a service to resolve JSON templates with dynamic token replacement — useful for building API payloads from form submissions or entity data, where a template JSON with tokens is filled in at runtime to produce the outgoing payload. It's a developer utility. Supports Drupal 9, 10, and 11.

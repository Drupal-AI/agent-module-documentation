Automatic JSON-LD structured-data generation and injection.

---

JSON-LD Generator provides automatic JSON-LD structured data generation and injection — building Schema.org JSON-LD from node/field data and injecting it into the page `<head>`, so search engines get rich structured data (Article, Product, etc.) without manual markup. Depends on core `node` and `field`; supports Drupal 10.3+ and 11.

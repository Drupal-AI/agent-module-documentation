Create content types and fields from a JSON structure.

---

JSON to content type builder creates content types and fields from a JSON structure — so a site builder can define a content model as JSON and have the module generate the corresponding node type(s) and fields, speeding up scaffolding. Depends on core `field` and `node`; supports Drupal 10 and 11.

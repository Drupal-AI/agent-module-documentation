# JSON:API Pathauto Breadcrumbs — agent index

Adds a **breadcrumb to JSON:API responses based on the URL alias** (Pathauto) — breadcrumb data for
decoupled/headless front ends. Depends on core `jsonapi`, `jsonapi_extras`. Version **1.1.0**. Core
`^10||^11`.

Web-services — adds derived data (reflects public routing); JSON:API's own access still applies. No access
role.

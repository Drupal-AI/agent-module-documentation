# JSON-LD Simple - agent index

SEO helper that outputs admin-configured **JSON-LD structured data** into the HTML head. Version **1.0.0**, core `^8.8 || ^9 || ^10`.

- Config route `jsonld_simple.settings` at `/admin/config/search/jsonld-simple/settings`, permission `administer JSON-LD` (trusted admins only).
- No entities, no external HTTP, no anonymous routes. Output is trusted-admin controlled.
- Category: SEO / Structured data (Schema.org).

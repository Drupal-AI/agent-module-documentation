Validate JSON against a developer-provided JSON Schema.

---

JSON Schema Validator validates JSON against a developer-provided JSON schema — so code/integrations can check that incoming or outgoing JSON conforms to a defined schema (types, required fields, formats), catching malformed data early. It's a developer utility. Supports Drupal 10 and 11.

# Test Helpers — agent index

An **API to simplify writing Drupal unit tests** (stubs/mocks for core services; fast unit tests without a full
kernel bootstrap). Version **1.7.0**. Core `^11.3||^12`.

Developer/testing — a dev/test dependency, not for production. No content/access role.

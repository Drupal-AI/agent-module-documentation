Test Helpers provides an API to simplify writing Drupal unit tests.

---

Test Helpers provides an **API to simplify writing Drupal unit tests** — stubs, mocks and helpers for core
services (entity storage, config, language, etc.) so developers can write fast unit tests without a full kernel
bootstrap. It is in the Development package.

Use it as a developer testing dependency. It is a developer/testing tool — a `require-dev`-style dependency used
in tests, not something to enable on production. It has no content or access role. Use its helpers in your test
suite.

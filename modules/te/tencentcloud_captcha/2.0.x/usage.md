TencentCloud Captcha adds TencentCloud's CAPTCHA as a CAPTCHA-module challenge.

---

TencentCloud Captcha integrates TencentCloud Captcha — Tencent's cloud bot-protection challenge — with the Drupal CAPTCHA module, so forms can use TencentCloud's CAPTCHA to block bots/spam, popular for sites serving Chinese audiences where reCAPTCHA may be unavailable.

TencentCloud API credentials should be stored securely (env-backed); the CAPTCHA verification is performed server-side against Tencent's API. Depends on `captcha`; supports Drupal 9.3+, 10, and 11.

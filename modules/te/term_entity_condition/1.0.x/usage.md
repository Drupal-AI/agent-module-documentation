Term Entity Condition provides a Condition plugin for blocks based on taxonomy terms.

---

Term Entity Condition provides a **condition plugin that gates block visibility by the current entity's
taxonomy terms** — so a block can be shown/hidden depending on which terms the current node references (e.g.
show a block only on content tagged "News"). It depends on core Taxonomy.

Use it to scope blocks by taxonomy term. It is a site-building/conditions feature. Note it controls **block
visibility** (presentation), not access — it does not restrict access to the block's content, and it has no
access-control role. Configure the term condition on a block.

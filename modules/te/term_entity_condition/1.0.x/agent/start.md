# Term Entity Condition — agent index

A **condition plugin that shows/hides blocks based on the current entity's taxonomy terms** (e.g. block only on
"News"-tagged content). Depends on core `taxonomy`. Version **1.0.1**. Core `^10||^11`.

Site-building/conditions — **visibility, not access** (doesn't restrict the block's content); no access role.

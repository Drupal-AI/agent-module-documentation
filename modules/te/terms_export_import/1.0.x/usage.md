Taxonomy Export / Import exports and imports taxonomy terms.

---

Taxonomy Export / Import (terms_export_import) **exports and imports taxonomy terms** — moving taxonomy terms
between sites (or backing them up) via export/import files. It depends on core Taxonomy.

Use it to transfer taxonomy terms. It is a taxonomy/import-export tool; it moves term content (admin-facing) and has
no access-control role. Note: imported terms are content — validate/sanitize on import, and gate the tool to
trusted admins. Configure and run the export/import.

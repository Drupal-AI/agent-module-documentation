Text Clarity Checker checks the clarity/readability of node content.

---

Text Clarity Checker **checks content clarity** — analyzing a node's text for clarity/readability and surfacing
suggestions to improve it, for editorial quality. It works on core 11–12.

Use it to improve content readability. It is a content-authoring feature; it analyzes text (editor-facing) and has
no content or access role. Note: if analysis uses an external service, that's egress — confirm. Configure the
clarity checker.

Telegram Media Type provides Telegram support for the Media system.

---

Telegram Media Type adds Telegram support to Drupal's Media system — a media type/source for embedding Telegram content (posts/channels/media) as managed media entities, so editors can add Telegram items through the Media library. Depends on core `media`; supports Drupal 9.3+, 10, and 11.

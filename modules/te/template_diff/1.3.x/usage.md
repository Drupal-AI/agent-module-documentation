Show the difference between two Twig templates.

---

Template Diff displays the difference between two templates — comparing two Twig template files (e.g. a base template and an override, or two theme versions) and showing a diff, so theme developers can see exactly what an override changed. It's a developer/theming tool. Supports Drupal 8.8 through 11.

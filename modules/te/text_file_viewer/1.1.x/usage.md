A file-field formatter that renders text file contents inline.

---

Text File Viewer is a file-field formatter for various files — rendering the contents of an uploaded text file (e.g. .txt, .md, source/log files) inline on the page instead of just showing a download link, so readers can view the file content directly. It operates on the managed File entity's URI (access-controlled by the field). Supports Drupal 10 and 11.

Terminal UI renders pages in a cURL-friendly plaintext layout for terminal access.

---

Terminal UI adds a cURL-compatible layout for a Drupal site — rendering pages in a plaintext/terminal-friendly format so they can be consumed nicely from the command line (e.g. `curl`), a novelty/utility for developer- or hacker-oriented sites that want a terminal-style interface.

Administration is gated by `administer terminal_ui`. It's a theming/presentation utility with no content role of its own. Depends on core `token`; supports Drupal 10 and 11.

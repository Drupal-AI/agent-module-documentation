Template breadcrumb enables the injection of breadcrumbs into the view mode, so breadcrumbs can be rendered within content templates.

---

Template breadcrumb enables injecting breadcrumbs into an entity's view mode — so the breadcrumb trail
can be rendered within the content's template/view mode (rather than only in the page-level breadcrumb
region), giving themers control over where breadcrumbs appear in the content structure.

Use it where breadcrumbs should be rendered inside the content template. It is a site-structure/theming
feature affecting breadcrumb placement; the breadcrumb reflects the current path/context and it has no
content or access role. Configure the view mode to include the breadcrumb.

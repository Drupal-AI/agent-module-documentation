Textimate provides text animation with various effects, built on the Splitting library.

---

Textimate provides animated text effects — applying eye-catching animations (per-word/character
reveals, transitions) to text, built on the Splitting library (which splits text into words/characters for
granular animation). It is configured at `textimate.admin`, depends on Splitting, and provides its own
permissions.

Use it to add animated text effects to headings/content for visual impact. It is a theming/presentation
feature affecting how text animates; it does not change content or access. Configure the effects and apply
them to the target text.

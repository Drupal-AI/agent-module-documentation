# Configuration

Textimate needs a little configuration before it does anything: you create the
animation effects and then apply them to your text. Everything is managed from one
screen.

## Open the management screen

1. Log in as a user with permission to administer the module (an administrator by
   default — Textimate provides its own permissions, so you can also grant the
   right to manage effects to a specific role).
2. Go to **Structure → Textimate**, or navigate directly to
   `/admin/structure/textimate`.

## What you can configure

The management screen is designed to be approachable for beginners and flexible
for advanced users. From it you add effects and set the options that control how
each one runs:

- **Choose and combine animations.** Pick from a range of animation effects, and
  combine them to build a unique result rather than being limited to a single
  preset.
- **Letter or word splitting.** Decide whether the animation runs on each
  individual character or on each word — the granularity is up to you.
- **JavaScript event trigger.** Select which JavaScript event starts the
  animation, so you control precisely when it fires.
- **Timing and delay.** Fine-tune when the animation begins and how it is staggered,
  so the effect feels deliberate and paced rather than abrupt.

Once an effect is defined, apply it to the text you want to animate — headings,
node titles, block or Views content, slideshow captions, and other output.

## Save

Save your effect from the management screen. Remember the module's own advice:
animations can lift the experience of a page, but too many can get in the way, so
apply them where they genuinely help.

# Template Generator — agent index

**Automatically generates (Twig) templates** (scaffold template files with the right suggestions/structure —
themer productivity). Config at `template_generator.settings`. Version **2.0.3**. Core `^9.3||^10||^11`.

Developer/theming — writes template files to the theme (use in development, review output); no content/access
role.

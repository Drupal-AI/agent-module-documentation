Template Generator provides automatic template generation.

---

Template Generator automatically generates templates — scaffolding Twig template files (for entities,
fields, views, etc.) so themers get a starting-point template with the right suggestions/structure rather than
writing them from scratch. It is configured at `template_generator.settings`, in the Template Generator
package.

Use it as a developer/theming productivity tool. It generates template files; because it writes files to the
theme, use it in development (it's a scaffolding aid) and review the generated templates. It has no content or
access role. Configure the generation and run it.

Auto-convert bare Telegram post URLs into widget embeds.

---

Telegram Embed auto-converts bare Telegram post URLs in filtered text to Telegram widget embeds — so when an editor pastes a `t.me/...` post link into content, it renders as the embedded Telegram post widget instead of a plain link. It's a text-format filter. Depends on core `filter`; supports Drupal 10.3+, 11, and 12.

# Textimage settings & image-style options

## Settings form

Route `textimage.settings` → `/admin/config/media/textimage` (permission:
`administer site configuration`). Config object: **`textimage.settings`**. Defaults
(`config/install/textimage.settings.yml`):

```yaml
debug: false
default_extension: 'png'          # default output format: png | gif | jpg | jpeg
url_generation:
  enabled: false                  # direct URL-based image generation
  text_separator: '---'           # splits URL text into separate "Text overlay" effects
default_font:
  name: ~                         # a default font made available to text effects
  uri: ~
```

Read/write with drush:

```bash
drush cget textimage.settings
drush cset textimage.settings default_extension jpg -y
drush cset textimage.settings url_generation.enabled true -y
```

- **default_extension** — file format Textimage derivatives are written as, unless an effect
  (e.g. "Convert") overrides it. Does not affect core Image module derivatives.
- **url_generation.enabled / text_separator** — when on, images can be generated straight from
  a URL path (see below). The separator string delimits the text pushed to each overlay effect.
- **default_font** — a font file registered so "Text overlay" effects always have a font.
- **debug** — log Textimage operations to the `textimage` logger channel.

## Cleanup

Route `textimage.flush_all` → `/admin/config/media/textimage/cleanup` runs
`TextimageFactoryInterface::flushAll()`: deletes every Textimage-generated file, flushes the
image styles, and clears all cache/store DB entries. NOTE: this also flushes core Image module
derivatives.

## Per-image-style "Textimage options"

Textimage extends each image style's edit form with a **Textimage options** section, stored as a
third-party setting on the style:

```yaml
# image.style.<style>.third_party.textimage
uri_scheme: 'public'   # or 'private', etc. — where Textimage derivatives are stored
```

This affects only derivatives generated by Textimage, not those of core Image. Only image styles
that contain at least one "Text overlay" effect are treated as Textimage-relevant
(`TextimageFactoryInterface::isTextimage()`).

## Direct URL generation

With `url_generation.enabled: true`, a request to
`/{public-files-path}/textimage/{style_name}/{Text_0}---{Text_1}….{ext}` builds the image if it
does not yet exist. The style must have a "Text overlay" effect and its Textimage "Image
destination" set to public. This route requires the `generate textimage url derivatives`
permission (see `permissions/permissions.md`).

Text Overlay Image a custom block to display text overlaid on an image.

---

Text Overlay Image **overlays text on an image in a block** — a block that displays configurable text on top of
a background image, for hero/banner content. It depends on core Block.

Use it for text-over-image banners. It is a content-display/block feature; the text is admin/editor-configured and
rendered over the image, and it has no access-control role. Note: rendered text should be output safely. Configure
the text-overlay block.

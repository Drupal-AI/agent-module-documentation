Fast server-side code syntax highlighting for CKEditor 5.

---

Tempest Highlight provides fast, extensible, server-side code highlighting — integrating the Tempest Highlight library so code blocks (e.g. from CKEditor 5) are syntax-highlighted on the server (no client-side JS highlighter needed), for fast, consistent code rendering. Depends on core `ckeditor5`; supports Drupal 10.2+ and 11.

Integrate Drupal with the Temporal.io durable-execution/workflow engine.

---

Temporal IO integrates Drupal with Temporal.io — the durable-execution/workflow-orchestration engine — so Drupal can start and participate in Temporal workflows/activities, letting long-running, reliable, retryable business processes be orchestrated by Temporal instead of ad-hoc cron/queue code.

The Temporal server connection details are admin-configured; store them securely (env-backed). Depends on core `options`; supports Drupal 11.

Customize text styles per site section (header, footer, body).

---

Text Style Manager lets you customize text style for different sections of the website like header, footer, and main body — configuring fonts, sizes, colours and weights per region through the admin and injecting the resulting CSS, so site builders can adjust typography without editing theme files. Depends on core `block`; supports Drupal 10 and 11.

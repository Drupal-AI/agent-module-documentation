Template Suggester extends core entity template suggestions with custom ones, selectable via a template_suggester field type.

---

Template Suggester extends Drupal's entity template suggestions with custom ones — providing a
`template_suggester` field type where an editor selects a customized template suggestion, so the **same
content structure can be displayed in multiple ways** (different templates) chosen per entity. It depends on
core Field.

Use it to let content choose an alternate template/display. It is a content-display/theming feature adding a
template suggestion based on a field value; the suggestion points to a theme template (themer-provided) and
it has no access-control role. Configure the field and the custom suggestions.

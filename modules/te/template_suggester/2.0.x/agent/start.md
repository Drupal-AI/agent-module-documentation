# Template Suggester — agent index

Extends core entity **template suggestions with custom ones**, selectable via a `template_suggester` field
(display the **same structure in multiple ways** — a template chosen per entity). Depends on core `field`.
Version **2.0.1**. Core `^8||^9||^10||^11`.

Content-display/theming — adds a template suggestion from a field value (points to themer-provided templates);
no access role.

Testimonials Block provides a testimonials block.

---

Testimonials Block provides a **configurable block that displays testimonials** — showing customer/user
quotes (name, quote, optional image) in a block, for marketing/social-proof sections. It depends on core Block,
in the Testimonials Block package.

Use it to show testimonials on a page. It is a content-display feature; testimonial content is admin/editor
configured and it has no access-control role. Place and configure the testimonials block.

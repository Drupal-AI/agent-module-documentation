Layout Builder Section Variations helps use layout section variations.

---

Layout Builder Section Variations **helps define and use variations of Layout Builder sections** — so a
section layout can offer preset style/config variations editors pick from, for consistent section design. It
depends on core Layout Builder, provides its own permissions, in the Utilities package.

Use it to offer section-style variations in Layout Builder. It is a site-building/theming feature affecting
layout config; it has no content or access role beyond its permission. Configure the section variations.

Layout Block ties a block_content type to a layout configuration.

---

Layout Block **ties a block content type to a layout** — letting a custom block (block_content) bundle use a
configured layout, so structured multi-region blocks can be built and reused. It depends on core Block, Block
Content, Layout Discovery and the Inline Entity Form module.

Use it to build layout-based reusable blocks. It is a site-building/layout feature; block content follows normal
block access and it has no access-control role. Configure the layout on a block type.

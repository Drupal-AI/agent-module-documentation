Language Switcher Menu adds the language-switch links generated by Drupal core's `language` module into a menu of your choice as regular (derivative) menu link items, so visitors switch language from an ordinary menu/menu block instead of the core Language switcher block.

---

The module reads a small config object (`language_switcher_menu.settings`: `type`, `parent`, `weight`) set on a settings form at *Configuration → Regional and language → Language Switcher Menu* (`configure` route `language_switcher_menu.configure`, gated by the `configure language_switcher_menu` permission). A menu-link deriver (`Plugin/Derivative/LanguageSwitcherLink`) then creates one `MenuLinkDefault`-based link per configured language under the chosen parent, using the chosen language *type* (interface, content, URL, …) and an incrementing weight; the deriver returns nothing unless the site is multilingual and both `type` and `parent` are set. Each link (`Plugin/Menu/LanguageSwitcherLink`) is dynamic: it resolves the actual switch URL for the current route at render time via `LanguageManager::getLanguageSwitchLinks()`, sets `set_active_class`, carries the `language` object in its options, and is uncacheable (`getCacheMaxAge()` returns 0). Because of Drupal core issue [#3008889](https://www.drupal.org/project/drupal/issues/3008889) these menu links would otherwise always be hidden, so the module overrides the core `menu.default_tree_manipulators` service with `LanguageLinkAccessMenuTreeManipulator`, which grants access to its own links to any user holding the `view language_switcher_menu links` permission (and whose target URL validates). Selecting the *Disabled* empty option for the parent removes the links without uninstalling. Links can be styled/targeted in a `menu.html.twig` override by testing whether the link id starts with `language_switcher_menu.language_switcher_link:`.

---

- Show language switch links inside your main navigation menu instead of a separate block.
- Place language links in the footer menu, or any custom menu.
- Add language links as children of an existing "Language" parent menu item.
- Add language links at the root level of a menu (choose the menu itself as parent).
- Switch languages based on the *Interface* language type.
- Switch languages based on the *Content* or *URL* language type where those are configurable.
- Control the ordering of language links via the starting menu weight.
- Temporarily disable the language links (choose *Disabled* as parent) without uninstalling the module.
- Theme language switch links differently from normal menu links by matching their plugin id prefix in Twig.
- Render each language link with a `lang` attribute and language-id abbreviation for accessible language menus.
- Grant only certain roles the ability to see the language menu links via the `view language_switcher_menu links` permission.
- Restrict who can configure the feature with the `configure language_switcher_menu` permission.
- Get automatically active-trail highlighting on the current language via `set_active_class`.
- Provide language switching in a mega-menu built from a single Drupal menu.
- Have language links follow the current page (they resolve the switch URL for the active route at render time).
- Fall back to the front page for language links on 404 pages or routeless contexts (e.g. big_pipe blocks).
- Alter the generated links with core's `hook_language_switch_links_alter()` from a custom module.
- Combine language switching and normal navigation in one menu block for simpler theming.
- Build a compact header language selector from menu markup rather than the core switcher block.
- Expose language links in a menu consumed by a decoupled/JSON menu endpoint.
- Rebuild the menu link tree automatically when settings change (the form calls `MenuLinkManager::rebuild()`).

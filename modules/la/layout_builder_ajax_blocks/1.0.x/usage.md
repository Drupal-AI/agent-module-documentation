Load Layout Builder blocks with Ajax.

---

Layout Builder Ajax Blocks allows Layout Builder blocks to be loaded with Ajax — so heavy or slow blocks in a Layout Builder layout render after the initial page load (lazy, via Ajax) rather than blocking the response, improving perceived performance. Depends on core `block`, `block_content`, `layout_builder`, `node`, `taxonomy`, `user`, and `views`; supports Drupal 10.2+ and 11.

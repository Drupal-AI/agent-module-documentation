# Lazy Iframe — agent index

Adds **`loading="lazy"` to all iframes** (deferred loading of embedded videos/maps/third-party iframes —
faster initial load). Version **1.2.0**. Core `^10||^11`.

Performance/display — affects iframe markup; no content/access role.

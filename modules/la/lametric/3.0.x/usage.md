Send notifications to a LaMetric Time device.

---

LaMetric Time sends notifications on the LaMetric Time device — pushing messages/metrics from Drupal to a physical LaMetric Time smart display (via its API), so site events (orders, alerts) can appear on an office device.

The LaMetric API token is admin-configured and should be stored securely (env-backed). Depends on core `system` and `service`; supports Drupal 8.8+.

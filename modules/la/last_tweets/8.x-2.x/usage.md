Last Tweets gets the last tweets.

---

Last Tweets **displays a user's latest tweets/posts from X (Twitter)** — fetching and showing recent posts
from a configured account in a block. It provides its own permissions, in the Social Media package.

Use it to show a Twitter/X feed. It is a social-media/integration feature. Security/data handling: it calls the
**X (Twitter) API** and authenticates with **API credentials/bearer token** — store them as **secrets** (env/
Key) over HTTPS; posts/assets are public content. (Note: X's API access/terms change frequently — verify the
integration still works for current API tiers.) It has no access-control role beyond its permission. Configure
the X credentials and account.

Layout Builder Shortcuts adds a quick shortcut for editing blocks inside Layout Builder.

---

The module attaches a JavaScript library that surfaces an inline edit shortcut on blocks while a user is in the Layout Builder editing UI, reducing the clicks needed to open a block's configure/edit form. It is a pure editor-UX enhancement: it ships JS/libraries only, adds no routes or entities, and operates within the existing Layout Builder editing context (so it is governed by core Layout Builder access).

---

- Add an inline edit shortcut to Layout Builder blocks.
- Reduce clicks to open a block's edit form.
- Speed up in-place block editing.
- Enhance the Layout Builder authoring UX.
- Attach behaviour via a JS library only.
- Work within the existing Layout Builder editor.
- Rely on core Layout Builder access controls.
- Improve editor efficiency on complex layouts.
- Avoid adding routes or entities.
- Support Drupal 8.8, 9, and 10.
- Complement core Layout Builder and Block modules.
- Provide a lightweight authoring convenience.
- Keep editing context inline (no page reload to find blocks).
- Help editors manage many inline blocks.
- Add no server-side attack surface of its own.
- Streamline repeated block edits.

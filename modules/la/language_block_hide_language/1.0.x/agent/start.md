# Language Block Hide Language — agent index

Lets you **hide specific languages from the core language-switcher block** (omit in-progress translations from
the switcher). Depends on core `language`. Version **1.0.1**. Core `^8.7.7||^9||^10||^11`.

Multilingual/UI — hides a language from the switcher **UI** but does NOT restrict access to that language's
content (presentation, not access control — still URL-reachable). No access role.

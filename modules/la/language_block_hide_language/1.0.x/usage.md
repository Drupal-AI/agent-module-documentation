Language Block Hide Language hides a language in the language block.

---

Language Block Hide Language lets you hide specific languages from the core language-switcher block — so
a language that exists on the site but shouldn't be offered in the switcher (e.g. an in-progress translation)
can be omitted from the block. It depends on core Language, in the Multilingual package.

Use it to curate which languages appear in the switcher. It is a multilingual/UI feature affecting the
language block; it hides a language from the switcher UI but does not restrict access to that language's
content (it is presentation, not access control — the language is still reachable by URL). It has no
access-control role. Configure which languages are hidden.

Language Fallback Fix makes the Language Fallback API extension available, improving how Drupal falls back between languages for untranslated content.

---

When content is not translated into the requested language, Drupal falls back to another language; the default fallback logic is limited. Language Fallback Fix exposes the Language Fallback API for more control over that behaviour. It is a multilingual infrastructure fix with no security surface. Confirm the fallback order matches intent, since fallback governs which language a visitor sees for untranslated content.

Layout Builder Awesome Sections adds configurable sections to Layout Builder for building page structure.

---

Layout Builder Awesome Sections **adds richer sections to Layout Builder** — providing configurable section
layouts with extra options (backgrounds, spacing, containers) to build page structure more flexibly in Layout
Builder. It depends on core Layout Builder.

Use it for richer Layout Builder sections. It is a site-building/theming feature; sections are admin/editor-configured
layout structure and it has no access-control role. Configure the sections.

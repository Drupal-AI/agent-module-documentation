Integrate Drupal Webform with Laposta mailing lists.

---

Laposta Webform integrates Drupal Webform with Laposta mailing lists — a Webform handler that subscribes form submitters to Laposta lists, supporting field mapping, multiple lists, and opt-in fields, so newsletter sign-ups flow from a webform to Laposta.

The Laposta API key is admin-configured and should be stored securely (env-backed), never committed. Depends on `webform`; supports Drupal 10.3+ and 11.

Layout Paragraphs Split adds a CKEditor 5 button to split a text layout paragraph into two.

---

Layout Paragraphs Split **splits a paragraph in CKEditor 5** — a button that splits a textual Layout
Paragraphs paragraph into two separate paragraphs at the cursor, creating a new one, for easier restructuring. It
depends on the Layout Paragraphs and core CKEditor 5 modules.

Use it to split paragraphs while editing. It is a content-editing/UX feature; it restructures paragraph content and
has no access-control role. Enable it for the split button.

# Configuration

Layout Builder Customizer provides a small settings form. Most of what the module
does — the hover **Configure / Move / Remove** links and the **Layout** operation
link on content lists — is automatic once the module is enabled and needs no
setup. The one setting you may want to change is the **Disable** option.

## The Disable option

The settings form offers a **Disable** checkbox. When it is ticked, the module
removes the **"Allow each content item to have its layout customized"** option
from the *Manage display* page of the relevant entity type. In other words, it
takes away the per‑entity layout‑override capability so that content items all
follow the default layout rather than each carrying their own customized version.

- **Leave it unchecked** if you want editors to be able to customize the layout of
  individual content items (the standard Layout Builder behaviour).
- **Tick it** if you want to keep layouts consistent by preventing per‑item
  overrides — the "Allow each content item to have its layout customized"
  checkbox will no longer appear on Manage display.

Save the form to apply your choice. Because this changes what appears on the
Manage display page, revisit that page afterwards to confirm the override option
is present or hidden as you intended.

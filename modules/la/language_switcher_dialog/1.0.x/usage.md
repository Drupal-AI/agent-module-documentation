Language Switcher Dialog provides a language switcher using a native HTML dialog and HTMX.

---

Language Switcher Dialog **provides a language switcher in a native HTML dialog** — presenting the site's
language options in an accessible `<dialog>` (loaded via HTMX) instead of a plain list, for a cleaner multilingual
switcher. It depends on core Language and provides its own permissions.

Use it for a modern language switcher UI. It is a multilingual/UI feature; switching follows core language
negotiation and it has no access-control role beyond its permission. Configure the language switcher dialog.

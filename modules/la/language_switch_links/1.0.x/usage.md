Language Switch Links translates the language switcher block links.

---

Language Switch Links **translates the language-switcher block's link labels** — so instead of showing
each language's native name (or the same label), the switcher links can be labelled per your configuration/
translation, improving how the language switcher reads. It depends on core Language, in the Multilingual
package.

Use it to customize language-switcher link text. It is a multilingual/display feature affecting the switcher
labels; it has no content or access role. Configure the switch-link labels.

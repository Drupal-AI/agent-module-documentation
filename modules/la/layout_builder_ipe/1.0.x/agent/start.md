# Layout Builder IPE — agent index

Frontend **in-place editing for Layout Builder** (Panels-IPE-like) — arrange layouts in the rendered
page context. Depends on core `layout_builder`; config at `layout_builder_ipe.config`; provides
permissions. Version **1.0.0-rc1**. Core `^9.5||^10||^11`.

Editing-experience layer — access governed by Layout Builder + this module's permissions (changes the
UI, not what a user may edit).

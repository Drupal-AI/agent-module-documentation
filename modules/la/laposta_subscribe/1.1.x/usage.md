Laposta Subscribe adds a newsletter subscribe block wired to the Laposta API.

---

Laposta Subscribe provides a block containing a subscribe form for Laposta — the Dutch email-marketing service — so visitors can sign up to a Laposta mailing list directly from the site, with submissions sent to Laposta via its API.

The Laposta API credential should be stored securely (env-backed); administration is gated by `administer laposta subscribe`. Submissions send subscriber data to Laposta (privacy/consent). Depends on core `block`; supports Drupal 10 and 11.

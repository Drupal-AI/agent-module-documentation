Layout Builder Dynamic Tabs provides a dynamic layout section allowing regions to be navigated as tabs.

---

Layout Builder Dynamic Tabs provides a dynamic layout section for Layout Builder that presents its
regions as navigable tabs — so editors can build tabbed content (a set of tabs, each a region with its own
blocks/components) directly within Layout Builder. It requires PHP 7.4 and is in the Layouts package.

Use it to build tabbed interfaces in Layout Builder without custom code. It is a content-display/site-
building layout feature; the tabbed content is authored and rendered through Layout Builder, and it has no
access-control role. Add the dynamic tabs section in Layout Builder and place components in each tab
region.

---

Layout Builder extras - live update provides UI/UX enhancements for Layout Builder — notably live-
updating the layout preview as changes are made, plus other editing-experience tweaks, making Layout Builder
feel more responsive. It depends on core Layout Builder, is configured at
`layoutbuilder_extras_live_update.settings_form`, provides its own permissions, in the Layout Builder
package.

Use it to improve the Layout Builder editing experience. It is a content-editing/layout UI feature affecting
the Layout Builder interface; it does not change content or access (Layout Builder access still applies), and
it has no access-control role beyond its permission. Configure the tweaks.

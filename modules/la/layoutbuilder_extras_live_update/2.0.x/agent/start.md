# Layout Builder extras - live update — agent index

Extra **UI/UX tweaks for Layout Builder** — notably **live-updating the preview** as changes are made.
Depends on core `layout_builder`; provides permissions. Config at
`layoutbuilder_extras_live_update.settings_form`. Version **2.0.1**. Core `^10||^11`.

Content-editing/layout UI — affects the LB interface, not content/access (LB access still applies). No
access role beyond permission.

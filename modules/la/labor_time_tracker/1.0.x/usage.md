Labor Time Tracker records user clock-in/out times for attendance tracking.

---

Labor Time Tracker tracks user enter/exit (clock-in/clock-out) times and provides a simple time-and-attendance tracking system — recording when users start and stop, and letting managers view labor times. It suits basic workforce/attendance needs inside Drupal.

Permissions cover administration (`administer labor time tracker`) and viewing times (`view labor times`); attendance data is personal, so handle per privacy policy. Depends on `admin_toolbar` and `honeypot`; requires Drupal 11.3+.

Landing Page Scheduler redirects users to a landing page for a limited time window.

---

Landing Page Scheduler **redirects to a landing page for a scheduled window** — configuring a time-limited
redirect so visitors are sent to a chosen landing page during a defined period (e.g. a campaign or maintenance
splash). It provides its own permissions.

Use it for time-boxed landing-page redirects. It is a site-building/marketing feature; the redirect target is an
**admin-configured internal page**, and it has no access-control role beyond its permission. Note: keep the redirect
scoped so it doesn't trap admins/logged-in users unintentionally; verify the target is an intended internal page.
Configure the schedule and target.

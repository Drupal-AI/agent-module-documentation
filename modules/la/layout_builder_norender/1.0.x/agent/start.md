# Layout Builder No Render — agent index

Adds a **publish/unpublish toggle to Layout Builder component blocks** (unpublished components aren't rendered
— stage/hide without deleting). Depends on core `layout_builder`. Version **1.0.1**. Core `^9||^10||^11`.

Content-editing/layout — controls **rendering** (editorial toggle, **not** access control; protect sensitive
component data with real access control). No access role.

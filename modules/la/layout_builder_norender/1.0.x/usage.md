Layout Builder No Render provides a publish/unpublish component block layout that does not render unpublished layouts.

---

Layout Builder No Render adds a **publish/unpublish toggle to Layout Builder component blocks** — so an
individual component (block) in a layout can be marked unpublished and **not rendered**, letting editors stage
or hide components without deleting them. It depends on core Layout Builder.

Use it to hide/stage Layout Builder components. It is a content-editing/layout feature. Note it controls
**rendering** (an unpublished component is not output), which is a presentation/editorial toggle — it is not a
security access control on the component's underlying content (if the component renders sensitive data, protect
that data with real access control, not just by unpublishing the component). It has no access-control role.
Toggle components published/unpublished.

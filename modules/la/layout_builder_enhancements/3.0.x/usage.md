Layout Builder Enhancements adds some functionality for Layout Builder.

---

Layout Builder Enhancements adds **extra functionality to Layout Builder** — with submodules for block,
views and visual enhancements (`layout_builder_enhancements_blocks`, `_views`, `_visual`), improving the
layout-building experience. It depends on core Layout Builder and Block Content.

Use it to enhance Layout Builder. It is a site-building/layout feature; layout content follows normal block/
entity access and it has no access-control role. Enable the enhancement submodules you need.

# Language Country Negotiation — agent index

Adds a **country-dependent language negotiation method** (select language based on the visitor's country).
Depends on core `locale`, `path_alias`. Version **1.0.0-alpha5**. Core `^10.3||^11`.

Multilingual — affects which language is served; no content/access role.

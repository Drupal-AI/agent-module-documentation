Language Country Negotiation provides an additional country-dependent language negotiation plugin.

---

Language Country Negotiation adds a **country-dependent language negotiation method** — selecting the
interface/content language based on the visitor's country (e.g. via a country segment or detection), extending
Drupal's language negotiation for country-specific language routing. It depends on core Locale and Path Alias,
in the Multilingual package.

Use it for country-based language selection. It is a multilingual feature affecting which language is served;
it has no content or access role. Configure the country→language negotiation.

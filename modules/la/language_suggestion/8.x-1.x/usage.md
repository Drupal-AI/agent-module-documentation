Language Suggestion detects the browser language, checks enabled translations, and suggests switching to the matching language.

---

Language Suggestion detects the visitor's browser language, checks which translations the site has
enabled, and — if the browser language differs from the current one and a translation exists — suggests
switching to that language (a non-intrusive prompt rather than a forced redirect). It is configured at
`language_suggestion.settings`. This helps visitors find content in their language without automatically
overriding their choice.

Use it on multilingual sites to gently prompt language switching. It is a multilingual/UX feature; it
suggests (doesn't force) a language and has no content or access role. It respects the browser's
Accept-Language and the site's enabled languages. Configure the suggestion behaviour.

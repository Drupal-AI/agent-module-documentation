# Language Suggestion — agent index

Detects the **browser language** and **suggests switching** to a matching enabled translation (non-intrusive
prompt, not a forced redirect). Config at `language_suggestion.settings`. Version **8.x-1.1**. Core
`^10.2||^11`.

Multilingual/UX — suggests (doesn't force) a language; respects Accept-Language + enabled languages; no
content/access role.

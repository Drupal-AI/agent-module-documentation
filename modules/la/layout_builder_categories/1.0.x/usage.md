Layout Builder Categories collapses the block category groups in the Layout Builder add-block UI.

---

Layout Builder Categories **collapses the block category groups in Layout Builder** — making the "add block"
off-canvas list show collapsible category groups so the long block list is easier to navigate. It depends on core
Layout Builder.

Use it to tidy the Layout Builder block picker. It is a content-editing/UX feature; it affects the Layout Builder
UI and has no content or access role. Enable it for collapsed categories.

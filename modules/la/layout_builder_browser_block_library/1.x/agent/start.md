# Layout Builder Browser Block Library (layout_builder_browser_block_library) — agent index

Adds the **global block library** to the Layout Builder browser alongside inline blocks. Version **dev**.

**Note:** it broadens what blocks are *offered* to editors (a UI/availability change, not an access
grant). Confirm all now-offered reusable blocks are appropriate for editorial placement; protect
sensitive blocks at the **block-access** level, not by not-listing them.

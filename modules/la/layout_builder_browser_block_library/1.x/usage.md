Layout Builder Browser Block Library adds access to the global block library on all inline blocks in the Layout Builder browser.

---

Layout Builder Browser categorises blocks for editors; this module adds access to the global (reusable) block library alongside inline blocks in that browser, so editors can place library blocks more readily. The consideration is exactly that it broadens what blocks are offered in the browser: making the global block library available means editors can place any reusable block, including ones not previously surfaced. That is a UI/availability change, not an access grant — but it can expose blocks to placement that were not intended for editorial use, so confirm that the reusable blocks now offered are all appropriate for editors to place, and that any block with sensitive content or its own access is protected at the block level rather than by not being listed.

Layout Builder Block Copy copies blocks within Layout Builder.

---

Layout Builder Block Copy lets editors **copy (deep-clone) blocks within Layout Builder** — duplicating a
placed block, including its inline block content, so a configured block can be reused elsewhere in a layout. It
depends on core Layout Builder and Block Content.

Use it to duplicate Layout Builder blocks. It is a site-building/editing feature; copying happens within the
Layout Builder edit flow, which is already gated by layout/edit access, and it has no access-control role of its
own. Use the copy control in Layout Builder.

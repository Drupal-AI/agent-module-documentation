# Layout Builder Block Copy — agent index

Lets editors **copy/deep-clone blocks (incl. inline content) within Layout Builder**. Depends on core
`layout_builder`, `block_content`. Version **1.0.8**. Core `^10.3||^11`.

Site-building/editing — happens within the layout-edit flow (gated by layout/edit access); no access role of its
own.

Use Laravel's HTTP client (Guzzle wrapper) in Drupal.

---

Laravel Http Client adds Laravel's HTTP Client to Drupal — a fluent wrapper around Guzzle (Laravel's `Http::get()/post()` style API) so developers who prefer that ergonomics can make outbound HTTP requests with less boilerplate. It's a developer library integration; it uses standard TLS verification. Supports Drupal 10 and 11.

Layout Builder Title Link adds a new URL field to the block's title to make it linkable in Layout Builder.

---

Layout Builder Title Link adds a URL field to a block's title in Layout Builder — so the block title can
be turned into a link (e.g. a section heading that links to a landing page), without custom templating. It is
in the Custom package.

Use it to make Layout Builder block titles linkable. It is a content-display/layout feature affecting block
title presentation; the link is admin-configured and it has no access-control role. Configure the title link
on the block.

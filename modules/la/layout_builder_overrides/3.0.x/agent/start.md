# Layout Builder View Modes Overrides — agent index

Lets **Layout Builder override any view mode** (per-entity layout overrides for teaser/card/custom, not just
the default). Depends on core `layout_builder`. Version **3.0.2**. Core `^10||^11`.

Content-display/layout — affects how view modes are laid out; blocks/fields respect their access; no access
role.

Layout Builder View Modes Overrides allows overriding any view mode with Layout Builder.

---

Layout Builder View Modes Overrides lets Layout Builder override any view mode — so per-entity layout
overrides can apply to any configured view mode (teaser, card, custom), not only the default full view,
giving finer control over layouts per display. It depends on core Layout Builder, in the Layout Builder
package.

Use it where different view modes need their own Layout Builder overrides. It is a content-display/layout
feature affecting how view modes are laid out; the content and its access are unchanged (blocks/fields
respect their access), and it has no access-control role. Enable Layout Builder overrides on the desired
view modes.

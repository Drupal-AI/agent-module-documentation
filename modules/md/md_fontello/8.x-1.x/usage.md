Fontello Icon integrates the Fontello icon service into Drupal, providing icon fonts and an icon-link submodule.

---

Fontello Icon (md_fontello) integrates the Fontello icon service — letting you use Fontello-generated
icon fonts in Drupal, with an `md_icon_link` submodule for icon-enhanced links. Fontello lets you build a
custom icon-font set from various icon libraries; this module makes those icons available in the site. It
is in the MegaDrupal package.

Use it to add Fontello icon fonts to a theme/content. It is a theming/media feature providing icon
assets; icon usage is presentational and it has no access-control role. Configure the Fontello icon set and
use the icons (and the icon-link submodule where links need icons).

Material Design Bootstrap (MDBootstrap) integrates the MDBootstrap Material Design UI kit for Bootstrap.

---

Material Design Bootstrap **integrates the MDBootstrap UI kit** — adding MDBootstrap's Material Design
components/styling for Bootstrap 4/5 to the site, via the Bootstrap UI module. It depends on Bootstrap UI and
provides its own permissions.

Use it to add Material Design Bootstrap styling. It is a theming feature; it provides front-end assets/components
and has no content or access role beyond its permission. Note: ensure your MDBootstrap license/usage terms are
respected. Configure the MDBootstrap integration.

Browse and read Markdown files from the Drupal admin.

---

MD Navigator lets you browse and read Markdown (.md) files in a directory tree from the Drupal admin — so project documentation stored as Markdown (READMEs, docs) can be navigated and read within the admin UI, useful for keeping docs handy. Depends on core `system`; supports Drupal 11.

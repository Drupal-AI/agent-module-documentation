A pseudo (computed/display-only) link field for entities.

---

Pseudo Link provides a pseudo link field for entities — a display-only/computed link field (not stored as real input) that renders a link based on entity data or configuration, useful for adding contextual links to an entity's display without a real stored field value. Supports Drupal 9.2+, 10, and 11.

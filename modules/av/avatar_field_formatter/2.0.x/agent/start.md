# avatar_field_formatter

Image field formatter that renders images as avatars.

- Plugin `src/Plugin/Field/FieldFormatter/AvatarFormatter.php`; assign on an image field's Manage Display.
- No routes/permissions/services. Works with core Image styles; usable on the user-picture field.

See [../usage.md](../usage.md).

Host and manage translations of projects (translation server).

---

Localization server (l10n_server) is a translation-management server — it parses projects' translatable strings (from packaged releases), lets a community suggest and vote on translations, and serves the resulting translation files, powering community localization portals (like localize.drupal.org). It's a large translation-workflow platform. Supports Drupal 10 and 11.

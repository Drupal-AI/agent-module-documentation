# Localization quick links - agent index

On-page **interface/config translation helper** (version **1.0.0**, core `^8.8||^9||^10`; depends on `locale`, `toolbar`).

- Routes: `l10n_quick_links.settings` (perm `administer languages`) and `l10n_quick_links.toggle` (perm `use localization quick links ui`).
- Registers a `string_translator` service to capture rendered strings and link them to translation forms.
- Category: Multilingual / Translation.

L10n Plural Config lets you configure plural formulas for site languages.

---

Localization Plural Config (l10n_pconfig) lets you **configure the plural formula for each site language** —
setting the correct plural rule (how many plural forms and which index applies for a given count) so translated
plural strings render correctly for languages with complex plural rules. It depends on core Locale and Language,
in the Multilingual package.

Use it to fix plural handling in translations. It is a multilingual/admin feature affecting translation
rendering; it has no content or access role. Configure the plural formula per language.

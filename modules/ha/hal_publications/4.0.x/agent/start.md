# HAL Publications — agent index

Displays **publications from the HAL (Hyper Articles en Ligne) open-archive API** (French research archive).
Depends on core `user`, `chosen`. Provides permissions. Version **4.0.1**. Core `^10.2||^11`.

Integration/content — calls the **HAL API** (HTTPS; any credentials as secrets); data is external. No access
role beyond permission.

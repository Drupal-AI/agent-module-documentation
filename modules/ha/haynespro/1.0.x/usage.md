Integrates the HaynesPro vehicle-data API.

---

HaynesPro implements the HaynesPro vehicle API — integrating with HaynesPro's automotive technical-data service so a site (e.g. a garage/parts site) can look up and display vehicle technical data.

The HaynesPro API credentials are stored via a Key entity (`key` dependency, env-backed), never committed. Depends on `key`; supports Drupal 10.4+ and 11.

A Key-module provider backed by HashiCorp Vault secrets.

---

Hashicorp Vault Secrets Key Integration is a plugin for the Key module to integrate with HashiCorp Vault secrets — so a Key entity can resolve its value from a Vault KV secrets engine at runtime, keeping the actual secret in Vault rather than in Drupal config/state.

The Vault address and auth token should be provided securely (env-backed) and communication should use HTTPS. Supports Drupal 10 and 11.

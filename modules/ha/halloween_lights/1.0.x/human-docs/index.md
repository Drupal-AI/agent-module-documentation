# Halloween Lights — manual setup guide

**Halloween Lights** (`halloween_lights`) adds a decorative string of
Jack-o'-lantern lights across the top of your website. The little pumpkins glow
at random, as if each were lit by a flickering candle — a bit of seasonal fun for
the Halloween period.

There's really nothing to it: enable the module and the lights appear on every
non-admin page. It's purely cosmetic front-end decoration — it adds some markup
and CSS and has no content, data, or access-control role of its own. When the
season's over, disable the module and the lights are gone.

It was inspired by the Happy New Year and Merry Christmas! decoration modules, and
is also available for Backdrop CMS. Development was supported by the Academy of
Model Aeronautics.

This guide is written for a **human** clicking through the admin UI. If you want
terse, token‑cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Contents

1. [Installation](installation/index.md) — install with Composer and enable the
   module.

There is **no configuration page** for this module. Enabling it turns the lights
on; disabling it turns them off. There are no settings to fill in.

## How to use it

Enable the module (see [Installation](installation/index.md)) and the string of
glowing Jack-o'-lantern lights appears automatically at the top of every
non-admin page. To remove it after the season, simply disable the module.

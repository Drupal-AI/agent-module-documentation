Publish Drupal content to a WordPress blog.

---

WordPress Publish publishes Drupal content to a WordPress blog — so content authored in Drupal can be pushed (cross-published) to a connected WordPress site via its API, for teams that syndicate to a WordPress-hosted blog.

The WordPress API credentials are admin-configured; store them securely (env-backed). Depends on core `node`, `taxonomy`, and `file`; supports Drupal 10.3+, 11, and 12.

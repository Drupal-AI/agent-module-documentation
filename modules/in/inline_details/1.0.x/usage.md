A (( )) text filter for inline expandable details.

---

Inline Details provides a `(( ))` text filter for inline details — so authors can wrap text in `(( ))` in a rich-text/plain field and have it rendered as an inline expandable details/disclosure element (like a `<details>` toggle), for footnotes/asides without HTML. Enable the filter on the relevant text formats. Supports Drupal 8.8 through 11.

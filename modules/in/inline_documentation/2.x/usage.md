Inline Documentation lets teams attach and view contextual documentation directly on site pages.

---

Inline Documentation lets authorized users add and view real-time documentation directly on pages — contextual notes/help attached to the site's own pages, so teams can document processes or UI in situ rather than in a separate wiki. Documentation is viewed inline where it's relevant.

Permissions cover viewing the overview (`view inline documentation overview`) and managing settings (`manage inline documentation settings`). Supports Drupal 8.8+ through 11.

Batch-translate untranslated interface strings via DeepL.

---

Interface Translation Auto translates untranslated interface strings in batch via DeepL — so a multilingual site can auto-fill missing UI string translations (from core/modules/themes) by sending them to the DeepL machine-translation API, reducing manual translation effort.

The DeepL API key is admin-configured and should be stored securely (env-backed); review machine translations for quality. Depends on core `language` and `locale`; supports Drupal 10.1+, 11, and 12.

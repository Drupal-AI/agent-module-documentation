Instagram Embed turns plain Instagram post URLs in rich text into embedded widgets.

---

Instagram Embed provides a text filter that automatically converts bare Instagram post URLs in filtered text into Instagram widget embeds — so editors can paste a plain Instagram link and have it render as the embedded post without manual embed code.

It's a text filter/display enhancement; the embed loads Instagram's third-party widget (privacy consideration). Enable it on the relevant text formats. Depends on core `filter`; supports Drupal 10.3+, 11, and 12.

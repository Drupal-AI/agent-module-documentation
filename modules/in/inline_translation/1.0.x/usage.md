Inline Translation allows users to translate entities in a single form.

---

Inline Translation lets users translate an entity into multiple languages from a **single form** —
editing all (or several) language versions together, rather than switching between separate per-language
translation forms, streamlining bulk translation. It provides its own permissions, in the Multilingual
package.

Use it to translate entities more efficiently in one form. It is a multilingual/content-editing feature;
translation capability is governed by core's content-translation permissions (this is a UI convenience, not
new access), and it has no access-control role beyond its permission. Configure the inline-translation
form.

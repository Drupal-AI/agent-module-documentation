# Inline Translation — agent index

Lets users **translate entities across languages in a single form** (edit multiple language versions together
vs separate forms). Provides permissions. Version **1.0.0**. Core `^9.4||^10||^11`.

Multilingual/content-editing — UI convenience; governed by core's content-translation permissions (not new
access). No access role beyond permission.

Manage inactive users with configurable notifications.

---

Inactive User Management provides a way to manage inactive users and uses configurable notifications — identifying accounts that haven't logged in for a configured period, notifying them (and admins), and optionally blocking/deleting them, to keep the user base clean and reduce dormant-account risk.

It runs on cron and sends email; depends on core `user`, `ultimate_cron`, and `symfony_mailer`; supports Drupal 11.

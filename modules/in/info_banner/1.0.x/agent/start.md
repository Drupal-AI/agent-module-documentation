# Info Banner — agent index

Displays a **configurable banner** (page top / a div by ID / popup) with **wildcard path targeting** and
**Varnish compatibility**. `info_banner_blocks` submodule. Config at `info_banner.settings`; provides
permissions. Version **1.0.3**. Core `^10.3||^11`.

Content/display — admin-authored banner shown to visitors; gate who configures via its permission. No access
role.

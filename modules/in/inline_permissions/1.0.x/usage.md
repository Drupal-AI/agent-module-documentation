Set user permissions directly in the user edit form.

---

Inline Permissions is a module for setting user permissions directly in the user edit form — so an admin can grant/revoke specific permissions for an individual user on their account page, rather than only through roles.

This is a powerful capability: managing permissions this way is itself gated by the core `administer permissions` permission — restrict it tightly, since per-user permission grants can escalate privileges outside the role model. Supports Drupal 10.3+ and 11.

# Instagram Posts Block — agent index

Provides an **Instagram feed in a block**. Version **2.1.0**. Core `^11`.

Social-media/integration — **fetches posts from Instagram/Meta** (egress); needs an **API access token** (store as
a secret — env/Key, HTTPS); loads third-party assets (privacy/consent). No access role.

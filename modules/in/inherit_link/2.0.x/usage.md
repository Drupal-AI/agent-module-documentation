Inherit Link allows a field to inherit a link from a related entity.

---

Inherit Link lets a field inherit its link/URL from a related entity — so an entity's link value can be
derived from (inherited from) another referenced/parent entity rather than set manually, keeping links
consistent. It ships an `inherit_link_ui` submodule.

Use it to derive link values from related entities. It is a content-editing/fields feature computing a link
value from related data; the link reflects the source entity and it has no access-control role. Configure the
inheritance source.

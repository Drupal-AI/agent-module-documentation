# Intense Images (intense) — agent index

Image **formatter** using **Intense.js** — click for a full-viewport image that pans on mouse move.
Version **3.0.1**. Core `>=9.4`.

Front-end enhancement, no security surface. Set as an image/media field formatter. Serve the library
locally if third-party origins matter; avoid conflicts with other lightbox/zoom modules.

Intense provides an image formatter using the Intense.js library, showing a full-viewport image with pan-on-mouse-move when an image is clicked.

---

Some images deserve the whole screen — a photograph, an artwork, a detailed graphic. Intense integrates the Intense.js library to give that: click an image and it expands to fill the viewport, panning as the mouse moves so a large image can be explored without controls. This module exposes it as a field formatter, so an image or media field renders with the Intense behaviour.

It is a front-end presentation enhancement with no security surface of its own. The usual JS-integration notes apply: confirm the library loads (locally if third-party origins are a concern), and that the full-viewport behaviour suits the site's UX and works with the theme.

For photography, portfolios and detail-rich images it is a distinctive full-screen viewer. Confirm it does not conflict with another lightbox or zoom module on the same images.

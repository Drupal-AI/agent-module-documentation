Inputmask Widget provides an input mask field widget with validation.

---

Inputmask Widget provides a **field widget that applies an input mask** — enforcing a format (e.g. phone,
date, currency) on a text field as the user types, using the Inputmask JS library, for cleaner, validated input.
It depends on core Text, in the Field Types package.

Use it to format/validate text input. It is a content-editing/forms feature affecting the widget; masking is a
client-side convenience (still validate server-side for anything security-relevant) and it has no content or
access role. Configure the mask on a text field.

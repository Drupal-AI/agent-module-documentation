# Inputmask Widget — agent index

A **field widget that applies an input mask (format validation)** to text inputs (phone/date/currency; Inputmask
JS). Depends on core `text`. Version **1.0.3**. Core `^8.9||^9||^10||^11`.

Content-editing/forms — masking is client-side (validate server-side for security-relevant input); no content/
access role.

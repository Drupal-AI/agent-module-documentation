# Instagram Nodes — agent index

Imports **Instagram posts into an `instagram_post` content type** (store Instagram content as Drupal nodes).
Provides permissions. Version **2.0.0**. Core `^10.2||^11`.

Integration/content — authenticates with **Instagram/Meta API tokens** (store as secrets, HTTPS); imports
**external content** as nodes (apply safe text formats). No access role beyond permission.

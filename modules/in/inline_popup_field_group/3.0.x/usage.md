Inline Popup Field Group adds a field group option "popup" which puts its children in a simple popup.

---

Inline Popup Field Group adds a new **Field Group** format — "popup" — that renders the group's child
fields inside a **simple popup** rather than inline, so grouped fields (on forms or displays) can be tucked
behind a popup trigger to declutter the layout. It depends on the Field Group module, in the Fields package.

Use it to present grouped fields in a popup. It is a content-editing/display feature (a Field Group plugin)
affecting layout only; the fields' access follows normal field access and it has no access-control role.
Choose the "popup" format on a field group.

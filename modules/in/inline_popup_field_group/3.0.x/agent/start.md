# Inline Popup Field Group — agent index

Adds a **"popup" Field Group format** that shows its child fields in a simple popup (declutter forms/displays).
Depends on `field_group`. Version **3.0.0**. Core `^8.8||^9||^10||^11`.

Content-editing/display — a Field Group plugin affecting layout only; field access follows normal field
access; no access role.

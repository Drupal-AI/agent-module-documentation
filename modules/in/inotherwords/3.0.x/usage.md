In Other Words provides field formatters that render lists in a more grammatical way (e.g. 'A, B and C') or condense long lists into shorter text.

---

In Other Words provides field formatters for multi-value fields that render lists more naturally — for
example joining values grammatically ("A, B and C" instead of "A, B, C"), or condensing a long list into
shorter text ("A, B and 3 others"). This improves how lists of items (tags, authors, references) read in
output. It is in the Fields package.

Use it wherever multi-value field output should read as natural language rather than a raw comma list. It
is a content-display/formatter feature affecting rendering; the stored values are unchanged and it has no
access-control role. Select the formatter on the field's display.

InvoiceXpress API integrates with InvoiceXpress.

---

InvoiceXpress API provides an **API integration for InvoiceXpress** — the Portuguese invoicing/billing
service — so Drupal can create/manage invoices, clients and documents in InvoiceXpress. It provides its own
permissions, in the InvoiceXpress package.

Use it to integrate billing with InvoiceXpress. It is an integration feature. Security/data handling: it calls
the **InvoiceXpress API** with an **API key** (store as a **secret** — env/Key — over HTTPS) and exchanges
**invoicing/client data (PII + financial/fiscal data)** — handle per your privacy/fiscal obligations. It has no
access-control role beyond its permission. Configure the InvoiceXpress credentials.

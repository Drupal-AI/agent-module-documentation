Set additional HTML attributes (e.g. pattern) on form inputs.

---

Input add more attributes (input_pattern) lets you set attributes for input elements — adding HTML5 attributes such as `pattern`, `minlength`, `inputmode`, etc. to form fields from configuration, so client-side validation and input hints can be tuned without custom code. Supports Drupal 10, 11, and 12.

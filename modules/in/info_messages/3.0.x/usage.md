Info Messages provides a simple way to display an informational message, such as a site-wide notice.

---

Info Messages provides a simple way to display an informational message — a lightweight site-wide
notice/banner for announcements or information. It depends on core System and is in the User interface
package.

Use it to show a simple info notice to visitors. It is a content-display/UI feature; the message is
admin-authored and rendered through Drupal's layers, and it has no access-control role. Configure the
message content and display.

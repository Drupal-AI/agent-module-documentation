Instagram Feed Block shows a feed of Instagram posts via the Instagram Graph API.

---

Instagram Feed Block displays a feed of Instagram posts in a block, fetched through the Instagram Graph API — so a site can show its latest Instagram content in a sidebar or region. It requires Instagram Graph API credentials.

The API access token is stored via the Key module (env-backed) and gated by `administer instagram feed block`. It fetches from Instagram's API (caching recommended). Depends on `key`; supports Drupal 10.1+, 11, and 12.

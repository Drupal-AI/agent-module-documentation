# IEF Table View — agent index

Lets a **View generate the table** shown by the **Inline Entity Form** widget — custom columns/
formatting for referenced entities instead of IEF's fixed table. Depends on core `views`,
`inline_entity_form`. Version **2.0.1**. Core `^8||^9||^10||^11`.

Content-editing/UI feature — the View applies entity access; adds no access of its own.

IEF Table View allows a View to generate the table for the Inline Entity Form (IEF) widget, giving control over the columns shown for referenced entities.

---

IEF Table View lets you use a View to render the table that the Inline Entity Form (IEF) widget
shows for its referenced entities — so instead of IEF's fixed columns, site builders define exactly
which fields/columns appear (and their formatting) via a View. This is useful when the default IEF
table doesn't show the columns editors need to distinguish or manage referenced items. It depends on
core Views and the Inline Entity Form module.

Use it on complex inline-entity workflows (order items, nested content) where the reference table needs
tailored columns. It is a content-editing/UI feature governing how the IEF table is displayed; it
respects the underlying entity access (the View still applies access) and adds no access of its own.

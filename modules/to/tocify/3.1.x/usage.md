Tocify generates a table of contents (tocify your content) from headings.

---

Tocify generates a table of contents from a page's content — building a navigable list from the
headings, so long content gets an automatic TOC. It provides Drush commands, in the Custom package.

Use it to add an auto-generated table of contents to content. It is a content-display/navigation feature; the
TOC reflects the page's headings (content the user can see) and it has no access-control role. Configure
where the TOC is generated.

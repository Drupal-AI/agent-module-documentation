# TOTHOM Slider — agent index

**Accessible, highly configurable sliders/carousels powered by Splide.js** (Views-driven). Depends on core
`views`. Provides permissions. Version **1.0.0-beta1**. Core `^10||^11`.

Content-display/theming — renders content in a carousel; no access role beyond permission.

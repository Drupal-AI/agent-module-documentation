# Touch icons — agent index

Adds theme settings to configure **Web Clip (touch) icons for iOS** (home-screen icons — apple-touch-icon
sizes). Version **1.0.x** (dev). Core `^8.8||^9.0||^10.0||^11`.

Theming feature — icon metadata/links; no content/access role. Configure in theme settings.

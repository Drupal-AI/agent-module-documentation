Touch icons provides additional theme settings to display special Web Clip icons on iOS devices when a page is saved to the home screen.

---

Touch icons provides additional theme settings for configuring Web Clip (touch) icons — the icons iOS
devices use when a site is saved to the home screen. It lets site builders set the various apple-touch-icon
sizes through theme settings, so the site has proper home-screen icons on Apple devices. It is in the Theme
settings package.

Use it to provide good home-screen icons for iOS. It is a theming feature adding icon metadata/links; it has
no content or access role. Configure the touch icons in theme settings.

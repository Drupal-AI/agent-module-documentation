Toolbar Link allows adding a top level single link on the toolbar.

---

Toolbar Link lets administrators add custom top-level single links to the admin Toolbar — so frequently-
used destinations (a report, an external tool, a specific admin page) can be one click away from the toolbar.
It depends on core Toolbar, is configured at the `toolbar_link_item` collection.

Use it to add quick-access links to the toolbar. It is an administration/UI feature; the links are admin-
configured and it has no access-control role (the linked destinations enforce their own access). Configure
the toolbar links.

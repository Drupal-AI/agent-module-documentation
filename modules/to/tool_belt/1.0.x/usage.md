Tool Belt provides a default collection of tools covering common Drupal core actions, built on the Tool module.

---

Tool Belt provides a default collection of "tools" — small utilities covering common Drupal core actions
across content, entities, users, system, workspaces and translation (via submodules `tool_belt_content`,
`tool_belt_entity`, `tool_belt_user`, `tool_belt_system`, `tool_belt_workspace`,
`tool_belt_content_translation`). It builds on the Tool module framework, giving admins a ready set of
common operational tools. It depends on the Tool module.

Use it to get a batch of common admin/operational tools without building them. It is an administration/tools
feature; the individual tools perform admin operations, so — as with any admin tooling — access to them is
governed by permissions and they act with the operator's privileges. Enable the submodules for the tool
categories you need and restrict access appropriately.

# Tool Belt — agent index

A default **collection of tools covering common Drupal core actions** (content/entity/user/system/
workspace/translation submodules), built on the **Tool** module. Depends on `tool`. Version
**1.0.0-alpha2**. Core `^10.3||^11||^12`.

Admin/tools feature — individual tools perform admin operations (govern by permissions; act with operator's
privileges). Enable needed submodules; restrict access.

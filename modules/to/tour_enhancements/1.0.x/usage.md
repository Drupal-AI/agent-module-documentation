Tour Enhancements provides additional routes and functionality for Tours.

---

Tour Enhancements **extends core's Tour module** — adding routes and functionality for guided tours
(onboarding walkthroughs that highlight UI elements), beyond what core Tour provides. It depends on core Tour.

Use it to build richer guided tours. It is an administration/onboarding feature; tours are admin-authored
walkthroughs and it has no content or access role. Configure the enhanced tours.

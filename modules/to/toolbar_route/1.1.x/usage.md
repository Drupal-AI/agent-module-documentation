Show the current route name in the admin toolbar.

---

Toolbar route displays the current route in the admin toolbar — showing the machine route name of the page you're on right in the toolbar, a handy developer/debugging aid for quickly identifying which route renders a given page. Depends on core `toolbar`; supports Drupal 10 and 11.

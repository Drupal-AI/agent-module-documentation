Torneo AI Language centralizes AI language policy/integration for the Torneoz platform.

---

Torneo AI Language provides a shared AI language policy and integration for Torneoz sites — centralizing how AI features handle language (which model/language settings apply) across a Torneoz multi-site setup, so AI behavior is consistent per language.

AI operations run through the configured AI provider (cost). Administration is gated by `administer torneo ai language`. Depends on core `language` and `ai`; requires Drupal 11.3+.

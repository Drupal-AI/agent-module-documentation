A Tool plugin that searches a Search API index and returns results.

---

Tool Search provides a generic tool plugin for searching any Search API index and returning markdown or rendered results — so an AI agent (or other consumer of the Tool framework) can query a site's Search API index as a callable tool and get back formatted results. Depends on `tool` and `search_api`; supports Drupal 10.3+ and 11.

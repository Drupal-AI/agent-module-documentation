Toolbar Manager helps manage the Drupal administration toolbar items, letting admins customize which items appear and how they are organized.

---

Toolbar Manager helps manage the items in the Drupal administration toolbar. It lets administrators
customize the toolbar — which items appear and how they are organized — so the admin navigation can be
tailored to a site's needs rather than showing the default set. It depends on core `toolbar` and
offers a settings form (`toolbar_manager_settings`) for the management interface.

Use it to streamline the admin toolbar for editors and administrators, hiding or reordering items to
match roles and workflows. It is an administration/UI tool; the toolbar reflects existing permissions
(it manages presentation of toolbar items, not the underlying access), so use it to reduce clutter and
guide users rather than as a security boundary.

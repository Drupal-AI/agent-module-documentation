# Toolbar Manager — agent index

Helps **manage/customize the Drupal admin toolbar** items — which appear and how they're organized.
Depends on core `toolbar`. Settings at `toolbar_manager_settings`. Version **2.0.2**. Core
`^9||^10||^11`.

Administration/UI tool — manages toolbar *presentation*, not underlying access (reflects existing
permissions). Use to reduce clutter, not as a security boundary.

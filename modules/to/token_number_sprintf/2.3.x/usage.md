Number Field Token Custom Format adds a custom formatting option to number field tokens using sprintf format strings.

---

Number Field Token Custom Format adds a custom formatting option to number-field tokens — letting you
format a number field's token value using a `sprintf` format string (e.g. zero-padding, fixed decimals,
thousands formatting), so tokenized number output can be precisely formatted. It depends on core System
(>=10) and Field, in the Token package.

Use it where number-field tokens need custom numeric formatting. It is a developer/token feature; the
`sprintf` format is **admin-configured** (not user input), so it is applied safely to the field's numeric
value. It has no content or access role. Configure the sprintf format on the number-field token.

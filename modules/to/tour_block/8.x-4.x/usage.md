Tour Block lets you place core Tour tours in a block.

---

Tour Block provides a Site Tour block — letting the core Tour module's guided tours be triggered/placed via a block, so a tour launcher can appear in a region rather than only on tour-tipped pages, improving discoverability of onboarding tours.

It's a UI/onboarding enhancement with no content or access role of its own (tour access follows core Tour). Supports Drupal 8 through 11.

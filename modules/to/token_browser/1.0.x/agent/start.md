# Token Browser — agent index

Highly performant **token-browser element** for the **Token** module (browse/insert tokens; faster than
the default on token-heavy sites). Depends on `token`. Config at `token_browser.settings`. Version
**1.0.1**. Core `^11.3||^12.0`.

Developer/content-editing UI — lists standard system tokens; no access role.

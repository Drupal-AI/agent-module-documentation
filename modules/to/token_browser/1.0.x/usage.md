Token Browser provides a highly performant token browser element for the Token module, for browsing available tokens.

---

Token Browser provides a highly performant token-browser element for the Token module — a UI element
for browsing and inserting available tokens (placeholders like `[node:title]`) that is faster/more
efficient than the default token browser, useful on sites with many tokens where the standard browser is
slow. It depends on the Token module and is configured at `token_browser.settings`.

Use it to give editors/site builders a better token-browsing experience when configuring token-based
fields/settings. It is a developer/content-editing UI feature listing available tokens; the tokens it shows
are the standard system tokens and it has no access-control role. Enable it to replace/enhance the token
browser.

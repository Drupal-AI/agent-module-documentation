Body Image Token provides a token that extracts the first image from the body field.

---

Body Image Token **provides a first-body-image token** — a token that extracts the first image found in a
node's body field, usable in Metatag/other token contexts (e.g. as a default social-share image). It depends on the
Token module.

Use it to derive a share image from body content. It is a content/SEO helper; it computes a token from existing
content and has no access-control role. Use the token in patterns.

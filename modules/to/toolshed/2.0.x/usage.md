Toolshed provides tools and helper functions to fill gaps in the standard Drupal API, for developers.

---

Toolshed is a developer utility library — a collection of helper functions and tools that fill gaps in
the standard Drupal API, giving module/theme developers convenient reusable helpers (and JS config
handling). It ships `toolshed_media` and `toolshed_search` submodules and is configured at
`toolshed.js_configs`.

Use it as a developer dependency/toolkit where its helpers are needed. It is a developer/API-support
module; it provides code utilities and has no content or access behaviour of its own. Its value is to
other modules/themes that build on its helpers.

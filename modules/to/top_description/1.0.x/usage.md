Top Description moves field descriptions/help text to appear directly under the field label (above
the input) rather than below the input, for themes that support this placement — a small usability/
UX improvement so users read the guidance before filling the field. It is in the Custom package.

Use it to improve form usability where description-below-input is easy to miss. It is a form/theming
presentation tweak affecting where descriptions render; it does not change the descriptions, data or
access. Enable it for the forms/themes where top-placed descriptions read better.

Integrate with the ToText web service to convert content to text.

---

ToText provides integration with the ToText web service — sending files/content to the ToText API and receiving back extracted plain text (e.g. transcription/text extraction), for making non-text content searchable or accessible.

The ToText API credentials are admin-configured; store them securely (env-backed). Supports Drupal 9, 10, and 11.

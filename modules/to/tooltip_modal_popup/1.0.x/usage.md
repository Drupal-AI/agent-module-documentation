Tooltip Modal Popup provides tooltip content in modals/popups.

---

Tooltip Modal Popup provides **tooltip and modal-popup content elements** — attaching helper tooltips or
click-to-open modal popups (with token support for dynamic content) to a page. It depends on core Token,
provides its own permissions, in the Tooltip package.

Use it to add tooltips/modals with contextual help. It is a content-display/UI feature; popup content is
admin/editor-authored (tokens resolve against access-respecting data) and it has no access-control role beyond
its permission. Configure the tooltips/modals.

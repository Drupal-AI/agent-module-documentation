Show/hide the admin toolbar with a keyboard hotkey.

---

Toolbar Toggle lets you toggle the admin toolbar with a hotkey — pressing a configurable keyboard shortcut shows or hides the admin toolbar, giving editors/developers more screen space on demand without disabling the toolbar. Supports Drupal 8 and later.

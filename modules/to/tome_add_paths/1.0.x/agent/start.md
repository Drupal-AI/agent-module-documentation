# Tome Add Paths — agent index

Adds **custom paths to export** when generating a **Tome** static site (force-include URLs Tome's crawler
wouldn't discover). Depends on `tome_static`. Config at `tome_add_paths.config`. Version **1.0.3**. Core
`^9||^10||^11`.

Developer/static-generation tool — affects which paths are exported; no runtime access role.

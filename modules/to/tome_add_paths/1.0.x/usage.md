Tome Add Paths lets you add custom paths to be exported on a Tome static site build.

---

Tome Add Paths lets you specify additional custom paths to include when Tome generates a static site —
so paths that Tome's crawler wouldn't discover automatically (or that you want to force-include) are
exported into the static build. It depends on Tome Static and is configured at `tome_add_paths.config`.

Use it on Tome-based static-site setups where certain URLs must be in the export but aren't reached by the
normal crawl. It is a developer/static-generation tool operating on the Tome build; it affects which paths
are exported and has no runtime access role. Configure the extra paths to include.

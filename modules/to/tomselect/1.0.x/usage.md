Tom Select is a development helper for including the Tom Select JavaScript library.

---

Tom Select is a **developer helper that bundles the Tom Select JavaScript library** — a lightweight,
accessible select/autocomplete/tagging UI library — so other modules/themes can attach it as a Drupal asset
library instead of shipping their own copy. It is a developer/library feature.

Use it as a shared dependency to get Tom Select. It is a developer/API utility providing an asset library; it
renders nothing on its own and has no content or access role. Depend on it and attach the library.

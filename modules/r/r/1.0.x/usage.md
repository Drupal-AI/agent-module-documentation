A text filter that executes and embeds R statistical output.

---

R is an R Filter module for executing and embedding R output in Drupal content — a text-format filter that runs R code blocks embedded in content and inserts the resulting output (text/plots) into the rendered page, for statistics/data-science content.

**Note:** executing R code is inherently powerful — restrict the filter to trusted text formats/roles only; never grant it on formats available to untrusted users. Supports Drupal 10 and 11.

# IVW Tracking — agent index

Integrates **IVW / SZM (SZM 2)** audience-measurement tracking (German reach measurement, IVW/INFOnline).
Per-content via Token settings. Depends on `token`; provides permissions. Version **8.x-2.9**. Core
`^10||^11`.

**Privacy/consent:** sends usage data to the measurement provider — require consent, integrate
cookie-consent, disclose per TTDSG/GDPR. No access role.

# Empty Page — agent index

Creates blank menu callbacks — dynamic routes that render an **empty** page (optional title),
so pages built entirely from blocks (or a blanked-out path) are possible. No dependencies
beyond core; no config schema.

- **Managing callbacks: admin routes, config object shape, dynamic routes** →
  [configure/callbacks.md](configure/callbacks.md)
- **Permissions** → [permissions/permissions.md](permissions/permissions.md)

Key facts: admin at `/admin/structure/empty-page` (route `empty_page.administration`, perm
`administer empty pages`). Each callback stored in config `empty_page.settings` as
`callback_<cid>` = `{cid, path, page_title, created, updated}` plus `new_id` counter. Dynamic
routes `empty_page.page_<cid>` are generated by `EmptyPages::routes` (route_callbacks) and gated
by perm `view empty pages`. Saving a callback rebuilds the router.

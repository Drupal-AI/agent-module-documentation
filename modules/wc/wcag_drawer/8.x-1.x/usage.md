WCAG Drawer provides a framework for easy accessibility settings.

---

WCAG Drawer provides a **framework for an accessibility settings drawer** — a visitor-facing panel offering
accessibility adjustments (e.g. font size, contrast, spacing) to help meet WCAG usability goals. It works across
core 9–11.

Use it to offer visitor accessibility controls. It is an accessibility/front-end feature affecting presentation;
settings are client-side preferences and it has no content or access role. Configure the accessibility drawer.

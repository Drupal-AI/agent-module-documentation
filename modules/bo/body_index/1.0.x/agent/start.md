# Body Index - agent index

**Body Index** is a field formatter that builds a table of contents from body headings. Version **1.0.2** (`1.0.x`). Core `^10`.

## Key files
- `src/Plugin/Field/FieldFormatter/BodyIndexFormatter.php` - the formatter.
- `templates/body-index-list.html.twig`, `config/schema/body_index.schema.yml`.

Field-formatter plugin; no routes/permissions.

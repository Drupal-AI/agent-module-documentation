CKEditor Advanced Container adds an advanced div-based container/columns layout to CKEditor 5, with responsive options.

---

CKEditor Advanced Container adds a div-based container/columns layout capability to CKEditor 5 — letting
editors create multi-column and container structures (with responsive options) within rich-text content,
so richer layouts can be built directly in the editor. It depends on core CKEditor 5.

Use it to give editors in-editor column/container layouts. It is a content-editing/CKEditor feature; the
layout becomes div markup with classes in the content, so ensure the text format's allowed tags/attributes
permit the container markup/classes (so they survive filtering). No access-control role. Add the container
tools to the text format's CKEditor 5 toolbar.

CKEditor Div as Block treats all divs in CKEditor 5 as block containers.

---

CKEditor Div as Block **treats divs as blocks in CKEditor 5** — configuring CKEditor 5 so `<div>` elements are
handled as block-level containers (for structured content editing). It depends on the CKEditor 5 Plugin Pack
Templates module.

Use it for div-based block editing. It is a content-editing/WYSIWYG feature; it affects how divs are edited and
passes markup through the text format (sanitize) and has no access-control role. Enable it for div-as-block
handling.

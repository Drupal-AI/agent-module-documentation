CKEditor Mentions Notifications sends notifications when a user is @-mentioned in CKEditor.

---

CKEditor Mentions Notifications **sends notifications for @-mentions made in CKEditor** — when an author
mentions a user (via the CKEditor Mentions feature), the mentioned user is notified. It depends on the CKEditor
Mentions module.

Use it to alert users when they're mentioned. It is a user-engagement/notification feature. Privacy note:
mentions and notifications reveal that a user was referenced (and typically email them) — send notifications only
to the intended recipient and follow your email/privacy practices. It has no access-control role. Configure the
mention notifications.

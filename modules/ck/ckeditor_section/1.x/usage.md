CKEditor Section adds a toolbar button to wrap content in a <section> element in CKEditor.

---

Semantic <section> elements structure content meaningfully. CKEditor Section adds a button to wrap content in a section. It is a CKEditor authoring enhancement. The text format's allowed HTML must permit <section> or the filter strips it. No security surface beyond that.

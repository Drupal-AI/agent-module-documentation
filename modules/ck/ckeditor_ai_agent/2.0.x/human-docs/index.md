# CKEditor AI Agent — manual setup guide

**CKEditor AI Agent** (`ckeditor_ai_agent`) puts AI assistance directly inside
CKEditor 5. An editor can ask for text to be written, rewritten, summarised, or
retoned — using intuitive slash commands like `/write blog about AI` or by
selecting text and choosing an action — and the request is generated by the
site's configured AI provider and streamed back into the document as it is
written.

Putting generation where the writing happens is the whole point: it is the
difference between a feature editors reach for and one they forget. The module
adds a CKEditor 5 plugin plus a server-side proxy, so requests are routed through
Drupal via the **AI module** (`drupal/ai`). That means the provider credential
(API key) stays on the server and never reaches the browser, and switching
providers — DXPR, OpenAI, Anthropic, Ollama, and 400+ models — is a
configuration change rather than a rewrite. It supports real-time streaming,
context-aware writing that uses the surrounding content, selection-based edits,
optional inclusion of content from user-provided URLs, and multilingual content.

Two things to plan for. First, **access is permission-gated**: only roles you
grant the *Use CKEditor AI Agent* permission can generate content, and the
administrative permission is marked restricted. Second — and this is the real
exposure — **the cost is on you, not your security**. Anyone who can use the AI
Agent can send arbitrary prompts through your provider account and can select a
more expensive model than your default. Nothing in the module rate-limits or
budgets. On a team with many editors that is a genuine spending exposure, so grant
the permission deliberately, watch your provider's usage dashboard, and consider
setting spend limits on the provider side rather than relying on the module.

It requires the AI module and core's CKEditor 5, and runs on Drupal 10.3 and 11.
See [Configuration](configuration/index.md) for the settings form and the
provider/permission setup.

This guide is written for a **human** clicking through the admin UI. If you want
terse, token‑cheap references for an AI coding agent, read the sibling
[`agent/`](../agent/start.md) docs instead.

## Where it lives in the admin menu

The AI Agent's global settings form is at **Configuration → Content authoring →
CKEditor AI Agent** (`/admin/config/content/ckeditor-ai-agent`). You also work
with the AI module's own settings at `/admin/config/ai/settings`, the permissions
page, and the text-format editor configuration — all covered in
[Configuration](configuration/index.md).

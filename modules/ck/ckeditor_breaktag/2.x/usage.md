CKEditor Break Tag lets editors insert a <br> break tag between text in CKEditor.

---

Inserting a line break (<br>) rather than a paragraph break is sometimes wanted in rich text. CKEditor Break Tag adds a button to insert a break tag. It is a CKEditor authoring enhancement. As with any CKEditor plugin inserting markup, the text format's allowed HTML must permit <br> (usually it does) or the filter strips it. No security surface beyond that standard consideration.

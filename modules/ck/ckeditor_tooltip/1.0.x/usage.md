Adds a tooltip plugin to CKEditor 5 using Drupal Modals.

---

CKEditor 5 Tooltip is a CKEditor 5 plugin that adds a tooltip plugin to CKEditor 5 using Drupal Modals. — extending the rich-text editor so editors can use this feature directly in the WYSIWYG.

It's a CKEditor 5 plugin (and, where relevant, a text-format filter); ensure any filter is enabled on the relevant text formats. Depends on `ckeditor5`; supports Drupal per ^10 || ^11.

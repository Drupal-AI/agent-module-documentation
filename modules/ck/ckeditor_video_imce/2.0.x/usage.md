CKEditor Video IMCE adds a CKEditor 5 video button that picks files via the IMCE browser.

---

CKEditor Video IMCE adds a video plugin to CKEditor 5 that integrates with the IMCE file browser, letting editors browse and select video files from the server and embed them in rich text. It streamlines adding self-hosted videos to content.

It's a CKEditor 5 plugin depending on IMCE; access to files is governed by IMCE's own configuration and permissions. Depends on core `ckeditor5` and `imce`; supports Drupal 10, 11, and 12.

CKEditor 5 Media Resizer allows content editors to resize embedded media images in CKEditor 5 by dragging handles or entering dimensions.

---

CKEditor 5 Media Resizer lets editors resize embedded media images in CKEditor 5 — by dragging resize
handles or entering explicit dimensions, so an embedded media image can be sized inline in the rich-text
editor. It depends on core CKEditor 5.

Use it to give editors media-image resizing in CKEditor 5. It is a content-editing/CKEditor feature affecting
embedded-media markup (adds width/height/style); ensure the text format's allowed attributes permit the
sizing markup, and it has no access-control role. Enable it in the CKEditor 5 configuration.

CKEditor Autosave History Log implements the CKEditor Autosave History Log plugin to save the text area to local storage.

---

CKEditor Autosave History Log adds the CKEditor Autosave History Log plugin — periodically saving the
editor's text to the **browser's local storage**, so if the browser crashes or the page is lost, the editor
can restore recent unsaved content from local storage. It depends on core CKEditor 5, in the CKEditor 5
package.

Use it to protect against losing in-progress edits. It is a content-editing/CKEditor feature. One thing to be
aware of: drafts are stored in the **browser's local storage** — on a **shared/public computer**, that draft
content persists in the browser until cleared (a data-remnant/privacy consideration for sensitive content).
It has no access-control role. Enable the plugin in CKEditor 5.

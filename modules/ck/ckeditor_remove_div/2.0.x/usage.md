CKEditor Remove Div adds the Remove Div plugin to CKEditor.

---

CKEditor Remove Div adds a **"Remove Div" plugin to CKEditor 5** — a toolbar action to remove/unwrap a
`<div>` container around selected content, helping editors clean up nested markup. It depends on core CKEditor
5, in the CKEditor package.

Use it to let editors remove div wrappers. It is a content-editing feature affecting the editor; output still
goes through the text format's filtering and it has no content or access role. Add the button to a CKEditor
toolbar.

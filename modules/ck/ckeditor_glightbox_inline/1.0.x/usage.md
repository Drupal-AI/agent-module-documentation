CKEditor GLightbox Inline adds a text filter so inline images open with GLightbox.

---

CKEditor GLightbox Inline adds a **text filter** that makes **inline images open in a GLightbox** lightbox
— so images embedded in rich text pop up in an overlay instead of just displaying, without editors wiring it
up. It depends on the GLightbox module.

Use it to lightbox inline content images. It is a content-display/filter feature affecting how inline images
render on output; it has no content or access role. Enable the filter on the relevant text format.

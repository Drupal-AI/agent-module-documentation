# WordsOnline Drupal Connector — agent index

A **TMGMT translator for the WordsOnline** translation service (connect Drupal's translation workflow to
WordsOnline). Depends on `tmgmt`. Version **2.0.5**. Core `^8.7.7||^9||^10||^11`.

**Security:** store WordsOnline API credentials as **secrets**; HTTPS; content is sent to WordsOnline
(data-handling). TMGMT governs the workflow. No access role.

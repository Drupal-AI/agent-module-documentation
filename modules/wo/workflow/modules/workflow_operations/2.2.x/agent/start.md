# Workflow Operations — agent index (obsolete)

**Obsolete, hidden submodule.** The extra transition permissions it once added — edit a
transition's comment and revert a transition — are now generated by the main `workflow` module.
This submodule ships only an `info.yml` (no code/permissions). You do **not** need to enable it.

- The permissions now live in the parent: `edit own/any <wid> workflow_transition`,
  `revert own/any <wid> workflow_transition` — see
  [permissions/permissions.md](../../../../2.2.x/agent/permissions/permissions.md).

Key fact: `hidden: TRUE`, depends on `workflow`, `configure: null`. Enabling it is a no-op kept
only for upgrade compatibility.

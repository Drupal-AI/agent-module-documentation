A Battle.net API integration toolkit for World of Warcraft.

---

World of Warcraft API is a Battle.net API integration toolkit for World of Warcraft — providing authentication, an API client and base infrastructure for WoW submodules (character, guild, mount, pet, title, toy) so a site can pull and display World of Warcraft game data from Blizzard's Battle.net API.

The Battle.net API credentials are handled via a Key entity (`key`, env-backed). Depends on core `views` and `key`; supports Drupal 10.3+ and 11.

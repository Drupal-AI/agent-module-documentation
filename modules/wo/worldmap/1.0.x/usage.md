Worldmap adds a configurable SVG-based World map as a block.

---

Worldmap adds a configurable **SVG-based world map** as a **block** — you can configure and place an
interactive/styled world map (e.g. highlight countries) in any block region. It requires PHP 7.4 and depends
on core Block, in the Worldmap package.

Use it to display a world map block. It is a content-display feature; the map is admin-configured presentation
and it has no content or access role. Place and configure the world-map block.

# Worldmap — agent index

Adds a configurable **SVG-based world map as a block** (styled/interactive map — highlight countries — in any
region). Requires PHP 7.4. Depends on core `block`. Version **1.0.0**. Core `^9.3||^10||^11`.

Content-display — admin-configured presentation; no content/access role.

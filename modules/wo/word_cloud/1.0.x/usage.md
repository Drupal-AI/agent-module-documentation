A canvas-based word-cloud field formatter.

---

Word Cloud provides a word cloud field formatter with advanced canvas-based rendering, multiple shapes, animations and colour customization, requiring no third-party JS libraries — so a text/tags field can render as an attractive word cloud (sized by frequency) drawn on an HTML canvas. Depends on core `field` and `text`; supports Drupal 10 and 11.

Citation Select adds a block that lets visitors pick a citation style and view/copy a formatted bibliographic citation for the current node, generated by mapping node fields to CSL-JSON and rendering them with citeproc-php against installed Citation Style Language (CSL) styles.

---

The module provides a `citation_select_block` (`BibliographySelectBlock`) that renders `SelectCitationForm`:
a style `<select>` (populated from enabled CSL style config entities), an AJAX-rendered formatted
bibliography for the node resolved from the current URL, and a "Copy Citation" clipboard button. On style
change, `CitationProcessorService` builds a CSL-JSON data array by iterating the admin-configured field map
(`csl_map`) — for each node field it picks a `CitationFieldFormatter` plugin by the field's type (`default`,
`edtf`, `entity_reference`, `typed_relation`) to convert the value into the right CSL shape (person names via
`adci/full-name-parser`, dates via `date_parse` or `professional-wiki/edtf`, standard strings, entity labels,
typed-relation roles). The reference **type** is resolved through a configurable `reference_type_field_map`
to a valid CSL type (default `document`). `CitationStyler` then renders the data with `seboettg/citeproc-php`
using the selected `citation_select_csl_style` config entity's CSL XML and the current language. CSL styles
are ConfigEntities you manage at *Config → Citation Select settings → CSL Styles* — add by pasting CSL XML or
uploading a `.csl`/`.xml` file; the module ships APA, MLA (2 editions), Chicago author-date, and AMA. Two
admin forms configure it: **Settings** (default style, show-on-load) and **CSL Mapping** (map node fields to
CSL fields, and typed-relation machine names to CSL name roles). All admin routes require
`administer site configuration`; output is `Xss::filter`ed before rendering. It defines the
`CitationFieldFormatter` plugin type so custom field types can be supported. No permissions of its own, no
Drush.

---

- Add a "cite this" block to node pages so visitors can copy a formatted citation.
- Let users switch between citation styles (APA, MLA, Chicago, AMA, …) and see the citation update live.
- Generate a bibliography for a node from its fields without manual formatting.
- Install additional CSL styles by pasting CSL XML into a config form.
- Upload a `.csl`/`.xml` CSL style file to add a new citation style.
- Map node fields to CSL-JSON fields (title, author, issued date, publisher, DOI, …) via the CSL Mapping form.
- Map a Typed Relation field's roles (e.g. `relators:aut`) to CSL name roles like `author`/`editor`.
- Resolve a node's reference type (e.g. "Paged Content" → `book`) via the reference-type field map.
- Format author/contributor names into CSL person objects using a full-name parser.
- Handle EDTF (Extended Date/Time Format) date fields when producing citations.
- Cite entity-reference field values by their referenced entity labels.
- Set a default citation style and whether the citation shows on page load.
- Scope the citation block to specific content types via block visibility.
- Copy the rendered citation to the clipboard with one click.
- Provide multilingual citations that render in the current interface language.
- Support the "current url" and "title" pseudo-fields in the field map.
- Add support for a custom field type by implementing a `CitationFieldFormatter` plugin.
- Preview citations for editors before publishing reference content.
- Offer researchers ready-to-paste citations for library/repository nodes.
- Keep citation output safe by XSS-filtering all mapped field values before rendering.
- Reuse Bibcite-style CSL style management without depending on the full Bibcite suite.

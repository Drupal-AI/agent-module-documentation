# Clickio Consent — agent index

**Integrates the Clickio Consent CMP** for GDPR/TCF/Consent-Mode cookie consent. Version **1.0.6**. Core `>=8`.

Privacy/integration — loads a **third-party Clickio script** (egress; runs in visitors' browsers, processes
consent) — vet + disclose the processor. Site ID is config (not a secret). No access role.

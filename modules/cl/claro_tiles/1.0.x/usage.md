Claro Tiles restyles Claro admin listings as tiles.

---

Claro Tiles adds custom CSS styling to the Claro (admin) theme — presenting certain admin listings/elements as styled tiles rather than the default layout, giving the admin UI a more visual, card-based appearance.

It's an admin-theme styling enhancement with no content or access role of its own. Supports Drupal 10 and 11.

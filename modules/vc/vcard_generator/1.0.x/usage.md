vCard Generator generates vCard (.vcf) contact files.

---

vCard Generator **generates vCard contact files** — producing downloadable vCard (.vcf) files from contact
data, so visitors can save a contact to their address book. It works on core 11.

Use it to offer vCard downloads. It is a content/utility feature. Data-handling note: vCards contain **contact
personal data (PII)** (names, emails, phones, addresses) — only generate vCards for contacts intended to be shared,
and handle the data per your privacy policy. It has no access-control role. Configure the vCard generation.

A unified client for version-control providers (GitLab, GitHub).

---

VCS Provider Client provides a unified client abstraction for version-control-system providers — wrapping the GitLab and GitHub API client libraries behind a common interface so other modules can fetch repositories, files and metadata from a configured VCS provider without coupling to a specific vendor SDK. It's a developer/integration dependency.

The VCS provider access tokens are admin-configured; store them securely (env-backed). Supports Drupal 10, 11, and 12.

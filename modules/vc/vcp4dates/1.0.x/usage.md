Views Cache Plugins for Dates provides Views cache plugins that set sensible cache metadata for temporal content.

---

Views Cache Plugins for Dates (vcp4dates) **adds date-aware Views caching** — cache plugins that compute
sensible cache max-age/metadata when a view depends on time (e.g. upcoming events), so temporal views invalidate at
the right moment. It depends on core Views.

Use it to cache time-dependent views correctly. It is a performance/Views feature; it sets cache metadata and has
no content or access role. Configure the date cache plugin on a view.

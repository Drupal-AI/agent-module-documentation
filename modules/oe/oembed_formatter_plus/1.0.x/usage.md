Adds extra options to the core oEmbed media formatter.

---

oEmbed Formatter Plus adds additional functionality to the basic oEmbed formatter — extra display options (sizing, lazy-loading, click-to-play, attributes) for oEmbed-based remote media (YouTube, Vimeo, etc.), so editors get more control over how embedded media renders. Depends on core `media`; supports Drupal 10.2+ and 11.

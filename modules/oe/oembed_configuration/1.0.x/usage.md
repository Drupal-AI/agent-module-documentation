oEmbed Configuration adds basic configuration for oEmbed media resources.

---

oEmbed Configuration **adds configuration for oEmbed resources** — letting admins configure how oEmbed media
(remote video/rich embeds) is handled (e.g. providers/settings) beyond core defaults. It depends on core Media and
provides its own permissions.

Use it to tune oEmbed media handling. It is a media-configuration feature; oEmbed embeds load third-party content
(as core oEmbed does) and it has no access-control role beyond its permission. Note: oEmbed fetches provider data
(core sandboxes embeds); keep providers trusted. Configure the oEmbed settings.

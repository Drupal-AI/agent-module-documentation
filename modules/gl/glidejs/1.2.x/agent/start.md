# Glide.js — agent index

A **Views style plugin rendering results as a Glide.js carousel** (lightweight swipeable slider). Depends on
core `views`. Version **1.2.0**. Core `^10.5||^11||^12`.

Content-display/Views — affects presentation; results respect the View's access; no access role.

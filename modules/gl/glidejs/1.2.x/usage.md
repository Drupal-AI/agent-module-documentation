Glide.js provides a Views style plugin for a Glide.js-based carousel.

---

Glide.js provides a Views style plugin that renders View results as a Glide.js carousel — a lightweight,
dependency-free slider/carousel — for presenting a list of content as a swipeable carousel. It depends on
core Views.

Use it to present a View as a Glide.js carousel. It is a content-display/Views feature affecting
presentation; the results respect the View's access and it has no access-control role. Select the Glide.js
style on the View.

# Global Node Translation — agent index

**Creates translations in all enabled languages when a node is created** in the original language. Depends on core
`language`, `content_translation`. Version **1.0.1**. Core `^10||^11`.

Multilingual/content — creates translation entities (follow core handling; created translations still need actual
translating); no access role.

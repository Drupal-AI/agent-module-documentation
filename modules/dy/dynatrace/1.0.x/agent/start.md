# Dynatrace (`dynatrace`)

Integrates Drupal with Dynatrace application performance monitoring: exposes OneAgent trace info and can post custom metrics to the Dynatrace metric ingest API.

- Project: `dynatrace`, version `1.0.x`, core `^9.4 || ^10`.
- Category: Integrations / Application performance monitoring.
- Configure via route `dynatrace.settings`.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

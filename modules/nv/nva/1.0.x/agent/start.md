# NVA Integration — agent index

Provides **integration with a Nasjonal (Norwegian national) service/register**. Depends on `key`. Version
**1.0.11**. Core `^10||^11`.

Integration — credentials stored as a **Key** (correct); exchanges data with the **external national service**
(egress, HTTPS; handle PII per privacy). No access role.

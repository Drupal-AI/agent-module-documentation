# CRM Membership (crm_membership) — agent index

**Manages memberships in the CRM project: links Contact entities to membership types, dated periods, and pluggable term rules (Fixed / Rolling / Lifetime) that drive activation, renewal and expiration.**

- **Version:** 1.0.x (dev checkout, branch `1.0.x`)
- **Core:** `>=11.1` (PHP 8.3+)
- **Requires:** `crm:crm`, `duration_field:duration_field`, core `datetime_range`

**Entities**
- `crm_membership` — Membership content entity (revisionable, published/unpublished). Links `contacts` (members) → `target_contact` (member-of). Base table `crm_membership`.
- `crm_membership_type` — config bundle selecting a MembershipTerm plugin + settings.
- `crm_membership_period` — concrete start/end date range + applicable contacts.

**Entity routes** (generated by `MembershipRouteHtmlRouteProvider`, under `/crm/membership`): collection, canonical `/{id}`, add-page, add-form/`{type}`, edit, delete, and `renew` (`/{id}/renew`, requirement `_entity_access: crm_membership.renew`).

**Permissions:** `administer crm_membership` (admin, restricted); `view/create/edit/delete crm membership types`; `view memberships`; `edit memberships`; `renew memberships`; `delete memberships` (restricted).

**Services:** `crm_membership.service` (`MembershipService`: isMember/getMemberships/getMembershipsForTarget, dispatches `MembershipEvents::IS_MEMBER`); `plugin.manager.crm_membership_term`; dedicated logger channel.

**Plugins:** MembershipTerm — `fixed_duration`, `rolling_duration`, `lifetime`. QueueWorker `crm_membership_expiration` (cron time 60). Views field `MembershipLabel`.

**Automation:** `CronHooks::cron()` queues active-but-lapsed memberships; the queue worker expires them via the term plugin.

**Security:** All entity operations gated by `MembershipAccessControlHandler` (granular per-op permissions + `administer crm_membership` override); unpublished memberships admin-only. No anonymous or mutating public endpoints; the renew route is `_entity_access`-gated. `MembershipService` queries use `accessCheck(FALSE)` deliberately for internal membership computation (not rendered to unprivileged users). No disabled TLS, raw SQL, unserialize, or hardcoded secrets found.

See [configure/membership-types.md](configure/membership-types.md) and [api/membership-service.md](api/membership-service.md).

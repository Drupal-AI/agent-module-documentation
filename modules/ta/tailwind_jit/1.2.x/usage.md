Tailwind JIT provides a Just-in-Time compiler for Tailwind CSS, generating the needed Tailwind utility CSS on the fly.

---

Tailwind JIT provides a Just-in-Time compiler for Tailwind CSS in Drupal — generating only the
Tailwind utility classes actually used, on the fly, rather than shipping the full framework. This suits
theming/component workflows that use Tailwind utility classes in templates and want the CSS produced
without a separate Node build step for every change.

Use it in a Tailwind-based theme or component setup to compile utilities as needed. It is a
theming/developer tool operating on CSS generation; it has no content or access behaviour. Consider the
performance characteristics of on-the-fly compilation (cache the generated CSS appropriately) and treat
it as part of your front-end build/theming toolchain.

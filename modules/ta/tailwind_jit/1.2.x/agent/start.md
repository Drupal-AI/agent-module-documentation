# Tailwind JIT — agent index

**Just-in-Time compiler for Tailwind CSS** — generates only used utility classes on the fly (no full
framework, no separate Node build per change). Version **1.2.0**. Core `^10.3||^11`.

Theming/developer tool (CSS generation, no content/access). Cache generated CSS; part of the front-end
toolchain.

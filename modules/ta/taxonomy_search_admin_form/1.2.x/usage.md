Taxonomy search admin form provides a search form for taxonomy terms.

---

Taxonomy search admin form provides a search form for taxonomy terms — letting administrators search/
find terms (by name) in the admin, easier than browsing large vocabularies. It provides its own permissions,
in the Custom package.

Use it to search taxonomy terms in the admin. It is an administration/search feature over taxonomy; the term
search respects taxonomy access and it has no access-control role beyond its permission. Use the form to find
terms.

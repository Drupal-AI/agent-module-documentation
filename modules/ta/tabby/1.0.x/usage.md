A theme function/helper for rendering tabbed content.

---

Tabby provides a theme function for rendering tabs — a small helper library that other modules/themes use to render tabbed content (a set of panes with tab navigation) consistently, without each re-implementing tab markup/behaviour. It's a building block (e.g. used by Tabby Viewfield). Supports Drupal 10 and 11.

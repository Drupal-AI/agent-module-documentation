# Taxonomy Term Preview — agent index

Adds a **preview button to the taxonomy term form** (preview a term before saving — like node preview).
Depends on core `taxonomy`. Version **1.1.0**. Core `^10.1||^11||^12`.

Content-editing — preview respects the term's normal access/rendering; no access role.

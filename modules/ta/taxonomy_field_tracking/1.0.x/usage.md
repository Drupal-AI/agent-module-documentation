Track taxonomy-field usage in nodes to override a view argument.

---

Taxonomy Field Tracking tracks the use of a taxonomy field in nodes and uses that information to override a view argument — so a listing View can be automatically filtered by the taxonomy terms actually used on the current node/context, driving related-content style listings. Supports Drupal 8 through 11.

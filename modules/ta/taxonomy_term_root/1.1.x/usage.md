Taxonomy Term Root provides a base field which maps to a term's highest parent (its root term).

---

Taxonomy Term Root adds a base field to taxonomy terms that maps each term to its highest ancestor (the
root term in its hierarchy) — so, given a deep term, you can reference/filter by its top-level category
without walking the parent chain each time. It depends on core Taxonomy. This is useful for grouping content
by top-level category in Views or logic.

Use it to work with terms' root categories efficiently. It is a taxonomy/fields feature providing derived
data (the root term); the value reflects the term hierarchy and it has no access-control role. Use the base
field in Views/logic where the root term is needed.

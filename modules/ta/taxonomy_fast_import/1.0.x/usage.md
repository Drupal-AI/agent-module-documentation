Taxonomies Fast Import imports taxonomy terms to a defined vocabulary, bulk-creating terms.

---

Taxonomies Fast Import provides a fast way to import taxonomy terms into a chosen vocabulary — bulk-
creating many terms (e.g. pasting or importing a list) into a defined vocabulary quickly, rather than adding
them one by one. It depends on core Taxonomy and provides its own permissions, in the Taxonomy package.

Use it to bulk-load taxonomy terms. It is a content/import feature that creates terms; the imported terms
are taxonomy content, and it has no access-control role beyond its permission. Gate the import permission to
trusted users (bulk term creation is an editorial/admin action). Configure the target vocabulary and
import.

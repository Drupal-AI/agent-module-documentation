# Taxonomies Fast Import — agent index

**Bulk-imports taxonomy terms into a defined vocabulary** (fast create-many vs one-by-one). Depends on core
`taxonomy`; provides permissions. Version **1.0.0-rc1**. Core `^10||^11`.

Content/import — creates taxonomy content; gate the import permission to trusted users. No access role beyond
permission.

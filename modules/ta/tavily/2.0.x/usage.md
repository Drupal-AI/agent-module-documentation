Tavily Core integrates the Tavily AI search/answer API with tools and AI Automators.

---

Tavily Core provides the core integration for calling the Tavily API — an AI-powered web search/answer engine — including AI Automator types and tools, so Drupal AI features (agents, automators) can perform web searches and retrieve answers via Tavily.

The Tavily API key is stored via the Key module (env-backed), and calls incur Tavily cost. Usage is gated by `use tavily tools`. Depends on `key`; supports Drupal 10.3+ and 11.

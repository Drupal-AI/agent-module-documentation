Tarte au citron Media Remote Videos provides a Remote Videos plugin for the Tarte au citron module using core media.

---

Tarte au citron Media Remote Videos integrates core Media remote videos with the Tarte au citron consent
manager — so embedded remote videos (YouTube/Vimeo etc. added as core media) are gated behind GDPR/cookie
consent, only loading the third-party video (and its cookies/trackers) after the visitor consents. It depends
on core Media and the Tarte au citron module, in the GDPR package.

Use it to make core-media remote videos GDPR-compliant via Tarte au citron. It is a privacy/consent feature:
it prevents third-party video embeds from loading (and setting cookies/contacting the provider) until
consent is given, which is its security/privacy value. It has no access-control role. Configure the consent
service for the video providers.

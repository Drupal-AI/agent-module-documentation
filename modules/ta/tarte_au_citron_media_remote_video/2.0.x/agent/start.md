# Tarte au citron Media Remote Videos — agent index

Adds **GDPR consent gating (Tarte au citron) for core Media remote videos** (YouTube/Vimeo embeds load — and
set cookies/contact the provider — only after consent). Depends on core `media`, `tarte_au_citron`. Version
**2.0.0**. Core `^10||^11`.

Privacy/consent — blocks third-party video embeds pre-consent (its privacy value); no access role.

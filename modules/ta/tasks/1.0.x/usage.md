Tasks provides initial configuration for tasks.

---

Tasks is a **configuration kit providing an initial task/to-do setup** — shipping ready-made configuration
(content type, views, listing/ordering, flags) to add a task/to-do feature to a site quickly. It depends on core
Link, User and several contrib modules (Add Content by Bundle, Display Link Plus, Draggable Views, Storage,
Flag), in the Configuration Kits package.

Use it to bootstrap a tasks/to-do feature. It is a site-building/configuration kit; it installs config (content
types/views/flags) that follows normal access, and it has no access-control role of its own. Enable it and adapt
the provided config.

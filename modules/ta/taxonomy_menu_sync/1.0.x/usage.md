Taxonomy Menu Sync allows creating menu items from taxonomy terms.

---

Taxonomy Menu Sync lets you **create and sync menu items from taxonomy terms** — automatically generating
menu links that mirror a taxonomy vocabulary's terms (and keeping them in sync as terms change). It depends on
core Menu Link Content and Taxonomy, provides its own permissions, in the Menu package.

Use it to build menus that track a vocabulary. It is a site-structure/navigation feature; term/menu content is
admin/editor-managed and it has no access-control role beyond its permission. Configure the vocabulary-to-menu
sync.

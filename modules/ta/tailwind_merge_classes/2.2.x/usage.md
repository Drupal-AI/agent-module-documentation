Tailwind Merge Classes provides a Twig extension to merge Tailwind CSS classes, avoiding duplication and conflicts.

---

Tailwind Merge Classes provides a Twig extension for merging Tailwind CSS classes — intelligently
combining class strings so conflicting Tailwind utilities resolve correctly (later wins) and duplicates are
removed, mirroring the JS `tailwind-merge` behaviour, for Tailwind-based themes. It is in the Tailwind Merge
Classes package.

Use it in Twig templates to merge Tailwind class lists cleanly. It is a developer/theming feature affecting
class-string output; it has no content or access role. Use the Twig function/filter in your templates.

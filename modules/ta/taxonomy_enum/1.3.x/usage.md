Taxonomy Enum synchronises taxonomy vocabularies with PHP enums.

---

Taxonomy Enum **syncs vocabularies with PHP enums** — keeping a taxonomy vocabulary's terms in sync with a PHP
enum (so developers can reference terms as typed enum cases), using term machine names. It depends on core Taxonomy
and the Taxonomy Machine Name module.

Use it to bridge taxonomy and code enums. It is a developer/site-building feature; it manages term/enum sync and
has no content or access role. Use the enum-backed terms in code.

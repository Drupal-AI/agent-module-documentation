Taxonomy Facets provides progressive content filtering with clean URLs using taxonomy terms as facets, 100% server-rendered.

---

Taxonomy Facets provides progressive content filtering — using taxonomy terms as facets to filter
content listings, with **clean URLs** and **100% server-side rendering (no JavaScript)**, so faceted listings
can even be exported as static HTML. It ships `taxonomy_facets_export`, `taxonomy_facets_simple_sitemap` and
`taxonomy_facets_tome` submodules, is configured at `taxonomy_facets.settings_form`, in the Taxonomy Facets
package.

Use it for SEO-friendly, JS-free faceted browsing. It is a site-search/facets feature shaping content
listings by taxonomy; the listed content respects its own access and it has no access-control role. Because
facets create many crawlable URLs, be mindful of crawl/duplicate-content considerations (the sitemap submodule
helps). Configure the facets.

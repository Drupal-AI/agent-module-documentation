# Taxonomy Facets — agent index

**Server-rendered progressive content filtering** using taxonomy terms as facets — **clean URLs, 100%
server-side (no JS)**, exportable as static HTML. `..._export`/`..._simple_sitemap`/`..._tome` submodules.
Config at `taxonomy_facets.settings_form`. Version **3.3.2**. Core `^11.0||^12`.

Site-search/facets — shapes listings by taxonomy (content respects its own access); facets create many
crawlable URLs (mind crawl/duplicate-content; sitemap submodule helps). No access role.

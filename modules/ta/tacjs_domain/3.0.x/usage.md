TacJS Domain allows configuration of TacJS services for multi-domain Drupal sites.

---

TacJS Domain adds **per-domain configuration** to TacJS (the tarteaucitron.js cookie-consent manager) on
Domain-module multi-domain sites — so each domain can enable a different set of consent-managed third-party
services. It depends on the Domain and TacJS modules, in the GDPR package.

Use it to run different consent/service configs per domain. It is a privacy/consent configuration layer; the
actual consent gating is done by **TacJS** (this module scopes it per domain), and it has no access-control
role. As with any consent setup, effectiveness depends on TacJS correctly gating the third-party scripts.
Configure the per-domain TacJS services.

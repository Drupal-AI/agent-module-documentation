# Tailwind Grid — agent index

A **Views style plugin laying out results in a Tailwind CSS grid** (responsive columns per breakpoint, no
custom templating — Tailwind themes). Config at `tailwind_grid.settings`. Version **1.0.1**. Core `^10||^11`.

Content-display/Views — affects presentation; results respect the View's access (Tailwind must be in the
theme). No access role.

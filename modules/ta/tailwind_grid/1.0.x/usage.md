Tailwind Grid provides a Views style that lays out results using Tailwind CSS grid classes.

---

Tailwind Grid provides a Views style plugin that arranges View results in a grid using Tailwind CSS
grid classes — so a View can be displayed as a responsive Tailwind grid (configurable columns per breakpoint)
without custom templating, for Tailwind-based themes. It is configured at `tailwind_grid.settings`, in the
Views package.

Use it to lay out Views as Tailwind grids. It is a content-display/Views feature affecting presentation; the
results respect the View's access and it has no access-control role. Select the Tailwind Grid style on the
View (Tailwind must be available in the theme).

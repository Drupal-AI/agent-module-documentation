TaaS helps developers create custom tokens.

---

TaaS (Tokens as a Service) **helps developers create custom tokens** — a helper/framework to define new
Token-module tokens with less boilerplate, so custom data becomes available wherever tokens are supported. It
depends on the Token module.

Use it as a developer aid to build tokens. It is a developer/API feature; tokens it defines resolve against data
that should already respect access, and it has no access-control role. Define custom tokens with it.

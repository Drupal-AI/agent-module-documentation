Taxonaut provides a fast taxonomy management UI with tree view and drag-and-drop reordering.

---

Taxonaut is a modern, high-performance taxonomy manager — providing a tree-view interface with drag-and-drop reordering and efficient handling of large vocabularies, so editors can manage taxonomy terms more comfortably than the standard overview, especially for big term hierarchies.

It exposes per-vocabulary permission callbacks (access follows taxonomy permissions). Depends on core `taxonomy`; supports Drupal 10.3+ and 11.

API-based integration with Tugboat QA preview environments.

---

Tugboat QA API is a module to enable API-based integration to Tugboat QA — so Drupal can talk to the Tugboat service (which builds on-demand preview/QA environments per branch or pull request), e.g. to trigger or query preview builds from within the site.

The Tugboat API token is admin-configured; store it securely (env-backed). Supports Drupal 8 through 11.

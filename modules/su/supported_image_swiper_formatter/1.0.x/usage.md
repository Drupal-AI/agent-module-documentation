A Swiper carousel formatter for Supported Image fields.

---

Supported Image Swiper Formatter provides a Swiper formatter for Supported Image fields — so a multi-value Supported Image field renders as a Swiper.js carousel/slider (swipeable, with navigation), for image galleries. Depends on `swiper_formatter` and `supported_image`; supports Drupal 10 and 11.

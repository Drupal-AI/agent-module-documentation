# Super Sitemap — agent index

Provides **taxonomy-oriented customizations on top of Simple Sitemap** (tailor XML sitemap generation). Depends
on `simple_sitemap`, `ultimate_cron`, core `views`. Version **1.0.0-beta2**. Core `^10||^11`.

SEO — the sitemap lists **public** content for search engines (ensure only public content is included; Simple
Sitemap governs inclusion); no access role.

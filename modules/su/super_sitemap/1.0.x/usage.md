Super Sitemap provides customizations for the taxonomy system on the sitemap.

---

Super Sitemap provides **customizations (taxonomy-oriented) on top of Simple Sitemap** — extending how the
XML sitemap is generated, particularly around taxonomy, for specific sitemap requirements. It depends on
Simple Sitemap, Ultimate Cron and core Field/Options/Text/Views, in the Search package.

Use it to tailor the XML sitemap (taxonomy). It is an SEO feature building on Simple Sitemap; the sitemap lists
**public** content for search engines, so ensure only content meant to be public is included (Simple Sitemap
governs inclusion), and it has no access-control role. Configure the sitemap customizations.

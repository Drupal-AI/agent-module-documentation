# Substr Formatter — agent index

A **field formatter that trims string fields from the left or right** (PHP `substr` — display truncated to a
length/offset; stored value unchanged). Depends on core `text`. Version **1.2.0**. Core `^8||^9||^10||^11`.

Content-display/formatter — presentation only; no content/access role.

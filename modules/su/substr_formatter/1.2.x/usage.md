Substr Formatter trims string fields from the left or right using the php substr function.

---

Substr Formatter provides a **field formatter that trims string fields** — cutting characters from the
left or right (via PHP `substr`) so a text field can be displayed truncated to a fixed length/offset without
changing the stored value. It depends on core Text, in the Fields package.

Use it to display a shortened form of a string field. It is a content-display/formatter feature affecting
presentation only (the stored value is unchanged); it has no content or access role. Choose the Substr
formatter on a string field's display.

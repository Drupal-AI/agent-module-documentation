# Supported Image Field — agent index

**A field type for image media with free-form caption and attribution sub-fields**. Depends on core `image`,
`text`. Version **1.0.0-beta1**. Core `^10||^11`.

Content-editing/field — caption/attribution are text sub-fields (output safely); no access role.

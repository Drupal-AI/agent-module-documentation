Supported Image Field provides an image field with caption and attribution sub-fields.

---

Supported Image Field **provides an image field with caption/attribution** — a field type for image media that
adds free-form supporting text (caption) and attribution sub-fields, for properly-credited images. It depends on
core Image and Text.

Use it for captioned/attributed images. It is a content-editing/field feature; caption/attribution are text
sub-fields (subject to normal text handling) and it has no access-control role. Note: caption/attribution is
user-entered text — output safely. Configure the supported-image field.

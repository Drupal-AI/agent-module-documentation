Manage the Supervisor process-control system from the Drupal admin UI.

---

Supervisor enables managing Supervisor through an admin UI — Supervisor is a process-control system that runs and monitors long-running worker processes (e.g. queue workers); this module surfaces its status and controls (start/stop/restart programs) inside Drupal so operators can manage background workers without shell access.

The Supervisor connection/credentials are admin-configured; store them securely (env-backed). Supports Drupal 10.4+ and 11.

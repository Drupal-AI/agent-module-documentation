A baguetteBox.js lightbox formatter for Supported Image fields.

---

Supported Image BaguetteBox Formatter provides a field formatter that integrates Supported Image field output with baguetteBox.js — so images in a Supported Image field open in a baguetteBox lightbox/gallery when clicked. Depends on `supported_image` and `baguettebox`; supports Drupal 10 and 11.

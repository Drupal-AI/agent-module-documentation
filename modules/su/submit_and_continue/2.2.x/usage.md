Submit and continue adds a button to forms that submits the form then redirects back to the form to start filling it out again.

---

Submit and continue adds a "submit and continue" button to forms — after submitting, it redirects back
to a fresh copy of the same form so the user can immediately start a new entry, speeding up repetitive data
entry (like a rapid-add workflow). It is in the Content package.

Use it to speed up repeated form submissions. It is a content-editing/workflow feature affecting post-submit
redirection; the form submission is still governed by the form's normal access/validation, and it has no
access-control role. Enable the button on the relevant forms.

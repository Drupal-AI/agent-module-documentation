# Submit and continue — agent index

Adds a **"submit and continue" button** that submits a form then reloads it for a new entry (rapid repetitive
data entry). Version **2.2.0**. Core `^8||^9||^10||^11`.

Content-editing/workflow — affects post-submit redirection; submission still governed by the form's normal
access/validation. No access role.

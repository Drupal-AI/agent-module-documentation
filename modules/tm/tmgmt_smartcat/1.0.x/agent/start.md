# Smartcat translator (tmgmt_smartcat) — agent index

**TMGMT translator plugin** routing translation jobs to the **Smartcat** platform (content out,
translations back). Depends on `tmgmt`, `tmgmt_file`. Version **1.0.17**. Core `^10||^11`.

Store Smartcat API credentials as secrets; content submitted for translation is sent to the external
Smartcat platform (data-handling consideration). TMGMT governs the workflow.

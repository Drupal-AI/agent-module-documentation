Ticketing Management System (TMS) enables users to create tickets and prioritize them, for support/issue tracking within Drupal.

---

Ticketing Management System (tms) provides a ticketing/support system within Drupal — users can create
tickets (issues/requests), assign priorities, and track them, giving a lightweight support or issue-tracking
workflow on the site. It provides its own permissions.

Use it to run support/help-desk or internal issue tracking in Drupal. The security/privacy-relevant point is
that tickets are user data — they may contain personal information, account details, or sensitive support
content — so gate access with the module's permissions so users see only their own tickets (unless staff),
and staff/agent access is appropriately scoped. Verify the ticket access model matches your intent
(requesters shouldn't read others' tickets). Configure the ticketing workflow and permissions.

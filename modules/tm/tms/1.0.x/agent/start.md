# Ticketing Management System (TMS) — agent index

**Ticketing/support system** — users create + prioritize tickets, track them (help-desk/issue tracking).
Provides permissions. Version **1.0.1**. Core `^10||^11`.

**Privacy:** tickets are user data (may contain PII/sensitive support content) — gate access so users see
only their own (unless staff), scope agent access. Verify the ticket access model matches intent.

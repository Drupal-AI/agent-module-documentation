TMGMT Spreadsheet lets you export/import translations as spreadsheets.

---

TMGMT Spreadsheet provides a **TMGMT translator that exports/imports translation jobs as spreadsheets** —
letting translators work in a downloadable spreadsheet (source/target columns) and upload the completed file
back into the Translation Management Tool. It depends on TMGMT File, in the Translation Management package.

Use it for offline/spreadsheet-based translation workflows. It is a multilingual/integration feature. Data-
handling note: exported spreadsheets contain the **content being translated** (may include unpublished/draft or
sensitive text) — handle the files per your data policy; imported files are parsed back into TMGMT (an uploaded
spreadsheet is untrusted input — the parser handles it). It has no access-control role. Configure the translator
and run jobs.

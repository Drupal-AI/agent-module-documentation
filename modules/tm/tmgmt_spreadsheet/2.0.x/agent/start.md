# TMGMT Spreadsheet — agent index

A **TMGMT translator that exports/imports translation jobs as spreadsheets** (offline translation). Depends on
`tmgmt_file`. Version **2.0.0**. Core `^10.4||^11.1`.

Multilingual/integration — exports contain the **content being translated** (handle per data policy); imported
spreadsheets are untrusted input. No access role.

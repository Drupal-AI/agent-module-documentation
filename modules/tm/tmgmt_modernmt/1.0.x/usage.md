A ModernMT machine-translation plugin for TMGMT.

---

ModernMT TMGMT integrates ModernMT with TMGMT for translation management — so translation jobs can be machine-translated by the ModernMT engine and imported into Drupal through TMGMT, for fast adaptive machine translation.

The ModernMT API key is handled via a Key entity (`key` dependency, env-backed). Depends on `tmgmt` and `key`; supports Drupal 9, 10, and 11.

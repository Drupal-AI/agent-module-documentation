# TMGMT Auto Translate Manager — agent index

**Extends TMGMT with automatic translation** (continuous job). Depends on `tmgmt`, `tmgmt_content`. Provides
permissions. Version **1.0.2**. Core `^10.3||^11`.

Multilingual/integration — **auto-sends content to the TMGMT provider** (egress, incl. drafts); provider
credentials as secrets. Own permissions.

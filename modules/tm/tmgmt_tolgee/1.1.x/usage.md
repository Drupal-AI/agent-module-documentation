A Tolgee-platform translator plugin for TMGMT.

---

TMGMT Tolgee Translator provides TMGMT Translator integration for the Tolgee platform — so translation jobs can be pushed to and pulled from Tolgee (a developer-focused localization platform) through TMGMT.

The Tolgee API key is handled via a Key entity (`key` dependency, env-backed). Depends on `tmgmt`, `key`, and `tagify`; supports Drupal 10.3+ and 11.

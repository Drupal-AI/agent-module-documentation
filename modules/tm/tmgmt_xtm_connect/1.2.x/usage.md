TMGMT XTM Connect localizes Drupal websites with XTM.

---

TMGMT XTM Connect provides a **TMGMT translator for the XTM Cloud** translation-management system — sending
content to XTM for professional translation and receiving completed translations, via the Translation Management
Tool. It depends on TMGMT and core Basic Auth, in the Translation Management package.

Use it to translate content with XTM. It is a multilingual/integration feature. Security/data handling: it
**sends content to the external XTM Cloud** (data egress — confirm acceptable, including unpublished/draft or
sensitive text) and authenticates with **XTM API credentials** (store as **secrets** — env/Key — over HTTPS; the
Basic Auth dependency is for the callback/API). It has no access-control role. Configure the XTM credentials and
TMGMT provider.

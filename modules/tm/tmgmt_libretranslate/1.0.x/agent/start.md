# LibreTranslate Translator (tmgmt_libretranslate) — agent index

**TMGMT translator plugin for LibreTranslate** (open-source, self-hostable machine translation). Depends on
`tmgmt`. Config at `entity.tmgmt_translator.collection`. Version **1.0.0**. Core `^9||^10||^11`.

**Security:** store any LibreTranslate API key as a **secret**; HTTPS endpoint; self-hosting keeps content
in-house (data-handling advantage). Uses standard HTTP. TMGMT governs the workflow.

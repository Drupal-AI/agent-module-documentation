# Translation Centre (CdT) — agent index

**TMGMT translator for the EU Translation Centre (CdT, cdt.europa.eu)**. Depends on `tmgmt`. Version
**8.x-1.10**. Core `^10||^11`.

cURL options for CdT API requests are configurable via the `tmgmt_cdt.curl_options` config. Store the
`api_password`/`api_access_token` credentials as secrets.

TMGMT Supertext is a Supertext translator plugin for the Translation Management Tools.

---

TMGMT Supertext adds a **TMGMT translator that uses Supertext** — a professional translation service — so
content queued in TMGMT (Translation Management Tool) can be sent to Supertext for translation and returned. It
depends on the TMGMT module, in the Translation Management package.

Use it to route TMGMT translations through Supertext. It is a multilingual/integration feature. Security/data
handling: it sends the **content to be translated to Supertext** (external data egress — confirm acceptable
for the content) and authenticates with **Supertext API credentials** (store as **secrets**, over HTTPS). It
has no access-control role. Configure the Supertext credentials and translator.

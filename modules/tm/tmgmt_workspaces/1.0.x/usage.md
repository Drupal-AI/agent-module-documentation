TMGMT Workspaces provides Workspaces integration for TMGMT.

---

TMGMT Workspaces **integrates TMGMT with Workspaces** — so translation jobs can be created and applied
within a Workspace (staging translations before publishing to Live), using Workspaces and Workspace Extra (wse).
It depends on core Workspaces, TMGMT and WSE, in the Translation Management package.

Use it to translate content in a workspace. It is a multilingual/workflow feature; translations follow TMGMT's
and Workspaces' own access, and it has no access-control role. Configure translation in workspaces.

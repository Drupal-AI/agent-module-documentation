Curate article text from a URL using the Python Newspaper3k library.

---

Migrate Process Newspaper3k allows you to use the Python3 Newspaper3/4k library to curate text from an endpoint — a migrate process plugin that runs Newspaper3k to extract the main article text (stripping boilerplate) from a URL, so a migration imports clean article content.

It shells out to Python/Newspaper3k (which must be installed) and fetches URLs server-side; run in the trusted migration context. Depends on core `migrate`; supports Drupal 8 through 11.

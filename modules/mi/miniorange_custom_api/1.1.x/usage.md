Create custom API endpoints to extract customised data from the database.

---

miniOrange Custom API helps create custom API endpoints for extracting customised data from the database — an admin defines endpoints that return chosen data (e.g. selected fields/entities) as an API response, so a frontend/integration can fetch exactly the data it needs.

**Security:** because these endpoints expose database data, configure each endpoint's access/authentication carefully and never expose sensitive data or run unauthenticated endpoints — the risk of over-exposure is on the endpoint configuration. Supports Drupal 10 and 11.

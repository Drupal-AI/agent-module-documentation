Use a specific language's translation when another language lacks one.

---

Missing Translation Fallback Language lets you set a specific language translation to be used when a language misses a translation — so instead of falling back to English (or the source), untranslated content/strings in language A can fall back to language B of your choice. Depends on core `language`; supports Drupal 8 through 11.

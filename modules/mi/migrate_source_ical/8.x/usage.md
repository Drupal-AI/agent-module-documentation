A migrate source for iCal/Google Calendar data.

---

Migrate Source iCal migrates data from calendars like Google Calendar or `.ical` files — a migrate source plugin that reads iCalendar events and exposes them as migration rows, so calendar events can be imported into Drupal content. Depends on core `migrate`; supports Drupal 10 and 11.

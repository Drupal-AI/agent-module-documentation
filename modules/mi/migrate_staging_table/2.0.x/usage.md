Migrate into, out of, and look up from a database staging table.

---

Migrate Staging Table provides a generic method to migrate data into, out of, and look up from a database staging table — so a migration can stage intermediate data in a dedicated table (write, read back, and use for lookups), useful for multi-pass migrations and cross-referencing. Depends on core `migrate`; supports Drupal 9, 10, and 11.

A migrate destination plugin that stores data in Drupal cache.

---

Migrate Destination Cache provides a migrate destination plugin that stores data in Drupal cache — so a migration can write its rows into a cache bin (instead of entities/DB tables), useful for staging fetched/transformed data for later use by other processes. Depends on core `migrate`; supports Drupal 9, 10, and 11.

Microformats provides microformats markup support.

---

Microformats **adds microformats markup support** — annotating content with microformats (h-card, h-entry,
h-event, etc.) classes so machines/indexers can extract structured data (people, posts, events) from the HTML.
It depends on core Block, provides its own permissions, in the Microformats package.

Use it to add microformats markup for machine-readability. It is an SEO/content-display feature adding
class-based metadata; it reflects on-page content and has no content or access role beyond its permission.
Configure the microformats markup.

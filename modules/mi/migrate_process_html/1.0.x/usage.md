Fetch a URL and render it as an HTML string in a migration.

---

Migrate Process HTML allows a URL to be fetched and then rendered as an HTML string — a migrate process plugin that retrieves a remote page and returns its HTML, so a migration can pull in content from an external URL as part of a row's processing.

Because it fetches URLs server-side, ensure migration source data (the URLs) is trusted; it's run in the migration context (admin/CLI). Depends on core `migrate`; supports Drupal 8 through 11.

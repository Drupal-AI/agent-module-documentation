# Migrate Default If No Stored Value — agent index

A **Migrate process plugin that applies a default only when no value was previously stored** (preserve edited
values on re-run). Depends on core `migrate`. Version **1.1.0**. Core `^9||^10||^11`.

Developer/migration — processes data with migration privileges; no access role.

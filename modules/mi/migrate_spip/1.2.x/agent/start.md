# Migrate SPIP — agent index

Provides a **SPIP rich-text-to-HTML converter** for migrations from the SPIP CMS (SPIP markup → HTML).
`migrate_spip_examples`/`_plus`/`_ui` submodules. Version **1.2.0**. Core `^10.3||^11||^12`.

Developer/migration utility — transforms text during import (converted content then filtered by the
destination text format); no content/access role.

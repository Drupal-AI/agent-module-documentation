Migrate SPIP provides a SPIP rich text converter into HTML.

---

Migrate SPIP provides a converter for SPIP rich text — turning SPIP's markup syntax into HTML during
migrations, so content migrated from a SPIP CMS renders correctly in Drupal. It ships `migrate_spip_examples`,
`migrate_spip_plus` and `migrate_spip_ui` submodules, in the Migration package.

Use it when migrating content from SPIP. It is a developer/migration utility that transforms text during
import; the converted content becomes Drupal content (which is then filtered by the destination text format).
It has no content or access role. Use the converter/process plugin in the SPIP migration.

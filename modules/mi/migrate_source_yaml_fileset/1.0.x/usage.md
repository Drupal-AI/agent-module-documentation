Migrate Source YAML Fileset reads migration source data from multiple YAML files.

---

Migrate Source YAML Fileset provides a migrate source plugin that reads from a set (fileset) of YAML files — so content defined across multiple YAML files can be used as a migration source, useful for config-as-code or structured content seeding. It's a developer/migration tool.

It's a migration source utility with no content or access role of its own. Depends on core `migrate`; supports Drupal 10 and 11.

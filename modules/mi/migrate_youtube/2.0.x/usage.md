A migrate source to import YouTube videos and playlists.

---

Migrate Youtube provides a migrate_plus source plugin to import videos and playlists to any entity type — pulling YouTube video/playlist data (via the YouTube API) as migration rows so a site can create media/content from a channel or playlist.

The YouTube API key is admin-configured and should be stored securely (env-backed). Depends on core `migrate` and `migrate_plus`; supports Drupal 10 and 11.

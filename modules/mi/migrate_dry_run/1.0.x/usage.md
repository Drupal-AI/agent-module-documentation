A dry-run mode for Migrate Tools migrations.

---

Migrate Dry run adds a dry-run mode for migrations (an addition to Migrate Tools) — so a migration can be executed without actually writing/saving anything, letting developers validate that a migration runs and produces expected results before committing changes. Depends on `migrate_tools`; supports Drupal 10, 11, and 12.

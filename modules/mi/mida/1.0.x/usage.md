Mida injects Mida A/B testing script.

---

Mida **injects the Mida A/B testing JavaScript snippet** — adding the Mida experimentation script so the
third-party Mida service can run A/B tests/experiments on the site's pages. It is in the Custom package.

Use it to run Mida A/B tests. It is a marketing/experimentation feature. Privacy/data handling: it loads a
**third-party experimentation script** that can modify page content client-side and may collect visitor data /
set cookies (Mida is external) — disclose it and integrate with consent tooling where required; the script has
access to the page it runs on. It has no content or access role. Configure the Mida snippet/site id.

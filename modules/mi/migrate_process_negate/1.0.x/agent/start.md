# Migrate Process Negate — agent index

A Migrate **process plugin that negates (logically inverts) a source value** (true→false / 1→0 during a
migration). Depends on core `migrate`. Version **1.0.3**. Core `^8||^9||^10||^11`.

Developer/migration — transforms values under the migration's control; no content/access role.

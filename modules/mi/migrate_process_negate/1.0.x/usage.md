Migrate Process Negate provides a migrate process plugin for negating a source value.

---

Migrate Process Negate provides a **Migrate process plugin that negates a source value** — logically
inverting a boolean-ish value (true→false, 1→0) during a migration, useful when a source's flag has the
opposite sense to the destination field. It depends on core Migrate, in the Migration package.

Use it in migration process pipelines to invert a value. It is a developer/migration feature; it transforms
values during import under the migration's control and has no content or access role. Use the plugin in a
migration process.

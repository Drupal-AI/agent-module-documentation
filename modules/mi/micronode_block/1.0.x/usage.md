Micronode Block derives blocks for micronodes.

---

Micronode Block **derives blocks for Micronode items** — exposing micronodes (lightweight reusable content
fragments) as placeable blocks, with Entity Browser and Inline Entity Form integration for selecting/creating
them. It depends on the Micronode module plus Entity Browser, core Views and Inline Entity Form.

Use it to place micronodes as blocks. It is a site-building/content-display feature; micronode content follows
its own access on view and it has no access-control role. Place the micronode blocks.

MiniKanban is a small project management tool.

---

MiniKanban is a **small project-management / kanban-board tool** — organizing tasks as cards across columns
(to-do/doing/done), with rich-text (CKEditor 5) descriptions, mentions, colors and drag-and-drop, for lightweight
project tracking. It depends on core Editor, CKEditor 5, Options, Views plus Entity, Markdown, CKEditor Mentions,
Editor File, Color Field and jQuery UI, provides its own permissions, in the Custom package.

Use it for simple in-Drupal project management. It is a content/collaboration tool. Security note: cards use a
**rich-text (CKEditor 5) editor** and **mentions** — content is authored by users, so it flows through the text
format's filtering (keep the format's allowed tags sane), and mentions can notify users — gate board/card access
via its permissions to the intended team. It has no broad access-control role beyond its permissions. Configure
the boards and permissions.

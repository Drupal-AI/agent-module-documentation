# MiniKanban — agent index

A **small project-management / kanban-board tool** (cards/columns, CKEditor 5 descriptions, mentions, drag-drop).
Depends on core `editor`, `ckeditor5`, `options`, `views` plus `markdown`, `ckeditor_mentions`, `color_field`,
jQuery UI. Provides permissions. Version **1.0.x** (dev). Core `^10||^11`.

Content/collaboration — cards use a rich-text editor + mentions (content flows through the text format's
filtering; gate board/card access to the team). No broad access role beyond permissions.

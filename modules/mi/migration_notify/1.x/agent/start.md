# Migration Notify — agent index

Sends **notifications based on migration status/outcome** (success/failure/errors) — alerts the team to
migration results. Depends on `migrate` (>=8.3). Config at `migration_notify.settings`. Version **1.x**
(dev). Core `^8||^9||^10||^11||^12`.

Developer/migration ops tool — ensure notification recipients are appropriate. No content-access role.

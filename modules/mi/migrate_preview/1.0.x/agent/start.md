# Migrate Preview — agent index

**A tool to display a preview of a migration** (source→destination mapping before running). Depends on `migrate`,
`migrate_tools`. Version **1.0.0-alpha2**. Core `^10||^11`.

Developer/migration — previews mapped data (may show sensitive source data; use in dev); no content/access role.

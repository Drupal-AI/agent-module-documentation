Migrate Preview displays a preview of a migration before running it.

---

Migrate Preview **displays a preview of a migration** — showing how source rows would map to destination
entities before actually running the migration, so builders can verify mappings/transforms. It depends on core
Migrate and the Migrate Tools module.

Use it to validate migrations before import. It is a developer/migration tool; it previews mapped data
(developer-facing) and has no content or access role. Note: previews may render **source data** (which can be
sensitive) — use in a controlled/dev context. Configure and run the preview.

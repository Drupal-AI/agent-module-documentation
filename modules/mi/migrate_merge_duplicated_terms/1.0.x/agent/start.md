# Migrate - Merge duplicated terms — agent index

During migration, **merges duplicate taxonomy terms into one and maps the other source IDs to it** (dependent
migrations resolve correctly, no duplicates). Version **1.0.2**. Core `^9.1||^10||^11`.

Developer/migration utility — processes migration mappings; no content/access role.

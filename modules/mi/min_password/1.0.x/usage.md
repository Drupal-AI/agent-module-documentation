Min Password allows setting a minimum password length requirement for users on the site.

---

Min Password lets administrators set a minimum password length requirement for user accounts — a
simple password policy enforcing that passwords meet a configured minimum length. It is in the
Administration package.

Use it to enforce a basic minimum password length. It is a security/password-policy feature. Note it is a
*minimal* policy tool (length only); for comprehensive password policy (character types, history, expiry,
username-in-password checks), the Password Policy module is the fuller solution — min_password covers just
the length requirement. Set the minimum length to match your security policy (longer is better; modern
guidance favors length over complexity).

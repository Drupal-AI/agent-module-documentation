# Min Password — agent index

Sets a **minimum password length** requirement for user accounts (simple length-only policy). Version
**1.0.5**. Core `^9||^10||^11`.

Security/password-policy (length only) — for fuller policy (character types/history/expiry/username checks)
use **Password Policy**. Set the minimum to your policy (favor length).

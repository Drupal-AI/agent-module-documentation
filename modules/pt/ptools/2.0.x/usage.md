A library of utility/helper classes for other Drupal modules.

---

PTools is a library of utility classes — a developer dependency that other modules build on, bundling reusable helper classes (and a `ptools_queue` submodule) so contrib/custom code can share common utilities rather than re-implementing them. It ships no site-facing features of its own; you enable it because another module requires it. Supports Drupal 10 and 11.

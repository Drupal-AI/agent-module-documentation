Reciprocal Rank Fusion to combine vector and keyword search results.

---

RRF Search implements Reciprocal Rank Fusion for combining vector and traditional search — merging the ranked result lists from a vector/semantic search and a keyword/Search API search into one blended ranking (via the RRF algorithm), so hybrid search returns the best of both. Depends on `search_api` and `ai:ai_search`; supports Drupal 10 and 11.

Shared code for the Open Government Community Builder.

---

OGCB Suite contains all non-separately-contributed code necessary to run a site using the Open Government Community Builder (OGCB) — the glue module (config, helpers, integrations) that ties the OGCB distribution's components together. It's a distribution base module. Supports Drupal 10 and 11.

OG Migrate provides migration helper code for Organic Groups.

---

OG Migrate **provides migration helper code for Organic Groups (OG)** — process plugins/utilities to migrate
OG group and membership data (e.g. from older OG versions or other systems) into current OG. It depends on core
Migrate and the OG module, in the Organic Groups package.

Use it when migrating OG data. It is a developer/migration tool run by privileged users; it processes group/
membership data with migration privileges (validate sources; run as trusted operator) and it has no access-control
role. Use it in an OG migration.

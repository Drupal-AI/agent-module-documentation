Update Manager Project Security Status adds security coverage status to core's Available Updates report.

---

Update Manager Project Security Status **adds security-coverage status to the Available Updates report** —
flagging which installed projects are covered by the Drupal security-advisory policy vs unsupported/uncovered,
so admins can spot modules that won't receive security fixes. It depends on core Update, in the Security
package.

Use it to see security-coverage gaps in your module set. This is a **security-positive** administration feature:
surfacing security-unsupported modules helps you avoid running code that won't get security updates (a real
risk). It reflects the update/coverage data and has no access-control role; the Available Updates report it
augments is already admin-gated. Review the security-coverage status.

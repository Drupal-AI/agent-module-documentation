Image Lazy Loader adds the lozad lazy-loading script to image fields, deferring image loading until they are near the viewport.

---

Image Lazy Loader applies the lozad.js lazy-loading library to image fields, so images load only as
they approach the viewport rather than all at once — reducing initial page weight and speeding up load,
especially on image-heavy pages. It depends on core Image.

Use it to improve performance on pages with many images below the fold. It is a performance/front-end
feature affecting how images load, not content or access. (Modern browsers also support native
`loading="lazy"`; this module uses lozad for finer control/older-browser coverage.) Apply it to the
relevant image fields' display.

# Image Lazy Loader — agent index

Adds the **lozad.js lazy-loading** script to **image fields** — images load as they near the viewport
(lighter initial load on image-heavy pages). Depends on core `image`. Version **2.2.0**. Core
`^9||^10||^11`.

Performance/front-end (affects image loading, not content/access). Complements native
`loading="lazy"`.

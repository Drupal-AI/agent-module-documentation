Add a description to image styles in the admin listing.

---

Image Style Description adds a Description column to the Image styles admin listing and lets site builders set a description when adding or editing an image style — so teams can document what each image style is for (e.g. 'hero 16:9', 'thumbnail square') directly in the admin UI. Depends on core `image`; supports Drupal 11.

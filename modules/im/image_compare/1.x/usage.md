Image Compare provides an accessible before/after image-comparison slider formatter, with media and responsive submodules.

---

A before/after slider — drag to reveal one image over another — is a common way to show comparisons (renovations, edits). Image Compare provides an accessible comparison slider formatter, with `image_compare_media`, `image_compare_responsive` and media-responsive submodules. It is a display formatter with no security surface. Its selling point is accessibility, so confirm the slider's keyboard operation meets requirements, and that the two images are appropriately sized.

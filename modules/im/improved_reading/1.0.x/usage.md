Improved reading bolds the leading part of words to aid reading, toggleable per user.

---

Improved reading changes text display to improve reading speed using a Bionic-Reading-like method — emphasizing the leading characters of words so the eye can move faster through text. Users with the `use improved_reading` permission can toggle it.

It's an accessibility/reading-aid feature. Permissions cover configuration (`administer improved_reading configuration`) and use (`use improved_reading`). Supports Drupal 9, 10, and 11.

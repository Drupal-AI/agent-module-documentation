Image Utilities provides developer-oriented improvements to the image system.

---

Image Utilities provides **developer-oriented improvements to the core Image system** — helper utilities/
APIs around image handling (styles, derivatives, metadata) to make working with images easier for developers.
It depends on core Image.

Use it as a developer aid for image handling. It is a developer/media feature; it works with images that follow
core file/image access and it has no access-control role. Use its utilities in your code.

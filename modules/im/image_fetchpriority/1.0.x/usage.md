Image Fetchpriority adds fetchpriority support to Image and Responsive Image fields.

---

Image Fetchpriority **adds the fetchpriority attribute to images** — letting builders set `fetchpriority`
(high/low/auto) on the built-in Image and Responsive Image field formatters, to hint the browser about image
loading priority (LCP optimization). It works on core 10–11.

Use it to prioritize key images. It is a performance/media feature; it adds an HTML attribute and has no content or
access role. Configure fetchpriority on the image formatter.

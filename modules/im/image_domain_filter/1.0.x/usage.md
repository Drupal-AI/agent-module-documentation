Image Domain Filter allows only images from allowlisted domains in filtered text.

---

Image Domain Filter provides a text-format filter that restricts `<img>` sources to a configured allowlist of trusted hosts — so images embedded in rich text can only load from approved domains, mitigating tracking pixels, mixed-content, and third-party image inclusion in user-generated content.

It's a defensive filter (allowlist-based) configured in admin settings; enable it on text formats used for untrusted input. Supports Drupal 10 and 11.

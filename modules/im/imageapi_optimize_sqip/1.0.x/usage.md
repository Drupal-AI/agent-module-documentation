ImageAPI Optimize - SQIP provides an SVG low-quality-image-placeholder processor for ImageAPI Optimize.

---

ImageAPI Optimize - SQIP **provides an SQIP processor** — generating an SVG-based low-quality image
placeholder (a primitive-shape SVG preview) that shows while the full image loads, as a processor for ImageAPI
Optimize. It depends on core File and the ImageAPI Optimize module.

Use it to add SVG placeholders. It is a performance/media feature; it produces SVG placeholder derivatives and has
no content or access role. Configure the SQIP processor in an optimize pipeline.

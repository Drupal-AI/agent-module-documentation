Import Maps provides an API for modules to declare JS import maps.

---

Import Maps provides an **API for modules to declare JavaScript import maps** — letting modules define
`importmap` entries so front-end ES-module imports resolve to the right (bundled/CDN/local) URLs, for modern JS
module workflows. It works across core 9+.

Use it as a developer API for JS import maps. It is a developer/front-end feature; import maps map module
specifiers to URLs (ensure mapped sources are trusted, since they define what JS the browser loads) and it has
no content or access role. Declare import maps from your module.

# Image Zoom (imagezoom) — agent index

Field **formatter** that **magnifies an image on hover** (lens effect); submodule `imagezoom_gallery`.
Version **dev**. Core `^8.8 || ^9 || ^10 || ^11`.

Display enhancement, no security surface. The classic e-commerce product-image zoom. **Use a
high-resolution source** — hover-zoom magnifies into the real image, so a small source zooms to
blur.

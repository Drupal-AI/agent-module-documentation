Images Optimizer provides a simple way to optimize uploaded images.

---

Images Optimizer provides a **simple way to optimize uploaded images** — compressing/optimizing image
files (reducing size for faster loading) as part of the upload/processing flow. It depends on core File, in
the Performance package.

Use it to shrink uploaded images for performance. It is a performance/media feature that processes uploaded
files (often via image-optimization tooling/libraries); ensure any external optimizer binaries it uses are
present and trusted, and it has no content or access role. Configure the optimization settings.

Image Library Widget provides a widget allowing users to upload or choose an existing image from a library.

---

Image Library Widget provides an image field widget that lets editors either **upload a new image** or
**choose an existing one from a reusable library** — promoting image reuse instead of re-uploading duplicates.
It is built on Media and Views (it ships a media image field and a library View). It depends on core Media and
Views.

Use it to give editors a browse-and-reuse image picker. It is a media/content-editing feature; the images are
Media entities (access follows core media/file access) and it has no access-control role. Set the widget on an
image/media field.

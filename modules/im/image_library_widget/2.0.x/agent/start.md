# Image Library Widget — agent index

An image field widget to **upload a new image OR pick an existing one from a reusable library** (image reuse
vs duplicate uploads). Built on Media + Views. Depends on core `media`, `views`. Version **2.0.0-alpha4**.
Core `^10.2||^11`.

Media/content-editing — images are Media entities (access follows core media/file access); no access role.

Image Background Formatter prints a div with the image applied as a background.

---

Image Background Formatter provides an image-field formatter that renders the image as the CSS
background of a `<div>` (rather than an `<img>` tag) — useful for hero/banner sections and CSS-driven layouts
where the image should be a background. It is in the Other package.

Use it where an image field should render as a background image. It is a content-display/formatter feature;
the image is rendered (as a background) respecting normal file access, and it has no access-control role.
Select the background formatter on the image field.

Convert images to WebP and <img> to responsive <picture>.

---

Image Processor processes images to WebP format and converts `<img />` tags to `<picture>` elements — so images are served in the smaller WebP format with a fallback, improving page-load performance without editors changing how they add images. It's a performance/media enhancement. Supports Drupal 9, 10, and 11.

An integration layer between the Immoweb API and Drupal.

---

Immoweb API Client provides an integration layer between the Immoweb API and Drupal modules — a base client for connecting to Immoweb (a Belgian real-estate platform) so other modules can fetch property listings/data, handling authentication and requests.

The Immoweb API credentials are admin-configured and should be stored securely (env-backed), never committed. It's a connectivity library. Supports Drupal 8.8 through 11.

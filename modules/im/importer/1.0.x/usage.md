A framework for importing files into content via extract/transform/save pipelines.

---

Importer is a framework for importing files (e.g. PDFs) into content via configurable extract/transform/save pipelines — so a site can turn uploaded documents into structured content (nodes/paragraphs) through a pipeline of pluggable extract, transform and save steps. Depends on core `node`, `views`, and `paragraphs`; supports Drupal 10.2+ and 11.

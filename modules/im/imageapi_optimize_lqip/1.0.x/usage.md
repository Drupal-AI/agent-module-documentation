ImageAPI Optimize - LQIP provides a low-quality-image-placeholder processor for ImageAPI Optimize.

---

ImageAPI Optimize - LQIP **provides an LQIP processor** — generating a tiny low-quality image placeholder that
shows while the full image loads (improving perceived performance), as a processor for ImageAPI Optimize. It
depends on core File and the ImageAPI Optimize module.

Use it to add LQIP placeholders. It is a performance/media feature; it produces placeholder derivatives and has no
content or access role. Configure the LQIP processor in an optimize pipeline.

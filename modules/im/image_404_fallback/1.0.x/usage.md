Image 404 Fallback replaces 404 image requests with a fallback image.

---

Image 404 Fallback **serves a fallback image when a requested image returns 404** — so a broken/missing
image URL renders a placeholder image instead of a broken-image icon, keeping layouts intact when files are
missing (e.g. after a migration or a purged derivative).

Use it to gracefully handle missing images. It is a media/display resilience feature; it responds to image
404s with a configured fallback and has no content or access role. Configure the fallback image.

# Image 404 Fallback — agent index

Serves a **fallback image when a requested image file is missing (404)** (placeholder vs broken-image icon —
keeps layouts intact after migrations/purged derivatives). Version **1.0.2**. Core `^10.3||^11`.

Media/display resilience — responds to image 404s with a configured fallback; no content/access role.

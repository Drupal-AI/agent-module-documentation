# IMCE Field Widget — agent index

A **single-value media field widget with IMCE file-selection** (modal dialog, required validation,
translation support). Depends on core `media`, `imce`. Version **1.0.2**. Core `^9||^10||^11`.

Content-editing/selection — selected files are managed files governed by **IMCE's profile/folder access** +
normal file access; no access role.

IMCE Field Widget provides a clean media field widget with IMCE integration for single-value media fields, with a modal file-selection dialog.

---

IMCE Field Widget provides a media-field widget backed by IMCE (the file manager) — a clean, single-value
media field widget with a modal file-selection dialog, required-field validation and translation support, for
an intuitive file-selection experience. It depends on core Media (and IMCE), in the Custom package.

Use it for IMCE-based media field selection. It is a content-editing/upload-and-selection feature; the
selected files are managed files governed by IMCE's and Drupal's normal file access (IMCE's own profile/
folder access controls what a user can browse/select), and it has no access-control role. Configure the IMCE
widget on the media field.

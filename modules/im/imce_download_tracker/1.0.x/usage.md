IMCE Download Tracker tracks file download counts and shows badges in IMCE.

---

IMCE Download Tracker **tracks file download statistics in IMCE** — counting downloads of files and showing
download-count badges next to file names in the IMCE file manager, for insight into file usage. It depends on the
IMCE module and core File and User.

Use it to see file download counts in IMCE. It is a file-management/statistics feature; it records download counts
(admin/editor-facing in IMCE) and has no access-control role. Note: file access itself is unchanged — this only
tracks and displays counts. Configure download tracking.

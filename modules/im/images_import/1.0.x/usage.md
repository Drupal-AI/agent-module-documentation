Import single or multiple images via CSV.

---

Images Import imports single or multiple images via CSV — so a site builder can bulk-create image media/files by uploading a CSV that references the images (and metadata), avoiding manual one-by-one uploads for large image sets. Supports Drupal 10 and 11.

Image Pointer enables the creation of a map for content with clickable pointers.

---

Image Pointer lets you build **interactive image maps with clickable pointers** — placing markers on an
image (e.g. a map of distributors/locations) that link to or reveal related content when clicked. It provides
its own permissions, core 8+.

Use it to create clickable image/location maps. It is a content-display feature; the pointer content is
admin/editor-authored and it has no access-control role beyond its permission. Configure the image and
pointers.

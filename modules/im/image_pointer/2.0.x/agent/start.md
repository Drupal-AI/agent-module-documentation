# Image Pointer — agent index

Creates **interactive image maps with clickable pointers** (e.g. a distributor/location map — markers link to/
reveal content). Provides permissions. Version **2.0.0**. Core `>=8`.

Content-display — pointer content is admin/editor-authored; no access role beyond permission.

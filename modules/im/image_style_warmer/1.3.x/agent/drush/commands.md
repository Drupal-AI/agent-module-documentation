# Drush commands & running the queue

## `image-style-warmer:warm-up` (alias `isw:wu`)

Defined in `ImageStyleWarmerCommands` (registered via `drush.services.yml`). Loads **every**
file entity and runs a batch that warms each file with the **Initial image styles** config
(`initial_image_styles`). Use it to back-fill derivatives for images that existed before you
configured the module, or after adding a new image style.

```bash
drush image-style-warmer:warm-up
drush isw:wu           # same thing
```

Notes:
- It uses the `initial_image_styles` list only. Styles that are in `queue_image_styles` but not
  in `initial_image_styles` are not generated by this command — run the queue for those.
- It processes all files via a Drush batch (`drush_backend_batch_process()`); on an empty site
  it prints "No files found."

## Running the cron queue

Queue styles (`queue_image_styles`) are generated by the `image_style_warmer_pregenerator`
QueueWorker on cron. Trigger it manually with core Drush:

```bash
drush queue:run image_style_warmer_pregenerator
# or just run cron
drush cron
```

The worker has a per-run time budget of 60 seconds (`cron = {"time" = 60}` in the plugin
annotation), so a large backlog drains over several cron runs.

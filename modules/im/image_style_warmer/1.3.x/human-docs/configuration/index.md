# Configuration

Image Style Warmer has a single settings form where you choose which image styles to
pre-generate, and two ways to warm images that already exist.

## Open the settings form

1. Log in as a user with the **Administer site configuration** permission (an
   administrator by default).
2. Go to **Configuration → Development → Performance → Image Style Warmer**, or navigate
   directly to `/admin/config/development/performance/image-style-warmer`.

## The two style lists

The form shows two groups of checkboxes, one box per image style defined on your site:

- **Initial image styles** — the styles ticked here are generated **synchronously**, in
  the same request, whenever a permanent image file is saved (uploaded or updated). Use
  this for fast, lightweight styles such as thumbnails and teasers, where generating them
  on save adds negligible time.
- **Queue image styles** — the styles ticked here are added to a background queue
  (`image_style_warmer_pregenerator`) and generated later, on the next **cron** run. Use
  this for heavy or expensive styles — large hero crops, responsive image sets, WebP
  conversions — so they don't slow down the save.

Tick the styles you want in each list and click **Save configuration**. Only the ticked
styles are stored; unticking a style removes it from the list.

A few things worth knowing:

- The lists apply **site-wide** to every uploaded image file — there is no per-field
  configuration.
- Only **permanent** files that validate as images are warmed; temporary files are
  skipped.
- Warming is **idempotent** — a derivative that already exists on disk is never rebuilt.

## Warming images that already exist

The settings above only affect images going forward. To back-fill derivatives for images
that were uploaded *before* you configured the module (or after you add a new style), use
the module's Drush command:

```bash
drush image-style-warmer:warm-up
drush isw:wu           # the same command, short alias
```

This loads every existing file and warms it using the **Initial image styles** list. Note
that it only uses the Initial list — styles that are only in the Queue list are not
generated by this command; run the queue for those.

## Running the queue

The **Queue image styles** are generated by a cron queue worker. They process
automatically whenever cron runs, but you can trigger them manually:

```bash
drush queue:run image_style_warmer_pregenerator
# or simply run cron:
drush cron
```

The worker has a time budget of about 60 seconds per cron run, so a large backlog is
drained gradually over several runs.

## Bulk-warming from a list (Views Bulk Operations)

The module also ships two action plugins for use with Views Bulk Operations, so editors
can warm existing content from an admin list:

- **Warmup image styles of files** — for a Views list of files.
- **Warmup image styles of media entities** — for a Views list of media entities.

Add the matching action to a VBO-enabled view, select the rows, and run it to pre-generate
their derivatives on demand.

Image Media Migrate migrates image fields into the media library.

---

Image Media Migrate helps convert legacy **plain image fields** into **Media** — moving existing image
field values into Media (image) entities and references so the content uses the media library instead of bare
image fields. It depends on core Media and Image, in the Media package.

Use it during a media migration to convert image fields to media references. It is a media/migration developer
tool run by admins; it transforms existing content (back up first, as with any content migration) and follows
core media/file access — it has no access-control role. Run the migration to convert the fields.

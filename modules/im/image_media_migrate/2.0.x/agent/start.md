Migrates plain **image fields into Media (image) references / the media library** (convert legacy image fields
to media). Depends on core `media`, `image`. Version **2.0.1**. Core `^8||^9||^10||^11`.

Media/migration developer tool — transforms existing content (back up first); follows core media/file access;
no access role.

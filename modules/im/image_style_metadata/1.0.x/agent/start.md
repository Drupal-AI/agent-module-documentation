# Image Style Metadata — agent index

**Stores metadata (dimensions, BlurHash, …) of derivative images** from image styles; exposes it (incl.
JSON:API). Depends on core `image`, `config`. Provides permissions. Version **1.0.0-beta11**. Core `^10||^11`.
Submodules: `blurhash_image_style_metadata`, `jsonapi_image_style_metadata`.

Media/decoupled — metadata derived from access-respecting images; no access role.

OData Client provides a client for querying OData services from Drupal.

---

OData Client provides a connection to an OData server — the open protocol for querying and updating data via REST-like APIs (used by Microsoft and enterprise systems) — so Drupal can consume OData services to read (and potentially write) data from external business systems.

OData endpoint/credentials should be stored securely (env-backed). It's an integration/developer library with no content or access role of its own. Supports Drupal 9, 10, and 11.

Twig IntlExtension provides the Twig IntlExtension (twig/intl-extra) in Drupal, enabling Intl-based Twig filters/functions in templates.

---

Twig IntlExtension makes the Twig IntlExtension (`twig/intl-extra`) available in Drupal, so templates
can use its internationalization filters/functions — formatting numbers, currencies, dates and names
according to locale (e.g. `format_currency`, `format_datetime`, `country_name`). It fills the gap where
these Intl-based Twig helpers aren't available by default. It is in the Twig package.

Use it in themes/templates that need locale-aware formatting via Twig. It is a theming/developer
integration exposing the Intl extension; it has no content or access behaviour. Use the extension's
filters/functions in Twig where internationalized formatting is required.

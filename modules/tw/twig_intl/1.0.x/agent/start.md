# Twig IntlExtension — agent index

Provides the **Twig IntlExtension (`twig/intl-extra`)** in Drupal — locale-aware Twig
filters/functions (`format_currency`, `format_datetime`, `country_name`, etc.). Version
**1.0.0-rc3**. Core `^10||^11`.

Theming/developer integration (no content/access). Use the Intl filters in Twig for internationalized
formatting.

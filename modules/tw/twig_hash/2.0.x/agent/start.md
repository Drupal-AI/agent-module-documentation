# Twig Hash — agent index

Provides **Twig functions for hashing values** in templates (cache keys, deterministic IDs, email
hashing) — no preprocess needed. Version **2.0.0**. Core `^8.8||^9||^10||^11`.

Theming/developer utility (no content/access). Template hashing is for non-security IDs — **not** a
security control for secrets.

Twig Toolkit provides extra Twig functions, filters and token parsers.

---

Twig Toolkit **provides extra Twig extensions** — a collection of additional Twig functions, filters and token
parsers to make theming more expressive. It works on core 10–11.

Use it for richer Twig theming. It is a theming/developer feature; it adds Twig capabilities and has no content or
access role. Use the extensions in templates.

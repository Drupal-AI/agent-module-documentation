# Twitter Filter — agent index

A text-format **filter that processes Twitter/X embeds/content for display** (convert tweet/X URLs/markers →
embeds). Version **2.0.3**. Core `^8.8||^9||^10||^11`.

Content-display/text-filter — transforms content on output; embedded content loads Twitter/X's third-party
script (privacy/consent). No access role.

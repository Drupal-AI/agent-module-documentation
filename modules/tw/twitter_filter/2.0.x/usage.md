Twitter Filter filters content in preparation for display.

---

Twitter Filter provides a text-format filter that processes Twitter/X-related content for display —
typically converting tweet/X URLs or embed markers in content into proper Twitter/X embeds. It is in the
Other package.

Use it to render Twitter/X embeds from content. It is a content-display/text-filter feature transforming
content on output; the embedded content is third-party (loads Twitter/X's script — a privacy/consent
consideration), and it has no access-control role. Add the filter to the appropriate text format.

Twig Nitro Bridge bridges to the Nitro Twig extension.

---

Twig Nitro Bridge is a **bridge to the Nitro Twig extension** — Nitro is a Twig rendering/performance
extension, and this module wires it into Drupal's Twig environment so themes can benefit from it. It is a
developer/theming feature.

Use it to enable the Nitro Twig extension in Drupal. It is a developer/performance utility affecting Twig
rendering; it has no content or access role. Enable it to bridge Nitro.

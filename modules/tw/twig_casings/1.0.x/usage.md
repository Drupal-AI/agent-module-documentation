---

Twig Casings provides **Twig filters** for converting strings between casing styles — camelCase,
kebab-case, MACRO_CASE, PascalCase, snake_case and Train-Case — so theme/template authors can reshape strings
(class names, machine names, labels) directly in Twig. It depends on core System.

Use it in templates/components to normalize string casing. It is a theming/developer utility exposing Twig
filters; it renders nothing on its own and has no content or access role. Use the filters in your Twig
templates.

# Twig Casings — agent index

**Twig filters** for converting strings between **camelCase, kebab-case, MACRO_CASE, PascalCase, snake_case,
Train-Case** (reshape class/machine names/labels in templates). Depends on core `system`. Version **1.0.5**.
Core `>=10`.

Theming/developer utility — Twig filters only (renders nothing); no content/access role.

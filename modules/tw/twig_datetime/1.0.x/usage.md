Twig DateTime adds a Twig function to create a datetime from a given date.

---

Twig DateTime **adds a Twig datetime helper** — a Twig function that creates a datetime object from a given
date string in templates, so theme developers can format/manipulate dates in Twig. It works across core 8–11.

Use it for date handling in Twig templates. It is a theming/developer feature; it adds a Twig function and has no
content or access role. Use the function in templates.

# Twig Font Awesome — agent index

Twig function to render **Font Awesome icons as inline SVGs** in templates (no webfont payload, full
CSS control). Version **1.0.0-beta3**. Core `>=8`.

Theming/developer utility — emits icon markup; icon names are developer-supplied in templates (no
access/data behaviour).

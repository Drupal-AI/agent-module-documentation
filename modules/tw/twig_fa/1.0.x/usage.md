Twig Font Awesome provides a Twig function to render Font Awesome icons as inline SVGs directly in templates.

---

Twig Font Awesome provides a Twig function that renders Font Awesome icons as inline SVGs from within
templates. Instead of loading the full Font Awesome webfont/CSS and using `<i class=...>` markup,
theme developers call the function to embed the icon's SVG directly, which avoids the webfont payload
and gives full CSS control over the vector. It is a lightweight theming helper.

Use it in a theme or module templates to place icons inline with minimal overhead. It is a
theming/developer utility — it emits icon SVG markup and has no access or data behaviour. Icon names
are provided by the developer in templates, not by end users.

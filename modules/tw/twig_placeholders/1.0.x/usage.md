Twig Placeholders provides Twig functions to generate placeholder content in templates.

---

Twig Placeholders provides **Twig functions that generate placeholder content** — dummy text, images or
values inside templates — so theme developers can prototype/preview layouts with realistic-looking placeholder
content without real data. It depends on core System.

Use it while building/prototyping themes. It is a theming/developer utility exposing Twig functions; the
placeholder content is generated (not real data) and it has no content or access role. Note it is a
**development aid** — placeholder output shouldn't ship in production templates. Use the functions in Twig.

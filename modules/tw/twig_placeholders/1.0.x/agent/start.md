# Twig Placeholders — agent index

Provides **Twig functions to generate placeholder (dummy) content in templates** (prototype layouts without
real data). Depends on core `system`. Version **1.0.1**. Core `>=10.3`.

Theming/developer utility — generated placeholder content (a **dev aid** — keep out of production); no content/
access role.

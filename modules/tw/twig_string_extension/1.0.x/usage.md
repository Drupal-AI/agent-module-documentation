Twig String Extension enables additional Twig String filters.

---

Twig String Extension **enables additional Twig filters from the Twig String Extra extension** — providing
string-manipulation filters (e.g. slug, truncate, title-case) for use in Drupal Twig templates. It is in the
Twig package.

Use it for richer string handling in templates. It is a theming/developer feature; template output still goes
through Twig autoescaping and it has no content or access role. Use the string filters in templates.

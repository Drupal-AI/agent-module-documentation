# Twig String Extension — agent index

Enables **additional filters from the Twig String Extra extension** (slug/truncate/case, …) in Drupal templates.
Version **1.0.2**. Core `^9||^10||^11`.

Theming/developer — output goes through Twig autoescaping; no content/access role.

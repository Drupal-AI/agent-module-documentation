Form Twig Template Suggester adds Twig template suggestions for form inputs.

---

Form Twig Template Suggester **adds Twig suggestions for form inputs** — providing cache-safe, namespaced
template suggestions for form elements (via form_alter metadata) so developers can theme specific form inputs. It
works on core 11.2, in the Development package.

Use it to theme individual form inputs. It is a theming/developer feature; it only adds template suggestions
(form_alter metadata) and has no content or access role. Use the suggested templates.

GDPR Alert allows you to display a GDPR consent alert.

---

GDPR Alert displays a **configurable GDPR consent alert/banner** — informing visitors about data/cookie
usage and recording their acknowledgement (cookie-based, via js_cookie). It depends on the JS Cookie library
module, provides its own permissions.

Use it to show a GDPR consent notice. It is a privacy/consent UI feature. Set expectations: it is a **consent
presentation** tool — real compliance depends on you **actually gating the tracking/cookie-setting scripts**
behind consent (a banner alone doesn't make a site compliant; ensure trackers don't fire before the user
accepts). It stores the acknowledgement as a cookie. It has no access-control role beyond its permission.
Configure the alert.

# GDPR Alert — agent index

Displays a configurable **GDPR consent alert/banner** (cookie-based acknowledgement via `js_cookie`). Provides
permissions. Version **1.x** (dev). Core `^9||^10||^11`.

Privacy/consent UX — a **presentation** tool: real compliance needs **actually gating trackers** behind consent
(a banner alone isn't compliance). No access role beyond permission.

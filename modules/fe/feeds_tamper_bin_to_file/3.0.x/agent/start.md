# Tamper Bin to File — agent index

Provides a **Feeds Tamper plugin to convert binary field data into Drupal file references**. Depends on `tamper`.
Version **3.0.0-beta1**. Core `^10.3||^11`.

Import/transformation — external binary becomes **managed files** (trust the source, validate types/extensions,
appropriate scheme); no access role.

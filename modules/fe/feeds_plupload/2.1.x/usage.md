A Feeds fetcher using the Plupload library for large file uploads.

---

Feeds Plupload provides a Feeds fetcher using the Plupload library — so a Feeds import can accept a large/chunked file upload (via Plupload) as its source, avoiding PHP upload-size limits for big import files. Depends on `feeds` and `plupload`; supports Drupal 10.2+ and 11.

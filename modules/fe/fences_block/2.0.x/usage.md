Fences block lets you alter the wrapping markup and classes of blocks, extending the Fences approach to block elements.

---

Fences block extends the Fences approach (control over field wrapper markup) to blocks — letting site
builders alter the HTML element and classes that wrap a block, so block markup can be tailored to a design
system without template overrides. It depends on core Block and the Fences module and provides its own
permissions.

Use it to clean up or standardize block markup (choosing wrapper tags/classes) declaratively. It is a
theming/markup feature affecting block output HTML; it does not change block content or access. Configure
the desired markup on the relevant blocks.

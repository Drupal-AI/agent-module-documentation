# Feeds Textarea Fetcher — agent index

A **Feeds fetcher where import data is pasted into a textarea** (no URL fetch). Depends on `feeds`, core `file`.
Version **1.0.2**. Core `^8.8.3||^9||^10||^11`.

Import/Feeds — data is **pasted by the operator** (no SSRF surface); processed under normal Feeds privileges. No
access role.

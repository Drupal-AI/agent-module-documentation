# Feeds XLS — agent index

Adds an **XLS/XLSX parser plugin to Feeds** (import from Excel spreadsheets — map columns to entity fields).
Depends on `feeds`. Version **2.0.0**. Core `^10||^11`.

Migration/import — parses spreadsheets server-side (run imports as trusted users, validate data); no access
role.

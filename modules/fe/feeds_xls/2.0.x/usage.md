Feeds XLS adds an Xls parser plugin for Feeds, letting Feeds import from Excel spreadsheets.

---

Feeds XLS adds an XLS/XLSX parser plugin to the Feeds module — so Feeds import configurations can read
Excel spreadsheets as a source, mapping spreadsheet columns to entity fields. It depends on the Feeds
module, in the Feeds package.

Use it to import content from Excel files via Feeds. It is a migration/import feature that parses uploaded/
fetched spreadsheets; the imported data becomes content per the Feeds mapping. As with any import, the
source file is parsed server-side (ensure the import is run/triggered by trusted users and validate the
data), and it has no access-control role. Configure the XLS parser on the Feed type.

# Feeds Tamper AI — agent index

An **AI-powered Tamper plugin for transforming Feeds import data** (summarize/translate/classify a feed field
during import). Version **1.0.1**. Core `^10||^11`.

Integration/data — **sends imported data to an AI model** (data egress if cloud — confirm acceptable); handle
AI **credentials** as secrets. No access role.

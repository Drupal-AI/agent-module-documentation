A Feeds parser that runs a simple XSLT pipeline.

---

Feeds XSLT Pipeline Parser implements a simple XSLT pipeline for Feeds — so an XML source can be transformed with XSLT stylesheets before parsing, letting site builders normalise/reshape arbitrary XML into a structure Feeds can import. Depends on `feeds`; supports Drupal 10 and 11.

Jquery Fireworks displays a canvas-based fireworks animation on the page, packaged as a Drupal block so site builders can place decorative fireworks in any region.

---

The module registers its JS/canvas library and provides a `JqueryFireworksBlock` plugin plus a hooks service (`JqueryFireworksHooks`) that attaches the library where the block is placed. Placement and visibility follow the standard block system (block admin UI, contexts and visibility conditions).

This is a purely decorative front-end effect with no data handling, routes or permissions of its own. It renders a client-side animation and has no access-control role.

---

- Show a canvas fireworks animation.
- Add fireworks via a placeable block.
- Place fireworks in any theme region.
- Use for celebratory or seasonal pages.
- Control visibility with block conditions.
- Attach the fireworks JS library automatically.
- Add festive effects without custom code.
- Render entirely client-side on canvas.
- Configure through the block settings form.
- Combine with other blocks in a region.
- Support modern Drupal 10/11/12 cores.
- Provide a lightweight decorative widget.
- Reuse Drupal's block placement and caching.
- Add no routes or permissions.
- Enhance landing or event pages visually.
- Toggle per page via visibility rules.

jQCloud provides blocks displaying taxonomy terms as a word cloud via jQCloud.

---

jQCloud **displays taxonomy terms as a word cloud** — blocks that render taxonomy terms in a word/tag cloud
using the jQCloud jQuery plugin, sized by usage. It depends on core Block.

Use it to show tag clouds. It is a content-display feature; term content follows normal taxonomy access and it has
no access-control role. Configure the word-cloud block.

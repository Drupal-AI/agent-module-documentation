# Jquery UI Field — agent index

Field type of **label/description** pairs rendered as jQuery UI **Tabs** or **Accordion**. Version **8.x-1.2** (dir `8.x-1.x`). Core `^8 || ^9 || ^10`.

- Type `JqueryuiFieldType`; formatters `JqueryuiFieldTabFormatter` (`#theme jqueryui_field`) and `JqueryuiFieldAccordionFormatter`.
- Depends on `field`. Display-layer only — no routes/permissions.

# jQuery ScrollUp — agent index

Smooth **back-to-top** button via the jQuery ScrollUp plugin. Version **2.0.0**. Core `^9.3 || ^10`.

- Settings `/admin/config/user-interface/jquery_scrollup` (route `jquery_scrollup.admin`, permission `access jquery scrollup settings`).
- `jquery_scrollup.api.php` documents alter hooks. Front-end UI only — permission gates the form, not content.

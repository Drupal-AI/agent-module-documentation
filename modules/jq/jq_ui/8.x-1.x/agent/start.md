# jQuery UI (jq_ui) — agent index

Provides the **jQuery UI library** (removed from core) as an asset library for modules/themes that still need
it. Version **8.x-1.9**. Core `^10||^11||^12`.

Developer/library — provides the library only; no content/access role. jQuery UI is **no longer actively
maintained** — use for legacy compatibility, prefer modern alternatives for new code.

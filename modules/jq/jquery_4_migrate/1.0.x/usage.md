jQuery 4 Migrate loads jQuery Migrate 4 to restore APIs removed in jQuery 4.

---

jQuery 4 Migrate adds the jQuery Migrate 4 library, which restores the API that was removed in jQuery 4 — helping older custom/contrib JavaScript keep working as Drupal core moves toward jQuery 4. It's a compatibility shim for the transition.

Administration is gated by `administer jquery 4 migrate`. It's a compatibility/developer utility with no content or access role. Requires Drupal 11.

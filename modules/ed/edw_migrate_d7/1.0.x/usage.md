EDW Migrate D7 is a developer toolkit of reusable Migrate source, process and destination plugins for building Drupal 7 to Drupal 8+ migrations.

---

EDW Migrate D7 provides a library of Migrate API plugins that you reference from your own migration configuration when upgrading a Drupal 7 site to Drupal 8, 9, 10 or 11. It ships no UI, routes, permissions, services or configuration and runs nothing on its own; you enable it and then name its plugins in the `source`, `process` and `destination` sections of your migration YAML. Source plugins extend core's D7 node, term, user, file and menu-link sources to add URL-alias handling, field-collection support, i18n and Entity Translation variants, plus draggableviews, locale-string and CSV sources. Process plugins download remote files into managed file entities, generate paragraph entities, flatten nested arrays and strip inline CSS. Destination plugins write directly to the `content_access`, `draggableviews_structure`, `locales_source` and `locales_target` tables. The module also implements `hook_migration_plugins_alter()` to drop the migrations auto-generated by Migrate Drupal, so the upgrade is driven entirely by the explicit migration configs you write. It depends on core Migrate together with Migrate Plus, Migrate Tools and Migrate Drupal, and migrations are run by a trusted operator via Drush or the Migrate Tools commands.

---

- Build a custom Drupal 7 to Drupal 10/11 upgrade instead of the automatic Migrate Drupal upgrade.
- Migrate D7 nodes with their URL aliases preserved using the `edw_d7_node` source.
- Pull D7 field-collection field values into a node migration.
- Migrate D7 taxonomy terms with parents, forum-container detection and Title-module fields via `edw_d7_taxonomy_term`.
- Migrate taxonomy term translations created with the i18n module (`edw_d7_taxonomy_term_i18n_translation`).
- Migrate taxonomy term translations created with Entity Translation (`edw_d7_taxonomy_term_et`).
- Migrate node translations created with Entity Translation, optionally filtered by node type (`edw_d7_node_entity_translation`).
- Migrate D7 users while skipping user 1 and remapping D7 role IDs to D8+ role machine names (`edw_d7_user`).
- Migrate D7 files with configurable public/private/temporary path constants (`edw_d7_file`).
- Migrate D7 menu links, converting `<void>` link paths to `<nolink>` (`edw_d7_menu_link`).
- Migrate Draggableviews ordering data from the D7 `draggableviews_structure` table.
- Migrate D7 interface-translation (locale) source strings and their translations.
- Import records from a CSV file into any destination using the `csv` source plugin.
- Download remote or D7 public-file URLs into managed file entities and store the resulting file ID with the `fid_download` process plugin.
- Rewrite `public://` URLs to an absolute domain during file download.
- Generate Paragraph entities from sub-processed source values with the `paragraph_generate` process plugin.
- Flatten an unpredictably nested source array down to its first scalar value with `deepest_value`.
- Strip inline `style` attributes (all, or only named CSS properties) from migrated markup with `strip_inline_styles`.
- Write migrated per-node access settings straight into the `content_access` table.
- Write migrated draggableviews ordering into the `draggableviews_structure` table.
- Populate the `locales_source` and `locales_target` tables with rollback support for interface translations.
- Suppress the auto-generated Migrate Drupal migrations so only your explicit migration configs run.
- Reuse the `EdwSource` trait's URL-alias lookup logic across your own custom D7 source plugins.
- Combine these plugins with Migrate Plus migration groups and Migrate Tools Drush commands for a repeatable upgrade workflow.

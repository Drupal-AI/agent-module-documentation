# Edit Entity (`edit_entity`)

Adds an 'Edit Entity' (and Translate) button to the admin toolbar on entity canonical pages, linking to the entity's edit form when the user has update access.

- Project: `edit_entity`, version `2.1.x`, core `^9 || ^10`.
- Category: Content editing experience / Admin toolbar / navigation.

See `../usage.md` for what it does, install/config, and usage/API details, and `../data.json` for structured metadata.

Integrate Transbank (Webpay) payment services via the official SDK.

---

Transbank integrates with Transbank services using their SDK — connecting Drupal Commerce to Transbank (Chile's main payment processor, e.g. Webpay / Oneclick) so customers can pay, using the official `transbank-sdk` for server-side transaction confirmation.

Transaction confirmation is delegated to the official Transbank SDK (server-side commit), the correct secure pattern. The Transbank commerce/API keys are admin-configured; store them securely (env-backed). Provides a Commerce payment gateway. Supports Drupal 10 and 11.

Trending Topics provides a block to display trending topics.

---

Trending Topics **provides a block that displays trending topics/content** — surfacing the most-viewed
content over a period, using core Statistics' view counts, to highlight popular items. It depends on core
Statistics.

Use it to show popular/trending content. It is a content-display/user-engagement feature; the block shows
published content the viewer can access (following access) and it has no access-control role. Note it relies on
core Statistics (which must be enabled and recording views). Place and configure the trending block.

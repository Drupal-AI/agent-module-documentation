Soft-delete comments via the Trash module.

---

Trash Comment integrates the Trash module with Drupal comments, including soft-delete support and deleted-parent placeholders — so deleting a comment moves it to the trash (recoverable) instead of permanent deletion, and threads with a trashed parent show a placeholder to keep replies coherent. Depends on core `comment` and `trash`; supports Drupal 11.1+.

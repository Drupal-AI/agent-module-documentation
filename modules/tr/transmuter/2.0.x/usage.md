Plugins that transmute elements and components (via Themespace).

---

Transmuter provides transmuter plugins that transmute elements and components — a developer framework (built on Themespace) for transforming render-array elements/components from one form into another via pluggable 'transmuter' plugins, enabling reusable render transformations. Depends on `themespace`; supports Drupal 11 and 12.

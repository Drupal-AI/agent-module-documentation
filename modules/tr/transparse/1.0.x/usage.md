Transparse parses and registers translatable strings.

---

Transparse **parses and registers translatable strings** — scanning source (e.g. templates/code) to extract
translatable strings and register them with Drupal's locale system, so they become available for translation. It
depends on core Locale, in the Custom package.

Use it to surface translatable strings for translators. It is a multilingual/developer tool; strings are code/
template text and it has no content or access role. Run the string parsing/registration.

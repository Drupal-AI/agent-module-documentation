Translation Extractor scans a directory to extract translatable strings.

---

Translation Extractor **scans a directory of a Drupal project to extract translatable strings** — walking
code/templates to collect `t()`/Twig translatable strings and produce `.po` translation files, for building
translations for custom code. It provides its own permissions, in the Multilingual package.

Use it as a developer aid to generate translation templates. It is a multilingual/developer tool; it reads
project source files and it has no content or access role beyond its permission. Run the extraction on a
directory.

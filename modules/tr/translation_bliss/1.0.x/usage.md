Translation Bliss provides Drush commands and APIs for translation workflows.

---

Translation Bliss **provides translation Drush commands and APIs** — developer tooling (Drush + API) to manage
config/content translation workflows programmatically. It works on core 10.1–11.

Use it as a developer/CLI aid for translations. It is a multilingual/developer feature. Security/data handling: if
its APIs/commands send content to an **external translation service**, that's egress (confirm acceptable) and any
provider credentials should be secrets. It has no access-control role. Use its Drush commands/APIs.

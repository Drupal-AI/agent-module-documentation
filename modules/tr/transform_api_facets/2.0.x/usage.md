Expose Facets through the Transform API for decoupled faceted search.

---

Transform API Facets integrates Facets into Transform API — so a decoupled/headless front end consuming the Transform API can retrieve and interact with faceted-search facets (filters) as part of the transformed JSON, enabling faceted search in headless setups. Depends on `facets` and `transform_api_views`; supports Drupal 10 and 11.

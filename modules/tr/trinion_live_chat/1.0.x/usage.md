A live-chat feature for the Trinion setup.

---

Trinion live chat provides a live chat feature for Trinion-based sites — letting visitors and staff exchange real-time chat messages (via REST endpoints), as part of the Trinion module suite. Depends on core `rest`, `serialization`, and `trinion_base`; supports Drupal 9, 10, and 11.

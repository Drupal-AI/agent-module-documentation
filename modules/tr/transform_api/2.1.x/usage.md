Expose routes and entities transformed to JSON via an API.

---

Transform API exposes routes and entities transformed to JSON with an API — a framework for building decoupled/headless JSON endpoints that transform Drupal entities (and custom routes) into a structured JSON representation, an alternative to JSON:API with its own transform layer. Depends on core `field_ui`; supports Drupal 10.3+ and 11.

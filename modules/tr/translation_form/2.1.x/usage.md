Translation Form provides inline translation help in forms.

---

Translation Form **provides inline translation help/editing in content forms** — surfacing translation
context (source values, missing translations) directly in the entity edit form so translators can work in place,
using core Content Translation. It depends on core Content Translation.

Use it to ease in-form translation. It is a multilingual/content-editing feature affecting the edit form;
translation access follows core Content Translation's own permissions and it has no access-control role. Enable
it for translated content types.

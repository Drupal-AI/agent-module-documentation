TripAdvisor Integration provides a TripAdvisor field type where users add the TripAdvisor ID of the content to integrate.

---

TripAdvisor Integration provides a TripAdvisor field type — editors enter a TripAdvisor ID for the
location/content to integrate, and the module embeds the corresponding TripAdvisor widget (reviews/rating
badge) on the site. It is configured at `tripadvisor_integration.admin_settings`, in the Fields package.

Use it to show TripAdvisor reviews/badges on content. It is a content-display/integration feature; it embeds
TripAdvisor's third-party widget (loading their script — a privacy/consent consideration), and any TripAdvisor
API credential should be stored as a secret. It has no access-control role. Configure the TripAdvisor field
and settings.

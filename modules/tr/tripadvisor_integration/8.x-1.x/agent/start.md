# TripAdvisor Integration — agent index

Provides a **TripAdvisor field type** for embedding TripAdvisor content by ID (reviews/rating badge widget).
Config at `tripadvisor_integration.admin_settings`. Version **8.x-1.3**. Core `^10.1||^11`.

Content-display/integration — embeds TripAdvisor's third-party widget (privacy/consent); store any API
credential as a secret. No access role.

Trinion changelog logs field-level changes on node save for an audit trail.

---

Trinion changelog solves the problem of tracking node changes by recording a change log of all changes made when saving nodes — capturing what changed (fields, values) on each save, so operators/editors have an audit trail of content edits over time.

Because change logs can contain sensitive field data, restrict access to the log and consider retention. Depends on core `node` and `views`; supports Drupal 9, 10, and 11.

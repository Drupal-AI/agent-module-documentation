Tranc translates strings to the content language.

---

Tranc **translates strings to the current content language** — providing a way to render strings in the
active content language (as opposed to the interface language), useful on multilingual sites where content-
language string translation is needed. It ships a `tranc_config` submodule.

Use it for content-language string translation. It is a multilingual/display feature; it translates strings
for display and has no content or access role. Configure the string translations.

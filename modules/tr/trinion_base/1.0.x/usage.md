A base/foundation module bundling configuration for the Trinion setup.

---

Trinion base is the base module for the Trinion setup — a foundation module that pulls in a curated set of contrib modules and ships baseline configuration (content model, editorial, permissions, editor, media) so a site starts from a consistent Trinion baseline. Depends on core `user`, `views`, `file`, `image`, `options`, `path`, `ckeditor5`, `menu_ui`, `taxonomy`, plus `views_bulk_operations`, `views_bulk_edit`, `twig_tweak`, `email_registration`, and `trinion_permissions`; supports Drupal 9, 10, and 11.

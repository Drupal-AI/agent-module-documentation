A simplified permissions table with non-essential settings removed.

---

Trinion permissions provides a permissions table with access rights from which all 'unnecessary' settings (unnecessary from the content creator's point of view) are removed — a decluttered permissions UI that hides the many low-level permissions site editors don't need, making role configuration simpler. Depends on core `user`; supports Drupal 9, 10, and 11.

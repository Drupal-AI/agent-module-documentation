Generate CSL citations for Islandora repository objects.

---

Citation Style Language (islandora_csl) generates Citation Style Language citations for Islandora repository objects — so a repository object's metadata is formatted into a scholarly citation (APA, MLA, Chicago, etc. via CSL styles), useful for academic/library repositories. Depends on `islandora` and `controlled_access_terms`; supports Drupal 10 and 11.

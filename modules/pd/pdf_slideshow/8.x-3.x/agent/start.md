# PDF Slideshow — agent index

Displays **PDF documents as an image slideshow** (browse PDF pages page-by-page without downloading). Config
at `pdf_slideshow.list_controller_list`; provides permissions. Version **8.x-3.1**. Core `^9.3||^10||^11`.

Media/display — renders PDF pages as images (PDF is authored content, follows normal file access); no access
role beyond permission.

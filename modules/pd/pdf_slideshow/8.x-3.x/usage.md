PDF Slideshow displays PDF documents as a slideshow of images.

---

PDF Slideshow displays PDF documents as a slideshow — converting/presenting a PDF's pages as a
navigable image slideshow, so visitors can browse a PDF page-by-page on the site without downloading it. It
is configured at `pdf_slideshow.list_controller_list`, provides its own permissions, in the Media package.

Use it to present PDFs as slideshows. It is a media/display feature that renders PDF pages as images; the PDF
is authored content, and access to it follows normal file access. It has no access-control role beyond its
permission. Configure the slideshow display.

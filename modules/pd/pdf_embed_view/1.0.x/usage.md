Embed and display PDF files inline, in a modal, or a new tab.

---

PDF Embed View embeds and displays PDF files inline, in a modal dialog, or in a new tab — a field formatter for file/media PDF fields so a PDF renders directly on the page (or opens in a modal/new tab) instead of just a download link, improving document display. Depends on core `field` and `media`; supports Drupal 10 and 11.

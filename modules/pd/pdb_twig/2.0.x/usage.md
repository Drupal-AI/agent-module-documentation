PDB Twig lets Progressively Decoupled Blocks use Twig components.

---

PDB Twig enables Twig components for use by Progressively Decoupled Blocks (PDB) — so developers building progressively-decoupled front-end blocks can implement them as Twig components alongside the JS-framework options PDB supports, giving a lighter-weight component option.

It's a developer/decoupling tool with no content or access role of its own. Depends on `pdb`; supports Drupal 10.2+ and 11.

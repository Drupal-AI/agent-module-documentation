Reduce the file size of uploaded PDFs.

---

PDF Reducer reduces the byte size of uploaded PDF files, for better performance — compressing/optimising PDFs on upload (downsampling images, stripping bloat) so they download faster and use less storage. It needs a PDF processing tool (e.g. Ghostscript) available. Supports Drupal 11.

Swoosh reports Web Vitals metrics to the Swoosh backend.

---

Swoosh **reports Web Vitals to the Swoosh backend** — collecting Core Web Vitals (LCP, CLS, INP, etc.) from
visitors' browsers and sending them to the Swoosh performance-monitoring service. It works on core 10–11.

Use it to monitor real-user performance. It is a performance/analytics integration. Security/data handling: it
**sends performance metrics (and possibly URL/session context) to the external Swoosh backend** (egress — disclose
per privacy policy, mind consent for any tracking) and any backend credentials should be secrets. It has no
access-control role. Configure the Swoosh reporting.

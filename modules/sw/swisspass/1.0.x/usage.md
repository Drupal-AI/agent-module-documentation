SwissPass provides a SwissPass number input element for forms and Webforms.

---

SwissPass **provides a SwissPass number input element** — a form/Webform element for entering a SwissPass
number (the Swiss public-transport customer card), with format validation (`000-000-000-0`). It depends on the
Webform module.

Use it to collect SwissPass numbers in forms. It is a forms/field element (not authentication). Data-handling
note: a SwissPass number is a **personal identifier (PII)** — collect it only when needed, store/transmit it
securely, and handle it per your privacy policy. It has no access-control role. Add the element to a form.

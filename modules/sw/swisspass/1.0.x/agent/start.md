# SwissPass — agent index

**Provides a SwissPass number input element for forms and Webforms** (format validation). Depends on `webform`.
Version **1.0.0-beta5**. Core `^10.3||^11`.

Forms/field element (not auth) — a SwissPass number is **PII** (collect only when needed, store securely, handle
per policy); no access role.

Switch Theme provides a theme negotiator depending on role.

---

Switch Theme provides a **theme negotiator that selects the active theme based on the user's role** — so
different roles (e.g. editors vs anonymous) can see a different front-end theme. It is in the Custom package.

Use it to serve role-specific themes. It is a theming feature and it controls **presentation only** — the theme
a user sees is not an access-control boundary (changing the theme does not restrict content or capabilities;
never rely on a theme to hide sensitive data). It has no access-control role. Configure the role-to-theme
mapping.

Swiper Cards provides a Swiper Cards block for entering slider content.

---

Swiper Cards provides a **block for configurable slider "cards"** using the Swiper library — you enter
slides (cards) and it renders them as a Swiper carousel, for hero/feature sliders. It depends on core Block, in
the Swiper Cards package.

Use it to add a Swiper card slider block. It is a content-display feature; card content is admin/editor-authored
(rendered markup — keep trusted) and it has no access-control role. Place and configure the Swiper Cards
block.

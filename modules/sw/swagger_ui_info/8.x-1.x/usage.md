Swagger UI Info displays info via Swagger UI.

---

Swagger UI Info **displays API information via an embedded Swagger UI** — rendering an OpenAPI/Swagger
specification in the interactive Swagger UI so developers can browse and try the site's API. It provides its own
permissions.

Use it to document/browse your API. It is a developer/API-docs feature. Security note: an API-explorer UI can
reveal your **API surface** (endpoints, parameters) and lets users make calls — gate the route to the intended
audience (its permission), don't expose internal/undocumented endpoints publicly, and remember any "try it"
calls run with the caller's own auth. It has no access-control role beyond its permission. Configure the spec and
access.

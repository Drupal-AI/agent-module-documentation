Swup integrates Swup.js for page transitions.

---

Swup integrates **Swup.js** — a library for animated, SPA-like page transitions that swaps page content via
AJAX instead of a full reload, for smoother navigation. It is in the User interface package.

Use it for animated page transitions. It is a front-end/UX feature affecting navigation/rendering; the content
it loads still comes from normal (access-respecting) page requests, and it has no content or access role.
Configure Swup on the site.

Skpr Logs logs system events for the Skpr Hosting Platform.

---

Skpr Logs logs system events for the Skpr hosting platform — integrating Drupal's logging with Skpr's
log infrastructure so events are captured in the platform's centralized logging (for sites hosted on Skpr).
It is in the Logging package.

Use it on Skpr-hosted sites to route logs to the platform. It is a developer/logging feature; it forwards log
events to the hosting platform's logging and has no content or access role. As with any logging, avoid
logging sensitive data. Enable it on Skpr-hosted environments.

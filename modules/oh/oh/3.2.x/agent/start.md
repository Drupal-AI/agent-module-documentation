# OH (Opening Hours) — agent index

An **alternative opening-hours module** — define (recurring via Date Recur), display, and query business hours
(`date_recur_oh_field`, `oh_regular`, `oh_review` submodules). Depends on `date_recur`. Version **3.2.3**. Core
`>=10`.

Content-display — hours are admin/editor content; no access role.
